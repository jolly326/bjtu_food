# 敏感词库（UGC 本地审核第一级，LocalSensitiveFilter 启动期载入 DFA 字典树）
#
# 位置约定：**必须放在 src/main/resources/ 根下**。LocalSensitiveFilter 用
# `new ClassPathResource("sensitive_words.txt")` 从 classpath 根加载，
# 放在 server/ 项目根不会被打进 jar，运行期只 log.warn 后静默跳过 → 本地过滤整体失效。
#
# 格式：一行一个词，UTF-8；空行与以 # 开头的行会被忽略。
# 分工：本文件为**本地低成本兜底**（命中替换为 *，不拦截）；
#      权威判定是微信 msgSecCheck v2（moderation.service.ContentSecurityService#checkText）。
#      本表**替代不了**远端审核，仅用于拦掉高频低级脏词、减少远端调用。
#
# 维护约定：新增词条时保持「一行一词」，避免空格与全角标点（DFA 按字符匹配）。
#           本文件不随请求热更新，改动后需重启应用生效。
