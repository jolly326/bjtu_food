## 2. 小程序（前端）上线

### 2.1 服务器域名（硬性前置条件）

小程序正式版**必须**配置合法服务器域名（微信官方要求），**本项目是自建 Spring Boot 后端，云开发/云托管免域名方案不适用**：

| 要求 | 说明 |
|------|------|
| 必须 HTTPS | 正式版不支持 http；开发/体验版可在开发者工具勾选「不校验合法域名」临时绕过 |
| 必须是域名，不能是 IP | `127.0.0.1` / 局域网 IP 都不能上线 |
| 不能带端口 | 443 默认；后端 8080 由 Nginx 反代隐藏 |
| 需 ICP 备案 | 中国大陆服务器域名必须备案（约 1-3 周） |
| request + uploadFile | `https://你的域名` 需同时加入微信后台「request 合法域名」和「uploadFile 合法域名」两个白名单 |

**无域名时的两条路线**：
1. **国内服务器**：购买域名 → ICP 备案 → Nginx HTTPS → 反代 `/api` 到 8080（推荐，延迟低、正式）
2. **海外服务器**：域名免备案可快速启用（仍需域名 + HTTPS），延迟略高
3. **微信网关（可选增强）**：若担心爬虫/刷接口，可免费接入微信网关做安全防护（防爬/防刷/防攻击），不影响域名配置

## 上线顺序建议

```
第1步 后端部署（D-1~D-9）          → 环境就绪
第2步 数据初始化（C-1~C-5）        → 内容就绪
第3步 小程序配置（F-1~F-5）        → 合规就绪
第4步 构建上传 + 真机回归（F-6~F-8）
第5步 提交审核（微信侧审核）
第6步 上线发布 → 首日运营值班（O-1~O-4）
```

> 提示：`application-secret.yml`（SMTP 授权码）不入库，生产用环境变量注入；`migration_phase6/7.sql` 幂等可重复执行，用于旧库补齐。
