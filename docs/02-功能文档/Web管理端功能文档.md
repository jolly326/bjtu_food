# 功能文档 — Web 管理端

> 版本：v2.0 | 更新日期：2026-07
>
> 仅系统管理员（admin）使用。只描述功能点，不涉及 UI 设计。

---

## 一、登录

管理员通过账号密码登录。

---

## 二、数据概览

| 编号 | 功能 | 说明 |
|------|------|------|
| A01 | 查看综合评分 | 全平台菜品平均评分 |
| A02 | 查看评论总数 | 累计评价数 |
| A03 | 查看活跃学生数 | 近期有操作的学生数 |
| A04 | 查看食堂/档口/菜品/学生统计 | 各维度数量 |
| A05 | 查看评论趋势 | 按天/周/月的评论量变化 |
| A06 | 查看排行 | 食堂评分排行、菜品热门排行 |
| A07 | 查看最新反馈 | 来自用户反馈的最新内容 |

---

## 三、食堂管理

| 编号 | 功能 | 说明 |
|------|------|------|
| B01 | 查看食堂列表 | 展示所有食堂 |
| B02 | 新增食堂 | 填写名称、位置、描述、封面图 |
| B03 | 编辑食堂 | 修改食堂信息 |
| B04 | 删除食堂 | 确认后删除 |
| B05 | 切换食堂状态 | 开放/关闭 |

---

## 四、档口管理

| 编号 | 功能 | 说明 |
|------|------|------|
| D01 | 查看档口列表 | 展示档口及所属食堂 |
| D02 | 新增档口 | 填写名称、位置、描述，选择所属食堂 |
| D03 | 编辑档口 | 修改档口信息 |
| D04 | 删除档口 | 确认后删除 |
| D05 | 绑定档口老板 | 将用户设为档口老板（role=stall_owner） |
| D06 | 切换档口状态 | 开放/关闭 |

---

## 五、菜品管理

| 编号 | 功能 | 说明 |
|------|------|------|
| E01 | 查看菜品列表 | 展示名称、价格、档口、标签、审核状态 |
| E02 | 新增菜品 | 管理员手动新增菜品 |
| E03 | 编辑菜品 | 修改菜品信息 |
| E04 | 下架菜品 | 软删除，小程序不可见 |
| E05 | 查看审核状态 | 查看 pending/approved/rejected |

---

## 六、内容审核

| 编号 | 功能 | 说明 |
|------|------|------|
| F01 | 查看待审核内容 | 档口提交的菜品/活动，含内容和提交时间 |
| F02 | 审核通过 | status → approved，小程序可见 |
| F03 | 审核驳回 | status → rejected，档口可重新提交 |

---

## 七、评价审核

| 编号 | 功能 | 说明 |
|------|------|------|
| G01 | 查看评价列表 | 展示用户、菜品、评分、内容、图片 |
| G02 | 隐藏评价 | 隐藏后小程序不可见 |
| G03 | 显示评价 | 恢复被隐藏的评价 |
| G04 | 删除评价 | 物理删除 |

---

## 八、轮播图管理

| 编号 | 功能 | 说明 |
|------|------|------|
| H01 | 查看轮播图列表 | 展示标题、封面、状态 |
| H02 | 新增轮播图 | 填写标题、副标题、上传图片、设置跳转 |
| H03 | 编辑轮播图 | 修改轮播图信息 |
| H04 | 删除轮播图 | 确认后删除 |
| H05 | 排序 | 调整轮播图顺序 |

---

## 九、用户管理

| 编号 | 功能 | 说明 |
|------|------|------|
| I01 | 查看用户列表 | 头像、昵称、用户名、邮箱、角色、状态 |
| I02 | 搜索用户 | 按用户名或昵称搜索 |
| I03 | 修改角色 | 将用户设为档口老板 |
| I04 | 禁用用户 | 用户不可登录，可恢复 |
| I05 | 冻结用户 | 账号暂时冻结，可解冻 |
| I06 | 封禁用户 | 永久封禁，不可解封 |
| I07 | 解封用户 | 恢复禁用/冻结的账号 |

---

## 十、账号设置

| 编号 | 功能 | 说明 |
|------|------|------|
| J01 | 编辑个人信息 | 昵称、头像 |
| J02 | 修改密码 | 当前密码 + 新密码 + 确认密码 |
