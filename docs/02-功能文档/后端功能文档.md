# 功能文档 — 后端

> 版本：v2.0 | 更新日期：2026-07
>
> 后端服务支撑三端业务。只描述功能模块和接口，不涉及实现细节。

---

## 一、模块划分

| 模块 | 核心职责 |
|------|---------|
| common | 全局配置、统一响应、异常处理、JWT工具、敏感词过滤、图片URL处理 |
| auth | 登录/注册/JWT/邮箱验证码/用户资料，支持 user/stall_owner/admin 角色 |
| canteen | 食堂/档口/轮播图 CRUD，档口绑定档口老板 |
| dish | 菜品查询/搜索/详情/浏览量/评分同步/审核状态管理/活动管理/标签管理 |
| review | 评价提交/编辑/删除/"喜欢"投票/评价审核 |
| content | 档口发布内容审核（通过/驳回） |
| favorite | 收藏/取消/批量收藏（前端MVP暂不使用） |
| list | 美食清单创建/查看/删除/分享 |
| upload | 图片上传（本地存储，按日期分目录） |

## 三、数据隔离

| 角色 | 数据范围 |
|------|---------|
| 学生/游客 | 只读，不可写档口数据 |
| 档口老板 | 只读写 `stall.owner_id = 自己` 的数据 |
| 管理员 | 全量读写 |

---

## 四、审核流程

档口提交菜品/活动 → status = pending → 管理员审核 → 通过（approved）/ 驳回（rejected）→ 通过后小程序可见，驳回后档口可重提
