# 功能文档 — 微信小程序端

> 版本：v2.0 | 更新日期：2026-07
>
> 只描述功能点，不涉及 UI 布局和交互设计。

---

## 一、首页

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| H01 | 展示轮播图 | 全部 | 自动轮播，可点击跳转至对应页面 |
| H02 | 展示食堂卡片，可切换筛选菜品 | 全部 | 点击食堂卡片，菜品列表切换为该食堂的菜品 |
| H03 | 展示"今日上新"菜品 | 全部 | 展示带"新"标签的菜品，点击跳转菜品详情 |
| H04 | 展示"限时活动"菜品 | 全部 | 展示特价菜品及活动倒计时，点击跳转菜品详情 |
| H05 | 展示热门菜品瀑布流 | 全部 | 默认展示全部食堂，按热度排序 |

---

## 二、发现页

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| F01 | 关键词搜索菜品 | 全部 | 按菜品名称模糊匹配搜索 |
| F02 | 分类标签筛选 | 全部 | 支持标签：今日上新 / 限时活动 / 本周热门 / 高分必吃 |
| F03 | 搜索结果展示 | 全部 | 搜索和筛选结果以列表形式展示 |

---

## 三、菜品详情

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| D01 | 查看菜品信息 | 全部 | 名称、价格、评分、评价数、档口位置 |
| D02 | 查看新品/活动标签 | 全部 | 新品显示"新"标签，活动显示特价和倒计时 |
| D03 | 查看评价列表 | 全部 | 展示用户评价内容、评分、图片 |
| D04 | 评价"喜欢"投票 | 学生/档口老板 | 点击"喜欢"投票，需登录，一人一票 |
| D05 | 跳转档口详情 | 全部 | 点击档口位置信息可进入档口详情页 |
| D06 | 跳转发表评价 | 学生/档口老板 | 未登录引导登录，已登录进入评价页 |

---

## 四、发表评价

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| R01 | 评分 | 学生/档口老板 | 1-5 星评分，必填 |
| R02 | 文字评价 | 学生/档口老板 | 文字输入，最多 500 字 |
| R03 | 图片上传 | 学生/档口老板 | 从相册选择，最多 3 张 |
| R04 | 提交评价 | 学生/档口老板 | 评分不为空且内容不为空时可提交 |

---

## 五、食堂详情

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| C01 | 查看食堂下档口列表 | 全部 | 展示档口名称/评分/菜品数 |
| C02 | 跳转档口详情 | 全部 | 点击档口进入档口详情页 |

## 六、档口详情

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| S01 | 查看档口信息 | 全部 | 名称、位置、描述、图片 |
| S02 | 查看档口菜品列表 | 全部 | 该档口全部菜品，可点击进入详情 |

## 七、个人中心

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| P01 | 登录 | 未登录 | 支持密码登录和邮箱验证码登录 |
| P02 | 注册 | 未登录 | 需校园邮箱验证，仅限 @bjtu.edu.cn |
| P03 | 找回密码 | 未登录 | 通过邮箱验证码重置密码 |
| P04 | 查看/编辑个人信息 | 已登录 | 头像、昵称 |
| P05 | 查看统计数据 | 已登录 | 评价数 |
| P06 | 查看版本号和产品介绍 | 已登录 | 展示当前版本和平台说明 |
| P07 | 联系开发者入口 | 已登录 | 跳转联系开发者页面 |
| P08 | 退出登录 | 已登录 | 清除登录状态 |
| P09 | 我的档口入口 | 档口老板 | 额外显示入口，跳转档口管理模块 |

## 八、联系开发者

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| K01 | 提交反馈 | 已登录 | 填写建议或 Bug 描述，选填联系方式 |
| K02 | 提交 | 已登录 | 提交后存入反馈表 |

---

## 九、档口老板管理

| 编号 | 功能 | 角色 | 说明 |
|------|------|------|------|
| M01 | 查看档口概览 | 档口老板 | 档口信息、菜品数、浏览量、评价数 |
| M02 | 新增菜品 | 档口老板 | 填写名称、价格、图片、标签、描述，提交后待审核 |
| M03 | 编辑菜品 | 档口老板 | 修改已发布的菜品信息 |
| M04 | 设置活动/特价 | 档口老板 | 选择菜品，设置活动价和截止时间 |
| M05 | 标记新品 | 档口老板 | 将菜品标记为新品 |
| M06 | 查看审核状态 | 档口老板 | 查看菜品审核进度（待审核/已通过/已驳回） |
| M07 | 重新提交 | 档口老板 | 驳回后可修改后重新提交审核 |
