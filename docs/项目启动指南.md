# 食在交大 · 项目启动配置指南

---

## 项目结构

```
bjtu_food/
├── backend/          # Spring Boot 后端 (Java 21)
├── frontend/         # Uni-App 微信小程序 (Vue 3 + Vite)
├── web/              # 浏览器后台管理系统 (Vue 3 + ECharts)
└── docs/             # 文档（产品定义/需求分析/功能文档/设计文档）
```

---

## 1. 后端启动

### 前置条件
- JDK 21、Maven 3.6+、MySQL 8.0

### 数据库配置
云端默认：`39.105.66.79:3306/bjtu_food`（用户 bjtu，密码 123456）

本地开发修改 `application-dev.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/bjtu_food?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: 你的密码
```

### 启动命令
```bash
cd backend
mvn spring-boot:run
```

### 访问地址
| 项目 | 地址 |
|------|------|
| API 基础路径 | `http://localhost:8080/api` |
| Knife4j 文档 | `http://localhost:8080/api/doc.html` |

### 预置测试账号
| 角色 | 用户名 | 密码 |

| 学生用户 | `20240001` | `123456` |
| 管理员 | `admin001` | `123456` |

## 2. 小程序端启动

### 前置条件
- Node.js >= 18、微信开发者工具

### 启动命令
```bash
cd frontend
npm install
npm run dev:mp-weixin
```

编译产物：`frontend/dist/dev/mp-weixin`

### 微信开发者工具导入
1. 导入项目，目录选择 `frontend/dist/dev/mp-weixin`
2. AppID：`wx2bd6e4b461467b74`
3. 详情 → 本地设置 → **不校验合法域名**

### API 地址配置
修改 `frontend/src/api/config.ts`：
```typescript
export const API_BASE_URL = 'http://localhost:8080/api'  // 本机
// export const API_BASE_URL = 'http://192.168.x.x:8080/api'  // 真机调试
```

## 3. 管理后台端启动

### 前置条件
- Node.js >= 20、pnpm

### 启动命令
```bash
cd web
pnpm install
pnpm dev
```

访问 `http://localhost:5173`，管理员登录 `admin001 / 123456`

---

## 4. 启动顺序

```
1. 后端：cd backend && mvn spring-boot:run
2. 管理后台：cd web && pnpm dev
3. 小程序：cd frontend && npm run dev:mp-weixin
```

验证：
- `http://localhost:8080/api/doc.html` → 后端运行
- `http://localhost:5173` → 管理后台
- 微信开发者工具 → 小程序

---

## 5. 常见问题

| 问题 | 解决方案 |
|------|---------|
| 后端连不上数据库 | 检查 application.yml 中的数据库配置 |
| 图片无法显示 | 检查 `app.public-base-url` 和上传目录 |
| 小程序图片不显示 | 开发者工具设置→不校验合法域名 |
| 验证码发送失败 | 配置 QQ 邮箱 SMTP 并获取授权码 |
