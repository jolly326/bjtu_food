# 食在交大 · 项目启动配置指南

## 项目结构

```
bjtu_food/
├── backend/          # Spring Boot 后端 (Java 21)
├── frontend/         # Uni-App 微信小程序 + H5 (Vue 3 + Vite)
├── web/              # 浏览器后台管理系统 (Vue 3 + Vite + ECharts)
└── docs/             # 文档
```

---

## 1. 后端启动 (backend)

### 1.1 技术栈
- Java 21 + Spring Boot 3.2 + MyBatis-Plus + MySQL 8.0 + JWT + Knife4j

### 1.2 前置条件
- JDK 21
- Maven 3.6+
- MySQL 8.0（可直接连接远端 `39.105.66.79` 或启动本地数据库）

### 1.3 数据库
云端数据库地址默认配置：
```
Host: 39.105.66.79
Port: 3306
Database: bjtu_food
Username: bjtu
Password: 123456
```

如需连接本地数据库，修改 `application-dev.yml`：
```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/bjtu_food?useUnicode=true&characterEncoding=utf-8&serverTimezone=Asia/Shanghai
    username: root
    password: 你的密码
```

初始化建表与种子数据：
```bash
mysql -h 39.105.66.79 -u bjtu -p bjtu_food < docs/bjtu_food_base.sql
```

### 1.4 SMTP 邮箱配置
发送验证码需配置 SMTP（QQ 邮箱示例，需开启 SMTP 服务）：
```yaml
# application.yml 中 spring.mail 部分
spring:
  mail:
    host: smtp.qq.com
    port: 465
    username: 你的QQ邮箱@qq.com
    password: SMTP授权码（非邮箱密码）
```

### 1.5 启动命令
```bash
cd backend
mvn spring-boot:run
```

### 1.6 访问地址
| 项目 | 地址 |
|------|------|
| API 基础路径 | `http://localhost:8080/api` |
| Knife4j 文档 | `http://localhost:8080/api/doc.html` |

### 1.7 预置测试账号
| 角色 | 用户名 | 密码 | 邮箱 |
|------|--------|------|------|
| 普通用户 | `20240001` | `123456` | `20240001@bjtu.edu.cn` |
| 管理员 | `admin001` | `123456` | `admin001@bjtu.edu.cn` |

### 1.8 环境变量（可选）

| 变量 | 说明 | 默认值 |
|------|------|--------|
| `APP_PUBLIC_BASE_URL` | 图片访问基础 URL | `http://localhost:8080/api` |
| `UPLOAD_PATH` | 上传文件存储路径 | `./uploads/images` |
| `MAIL_HOST` | SMTP 服务器 | `smtp.example.com` |
| `MAIL_PORT` | SMTP 端口 | `465` |
| `MAIL_USERNAME` | SMTP 用户名 | 空 |
| `MAIL_PASSWORD` | SMTP 密码 | 空 |

## 2. 小程序端启动 (frontend)

### 2.1 技术栈
- uni-app (Vue 3 + TypeScript + Vite) → 微信小程序 / H5

### 2.2 前置条件
- Node.js >= 18（推荐使用 nvm 管理版本）
- npm >= 8
- **微信开发者工具**（最新稳定版）

### 2.3 安装依赖
```bash
cd frontend
npm install
```

### 2.4 配置 API 地址

**文件：** `frontend/src/api/config.ts`

```typescript
// 小程序运行时指向后端地址
export const API_BASE_URL = 'http://10.218.135.128:8080/api'
```

> **开发环境**：后端在本机运行，改为 `http://localhost:8080/api`
>
> **真机调试**：改为电脑局域网 IP，如 `http://192.168.x.x:8080/api`

### 2.5 图片处理配置

**文件：** `frontend/src/utils/image.ts`

当前为 Mock 阶段直接透传路径。切换到真实后端后，取消注释 `IMAGE_BASE`：

```typescript
const IMAGE_BASE = 'http://10.218.135.128:8080/api'  // 取消注释后拼接完整 URL
```

> 说明：真实后端已经通过 `ImageUrlUtil` 返回完整绝对 URL（如 `http://.../api/images/...`），
> `getImageUrl()` 对以 `http://` 开头的 URL 会直接透传，因此**即使不取消注释也不影响图片显示**。
> 仅在需要将本地相对路径转为完整 URL 时才需开启。

### 2.6 启动

| 平台 | 命令 | 说明 |
|------|------|------|
| H5 (浏览器) | `npm run dev:h5` | 启动后浏览器打开 `http://localhost:5173` |
| 微信小程序 | `npm run dev:mp-weixin` | 编译后需在微信开发者工具中导入产物目录 |

编译输出目录：`frontend/dist/dev/mp-weixin`

> 如果只需一次性构建（不监听文件变更），可使用：
> ```bash
> npm run build:mp-weixin
> ```

### 2.7 微信开发者工具导入

1. 打开 **微信开发者工具**
2. 点击 **导入项目**
3. **项目目录** 选择：`bjtu_food/frontend/dist/dev/mp-weixin`
4. **AppID**：`wx2bd6e4b461467b74`（已在 `src/manifest.json` 中配置），也可使用测试号
5. 点击 **导入** 即可预览
6. 详情 → 本地设置 → **不校验合法域名**（开发阶段开启）

### 2.8 真机调试
- 确保手机和电脑在同一局域网
- API 地址使用电脑局域网 IP，如 `http://192.168.x.x:8080/api`

## 3. 浏览器后台管理端启动 (web)

### 3.1 技术栈
- Vue 3 + TypeScript + Vite + Pinia + Vue Router + ECharts

### 3.2 前置条件
- Node.js >= 20.19（package.json engines 要求）
- pnpm（项目使用 pnpm-lock.yaml）

### 3.3 配置 API 地址

**文件：** `web/src/api/config.ts`

```typescript
export const API_BASE_URL = 'http://localhost:8080/api'
```

> 后端部署在远端时，改为远端服务器地址，例如 `http://39.105.66.79:8080/api`

### 3.4 安装依赖
```bash
cd web
pnpm install
```

### 3.5 启动
```bash
pnpm dev
```

浏览器访问 `http://localhost:5173`（Vite 默认端口）。

> ⚠️ 注意：如遇端口冲突，可通过 `--port` 参数修改：
> ```bash
> pnpm dev -- --port 3000
> ```

### 3.6 构建
```bash
pnpm build
```

构建产物在 `dist/` 目录，可部署到 Nginx 等静态服务器。

## 4. 端到端启动流程（推荐顺序）

```
1. 启动后端
   └─ cd backend && mvn spring-boot:run

2. 启动浏览器后台
   └─ cd web && pnpm dev

3. 启动小程序 H5 开发模式
   └─ cd frontend && npm run dev:h5

4. 验证
   └─ 浏览器访问 http://localhost:8080/api/doc.html 确认后端运行
   └─ 浏览器访问 http://localhost:5173      确认后台管理端运行
   └─ 浏览器访问 http://localhost:5174      确认小程序 H5 运行
```

## 6. 常见问题

### 6.1 后端连不上数据库
检查 `application.yml`/`application-dev.yml` 中的数据库地址、用户名、密码是否正确。

### 6.2 图片无法显示
1. 检查 `app.public-base-url` 配置是否正确
2. 检查 `WebMvcConfig` 中 `/images/**` 映射的目录是否正确
3. 检查上传目录 `./uploads/images` 是否存在且包含图片文件

### 6.3 小程序端图片不显示
1. 确保 `API_BASE_URL` 指向可访问的后端地址
2. 微信开发者工具设置 → 不校验合法域名
3. 真机调试时确保手机能访问电脑 IP

### 6.4 验证码发送失败
1. 检查 `spring.mail` 配置是否正确
2. QQ 邮箱需开启 SMTP 服务并获取授权码（非邮箱密码）
3. 检查网络是否能连接 SMTP 服务器

### 6.5 端口冲突
```bash
# 后端
mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8081

# 前端 H5（在 vite.config.ts 中配置）
export default defineConfig({
  server: { port: 3000 },
  plugins: [uni()],
})
```
