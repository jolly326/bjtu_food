## 一、技术架构

```
客户端（小程序/Web）
       ↓ HTTP REST API
Spring Boot 3.2 + Java 21
  ├── Controller 层（接收请求，参数校验）
  ├── Service 层（业务逻辑，事务管理，事件发布）
  ├── Mapper 层（MyBatis-Plus CRUD）
  └── Entity 层（表映射）
       ↓
MySQL 8.0
```

## 三、事件驱动

| 触发点 | 事件 | 监听器 | 操作 |
|--------|------|--------|------|
| 评价提交/修改/删除 | ReviewSubmittedEvent | RatingUpdateListener | 重算 dish.avg_rating |
| 收藏/取消收藏 | FavoriteChangedEvent | CollectCountListener | 同步 dish.favorite_count |

> 使用 `@TransactionalEventListener(AFTER_COMMIT)` 确保事务提交后执行，demo 阶段使用同步事件。

## 四、安全设计

| 机制 | 说明 |
|------|------|
| JWT 认证 | Token 7 天有效期，存储 userId/role/username |
| 密码加密 | BCrypt 哈希 |
| 角色体系 | user / stall_owner / admin，通过 SecurityConfig 配置 URL 权限 |
| 数据隔离 | stall_owner 的接口通过 `SecurityUtil.getCurrentUserId()` 获取用户，查询条件拼接 `stall.owner_id = ?` |
| 过滤器 | JwtAuthFilter 继承 OncePerRequestFilter，放行无 Token 请求（视为未登录） |

## 五、审核流程实现

```
档口提交菜品 → status = 'pending'
管理员审核 → PUT /admin/content/review/{id}?action=approve|reject
  → approve → status = 'approved' → 小程序可见
  → reject → status = 'rejected' → 档口可重提
```

## 六、图片处理

```
上传：POST /upload/image → 存储至 uploads/images/YYYY/MM/uuid.ext
存储：数据库存相对路径 /images/YYYY/MM/uuid.ext
返回：ImageUrlUtil.toAbsoluteUrl() 拼接完整 URL
映射：WebMvcConfig → /images/** → ./uploads/images
限制：≤5MB，仅 jpg/jpeg/png/webp
```
