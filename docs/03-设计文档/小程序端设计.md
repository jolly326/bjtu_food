## 二、导航流

```
[首页]
  ├── 食堂卡片 ──→ [食堂详情] ──→ [档口详情] ──→ [菜品详情]
  ├── 上新/活动卡片 ──→ [菜品详情]
  └── 菜品瀑布流 ──→ [菜品详情]
        ├── 位置 ──→ [档口详情]
        ├── 写评价 ──→ [发表评价]
        └── "喜欢" → 投票（本页）

[发现页]
  ├── 分类标签 → 瀑布流刷新
  └── 菜品卡片 ──→ [菜品详情]

[我的]
  ├── [未登录] 登录 / 注册 / 找回密码
  ├── [学生] 个人信息 → 联系开发者
  └── [档口老板] 学生功能 + 我的档口
        ├── [我的档口] ──→ 菜品发布
        ├── [我的档口] ──→ 活动设置
        └── [我的档口] ──→ 审核状态
```

## 三、组件树

| 组件 | 复用页面 | 说明 |
|------|---------|------|
| Header | 全局 | 自定义导航栏，砖红色背景 |
| SearchBar | 发现页 | 输入模式，支持搜索 |
| CustomTabBar | 全局 | 底部 3 个 Tab |

| StallCard | 食堂详情 | 档口卡片 |
| CardSection | 菜品详情/档口详情 | 通用卡片容器 |
| Rating | 菜品详情/发表评价 | 只读/交互两种模式 |
| TagLabel | 菜品卡片/详情 | "新"/"热"等标签 |
| Loading | 全局 | 加载动画 |
| AppButton | 全局 | 通用按钮 |
| ActivityCard | 首页 | 🆕 上新/活动横滑卡片 |

| StatusBadge | 档口老板页 | 🆕 审核状态标签 |

## 四、Store 结构

```
useDishStore
  ├── state: dishList, recommendList, homeBanners, canteenList, newDishes, promotionDishes
  └── actions: fetchHomeBanners(), fetchCanteens(), fetchRecommend(), fetchNewDishes(), fetchPromotions(), search(tag?)

useUserStore
  ├── state: token, userInfo, userStats, role
  └── actions: login(), register(), updateProfile(), logout()

⭐ useStallOwnerStore（新增）
  ├── state: myStall, myDishes, reviewStatus
  └── actions: fetchMyStall(), createDish(), updateDish(), setPromotion(), fetchReviewStatus()
```

## 五、UI 规范

UI 设计严格遵循 [UI风格指南.md](./UI风格指南.md)，关键数值摘要如下：

| 项目 | 值 |
|------|-----|
| **主色调** | `#8B3A2B`（砖红色） |
| **强调色** | `#E67E22`（橙红，价格/活动） |
| **成功色** | `#27AE60` |
| **页面背景** | `#F8F8F8` |
| **卡片背景** | `#FFFFFF`，圆角 `28px`，阴影 `0 4px 12px rgba(0,0,0,0.05)` |
| **按钮** | 主按钮圆角 `28px`，字重 `800`，字号 `17-18px` |
| **底部导航** | 固定在 `bottom: 20px`，圆角 `32px`，深色渐变背景 |
| **内页 Tab** | 水平滚动，选中深色背景/未选中浅色，圆角 `24-32px` |
| **标题** | `900` 字重，`18-20px`（小标题）/ `22-26px`（页面标题） |
| **正文** | `600-700` 字重，`15-17px` |
| **辅助文字** | `500` 字重，`12-14px` |
| **间距体系** | 水平边距 `20-24px`，区块间距 `14-18px`，卡片 padding `18-24px` |
| **圆角体系** | 标签 `14-18px` / 按钮 `28px` / 卡片 `28px` / 底部导航 `32px` / 头像 `50%` |
| **空状态** | 居中，图标 `100px`，文字 `16-18px` 浅色 |
| **过渡** | 统一 `0.2s`，仅缩放和背景色 |
