# 需求分析 — 非功能需求

> 版本：v1.0 | 更新日期：2026-07

---

## 一、性能需求

| 指标 | 要求 | 说明 |
|------|------|------|
| 页面加载时间 | ≤ 2 秒 | 小程序首页首屏加载 |
| 图片加载 | ≤ 1 秒/张 | 使用缩略图或懒加载 |
| API 响应时间 | ≤ 500ms | 大部分业务接口 |
| 并发用户数 | ≥ 100 | 高峰时段同时在线 |
| 搜索响应 | ≤ 1 秒 | 菜品关键词搜索 |

---

## 二、安全需求

| 需求 | 说明 |
|------|------|
| 密码加密 | BCrypt 哈希存储，不存明文 |
| JWT 认证 | Token 7天有效，敏感接口需鉴权 |
| 数据隔离 | 档口老板只能操作自己档口的数据 |
| 敏感词过滤 | 评价内容需经过敏感词过滤 |
| 图片合规 | 上传图片需审核通过后展示 |
| 邮箱验证 | 仅限 `@bjtu.edu.cn` 邮箱注册 |

---

## 三、兼容性需求

| 平台 | 要求 |
|------|------|
| 微信小程序 | 兼容 iOS 和 Android |
| 微信基础库 | ≥ 3.0.0 |
| Web 管理端 | 兼容 Chrome / Edge 最新版 |

---

## 四、可用性需求

| 需求 | 说明 |
|------|------|
| 操作反馈 | 所有操作需有加载/成功/失败提示 |
| 空状态处理 | 无数据时显示友好提示，非白屏 |
| 错误处理 | 网络错误/服务器错误需有兜底提示 |
| 图片兜底 | 图片加载失败时显示默认占位图 |
| 登录引导 | 未登录触发互动操作时引导登录 |

---

## 五、数据需求

| 需求 | 说明 |
|------|------|
| 数据备份 | 数据库定期备份 |
| 字符集 | utf8mb4，支持 emoji |
| 软删除 | 评价、菜品等关键数据使用软删除 |
