# 需求分析 — 用户场景

> 版本：v1.0 | 更新日期：2026-07

---

## 一、学生场景

### 场景 1：午饭选择困难

> **用户**：大二学生小明，每天中午下课最纠结的就是"吃什么"

```
11:50 下课铃响
  → 小明打开食在交大小程序
  → 首页看到"今日上新"：一食堂新上了麻辣拌，带🔥 标签
  → 点进去看到评价：4.8 分，同学晒图说"好吃！分量足"
  → 决定：就去吃这个了
```

**满足的需求**：快速获取决策信息，减少纠结时间。

---

### 场景 2：发现新菜品

> **用户**：大三学生小红，吃腻了常去的几个档口，想换换口味

```
晚饭时间
  → 小红打开发现页
  → 点击"今日上新"标签
  → 看到学苑餐厅新上了 3 道菜
  → 其中番茄肥牛面看起来不错，记下了
  → 今晚就去试试
```

**满足的需求**：发现有新鲜感的选择，打破"吃腻了"的困境。

---

### 场景 3：分享与安利

> **用户**：大四学生小张，吃到好吃的一定要告诉别人

```
中午在明湖餐厅吃了麻辣香锅
  → 味道很好，拍照
  → 打开食在交大写评价：5 星 + 图片 + "明湖二楼香锅绝了！"
  → 过了两天发现这条评价收到了 12 个"喜欢"❤️
  → 很开心，更有动力继续分享了
```

**满足的需求**：表达和分享的成就感，帮助更多人做选择。

---

### 场景 4：赶上活动

> **用户**：大一小李，生活费有限，喜欢找实惠的

```
刷首页时看到"限时活动"板块
  → 学四餐厅的黄焖鸡原价 15 现价 12，还有 2 小时结束
  → 赶紧截图发宿舍群："兄弟们冲！"
  → 四个人一起去吃了一顿
```

**满足的需求**：获取优惠信息，节省生活开支。

---


## 二、档口老板场景

> 档口老板拥有和普通学生一样的浏览功能（首页、发现页、菜品详情、食堂/档口浏览），此外额外拥有以下管理能力。

### 场景 5：浏览与参考

> **用户**：一食堂麻辣拌窗口阿姨，想看看别人家在卖什么

```
午休时间
  → 阿姨打开小程序
  → 浏览首页上新流："学苑餐厅新上了烤鱼饭，看起来不错"
  → 看看评价："学生普遍喜欢辣的，我下次也做个辣口的"
  → 了解行情后决定推出新口味
```

**满足的需求**：参考同行，了解学生口味偏好。

---

### 场景 6：发布新菜品

> **用户**：阿姨今天研发了新口味番茄肥牛面

```
新做的番茄肥牛面出锅
  → 阿姨拿出手机拍照
  → 打开食在交大小程序，进入"我的档口"
  → 点击"发布新菜品"：填写名称、价格、上传图片
  → 提交成功 → 状态变为"待审核"
```

**满足的需求**：快速发布内容，无需复杂操作。

---

### 场景 7：设置限时活动

> **用户**：学四餐厅黄焖鸡窗口大叔，今天想搞个促销

```
今天备料多了，想赶紧卖完
  → 打开小程序 → 我的档口 → 活动设置
  → 选择菜品：黄焖鸡
  → 设置活动价 12 元，截止今晚 7 点
  → 提交 → 审核通过后首页"限时活动"自动展示
  → 不到 6 点就卖完了
```

**满足的需求**：灵活设置促销，提升销量。

---

### 场景 8：查看数据

> **用户**：阿姨想知道自己档口的菜卖得怎么样

```
一周结束
  → 打开小程序 → 我的档口 → 数据概览
  → 看到：本周浏览量 500+、评价 12 条
  → 最受欢迎的菜是麻辣拌
  → 决定下周多做麻辣拌，减少冷门菜的备料
```

**满足的需求**：了解经营状况，辅助决策。

---

### 场景 9：查看审核结果

> **用户**：阿姨提交了新菜品后

```
第二天打开小程序
  → 看到通知：番茄肥牛面审核已通过 ✅
  → 在首页"今日上新"已经能看到了
  → 陆续有学生来问"今天有这个新面吗？"
```

**满足的需求**：了解内容上线状态，看到发布效果。

---

## 三、系统管理员场景

### 场景 10：审核档口内容

> **用户**：学生会生活部成员小王，负责平台内容管理

```
收到审核提醒
  → 登录 Web 管理后台 → 内容审核
  → 看到待审核列表：番茄肥牛面（档口提交）
  → 检查：图片清晰、价格合理、描述正常
  → 点击"通过"
  → 该菜品即刻在首页"今日上新"展示
```

**满足的需求**：确保档口发布的内容质量，防止不合规信息展示。

---

### 场景 11：审核学生评价

> **用户**：小王每天审核学生提交的评价和图片

```
收到评价审核提醒
  → 登录管理后台 → 评价审核
  → 看到学生提交的评价和图片列表
  → 检查是否有不当言论、不合适图片
  → 正常的放行 → 有问题的隐藏/删除
  → 确保平台内容干净、正面
```

**满足的需求**：把控学生 UGC 内容质量，维护社区氛围。

---

### 场景 12：数据看板

> **用户**：小王每周一看数据

```
登录管理后台 → 数据概览
  → 本周上新菜品：12 道
  → 本周新增评价：56 条
  → 最热门食堂：明湖餐厅
  → 最受欢迎菜品：麻辣香锅（浏览量 2300+）
  → 根据数据决定下周运营重点
```

**满足的需求**：了解平台运营状况，辅助决策。
