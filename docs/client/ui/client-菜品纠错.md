# 菜品信息纠错 — 页面 UI 设计稿

> 所属端：学生端（微信小程序）
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**；功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 本页采用「**锚定只读（不切换菜品）+ 动态属性 `AttributeGroup`**」形态 —— 进页自动预填菜品全部信息，用户**只改错项**，提交**仅带上改动过的项**（patch）；不进审核前置、**不实时生效**。
> ① 基础信息表单**双列并排**（菜品名称跨整行；售价｜食堂名称、楼层｜档口名称），消除短字段独占整行的纵向留白；② **楼层**由自由文本 input 改为**固定字典底部单选**（`BaseSheet` 弹层，汉字展示），端上做**汉字 ↔ 后端存储值**双向映射；③ `TagChip` 视觉强化（圆角 / 字重 / 删除叉尺寸）；④ **去冗余提示**：无页首提示条、无「正在纠错」标题与「菜品不可切换」小字、无组内重复操作说明，锚定行即表单首行纯文本；⑤ **候选按数量分档**（R41）：总数 ≤4 全部就地平铺（一步直达）、>4 常驻前 4 项 + 「更多候选」**底部弹层**（`BaseSheet` 底座，≥12 项自带本地搜索）。
> 边界：**菜品纠错 = 依附某条菜品数据的专项修正**（自带 `dishId`、字段结构化）；**意见反馈 = 面向小程序本身的通用反馈**（见 [client-意见反馈.md](./client-意见反馈.md)）。两者互不耦合。

- **入口（唯一）**：菜品详情页**信息卡名称行「信息有误?」入口** → `correctionUrl(dishId)`（`utils/routes`，禁止手拼 URL）⇒ 进页即按 `dishId` 拉详情**预填**；**页内不提供切换菜品**。
- 页面：`pages/correction/index`（独立分包 `pages/correction/`；二级页，**无 TabBar**；页底随全局 `page{}` 奶油米白 + `PageWallpaper`；页头 `AppHeader`「菜品信息纠错」+ 返回）。

## 视觉基线

**页面底**：低透明度手绘食物底纹（`PageWallpaper`），底色奶油米白。
**主卡片**：一枚大卡片承载全部表单 —— 底 `--bg-card`、圆角 **16rpx**（`--radius-btn`）+ `--border-color` 细描边 + 柔和低饱和卡阴影（`--shadow-card`）；卡片左右外边距 `--spacing-md`、内边距 `--spacing-lg`；**卡片内不使用分割横线**，靠间距 / 分组区分模块。

**色彩（设计参考值 → 落地口径）**：

| 用途 | 设计参考色值 | 落地口径 |
|---|---|---|
| 页面背景底色 | `#FFFBF5` | 全局 `page{}` 奶油米白（既有 Token） |
| 卡片容器底色 | `#FFFFFF` | `--bg-card`（**实色白卡**） |
| 主题橙（主色） | `#E57A3A` | `--color-primary` |
| 选中标签底 / 描边 | `#FFE7D6` | 底 `--color-primary-soft` / 描边 `--color-primary` |
| 默认候选标签底 | `#F7F1E7` | `--bg-soft`（次级浅底） |
| 正文文字 | `#3E3A36` | 正文文字 Token |
| 辅助 / 小字说明 | `#8A837B` | 次要文字 Token |
| 输入框默认底线 | `#EDE3D4` | `--border-color`（浅描边） |

| 错误提示文字 | `#C62828` | `--color-error`（错误色 Token） |

> **卡片底口径**：半透底叠在 `PageWallpaper` 上会掉文字对比度，且与全站卡片（`--bg-card`）口径分叉，故本页主卡用**实色 `--bg-card`**，卡内层次改由「`--border-color` 细描边 + `--shadow-card` + `--bg-input` 凹槽」表达。参考色值与现行 Token 不一致时**一律以「落地口径」列为准**。

> **红线**：颜色**一律走语义 Token（`var(--color-*)`），禁裸 hex**（上表色值仅为设计参考，实现须落到 Token；确无对应 Token 时新增，原生 API 不接受 `var()` 的常量集中登记）。图标统一 `IconSvg`，**禁 emoji / 文本 / `content:'+'` 当图标**。

## 触达尺寸口径

**基线**：全站独立可点件 ≥ **88rpx = 44pt**（`1rpx = 0.5pt`，`750rpx = 375pt`）。本页 `.row-field`（下划线输入行）/ `.ag-more`（**「更多候选」弹层入口**）/ `.ag-input-wrap`（自定义输入行）/ `ImagePicker` 添加格与删除钮 / **属性弹层内的一切可点件**（候选 chip、清空搜索、去自定义、清空全部、确认）均按 88rpx 落实。

| 元素 | 视觉尺寸 | 命中区 | 结论 |
|---|---|---|---|
| 属性 chip（选中 / 候选） | 高 ≈67rpx（≈33.5pt）= 内边距 16×2 + 文字行 30.8 + 描边 2×2 | 整 chip 全宽可点 | **登记例外**：属性区密集 chip 放行小于 44pt（见下） |
| chip 删除叉 `.tag-chip-x` | 图标 **24rpx** | **64rpx × 64rpx**（= 32pt），完全落在 chip 内 | 命中区尺寸**不变**；仅图标放大 |
| 组内节距 | gap `--spacing-sm` = 16rpx | — | 行节距 ≥ 83rpx（≈41.5pt），吸收纵向误触 |
| **弹层内候选 chip**（`TagChip size="lg"`） | 视觉高 **88rpx**（`min-height` 抬至 88；内边距 `--spacing-sm --spacing-lg`） | 整 chip 全宽可点 | **独立可点件**：弹层内不与删除叉热区竞争 ⇒ **不适用** chip 例外 |
| **楼层 picker 单元格** | 高 **88rpx**（与同行 input 行等高） | 整单元格可点 | **独立可点件**，不适用 chip 例外 |

**例外成立的前提（红线，任一被突破即例外失效）**：
1. chip 内边距恒 `--spacing-sm --spacing-md`（16 / 24rpx），**不得再缩**；
2. 删除叉命中区 **≥ 64rpx**，组内 gap **不得低于 `--spacing-sm`**；
3. 本例外**仅限主表单属性区的成组 chip**；独立可点件（提交按钮 / 输入行 / 「更多候选」弹层入口 / 图片添加格与删除钮 / **弹层内候选 chip 与弹层按钮**）仍须 88rpx。

**chip 视觉高 = 67rpx**：算式 = `16×2`（内边距）+ `22 × 1.4 = 30.8`（文字行）+ `4`（描边）= **66.8rpx ≈ 67rpx**。**描边不得去掉**：候选态用 `2rpx solid transparent` 与选中态**保等高**，两态切换时 chip 不跳高（刻意设计）。

**删除叉命中盒不外溢、不抬 gap**：命中盒 64×64rpx 完全落在 chip 边框内；图标右侧 ≈24rpx 留白即 chip 自身右内边距（`--spacing-md`），不是错位 —— 图标紧贴文字（gap `--spacing-2xs`）且强化「× 属于本标签」的归属感。**外溢热区不可取**：① 溢出 ≥16rpx 时命中盒会侵入**相邻 chip** 的标签体 / 删除叉热区 ⇒ **误删相邻标签**（破坏性误触）；② 为容下外溢需把 `gap` 抬到 ≥24rpx，选中区 chip 密度与候选面板内 chip 密度分叉。命中偏小时的兜底是「点标签体 = 删除」或放大 × 图标，**不是外溢热区**。

> **× 图标为 24rpx**（`IconSvg name="close" :size="24"`），命中盒 **64×64rpx 不变**。实现约束：命中盒靠 `margin: -17rpx -22rpx -17rpx 0` **负外边距居中抵消** —— 图标 24rpx 下为 `(64 − 24) / 2 = 20rpx` 并垂直方向抵消 chip 内边距，**保证选中 / 候选两态切换时 chip 视觉高不跳变**。

**chip 视觉高 67rpx 不受视觉强化影响。** `TagChip` 三项调整全部**不触碰高度**：① 圆角 `--radius-icon`（24rpx）—— 圆角只影响轮廓，不改变盒高；② 选中态字重 `--weight-semibold`(600) —— `line-height: 1.4` 不变，文字行仍为 30.8rpx；③ × 图标 24rpx 但命中盒尺寸不变、经负外边距抵消。**故 67rpx 与行节距 ≥83rpx 均维持。**

> **字重取值说明**：`--weight-medium` = 500 在部分小程序端会回落至 400（真字重只有 400 / 600 两档时 500 被就近取整），故「强调选中态」必须用 **`--weight-semibold` = 600** 才生效（与 `client-首页菜品浏览.md` 的同源口径一致）。

**chip 圆角 = `--radius-icon`（24rpx）**，不新增 28rpx 档位。`App.vue` 圆角标度为 `8 / 16(3 个别名) / 24 / 32 / 48 / 999`，**无 28rpx 档**；按「Token 标度内取最近档、不为单页新增标度」的原则取 **24rpx**：`--radius-tag`(16rpx) 对 chip 过方，`--radius-card`(32rpx) 过于方正，24rpx 兼顾圆润与密度。**禁**在本页裸写 `28rpx`。

**属性区 chip 不拉到 88rpx**（chip 67rpx、× 命中 64rpx）。88rpx 基线针对**独立可点件**；属性 chip 是**成组密集选择控件**：单个 chip 宽 ≈130–180rpx（≈65–90pt）远超 44pt，纵向由 gap 16rpx 补足（节距 ≥83rpx ≈41.5pt，且点到缝隙不命中任何 chip）。若拉到 88rpx：多维度组页长膨胀约 1.3 倍，与禁止项 2「防页面过长臃肿」冲突，且与全站筛选 chip 刻度分叉。**放行条件 = 上述三条前提全数保持。**

> **例外不适用于候选弹层内的 chip**（`size="lg"` = 88rpx）：弹层是模态全屏语境、候选稀疏排布，不存在「密集 chip 抬到 88rpx 会撑爆页面」的问题，且弹层内 chip **不与删除叉热区竞争** ⇒ 没有误删相邻标签的风险，理应回到 44pt 基线。

## 卡片结构（自上而下）

1. 菜品锚定行（纯文本，只读）
2. 基础信息表单区（下划线轻量输入）
3. 属性编辑区（`AttributeGroup` ×N，核心）
4. 图片上传区（选填，≤3 张）
5. 提交说明文案
6. 底部提交按钮

> **无页首提示条**：不渲染任何「已自动填充菜品原有信息…」类顶部横幅；进入卡片即锚定行。

### 1. 菜品锚定行（纯文本 · 只读）

- 形态：**无标题、无底色、无卡片背景** —— 直接作为表单最上方一行纯文本 `<菜品名称>｜<食堂>·<楼层>·<档口>`（示例 `杨枝甘露｜嘉园餐厅·负一层·嘉园奶茶`）；**不渲染**「正在纠错」标题与「菜品固定不可切换」小字。
- **预填未就绪时**：该行显示「正在载入菜品信息…」，且此时**只渲染锚定行、不渲染表单**（防误改误提交）。
- **楼层展示口径**：楼层段**同样走映射**，展示为汉字（`B1` → 「负一层」），与表单单元格口径一致 —— 同一页内不得一处汉字、一处 `B1`。映射规则与兜底见「[楼层控件（自由文本 → 固定字典单选）](#楼层控件自由文本--固定字典单选)」。
- **无任何点击交互、无箭头**；作用：防止用户改错菜品（与功能文档「表单内不允许切换」一致）。

### 2. 基础信息表单区（下划线轻量化输入 · 双列并排）

- **行内样式**（不变）：标签在左，输入控件占剩余宽度；**输入框背景透明，仅保留底部横线**（**禁全包围矩形框**）。
- **布局规则**：**菜品名称**独占整行（名称文字长，拆分后每列宽度不足）；其余 4 个短字段**两两并排**，压掉纵向留白。
- **仅保留字段名**：行内不渲染任何附加说明小字（售价行尾单位「元」除外）；字段之间靠**垂直留白**分隔，不使用分割线。

| 行 | 左列 | 右列 |
|---|---|---|
| 1（**跨整行**） | 菜品名称*　`input` | — |
| 2（双列） | 售价*　`input` + 行尾「元」 | 食堂名称*　`input` |
| 3（双列） | 楼层*　**picker 单元格**（见下） | 档口名称*　`input` |

- **实现口径**：双列用 **flex 两列**（每 `.cell` `flex: 1 1 0` + `min-width: 0`，列间 gap `--spacing-lg`），**不用 CSS grid** —— 本项目 `client/src` **零 grid 先例**（grid 仅 `web/` 使用），避免引入 mp-weixin 基础库差异。
- **标签宽度**：跨整行行 **160rpx**；双列行内 **96rpx**（双列每列 ≈307rpx，扣标签后余 ≈190rpx 供输入）。

| 标签 | 必填 | 呈现 | 预填 / 说明 |
|---|---|---|---|
| 菜品名称 | ✅ | 单行 input（跨整行） | 预填详情 `name`，可改；提交前非空、≤64 字 |
| 售价 | ✅ | 单行 input，digit 键盘，**行尾随单位小字「元」** | 预填详情 `price`（**API 层已完成 `fenToYuan` 分 → 元**，页面不换算金额）；单位「元」是**行尾小字**，不写进输入值、不参与提交；提交前 `yuanToFen` 转分（金额红线） |
| 食堂名称 | ✅ | 单行 input | 预填详情 `canteenName`（自由文本，无 picker / 无字典） |
| 楼层 | ✅ | **底部单选弹层**（见「楼层控件（自由文本 → 固定字典单选）」） | 预填详情 `floor`（**归属档口**）；恒存后端存储值，**展示层做映射** |
| 档口名称 | ✅ | 单行 input | 预填详情 `stallName`（自由文本） |

> **原价不纳入纠错**：原价随促销波动、属运营口径，短期打折不构成稳定事实；本页**只纠错现价（`price`）**，不渲染原价行。

- 交互：默认底线 `--border-color` → 聚焦切 `--color-primary`；必填标签的 `*` 与行内错误小字**同走 `--color-error`**（错误色 Token）；提交时校验必填，空值在**对应单元格下方**弹错误色行内小字（`padding-left` **跟随本列标签宽**：跨整行 160rpx / 双列 96rpx，不固定为 160rpx），输入行底线同步切错误色，**错误态优先于聚焦态**。

#### 楼层控件（自由文本 → 固定字典单选）

- **控件类型**：**底部弹出单选弹层**，走公共 `components/BaseSheet.vue`（底部弹层骨架唯一真源：遮罩点击关闭 / grabber / 下滑关闭手势 / 安全区 / 焦点回收），**本页不自建弹层、不用原生 `<picker>`** —— 本项目 `client/src` **零 `<picker>` / `<picker-view>` / `showActionSheet` 先例**，`BaseSheet` 是弹层唯一真源（`zToken` 走默认 `--z-sheet`）。
- **单元格形态**：汉字文案 + 右侧 `IconSvg name="arrow-down"`（`size="24"`，**已注册键**）；下划线样式与同行 input 一致，**高 88rpx**（独立可点件触达基线，见触达尺寸口径）。

**值模型：`form.floor` 恒存「后端存储值」，映射只发生在展示层。**

这样 diff 比对、必填校验、提交组装**三处逻辑零改动**（无需反查字典、无需判断「是否等于原值」）。映射表（端上常量）：

| 后端存储值 | 页面展示汉字 |
|---|---|
| `B1` | 负一层 |
| `1F` | 一层 |
| `2F` | 二层 |
| `3F` | 三层 |
| `4F` | 四层 |

- **加载预填**：详情返回 `floor` → 单元格查表渲染汉字；**锚定行同步走映射**（锚定行的楼层段展示「**负一层**」，与单元格口径一致）。
- **提交**：用户选中汉字 → 写入 `form.floor` 的**对应存储值**（如 `B1`）；未改动则不产生 diff、不提交。
- **未命中兜底（新增，必需）**：管理端 `stall.floor` 仍是**自由文本**（≤16 字，`docs/web/feature/web-档口管理.md` 明确），故详情值**可能不在字典内**，必须容错：

| 详情 `floor` | 单元格展示 | 提交行为 |
|---|---|---|
| 命中字典（`B1` / `1F` …） | 对应汉字，picker 内该项高亮 | 未动 ⇒ **无 diff**（原值随 `form.floor` 保留） |
| **非空但未命中**（如 `B2` / `5F`） | **原值原样展示** + 次要小字「不在预设范围」；picker 内无选中项 | 未动 ⇒ **无 diff**（不因"无法映射"而清空或报错）；一旦改选字典项 ⇒ 覆盖为该存储值 |
| 空串 | 占位「请选择楼层」 | **必填不放行**（维持现状口径），错误小字落该单元格下方 |

- **禁止**：楼层**不得提供自由输入**（彻底杜绝 `B3` / `5F` 等字母数字格式进入展示层）；**不得**为未知值新造汉字；**不得**在提交时把汉字直接当存储值发出。

### 3. 属性编辑区（核心 · `AttributeGroup` 可复用组件）

> **数据驱动**：`GET /dishes/{id}` 的 `attributes`（键 = 维度 `fieldKey`，值 = 中文文本 / 数组）决定**已选**；`GET /dishes/{id}/attributes`（编辑态**按需**）的 `options` 决定**候选**；`valueType` 决定单选 / 多选。**每一个维度单独一组 `AttributeGroup`**（`dietType` 饮食属性 `single` / `ingredients` 食材 `multi` / `flavorTags` 口味 `multi` / `serveTemp` 冷热 `single`）。

- **零维度**（详情 `attributes` 为空）⇒ **整段属性编辑区不渲染**（无占位文案、不留空档）；单个维度无原始值时，仅该组已选区为空并显示占位小字「暂无，可从下方选择或直接输入」。
- **属性区无字段级错误**：属性不存在「必填」概念，故不设行内错误位；属性变更只承担「撤下过期失败提示」的职责。

**单组布局（自上而下）**：

```
【分组标题】<维度名>          单选 / 可多选   ← 右上角小字（valueType 驱动）
├─ 已选中标签区（常驻）                  [珍珠 ×] [奶茶 ×]
├─ 就地常驻候选    ≤4 项 ⇒ 全部平铺；>4 项 ⇒ 前 4 项 + 【更多候选（共 N 项）▾】→ 底部弹层
└─ 自定义输入行    [输入自定义<维度名>，回车添加]      ← 与弹层入口同处「入口行」
```

> **标题行右上角标注**：**单选组**（`single`：饮食属性 / 冷热）标注「**单选**」；**多选组**（`multi`：食材 / 口味）标注「**可多选**」。两组均渲染（`.ag-head` 为 `display: flex; align-items: baseline`，`.ag-name` 与 `.ag-tip` 并排），文案由 `valueType` 驱动、端上零硬编码；`.ag-tip` 用 `--font-tiny` + `--text-tertiary`。
> **不渲染**组内重复操作说明：「点击标签增删，支持自定义输入」整行已移除，不再出现在任何分组下。

**区域1 · 已选中标签区（常驻，永远可见）**
- 展示当前菜品**原始选中属性**（预填）；标签右上角**关闭叉**（`IconSvg name="close"`，`:size="24"`）。
- **选中态按 `valueType` 分两套视觉（不得互串）**：
  - **单选组**（饮食属性 / 冷热）：**实心 `--color-primary` 底 + `--color-on-primary` 白字**；2rpx 描边取与底同色（保持 67rpx 等高、不显边）。
  - **多选组**（食材 / 口味）：底 `--color-primary-soft`、2rpx `--color-primary` 描边、`--color-primary-text` 文字（浅橙描边 + 浅橙底 + 橙字）。
  - 两套共同：**`--weight-semibold`(600)**、圆角 **`--radius-icon`(24rpx)**、选中标签带关闭 ×。
- 交互：点标签右上角 × 直接删除该项。
- **标签体本身无点击行为**：已选区 chip **不挂 `role=button`、不挂按压反馈** —— 避免「看着可点、按了什么也不发生」的死 affordance；删除语义唯一且明确地落在 × 上（回归 `AttributeGroup` 传 `:pickable="false"`）。
- 触达：chip 视觉高 ≈67rpx、删除叉命中区 64rpx（属性区密集 chip 的**登记例外**），见「触达尺寸口径」；组内 gap 恒 `--spacing-sm`。

**区域2 · 候选区（R41：单一控件 + 一条按数量分档的收纳规则）**

> **为什么按数量分档、而不是「一律弹层」**：候选池 `options` 由**全库已用中文值去重**得出（`schema.sql` 明示「无取值字典表、加值零登记」），会随纠错被采纳而**单调增长** ⇒ 长尾必须有一个能扩容的容器；但当前四个维度里有两个是 2~4 项的小集合（饮食属性 / 冷热），为改一个值开弹层（3 步）明显劣于就地一点（1 步）。
> **唯一一条规则**：候选总数 **≤4** ⇒ 全部就地平铺；**>4** ⇒ 就地常驻前 4 项 + 「更多候选」开底部弹层看全量。
> **控件恒为 `TagChip`**（就地与弹层同一视觉语言，只差尺寸档）⇒ 用户面对的始终是「点标签」，不存在「这个就地选、那个弹窗选」的范式分叉。

- **就地常驻**：总数 ≤4 ⇒ **全部候选**平铺（不给入口）；总数 >4 ⇒ 常驻 `options` **前 4 项**（后端按频次 / `order` 倒序下发 ⇒ 前 4 项即最常用，端上**不新增「常用」字段**），其后紧跟入口按钮「**更多候选（共 N 项）▾**」（高 **88rpx**、`IconSvg name="arrow-down"`）。
- **就地不再有任何滚动面板**：旧「`height: 240rpx` 定高内滚折叠面板」已删除 —— 该形态依赖给 `scroll-view` 硬定高（mp-weixin 对 `max-height` 不保证），且候选一多只能盲滚；长尾候选一律交给弹层。
- **候选总数 = 0**（`options` 为空 **或** 候选接口失败）⇒ 常驻区与入口**一并隐藏**，仅留自定义输入。
- 候选（未选中）样式：底 `--bg-soft`、`--text-body` 文字、`--weight-medium`(500)、**2rpx 透明描边**（与选中态**等高**，但无可见描边 —— 描边是「选中态」独占的视觉标识）；圆角同为 `--radius-icon`(24rpx)（两态统一）。
- **候选池含已选项、不去重**：已选项以**选中态**呈现（一眼看出「这个已经在上面了」），点它即**反选移除**；不隐藏、不置灰、不另排序。
- **就地点击逻辑**：`multi`（多选：食材 / 口味）→ 点候选**加入**已选区，再点**取消选中**；`single`（单选：饮食属性 / 冷热）→ 点候选**直接替换**上方已选标签，**仅保留 1 个**；**`single` 再点当前已选项 = 清空该维度**（允许把单选维度改成「未选」，等价于删掉已选 chip）。

**区域2b · 候选弹层（`AttributePickerSheet`，`BaseSheet` 底座）**

- **触发**：仅「更多候选」入口。**标题**「选择<维度名>」+ 右上关闭钮；内容区走 `BaseSheet` 的 `scroll-body`（`max-height: 88vh` + 内部滚动）⇒ 候选少时贴合内容、候选多时内滚，**不自设定高**。
- **候选全览**：全部候选（含已选项）流式排布，`TagChip size="lg"`（**88rpx** 触达档）+ `checkable`（选中态带 `check` 对勾 —— 弹层内没有删除叉，「已选」不能只靠底色表达，色觉障碍 / 低亮度下不可辨）。
- **搜索**：候选总数 **≥12** 才渲染搜索框（判据用**总数**而非过滤后条数 ⇒ 打字过程中搜索框不会消失）；**仅本地子串过滤，禁再发请求**；非空时行尾给清空钮（88rpx）。
- **多选组（草稿态）**：点候选只在弹层内勾选（本地 `draft`）；底部【**清空全部**】（文字按钮，语义是「动作」⇒ 直接回抛空数组并关闭）与【**确认**】（主色实心 88rpx，回抛草稿）；**点关闭 / 遮罩 / 下滑 = 丢弃草稿**，主表单不变。
- **单选组（无确认按钮）**：点候选 = **选中并立即关闭**（省一步空操作）；点当前已选项 = **视为无改动**（不产生 diff）。单选维度**不在弹层内清空** —— 清空只走主表单已选 chip 的删除叉，保持「一个维度只有一个清空入口」。
- **「没找到？去自定义」**：底部恒在的文字入口 ⇒ 关弹层并**聚焦该组自定义输入框**（失焦即撤聚焦态）。弹层内**不放**自定义输入框 —— 小程序键盘会把弹层顶穿 `88vh` 上限。
- **挂载**：随 `AttributeGroup` 就近挂载，首次打开后 `v-if` 置真**常驻**（候选池可达数十项，避免每次开合重建子树），开合动画仍由 `visible` 驱动。

**区域3 · 自定义输入框（每组底部常驻）**
- 占位：`输入自定义<维度名>，回车添加`。
- 规则：回车 / 添加 → 加入上方已选区；**自动去重**，禁空 / 纯空格，长度上限 **10 字**；自定义项**不入后端候选池**，仅存本次表单选中列表；`single` 维度自定义输入遵循单选（替换；输入值与当前已选项相同则视为无变化、不产生 diff）。
- **「添加」按钮**：草稿非空时出现在输入行行尾（**文字按钮**，非图标；视觉高 56rpx，命中区经伪元素纵向扩至**行高 88rpx**）；回车与点「添加」等价；草稿为空时**不渲染**（不留无效按钮）。

### 4. 图片上传区（选填）

- 标题：`补充实拍图片（选填，最多 3 张）`。
- 初始态（**与公共 `ImagePicker` 逐项对齐**）：`--bg-input` 浅底虚线框 + `IconSvg name="image"`（**「添加图片」语义，不是相机图标**）+ 文案「**添加图片**」；上传中该格显示环形 loading +「上传中…」。
- 上传后：缩略图**横向排布**（flex 横排，≤3 张恒一行、超限换行）+ 每张**右上角**删除钮（半透明黑圆底 `--badge-dark-bg` + 白叉 `IconSvg name="close"`，**热区 88rpx**）；点击缩略图预览大图（微信原生 `previewImage`）；满 3 张时末位显示 `3/3` 计数格（排布不塌、保留「已选」感知）；**破图走统一 `ImagePlaceholder`（灰底 + `image-broken`）且不进预览**。
- 实现复用公共 `ImagePicker`（多图形态，`max=3`），与**服务端上限 ≤3 一致**；**本页不另写上传 / 预览 / 删除逻辑，也不自绘删除钮位置**（图标、文案、位置一律随公共组件，避免两套口径漂移）。提交中删除钮与添加格同步弱化（0.5）并禁点。

### 5. 提交说明文案

- 文案：`提交后人工审核，审核通过更新菜品信息`；浅灰小字，无警示色（**不暗示提交即生效**）。

### 6. 底部提交按钮

- 文案「**提交纠错**」（提交中「提交中…」）；**随内容滚动**（非固定底栏）。
- 正常可提交：主色 `--color-primary` 底、`--color-on-primary` 白字、圆角 **16rpx**（`--radius-btn`）、高 **88rpx**（= 44pt）、宽 100%（`AppButton` 公共件）。
- **禁用态**：**复用全站 `.is-disabled`**（`opacity 0.5` + `pointer-events: none` + 轻灰度，**唯一定义在 `App.vue`**）—— 本页**不自设**灰底 / 灰字档位，避免与全站按钮禁用口径分叉（`AppButton` 已按此口径实现）。
- 禁用触发条件（四选一即置灰）：必填项为空 **或** 表单**无任何改动**（无改动 = 无可提交内容）**或** 预填未就绪（`loading`）**或** 限频退避中。
- 置灰点击由**外层热区**兜底 toast（`AppButton` 禁用态 `pointer-events: none`，点击落到 `.submit-area`），文案指名缺失项 / 无改动 / 限频倒计时；提交中 `loading` 态（`opacity 0.6` + 禁点）防重复提交。

## 交互规则

1. **加载**：进页按 `dishId` 拉 `GET /dishes/{id}` 预填全部字段与原始属性；`GET /dishes/{id}/attributes` **与详情并发取一次**（多选组常驻的常用标签依赖它；失败静默 ⇒ 隐藏候选入口、仅留自定义输入，不阻塞表单）；**楼层映射为纯前端查表，不额外请求**（字典硬编码在端上，后端不提供楼层字典端点）。
2. **提交策略**：**仅提交改动项**（patch）—— 与初始快照逐字段比对，未改动不传；`attributes` 仅含**改动的维度项**；`price` 以**分**提交。
3. **成功**：Toast「提交成功，等待审核」→ 自动返回上一页（菜品详情）。
4. **失败**：页面底部**错误色文字**（`--color-error`）提示失败原因，**完整保留已填内容**（不清空表单）；用户一旦改动任一文本字段 / 属性 / 图片，即撤下这条过期提示（不改动则不撤，便于回头核对）。
5. **重置**：不单独提供重置按钮；退出页面即丢弃表单。
6. **边界**：某维度无原始属性 → 已选区为空，候选入口与自定义输入仍保留（可新增）；属性候选接口异常 → 隐藏候选入口，仅留自定义输入；**全部维度为空 → 整段属性编辑区不渲染**。
7. **限频退避**：命中 IP 限频（2 条/分钟、10 条/小时）后进入**退避期** —— 提交按钮置灰（`.is-disabled`）**且不发请求**，点击由外层热区 toast「提交过于频繁，请 N 秒后再试」（N = **实时倒计时**）；退避结束自动恢复可提交态；退避期内连点**不叠加请求、不延长封锁**。
8. **候选弹层（R41）**：`options` 总数 >4 时经「更多候选」入口打开；打开时**回显当前已选**（多选建草稿、单选高亮当前项）；多选**确认才回写**、关闭 / 遮罩 / 下滑**丢弃**；单选**点项即回写并关闭**；「去自定义」= 关弹层 + 聚焦该组自定义输入框。弹层内的任何改动**都不产生 diff，直到回写那一刻**。

**`FloorPickerSheet` 入参**：

```ts
props: {
  visible: boolean                       // 显隐（v-if 懒挂载后由父级控制）
  value: string                          // 当前「后端存储值」（未命中字典时为原值）
  options: { value: string; label: string }[]  // 5 项固定字典（value=B1/1F/…，label=负一层/一层/…）
}
// emits: select(value: string)  —— 回抛存储值，不回抛汉字
```

> **职责边界**：映射字典与「未命中兜底」判定归 **`CorrectionForm` / `useCorrection`**（表单层），`FloorPickerSheet` 只负责「把字典渲染成可选行 + 把点击行回抛为存储值 + 高亮当前值」。这样弹层可复用、且**汉字永远不会出现在提交路径上**。

**`AttributeGroup` 入参**：

```ts
props: {
  fieldKey: string              // 维度键，如 mainMaterial
  name: string                  // 分组名，如 食材
  valueType: 'single' | 'multi' // 单选 / 多选
  selected: string[]            // 当前已选（预填原始值，可增删）
  candidates: string[]          // 候选（来自编辑态接口，仅提示、不限制）
}
// emits: change(fieldKey: string, selected: string[])
```

> **入参未因弹层方案改动**：候选弹层是 `AttributeGroup` 的**内部实现细节**，`CorrectionForm` / `useCorrection` 零感知（表单值真源仍在 `useCorrection`）。

**`AttributePickerSheet` 入参**（R41 新增）：

```ts
props: {
  visible: boolean                    // 显隐（父级 v-if 懒挂载后置真并常驻，开合动画由 visible 驱动）
  name: string                        // 维度名（标题「选择<维度名>」+ 搜索占位文案）
  valueType: 'single' | 'multi'       // single = 点项即选即关；multi = 草稿勾选 + 确认 / 清空
  selected: string[]                  // 主表单当前已选（草稿初值 + 单选「点当前项 = 无改动」判据）
  candidates: string[]                // 全部候选（总数 ≥12 时启用本地搜索过滤）
  selectedStyle?: 'soft' | 'solid'    // 与主表单两套选中视觉同源，由父级按 valueType 下发
}
// emits: update(next: string[])  —— 确认 / 清空 / 单选点项后回抛新数组（父级转发 change）
//        requestCustom()         —— 「去自定义」：父级关弹层并聚焦该组自定义输入框
//        close()                 —— BaseSheet 统一上抛（遮罩 / 下滑 / 关闭钮），多选场景即丢弃草稿
```

## 禁止项（UI 约束）

1. 卡片内部**不使用分割横线**，靠间距 / 分组区分模块，避免割裂感。
2. **候选收纳只认数量、不认单 / 多选**：候选总数 ≤4 才可全部就地平铺；**>4 时就地最多常驻前 4 项**，其余必须进「更多候选」**底部弹层**（**禁**在卡片内做滚动 / 内滚面板、**禁**就地全量平铺 —— 防页面过长臃肿）；**禁**再按 `valueType` 给单选组特判（旧「单选组不常驻平铺」口径已作废）。
3. **不增加多余 Tab**；本页独立，不嵌入意见反馈页。
4. 输入框**禁全包围矩形框**，统一**下划线**轻量样式。
5. **不支持切换菜品**，锚定菜品只读，防提交错误菜品。
6. 颜色走 Token**禁裸 hex**；图标统一 `IconSvg` **禁 emoji**；事件统一 **`@tap`**；按压用 `background` / `opacity` 微降，**禁 `transform: scale`**。
7. **属性区 chip 不得再缩**：内边距恒 `--spacing-sm --spacing-md`、删除叉命中区 ≥ 64rpx、组内 gap 恒 `--spacing-sm`（见「触达尺寸口径」例外前提）；**禁**用「热区外溢」换视觉贴边（会侵入相邻 chip ⇒ 误删）。**圆角恒 `--radius-icon`(24rpx)**（两态统一），**禁**裸写 `28rpx`、**禁**退回 `--radius-pill`。
8. **禁用态不得自设档位**：一律复用全站 `.is-disabled`（`App.vue` 唯一定义）；**禁**本页再写灰底 / 灰字 / 自定义 opacity 作为禁用视觉。
9. **图片区不得离开公共 `ImagePicker`**：删除钮位置（右上角）、初始态图标（`image`）与文案（「添加图片」）**随公共组件**；**禁**本页自绘或改位。

### 入参提交

`POST /dishes/{id}/correction`（**patch**，仅改动项；`dishId` 在路径；公开匿名、IP 限频 2 条/分钟、10 条/小时）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `name` | string | 改动时传；非空、≤64 字 |
| `price` | number | 改动时传；**整数分**（端上 `yuanToFen`）、> 0 |
| `canteenName` | string | 改动时传；非空（自由文本） |
| `stallName` | string | 改动时传；非空（自由文本） |
| `floor` | string | 改动时传；非空、≤16 字（**归属档口**，采纳写回 `stall.floor`）。**端上以固定字典单选呈现（负一层/一层/二层/三层/四层），但提交仍是后端存储值（`B1`/`1F`/`2F`/`3F`/`4F`）** |
| `attributes` | object | 仅**改动的维度**；键 = 维度 `fieldKey`，值 = 中文文本 / 数组 |
| `images` | string[] | 改动时传；**≤3**（与服务端一致） |

> **空改动**（未提交任何改动项）→ 服务端 `400`「未提交任何改动」；端上应据此**禁用提交**。
> **楼层**：`floor` 为局部提交的改动项（string，传入非空 ≤16）；**归属档口**，采纳时写回 `stall.floor`。

### 错误码

`400` 菜品名称不能为空 / 超长 / 含敏感词 ｜ 价格必须为大于 0 的整数（单位：分）｜ 图片地址不合法 / 超上限 ｜ IP 限频「提交过于频繁（含剩余秒数）」｜ 空请求体「未提交任何改动」；`4001` 菜品不存在 / 已下架。

### 控件类型

`scroll-view`、下划线 `input`（名称跨整行 / 价格 digit 键盘，售价行尾「元」小字）、**楼层 picker 单元格（`BaseSheet` 底部单选弹层，汉字展示）**、**双列并排基础表单（flex 两列）**、`AttributeGroup`（选中 chips + 就地常驻候选 + 自定义输入）、**`AttributePickerSheet`（候选 >4 时的底部弹层：全览 chip + ≥12 项本地搜索 + 多选草稿确认 / 单选点项即关）**、`ImagePicker`（多图形态，`max=3`）、字段级错误定位（**输入行底线切 `--color-error`** + 行内错误色小字 + 首错 `scroll-into-view`）。
