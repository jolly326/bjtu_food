# 写评价（A-06）

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔐 认证**（需学号邮箱认证）
> 返回：[功能总览](./README.md)

## 介绍

给一道菜打星 + 写文字 + 最多 3 张配图。**先发后审**：文本与图片通过微信内容安全检测即**立即公开**，无人工复核；后续如被举报，由管理员事后处置。

**提交是单一动作**：恒 `POST /dishes/{id}/reviews`。每人对同一菜品仅一条评价（唯一键 `uk_review_user_dish`）——未评价时新建；已评价时由服务端**覆盖同一行**（评分 / 文字 / 配图整体重写）。端上不区分首评 / 重评：**无「写前判定」、无「重新评价」双态**，详情页不预填旧值，点「写评价」恒打开空表单（页面形态见 `docs/client/ui/`）。提交流程：选星级（1~5 必填）→ 文字（可跳过）→ 配图（≤3 张，逐张压缩上传取 COS URL 后随评价提交）；检测不通过则提示错误、不发布。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| POST | `/upload/cloud-image` | 🔑 需登录 | **前置调用**：配图逐张转存（微信内容安检 + 转存 COS） |
| POST | `/dishes/{id}/reviews` | **🔐 认证**（`@RequireVerified`；未认证 → 4031） | 提交评价（新建或覆盖）；路径 `{id}` = 菜品 ID，body 不收 `dishId`。每人对同一菜品仅一条评价（唯一键 `uk_review_user_dish`）；`risky` 内容 → 400 |

## 字段

### 请求 · `ReviewReq`

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `rating` | number | **是** | 评分，**1~5 星**（超出范围 → 400） |
| `content` | string | 否 | 文字评价，最长 **500 字**（可只打星不写文字） |
| `images` | string[] | 否 | 评价配图 URL 数组，**最多 3 张**；元素须为经 `POST /upload/cloud-image` 转存后的 COS 绝对地址 |

路径 `{id}` = **菜品 ID**；归属由 token 锁定当前登录用户（**禁止信任前端**），不可换菜。

### 响应

| `data` | 中文解释 |
|---|---|
| `{ "id": number }` | **评价 ID**。**重复提交 = 服务端覆盖旧评价**（唯一键保证一人一菜一条）；端上无须回读，提交成功后重拉评价列表即可 |

### 重复提交的覆盖口径

| 项 | 口径 |
|---|---|
| 落库 | **覆盖更新同一行**（非删行重建）：唯一键 `uk_review_user_dish` 不变、无并发窗口；旧内容不留残留 |
| `created_at` | **刷新为当前时间**（重评即新发布，时间倒序下自然置顶） |
| `is_hidden` | **重置为 0** |
| 次数 | **不限次**（一人一菜只有一票，改多少次也只是一票） |

> 覆盖路径与首次提交**逻辑完全相同**：安检口径、配图规格与前置上传、4031 分流、评分聚合事件均一致。

### 前置调用字段 · `POST /upload/cloud-image`

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `fileId` | string | **是** | 微信云存储文件标识（`wx.cloud.uploadFile` 返回的 `cloud://...`） |
| → 响应 `url` | string | — | 安检通过并转存后的 **COS 绝对 URL**（收集后随 `images` 提交） |

### 内容安全（提交闸门，不落库）

| 环节 | 判定 | 中文解释 |
|---|---|---|
| 文本 `msgSecCheck` v2（`scene=2`） | `pass` / `review` → **放行**；`risky`（含未知/缺失态）→ **400 拦截、不落库** | 内容安全检测即终局，**无人工复核** |
| 图片 `imgSecCheck` | 违规（微信码 `87014`）→ 400 | 单张失败只跳过该张，不中断其余图片上传 |

### 错误码

| code | 含义 | 中文解释 |
|---|---|---|
| 400 | 参数/业务校验失败 | 含内容安检违规（提示违规文案）、配图超 3 张、评分越界等 |
| **4031** | 邮箱未认证 | 区别于 403：前端据此跳转身份认证页 |

## 数据（落库）

| 表 | 变化 | 中文解释 |
|---|---|---|
| `review` | **INSERT**（未评价）/ **UPDATE**（已评价覆盖同一行） | 写入 `user_id`（当前登录用户，**禁止信任前端**）、`dish_id`、`rating`、`content`、`images`（JSON 数组，COS URL）；覆盖时重写评分 / 文字 / 配图，并刷新 `created_at`、`is_hidden` 重置 0 |
| `dish.avg_rating` / `dish.rating_count` | **异步** UPDATE | 通过 `ReviewSubmittedEvent` → `RatingUpdateListener`（`@Async` AFTER_COMMIT）重算；**口径：仅计 `is_hidden=0` 的评价** |
