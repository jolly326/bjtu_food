# 校园食堂信息系统 - 小程序前端功能设计

## 项目背景

本项目为数据库课程设计 MIS 系统。

目标：

解决学校食堂活动、新品信息只能通过公众号发布、触达率低且无法收集反馈的问题，同时帮助学生解决“今天吃什么”的选择困难，并帮助游客快速获取校园食堂信息。

系统采用前后端分离架构。

---

# 技术栈

前端：

- uni-app
- Vue3
- TypeScript
- Composition API
- Pinia
- uni-ui

后端：

- Spring Boot
- MySQL
- REST API

开发要求：

- 使用 TypeScript
- 使用 setup 语法
- 使用 Composition API
- 禁止 Options API
- 接口统一封装
- 页面组件化
- 页面数据使用 Pinia 管理
- 尽量使用 hooks 抽离逻辑

---

# 用户角色

系统仅开发小程序端。

存在两种用户：

## 游客

权限：

允许：

- 浏览首页
- 搜索菜品
- 查看菜品详情

禁止：

- 收藏
- 评价
- 创建清单
- 一键收藏
- 分享清单

游客点击受限功能：

弹窗提示：

"登录后使用该功能"

随后跳转登录页。

---

## 学生

权限：

允许：

- 浏览菜品
- 搜索
- 收藏
- 评价
- 创建美食清单
- 分享清单

功能：

模块：

功能：

- 输入档口名称

### 推荐区域

- 招牌菜
- 必吃推荐

# 开发规范

组件：

- 单组件不超过300行
- 复杂逻辑抽离hooks

命名：

页面：

index.vue

组件：

Pascal命名

hooks：

useXxx.ts

类型：

xxx.type.ts

API：

api/xxx.ts

样式：

scss

禁止：

页面直接写请求逻辑

必须：

统一使用API层调用接口
