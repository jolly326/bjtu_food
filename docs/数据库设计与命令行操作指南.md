# 数据库设计与字段说明文档

> 项目：食在交大 | 数据库：MySQL 8.0 | 数据库名：`bjtu_food`
>
> v3.0 调整：新增档口老板角色、内容审核体系、菜品活动管理、标签规范化、评价喜欢投票。

---

## 一、总体关系

```
user ── N review N ── dish N ── stall N ── canteen
user ── N review_useful N ── review
user ── N user_feedback
user ── 1:1 stall（档口老板）

dish ── N dish_tag
dish ── 0:1 dish_promotion
```

通用约定：
- 所有 `id` 为自增 BIGINT 主键
- `created_at` / `updated_at` 每表必有
- `images` 字段存 JSON 字符串数组
- 菜品价格以"分"存储（1200=12元）

---

## 二、核心表

### user 用户表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| username | VARCHAR(50) | 学号/工号，UNIQUE |
| email | VARCHAR(100) | 校园邮箱，UNIQUE |
| password | VARCHAR(255) | BCrypt 哈希 |
| nickname | VARCHAR(50) | 昵称 |
| avatar | VARCHAR(255) | 头像 URL |
| role | VARCHAR(20) | `user` / `stall_owner` / `admin` |
| status | VARCHAR(20) | `active`(正常) / `frozen`(冻结) / `banned`(封号) |

### canteen 食堂表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| name | VARCHAR(100) | 食堂名称 |
| images | TEXT | JSON 图片数组 |
| location | VARCHAR(255) | 位置描述 |
| description | TEXT | 简介 |
| status | VARCHAR(20) | `open` / `closed` |
| sort_order | INT | 排序权重 |

### stall 档口表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| canteen_id | BIGINT | FK→canteen |
| name | VARCHAR(100) | 档口名称 |
| images | TEXT | JSON 图片数组 |
| location | VARCHAR(255) | 位置 |
| description | TEXT | 简介 |
| avg_rating | DECIMAL(2,1) | 平均评分 |
| owner_id | BIGINT | 🆕 FK→user，档口老板 |
| status | VARCHAR(20) | `open` / `closed` |
| sort_order | INT | 排序 |

### dish 菜品表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| stall_id | BIGINT | FK→stall |
| name | VARCHAR(100) | 菜品名称 |
| price | INT | 价格（分） |
| description | TEXT | 介绍 |
| images | TEXT | JSON 图片数组 |
| status | VARCHAR(20) | `off`(下架) / `pending`(待审核) / `approved`(已上架) / `rejected`(已驳回) |
| is_new | TINYINT | 🆕 是否标记为新品 |
| created_by | BIGINT | 🆕 FK→user，提交者（档口老板） |
| view_count | INT | 浏览量 |
| avg_rating | DECIMAL(2,1) | 平均评分 |
| rating_count | INT | 评价数 |
| is_deleted | TINYINT | 软删除标记 |

> 原 `tags`、`is_promotion`、`promotion_price`、`promotion_end_time` 字段已移至独立的 dish_tag 和 dish_promotion 表。

### dish_tag 菜品标签表（新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| dish_id | BIGINT | FK→dish |
| tag | VARCHAR(30) | 标签名 |

### dish_promotion 菜品活动表（新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| dish_id | BIGINT | FK→dish, UNIQUE |
| promotion_price | INT | 活动价（分） |
| end_time | DATETIME | 活动截止时间 |

### review 评价表

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | FK→user |
| dish_id | BIGINT | FK→dish |
| rating | TINYINT | 1-5 |
| content | TEXT | 文字评价 |
| images | TEXT | JSON 图片数组 |
| is_hidden | TINYINT | 管理员隐藏 |

> UNIQUE(user_id, dish_id)：一人一菜一评。

### review_useful 评价喜欢表（新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | FK→user，投票者 |
| review_id | BIGINT | FK→review，被投票评价 |

> UNIQUE(user_id, review_id)：一人一评一票。

### user_feedback 用户反馈表（新增）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| user_id | BIGINT | FK→user |
| content | TEXT | 反馈内容 |
| contact | VARCHAR(100) | 联系方式（选填） |
| status | VARCHAR(20) | `pending` / `read` / `resolved` |

## 四、数据维护建议

1. 角色仅使用 `user`（学生）、`stall_owner`（档口老板）、`admin`（管理员）
2. 删除菜品前先确认是否存在评价、收藏、标签、活动关联
3. 关键数据使用软删除（is_deleted）
