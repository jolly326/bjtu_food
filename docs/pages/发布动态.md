# 发布动态 / 评价页（PublishReview）

> 路径（复用同一组件 `PublishReview`）：
> - 发表评价：`pages/pages-detail/review`（从菜品详情「写评价」进入，自动带入 `dishId` / 菜品名）。
> - 发布动态：`pages/pages-user/publish-moment/index`（从动态页底部发布 / 我的进入，需自行选择菜品）。
> 设计基调：「评价即动态」单一内容模型（见 `project_spec.md` §2.1.4）；两种入口共用同一份表单与校验，提交后内容同步到动态列表、菜品详情评价区与「我发布的」（见 `动态页.md` / `菜品详情.md` / `我发布的.md`）。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

统一发布页为纵向滚动表单页，自上而下：顶部 Header → 表单内容区（菜品选择 / 评分 / 内容 / 图片）→ 固定底部提交按钮。两种入口的差异仅在「菜品选择」字段：

```
Header（返回+确认 + 标题「发布动态」/「写评价」）
────────────────────────
表单：
  菜品名称（评价模式预填只读 / 动态模式 RelatedPickerSheet 选择）
  评分选择器（Rating，必选）
  评价内容（多行，0/200）
  图片上传（ImageUploader，最多 3 张）
────────────────────────
底部提交按钮（发布 / 发布中...）
```

## 一、顶部 Header

- 左上返回箭头（`arrow-left`）：点之若表单已有内容未提交 → 弹确认「确定放弃发布吗？」，防误触丢失；确认后 `navigateBack`。
- 居中标题：评价模式「写评价」/ 动态模式「发布动态」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 二、表单内容区

- **菜品名称**：
  - 评价模式（从菜品详情进入）：自动带入当前 `dishId` / 菜品名，预填只读，用户无需操作。
  - 动态模式（从动态页 / 我的进入）：`RelatedPickerSheet` 搜索选择已有菜品（见 spec §4.2 组件），必填。
- **评分选择器**：`Rating` 五颗星（选中 `var(--color-star)`，未选 `var(--color-star-empty)`），点击选星；必选（至少 1 星）。
- **评价内容输入框**：多行文本，占主要面积、高度自适应；上方字数统计「0/200」（`var(--font-aux)` / 三级灰），上限 200 字。
- **图片上传区域**：`ImageUploader`（统一组件，见 spec §4.9），点击添加（相册 / 拍照），最多 3 张，每张 ≤ 2MB；上传后缩略图预览，支持删除。

## 三、底部提交按钮

- 固定底栏，`AppButton` primary，文字「发布」；提交中显示「发布中...」并禁用重复点击（`disabled`）。
- 遵循固定底栏避让红线：`.scroll-wrap` 加 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`。
- 初始态：必填项未齐时按钮置灰不可用（`var(--bg-soft)` / 三级灰），齐后转 `var(--color-primary)` 可用。

## 四、表单校验

提交时校验：
- 菜品名称：必填（评价模式自动满足；动态模式须已选）。
- 评分：必选，至少 1 星。
- 评价内容：必填，至少 5 字、不超过 200 字。
- 图片：可选，最多 3 张，每张 ≤ 2MB。

不通过时在对应字段下方显示错误提示（`var(--color-error)` 文字），不提交。

## 五、状态与交互细节

- 初始态：字段空 / 评价模式仅菜品预填；提交按钮置灰不可用，必填齐后转可用。
- 加载态：提交中按钮「发布中...」禁用，防重复提交。
- 错误态：提交失败 → 错误信息提示，已填内容不丢失，可改后重提。
- 成功态：Toast「发布成功」，`navigateBack` 回上一页；新内容置顶（动态列表 / 菜品评价区），评分与摘要同步更新；同步至「我发布的」（见 `我发布的.md`）。
- 返回确认：表单有未提交内容时点返回 → 确认「确定放弃发布吗？」。
- 认证弹层：未登录进入发布页 / 触发提交 → `AuthSheet` 弹出登录引导（见 spec §5.x 喜欢/收藏单一概念与登录约束）。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 表单内容区
- 区块：左右 `var(--spacing-md)` 外边距，纵向 `var(--spacing-md)` 间距；每个字段 `padding: var(--spacing-sm) 0`。
- 菜品名称：评价模式只读展示 `var(--font-card)` / `var(--weight-bold)` / 主色；动态模式 `RelatedPickerSheet` 触发块（药丸 `var(--bg-soft)` + `var(--text-tertiary)` 占位）。
- 评分 `Rating`：星 `44rpx`，选中 `var(--color-star)`、未选 `var(--color-star-empty)`；按压态 `scale(var(--press-scale))`。
- 评价内容：多行 `var(--bg-card)` 圆角 `var(--radius-card)`、`padding: var(--spacing-md)`，字号 `var(--font-body)` / `var(--text-primary)`；字数统计 `var(--font-aux)` / 三级灰，右上对齐。
- 图片 `ImageUploader`：缩略图 `160rpx` 圆角 `var(--radius-card)`，删除角标 `var(--color-error)`；添加块 `dashed` 边框 `var(--text-tertiary)` + `plus` 图标。

### 底部提交按钮
- 固定底栏，`height: var(--action-bar-height)`，半透材质（见 spec §4.5），含 `env(safe-area-inset-bottom)` 安全区避让；圆角顶边 `var(--radius-sheet)`。
- 「发布」`AppButton`（primary，可用态 `var(--color-primary)` / 白字；禁用态 `var(--bg-soft)` / 三级灰）；提交中禁用 + 文案「发布中...」。

## 交互路径

动态页底部发布 / 我的 → 发布动态页（选菜品 + 评分 + 内容 + 图）→ 发布 → 回列表（新动态置顶，同步菜品评价区与「我发布的」）。菜品详情「写评价」→ 同一页（菜品预填）→ 发布 → 回详情页（新评价置顶、评分/摘要同步）。
