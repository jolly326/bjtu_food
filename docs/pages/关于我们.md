# 关于我们页（about）

> 路径 `pages/about/index`，从「我的」菜单「关于我们」进入的二级页（见 `project_spec.md` §2.1.1）。
> 设计基调：纯展示页，呈现产品身份与基础信息；品牌色统一用主色 token（朱砂红 `#9B2A1D`，见 `project_spec.md` §4.2），不另行定义色值。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

关于我们页为纵向滚动展示页，自上而下：顶部 Header → 品牌区（名称 + Logo）→ 简介 → 信息条目（`CardSection`）→ 底部免责声明。纯展示，无复杂交互。

```
Header（返回 + 标题「关于我们」）
────────────────────────
品牌区（Logo + 产品名称）
简介（产品定位）
信息条目：版本号 / 联系方式·公众号 / 隐私说明
底部免责声明
```

## 一、顶部 Header

- 左上返回箭头（`arrow-left`）：点之回「我的」页（`navigateBack`）。
- 居中标题「关于我们」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 二、内容区

- **品牌区**：Logo（`ImageFallback` 中性 `empty` 占位，主色描边 `var(--color-primary)`）+ 产品名称「食在交大」（`var(--font-title)` / `var(--weight-bold)` / `var(--color-primary)`）。
- **简介**：校园美食发现与推荐工具定位说明（UGC 驱动、无下单 / 支付），`var(--font-body)` / `var(--text-secondary)`。
- **信息条目**（`CardSection`）：版本号、官方联系方式 / 公众号、隐私说明链接（可点击复制或经 `web-view` 跳转，见 spec §2.1.4 唯一 `web-view` 场景）；每条左标签 `var(--font-aux)` / `var(--text-secondary)`，值 `var(--font-body)` / `var(--text-primary)`。
- **底部免责声明**：「内容由用户生成，仅供参考」，`var(--font-aux)` / `var(--text-tertiary)`。

## 状态与交互细节

- 纯展示页：无骨架 / 分页 / 空状态需求。
- 链接交互：隐私说明等可点项 → 复制（`copy`）或 `web-view` 跳转（仅隐私类外链，不滥用 `web-view`，见 spec §2.1.4）。
- 无登录触发点。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 品牌区
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-lg)`，居中。
- Logo `120rpx` 圆形 / 方形（按实现），主色描边 `var(--color-primary)`；产品名称 `var(--font-title)` / `var(--weight-bold)` / `var(--color-primary)`。

### 简介
- 左右 `var(--spacing-md)` 外边距，`var(--font-body)` / `var(--text-secondary)`，多行。

### 信息条目（CardSection）
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`；项间 `var(--spacing-sm)` 间距（或分隔线）。
- 每条：标签 `var(--font-aux)` / `var(--text-secondary)`，值 `var(--font-body)` / `var(--text-primary)`；可点项右 `arrow-right` `var(--text-tertiary)` 或「复制」文字 `var(--text-tertiary)`。

### 底部免责声明
- `var(--font-aux)` / `var(--text-tertiary)`，居中，左右 `var(--spacing-md)` 外边距。

## 交互路径

「我的」菜单「关于我们」→ 关于我们页（查看品牌 / 简介 / 版本 / 联系方式；隐私链接复制或 `web-view` 跳转）→ 返回「我的」。
