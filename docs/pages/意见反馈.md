# 意见反馈（feedback，合并反馈中心）

> 路径 `pages/feedback/index`，从「我的」菜单「意见反馈」进入的二级页。
> **2026-08-15 合并**：原「反馈中心」(`messages-services`) 与「意见反馈」(`feedback`) 合并为单一「意见反馈」页——提交表单与「我的反馈记录」同页展示，不再跨页跳转。遵循 `docs/mini-app-ui/README.md` 模式库（P1/P2/P3/P4/P8/P9）。

## 一、顶部 Header（P1）
左上返回箭头 + 居中标题「意见反馈」。

## 二、我的反馈记录列表（登录后展示）
- 区块标题「我的反馈」（`CardSection` + `SectionTitle`）。
- **未登录**：显示「登录后可查看你的反馈记录 ›」引导行，点击触发认证（`AuthSheet`），登录成功后自动加载（P1 行点击）。
- **已登录**：白底圆角卡片列表（P2），每项：反馈类型标签 + 处理状态徽标（待处理/已处理，`StatusBadge`）+ 内容摘要（两行截断）+ 提交时间；点击整卡 `showModal` 展示详情（内容 + 状态 + 后台回复）。
- 三态（P4）：加载中骨架 / 空状态「还没有反馈记录」/ 加载失败「加载失败，请重试」+ 重试。
- 游客（未登录）不展示列表，仅展示提交表单。

## 三、提交表单区
- **反馈类型**：`CardSection` 内分段选择（功能建议 / 问题报告 / 其他），单选高亮。
- **反馈对象（选填）**：`CardSection` 内分段选择（菜品 / 档口 / 食堂 / 其他），映射 `relatedType`；选「其他」则不传 `relatedType`。
- **反馈内容**：多行输入，必填，≤1000 字，实时字数计数。
- **联系方式（选填）**：输入框，便于回访。
- 反馈**不登录也可提交**（后端 `POST /feedback` 公开，游客 `userId=null`）。

## 四、底部提交栏（P3）
固定底部 `AppButton` primary「提交反馈」；提交态禁用 +「提交中…」。
- 校验：内容必填、≤1000 字。
- 成功 Toast「提交成功，感谢反馈」+ 返回上一页；失败保留已填内容可重提（P9）。

## 五、交互路径
我的 → 意见反馈 →（登录后见记录列表；填类型/对象/内容/联系方式）→ 提交 → 返回。
记录项点击 → 详情弹窗（含后台回复）；未登录 → 点击引导行 → 登录 → 记录列表自动载入。

## 六、与发布区的关系
本页 = 反馈提交 + 反馈历史归档；用户的「发布内容」（动态/评价）由「我发布的」(`docs/pages/我发布的.md`) 承载，二者职责分离，不混淆。
