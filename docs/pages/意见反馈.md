# 意见反馈页（feedback，合并反馈中心）

> 路径 `pages/feedback/index`，从「我的」菜单「意见反馈」进入的二级页；亦从首页「万能区域 → 上传菜品」进入并**预选菜品**（带入预选菜品，反馈对象默认「菜品」）。
> **2026-08-15 合并**：原「反馈中心」(`messages-services`) 与「意见反馈」(`feedback`) 合并为单一「意见反馈」页——提交表单与「我的反馈记录」同页展示，不再跨页跳转（见 `project_spec.md` §2.1.1）。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

意见反馈页为纵向滚动页，自上而下：顶部 Header → 我的反馈记录列表（登录后）→ 提交表单区 → 固定底部提交栏。

```
Header（返回 + 标题「意见反馈」）
────────────────────────
我的反馈记录（登录后：引导行 / 记录卡片列表）
提交表单：
  反馈类型（功能建议/问题报告/其他）
  反馈对象（菜品/档口/食堂/其他，上传菜品入口预选菜品）
  反馈内容（多行，≤1000）
  联系方式（选填）
────────────────────────
底部提交栏（提交反馈）
```

## 一、顶部 Header

- 左上返回箭头（`arrow-left`）：点之回上一页（`navigateBack`）；从首页万能区域进入则回首页。
- 居中标题「意见反馈」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 二、我的反馈记录列表（登录后展示）

- 区块标题「我的反馈」（`CardSection` + `SectionTitle`）。
- **未登录**：显示「登录后可查看你的反馈记录 ›」引导行，点击触发认证（`AuthSheet`），登录成功后自动加载（P1 行点击）。
- **已登录**：白底圆角卡片列表（P2），每项：反馈类型标签 + 处理状态徽标（`StatusBadge`：待处理 `var(--color-warning)` / 已处理 `var(--color-success)`）+ 内容摘要（两行截断）+ 提交时间；点击整卡 `showModal` 展示详情（内容 + 状态 + 后台回复）。
- 游客（未登录）不展示列表，仅展示提交表单。

## 三、提交表单区

- **反馈类型**：`CardSection` 内分段选择（功能建议 / 问题报告 / 其他），单选高亮（选中 `var(--color-primary)` 描边 / 文字）。
- **反馈对象（选填）**：`CardSection` 内分段选择（菜品 / 档口 / 食堂 / 其他），映射 `relatedType`；选「其他」则不传 `relatedType`。从首页「上传菜品」进入时默认预选「菜品」并带入预选菜品名 / `relatedId`，可点「移除」解除预选后另选。
- **反馈内容**：多行输入，必填，≤1000 字，实时字数计数（`var(--font-aux)` / 三级灰）。
- **联系方式（选填）**：输入框，便于回访。
- 反馈**不登录也可提交**（后端 `POST /feedback` 公开，游客 `userId=null`）。

## 四、底部提交栏

- 固定底栏 `AppButton` primary「提交反馈」；提交态禁用 +「提交中…」。
- 遵循固定底栏避让红线：`.scroll-wrap` 加 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`。
- 校验：内容必填、≤1000 字。
- 成功 Toast「提交成功，感谢反馈」+ 返回上一页；失败保留已填内容可重提。

## 状态与交互细节

- 骨架屏：记录列表首屏加载时以占位块呈现（灰块 + 圆角）。
- 空状态：已登录无记录 → 记录区「还没有反馈记录」；游客 → 仅展示提交表单。
- 失败状态：记录加载异常 → 「加载失败，请重试」+ 重试；提交失败 → 保留已填内容可重提。
- 认证弹层：未登录点击记录引导行 → `AuthSheet` 弹出登录引导，登录后自动载入记录。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 我的反馈记录
- 区块：左右 `var(--spacing-md)` 外边距，`CardSection` 包裹 + `SectionTitle`「我的反馈」。
- 引导行（未登录）：整行 `var(--bg-soft)` 圆角 `var(--radius-card)`、`padding: var(--spacing-md)`，文字 `var(--text-tertiary)` + `arrow-right`。
- 记录卡片：白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`，条间 `var(--spacing-sm)` 间距；类型标签 `var(--font-aux)` / `var(--text-secondary)`；状态徽标 `StatusBadge`（待处理 `var(--color-warning)`，已处理 `var(--color-success)`）；摘要 `var(--font-body)` / `var(--text-primary)`，两行截断；时间 `var(--font-aux)` / 三级灰。
- 按压态：`.pressed` 背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

### 提交表单区
- 区块：左右 `var(--spacing-md)` 外边距，`CardSection` 分隔；每段标题 `SectionTitle`，选项药丸 `var(--bg-soft)` 圆角 `var(--radius-pill)`，选中态 `var(--color-primary)` 描边 + 文字。
- 反馈内容：多行 `var(--bg-input)`（与联系方式输入框同底色）圆角 `var(--radius-card)`、`padding: var(--spacing-md)`，字号 `var(--font-body)` / `var(--text-primary)`；字数计数 `var(--font-aux)` / 三级灰（≥900 字转 `var(--color-warning)` 警示），右上对齐。
- 联系方式：单行输入同风格。

### 底部提交栏
- 固定底栏，`height: var(--action-bar-height)`，半透材质（见 spec §4.5），含 `env(safe-area-inset-bottom)` 安全区避让；圆角顶边 `var(--radius-sheet)`。
- 「提交反馈」`AppButton`（primary，可用态 `var(--color-primary)` / 白字；禁用态 `var(--bg-soft)` / 三级灰）；提交中禁用 + 文案「提交中...」。

## 交互路径

「我的」菜单「意见反馈」/ 首页万能区域「上传菜品」（预选菜品）→ 意见反馈页 →（登录后见记录列表；填类型 / 对象 / 内容 / 联系方式）→ 提交 → 返回。记录项点击 → 详情弹窗（含后台回复）；未登录 → 点击引导行 → 登录 → 记录列表自动载入。

## 与发布区的关系

本页 = 反馈提交 + 反馈历史归档；用户的「发布内容」（动态 / 评价）由「我发布的」(`我发布的.md`) 承载，二者职责分离，不混淆。
