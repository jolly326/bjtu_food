# 意见反馈（pages/feedback/index）

> 本页为小程序二级页，从「我的」菜单 `navigateTo` 进入（可 `navigateBack`）。
> 首页「上传菜品」入口经 `onLoad` 带 `object/name/id` 预置菜品关联。
> 2026-08-17 拍板：采用**双 Tab 分栏**结构（原「提交表单 + 记录同页长滚动」改为顶部 `SegmentTabs` 切换「写反馈 / 我的反馈」），根治底部固定提交栏常驻遮挡问题。

## 一、页面结构（顶部 → 底部）

```
Header（朱砂红底，返回键 @back="goBack"）
└─ SegmentTabs（自绘 .seg：写反馈 / 我的反馈，选中态主色软底+主色字+卡阴影）
   ├─ [写反馈] scroll-view（padding-bottom: calc(--action-bar-height + safe-area)）
   │   ├─ CardSection[反馈类型]        → type-chip（pill 药丸，选中主色）
   │   ├─ CardSection[反馈对象(选填)]  → preset-tip（预选菜品+「移除」）+ type-chip
   │   ├─ CardSection[反馈内容]        → textarea(--bg-input) + counter(≥900 转 warning)
   │   ├─ CardSection[联系方式(选填)]  → input(--bg-input) + 轻提示/错误文案
   │   └─ 底部固定 .submit-bar（仅写反馈视图渲染；半透玻璃+圆角顶边）
   └─ [我的反馈] scroll-view（无底栏，仅 safe-area 留白）
       ├─ 未登录 → login-hint（去登录，@tap="goLogin"）
       ├─ 已登录 → filter-tabs（全部/待处理/已处理 + 数量角标）
       │          → 骨架屏 / EmptyState / rec-list（卡片 tap → 详情 Sheet）
       └─ (无底栏)
BottomSheet（详情：复制内容 / 再反馈一次；拖拽手势）
AuthSheet（登录引导）
```

## 二、区块规范

### 1. SegmentTabs（顶部分段）
- 白卡胶囊容器：`bg-soft` + `radius-pill`，内两等宽分段 `flex:1`，高 `72rpx`。
- 选中态 `.seg.on`：`bg-card` + `shadow-card` + 主色字；未选 `text-secondary`。
- 过渡：`background/color 0.25s ease` + `var(--press-transition)`；真机 `hover-class="pressed"`，H5 `:active` 兜底 `scale(var(--press-scale))`。
- 切换时：写反馈↔我的反馈 条件渲染；首切到「我的反馈」且已登录且记录为空时 `loadRecords(true)`。

### 2. 写反馈表单
- **反馈类型**（pill 药丸，`--radius-pill`）：功能建议 / 问题报告 / 其他 / 举报。选中 `.type-chip.active`：`bg-primary-soft` + `border-color: var(--color-primary)`，字转主色。
- **反馈对象**（选填）：预选菜品提示条 `bg-primary-soft` + `dish` 图标 + 名称 + 「移除」（`hover-class="pressed"`）；下方对象 chips（菜品/档口/食堂/其他）。
- **反馈内容**：`--bg-input` 多行框 + `--radius-card`，`padding-md`，`min-height:220rpx`，`font-body`；右上角计数器 `--font-aux`，`≥900/1000` 转 `--color-warning`。
- **联系方式**（选填）：`--bg-input` 单行 `input` + `--radius-btn`，`cursor-spacing:20` 键盘避让；下方轻提示文案，格式错误时转 warning 并 Toast（不阻断提交）。
- 提交栏：仅写反馈视图渲染（`v-if activeTab==='write'`）。半透玻璃 `--blur-bg-solid` + `backdrop-filter: blur(var(--blur-radius)) saturate(180%)`；圆角顶边 `--radius-sheet`；`padding` 撑高（88rpx 按钮 + 上下 16rpx = 120rpx，对齐 `--action-bar-height`），safe-area 并入底部 padding；内嵌 `AppButton` 占满宽度（`:deep(.app-btn){flex:1}`）。

### 3. 我的反馈列表
- **筛选条**：全部 / 待处理 / 已处理，自绘 chips（选中主色态），带数量角标 `filter-count`。
- **列表卡片**：`bg-card` + `radius-card` + `shadow-card`；顶部 `rec-type-tag`（`--font-aux` + `bg-soft` + `--radius-tag`）+ `.fb-status` 状态徽标（自绘，待处理 `--color-warning-soft`/已处理 `--color-success-soft`，`--font-aux` + `--radius-tag`）+ 箭头；摘要 2 行截断 `--line-clamp:2`；时间 `--font-aux` 三级灰。
- 卡片按压：真机 `hover-class="pressed"`（`.rec-item.pressed{bg-soft}`），H5 `:active` 兜底。
- 状态：骨架屏（首屏 `records.length===0 && loading`）、`EmptyState`（report 图标）、加载失败 `EmptyState :retry`。

### 4. 详情 BottomSheet
- 复用 ApplySheet/RelatedPickerSheet 范式：`.sheet-mask`（固定 inset 0，`--overlay-scrim`，淡入）+ `.bottom-sheet`（`--radius-modal` 顶边圆角、`--shadow-modal`、拖拽手势 `translateY`、速度/位移阈值关闭）。
- 主体 scroll-view：类型 / 状态徽标 / 内容（`overflow-wrap:break-word` 防溢出）/ 后台回复（有则显示）/ 提交时间。
- **底部操作行**：「复制内容」（`uni.setClipboardData`）+「再反馈一次」（`activeTab='write'` 并预填 type/content，关闭 Sheet）；图标 + 文字，按压反馈。

## 三、交互与状态

| 行为 | 实现 |
|---|---|
| 提交校验 | 内容非空、≤1000 字；contact 轻校验（可空，填了校验邮箱/微信格式，错误仅提示不阻断） |
| 提交成功 | Toast → 清空表单 → 已登录则 `loadRecords(true)` 即时刷新 → `activeTab='mine'` 新反馈置顶（后端倒序） |
| 返回 | `goBack`：`getCurrentPages().length>1` 则 `navigateBack`，否则 `reLaunch` 首页（从「我的」进入回「我的」） |
| 登录引导 | `AuthSheet` 经 `userStore.requireAuth`；登录成功 `watch` 自动 `loadRecords` |
| 键盘避让 | textarea/input 均 `:cursor-spacing="20" :adjust-position="true"` |

## 四、设计 Token（引用，单一事实源 App.vue / tokens.ts）

- 主色：`--color-primary`（朱砂红 `#9B2A1D` / 深色 `#C45A3C`）、`--color-primary-soft`。
- 圆角：`--radius-pill`(药丸) / `--radius-card`(卡片) / `--radius-tag`(标签/徽标) / `--radius-btn`(输入) / `--radius-sheet`(提交栏顶边) / `--radius-modal`(Sheet 顶边)。
- 底色：`--bg-page` / `--bg-soft` / `--bg-card` / `--bg-input`。
- 材质：`--blur-radius`、`--blur-bg-solid`、`--overlay-scrim`、`--shadow-card`、`--shadow-bar-soft`、`--shadow-modal`。
- 字号：`--font-aux`(辅助) / `--font-body`(正文) / `--font-h3`(标题)；字重 `--weight-bold/semibold`。
- 功能色：`--color-warning` / `--color-success` 及对应 `-soft`。
- 间距：`--spacing-2xs/xs/sm/md/lg/xl`。
- 动效：`--press-scale`(0.97)、`--press-transition`；视口 `100dvh` 渐进降级 `100vh`。

## 五、审计红线（来自 project_spec §4，强制）

- 固定底栏页面 `.scroll-wrap` 必须 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`（仅写反馈视图，我的反馈无底栏）。
- 事件绑定用 `@tap` 而非 `@click`；列表/可点元素用 `role` + `aria-label`。
- 按压缩统一 `var(--press-scale)`，禁止裸 `scale()`；真机按压用 `hover-class="pressed"`（微信 view 不支持 `:active`）。
- 图标统一 `IconSvg`（线性 24px 网格，stroke 注入色），禁止 emoji 充当图标；复制图标已补 `copy`、再反馈用 `edit`。
- 底部弹层材质 `blur(20px) saturate(180%)`、顶边圆角 `20px 20px 0 0`、阴影 `0 -8px 30px rgba(0,0,0,0.12)`。
- `prefers-reduced-motion` 降级：去弹性、交叉淡入、禁 transform（已在 `@media` 块覆盖全部可点元素）。

## 六、已知约束 / 待办
