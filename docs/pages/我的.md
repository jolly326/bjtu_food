# 我的页（profile）

> 路径 `pages/profile/index`，从小程序底部 TabBar「我的」进入的 TabBar 页；亦从首页顶部头像点击经 `navigateTo` 进入（此时左上角显示返回箭头，点之回首页）。
> 设计基调：个人中心，承载「查看自身信息 / 管理已发布内容 / 进入运营页（活动 / 反馈 / 关于）」；菜单项与 `project_spec.md` §2.1.1 入口表一致（含最新活动）。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

我的页为纵向滚动页，自上而下：顶部 Header（可选返回）→ 用户信息卡片 → 功能菜单列表（纵向卡片，左图标+名称、右箭头）。

```
Header（标题「我的」+ 可选返回）
────────────────────────
用户信息卡（头像 + 昵称 / 点击登录）
菜单列表：
  「我发布的」        →
  「最新活动」        →
  「意见反馈」        →
  「关于我们」        →
  「退出登录」（警示色）
```

## 一、顶部 Header

- 居中标题「我的」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。
- 左上角返回箭头（`arrow-left`）：仅从首页顶部头像等二级入口 `navigateTo` 进入时显示，点之回首页；TabBar 直入时不显示。

## 二、用户信息卡片

- 头像：圆形（`ImageFallback` 中性 `empty` 占位），尺寸适中（如 `112rpx`）。
- 昵称（`var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`）。
- 未登录：显示默认头像 +「点击登录」提示（`var(--text-tertiary)`），点击触发登录流程（邮箱验证码登录，见 spec §5.x）。

## 三、功能菜单列表

纵向卡片式，每项占一行：左图标（`IconSvg`）+ 名称，右 `arrow-right`；点击进入对应二级页。顺序与 spec §2.1.1 对齐：

- **我发布的** → `pages/pages-user/my-posts/index`（见 `我发布的.md`）；展示用户发布的所有评价内容，支持编辑 / 删除（编辑复用 `PublishReview`，见 `发布动态.md`）。
- **最新活动** → `pages/activity/index`（见 `最新活动.md`）；由「我的」菜单进入活动聚合列表。
- **意见反馈** → `pages/feedback/index`（见 `意见反馈.md`）；反馈提交 + 历史记录。
- **关于我们** → `pages/about/index`（见 `关于我们.md`）；产品信息 / 版本 / 团队。
- **退出登录** → 文字 `var(--color-error)` 警示色；点击 `showModal` 确认「确定要退出登录吗？」，确认后清除登录态回未登录态。

## 四、登录态与未登录态

- **未登录**：信息卡显示默认头像 +「点击登录」；菜单中「我发布的」置灰不可点击（或无数据）；「最新活动 / 意见反馈 / 关于我们」可见可用；「退出登录」置灰不可点击。点击「我发布的」置灰项 → 触发 `AuthSheet` 登录引导。
- **已登录**：信息卡显示头像 + 昵称；全部菜单项正常可点。

## 状态与交互细节

- 认证弹层：未登录点击「我发布的」→ `AuthSheet` 弹出登录引导，登录后跳转「我发布的」。
- 退出确认：点击「退出登录」→ `showModal` 二次确认，防误触。
- 无骨架 / 分页需求（本页为轻量个人中心，登录态切换即时刷新）。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 用户信息卡片
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-lg)`；与搜索前发现主页卡片同风。
- 头像 `112rpx` 圆形（`ImageFallback` 中性 `empty`）；昵称 `var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`；未登录提示 `var(--text-tertiary)`。
- 按压态：`.pressed` 背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

### 功能菜单列表
- 纵向卡片（或每组 `CardSection` 包裹），左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`；项间 `var(--spacing-sm)` 间距。
- 菜单项：左图标 `IconSvg` `40rpx` / 主色 + 名称 `var(--font-body)` / `var(--text-primary)`；右 `arrow-right` `var(--text-tertiary)`；整行可点。
- 「退出登录」名称 `var(--color-error)`；「我发布的」置灰态 `var(--text-tertiary)` / 不可点。
- 按压态：`.pressed` 背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

## 交互路径

TabBar「我的」/ 首页顶部头像 → 我的页 →（未登录先登录）→ 点「我发布的」管理内容 / 点「最新活动」「意见反馈」「关于我们」进入对应页 / 点「退出登录」确认退出。
