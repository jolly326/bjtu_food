
## 首页整体结构

首页是用户进入小程序后看到的第一个页面，从上到下依次为：顶部操作栏、广播栏、万能区域、菜品瀑布流。

> 设计基调：首页核心是「推荐」而非「导航」——顶部无定位条、菜品无收藏（距离由后端下发展示），所有信息围绕"有什么好吃的"展开。


### 一、顶部操作栏

顶部操作栏为**单行**胶囊布局（**统一行高 `88rpx`，不强制对齐微信右上角胶囊——全站 header 高度一致、视觉统一**）。

> 顶部操作栏为**朱砂红大面积品牌色块**（`--color-primary` 背景，与搜索页 header 同款）；头像 / 搜索胶囊浮于其上，搜索胶囊白底 `--bg-card` 不破坏品牌色整体性（白字按钮对比高，沉稳醒目）。

左侧仅保留**用户头像**（直径 `72rpx` 圆形，未登录回退默认 `user` 图标），点击进入「我的」页面；不展示昵称——昵称信息收归「我的」页，避免与搜索框横向抢位、更聚焦。

右侧为**搜索胶囊**：与头像同高（`72rpx`）、同圆角（药丸 `999rpx`）、白底卡片 + 阴影；占位文字「搜索你想吃的...」，点击进入搜索页（`/pages/find/index`）。**搜索胶囊右侧预留微信小程序胶囊（关闭 / 分享）占用区**——右侧 `margin-right` 由运行时实测胶囊位置写入（`getCapsuleReservePx()`），搜索框不覆盖原生胶囊；因此搜索胶囊与右上角系统胶囊同处一行、互不遮挡。

> 首页**不显示定位条**（无校区定位 UI、无坐标授权）；定位与距离由**后端**按坐标计算，以 `distance`（米）字段随菜品下发，菜品卡片展示"距你 Xm"。食堂/档口仅作为菜品属性在菜品详情展示，不在首页提供位置相关入口。

> 搜索胶囊与搜索页搜索框**同一屏幕位置、同一尺寸**（见 `docs/pages/搜索页.md` §顶部固定区）：从首页点搜索框跳入搜索页时，搜索框在屏幕上「原地不动」，仅左上角头像位切换为返回键。


### 二、广播栏（动态信息流，可点击）

广播栏位于搜索框下方，用于滚动播放**动态信息**——即学生对菜品的最新评价/动态摘录，而非运营公告。它的作用是让用户在首页就能看到"大家在说什么"，同时作为进入完整动态列表的入口。

广播内容为一条一条纯文本动态，自动向上切换，每次显示一条，滚动间隔约为 3 秒；触摸广播栏会暂停轮播，松手后恢复。每条动态**仅展示评论文字本身**（不含评价人、菜品名、评分等附加信息），单行显示、超出部分以"…"省略号截断，例如"这家麻辣香锅真的绝了，分量足还便宜…"。

**点击广播栏跳转按条目类型路由**（数据源以 `broadcastType` 下发，前端据此分发）：
- `community`（评价/动态）→ 动态列表页（community tab）
- `dish`（菜品相关）→ 菜品详情页
- `url`（外链）→ web-view 打开 / 复制链接

> 首页广播**只承载动态信息**（评价/动态摘录），不混运营公告；非动态类（如纯通知 `NOTICE`/`ACTIVITY`）不进入首页广播。


### 三、万能区域（水平一行网格，每列独立跳转）

万能区域位于广播栏下方，采用**水平一行网格（均分布局）**：同一行内并列多个模块单元格，每个单元格宽度均分。每个单元格**仅由图标 + 内容（模块名 + 副信息）构成，不附加"查看全部"等任何引导性文案**；各单元格**独立底色**以区分模块（见细节设计）。

**每个单元格（每一列）对应一个独立跳转目标**，便于后续小程序拓展——新增业务模块时只需在网格中追加一列、并定义它自己的跳转，互不影响：
- **列一：最新活动** → 活动列表页（`pages/activity/index`）。单元格结构为「图标(`fire`) + 模块名(最新活动) + 最近一条活动预览(标题 · 相对时间)」；整列点击即跳转，**无「查看全部」入口**（单元格本身即完整跳转目标）。
- **列二：全部菜品** → 搜索 / 浏览页（`pages/find/index`）。单元格结构为「图标(`search`) + 模块名(全部菜品) + 副信息(分类·榜单·发现更多)」；整列点击即跳转，无「查看全部」入口。将首页 prime 位置从低转化的"投稿"动作改为更通用的"浏览全部菜品"入口，与顶部搜索框形成"快捷搜索 + 分类浏览"互补，**不新增路由**。
- 未来模块（如专题、食堂推荐等）：各自定义跳转目标（列表页 / 详情页 / web-view 等），在同一行追加列、均分宽度即可，无需改动布局。

- 活动数据由后台运营手动录入（活动标题、活动描述、发布时间、公众号文章链接）；活动列表页按时间倒序排列，点击具体活动经微信 `web-view` 跳公众号文章。

> 说明：当前固定为**两列**（最新活动 + 全部菜品），各占一半宽度；未来模块数变化时按列均分。它不是横滑卡片，也不是竖向列表。


### 四、双列菜品瀑布流

瀑布流是首页的主体内容，展示所有菜品卡片，采用双列布局。

每个菜品卡片包含：
- **菜品图片**：正方形（含右上角评分角标 ⭐ 数字）
- **菜名**：一行显示，超长截断
- **价格**：如"¥18"
- **标签**：如"辣"/"新品"等（可选）
- **所属食堂 · 档口**：如"一食堂 · 麻辣香锅"
- **距你距离**：如"距你 200m"（来自后端按定位计算，字段缺省时不展示；前端无定位条 UI）

卡片采用白色背景，圆角设计，**加 `1rpx` 浅色描边（`--border-light`）以增强与页面底色的边界区分**（配 `--shadow-card`），点击后进入菜品详情页。瀑布流支持上滑触底加载更多，默认按**综合热度**排序（评价数 + 评分综合计算，**不含收藏量——收藏功能已移除**）。首页**不提供排序切换 UI**——排序固定为综合热度，不做"综合/距离/最新"的 tab 切换（距离仅作信息展示，不参与排序）。


## 细节设计（尺寸与样式规范）

本节用设计 token 标注各区块的具体尺寸与样式，确保设计与实现一致。页面级 CSS 变量（`--spacing-*` / `--color-*` / `--bg-*` / `--radius-*` / `--font-*` 等）声明在 `client/src/App.vue` 的全局 `<style>`；图标色常量（IconSvg 用，SVG data-uri 无法解析 var）在 `client/src/theme/tokens.ts`；`client/src/uni.scss` 仅保留 uni 默认 scss 兼容变量、不声明裸 CSS 变量（裸 CSS 编译会被丢弃）。

### 顶部操作栏（单行星胶囊）
- 容器（`.header-wrap.home`）：`background: var(--color-primary)`（朱砂红 header 大面积品牌色块，与搜索页 header 同款）；顶部 `padding-top = max(statusBarHeight, safe-area-inset-top)`，**底部 `padding-bottom: 0`**（与全站二级页 header 总高一致：`statusBar + 88rpx`，保证首页 / 二级页 / 搜索页 / web-view 四类 header 等高）；红色区下探后，与下方广播白卡之间仍由广播自身 `margin-top: var(--spacing-md)` 提供页面底色间距（广播压缩自身内边距、不抬高），二者独立不冲突。左右内边距 `var(--spacing-md)`。
- **全站 header 统一主题色**：通用/二级页 header（`.nav-header`，返回箭头 + 居中标题）同样使用 `--color-primary` 背景、标题与返回箭头取 `--color-on-primary-surface`（白）；高度统一 `88rpx`，与首页 header 视觉一致。深色模式回落 `--bg-page`。
- 单行（`.home-row`）：`display:flex; align-items:center; gap: var(--spacing-sm); height: 88rpx`（**固定行高，全站 header 统一，不绑定微信胶囊坐标**），头像 + 搜索胶囊同处一行并垂直居中。
- 头像（`.user-chip`）：仅头像，直径 `72rpx` 圆形，左侧；命中区 `72rpx`，点击进「我的」；未登录回退半透明白底 `user` 图标。不展示昵称。
- 搜索胶囊（`.home-search-pill`）：`flex:1; height: 72rpx; border-radius: var(--radius-tag)（药丸）`；白底 `var(--bg-card)` + 阴影 `var(--shadow-card)`；**内部左右 `var(--spacing-sm)` 内边距（避免横向留白过大）**、前置 `search` 图标 `36rpx` / `var(--color-primary)`、占位文字 `var(--text-tertiary)` / `var(--font-body)`；右侧 `margin-right` 运行时写入 = 微信胶囊预留宽度（`getCapsuleReservePx()`），不覆盖原生胶囊。
- 对齐约束：头像左缘与搜索胶囊左缘统一从 `var(--spacing-md)` 起；搜索胶囊与搜索页搜索框同一屏幕位置、同一尺寸（见 `docs/pages/搜索页.md` §顶部固定区）。

### 广播栏（胶囊卡片，与搜索胶囊同视觉语言）
- 容器：最小高度 `100rpx`（**与万能区卡片等高且更矮**，视觉对齐），`padding: 0 var(--spacing-sm)`（横向内边距收敛，避免过大留白），`margin: var(--spacing-md)`（上 / 下 `spacing-md`、左右 `spacing-md`；**顶部 margin 与红色 Header（底部 `padding-bottom:0`，行高 88rpx）之间留出页面底色间距**，白卡不贴红头；**左右再叠加 `env(safe-area-inset-left/right)` 适配异形屏 / 横屏**）；背景 `var(--bg-card)` + 阴影 `var(--shadow-card)`；**内容自适应高度**：文字最多展示 `2` 行（`-webkit-line-clamp: 2` 超出省略），长广播不再被单行截断，高度随文字行数撑高。
- 文字：字号 `var(--font-body)`（`28rpx`，较原 `font-aux` 放大更易读）/ `var(--text-secondary)`；**仅评论文字本身**，不含评价人 / 菜品名 / 评分等附加信息，超长以"…"省略号截断。广播图标（`.broadcast-icon`）`36rpx` / `var(--color-primary)`（较原 `28rpx` 放大）。
- 轮播：向上切换（每条一条，高度一行），间隔 `3s`；`touchstart`/`mousedown` 暂停，`touchend`/`mouseup`/`mouseleave` 恢复；无指示点、无左右箭头。
- 可点性：整条可点 `@tap`，按当前条目 `broadcastType` 分发（见 §二）；非动态类条目不进此流。

### 万能区域（水平一行网格）
- 容器：上 `0`（由广播栏 `margin-bottom: var(--spacing-md)` 提供间距，与广播栏同构、间距一致）、左右 `var(--spacing-md)` 外边距（**再叠加 `env(safe-area-inset-left/right)` 适配异形屏 / 横屏**）、下 `var(--spacing-md)`；`display:flex; gap: var(--spacing-md)` 横向排列（与全站纵向节奏统一）。**与广播栏间距模型完全一致（上 0 / 下 md），保证首页区块纵向节奏统一。**
- 单元格：每个 `flex:1 1 0; min-width:0`，圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、内边距 `var(--spacing-sm)`（`16rpx`，由 `24rpx` 收敛）、`min-height: 100rpx`（**与广播栏等高且更矮**）；**各单元格独立背景色**（不统一用白底）；列数 = 当前模块数（**当前两列：最新活动 + 全部菜品，各 `flex:1` 均分**）；未来追加列自动重排均分，每列各配一色。
- 单元格配色（每列独立；页面背景 token 声明于 `client/src/App.vue`，图标色常量见 `client/src/theme/tokens.ts`）：
  - 列一（最新活动）：背景 `--bg-cell-activity`（暖橙浅底），图标 `var(--color-activity)`（暖橙系）；
  - 列二（全部菜品）：背景 `--bg-cell-upload`（清凉浅底），图标 `var(--color-upload)`（冷色系）。
- 单元格结构（从左到右）：
  - 图标区：`IconSvg` 尺寸 `44rpx`，色值随所在列（列一 `var(--color-activity)` / 列二 `var(--color-upload)`）；
  - 主区（flex:1，纵向）：
    - 模块名 `30rpx` / `var(--weight-semibold)` / `var(--text-primary)`，单行截断；
    - 副信息 `22rpx` / `var(--text-tertiary)`，**最多 `2` 行截断**（`-webkit-line-clamp: 2`，活动标题较长时不被单行截断丢失；活动：最近一条标题 · 相对时间；无活动："暂无活动，敬请期待"）。
- 按压态：`.pressed` 时背景转 `var(--bg-soft)`、整体 `transform: scale(var(--press-scale))`；点击单元格整列触发其 `onTap`（当前：**列一→活动列表页，列二→意见反馈页**）。

### 双列菜品卡片（DishCard）
- 栅格：双列，`column-gap` / `row-gap` 由 `WaterfallList` 统一控制（左右 `var(--spacing-md)` 外边距内两列，与广播栏 / 万能区左右边距对齐）；卡片白底、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`。
- 图片：可不强制 1:1 等比（当前采用固定高度 `200rpx` 等高热图方案，双列等高、错落感弱、性能稳妥，宽度撑满列、高度等比非必需）；右上角评分角标（半透明深色底 + ⭐ + 数字，白字 `22rpx`）。
- 文字区：上下 `12rpx`、左右 `14rpx` 内边距：
  - 菜名 `30rpx` / `var(--weight-semibold)` / `var(--text-primary)`，单行截断；
  - 价格 `30rpx` / `var(--weight-bold)` / `var(--color-price)`，如"¥18"；
  - 标签行：`tags` 以浅色胶囊呈现（可选，无则隐藏）；
  - 元信息行（两端对齐）：左侧"食堂 · 档口" `var(--font-aux)` / `var(--text-tertiary)` 截断；右侧"距你 Xm" `var(--font-aux)` / `var(--color-primary)` / `var(--weight-medium)`，`distance` 缺省时整段不渲染。
- 距离格式：`<1000m` 显示"Xm"（四舍五入），`≥1000m` 显示"X.Xkm"；仅展示，不参与排序。
- 点击态：整卡可点进菜品详情页。

### 空 / 加载 / 失败态
- 骨架屏：首屏加载时广播位与菜品网格以占位块呈现（灰块 + 圆角），不展示真实数据。
- 空状态：三个板块均无数据 → 居中空图标 + "暂时没有内容"。
- 失败状态：请求异常 → 提示"加载失败 / 网络异常或后端未启动，下拉刷新后重试"。
- 下拉刷新：下拉 `onRefresh` 重拉广播 + 活动 + 热门；刷新中有转圈指示。
- 触底加载：滚动到底 `loadMoreHomeHot`，底部文案"加载中…" → 全部加载完显示"— 已经到底啦 —"。
- 认证弹层：未登录触发需登录动作（写评价、点赞）→ `AuthSheet` 弹出登录引导，不静默失败。


## 三个入口的分工

| 区域 | 内容 | 点击跳转 |
|---|---|---|
| 广播栏 | 动态信息流（最新评价/动态摘录，自动轮播） | 按 `broadcastType` 路由：`community`→动态列表页 / `dish`→菜品详情页 / `url`→web-view |
| 万能区域 | 水平一行网格，每列一个模块（当前：最新活动 / 全部菜品） | 每列独立跳转（列一→活动列表页；列二→搜索浏览页）；未来模块各自定义 |
| 瀑布流 | 双列菜品卡片 | 菜品详情页 |

> 广播栏只承载动态类（`community`/`dish`/`url`），非动态类（`NOTICE`/`ACTIVITY`/食堂档口类）不进首页广播、不展示。


## 页面的信息层级

用户打开首页，从上到下依次获取三类信息：

- **大家在说什么**（广播栏）→ 动态信息流，可点击按类型进入
- **现在有什么活动 / 想浏览全部菜品**（万能区域）→ 活动入口 + 全部菜品（每列独立跳转）
- **有什么好吃的**（瀑布流）→ 菜品详情入口

三个模块各有分工，互不重叠，用户需要什么就点什么，不需要滚动到底才能找到想要的功能。


## 状态与交互细节

- **骨架屏**：首屏数据加载中展示（广播位 + 菜品网格占位）。
- **空状态**：全板块无数据时展示空图标 + "暂时没有内容"；加载失败展示"加载失败 / 网络异常或后端未启动，下拉刷新后重试"。
- **下拉刷新**：下拉触发 `onRefresh`，重新拉取广播 + 活动 + 热门菜品。
- **触底加载**：瀑布流滚动到底自动 `loadMoreHomeHot`，底部展示"加载中…" / "— 已经到底啦 —"。
- **认证弹层**：未登录用户触发需登录操作（如写评价、点赞）时，统一由 `AuthSheet` 弹出登录引导。
