# 个人信息（profile-edit）

> 路径 `pages/pages-user/profile-edit/index`，从「我的」点击头像/昵称区域或菜单「个人信息」进入的二级页。遵循 `docs/mini-app-ui/README.md` 模式库（P1/P3/P9）。

## 一、顶部 Header（P1）
左上返回箭头 + 居中标题「个人信息」。

## 二、信息卡
- **头像**（可点）：当前头像缩略图 + 右箭头；点击调起选图/上传（复用 `uploadImage`），上传中 loading 态。
- **昵称**：输入框，≤16 字，必填。
- **学号 / 校园邮箱 / 身份**：只读展示（校园身份由认证决定，不可改）。

## 三、底部保存栏（P3）
固定 `AppButton` primary「保存」；保存态禁用+「保存中…」。
- 校验：昵称非空。
- 成功 Toast「已保存」+ 返回；失败保留已填内容可重提（P9）。

## 四、交互路径
我的 → 个人信息 → 改头像/昵称 → 保存 → 返回（同步更新「我的」页用户卡）。
