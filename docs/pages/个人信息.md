# 个人信息页（profile-edit）

> 路径 `pages/pages-user/profile-edit/index`，从「我的」页点击用户信息卡（头像 / 昵称区域）进入的二级页（入口以 `project_spec.md` §2.1.1 为准；若实现侧在「我的」菜单增加「个人信息」项则同入口）。
> 设计基调：仅维护可改字段（头像 / 昵称）；校园身份（学号 / 校园邮箱 / 身份）由认证决定，只读不可改，避免自服务改写的权限风险。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

个人信息页为纵向滚动表单页，自上而下：顶部 Header → 信息卡（头像 / 昵称 / 只读校园身份）→ 固定底部保存栏。

```
Header（返回 + 标题「个人信息」）
────────────────────────
信息卡：
  头像（缩略图 + 右箭头，可点上传）
  昵称（输入框，≤16）
  学号 / 校园邮箱 / 身份（只读）
────────────────────────
底部保存栏（保存）
```

## 一、顶部 Header

- 左上返回箭头（`arrow-left`）：点之若未保存改动 → 可提示「放弃修改？」，确认后回「我的」（`navigateBack`）。
- 居中标题「个人信息」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 二、信息卡

- **头像（可点）**：当前头像缩略图（`ImageFallback` 中性 `empty`）+ 右 `arrow-right`；点击调起选图 / 上传（复用统一图片上传组件，见 spec §4.2，头像仅单张），上传中 loading 态。
- **昵称**：输入框，≤16 字，必填（`var(--font-body)` / `var(--text-primary)`）。
- **学号 / 校园邮箱 / 身份**：只读展示（`var(--text-tertiary)`），校园身份由认证决定，不可改。

## 三、底部保存栏

- 固定底栏 `AppButton` primary「保存」；保存态禁用 +「保存中…」。
- 遵循固定底栏避让红线：`.scroll-wrap` 加 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`。
- 校验：昵称非空。
- 成功 Toast「已保存」+ 返回上一页，同步更新「我的」页用户卡；失败保留已填内容可重提。

## 状态与交互细节

- 初始态：字段回填当前用户值；保存按钮在昵称为空时置灰不可用。
- 加载态：头像上传 / 保存中显示 loading，禁用重复操作。
- 错误态：保存失败 → 错误信息提示，已填内容不丢失，可改后重提。
- 返回确认：有未保存改动时点返回 → 提示「放弃修改？」。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 信息卡
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`。
- 头像行：缩略图 `96rpx` 圆形（`ImageFallback` 中性 `empty`）+ 右 `arrow-right` `var(--text-tertiary)`；整行可点上传；上传中 loading。
- 昵称行：标签 `var(--font-aux)` / `var(--text-secondary)`，输入框 `var(--font-body)` / `var(--text-primary)`，右下字数计数 `var(--font-aux)` / 三级灰。
- 只读行（学号 / 校园邮箱 / 身份）：标签 `var(--font-aux)` / `var(--text-secondary)`，值 `var(--text-tertiary)`，不可编辑。

### 底部保存栏
- 固定底栏，`height: var(--action-bar-height)`，半透材质（见 spec §4.5），含 `env(safe-area-inset-bottom)` 安全区避让；圆角顶边 `var(--radius-sheet)`。
- 「保存」`AppButton`（primary，可用态 `var(--color-primary)` / 白字；禁用态 `var(--bg-soft)` / 三级灰）；保存中禁用 + 文案「保存中...」。

## 交互路径

「我的」页点击用户卡（头像 / 昵称）→ 个人信息页 → 改头像 / 昵称 → 保存 → 返回（同步更新「我的」页用户卡）。
