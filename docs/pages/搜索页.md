# 搜索页（find）

> 路径 `pages/find/index`，从首页搜索框点击进入的二级页。
> 设计基调：**搜索只针对「菜品」**。食堂 / 档口已降级为菜品属性（见首页拍板），不再作为独立可搜实体、也不再有独立结果类型与详情页；用户搜食堂 / 档口名时，后端在菜品索引中一并匹配，返回的仍是该食堂 / 档口的**菜品列表**。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（页面级 CSS 变量声明于 `client/src/App.vue` 全局 `<style>`；图标色常量见 `client/src/theme/tokens.ts`；`client/src/uni.scss` 仅保留 uni 默认 scss 兼容变量、不声明裸 CSS 变量）。
>
> 搜索页由**两个页面**构成：
> - **页面一 · 搜索前**：进入即见，含「发现主页」与「输入联想态」两个子态；
> - **页面二 · 搜索后**：提交搜索后进入，展示菜品结果列表。
> 两页面共用顶部固定区。

## 顶部固定区（两页面共用，不随滚动；与首页搜索胶囊同位置）

> 该固定区为**朱砂红大面积品牌色块**（`--color-primary` 背景），与首页 header **同高、同背景、同左右内边距（`var(--spacing-md)`）**，仅左上角控件由「头像」换为「返回箭头」——建立「搜索框原地不动、仅头像位切回返回键」的心智。搜索框白底 `--bg-card` 浮于之上；返回箭头用 `--color-on-primary-surface`（白 / 暖白，位于红底之上），**搜索框内占位文字在白底搜索框上用三级灰 `--text-tertiary`**（与首页搜索胶囊一致，不可用白字）。背景始终贴合屏幕顶部、不随滚动。

- 左上返回箭头（`arrow-left`）：在任一子态 / 结果态点返回，先收起键盘、回发现主页；已在发现主页时点返回回首页（`goBackHome`）。**返回键命中区 `72rpx` 见方，位于首屏左上角，与首页头部头像「同一屏幕位置」**（左缘统一 `var(--spacing-md)`）——建立「搜索框位置不变、仅左上键在头像位切换」的心智。
- 中部药丸搜索框：图标（`search`）+ 输入框（`placeholder="搜索你想吃的..."`）+ 清空按钮（`close`，有输入才出现）；`confirm-type="search"`，回车 / 确认触发搜索。**搜索框与首页搜索胶囊尺寸、圆角、背景、左右位置、占位文字完全一致**——高 `72rpx`、药丸 `border-radius: var(--radius-tag)`、白底 `var(--bg-card)` + 阴影 `var(--shadow-card)`；左缘在头像 / 返回键右侧统一间距，右侧 `margin-right` 同样由 `getCapsuleReservePx()` 写入避让微信胶囊；从首页点搜索框跳入时，搜索框在屏幕上「原地不动」。
- **结果分类 Tab 已移除**：搜索结果只有「菜品」单一类型，无需切换。
- **三者同一行**：返回箭头 + 药丸搜索框 + 微信右上角系统胶囊同处顶部一行；搜索框右侧 `margin-right` 由运行时实测胶囊位置写入，避让胶囊占用区（关闭 / 分享按钮），搜索框不可覆盖胶囊。

## 页面一 · 搜索前

进入搜索页的默认页面，含两个子态：

- **顶部间距**：顶部固定区为 `fixed` 不随滚动，页面一内容容器需先避让固定区总高度（statusBar + 搜索行高，勿被遮挡），再在其下叠加 `var(--spacing-md)` 组件间隔（与首页「顶部操作栏 → 广播栏 → 万能区域」间隔一致），既不留过大空白、也不可被固定区压住。

### 子态 A：发现主页（未输入 / 未搜索）

- **搜索记录**（首位）：`CardSection` 包裹，标题「搜索记录」，右侧「清空」；历史词以 chip 展示，超 3 条折叠为「展开全部 N 条」；单条 chip 可点（直接搜索）或点 × 删除（`.stop` 阻止触发搜索）。
- **热搜列表**：火标（`ic-fire`）+ 排名序号 + 关键词；点击直接搜索。加载中骨架、失败可重试（避免首屏空白）。
- 此子态下不显示联想面板。

### 子态 B：输入联想态（输入中，尚未提交搜索）

输入即触发联想（防抖约 300ms 调用 `fetchSuggestions`）。采用美团式**覆盖式联想**：在发现主页上方覆盖一张联想页，发现主页的搜索记录 / 热搜卡片**不卸载、仅被遮住**（清空输入即瞬时还原，无需重新拉取 / 重渲染）。

- **面板形态**：`fixed` **实底浮层**（背景 `var(--bg-page)` 不透明直接覆盖，不启用毛玻璃）；覆盖在发现主页上方、搜索框正下方，不随页面滚动；触摸空白 / 点返回收起键盘并还原发现主页。小程序端 `backdrop-filter` 支持不稳且费性能，采用美团小程序同款实底覆盖方案。
- **与微信键盘共存**：面板置于可随键盘上移的滚动容器内（或按运行期键盘高度动态写入 `bottom`），避免被系统键盘遮挡；联想项多时面板内部滚动，最多约 8 条由后端截断。
- **内容（仅菜品）**：每项一行——
  - 左：菜品缩略图（无图回退 `dish` 类型图标）；
  - 中：菜名，**命中的搜索关键词高亮**（主色），单行截断；下方一行属性「食堂 · 档口」（`font-aux` / 三级灰）；
  - 右：价格（主色）+ 评分（⭐ + 数字）。
- **数量上限**：最多约 8 条，超出由后端截断，避免面板过长。
- **边界态**：
  - 加载中：面板顶部骨架 / 转圈，避免闪白；
  - 无匹配：面板内显示「无相关菜品」，不空洞收起。
- **点击**：任一联想项 → 菜品详情页（`/pages/pages-detail/dish`），进入**页面二**。

## 页面二 · 搜索后（结果列表）

由确认搜索 / 点历史词 / 点热搜 / 点联想项触发，进入结果态。

- **内容（仅菜品）**：采用**单列横向行卡**（复用与联想态一致的「混合行卡」视觉，见子态 B）——左缩略图、右信息列，整行可点进菜品详情页。搜索是目标导向，单曲行卡一行一菜、字段完整（尤其距离/评分/食堂档口一眼可比），且**与联想态真正统一同一套行卡**。分页仍按瀑布流式分页（触底加载，见下）。
  - **行卡字段（左→右）**：
    1. 缩略图（左，`160rpx` 圆角，无图回退 `dish` 图标）；
    2. 菜名（加粗，单行截断，**命中搜索词主色高亮**）；
    3. 价格（主色加粗）；
    4. 评分（⭐ 图标 + 数字）；
    5. 一行「食堂 · 档口」属性（三级灰）；
    6. 距你距离（`distance` 缺省不渲染，见首页拍板——搜索场景核心决策信息）。
- **分页**：按相关度 / 热度综合排序，后端**分页返回**；首屏先取前 N 条，上滑触底自动加载下一页，末页显示「没有更多了」（瀑布流式分页，符合官方做法，避免一次性拉全量）。
- **空结果**：`EmptyState`「没有找到与"xxx"相关的菜品」+ 引导换词。
- 顶部返回箭头变为「退出筛选」，点之回**页面一 · 发现主页**。

## 交互路径

首页搜索框 → 页面一（发现主页 / 输入联想态）→ 提交搜索 → 页面二（菜品结果列表）→ 菜品详情页。

全流程只有「菜品」一种结果类型，联想与结果共用同一套行卡视觉，逻辑统一、无类型分支。


## 细节设计（尺寸与样式规范）

本节用设计 token（页面级 CSS 变量：`client/src/App.vue` 全局 `<style>`；图标色常量：`client/src/theme/tokens.ts`；`client/src/uni.scss` 不声明裸 CSS 变量）标注关键区块尺寸，确保设计与实现一致。

### 顶部固定区（与首页搜索胶囊同位置）
- 返回键：`IconSvg` `arrow-left` `40rpx` / `var(--color-on-primary-surface)`（朱砂红 header 上的白色箭头），命中区 `64rpx` 见方；位于首屏左上角，与首页头部头像同一屏幕位置（左缘统一 `var(--spacing-md)`）。
- 搜索框：高 `64rpx`，药丸 `border-radius: var(--radius-tag)`，背景 `var(--bg-card)` + 阴影 `var(--shadow-card)`，左右内边距 `var(--spacing-md)`；前置 `search` `30rpx` / `var(--color-primary)`；清空 `close` `28rpx` / 三级灰（有输入才显）；右侧 `margin-right = getCapsuleReservePx()` 避让微信胶囊。**尺寸 / 圆角 / 背景 / 左右位置与首页搜索胶囊完全一致**（见 `docs/pages/首页.md` §顶部操作栏）。

### 页面一 · 发现主页
- 容器：顶层 `padding-top = 固定区总高度 + var(--spacing-md)`（先避让 `fixed` 顶部固定区、再留与搜索栏的组件间隔），左右 `var(--spacing-md)`。
- 搜索记录：`CardSection` + `SectionTitle`（标题 + 右侧「清空」`font-aux`/三级灰）；chip 药丸 `border-radius: var(--radius-pill)`、背景 `var(--bg-soft)`、内边距 `sm/lg`、字号 `var(--font-body)`/二级灰；超 3 条折叠按钮「展开全部 N 条」。
- 热搜：火标 `ic-fire` + 排名序号（主色/加粗）+ 关键词 chip；点击直接搜索。

### 页面一 · 输入联想态
- 面板：`position: fixed`，左右 `var(--spacing-md)`，实底背景 `var(--bg-page)`（不透明，直接覆盖下方发现主页，**不启用毛玻璃 blur**），圆角 `var(--radius-card)`，阴影 `var(--shadow-modal)`；联想行卡白底 `var(--bg-card)` 浮于其上。
- 行项：`padding: var(--spacing-sm) var(--spacing-md)`，hairline 分隔；缩略图 `56rpx` 圆角 `16rpx`（图或 `dish` 图标）；菜名 `var(--font-body)` / 主色，命中词 `var(--color-primary)`；属性行 `var(--font-aux)` / 三级灰；价格 / 评分同行靠右。
- 按压态：`.pressed` 时 `transform: scale(var(--press-scale))` + 背景 `var(--bg-soft)`。

### 页面二 · 结果行卡（单列横向）
- 容器：列表左右 `var(--spacing-md)` 外边距，行间 `var(--spacing-sm)` 分隔；**非 `WaterfallList` 双列**，为单列纵向行卡流。
- 行卡：白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`；`display:flex; gap: var(--spacing-md)`（左缩略图 + 右信息列）。
  - 左缩略图：`160rpx` 见方圆角 `20rpx`（图或 `dish` 类型占位）；
  - 右信息列（`flex:1; min-width:0`，纵向）：
    - 菜名 `var(--font-card)` / `var(--weight-bold)` / 主色（单行截断），**命中搜索词 `var(--color-primary)` 高亮**；
    - 价格 `var(--font-card)` / `var(--weight-bold)` / `var(--color-primary)`；
    - 评分 `star` 图标 + 数字 `var(--color-star)` + 评价数（`font-aux` / 三级灰）；
    - 属性行 `var(--font-aux)` / 三级灰：「食堂 · 档口」+ 右侧「距你 Xm」（主色 / `var(--weight-medium)`，`distance` 缺省整段不渲染；距离格式同首页：`<1000m` 显"Xm"，`≥1000m` 显"X.Xkm"）。
- 按压态：`.pressed` 时背景转 `var(--bg-soft)`（Apple 偏好 highlight 而非 scale）。
- 触底加载：上滑到底自动拉下一页，末页显示「没有更多了」（非 `EmptyState` 报错态）。
