# 搜索页（find）

> 路径 `pages/find/index`，从首页搜索框点击进入的二级页。遵循 `docs/mini-app-ui/README.md` 模式库。

## 一、顶部固定区（P1 变体）
- 左上返回箭头（`backToHome` 回首页）；结果态下返回箭头变为「退出筛选」(退出结果态回发现主页)。
- 中部搜索框：图标 + 输入框（`placeholder="搜索菜品、档口或食堂"`）+ 清空按钮；`confirm-type="search"`，回车或确认触发搜索。
- 结果分类 Tab（仅结果态显示，固定于搜索框下，不随滚动）：`全部 / 菜品 / 档口 / 食堂`，每项带数量角标。

## 二、发现主页（未输入/未搜索时）
- **搜索记录**（首位）：`CardSection` 包裹，标题「搜索记录」，右侧「清空」；历史词以 chip 展示，超 3 条折叠为「展开全部 N 条」；单条 chip 可点（直接搜索）或点 × 删除（`.stop` 阻止触发搜索）。
- **热搜列表**：火标 `ic-fire` + 排名 + 关键词；点击直接搜索。加载中骨架、失败可重试（避免首屏空白）。
- 搜索联想下拉：输入时按「菜品/档口/食堂」分类型联想，每项带缩略图(或类型图标)+名称+类型标签；点击进入对应结果或详情。

## 三、搜索结果态
- 结果按 `resultTabs` 分桶：全部 / 菜品(`DishCard`) / 档口 / 食堂，分页加载（P5：上滑加载更多、到底「没有更多了」）。
- 菜品结果点击 → 菜品详情页（`/pages/pages-detail/dish`）；档口/食堂当前**不作为独立详情页**（2026-08-15 拍板，食堂/档口降级为菜品属性），故档口/食堂结果点击 → 菜品列表（按该档口/食堂筛选的菜品）。
- 空结果：`EmptyState`「没有找到相关结果」+ 引导换词。

## 四、交互路径
首页搜索框 → 搜索页 →（输入/联想/历史/热搜）→ 结果态（Tab 分桶）→ 菜品详情 / 档口菜品列表。
