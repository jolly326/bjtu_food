# 动态详情页（moment）

> 路径 `pages/pages-detail/moment`，从动态列表(`community`) / 我的动态点击动态卡片（头像或昵称区域）进入的二级页（菜品详情分包）。
> 设计基调：「评价即动态」单一内容模型（见 `project_spec.md` §2.1.4）；本页展示单条动态全文、评论与互动；档口 / 食堂已降级为菜品属性，动态仅关联菜品（见 spec §2.1.4）。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

动态详情页为纵向滚动页，自上而下：顶部 Header → 动态主卡（含关联菜品卡 + 互动栏）→ 评论区 → 固定底部评论输入栏；退回态在正文上方展示退回原因。

```
Header（返回 + 标题「动态详情」）
────────────────────────
动态主卡（头像/昵称/时间 + 正文 + 九宫格图 + 关联菜品卡 + InteractBar）
评论区（标题「评论 (N)」+ CommentItem 列表）
────────────────────────
底部评论输入栏
```

## 一、顶部 Header

- 左上返回箭头（`arrow-left`）：点之回上一页（`navigateBack`）。
- 居中标题「动态详情」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 二、动态主卡

- **头部**：圆形头像（`ImageFallback` 中性 `empty` 占位）+ 昵称（`var(--text-primary)` 加粗）+ 相对时间（`var(--text-tertiary)`）；作者本人可见审核态徽标（`StatusBadge`：待审 / 退回）。
- **正文**：评价即动态，全文展示，不截断（`var(--font-body)` / `var(--text-primary)`）。
- **九宫格大图**：`MomentImageGrid`，点击放大查看。
- **关联对象卡**（关联菜品时显示）：菜品缩略图 + 菜名 + `arrow-right`，点击 → 菜品详情页（`pages/pages-detail/dish`，见 `菜品详情.md`）；档口 / 食堂已降级为菜品属性，动态不单独关联档口实体（见 spec §2.1.4）。
- **互动栏 `InteractBar`**：点赞（`ic-thumb`，有用 / 点赞语义，见 spec §4.2）+ 评论 + 举报；点赞态暖色高亮（`var(--color-like)`）。

## 三、用户评价（关联菜品时）

- 展示该菜品前 2 条 `ReviewItem`；「查看全部」→ 全部评价页（`pages/pages-detail/review-list`，见 `全部评价页.md`）。

## 四、评论区

- 标题「评论 (N)」（`SectionTitle` + 数量）。
- 列表 `CommentItem`：支持回复、删除本人评论。
- 超 `collapseThreshold` 条折叠为「共 N 条，点击展开」。
- 空状态：`IconSvg name="empty"` +「还没有评论，来说两句」。
- 底部固定评论输入栏：聚焦弹出键盘 + 发送。遵循固定底栏避让红线：`.scroll-wrap` 加 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`。

## 五、审核 / 编辑 / 边界

- 退回态：正文上方展示退回原因 +「编辑重提」入口（复用统一 `PublishReview` 组件，见 `发布动态.md`），编辑后 `audit_status` 回 `pending`、`reject_reason` 清空（见 spec §5）。
- 加载失败 / 动态不存在：`EmptyState` 带重试。

## 状态与交互细节

- 骨架屏：首屏加载时主卡 + 评论区以占位块呈现（灰块 + 圆角）。
- 空状态：无评论 → 评论区「还没有评论，来说两句」；动态不存在 → `EmptyState` + 重试。
- 失败状态：请求异常 → 提示「加载失败，下拉刷新后重试」+ 重试按钮。
- 认证弹层：未登录触发点赞 / 评论 / 举报 → `AuthSheet` 弹出登录引导，不静默失败。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 动态主卡
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`。
- 头部：头像 `64rpx` 圆形（`ImageFallback` 中性 `empty`）；昵称 `30rpx` / `var(--weight-semibold)` / `var(--text-primary)`；相对时间 `var(--font-aux)` / 三级灰；审核徽标 `StatusBadge`（待审 `var(--color-warning)`，退回 `var(--color-error)`）。
- 正文：`var(--font-body)` / `var(--text-primary)`，完整展示不截断。
- 九宫格：`MomentImageGrid`，间距 `var(--spacing-sm)`，圆角 `var(--radius-card)`。
- 关联菜品卡：缩略图 `80rpx` 圆角 `var(--radius-card)` + 菜名 `var(--font-card)` / `var(--weight-bold)` / 主色 + `arrow-right` `var(--text-tertiary)`；整卡可点进菜品详情。
- 互动栏 `InteractBar`：点赞 `ic-thumb` `36rpx` / 三级灰，点赞态 `var(--color-like)`；评论 `ic-comment`、举报 `ic-report` 同尺寸；按压态 `.pressed` 背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

### 评论区
- 标题 `SectionTitle`「评论 (N)」；`CommentItem` 头像 `56rpx` 圆形（`ImageFallback` 中性 `empty`），昵称 `var(--font-body)` / 主色，内容 `var(--font-body)` / `var(--text-primary)`；本人评论显示删除入口。
- 折叠按钮 `var(--text-tertiary)`；空状态 `IconSvg name="empty"` + 三级灰文案。

### 底部评论输入栏
- 固定底栏，`height: var(--action-bar-height)`，半透材质（见 spec §4.5），含 `env(safe-area-inset-bottom)` 安全区避让；圆角顶边 `var(--radius-sheet)`；输入框 `var(--bg-soft)` 圆角 `var(--radius-pill)`，发送 `AppButton`（primary / text）。

## 交互路径

动态列表 / 我的动态 → 动态详情 →（点赞 / 评论 / 看关联菜品 / 编辑重提）；关联菜品卡 → 菜品详情页；评论区回上一页原位。
