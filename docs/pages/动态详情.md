# 动态详情（moment）

> 路径 `pages/pages-detail/moment`，从动态列表(`community`)/我的动态/消息等点击动态卡片进入的二级页。遵循 `docs/mini-app-ui/README.md` 模式库（P1/P2/P6/P7）。

## 一、顶部 Header（P1）
左上返回箭头 + 居中标题「动态详情」。

## 二、动态主卡（合并卡）
- **头部**：圆形头像（缺省用 `ic-user` 占位）+ 昵称 + 相对时间（P6）；作者本人可见审核态徽标（待审/退回）。
- **正文**：全文展示（评价即动态，不截断）。
- **九宫格大图**：`MomentImageGrid`，点击放大。
- **关联对象卡**（关联菜品/档口时）：类型图标 + 类型标签 + 名称 + 右箭头，点击跳对应页（菜品详情 `dish`；档口/食堂当前不独立成页，降级为菜品属性，故关联档口时跳该档口菜品列表）。
- **互动栏 `InteractBar`**：点赞(`ic-thumb`)+评论+举报；点赞态暖色高亮。
- **用户评价**（关联菜品时）：展示前 2 条 `ReviewItem`，「查看全部」跳全部评价页 `review-list`。

## 三、评论区
- 标题「评论 (N)」；列表 `CommentItem`（支持回复/删除本人评论）。
- 超 `collapseThreshold` 条折叠为「共 N 条，点击展开」。
- 空状态（P4）：「还没有评论，来说两句」。
- 底部固定评论输入栏（聚焦弹出键盘+发送）。

## 四、审核/编辑
- 退回态展示退回原因 + 「编辑重提」入口（复用统一 `PublishReview` 组件）。
- 加载失败/不存在：`EmptyState` 带重试（P4）。

## 五、交互路径
动态列表/我的动态/消息 → 动态详情 →（点赞/评论/看关联菜品/编辑重提）；关联菜品 → 菜品详情。
