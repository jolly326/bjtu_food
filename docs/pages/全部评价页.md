## 页面定位

全部评价列表页是一个二级页面，从菜品详情页的“查看全部评价”按钮进入，用于展示该菜品下的所有评价。

## 各部分详细设计

### 一、顶部 Header

左上角是返回按钮，点击后回到菜品详情页。中间显示页面标题“全部评价”。右上角留空，避开微信胶囊按钮。


### 二、评价总数（可选）

Header 下方显示该菜品的评价总数，如“共 234 条评价”。字号小，颜色灰色，用于提示用户当前列表的规模。如果不做这个模块，直接显示评价列表也可以。

### 三、评价列表

评价卡片纵向排列，卡片之间用间距自然分割。每条评价卡片包含：

- **评价人头像**：圆形头像
- **评价人昵称**
- **评价时间**：相对时间（如“2小时前”）
- **评分星级**：星星展示
- **评价文字**：完整展示
- **评价图片**：如果有图片，在文字下方以缩略图横向排列，点击可放大查看

### 四、分页加载

列表支持上滑加载更多。每次加载 20 条，到达底部时自动加载下一页内容。加载过程中底部显示“加载中...”，全部加载完成后显示“没有更多了”。

### 五、空状态

如果菜品没有任何评价，显示空状态：居中展示“还没有评价，来做第一个评价的人吧”，下方提供“去评价”按钮，点击后返回菜品详情页并触发发布流程。


## 跳转路径

菜品详情页 → 点击“查看全部评价” → 全部评价列表页 → 上滑加载更多


## 与菜品详情页评价列表的区别

| | 菜品详情页评价列表 | 全部评价列表页 |
|---|---|---|
| 展示数量 | 最近 3 条 | 全部 |
| 分页 | 无 | 支持上滑加载更多，每次 20 条 |
| 入口 | 默认展示 | 点击“查看全部评价”进入 |
| 定位 | 预览 | 完整列表 |

---

这个页面设计保持与整体风格一致：简洁、干净、专注。不添加任何多余元素，只做一件事——展示所有评价。
