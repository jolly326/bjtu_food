# 全部评价页（review-list）

> 路径 `pages/pages-detail/review-list`，从菜品详情页「查看全部评价」进入的二级页（菜品详情分包）；展示某菜品的全部评价。
> 设计基调：与菜品详情页评价列表同源（同一份评价数据，见 `project_spec.md` §2.1.4），本页为「完整列表」定位，支持分页；不承载发布，发布统一走 `PublishReview`（见 `发布动态.md`）。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

全部评价页为纵向滚动列表页，自上而下：顶部 Header → 评价总数（可选）→ 评价列表（`ReviewItem`，分页）→ 触底加载 / 空状态。

```
Header（返回 + 标题「全部评价」）
────────────────────────
评价总数（可选：「共 N 条评价」）
ReviewItem（头像/昵称/时间/评分/文字/图）
ReviewItem
...
触底：加载中… / 没有更多了
```

## 一、顶部 Header

- 左上返回箭头（`arrow-left`）：点之回菜品详情页（`navigateBack`）。
- 居中标题「全部评价」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 二、评价总数（可选）

- Header 下方显示该菜品评价总数，如「共 234 条评价」，`var(--font-aux)` / `var(--text-tertiary)`；不做也可直接显示列表。

## 三、评价列表

- 评价卡片纵向排列，卡片间间距自然分隔；每条渲染 `ReviewItem`：
  - 评价人头像（`ImageFallback` 中性 `empty` 占位）+ 昵称（`var(--text-primary)` 加粗）。
  - 相对时间（`var(--text-tertiary)`）。
  - 评分 `Rating`（1–5 星，`var(--color-star)` / `var(--color-star-empty)`）。
  - 评价文字完整展示（`var(--font-body)` / `var(--text-primary)`）。
  - 评价图片（缩略图横排，点之放大）。

## 四、分页加载

- 列表支持上滑触底加载更多，每次加载 20 条；底部「加载中…」→ 全部加载完「— 没有更多了 —」。

## 五、空状态

- 菜品无任何评价 → 居中 `IconSvg name="empty"` +「还没有评价，来做第一个评价的人吧」+「去评价」按钮（点之回菜品详情页并触发写评价，见 `发布动态.md`）。

## 状态与交互细节

- 骨架屏：首屏加载时列表以占位块呈现（灰块 + 圆角）。
- 空状态：见 §五。
- 失败状态：请求异常 → 提示「加载失败，下拉刷新后重试」+ 重试按钮。
- 触底加载：滚动到底 `loadMore`，底部「加载中…」/「— 没有更多了 —」。
- 认证弹层：本页仅浏览，无登录触发点；点赞等互动若引入须 `AuthSheet`（当前列表只读，不展开）。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 评价总数
- 左右 `var(--spacing-md)` 内边距；`var(--font-aux)` / `var(--text-tertiary)`。

### 评价列表（ReviewItem）
- 左右 `var(--spacing-md)` 外边距；每条白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`，条间 `var(--spacing-sm)` 间距。
- 头像 `64rpx` 圆形（`ImageFallback` 中性 `empty`）；昵称 `30rpx` / `var(--weight-semibold)` / `var(--text-primary)`；相对时间 `var(--font-aux)` / 三级灰。
- 评分 `Rating`（`var(--color-star)` / `var(--color-star-empty)`）；评价文字 `var(--font-body)` / `var(--text-primary)`，完整展示；评价图缩略图 `160rpx` 圆角 `var(--radius-card)`，横排 `gap`，点之放大。
- 按压态：`.pressed` 时背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

## 交互路径

菜品详情页「查看全部评价」→ 全部评价页（完整列表，分页加载）；空态「去评价」→ 回详情页触发写评价（见 `发布动态.md`）；返回 → 菜品详情页。

## 与菜品详情页评价列表的区别

| | 菜品详情页评价列表 | 全部评价页 |
|---|---|---|
| 展示数量 | 最近 3 条 | 全部 |
| 分页 | 无 | 触底加载，每次 20 条 |
| 入口 | 详情页默认展示 | 「查看全部评价」进入 |
| 定位 | 预览 | 完整列表 |
