# 最新活动（activity）

> 路径 `pages/activity/index`，从首页「万能区域 → 最新活动」查看全部进入的二级页。遵循 `docs/mini-app-ui/README.md` 模式库（P1/P2/P5）。

## 一、顶部 Header（P1）
左上返回箭头 + 居中标题「最新活动」。

## 二、活动列表（卡片列表 P2）
- 白底圆角 16px 卡片，纵向排列，间距分割。
- 卡片项（与首页 `ActivityPreview` 同款）：活动标题 + 发布时间（`relativeTime` P6）+ 封面图（若有）。
- 分页加载（P5）：上滑加载更多，到底「没有更多了」。
- 空状态（P4）：「还没有活动，敬请期待」。

## 三、交互路径
- 列表项点击 → 活动详情（当前实现为 `web-view` 打开公众号文章，`/pages/webview/index?url=...`）。
- 数据：`GET /activities?page=&size=`（遵循 spec §3.4 接口契约）。

## 四、备注
活动与「广播栏」分工：广播栏=逐条短播+点击跳动态列表；活动页=完整活动聚合列表。两者均为校园运营内容入口。
