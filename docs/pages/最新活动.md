# 最新活动页（activity）

> 路径 `pages/activity/index`，从首页「万能区域 → 最新活动」整列点击进入的二级页；亦从「我的」菜单进入（见 `project_spec.md` §2.1.1）。
> 设计基调：活动为独立功能模块（见 spec §0.3 / §2.1.4），数据由后台运营录入；本页为完整活动聚合列表，点击经微信 `web-view` 跳转对应公众号文章（全站唯一 `web-view` 场景）。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

最新活动页为纵向滚动列表页，自上而下：顶部 Header → 活动卡片列表（按发布时间倒序）→ 触底加载 / 空状态。

```
Header（返回 + 标题「最新活动」）
────────────────────────
活动卡片（封面图 / 标题 / 相对时间 / 简要描述）
活动卡片
...
触底：加载中… / 没有更多了
```

## 一、顶部 Header

- 左上返回箭头（`arrow-left`）：点之 `backToHome` 回首页（reLaunch，与 spec §4.8 对齐）。
- 居中标题「最新活动」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 二、活动列表

- 纵向列表，按发布时间倒序；每条为活动卡片（`ActivityPreview` 同款视觉）。
- 卡片内容：封面图（若有，`ImageFallback` 中性 `empty` 占位）+ 活动标题（`var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`，稍大字号）+ 发布时间（相对时间 `var(--font-aux)` / 三级灰，标题下方）+ 简要描述（更小字号 `var(--text-secondary)`，置底）。
- 整卡 `@tap` → 经微信 `web-view` 跳转对应公众号文章链接（`/pages/webview/index?url=...`，活动唯一 `web-view` 场景，见 spec §2.1.4）。
- 卡片白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`，卡片间间距自然分割。
- 分页加载：上滑触底加载更多，底部「加载中…」→ 全部加载完「— 没有更多了 —」。

## 状态与交互细节

- 骨架屏：首屏加载时列表以占位块呈现（灰块 + 圆角）。
- 空状态：无任何活动 → 居中 `IconSvg name="empty"` +「还没有活动，敬请期待」。
- 失败状态：请求异常 → 提示「加载失败，下拉刷新后重试」+ 重试按钮。
- 触底加载：滚动到底 `loadMore`，底部「加载中…」/「— 没有更多了 —」。
- 动效：卡片 `tap` 反馈 `scale(var(--press-scale))`、入场 spring `1.0/0.3`（与全局卡片一致，见 spec §4.8）。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 活动卡片（ActivityPreview）
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`，卡片间 `var(--spacing-md)` 间距。
- 封面图：宽度撑满、高度等比（如 `320rpx`），圆角 `var(--radius-card)`；无图 `ImageFallback` 中性 `empty`。
- 标题 `var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`，单行或两行截断。
- 发布时间 `var(--font-aux)` / `var(--text-tertiary)`，标题下方。
- 简要描述 `var(--font-body)` / `var(--text-secondary)`，置底，多行截断。
- 按压态：`.pressed` 时背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

## 交互路径

首页万能区域「最新活动」/ 「我的」菜单 → 最新活动页（活动聚合列表）→ 点卡片 → `web-view` 跳转公众号文章。

> 备注：广播栏（首页动态信息流）与活动页分工——广播栏逐条短播动态、点击路由到动态/菜品/外链；活动页为完整活动聚合列表，二者均为校园运营内容入口，互不重叠（见 `首页.md` §二 / §三）。
