# 菜品详情页（dish）

> 路径 `pages/pages-detail/dish`，从首页瀑布流 / 搜索结果 / 动态卡片主体点击进入的二级页（菜品详情分包）。
> 设计基调：食堂 / 档口仅作菜品属性（见 `project_spec.md` §2.1.4），本页专注「这道菜长什么样、好不好吃、去哪吃、大家怎么说」；收藏功能已移除，无收藏入口。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（页面级 CSS 变量声明于 `client/src/App.vue` 全局 `<style>`；图标色常量见 `client/src/theme/tokens.ts`；`client/src/uni.scss` 仅保留 uni 默认 scss 兼容变量、不声明裸 CSS 变量）。

## 页面结构总览

菜品详情页为「顶部固定视觉区 + 下方滚动信息区」：顶部固定区（朱砂红 Header + 菜品大图，**钉在页面顶端、上滑不滚走**）→ 下方独立滚动区（头部信息卡〔含位置〕 → 评价区〔摘要卡 + 前 3 条列表〕）→ 固定底部操作栏（分享给同学 / 写评价）。

```
┌─ 顶部固定区（fixed / sticky，上滑不滚走）──────────┐
│ Header（返回 + 标题「菜品详情」）                  │
│ ImageSwiper（菜品大图，高约 56vw）                │
└──────────────────────────────────────────────────┘
下方滚动区（各区块均为白底圆角卡）：
头部信息卡（名称+徽标 / 价格 | 位置 | 四列指标：评分｜评价｜口味｜地域）
评价区：「大家说」标题 → 评价摘要卡（左大评分 / 右星分布）→ 前 3 条 ReviewItem
────────────────────────
底部操作栏（分享给同学 / 写评价）
```

## 一、顶部 Header

> 顶部 Header 为**朱砂红大面积品牌色块**（`--color-primary` 背景，与首页 / 搜索页 header 同款），标题与返回箭头用 `--color-on-primary-surface`（白 / 暖白），与全站 header 视觉统一。

- 左上角返回箭头（`arrow-left`）：点之回上一页（`navigateBack`），来源页可能是首页 / 搜索 / 动态列表，不强制回首页；返回键 `40rpx` / `--color-on-primary-surface`（白），命中区 `72rpx` 见方。
- 居中标题「菜品详情」，`var(--weight-bold)` / `var(--color-on-primary-surface)`（朱砂红 header 白字）；右上角留空，避让微信胶囊按钮。

## 二、菜品大图（顶部固定区，不随滚动上滑）

- **固定顶部，不参与上滑**：图片区域紧邻朱砂红 Header 正下方（顶部即页面内容区顶部，与 Header 共同构成「顶部固定视觉区」，`position: sticky / fixed` 钉在页面顶端），上滑时图片不滚走，仅下方基本信息 → 评价区在独立滚动容器内滚动；滚动区 `.scroll-wrap` 须 `padding-top = 顶部固定区总高`（Header 高 + 大图高 + statusBar）防止内容被遮挡。
- 横向撑满屏幕，**高度收敛为约 `56vw`**（原 `80vw` 在竖屏接近方形、固定后占屏过大，改为 16:9 横幅观感，聚焦菜品又不挤压下方信息）；`ImageSwiper` 多图横滑（左右滑切换，非上滑）+ 指示点（指示点色走 `client/src/App.vue` 登记的页面 token）；圆角 `var(--radius-card)`，与卡片风格一致。
- 无图：`ImageFallback` 中性 `empty` 占位（禁 `dish` 冒充，见 spec §4.9 图标红线）；无首字占位逻辑。

## 三、头部信息卡（紧贴大图下方，白底圆角卡）

紧接顶部固定大图下方，独立白底圆角卡（`var(--bg-card)` / `var(--radius-card)` / `var(--shadow-card)`），与全站白卡视觉统一；卡片内边距 `var(--spacing-md)`，与下方卡片间距 `var(--spacing-sm)`。卡内分四层：
- **名称与价格行**（卡内顶层，`display:flex; justify-content:space-between; align-items:flex-start; gap: var(--spacing-md)`）：
  - 左：`.name-badges { display:flex; align-items:center; gap: var(--spacing-2xs); flex:1; min-width:0; padding-right: var(--spacing-sm); }`，菜名 `var(--font-title)` / `var(--weight-heavy)` / `var(--text-primary)`，页面唯一视觉锚点，单行优先、超长 `text-overflow:ellipsis` 截断；名称右侧紧跟 1–2 个徽标（`TagLabel`），如「新品」「重辣」「招牌菜」。
  - 右：价格 `var(--font-h3)` / `var(--weight-bold)` / `var(--color-price)`，字号比菜名小一号，不再与名称抢戏；支持折扣价（促销价 + 删除线原价），无价隐藏，右对齐（`flex-shrink:0; max-width:40%; justify-content:flex-end`）。
- **描述（介绍）行**（卡内第二层，可选）：紧跟名称价格行下方，`margin-top: var(--spacing-xs)`，`var(--font-small)` / `var(--text-secondary)` / `line-height:1.5`，默认 `line-clamp:2` 截断，与菜名形成「主标题-副标题」层级。
- **位置行**（卡内第三层，由独立来源卡合并而来）：`display:flex; justify-content:space-between; align-items:center`，`margin-top: var(--spacing-md)`；左侧 `location` 图标（`24rpx`）+「食堂 › 楼层 › 档口 › 窗口」文案，右侧「距你距离」。本行底部加 `var(--border-color)` 细线，与下方指标条自然分隔。
- **关键指标条**（卡内第四层，仿应用商店详情页）：`display:flex; justify-content:space-between; align-items:center`，`padding-top: var(--spacing-md)`，四等分列，列间以 `2rpx` 竖线（`var(--border-color)`）分隔：
  - 评分：`dish.rating.toFixed(1)`（不带星标），`var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`；无评分显示「-」。
  - 评价：`formatCount(dish.ratingCount)`（如「2667」或「1.2万」），`var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`。
  - 口味：酸甜苦辣咸；当前数据无标准字段，实现上优先从 `tags` 匹配「酸/甜/苦/辣/咸」字样，未命中则按 `spice_level` 回退为「不辣/微辣/中辣/重辣」，仍无则显示「-」。
  - 地域：西北/广东/川湘等；优先从 `tags` 匹配地域关键词，未命中则取 `dish.canteen`（食堂名）作为地域近似，无数据显示「-」。
  - 列标题标签统一用 `var(--font-aux)` / `var(--text-tertiary)`（「评分 / 评价 / 口味 / 地域」）。

## 四、评价区（SectionTitle「大家说」统领）

区块标题 `SectionTitle`「大家说」+ 右侧「查看全部评价 →」（`var(--text-tertiary)` / `arrow-right`，点击 → 全部评价页 `pages/pages-detail/review-list`）；标题下含：

- **评价摘要卡**（白底圆角卡，仿应用商店「综合评分」）：水平双栏布局——
  - 左栏：**综合评分大数字**（`var(--font-headline)` / `var(--weight-heavy)` / `var(--color-star)`，如「4.8」）+ 实心星标 + 评价总条数（`var(--font-aux)` / `var(--text-tertiary)`，如「2669人评价」），数字左对齐、视觉锚点突出。
  - 右栏：5 星 → 1 星占比分布，每行「实心星标 + 星级数字 + 进度条 + 该星数量」（填充 `var(--color-star)`，底 `var(--bg-soft)`，`var(--radius-pill)` 圆角）。
  - 价值：总评分一眼可读（左大数字锚点），右栏辅助看口碑分布（5 星占绝大多数 = 口碑好；1–2 星占比高 = 谨慎）。
- 无评价数据 → 摘要卡显示「暂无评价，来做第一个评价的人吧」，底部「写评价」保持可用。

## 五、评价列表

- 默认展示最近 3 条评价（在「大家说」标题下方、摘要卡之后），按时间倒序；每条渲染 `ReviewItem`：评价人头像（`ImageFallback` 中性 `empty`）+ 昵称 + 相对时间 + `Rating` + 评价文字（完整）+ 评价图片（缩略图横排，点之放大）。
- 「查看全部评价 →」入口见 §四 区块标题右侧（→ 全部评价页 `pages/pages-detail/review-list`，见 `全部评价页.md`）。

## 六、底部操作栏

- 固定底栏（固定底栏语义），两个操作：
  - **分享给同学**（`AppButton` default / 描边次要按钮，文字「分享」或 `share` 图标 + 文字）：调用小程序 `onShareAppMessage` 转发菜品卡片给微信好友 / 群，不引入新数据实体；占底栏左侧约 2/3 宽。
  - **写评价**（`AppButton` primary，文字「写评价」）：占底栏右侧固定 1/3 宽（不占满整栏），点击 → 发表评价页（`pages/pages-detail/review`，统一 `PublishReview` 组件，自动带入当前 `dishId` / 菜品名；发布逻辑与字段校验见 `发布动态.md`）。
- 收藏功能已移除，无收藏入口（见 spec §5.x）。
- 固定顶栏 + 固定底栏双避让红线：页面 `.scroll-wrap` 须 `padding-top = 顶部固定区总高`（Header + 大图 + statusBar，防被固定大图遮挡）且 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`（防被底栏遮挡）。

## 状态与交互细节

- 骨架屏：首屏加载时大图 + 信息区 + 评价区以占位块呈现（灰块 + 圆角），不展示真实数据。
- 空状态（评价区）：菜品无评价 → 评价摘要 / 列表区显示「还没有人评价过这道菜，来做第一个吧」，底部「写评价」保持可用。
- 失败状态：请求异常 → 提示「加载失败，下拉刷新后重试」+ 重试按钮。
- 下拉刷新：下拉 `onRefresh` 重拉菜品信息 + 评价。
- 认证弹层：未登录触发写评价 → `AuthSheet` 弹出登录引导（不静默失败，不进发布页）。

## 细节设计（尺寸与样式规范）

本节用设计 token（页面级 CSS 变量：`client/src/App.vue` 全局 `<style>`；图标色常量：`client/src/theme/tokens.ts`；`client/src/uni.scss` 不声明裸 CSS 变量）标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 容器 `background: var(--color-primary)`（朱砂红 header，与首页 / 搜索页同款）；返回 `arrow-left` `40rpx` / `var(--color-on-primary-surface)`（白），命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--color-on-primary-surface)`，居中；右上留空避让胶囊。

### 菜品大图（ImageSwiper，顶部固定）
- 与 Header 共同构成 `position: sticky / fixed` 顶部固定区（`top: 0` 贴合页面顶，不随下方滚动上滑消失）；横向撑满，高度约 `56vw`（收敛自 `80vw`，避免固定后占屏过大）；圆角 `var(--radius-card)`；指示点色走 `client/src/App.vue` 登记 token；无图 `ImageFallback` 中性 `empty`。

### 头部信息卡
- 白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`，`padding: var(--spacing-md)`；紧贴固定大图下方，卡片间 `var(--spacing-sm)` 间距。
- **名称与价格行**（顶层）：`display:flex; justify-content:space-between; align-items:flex-start; gap: var(--spacing-md)`。
  - 左：`.name-badges { display:flex; align-items:center; gap: var(--spacing-2xs); flex:1; min-width:0; padding-right: var(--spacing-sm); }`，菜名 `var(--font-h1)`（48rpx，页面最大字号）/ `var(--weight-heavy)` / `var(--text-primary)`（最深，页面唯一视觉锚点，单行 `text-overflow:ellipsis` 截断）；名称右侧 1–2 个徽标（`TagLabel`，如「新品」「重辣」「招牌菜」）。
  - 右：`.price-col { display:flex; align-items:baseline; gap: var(--spacing-xs); flex-wrap:wrap; justify-content:flex-end; max-width:40%; }`，价格 `var(--font-h3)`（36rpx，次大）/ `var(--weight-bold)` / `var(--color-price)`（暖橙红，区别于正文灰），字号明显小于菜名，支持折扣价（促销价 + 删除线原价），无价隐藏。
- **字号/灰度层级**（信息卡自上而下）：菜名 48rpx 黑（最重最黑）→ 价格 36rpx 暖橙（次大彩色）→ 指标数值 32rpx 黑 → 介绍/位置 24rpx 灰（`--text-secondary`）→ 指标标签 22rpx 浅灰（`--text-tertiary`），形成「最大黑字锚点 → 彩色价格 → 中等黑字 → 灰副信息」四级层级，避免平铺。
- **描述（介绍）行**（第二层，可选）：紧跟名称价格行下方，`margin-top: var(--spacing-xs)`，`var(--font-small)` / `var(--text-secondary)` / `line-height:1.5`，默认 `line-clamp:2` 截断，与菜名形成「主标题-副标题」层级。
- **位置行**（第三层，原独立来源卡合并至此）：`display:flex; justify-content:space-between; align-items:center; gap: var(--spacing-sm)`；`margin-top: var(--spacing-md); padding: var(--spacing-sm) 0; border-bottom: 2rpx solid var(--border-color);`。
  - 左：`location` 图标（`var(--color-primary)`，`24rpx`）+「食堂 › 楼层 › 档口 › 窗口」`var(--font-small)` / `var(--text-secondary)` / `var(--weight-medium)`，单行截断。
  - 右：「距你距离」`var(--font-small)` / `var(--color-primary)` / `var(--weight-medium)`（格式同首页：`<1000m` 显「Xm」、`≥1000m` 显「X.Xkm」，`distance` 缺省整段不渲染）。
- **关键指标条**（第四层，仿应用商店）：`display:flex; justify-content:space-between; align-items:center`，`padding-top: var(--spacing-md)`，四等分列，列间以 `2rpx` 竖线（`var(--border-color)`）分隔。
  - 评分列：数值 `dish.rating.toFixed(1)`（不带星标），`var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`；无评分显「-」。
  - 评价列：`formatCount(dish.ratingCount)`（<1万显原数、≥1万显 x.x万），`var(--font-card)` / `var(--weight-bold)` / `var(--text-primary)`。
  - 口味列：酸甜苦辣咸；实现上优先从 `tags` 匹配「酸/甜/苦/辣/咸」，未命中按 `spice_level` 回退为「不辣/微辣/中辣/重辣」，仍无显「-」。
  - 地域列：西北/广东/川湘等；优先从 `tags` 匹配地域关键词，未命中取 `dish.canteen`，无显「-」。
  - 列标题统一 `var(--font-aux)` / `var(--text-tertiary)`（「评分 / 评价 / 口味 / 地域」）。

### 评价摘要卡
- 本卡位于「大家说」`SectionTitle`（含右侧「查看全部评价 →」入口，点击 → 全部评价页 `pages/pages-detail/review-list`）之下；白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`；`display:flex`（左综合分栏 + 右分布栏，`gap: var(--spacing-md)`），仿应用商店「综合评分」区块。
- 左栏：综合评分大数字 `var(--font-headline)` / `var(--weight-heavy)` / `var(--color-star)`（如「4.8」）+ 实心星标 + 评价总条数 `var(--font-aux)` / `var(--text-tertiary)`（如「2669人评价」），左对齐、数字为视觉锚点。
- 右栏：5→1 星每行：`star-filled` 星标 + 星级数字 `var(--font-aux)` / 三级灰 + 进度条（填充 `var(--color-star)`，底 `var(--bg-soft)`，`var(--radius-pill)` 圆角）+ 该星数量（右对齐，`var(--font-aux)` / 三级灰）。

### 评价列表（ReviewItem）
- 列表位于 `review-section` 容器内，与上方头部信息卡**等宽**：容器统一 `margin: var(--spacing-md) var(--spacing-md) 0` 内缩，内部各 `CardSection` 取消自带左右 margin（避免双重内缩导致卡片更窄）；每条白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`，条间 `var(--spacing-sm)` 间距。
- 「大家说」`SectionTitle` 左侧竖条在本页弱化为 `4rpx × 22rpx`、`opacity: 0.5` 的细短半透明朱砂条，降低视觉抢占（全局 SectionTitle 仍为 `8rpx × 32rpx` 实心品牌条，仅本页评价区收敛）。
- 头像 `64rpx` 圆形（`ImageFallback` 中性 `empty`）；昵称 `30rpx` / `var(--weight-semibold)` / `var(--text-primary)`；相对时间 `var(--font-aux)` / 三级灰。
- 评价文字 `var(--font-body)` / `var(--text-primary)`，完整展示；评价图缩略图 `160rpx` 圆角 `var(--radius-card)`，横排 `gap`，点之放大。
- 按压态：`.pressed` 时背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

### 底部操作栏
- 固定底栏，`height: var(--action-bar-height)`，半透材质（见 spec §4.5），含 `env(safe-area-inset-bottom)` 安全区避让；圆角顶边 `var(--radius-sheet)`；`display:grid; grid-template-columns: 2fr 1fr; gap: var(--spacing-sm)`（左侧「分享」占约 2/3，右侧「写评价」固定占 1/3，不占满整栏）。
- 「分享」`AppButton`（default / 描边，`var(--color-primary)` 文字 + `share` 图标，占左 2/3 宽区），调用 `onShareAppMessage` 转发；「写评价」`AppButton`（primary，占右 1/3 宽区），点之 → 发表评价页（统一 `PublishReview`，带入 `dishId`）。

## 交互路径

首页瀑布流 / 搜索结果 / 动态卡片主体 → 菜品详情页 → 看大图 / 评分 / 来源 / 评价摘要与列表 → 点「查看全部评价」进全部评价页；点底部「写评价」进发表评价页（自动带入菜品）→ 发布完成回详情页（新评价置顶、评分与摘要同步）。
