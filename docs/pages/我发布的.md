# 我发布的（my-published）

> 路径 `pages/pages-user/my-moments/index`（2026-08-15 合并 `my-moments`+`my-reviews` 后的唯一入口）。从「我的」菜单「我发布的」进入。遵循 `docs/mini-app-ui/README.md` 模式库（P1/P2/P4/P5/P6）。

## 一、背景（合并决策）
评价即动态、单一内容模型（spec §2.1），故「我的动态」与「我的评价」本质同一份数据，合并为单一「我发布的」列表，避免冗余（原 `my-reviews` 路由删除）。`profile` 菜单原「我发布的/我的评价」两项收敛为一项「我发布的」。

## 二、顶部 Header（P1）
左上返回箭头 + 居中标题「我发布的」。

## 三、列表（卡片列表 P2）
- 直接一列展示用户发布的全部内容（动态 + 评价），`MomentCard` 复用，作者本人带审核态徽标（`show-audit`）。
- 卡片点击 → 动态详情 `moment`；关联对象点击 → 对应菜品/档口。
- 分页加载（P5）+ 空状态（P4）：「你还没有发布动态」+ 引导去发布。
- 加载失败与空数据语义区分，提供重试。

## 四、管理操作
- 单条支持「编辑」（退回态或本人）重提（复用统一 `PublishReview`）、「删除」（确认弹层 + `DELETE`，成功局部移除 + Toast）。
- 评论/点赞等互动数据随内容同步。

## 五、交互路径
我的 → 我发布的 → 动态详情 / 编辑重提；空态 → 去发布（动态页底部入口）。
