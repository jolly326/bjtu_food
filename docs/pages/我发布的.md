# 我发布的页（my-published）

> 路径 `pages/pages-user/my-moments/index`（`my-moments` + `my-reviews` 合并后的唯一入口，见 `project_spec.md` §2.1.1），从「我的」菜单「我发布的」进入。
> 设计基调：「评价即动态」单一内容模型（见 spec §2.1.4）——「我的动态」与「我的评价」本质同一份数据，合并为单一「我发布的」列表，避免冗余；`profile` 菜单仅保留一项「我发布的」。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

我发布的页为纵向滚动列表页，自上而下：顶部 Header → 内容列表（`MomentCard`，本人带审核态徽标）→ 触底加载 / 空状态；每条支持编辑 / 删除管理操作。

```
Header（返回 + 标题「我发布的」）
────────────────────────
MomentCard（本人带审核态徽标 + 编辑 / 删除）
MomentCard
...
触底：加载中… / 没有更多了
```

## 一、合并背景（评价即动态）

评价即动态，用户对菜品的评价与动态同源（`dish_id` 关联，见 spec §2.1.4）。故「我的动态」与「我的评价」合并为单一「我发布的」列表，原 `my-reviews` 路由删除，不重复维护两份数据。

## 二、顶部 Header

- 左上返回箭头（`arrow-left`）：点之回「我的」页（`navigateBack`）。
- 居中标题「我发布的」，`var(--weight-bold)` / `var(--text-primary)`；右上角留空，避让微信胶囊按钮。

## 三、内容列表

- 直接一列展示用户发布的全部内容（动态 + 评价），复用 `MomentCard`；作者本人条目带审核态徽标（`StatusBadge`：待审 / 退回）。
- 卡片点击 → 动态详情页（`pages/pages-detail/moment`，见 `动态详情.md`）。
- 关联对象点击 → 仅关联菜品时跳菜品详情页（`pages/pages-detail/dish`）；档口 / 食堂已降级为菜品属性，不单独关联（见 spec §2.1.4）。

## 四、管理操作

- 单条支持「编辑」（退回态或本人）重提：复用统一 `PublishReview` 组件，编辑后 `audit_status` 回 `pending`、`reject_reason` 清空（见 `发布动态.md`）。
- 「删除」：`showModal` 二次确认 + `DELETE`，成功局部移除 + Toast「已删除」。
- 评论 / 点赞等互动数据随内容同步。

## 状态与交互细节

- 骨架屏：首屏加载时列表以占位块呈现（灰块 + 圆角）。
- 空状态：无任何发布 → 居中 `IconSvg name="empty"` +「你还没有发布动态」+ 引导去发布（跳动态页底部发布入口 → `发布动态.md`）。
- 失败状态：请求异常 → 提示「加载失败，下拉刷新后重试」+ 重试按钮（加载失败与空数据语义区分）。
- 触底加载：滚动到底 `loadMore`，底部「加载中…」/「— 没有更多了 —」。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；右上留空避让胶囊。

### 内容列表（MomentCard）
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`，卡片间 `var(--spacing-md)` 间距。
- 头部：头像 `64rpx` 圆形（`ImageFallback` 中性 `empty`）；昵称 `30rpx` / `var(--weight-semibold)` / `var(--text-primary)`；审核徽标 `StatusBadge`（待审 `var(--color-warning)`，退回 `var(--color-error)`）。
- 主体：菜品名 `var(--font-card)` / `var(--weight-bold)` / 主色 + 「食堂 · 档口」属性行 `var(--font-aux)` / 三级灰；评分 `Rating`（`var(--color-star)`）；评价文字完整展示 `var(--font-body)` / `var(--text-primary)`；评价图缩略图 `160rpx` 圆角 `var(--radius-card)`，横排 `gap`，点之放大。
- 管理操作：右下「编辑」（`var(--text-tertiary)`）/「删除」（`var(--color-error)`）文字按钮，点之触发编辑 / 删除确认。
- 按压态：`.pressed` 背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`。

## 交互路径

「我的」菜单「我发布的」→ 我发布的页（本人内容列表，带审核态）→ 点卡片进动态详情；点「编辑」复用 `PublishReview` 重提；点「删除」确认移除；空态「去发布」→ 动态页底部发布入口（见 `发布动态.md`）。
