# 动态页（community）

> 路径 `pages/community/index`，从小程序底部 TabBar「动态」进入的 TabBar 页；亦从首页广播栏点击 `community` 类条目经 `navigateTo` 进入（此时左上角显示返回箭头，点之回首页）。
> 设计基调：「评价即动态」——对菜品的评价自动同步为动态卡片，单一内容模型，无独立动态发布态之外的产物（见 `project_spec.md` §2.1.4）。
> 复用小程序自研组件（见 `docs/project_spec.md` §4.2 组件清单）与设计 token（见 `client/src/uni.scss` / `client/src/theme/tokens.ts`）。

## 页面结构总览

动态页为单一滚动列表页，自上而下：顶部 Header（标题 + 可选返回）→ 动态卡片列表（`MomentCard`）→ 固定底部发布入口。

```
Header（标题「最新动态」+ 可选返回）
────────────────────────
MomentCard（评价人 / 时间 / 菜品 / 评分 / 文字 / 图）
MomentCard
MomentCard
...
────────────────────────
底部发布入口（「说点什么...」+ 发布）
```

## 一、顶部 Header

- 居中标题「最新动态」，`var(--weight-bold)` / `var(--text-primary)`，与全局二级页规范一致；右上角留空，避让微信胶囊按钮。
- 左上角返回箭头（`arrow-left`）：仅从首页广播栏等二级入口 `navigateTo` 进入时渲染，点之回首页（`goBackHome`）；TabBar 直入时不显示返回键。

## 二、动态卡片列表

列表按时间倒序，最新动态置顶；每条渲染为 `MomentCard`。

单条 `MomentCard` 内容：
- 头部：评价人头像（`ImageFallback` 中性 `empty` 占位）+ 昵称（`var(--text-primary)` 加粗）；右侧相对时间（如「2小时前」「昨天」，`var(--text-tertiary)`）。
- 主体：被评价菜品名（含「食堂 · 档口」属性行，`var(--font-aux)` / 三级灰）+ 评分星级（`Rating`，1–5 星，`var(--color-star)`）+ 评价文字（完整展示，非截断）+ 评价图片（`ImageSwiper` / 横排缩略图，点之放大查看）。
- 卡片白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`，卡片间用间距自然分隔（与首页风格一致）。

跳转（两条分支，目标页见 `动态详情.md` / `菜品详情.md`）：
- 点击卡片**主体** → 菜品详情页（`pages/pages-detail/dish`），查看该菜品完整信息 / 全部评价。
- 点击**头像或昵称**区域 → 动态详情页（`pages/pages-detail/moment`），查看单条动态全文、评论与互动。

列表支持上滑触底加载更多（`loadMore`），底部文案「加载中…」→ 全部加载完「— 没有更多了 —」。

## 三、底部发布入口

列表底部固定一条轻量发布入口栏（固定底栏语义）：
- 左侧引导文案「说点什么...」（`var(--text-tertiary)`），右侧「发布」按钮（`AppButton` primary）。
- 点击 → 发布动态页（`pages/pages-user/publish-moment/index`，见 `发布动态.md`）。
- 样式：浅色圆角条，半透材质（见 `project_spec.md` §4.5），不遮挡列表；仅在动态页存在。
- 遵循固定底栏避让红线：页面 `.scroll-wrap` 须加 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`，禁止内容被底栏遮挡（见 spec §4.9）。

## 四、数据来源

动态列表展示所有用户对菜品的评价内容。**评价即动态**——用户在任意菜品详情页发布评价后，该内容自动同步到动态列表，无需额外操作。动态卡片与菜品详情页评价为同一份数据（`dish_id` 关联），不同展示形式。发布走统一 `PublishReview` 组件（见 `发布动态.md`）。

## 状态与交互细节

- 骨架屏：首屏加载时卡片列表以占位块呈现（灰块 + 圆角），不展示真实数据。
- 空状态：无任何动态 → 居中空图标（`IconSvg name="empty"`）+「还没有动态，去写第一条评价吧」。
- 失败状态：请求异常 → 提示「加载失败，下拉刷新后重试」+ 重试按钮。
- 下拉刷新：下拉 `onRefresh` 重拉最新动态。
- 触底加载：滚动到底 `loadMore`，底部「加载中…」/「— 没有更多了 —」。
- 认证弹层：未登录触发发布 / 点赞 → `AuthSheet` 弹出登录引导，不静默失败。

## 细节设计（尺寸与样式规范）

本节用设计 token 标注关键区块尺寸，确保设计与实现一致。

### 顶部 Header
- 容器：高度与全局二级页 Header 一致；标题 `var(--font-title)` / `var(--weight-bold)` / `var(--text-primary)`，居中；返回 `arrow-left` `40rpx` / 主色，命中区 72rpx 见方（仅二级入口进入时渲染）。

### 动态卡片（MomentCard）
- 容器：左右 `var(--spacing-md)` 外边距，白底 `var(--bg-card)`、圆角 `var(--radius-card)`、阴影 `var(--shadow-card)`、`padding: var(--spacing-md)`，卡片间 `var(--spacing-md)` 间距。
- 头部：头像 `64rpx` 圆形（`ImageFallback` 中性 `empty`）；昵称 `30rpx` / `var(--weight-semibold)` / `var(--text-primary)`；相对时间 `var(--font-aux)` / 三级灰，右对齐。
- 主体：菜品名 `var(--font-card)` / `var(--weight-bold)` / 主色，单行截断；属性行「食堂 · 档口」`var(--font-aux)` / 三级灰；评分 `Rating`（`var(--color-star)`）；评价文字 `var(--font-body)` / `var(--text-primary)`，完整展示，长文可滚读不截断；评价图缩略图 `160rpx` 圆角 `var(--radius-card)`，横排 `gap` 间距，点之放大。
- 按压态：`.pressed` 时背景转 `var(--bg-soft)`、`transform: scale(var(--press-scale))`（统一按压 token，禁裸 scale）。

### 底部发布入口
- 容器：固定底栏，`height: var(--action-bar-height)`，半透材质（见 spec §4.5），左右 `var(--spacing-md)` 内边距，含 `env(safe-area-inset-bottom)` 安全区避让；圆角顶边 `var(--radius-sheet)`。
- 引导文案 `var(--font-body)` / 三级灰；「发布」`AppButton`（primary）。

## 交互路径

TabBar「动态」/ 首页广播栏(`community`) → 动态列表 → 点卡片主体进菜品详情；点头像/昵称进动态详情；点底部发布进发布动态页 → 发布完成回列表（新动态置顶）。

整个流程从「看到动态」到「进菜品详情」仅一次点击；从「想发表」到「发布完成」两步，路径短、反馈清晰。
