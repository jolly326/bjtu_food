## 二、设计原则

### 2.1 色彩情感
- **砖红色**代表：沉稳、温暖、食欲（呼应食堂场景）
- 避免大面积使用高饱和度红色，以砖红色作为点缀和品牌标识

### 2.2 可用性原则
- **触控区域不小于 88rpx**：确保手指点击舒适
- **信息层级清晰**：每屏突出1-2个核心操作
- **加载状态反馈**：所有异步操作必须有loading提示
- **空状态设计**：无数据时展示友好插画+引导文案

### 2.3 品牌一致性
- 所有页面的导航栏背景色统一为砖红色 `#8B3A2B`
- 导航栏标题文字白色，返回箭头白色
- Tab栏选中态图标和文字使用砖红色
