## 2. 后端分层架构

```
┌──────────────────────────────────────────────────────────┐
│                    前端（uni-app → 微信小程序）            │
│                          ↓ HTTP                           │

│                    Spring Boot                            │
│                                                          │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│  │   auth   │  │  dish    │  │  review  │  │ favorite │ │
│  │ 认证模块  │  │ 菜品模块  │  │ 评价模块  │  │ 收藏模块  │ │
│  └────┬─────┘  └────┬─────┘  └────┬─────┘  └────┬─────┘ │

│  │  canteen │  │      common         │  │    list      │ │
│  │ 食堂档口  │  │  (公共: 结果、异常、   │  │   清单模块    │ │

│  └──────────┘  └─────────────────────┘  └──────────────┘ │
│                                                          │
│  ┌──────────┐                                            │
│  │  upload  │                                            │
│  │ 文件上传  │                                            │
│  └──────────┘                                            │
├──────────────────────────────────────────────────────────┤
│                         MySQL                             │
└──────────────────────────────────────────────────────────┘
```

### 模块依赖原则

- **所有模块仅依赖 `common`**，互不直接依赖
- `review`、`favorite` 通过 **Spring 事件** 通知 `dish` 模块更新评分/收藏数
- `list` 模块通过 **Service 接口注入** 调用 `favorite` 的批量收藏方法
- 新增功能只需新建模块，已有模块不受影响

## 3. 数据库设计

### 3.1 E-R 关系

```
user 1 ──── N review N ──── 1 dish N ──── 1 stall N ──── 1 canteen
  │                           │
  │                           │
  1                           1
  │                           │
  N                           N
favorite N ──── 1 dish    list_item N ──── 1 dish
  │
  │
  1
  │
  N
item_list N ──── 1 user
```

### 3.3 建表 SQL 示例

```sql
CREATE TABLE `user` (
  `id`         BIGINT       NOT NULL AUTO_INCREMENT,
  `username`   VARCHAR(50)  NOT NULL,
  `password`   VARCHAR(255) NOT NULL,
  `nickname`   VARCHAR(50)  NOT NULL DEFAULT '',
  `avatar`     VARCHAR(255) DEFAULT NULL,
  `role`       VARCHAR(20)  NOT NULL DEFAULT 'student',
  `stall_id`   BIGINT       DEFAULT NULL,
  `status`     VARCHAR(10)  NOT NULL DEFAULT 'active',
  `created_at` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` DATETIME     NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

  KEY `idx_user_stall` (`stall_id`)
```

## 4. API 接口定义

### 4.1 通用规范

- 基础路径：`/api`
- 统一响应格式：
  ```json
  { "code": 200, "message": "success", "data": { ... } }
  ```
- 分页响应：
  ```json
  { "code": 200, "message": "success", "data": { "list": [...], "total": 100 } }
  ```
- 认证方式：`Authorization: Bearer <token>`
- HTTP 状态码：200=成功, 400=参数错误, 401=未登录, 403=无权限, 500=服务端错误

### 4.2 auth — 认证模块

#### 公开接口

##### POST /api/auth/login

登录。

```json
// Request
{ "username": "stu001", "password": "123456" }

// Response 200
{ "token": "eyJ...", "userId": 3, "nickname": "张三", "avatar": null, "role": "student", "stallId": null }
```

##### POST /api/auth/register

注册。

```json
// Request
{ "username": "stu003", "password": "123456", "nickname": "王五" }

// Response 200 — 同登录响应
```

#### 需登录接口

##### GET /api/auth/profile

获取当前用户信息。

```json
// Response 200
{ "id": 3, "username": "stu001", "nickname": "张三", "avatar": null, "role": "student" }
```

##### PUT /api/auth/profile

修改个人信息。

```json
// Request
{ "nickname": "张三三", "avatar": "/uploads/xxx.jpg" }

// Response 200
```

#### 管理端接口（sys_admin）

##### GET /api/admin/users

用户列表。

参数：`?page=1&pageSize=10&role=student&status=active`

```json
// Response
{ "list": [{ "id": 1, "username": "stu001", "nickname": "张三", "role": "student", "status": "active", "createdAt": "2024-01-01" }], "total": 10 }
```

##### PUT /api/admin/users/{id}/status

启用/禁用用户。

```json
// Request
{ "status": "disabled" }
```

##### PUT /api/admin/users/{id}/role

修改用户角色。需同时传入 `stallId`（当角色为 canteen_admin 时必填）。

```json
// Request
{ "role": "canteen_admin", "stallId": 1 }
```

##### DELETE /api/admin/stalls/{id}

### 4.4 dish — 菜品模块

#### 公开接口

##### GET /api/dishes

菜品列表（分页 + 筛选 + 排序）。

参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | Integer | 否 | 默认 1 |
| pageSize | Integer | 否 | 默认 10 |
| keyword | String | 否 | 菜品名模糊搜索 |
| canteenId | Integer | 否 | 按食堂筛选 |
| stallId | Integer | 否 | 按档口筛选 |
| tag | String | 否 | `recommended` / `signature` |
| minPrice | Integer | 否 | 最低价（分） |
| maxPrice | Integer | 否 | 最高价（分） |
| sortBy | String | 否 | `rating` / `collects` / `price` / `created_at` |
| sortOrder | String | 否 | `asc` / `desc`，默认 `desc` |
| status | String | 否 | `on` / `off`（公开接口默认只查 `on`） |

默认排序：`(collect_count * 3 + view_count + rating_count * 5)` 综合降序。

```json
// Response
{
  "list": [{ "id": 1, "name": "牛肉拉面", "price": 1200, "image": null, "tags": "recommended", "stallName": "面食窗口", "canteenName": "第一食堂", "avgRating": 4.5, "ratingCount": 20, "collectCount": 15 }],
  "total": 8
}
```

##### GET /api/dishes/hot

热门菜品 TOP10（按收藏量降序）。

```json
// Response — 同上列表项
[{ "id": 4, "name": "宫保鸡丁盖饭", ... }]
```

##### GET /api/dishes/{id}

菜品详情。

```json
// Response
{
  "id": 1,
  "name": "牛肉拉面",
  "price": 1200,
  "description": "手工拉面配卤牛肉片",
  "image": null,
  "tags": "recommended",
  "stallId": 1,
  "stallName": "面食窗口",
  "canteenId": 1,
  "canteenName": "第一食堂",
  "avgRating": 4.5,
  "ratingCount": 20,
  "collectCount": 15,
  "viewCount": 200,
  "status": "on",
  "isFavorited": true,     // 已登录时返回当前用户是否收藏
  "hasReviewed": false,    // 已登录时返回当前用户是否评价过
  "createdAt": "2024-01-01"
}
```

##### POST /api/dishes/{id}/view

增加浏览量（防刷：同用户同一菜品 5 分钟内只计 1 次）。不需要请求体。

#### 管理端接口（canteen_admin）

##### GET /api/admin/dishes

当前管理员绑定的档口的菜品列表（含已下架）。

##### POST /api/admin/dishes

新增菜品。

```json
// Request
{ "name": "红烧牛肉面", "price": 1500, "description": "...", "image": "/uploads/xxx.jpg", "tags": "recommended", "status": "on" }
```

##### PUT /api/admin/dishes/{id}

编辑菜品。

##### DELETE /api/admin/dishes/{id}

软删除（置 `is_deleted = 1`）。

#### 统计接口（canteen_admin）

##### GET /api/admin/stats/overview

数据总览。

```json
// Response
{ "totalViews": 1500, "totalCollects": 200, "avgRating": 4.3, "totalDishes": 8 }
```

##### GET /api/admin/stats/trend?days=7

趋势数据。

```json
// Response
{ "dates": ["01-01", "01-02", ...], "views": [100, 120, ...], "ratings": [4.2, 4.3, ...] }
```

##### GET /api/admin/stats/rank

热门菜品排行。

```json
// Response
[{ "dishId": 4, "name": "宫保鸡丁盖饭", "collectCount": 25, "ratingCount": 25, "avgRating": 4.7 }]
```

### 4.5 review — 评价模块

#### 公开接口

##### GET /api/dishes/{dishId}/reviews

评价列表（仅查 `is_hidden=0 AND is_deleted=0`）。参数：`?page=1&pageSize=10`，默认按时间倒序。

```json
// Response
{
  "list": [{
    "id": 1, "userId": 3, "userNickname": "张三", "userAvatar": null,
    "rating": 4, "content": "好吃！", "images": ["/uploads/xxx.jpg"],
    "createdAt": "2024-01-01"
  }],
  "total": 20
}
```

#### 需登录接口（student）

##### POST /api/reviews

提交评价。

```json
// Request
{ "dishId": 1, "rating": 4, "content": "味道不错", "images": ["url1"] }
```

提交后触发事件 → dish 模块重算评分。

##### PUT /api/reviews/{id}

修改自己的评价（仅本人，只允许修改评分和内容）。

```json
// Request
{ "rating": 5, "content": "非常好吃！" }
```

##### DELETE /api/reviews/{id}

删除自己的评价（软删除，置 `is_deleted = 1`）。仅本人可操作。

#### 管理端接口（sys_admin）

##### GET /api/admin/reviews

所有评价列表（含已隐藏/已删除，敏感词高亮标记）。

参数：`?page=1&pageSize=10&isHidden=&isDeleted=`

##### PUT /api/admin/reviews/{id}/hide

切换隐藏/显示（`is_hidden` 取反）。

##### DELETE /api/admin/reviews/{id}

软删除（`is_deleted = 1`）。

### 4.6 favorite — 收藏模块

#### 需登录接口（student）

##### POST /api/favorites/toggle

切换收藏状态。

```json
// Request
{ "dishId": 1 }

// Response
{ "favorited": true }
// favorited=true 表示已收藏, false 表示已取消
```

操作后触发事件 → dish 模块更新 `collect_count`。

##### GET /api/favorites

我的收藏列表（分页）。

参数：`?page=1&pageSize=10`

```json
// Response
{
  "list": [{ "id": 1, "dishId": 1, "dishName": "牛肉拉面", "dishImage": null, "price": 1200, "avgRating": 4.5, "stallName": "面食窗口", "createdAt": "2024-01-01" }],
  "total": 5
}
```

##### POST /api/favorites/batch

批量收藏（供清单一键收藏调用）。

```json
// Request
{ "dishIds": [1, 3, 5] }

// Response
{ "succeeded": 3, "skipped": 0 }
```

### 4.7 list — 清单模块

#### 需登录接口（student）

##### POST /api/lists

创建清单（**创建时自动生成 `share_token`**）。

```json
// Request
{ "name": "一食堂必吃TOP3", "description": "我最爱的三个菜", "dishIds": [1, 3, 5] }

// Response
{ "id": 1, "name": "一食堂必吃TOP3", "shareToken": "abc123def456", "dishCount": 3 }
```

##### GET /api/lists

我的清单列表。

```json
// Response
[{ "id": 1, "name": "一食堂必吃TOP3", "description": "", "dishCount": 3, "shareToken": "abc123def456", "createdAt": "2024-01-01" }]
```

##### GET /api/lists/{id}

清单详情（**包含完整的菜品信息**）。

```json
// Response
{
  "id": 1, "name": "一食堂必吃TOP3", "description": "",
  "shareToken": "abc123def456",
  "dishes": [
    { "id": 1, "name": "牛肉拉面", "price": 1200, "image": null, "avgRating": 4.5, "stallName": "面食窗口" },
    { "id": 3, "name": "番茄炒蛋盖饭", "price": 1100, "image": null, "avgRating": 4.3, "stallName": "盖饭窗口" }
  ],
  "createdAt": "2024-01-01"
}
```

##### DELETE /api/lists/{id}

删除清单（级联删除清单项）。

##### POST /api/lists/{id}/collect-all

清单一键收藏所有菜品。

```json
// Response
{ "succeeded": 2, "skipped": 1 }
// skipped 表示已收藏过的，自动去重
```

#### 公开接口（无需登录）

##### GET /api/lists/share/{token}

通过分享 token 查看清单（响应格式同 `GET /api/lists/{id}`）。

### 4.8 upload — 文件上传模块

#### POST /api/upload/image

上传图片。需登录（所有角色可用）。

- Content-Type: `multipart/form-data`
- 字段名: `file`
- 限制: 单文件 ≤5MB, 格式 jpg/png/jpeg

```json
// Response 200
{ "url": "/uploads/2024/01/abc123.jpg" }
```

## 8. 事件驱动流程

### 流程图

```
评价提交                         收藏/取消
  │                                │
  ▼                                ▼
ReviewService                   FavoriteService
  │                                │
  ├─ 保存评价到 DB                  ├─ 增删 favorite 表
  ├─ publishEvent()                ├─ publishEvent()
  │                                │
  ▼                                ▼
ReviewSubmittedEvent           FavoriteChangedEvent
  │                                │
  └──────┐                  ┌──────┘
         ▼                  ▼
    RatingUpdateListener    CollectCountListener
         │                  │
         ├─ AVG(rating)     ├─ COUNT(favorites)
         ├─ UPDATE dish     ├─ UPDATE dish
         ▼                  ▼
      dish.avg_rating      dish.collect_count
      实时更新               实时更新
```

### 注意事项

- 事件处理建议使用 `@TransactionalEventListener(phase = TransactionPhase.AFTER_COMMIT)`，确保事务提交后再触发事件，避免事件处理时读到未提交的数据
- demo 阶段用同步事件即可，无需引入消息队列
