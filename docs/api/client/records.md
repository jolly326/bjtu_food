# 学生端接口 · 饮食记录

> **契约真源**：端点 / 入参 / 出参 / 错误码。通用约定见 [`api/README.md`](../README.md)。
> 列定义见 [`schema/dish_record.md`](../../schema/dish_record.md)。

一条**饮食记录** = 用户对某道菜的一次「去品尝 → 吃 → 评分」。本域全部操作落在**同一资源** `/my/records` 上，无动作式端点。

## `GET /my/records`

🔑 需登录 —— 「**记忆**」清单。

| 项 | 口径 |
|---|---|
| 入参 | 无 |
| 出参 | `[RecordVO]` —— 该用户**全部**记录，按 `wantedAt` **降序** |
| 分组 | 服务端**平铺**下发；端上按 `wantedAt` 的**月份 / 日期**自行分组（记录量级小，不做服务端筛选） |

**`RecordVO`**

| 字段 | 类型 | 可空 | 说明 |
|---|---|---|---|
| `id` | number | 否 | 记录 ID |
| `dishId` | number | 否 | 菜品 ID |
| `name` | string | 否 | 菜品名称 |
| `imageUrl` | string | **是** | 菜品图绝对 URL；`null` = 该菜未配图 |
| `wantedAt` | string | 否 | 点「去品尝」的时间 |
| `reaction` | number | **是** | `5` = 喜欢 ｜ `3` = 一般 ｜ `1` = 不喜欢；**`null` = 尚未评分** |
| `canteenName` | string | 否 | 菜品所属**食堂名**（记忆卡辅助行用；取不到时为空串） |
| `stallName` | string | 否 | 菜品所属**档口名**（记忆卡辅助行用；取不到时为空串） |
| `price` | number | 否 | 菜品**现价，单位「分」**（记忆卡辅助行用） |

## `POST /my/records`

🔑 需登录 —— 「**去品尝**」：在记录集合中创建一条。

| 项 | 口径 |
|---|---|
| 入参 | `{ dishId }` |
| 行为 | INSERT 一条（`reaction = NULL`，`wantedAt` = 当前时间） |
| 幂等 | 该菜**已有未评分记录** ⇒ **不新建**，直接返回该既有记录 |
| 出参 | `RecordVO`（新建或复用的那条） |
| 错误码 | `400` `dishId` 缺失 ｜ `4001` 菜品不存在 / 已下架 ｜ `429` 命中限频 |

## `PATCH /my/records/{id}`

🔑 需登录 —— **评分**（更新记录的 `reaction`）。

| 项 | 口径 |
|---|---|
| 入参 | `{ reaction }` —— **`5` / `3` / `1`**，或 **`null`（清除评价、回到未评分）**；其它值 ⇒ `400` |
| 行为 | 写 `reaction`；非 `null` 时同时写 `reactedAt`（清除时置 `NULL`） |
| 可循环改分 | 🔴 **可重复调用**：喜欢 → 一般 → 不喜欢 → 清除 均为合法写入（不再限制「仅未评分可评」） |
| 归属 | 只能改**自己的**记录；非本人 ⇒ `4001`（不暴露他人记录是否存在） |
| 出参 | `RecordVO`（更新后） |
| 副作用 | 同事务内重算 `dish.avg_reaction` / `reaction_count`（清除评价同样触发重算）；聚合**一人一菜一票**，同一用户同菜以**最新一次有效评分**为准 |
| 错误码 | `400` 取值非法 ｜ `4001` 记录不存在或非本人 ｜ `429` 命中限频 |

## `DELETE /my/records/{id}`

🔑 需登录 —— **删除饮食记录**：把该条记录移出「我的饮食记录」（`wantedAt` 时间线少一条）。

| 项 | 口径 |
|---|---|
| 行为 | 物理删除该记录；**未评分 / 已评分记录都可删** |
| 副作用 | 🔴 **同事务重算** `dish.avg_reaction` / `reaction_count`（删掉最新一条后按「一人一菜一票、取最新有效评分」回退到该用户上一条有效评分） |
| 归属 | 只能删**自己的**记录；非本人 ⇒ `4001`（与不存在同响应） |
| 出参 | `data: null` |
| 错误码 | `4001` 记录不存在或非本人 ｜ `429` 命中限频 |
