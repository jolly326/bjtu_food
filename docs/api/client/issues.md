# 学生端接口 · 菜品纠错

> **契约真源**：端点 / 入参 / 出参 / 错误码。通用约定（信封 / 分页 / 错误码 / 金额 / 时间）见 [`api/README.md`](../CONVENTIONS.md)。

## 端点

### `GET /dish-issue-options`

选项字典（🔑 需登录，只读）。

- **出参**：`[{ id, name }]` —— 按 `id` 升序；端上零硬编码、不排序。当前 3 项（信息错误 / 图片不对 / 已停售关闭），以字典实况为准。

### `POST /dishes/{id}/issues`

提交菜品纠错（🔑 需登录）。

- **入口**：美食地图点磁贴唤起底部弹窗 → 点击「纠错 ›」进入反馈页（见 [`func/client/B2`](../../func/client/B-轻量反馈/B2-菜品纠错.md)）。
- **入参**：`{ optionId }` —— **只有一个字段**；缺少 / 不存在 ⇒ `400`
- **归属**：提交人取自登录态，**禁止前端传入**
- **去重**：无。同一人 + 同一菜 + 同一选项可重复提交，每条独立计入纠错计数
- **出参**：`data: null`
- **错误码**：`400` 参数非法 ｜ `4001` 菜品不存在 / 已下架 ｜ `429` 命中限频

> 列定义见 [`schema/dish_issue.md`](../../schema/dish_issue.md) · 业务规则见 [`func/client/B2`](../../func/client/B-轻量反馈/B2-菜品纠错.md) · 管理端见 [`api/web/issues.md`](../web/issues.md)。
