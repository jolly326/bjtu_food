## POST /upload/cloud-image

**鉴权**：🔑 需登录 ｜ **用途**：小程序云存储配图转存（**提交链路第二步：先上云存储拿 fileID → 再由本端点机审 + 转存 COS**）

### 请求体 `CloudImageUploadReq`
| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `fileId` | string | **是** | 微信云存储文件标识（`wx.cloud.uploadFile` 返回的 `cloud://...`） |

### 端上调用时机（**提交时才调**，选图阶段零上云）

UGC 配图（写评价 / 意见反馈 / 菜品纠错）的图片**只在用户确认提交后才离开本地**：

| 阶段 | 端上动作 | 是否调本端点 |
|---|---|---|
| **选图时** | 规格收敛（压缩 / 最长边 ≤1334 / ≤1MB）；缩略图、预览、删除**全部只在本地临时文件**进行 | **否** |
| **提交时** | 逐张「`wx.cloud.uploadFile` 上云存储得 `fileId` → 送本端点（内容安检 + 转存 COS），拿到正式 URL 后随 `images` 上送 | **是**（逐张） |

- **用户不提交 ⇒ 云存储桶零写入**：挑完图直接离开时，图片仍在本机临时目录（由微信自行回收），既不占云存储空间，也不产生永不引用的孤儿对象。
- **失败文案带张号**：端上把后端 `message` 拼成「第 N 张图片……」（如「第 2 张图片包含违规内容，无法上传」）；**已成功的张数保留**，用户重试时只传剩余未成功的张。
- 头像（`PUT /auth/profile` 的 `avatar`）走**选图即传**：头像是账号资料、无「多张 + 逐张机审」语义，也不存在「取消表单提交」的中间态，故选图后一次性走完「云存储 → 本端点」。

### 响应 `data` = `UploadResultVO`
| 字段 | 类型 | 可空 | 说明 |
|---|---|---|---|
| `url` | string | 否 | 安检通过并转存后的 **COS 绝对 URL** |

### 处理链路
```
cloud:// fileId
  → 微信 batchdownloadfile 换取临时下载链接
  → 下载图片
  → 大小 / 格式 / 尺寸校验
  → 微信 imgSecCheck 内容安检
  → 转存腾讯云 COS
  → 返回 COS 绝对 URL
```

### 错误码
| code | 条件 |
|---|---|
| 400 | 图片违规（`87014`）/ 格式不支持（仅 jpg、jpeg、png、webp）/ 超过大小上限 / fileId 无效 / COS 未配置 |
| 401 | 未登录 |

### 硬性限制
| 项 | 限制 | 来源 |
|---|---|---|
| 单图大小 | **≤1MB** | 微信 `imgSecCheck` 硬限制 |
| 尺寸 | ≤750 × 1334 | 端上压缩后仍超限则拒绝 |
| 格式 | jpg / jpeg / png / webp | 按**文件头 magic number** 校验，不信任扩展名 |
| 张数 | 评价 / 反馈 **≤3 张**；菜品问题反馈 **≤3 张**；**头像 1 张** —— 各自校验 | 各 feature 文档 |

### 备注
- **返回的 URL 有时效性**：作为草稿缓存或长时间持有后可能失效，提交前应确保在同一会话内使用。
- 端上在提交 UGC 前需把本端点返回的 URL 收集进 `images` 数组；**直接填 `cloud://` 或非 COS 地址 → 400**。
- **头像与 UGC 配图同走本端点**（学生端唯一上传入口）：`PUT /auth/profile` 的 `avatar` 只接受本端点产出的地址或站内相对路径（见 [auth.md](./auth.md)）。
- 管理端 multipart 上传走 `/admin/upload`（契约见 [`api/web/upload.md`](../web/upload.md)）。

### 运维注记（零代码 · 兜底清理）

云存储中的 UGC 对象只在**提交链路**里产生，且提交成功后即被业务数据（COS URL）引用 —— 正常路径下不会留下未引用对象。

**仍建议**为 **`ugc/` 前缀**配置生命周期规则（**7 天过期**）作为兜底：覆盖「提交后网络中断、后端未落库」等极端场景留下的少量对象。

> 不配也能正常运行（只是这些对象会持续占空间）；配置后由云存储侧自动过期删除，无需代码介入。
