# 学生端接口 · 食堂字典

> **契约真源**：端点 / 入参 / 出参 / 错误码。通用约定见 [`api/README.md`](../README.md)。

## `GET /canteens`

🔑 需登录 —— 食堂字典（食堂 / 档口位置上下文）。

| 项 | 口径 |
|---|---|
| 入参 | 无 |
| 出参 | `[{ id, name }]` —— 按 `id` 升序；**全量**（不筛选、不分页） |
| 错误码 | — （空集合返回 `[]`） |

**字段**

| 字段 | 类型 | 可空 | 说明 |
|---|---|---|---|
| `id` | number | 否 | 食堂 ID（端上回传 `canteenId`） |
| `name` | string | 否 | 食堂名称 |

> 列定义见 [`schema/canteen.md`](../../schema/canteen.md)。
