# 学生端接口 · 档口海报

> **契约真源**：端点 / 入参 / 出参 / 错误码。通用约定见 [`api/README.md`](../README.md)。

## `GET /posters`

🔑 需登录 —— 海报页的档口海报列表。

| 项 | 口径 |
|---|---|
| 用途 | 海报页一屏一张的竖版海报序列 |
| 入参 | 无 |
| 出参 | `[{ id, imageUrl }]` —— **随机顺序**（每次请求重掷）；无分页（档口量级小） |
| 过滤 | **仅返回已上传海报的档口**（`poster IS NOT NULL`） |
| 错误码 | — （空集合返回 `[]`） |

**字段**

| 字段 | 类型 | 可空 | 说明 |
|---|---|---|---|
| `id` | number | 否 | 档口 ID（端上列表 key） |
| `imageUrl` | string | 否 | 海报绝对 URL（库内为相对路径，出参转绝对） |

> 列定义见 [`schema/stall.md`](../../schema/stall.md) · 页面形态见 [`ui/client/档口海报.md`](../../ui/client/档口海报.md)。
> 🔴 海报**不叠加任何文本** —— 档口名称 / 食堂 / 位置由海报图自身承载，故本端点**不下发**这些字段。
