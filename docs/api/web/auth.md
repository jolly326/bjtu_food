#/web/auth/—/管理端鉴权与访问控制

**归属**：`AdminAuthFilter`/｜/**功能口径**：[`func/web/C-账号与访问/C1-管理员登录与访问控制.md`](../../func/web/C-账号与访问/C1-管理员登录与访问控制.md)/｜/**安全设计**：[`secur/web/`](../../secur/web/README.md)
**通用约定**见/[api/README.md](../README.md)

>/覆盖全部/`/admin/**`/端点的访问控制。管理端采用**独立管理员账号/+/账密登录（JWT）**。

---

##/鉴权机制

###/登录换取/token

`POST//admin/auth/login`/——/🔓/**必须在鉴权白名单内**（否则登录请求自身被拦截，必/401）。

**请求**

|/字段/|/类型/|/必填/|/说明/|
|---|---|---|---|
|/`username`/|/string/|/是/|/管理员登录名（`admin_account.username`）|
|/`password`/|/string/|/是/|/明文口令，服务端以/BCrypt/校验；**不入库明文、不写日志**/|

**响应**

```json
{
//"code":/200,
//"message":/"操作成功",
//"data":/{
////"token":/"<管理端/JWT>",
////"username":/"kingdo404",
////"expiresIn":/86400
//}
}
```

|/字段/|/类型/|/说明/|
|---|---|---|
|/`token`/|/string/|/管理端/JWT（**独立/secret/签名**，与学生端不通用）|
|/`username`/|/string/|/回显登录名，供端上展示/|
|/`expiresIn`/|/number/|/有效期秒数（默认/**86400**/=/24h）|

**错误码**：账密错误 / 账号停用 ⇒ `401`「账号或密码错误」（不区分账号不存在与密码错误，防用户名枚举）；达锁定阈值 ⇒ `429`。

###/携带方式

|/项/|/口径/|
|---|---|
|/请求头/|/`Authorization:/Bearer/<token>`/|
|/前端存储/|/**`sessionStorage`**（关标签页即失效）|
|/🔴/前端**不持有口令**/|/口令仅存在于登录时的表单提交中/|

###/校验当前登录态

`GET//admin/auth/me`/——/✅/需/token。用于前端刷新页面时确认/token/是否仍有效。

**响应/`data`**：`{/"username":/"...",/"role":/"super|operator|viewer",/"lastLoginAt":/"yyyy-MM-dd/HH:mm:ss",/"passwordAging":/false/}`

|/字段/|/说明/|
|---|---|
|/`role`/|/当前账号角色，供端上按角色**隐显入口**；**真正的门控在服务端**（见「角色与权限」）/|
|/`passwordAging`/|/口令是否已超期（距上次改密/>/180/天）⇒/端上提示改密，**不强制踢出**/|

###/修改口令

`POST//admin/auth/password`/——/✅/需/token。

**请求**

|/字段/|/类型/|/必填/|/说明/|
|---|---|---|---|
|/`oldPassword`/|/string/|/是/|/当前口令/|
|/`newPassword`/|/string/|/是/|/新口令：**≥12/位**且含大写///小写///数字///符号中**至少三类**（服务端强制）/|

**响应**：与登录成功形态一致（回一枚**新/token**）——/改密会使既有/token/**全部失效**，回新/token/让本端得以续用，其余端需重新登录。

##/错误码

|/code/|/条件/|/端上行为/|
|---|---|---|
|/`400`/|/参数缺失///格式非法///**新口令不满足强度要求**///当前口令不正确/|/Toast/透出/`message`/|
| `401` | **未带 token** / token 签名无效 / **已过期** / 账号已停用 / **凭证版本已失效（改密）** | **清 token → 跳登录页** |
|/`403`/|/已认证但**权限不足**（只读角色执行写操作///非/`super`/执行删除）/|/提示无权限（**不触发重新登录**）/|

> 🔴 **登录失败不区分「账号不存在」与「密码错误」** —— 统一返回 `401` +「账号或密码错误」。区分二者等于**用户名枚举**（攻击者可据此批量探测有效账号）。

###/登录限频

**维度与阈值以/[`secur/web/防爆破与限流.md`](../../secur/web/防爆破与限流.md)/为真源**（登录按/**IP/×/账号**双维度、`/admin/**`/按/**IP/×/token**/双维度，任一超限即拒/⇒/`429`），本文档不复述。

>/📌/**限频不能替代鉴权**：它防「速率」，不防「身份」。

##/备注

-/**角色与权限**：三档/`super`///`operator`///`viewer`，由/`AdminAuthFilter`/按「HTTP/方法/+/角色」**服务端强制**判定（`viewer`/仅只读、`DELETE`/仅/`super`）；越权返回/`403`。口径见/[`secur/web/登录与凭证.md`](../../secur/web/登录与凭证.md)/§2.5。
-/**操作审计与告警**：见/[`secur/web/审计与告警.md`](../../secur/web/审计与告警.md)/——/只追加审计日志，覆盖全部管理端写操作。
-/**IP/白名单**：**不可行**/——/微信云托管无安全组能力，且校园网出口/IP/共享。详见/[secur/server/部署与网络边界.md](../../secur/server/部署与网络边界.md)。
-/**`admin.jwt.secret`**：走环境变量、**不入库不入仓**；须为**固定值**（每次重启变则已登录/token/全部失效）；须**独立于**/`spring.jwt.secret`（共用则学生可自签管理员/token/冒充）。
