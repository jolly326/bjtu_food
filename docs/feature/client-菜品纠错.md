# 菜品信息纠错（A-17）

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔓 公开**（免认证；游客可提交）
> 返回：[功能总览](./README.md)
> **来源**：2026-09-27 自「意见反馈」拆出为**独立功能**（[A-11](./client-意见反馈.md) 的对侧）——
> 边界：**菜品纠错 = 依附某条菜品数据的专项修正**（自带 `dishId`、字段结构化）；
> **意见反馈 = 面向小程序本身的通用反馈**（纯文本 + 截图）。两者互不耦合。

## 介绍

用户浏览菜品时发现资料有误（菜名 / 价格 / 食堂 / 档口 / 口味 / 配图），从**菜品详情页底栏「反馈错误」**进入本功能：按 `dishId` 拉取该菜品详情并**预填全部字段** → 用户只改错的地方 → 提交 → 管理员核实后更新菜品资料。

- **入口唯一**：菜品详情页底栏「反馈错误」（携带当前菜品 ID）；「意见反馈」页**不提供**该入口，也不提供任何跨菜品的纠错表单；
- **只改差异项**：字段全部预填（名称 / 价格 / 食堂名 / 档口 / 口味 / 食材 / 图片），用户改哪里提交哪里；
- **预填未完成禁止提交**；字段错误 = 错误边框 + 行内文案 + 首错定位；
- 图片上限：端上 **≤1 张**（预填菜品首图，可替换）；
- **不暗示提交即生效**：提交后由管理员核实，确认无误才更新菜品信息；
- 处理结果经站内通知回执（仅已认证提交人）。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/dishes/{id}` | 🔓 公开 | **预填数据源**（字段口径见 [client-菜品详情](./client-菜品详情.md)） |
| GET | `/dishes` | 🔓 公开 | 换一道菜时的候选搜索（`keyword` / `page` / `pageSize`） |
| GET | `/dishes/attributes` | 🔓 公开 | 四维字典（口味 / 食材机器值 → 中文；失败静默，展示原始值） |
| POST | `/dishes/{id}/correction` | 🔓 公开 | **提交纠错**（`dishId` 在路径）；公开匿名，IP 限频 2 条/分钟、10 条/小时 |

## 字段

### 请求 · `POST /dishes/{id}/correction`（`CorrectionReq`，七字段平铺）

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `name` | string | 是 | 菜品名称（预填详情 `name`，可改；≤64 字，敏感词由后端 400 `message` 直透） |
| `price` | number | 是 | 价格，**单位 = 分**（端上以元填写，提交前经 `utils/money` 的 `yuanToFen` 换算 —— 金额红线） |
| `canteenName` | string | 是 | 食堂名（**自由文本**，预填详情 `canteenName`，无字典 / 无 picker） |
| `stallName` | string | 是 | 档口名（**自由文本**，预填详情 `stallName`） |
| `flavorTags` | array | 否 | 口味标签（预填详情机器值 + 用户自由输入项，可增删、去重、≤12 项） |
| `ingredients` | array | 否 | 食材（同上） |
| `images` | array | 否 | 图片 URL 数组（预填菜品**首图**，端上 ≤1；服务端上限 9） |

> 请求体**无 `type`、无 `dishId` 字段**（`dishId` 在路径中）；提交内容为用户改后的差异项。

### 响应 · `POST /dishes/{id}/correction`

`data` = `null`；失败时 `code` / `message` 见下表。

| 情况 | `code` | `message` 口径 |
|---|---|---|
| 菜品名称缺失 / 超 64 字 | 400 | 菜品名称不能为空 / 超长 |
| 价格非大于 0 的整数（分） | 400 | 价格必须为大于 0 的整数 |
| 图片地址不合法 / 超上限 | 400 | 图片地址不合法 |
| 文本 / 图片命中内容安检 | 400 | 含敏感词 / 图片包含违规内容 |
| 提交过于频繁（IP 限频） | 400 | 提交过于频繁（含剩余秒数） |
| 菜品不存在 / 已下架 | **4001** | 资源不存在 |

## 数据（落库）

| 表 | 操作 | 说明 |
|---|---|---|
| `dish_correction` | INSERT | 七字段**拆列快照**（`name` / `price`（分）/ `canteen_name` / `stall_name` / `flavor_tags` JSON / `ingredients` JSON / `images` JSON）+ `dish_id` + `user_id`（游客为 null，匿名提交）+ `status='pending'` |

> 管理端消费见 [web-信息纠错](./web-信息纠错.md)（`/admin/corrections*`，管理员核实后才更新菜品资料）。
