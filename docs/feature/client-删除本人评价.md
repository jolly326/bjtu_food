# 删除本人评价（A-08）

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔐 认证**（需学号邮箱认证）
> 返回：[功能总览](./README.md)

## 介绍

删掉自己写的评价；删除后该菜品的**评分与评价数会随之重算**（不影响他人评价）。

**入口链路**：菜品详情页**每条评价卡右上角均有常驻三点**（更多操作）——点击后**底部弹出动作菜单**（`ActionSheet`）：本人的评价显示「**删除评价**」（危险红色态）。点击「删除评价」→ 先弹**二次确认**弹窗（不可恢复警示）→ 确认后调 `DELETE /reviews/{id}`，行从列表移除；失败按错误码提示。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| DELETE | `/reviews/{id}` | **🔐 认证**（`@RequireVerified`） | 删除本人评价；**仅本人可删**，他人评价 → 403 |

## 字段

### 请求

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `id` | number | **是** | 评价 ID（路径参数，如 `/reviews/1`）。**无请求体**；归属校验用 JWT 中的 userId，端上不传 userId |

### 响应

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `data` | null | 无载荷；成功即 `code=200` |

### 错误码

| code | 含义 | 中文解释 |
|---|---|---|
| 403 | 无权限 | 试图删除他人评价 |
| 4031 | 邮箱未认证 | 跳转身份认证页 |
| 400 | 资源不存在 | 评价 ID 不存在 |

### 副作用

| 目标 | 变化 | 中文解释 |
|---|---|---|
| `review` | DELETE 行 | 物理删除该条评价（无投票关联数据需清理） |
| `dish.avg_rating` / `dish.rating_count` | 异步 UPDATE | 发 `ReviewSubmittedEvent` → 异步重算（口径：仅计 `is_hidden=0` 的评价） |

## 数据（落库）

| 表 | 变化 | 中文解释 |
|---|---|---|
| `review` | 删行 | 评价本体 |
| `dish` | 异步重算两列 | 平均评分、评价数 |
