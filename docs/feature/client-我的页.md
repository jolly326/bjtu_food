## 介绍

「我的」是 **TabBar 主根页之一**（另一个是首页），作为**个人中心的入口聚合页**：展示当前身份（游客 / 已认证）与账号资料，提供三个功能入口（意见反馈 / 系统通知 / 我的评价），并提供合规入口（隐私政策与用户协议 / 注销账号）。**本功能不产生业务数据**，只做身份展示与导航分发。用户卡点击**二分**：游客态弹 `AuthSheet` 认证弹层，已认证态进入个人信息编辑；「我的评价」为**需认证入口**（未认证弹 `AuthSheet`，认证成功后自动续跑进入）；「系统通知」入口有未读时右上红点（每次 `onShow` 刷新未读数）；「注销账号」经**二次确认**弹窗后调注销端点并清本地态。

## 字段

本页**不展开任何端点的字段表**（字段含义见上表主体文档）；以下为**本页展示的派生值**：

| 展示项 | 来源 | 中文解释 |
|---|---|---|
| 昵称 | `UserInfoVO.nickname` | 用户卡主标题；未设置时游客显示「游客」、认证态显示「食客」 |
| 绑定邮箱 | `UserInfoVO.bindEmail` | 认证态用户卡副行（**校园邮箱唯一出参来源**） |
| 游客短标识 | **端上派生** = 「食客 + `UserInfoVO.id` 尾 4 位」（id 不足 4 位取全量；`id` 不可得时回退本地游客 ID 兜底，保证不空白） | 游客态用户卡副行（短标识由端上派生，非接口出参，见 `project_spec.md` §7.32） |
| 认证态判据 | **`bindEmail` 非空**（判据单点收敛，见 `project_spec.md` §7.36） | 决定用户卡两态与「去认证」按钮显隐 |
| 通知未读数 | `GET /my/notifications/unread-count` 的 `count` | 宫格「系统通知」红点 |
| 版本号 | 构建期注入 `__APP_VERSION__`（源自 `manifest.json` 的 versionName） | 底部信息区第一行（纯展示） |
