# 我的评价（A-10）

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔐 认证**（需学号邮箱认证）
> 返回：[功能总览](./README.md)

## 介绍

查看自己发过的**全部有效评价**——**本质是评价列表的「本人过滤视图」**：对后端评价全集按 `userId` = 本人过滤拆分后分页返回，能力与菜品详情页评价区同源（同一张表、同一套分页与排序口径、**同一张评价卡组件**）。客户端能访问到的评价都是**未被隐藏的正常评价**（被管理员隐藏的评价不对客户端返回，含作者本人），故列表无需隐藏标记。支持删除自己的评价；列表分页加载（上滑加载更多），排序唯一为**时间倒序**（与公开评价列表同口径）。删除链路与详情页同款：卡片右上角三点 → 底部 `ActionSheet`「删除评价」→ 二次确认 → 调 `DELETE /reviews/{id}`。

**承载形态**：本功能落在**「我的主页」**——该页由**用户信息卡**（头像 / 昵称 / 认证态副行 + 个人信息编辑入口）与**本人评价列表**（区块标题「我的评价」，**列表有数据时才渲染**）两段构成。入口：「我的」页**用户卡点击**（**游客直接进入**，无认证拦截；游客态列表显示空态「暂无评价，完成身份认证后可发表评价」，认证要求仅在评价写操作时给出）。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/my/reviews` | **🔐 认证**（`@RequireVerified` + 方法级 `hasRole('STUDENT')`） | 我的评价列表：对评价全集按当前用户过滤拆分（`user_id` = 本人 且 `is_hidden` = 0），联表补齐菜品名后分页返回。**可选 `dishId` 过滤**（按菜品过滤本人评价） |

## 字段

### 请求（query）

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `dishId` | number | 否 | **按菜品过滤**（菜品详情页判定「我是否已评价」时传）；不传 = 全部 |
| （鉴权） | — | — | 用户身份从 JWT 取，**端上不传 userId**（数据隔离红线） |

### 响应（`data` = `PageResult<MyReviewVO>`）

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `records` | MyReviewVO[] | 当前页评价行数组 |
| `total` | number | 本人评价总条数 |
| `page` | number | 实际生效页码（归一化后） |
| `pageSize` | number | 实际生效每页条数（归一化后） |

> **`page` / `pageSize` 归一化规则（R11）**：回传经 `PageUtil.normalize` 归一化后的**实际生效值**（`page < 1 → 1`；`pageSize < 1 → 10`；`pageSize > 100 → 100`）—— 入参越界 / 超限时端上据此得知服务端真正用了什么。

### 响应 · `MyReviewVO` 单行字段（**本人视角，10 字段**）

> **继承声明**：`MyReviewVO` = 公开视角 `ReviewVO` 的 **8 个字段**（`id` / `userId` / `userNickname` / `userAvatar` / `rating` / `content` / `images` / `createdAt`——逐字段口径以 [client-菜品详情](./client-菜品详情.md) 的公开评价字段表为唯一真源，此处不重复维护）+ 下表 **2 个本人视角专属字段**。两视角 **MUST 是两个类型**，端上 **SHALL NOT** 用单一 interface 复用。

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `dishId` | number | 关联菜品 ID |
| `dishName` | string | **关联菜品名称**（后端联表补齐；本页必展示，用于辨识是哪道菜） |

## 数据（读取）

| 表 | 读什么 | 中文解释 |
|---|---|---|
| `review` | 本人未被隐藏的评价（`user_id` = 本人 且 `is_hidden` = 0） | 评价本体 |
| `dish` | `name` | 联表补齐菜品名，供列表评价卡的菜名行展示 |
| `user` | `nickname`、`avatar` | 联表补齐昵称与头像 |
