# 我的评价（A-10）

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔐 认证**（需学号邮箱认证）
> 返回：[功能总览](./README.md)

## 干什么

查看自己发过的**全部评价**——包括被管理员隐藏的（会标「已被隐藏」），并支持删除自己的评价。

## UI

- 入口：「我的」页宫格「我的评价」（一行 3 列：意见反馈 / 系统通知 / 我的评价）。
- 页面：`pages/my-reviews/index`——列表行展示：菜品名、星级、评价内容、配图、时间、有用数；被隐藏的行显示「已被隐藏」标记；行尾「删除」。
- 空态：未发过评价时给空态引导（去首页看看）。

## 操作

1. 进页 → 拉取本人评价列表（分页，按后端默认排序）。
2. 上滑加载更多。
3. 点「删除」→ 二次确认 → 调 `DELETE /reviews/{id}`（见 [删除本人评价](./client-删除本人评价.md)）。
4. 点行 → 可跳菜品详情查看该评价的公开展示态。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/my/reviews` | **🔐 认证**（`@RequireVerified` + 方法级 `hasRole('STUDENT')`） | 我的评价列表；**本人视角不过滤 `is_hidden`**（自己的隐藏评价也可见）。**可选 `dishId` 过滤**（2026-09-20 §7.30，供菜品详情页判定「我是否已评价」） |

## 字段

### 请求（query）

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `dishId` | number | 否 | **按菜品过滤**（菜品详情页判定「我是否已评价」时传）；不传 = 全部 |
| （鉴权） | — | — | 用户身份从 JWT 取，**端上不传 userId**（数据隔离红线） |

### 响应（`data` = `PageResult<ReviewVO>`）

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `records` | ReviewVO[] | 当前页评价行数组 |
| `total` | number | 本人评价总条数 |
| `page` | number | 实际生效页码（归一化后） |
| `pageSize` | number | 实际生效每页条数（归一化后） |
| `list` | ReviewVO[] | 过渡期兼容字段，恒等于 `records` |

### 响应 · `ReviewVO` 单行字段

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `id` | number | 评价 ID |
| `userId` | number | 评价者用户 ID（本人） |
| `dishId` | number | 关联菜品 ID |
| `dishName` | string | **关联菜品名称**（后端联表补齐；本页必展示，用于辨识是哪道菜） |
| `userNickname` | string | 评价者昵称 |
| `userAvatar` | string | 评价者头像 URL |
| `rating` | number | 评分（1~5 星） |
| `content` | string | 评价文字内容 |
| `images` | string[] | 评价配图 URL 数组（≤3 张 COS 地址，无图空数组） |
| `createdAt` | string | 评价发表时间（端上归一为 `createTime`） |
| `usefulCount` | number | 该评价「有用」总数（**若 A-07 删除「有用」则此字段下线**） |
| `useful` | boolean \| null | 当前用户是否已标记「有用」（本人列表恒为 false/null，本人一般不给自己点） |
| `isHidden` | number | **是否被管理员隐藏：0=正常 / 1=已隐藏**——本接口本人视角**必然返回**，端上据此标注「已被隐藏」 |

## 数据（读取）

| 表 | 读什么 | 中文解释 |
|---|---|---|
| `review` | 本人全部评价（**不过滤 `is_hidden`**） | 评价本体（含被隐藏的） |
| `dish` | `name` | 联表补齐菜品名，供「我的评价」列表展示 |
| `user` | `nickname`、`avatar` | 联表补齐昵称与头像 |
| `review_useful` | 按评价聚合 | 有用数 |
