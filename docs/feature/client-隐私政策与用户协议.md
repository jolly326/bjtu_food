# 隐私政策与用户协议（A-16）

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔓 公开**
> 返回：[功能总览](./README.md)

## 干什么

合规入口：向用户说明**收集哪些信息、用途、存储与删除权利**。属静态展示页，不产生任何业务数据。

## UI

- 入口：「我的」页**底部信息区唯一可点元素**。
- 页面：`pages/privacy/index`，两个 tab（**隐私政策** / **用户协议**）。
- 纯展示，无表单、无按钮交互（仅 tab 切换与滚动）。

## 操作

查看即可。切 tab 阅读两份文本，无提交动作。

## 接口

**无**（端内静态文案，不发起任何网络请求）。

## 字段

**无**（不消费任何接口字段）。

> 若未来改为服务端下发文案，需在此登记「接口 + 字段 + 版本号」，并纳入接口契约文档。

## 数据

**无**（不读写任何数据库表）。
