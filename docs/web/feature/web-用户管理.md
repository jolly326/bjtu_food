# 用户管理（B-12）

> 所属端：**管理后台（Web）** ｜ 鉴权：🔑 管理员
> 返回：[管理后台功能总览](./README.md)

## 介绍

查看并治理**学生用户**（`user` 表）。本功能的动作很克制：**只有启用 / 禁用**。

**为何能力这么少（数据安全边界）**：
- 管理员**不能**改用户的昵称 / 头像 / 绑定邮箱——这些是学生自助维护的（A-12 / A-13），管理员代改会制造「不是本人操作」的内容归属问题；
- 管理员**不能**代学生发内容、代注销账号（注销是学生自助，A-14）；
- **不展示 `openid`**：微信 openid 是平台侧凭据，属敏感字段，管理端**不出参、不提供解绑**；是否绑定微信以一个布尔 `wechatBound` 表达。

**禁用语义**：禁用后该账号**登录与全部写操作一律拒绝**（`401`）；已发表的**内容保持原样**——禁用是「停止活动」，不是「抹除痕迹」（避免管理员一键让历史评价消失）。可随时启用恢复（幂等）。

**禁用与内容治理的关系**：禁人 ≠ 删内容。若要处置具体内容，走 B-08（隐藏 / 删除评价）；两者互不替代。

**排序与筛选**：按注册时间倒序；支持按关键词（昵称 / 邮箱）与状态筛选。**不提供**按活跃度排序（活跃口径见 B-02，属看板职责）。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/admin/users` | 🔑 | 用户列表（分页 + 筛选） |
| PUT | `/admin/users/{id}/status` | 🔑 | 启用 / 禁用切换（幂等）；不存在返回 `4001` |

### 请求参数（`GET /admin/users`）

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `keyword` | string | 否 | 按昵称或绑定邮箱模糊匹配 |
| `status` | string | 否 | `normal` / `disabled`；不传 = 全部 |

### 请求 · `PUT /admin/users/{id}/status`

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `disabled` | boolean | 是 | `true` 禁用 / `false` 启用（**必须显式布尔**，非法 → `400`） |

## 字段

### 响应 · `UserAdminVO`

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `id` | number | 用户 ID |
| `nickname` | string | 昵称（无为空串） |
| `avatar` | string | 头像绝对 URL（无头像为空串） |
| `bindEmail` | string \| null | 已认证绑定的校园邮箱（`null` = 未认证 / 游客态） |
| `verified` | boolean | 是否已邮箱认证（由 `bindEmail` 非空派生，**只读投影**，非独立存储字段） |
| `wechatBound` | boolean | 是否已绑定微信（由 `openid` 非空派生；**不暴露 openid 本身**） |
| `status` | string | `normal` / `disabled` / `deleted` |
| `reviewCount` | number | 可见评价数（只读，联表统计） |
| `createdAt` | string | 注册时间 |
| `lastLoginAt` | string \| null | 最近登录时间（从未登录为 `null`） |

### 错误码

| 码 | 场景 |
|---|---|
| `400` | `disabled` 缺失或非布尔 |
| `4001` | 用户不存在 |

## 数据（读写）

| 表 | 读写什么 | 中文解释 |
|---|---|---|
| `user` | 查、写 `status`；读 `openid` **仅用于派生** `wechatBound`（不出参） | 学生用户 |
| `review` | 统计可见评价数（`is_hidden=0`） | 只读统计 |

## 与当前代码的差异

> 本节集中登记与现有代码的差异；清零即写「无」。

- **`disabled` 改为强布尔**：现有实现用宽松判据，传非布尔值可能被静默当作 `false`（想禁用却变成启用）。本功能要求显式布尔，非法即 `400`。
- **新增 `verified` / `wechatBound` 只读投影**：现有管理端不下发认证态与微信绑定态，管理员无法判断账号为何不能发表评价。
- **新增 `reviewCount` 出参**：现有列表不回带内容量，禁用前无法评估影响面。
- **明示禁用不删除内容**：现有实现未文档化该语义。
