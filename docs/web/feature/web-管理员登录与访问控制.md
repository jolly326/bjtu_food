# 管理员登录与访问控制（B-01）

> 所属端：**管理后台（Web）** ｜ 鉴权：登录接口 🔓 公开，其余 🔑 管理员
> 返回：[管理后台功能总览](./README.md)
>
> ⚠️ 本管理后台（Web 后台）已软冻结，待后期整体重构移除（详见 [管理后台功能总览](./README.md) 顶部声明）。

## 介绍

管理后台的**唯一准入入口**：管理员用「账号 + 密码」登录后取得令牌，后续所有 `/admin/**` 请求携带该令牌访问；登出即作废旧令牌。

**与学生端体系完全隔离**——学生走微信静默登录（A-01），管理员走本端点。两套令牌互不适用：管理后台端点**不接受学生 JWT**，学生端端点**不接受管理员令牌**。

**角色口径（遵守红线）**：角色**仅** `STUDENT` / `ADMIN`，本端点签发的账号角色恒为 `ADMIN`，**不引入子角色 / 权限点**（如需分级见总览 W-1，须先修订红线）。

**账号存储**：管理员账号独立建表 `admin_user`，**不复用学生 `user` 表**——两者凭据体系不同（学生无密码、管理员有密码），混表会让「密码登录」语义渗入学生侧。

**口令安全**：密码仅存 BCrypt 摘要，**不存明文、不回传**；登录失败统一返回 401 且不区分「账号不存在」与「密码错误」（防账号枚举）。种子账号首次登录**强制改密**（`mustChangePassword=true` 时，除改密外其余端点一律 403）。

**会话**：令牌为服务端签发的随机串（非 JWT），存于 `admin_session` 表并可单个 / 全部作废；有效期 8 小时，临近过期续期。登出即删当前会话。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| POST | `/admin/auth/login` | 🔓 公开 | 账号密码登录，成功返回令牌与管理员信息；失败 401 |
| POST | `/admin/auth/logout` | 🔑 管理员 | 作废旧当前令牌（幂等） |
| GET | `/admin/auth/me` | 🔑 管理员 | 取当前登录管理员信息（用于顶栏展示与过期校验） |
| PUT | `/admin/auth/password` | 🔑 管理员 | 修改当前管理员密码（改后其它会话全部失效） |

## 字段

### 请求 · `POST /admin/auth/login`

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `username` | string | 是 | 管理员账号（3~32 字符） |
| `password` | string | 是 | 密码明文（仅传输，服务端即时校验后立即丢弃；6~64 字符） |

### 响应 · `POST /admin/auth/login`（`data` = `LoginVO`）

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `token` | string | 访问令牌，后续请求以 `Authorization: Bearer <token>` 携带 |
| `expiresAt` | string | 令牌过期时间（`yyyy-MM-dd HH:mm:ss`） |
| `admin` | object | 管理员信息，结构见下表 |

### 响应 · `AdminVO`（管理员信息）

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `id` | number | 管理员 ID |
| `username` | string | 账号（登录用，不可改） |
| `nickname` | string | 展示名（顶栏显示） |
| `role` | string | 角色，恒为 `ADMIN` |
| `mustChangePassword` | boolean | 是否须强制改密（种子账号首次登录为 `true`） |
| `lastLoginAt` | string \| null | 上次登录时间（首次登录为 `null`） |
| `createdAt` | string | 账号创建时间 |

### 请求 · `PUT /admin/auth/password`

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `oldPassword` | string | 是 | 原密码（校验通过才允许改） |
| `newPassword` | string | 是 | 新密码（6~64 字符，不得与原密码相同） |

### 错误码

| 码 | 场景 |
|---|---|
| `400` | 账号 / 密码格式不合法 |
| `401` | 账号或密码错误；令牌缺失 / 失效 / 已作废 |
| `403` | `mustChangePassword=true` 时访问其它端点 |

## 数据（读写）

| 表 | 读写什么 | 中文解释 |
|---|---|---|
| `admin_user` | 读账号 + 校验 BCrypt 摘要；写 `last_login_at` | 管理员账号（**本功能新增表**） |
| `admin_session` | 登录写、登出删、校验读 | 令牌会话（**本功能新增表**） |

> 两表均需在 `server/src/main/resources/db/schema.sql` 新增（**库结构变更只改脚本，禁直连 ALTER**）；种子脚本灌一个初始管理员，初始密码由部署者注入环境变量，**首次登录强制改密**。

## 与当前代码的差异

> 本节集中登记与现有代码的差异；清零即写「无」。

**整套为本功能的新设计，现有实现无对应物**：当前管理端靠环境变量 `ADMIN_TOKEN` + 请求头 `X-Admin-Token` 做单口令保护，**无账号体系、无登录态、无会话**。本功能落地即取代该机制（`ADMIN_TOKEN` / `AdminTokenFilter` 随之移除）。
