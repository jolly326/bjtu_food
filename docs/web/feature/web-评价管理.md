## 介绍

治理学生在 A-06 发表的评价。管理员可**查看全部评价**（含已隐藏）、**隐藏 / 取消隐藏**、**删除**。

**隐藏语义（关键）**：`is_hidden=1` 的评价**对所有客户端不可见**，包括：
- 学生端公开评价列表（`GET /dishes/{id}/reviews`）；
- **「我的评价」（A-09）——作者本人也看不到**；
- 同时**不计入**菜品平均分与评价数（评分聚合口径统一为「仅未隐藏评价」）。

即：隐藏是**面向作者的强处置**，不是「仅他人不可见」。管理员隐藏后无需另行通知（本功能**不投递站内通知**，避免把处置动作暴露为学生可见的回执）。

**删除语义**：物理删除，并**触发该菜品平均分重算**（评价变更事件，提交后异步）。删除是不可逆操作，前端须二次确认。

**与举报的关系**：被举报的评价在 B-10 处置；处置动作落到本功能的「隐藏 / 删除」。两功能通过「被举报对象 ID」跳转衔接，不在本功能内展示举报信息。

**不做的事**：
- **无**「有用 / 点赞」相关字段或操作；
- **无**人工复核队列与安检态 —— 违规内容由微信机审在**发表时**拦截，管理员只处理已落库内容。

## 接口

| 方法 | 路径 | 鉴权 | 说明 |
|---|---|---|---|
| GET | `/admin/reviews` | 🔑 | 评价列表（分页 + 筛选，见下） |
| PUT | `/admin/reviews/{id}/hidden` | 🔑 | 设置隐藏状态（幂等；不存在返回 `4001`） |
| DELETE | `/admin/reviews/{id}` | 🔑 | 删除评价（物理删除 + 触发评分重算） |

### 请求参数（`GET /admin/reviews`）

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `page` | number | 否 | 页码，默认 1 |
| `pageSize` | number | 否 | 每页条数，默认 20 |
| `keyword` | string | 否 | 按评价内容模糊匹配 |
| `dishId` | number | 否 | 按菜品筛选 |
| `userId` | number | 否 | 按评价者筛选 |
| `hidden` | boolean | 否 | 按隐藏状态筛选；**不传 = 全部**（管理端必须能看到已隐藏的） |

### 请求 · `PUT /admin/reviews/{id}/hidden`

| 字段名 | 类型 | 必填 | 中文解释 |
|---|---|---|---|
| `hidden` | boolean | 是 | `true` 隐藏 / `false` 取消隐藏（**必须显式传布尔**，不接受 `1` / `"true"` 等宽松值） |

## 字段

### 响应 · `ReviewAdminVO`

| 字段名 | 类型 | 中文解释 |
|---|---|---|
| `id` | number | 评价 ID |
| `dishId` | number | 被评价菜品 ID |
| `dishName` | string | 菜品名（联表带出；菜品已删除为 `null`，前端按「菜品已删除」展示） |
| `userId` | number | 评价者用户 ID |
| `userNickname` | string | 评价者昵称（联表带出；账号已注销显示「已注销用户」） |
| `rating` | number | 评分（1~5） |
| `content` | string | 评价内容（无为空串） |
| `images` | string[] | 配图绝对 URL 数组（无图空数组，≤3 张） |
| `isHidden` | boolean | 是否已隐藏 |
| `createdAt` | string | 发表时间（重新评价后为新的时间） |

### 错误码

| 码 | 场景 |
|---|---|
| `400` | `hidden` 缺失或非布尔 |
| `4001` | 评价不存在 |

## 数据（读写）

| 表 | 读写什么 | 中文解释 |
|---|---|---|
| `review` | 查（含隐藏）、改 `is_hidden`、物理删除 | 评价本体 |
| `dish` | 读 `name` 回填；删除时触发评分重算 | 被评价菜品 |
| `user` | 读 `nickname` 回填 | 评价者 |

## 与当前代码的差异

> 本节集中登记与现有代码的差异；清零即写「无」。

- **`hidden` 为强布尔**：本功能要求显式布尔，非法即 `400`。
- **新增 `dishId` / `userId` / `hidden` 筛选**：现有列表仅支持关键词。
- **新增 `images` 出参**：现有管理端列表不下发配图（管理员无法核对图片内容）。
