# 校园食堂信息系统 Web管理端功能文档
## 一、登录与权限管理
1. 后台账号登录、退出功能
2. 基于角色权限控制，系统管理员

## 二、用户管理
1. 全平台用户列表查询，支持条件筛选
2. 账号新增、编辑、启用/禁用、密码重置
3. 用户角色分配、档口管理员与所属档口绑定

## 三、食堂管理
1. 食堂信息列表查看、检索
2. 新增、编辑、删除食堂基础信息
3. 食堂状态启停、展示顺序调整

## 四、档口管理
1. 按食堂分类展示档口列表
2. 新增、编辑、删除档口信息
3. 档口营业状态管理、排序调整、管理员绑定

## 五、菜品管理
1. 全平台菜品列表多条件筛选查询
2. 菜品新增、信息编辑、删除操作
3. 菜品上下架、标签设置、价格维护
4. 菜品图片、简介等内容管理

## 六、评价管理
1. 全局评价数据列表查看、筛选
2. 违规评价隐藏、删除、恢复操作
3. 评价内容预览、举报/违规记录查看

## 七、数据统计看板
1. 整体运营数据汇总展示
2. 菜品浏览量、收藏量、评分数据统计
3. 热门菜品排行、流量与评价趋势图表
4. 支持按食堂、档口、时间段拆分统计

## 八、轮播/公告管理
1. 首页轮播图、公告列表管理
2. 新增、编辑、删除轮播内容
3. 轮播图上下线、排序、跳转配置

## 九、系统基础设置
1. 基础参数配置
2. 敏感词库维护
3. 操作日志查询
