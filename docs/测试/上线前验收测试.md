# 上线前验收测试（client 学生端 · web 管理端）

> **用法**：逐行执行「测试功能」列的操作，对照「预期效果」，在「是否通过」列填 ✅ / ❌（❌ 请补一句现象）。
> **前置**：云上后端已部署最新版本；client 用微信开发者工具打开（填测试 AppID）；web 执行 `cd web && npm run dev` 后用管理员账号登录；云托管环境变量确认含 `WECHAT_APPID` / `WECHAT_SECRET`（推荐另配 `WECHAT_API_BASE_URL=http://api.weixin.qq.com` + `WECHAT_INTERNAL_CALL=true`）。
> 准备：两个微信测试号（微信 A 未认证 / 微信 B 已认证且学号邮箱可收码）、管理员账号；测试用菜菜品 / 评价 / 反馈各若干。
