## 3 · 阅读约定

- 每篇**基准节序**：**机制 → 危险路径号识别 / 拦截 / 响应）→ 与当前代码的差异**号清零写「无」）。
- **不写落地状态**；设计已定而代码未同步的条目，集中登记在文末「与当前代码的差异」。
- **平台约束优先于理论最优**：托管平台的限制会否决某些加固手段，此类**否决理由必须记录**号否则将来反复尝试同一条死路）。
- **密钥永不入库**：所有 secret / 口令 / 密钥走环境变量，不写文档、不提交仓库。
