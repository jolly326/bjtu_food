## 威胁面与处置

| 面 | 处置 | 归属 |
|---|---|---|
| 用户身份伪造 | **端上不传身份** —— 一律服务端从凭证解析 | [S-01](./S-01-身份与凭证.md) |
| 越权访问他人数据 | `/my/**` 归属校验，非本人 ⇒ `4001`（与「不存在」同响应） | [S-02](./S-02-鉴权与归属校验.md) |
| 刷点赞 / 刷纠错 | 写入口限频 | [S-03](./S-03-限频与接口防护.md) |
| 爬取全量数据 | 读端点**账号**限频（+ 全局 IP 兜底）+ 分页封顶 | [S-03](./S-03-限频与接口防护.md) |
| 内容违规 | **不在范围** —— 学生端无文字 / 图片 UGC（仅纠错选项） | — |
| 运营端越权 / 爆破 | **不在本期范围**（单管理员；登录端点仅保留 IP 限频兜底） | [S-03](./S-03-限频与接口防护.md) |
| 凭据泄露 | 一律环境变量 + `server/.env`，禁入文档与代码 | [S-04](./S-04-凭据与部署边界.md) |
| 生产配置错误（缺签名密钥 / 双端同密钥 / 缺 `COS_DOMAIN`） | **启动预检 fail-fast**：拒绝启动；CORS `*` 生产打告警 | [S-04](./S-04-凭据与部署边界.md) |
| 恶意大请求体打爆内存 | 请求体上限 **6MB**（`Content-Length` 预检、先限频再拒体）+ `nosniff` / `no-store` 响应头 | [S-04](./S-04-凭据与部署边界.md) |

## 不在范围内的能力（防回退）

| 能力 | 口径 |
|---|---|
| 内容安全机审（文本 / 图片） | **不引入** —— 学生侧零自由输入 |
| 用户认证 / 角色 / 权限分级 | **不引入** —— 学生端只有一种身份 |
| 操作日志 / 审计表 | **不引入** —— 无管理端写操作留痕需求 |
| IP 白名单 / 安全组 | **平台不支持**，见 [S-04](./S-04-凭据与部署边界.md) |
