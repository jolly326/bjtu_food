# S-01 · 身份与凭证

> 返回：[安全总览](INDEX.md)

## 学生端

| 项 | 口径 |
|---|---|
| **识别** | 冷启动 `wx.login` 取 code → `POST /auth/wechat-login` → 服务端换 openid → 建 / 取 `user` 行（见 [`api/client/auth.md`](../api/client/auth.md)） |
| **凭证** | 服务端签发 **JWT**（独立 secret）；**端上只存 token —— 不持有、不传递 openid** |
| **有效期** | **7 天**（服务端 `JWT_TTL_SECONDS` 可覆盖，缺省 `604800`） |
| **端上留存** | token 存**本地 storage**，**端上不设 TTL** —— 不按时间主动清理；仅在遇 `401` 时清掉并静默重登 |
| **失效** | `401` ⇒ 端上**清 token → 静默重登，并自动重试原请求一次** |
| **端上流程** | `wx.login` 与页面渲染**并行**；有缓存 token 时**直接用**（7 天内日常打开**零额外往返**）；无 / 过期时才走 `POST /auth/wechat-login` |
| **覆盖范围** | 🔴 **所有业务端点都要求凭证**（唯一例外是换凭证的 `POST /auth/wechat-login`）—— 无「公开端点」态 |
| **吊销** | **不提供** —— 无注销、无用户管理，故不需要吊销通道 |
| 🔴 **权威来源** | 任何身份判断只认**服务端从凭证解析**出的用户；**禁止信任**请求体 / query / header 里的用户标识 |

> openid 属**个人信息** —— 须与微信 MP 后台的《用户隐私保护指引》声明一致（见 [`func/client/README.md`](../func/client/约定与红线.md) 的「合规与不做的事」）。

## 运营端

| 项 | 口径 |
|---|---|
| **识别** | `POST /admin/sessions` —— 账密比对该行 `password`（**BCrypt 哈希**，见 [`schema/admin.md`](../schema/admin.md)） |
| **凭证** | 独立 JWT，**secret 与学生端分离**；后续请求 `Authorization: Bearer <token>` |
| **前端** | **不持有口令**；token 存 **`sessionStorage`**（关页即失效）；登出 = 前端清 token（无服务端吊销端点） |
| **角色** | **无分级** —— 单管理员运营，不设按角色的入口隐藏 |
| **登录防护** | **本期不展开**（运营端防护不在范围）；登录端点保留 IP 限频兜底，见 [S-03](./S-03-限频与接口防护.md) |

## 凭证参数集中表

| 参数 | 学生端 | 运营端 |
|---|---|---|
| 形式 | JWT | JWT |
| 签名 secret | `JWT_SECRET` | 独立 secret（`ADMIN_JWT_SECRET`，**不通用**） |
| 有效期 | 7 天（`JWT_TTL_SECONDS`，缺省 `604800`） | 同为 7 天 —— **`JWT_TTL_SECONDS` 两端共用** |
| 失效响应 | `401` | `401`（前端清 token 跳登录页） |
| 端上留存 | 本地 storage，**无端上 TTL**（仅 `401` 时清理） | `sessionStorage`，**关页失效** |
