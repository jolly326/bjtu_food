# S-04 · 凭据与部署边界

> 返回：[安全总览](./README.md)

## 一、凭据清单（一律环境变量）

| 凭据 | 用途 |
|---|---|
| `DATABASE_URL` / `DATABASE_USER` / `DATABASE_PASSWORD` | MySQL 连接（**等价名**：`SPRING_DATASOURCE_URL` / `SPRING_DATASOURCE_USERNAME` / `SPRING_DATASOURCE_PASSWORD`；两组等价，填任一套即可，都填时以前者为准） |
| `JWT_SECRET` | **学生端** JWT 签名 |
| `ADMIN_JWT_SECRET` | **运营端** JWT 签名 —— **与学生端分离**（变量名与根 `README.md` 的「快速开始」一致） |
| `JWT_TTL_SECONDS` | 学生端 / 运营端 JWT 有效期（秒，**缺省 `604800` = 7 天**） |
| `APP_ENV` | 运行模式：`dev` / `development` / `local` ⇒ 非生产；`prod` / `production` / **留空** ⇒ 生产（决定接口文档是否注册，见 §二） |
| `WECHAT_APPID` / `WECHAT_SECRET` | `wx.login` 换取 openid |
| `COS_BUCKET` / `COS_REGION` / `COS_SECRET_ID` / `COS_SECRET_KEY` | 运营端图片转存 |
| `COS_DOMAIN` | 图片**访问域名** —— 出参恒**绝对 URL**；🔴 **所有环境必填**，缺失时服务**拒绝启动**（见 `app/core/config.py` 的 `require_cos_domain`） |
| `CORS_ALLOW_ORIGINS` | 运营端浏览器直连的跨域白名单（口径见 §二；**注意拼写：`ORIGINS`，无 `ED`**） |

🔴 **启动预检（fail-fast）**：生产模式下 `JWT_SECRET` / `ADMIN_JWT_SECRET` **缺任一**、或**两者取值相同**（学生 token 可冒充运营端，见 [S-01](./S-01-身份与凭证.md)）⇒ 服务**拒绝启动** —— 与 `COS_DOMAIN` 同口径（`app/main.py` 的 `_preflight`）。dev 模式降级为错误日志不阻断。`CORS_ALLOW_ORIGINS=*` 时生产启动打**告警**（不阻断）。

🔴 **凭据纪律**：**不得**写入任何 `docs/` 文档、代码注释、commit message —— 只经**环境变量**与 `server/.env`（已 `.gitignore`）流转。

## 二、部署边界

| 项 | 口径 |
|---|---|
| 平台 | 微信云托管，**单容器** |
| 服务基路径 | **根路径**（**无版本段**）—— 端点路径见 [`api/`](../api/README.md)。小程序端默认走**云调用**（`VITE_TCB_ENV`，免域名白名单），未配置时回退 `VITE_API_BASE_URL` 直连域名；运营端走 `web/.env.*` 的 `VITE_API_BASE_URL` |
| 容器端口 | 监听平台注入的 `$PORT`，未注入时回退 **`8080`** —— 🔴 必须与云托管服务的**探活端口**一致，否则容器虽启动仍判 `connection refused`（见 `server/Dockerfile`） |
| 跨域（CORS） | 运营端在浏览器直连本服务 ⇒ 需放行跨域：`CORS_ALLOW_ORIGINS`（`*` 或逗号分隔白名单）；**不使用 Cookie**（凭证走 `Authorization` 头），故 `allow_credentials=false` |
| 进程模型 | **单 worker（uvicorn 单进程，CMD 显式 `--workers 1`）** —— 限频依赖进程内计数（见 [S-03](./S-03-限频与接口防护.md)）；满足 [S-03](./S-03-限频与接口防护.md) §三 任一触发条件时才引入共享存储 |
| 容器用户 | 镜像内以**低权用户** `appuser`（uid 10001）运行 —— **非 root**；`tzdata` 兑现 `TZ=Asia/Shanghai`（slim 镜像默认无时区数据，缺失则时间戳回落 UTC） |
| 信任的代理 | uvicorn 以 `--proxy-headers --forwarded-allow-ips=*` 启动：信任**平台反代**注入的 `X-Forwarded-For`（仅影响访问日志与 `request.client`）。限频 `client_ip` 另取 XFF 首段 —— 残余风险：XFF 首段可被端上伪造，**只影响限频粒度**（不涉及鉴权：身份一律来自凭证解析，见 [S-02](./S-02-鉴权与归属校验.md)） |
| 网络 | **无 IP 白名单、无安全组** —— 🔴 **平台不支持**（仅「公网 / 内网」开关）；且校园网出口 IP 共享，白名单会退化为「全校可访问」。**勿重复尝试** |
| 运维端点 | 只暴露探活 `GET /healthz`；**不暴露** `env` / `beans` / `heapdump` 之类 |
| 接口文档 | `/docs` 与 `/openapi.json` **仅在非生产模式注册**（`APP_ENV` 取 `dev` / `development` / `local`；生产含**缺省** ⇒ 两者均为 `404`）—— 契约刷新走本地 `dev` 实例，生产不对外给出端点清单 |
| 限频状态存储 | 见 [S-03](./S-03-限频与接口防护.md) —— **一旦扩到 ≥2 实例，必须下沉共享存储** |

## 三、信息暴露基线

| 项 | 口径 |
|---|---|
| 统一响应 | 失败只回 `code` + 可展示文案 —— **不回**栈信息 / SQL / 内部异常类名；原生 **404 / 405 也归一**为信封（`4001` / `400`）——「HTTP 恒 200」无例外。未捕获异常由边缘中间件兜底：服务端 `logger.exception` 记路径 + 堆栈，端上只收 `500` 信封（响应仍经跨域 / 压缩中间件） |
| 请求体上限 | **6MB**（图片 multipart 5MB + 边界预留）：`Content-Length` 预检、超限即 `400`、**不读体**；顺序上**先限频再拒体**（超大请求照样消耗 IP 配额，无法借大包绕过限频）。无 `Content-Length` 的分块传输不在预检范围 |
| 安全响应头 | 全部响应 `X-Content-Type-Options: nosniff` + `Cache-Control: no-store`；≥500B 响应 GZip 压缩（最外层中间件，连兜底响应一并覆盖） |
| 参数校验 | **全部入参服务端校验**；非法 ⇒ `400`，**不静默降级** —— 含**未声明字段**（入参模型拒绝额外字段，`userId` / `openid` 一类即落在此处，见 [S-02](./S-02-鉴权与归属校验.md)） |
| 排序 / 分页参数 | 白名单校验（`canteenId` 非法 ⇒ `400`）；`pageSize` 封顶 **50** |
| 运营端点 | `/admin/**` 一律需 bearer；缺失 ⇒ `401`（**唯一免鉴权例外**：换凭证的 `POST /admin/sessions`） |
| 库结构 | 结构真源在 [`schema/`](../schema/README.md) —— 端点出参只给端上需要的列（见 [S-02](./S-02-鉴权与归属校验.md) 的出参最小化） |

## 四、本项目**不引入**的安全能力（防回退）

| 能力 | 原因 |
|---|---|
| 内容安全机审（文本 / 图片） | 学生侧**零自由输入**（只有选项与评分数字） |
| 用户认证 / 角色 / 权限分级 | 学生端只有一种身份；运营端单管理员无分级 |
| 操作日志 / 审计表 | 无对应需求（处置只用一个 `handled_at` 时间戳） |
| IP 白名单 / 安全组 | 平台不支持 |
| 凭证吊销通道 | 无注销、无用户管理 ⇒ 无吊销场景 |
