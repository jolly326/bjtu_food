# S-04 · 凭据与部署边界

> 返回：[安全总览](./README.md)

## 一、凭据清单（一律环境变量）

| 凭据 | 用途 |
|---|---|
| `DATABASE_URL` / `DATABASE_USER` / `DATABASE_PASSWORD` | MySQL 连接 |
| `JWT_SECRET` | **学生端** JWT 签名 |
| （独立 secret） | **运营端** JWT 签名 —— **与学生端分离** |
| `WECHAT_APPID` / `WECHAT_SECRET` | `wx.login` 换取 openid |
| COS 凭据 | 运营端图片转存 |

🔴 **凭据纪律**：**不得**写入任何 `docs/` 文档、代码注释、commit message —— 只经**环境变量**与 `server/.env`（已 `.gitignore`）流转。

## 二、部署边界

| 项 | 口径 |
|---|---|
| 平台 | 微信云托管，**单容器** |
| 进程模型 | **单 worker（uvicorn 单进程）** —— 限频依赖进程内计数（见 [S-03](./S-03-限频与接口防护.md)）；满足 [S-03](./S-03-限频与接口防护.md) §三 任一触发条件时才引入共享存储 |
| 网络 | **无 IP 白名单、无安全组** —— 🔴 **平台不支持**（仅「公网 / 内网」开关）；且校园网出口 IP 共享，白名单会退化为「全校可访问」。**勿重复尝试** |
| 运维端点 | 只暴露探活 / 指标；**不暴露** `env` / `beans` / `heapdump` 之类 |
| 限频状态存储 | 见 [S-03](./S-03-限频与接口防护.md) —— **一旦扩到 ≥2 实例，必须下沉共享存储** |

## 三、信息暴露基线

| 项 | 口径 |
|---|---|
| 统一响应 | 失败只回 `code` + 可展示文案 —— **不回**栈信息 / SQL / 内部异常类名 |
| 参数校验 | **全部入参服务端校验**；非法 ⇒ `400`，**不静默降级** |
| 排序 / 分页参数 | 白名单校验（`canteenId` 非法 ⇒ `400`）；`pageSize` 封顶 **50** |
| 运营端点 | `/admin/**` 一律需 bearer；缺失 ⇒ `401` |
| 库结构 | 结构真源在 [`schema/`](../schema/README.md) —— 端点出参只给端上需要的列（见 [S-02](./S-02-鉴权与归属校验.md) 的出参最小化） |

## 四、本项目**不引入**的安全能力（防回退）

| 能力 | 原因 |
|---|---|
| 内容安全机审（文本 / 图片） | 学生侧**零自由输入**（只有选项与三态数字） |
| 用户认证 / 角色 / 权限分级 | 学生端只有一种身份；运营端单管理员无分级 |
| 操作日志 / 审计表 | 无对应需求（处置只用一个 `handled_at` 时间戳） |
| IP 白名单 / 安全组 | 平台不支持 |
| 凭证吊销通道 | 无注销、无用户管理 ⇒ 无吊销场景 |
