# 接口安全与越权防护

> **范围**：小程序端的身份链路、传输、对象级授权（IDOR）、参数与字段校验。
> **真源**：本文档。限频 / 机审 / 违规处置见 [滥用与内容防护](./滥用与内容防护.md)；跨端机制见 [`secur/server/通用防护机制.md`](../server/通用防护机制.md)。

## 1 · 身份与凭证

### 1.1 · 身份从哪来

```
小程序启动 → wx.login 取 code
  → POST /auth/wechat-login（服务端 code2Session）
  → 服务端取 openid，建号或查号 ⇒ 签发学生 JWT（含 userId）
  → 端上存 token，后续请求带 Authorization: Bearer <jwt>
```

| 项 | 口径 | 理由 |
|---|---|---|
| 身份权威 | **仅服务端 `code2Session`** | 客户端传入 openid 一律忽略（客户端不可信） |
| 凭证形态 | 学生 JWT，密钥 `JWT_SECRET`，**与管理端 `ADMIN_JWT_SECRET` 物理隔离** | 共用则学生 token 可冒充管理员 |
| 当前用户取值 | 一律 `SecurityUtil.getCurrentUserId()` | **禁信任前端传 `userId`** |
| 认证态判据 | `bindEmail` 非空，**实时查库、不进 JWT** | 解绑即刻生效，无需等 token 过期 |
| 密钥强度 | 启动时校验：缺失 / 短于 32 字节 / 命中开发默认值 ⇒ **启动失败**（fail-fast） | 弱密钥 = 可自签任意学生 token |

### 1.2 · 凭证存储（平台限制）

token 落 `uni.setStorageSync`（= `wx.setStorageSync`），按 App 沙箱隔离但**平台不提供加密存储**，亦无 `httpOnly` 等价机制。

**因此纵深放在服务端**：

| 措施 | 口径 |
|---|---|
| 短时效 | JWT 有效期按现行值，不长期有效 |
| **全局吊销** | `TokenBlacklist` 支持 **token 维度**与 **userId 维度**失效；触发点：① 注销账号（本人 / 管理员）② 账号被禁用（含违规累积达封禁档）③ 邮箱换绑（本人认证与管理员解绑）④ 管理员人工踢下线（`POST /admin/users/{id}/kick`） |
| 最小缓存 | 非必要的个人信息不长期落本地缓存（仅缓存展示用昵称 / 头像） |

> 🔴 **全局吊销是「发现异常 → 立即止损」的操作位**：能一键让某账号的所有端失效，不必等 token 自然过期。

### 1.3 · 传输

| 通道 | 口径 |
|---|---|
| 小程序 | `wx.cloud.callContainer` —— 微信内网加密链路，不受公网 / CORS 约束 |
| H5（本地联调） | 生产构建缺 API 基址即**拒绝启动**（fail-closed）；开发态允许 localhost |
| H5（对外发布） | **不发布** —— 明文 HTTP 回落会泄露 `Bearer` token，故生产一律 fail-closed |
| token 位置 | `Authorization` 请求头，**不进 URL / Query**（避免被日志与 Referer 记录） |

## 2 · 对象级授权（IDOR 防护）—— 主要威胁面

**攻击形态**：攻击者用**自己的合法 token**，篡改路径 / 请求体里的 `{id}` / `{reviewId}` / `userId`，去读或改**别人的资源**。这是校园攻击者最先尝试的路径。

### 2.1 · 判定口径（硬约束）

| # | 约束 |
|---|---|
| 1 | 资源归属判据 = **查询资源的 `user_id` 与 `SecurityUtil.getCurrentUserId()` 相等**，不得依赖请求体传入的 userId |
| 2 | 归属不符 ⇒ **`403`**，回统一文案「无权操作」（**不区分**「不存在」与「无权限」的措辞差异，避免探测） |
| 3 | 写操作以 **JWT 内 userId** 建立归属（如「我的评价」按 `userId + dishId` 锁定行），**从设计上无法写到他人行** |
| 4 | **不提供批量写端点**；若将来出现，须**逐项**校验归属 |

### 2.2 · 归属校验矩阵（逐个写端点核对）

| 端点 | 归属判定 | 位置 |
|---|---|---|
| `DELETE /reviews/{id}` | ✅ `review.user_id == 当前 userId` | `ReviewServiceImpl` |
| `POST /dishes/{id}/reviews` | ✅ 按 `userId + dishId` 锁定/覆盖，写不到他人行 | `ReviewServiceImpl` |
| `PUT /my/notifications/{id}/read` | ✅ `notification.user_id == 当前 userId` | `NotificationServiceImpl` |
| `PUT /auth/profile` | ✅ 只操作自身 | `AuthController` |
| `DELETE /auth/account` | ✅ 只操作自身 | `AuthController` |
| `POST /feedback` · `POST /dishes/{id}/correction` · `POST /reviews/{id}/report` | 仅建单、无「他人资源」语义；`userId` 取当前登录态（匿名提交记 `0`） | 各 Controller |

> **核对结论**：学生端全部按 `{id}` 操作的写端点**均已具备归属校验**，无缺口。防回退约束：**新增任何带 `{id}` 的写端点，必须同步补归属校验并登记进本表**。

## 3 · 参数与字段校验

| 层 | 口径 |
|---|---|
| DTO 约束 | 全部写端点入参 `@Valid` + 长度 / 范围 / 枚举白名单约束（`@Size` / `@Min` / `@Max` / `@Pattern` / `@NotBlank` / `@Positive`） |
| **拒绝未声明字段** | **写端点 DTO 一律拒绝请求体中的未声明字段**（请求体多一个字段 ⇒ `400`）。防「字段注入」试探：攻击者塞入 `userId` / `status` / `isAdmin` 等，试探服务端是否误把 body 当权威值 |
| 类型严格 | 不开启全局「忽略未知字段」的宽松反序列化；读端点不受此约束 |
| 枚举闭合 | 状态类字段只接受白名单取值，**拒绝未声明枚举键** |
| 分页参数 | 学生端 `pageSize` 上限 **50**，超限服务端截断（见 [滥用与内容防护](./滥用与内容防护.md) §2） |
| 数值语义 | 金额一律「分」，评分 `DECIMAL` —— 越界 / 溢出在 DTO 层拦下 |

> 📌 **契约同步**：端上类型由后端 VO 经 SpringDoc 导出（`client/openapi.json` + `api.d.ts`），并在门禁中校验一致性 —— 因此「拒绝未声明字段」不会与端上现实请求冲突。

## 4 · 设计边界：不做请求级签名

**不做** `timestamp + nonce + HMAC` 一类的请求级签名 / 防重放：

| 理由 | 说明 |
|---|---|
| 密钥必随包分发 | 签名密钥必须分发到客户端，反编译即得 ⇒ 对「懂逆向的对手」**不构成真防护**，只是提高门槛 |
| 真实风险位已被覆盖 | 参数篡改由服务端校验（§3）与归属校验（§2）兜底；重放对写操作由**限频**压制（见 [滥用与内容防护](./滥用与内容防护.md)） |
| 成本收益不匹配 | 每请求多一次签名计算 + nonce 存储，换来的边际安全极低 |

**触发重评的条件**：出现「重放导致实际损失」的事故。

## 5 · 危险访问路径：识别 / 拦截 / 响应

| 路径 | 识别 | 拦截 | 响应 |
|---|---|---|---|
| **IDOR**（篡改 id 操作他人资源） | 归属校验不通过 | `403`（统一「无权操作」） | 审计 + 账号违规累积标记 |
| **越权读**（读他人资料 / 通知） | 归属校验 / VO 白名单 | `403` / `4001`（不区分不存在与无权限） | 审计（高频则告警） |
| **参数篡改 / 字段注入** | DTO 约束 + 拒绝未声明字段 | `400` | 高频异常 ⇒ 审计 + 告警 |
| **JWT 伪造 / 改签** | 签名校验失败 | `401`（fail-closed） | 审计 + 源 IP 标记 |
| **JWT 盗用 / 重放** | 黑名单（token / userId 维度） | `401` + 全局吊销 | 审计 + 告警 |
| **身份自述**（请求体传 `userId` / openid） | 服务端只认 JWT 与 `code2Session` 结果 | 忽略 / `400` | — |
