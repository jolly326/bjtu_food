# secur/client — 小程序端安全设计

> **范围**：学生端（微信小程序 `client/`）的**身份链路、越权防护、参数校验、滥用与内容防护** —— 即威胁模型中的 **Zone B**。
> **性质**：小程序端**安全设计真源**。业务口径见 [`func/client/`](../../func/client/README.md)，页面形态见 [`ui/client/`](../../ui/client/README.md)，接口契约见 [`api/`](../../api/README.md)，库表见 [`schema/`](../../schema/README.md)。
> **总览与跨端矩阵**见 [`secur/README.md`](../README.md)；后端通用机制见 [`secur/server/`](../server/README.md)；管理端见 [`secur/web/`](../web/README.md)。

## 1 · 设计前提

| 前提 | 含义 |
|---|---|
| **客户端不可信** | 小程序包可被反编译 —— 请求结构、字段名、枚举值全部暴露。任何「前端隐藏」都不算防护 |
| **网络不可信** | 非微信链路（H5 / 抓包代理）流量可被观察与重放 |
| **用户身份不可信** | 攻击者可自己走一遍静默登录拿到合法 JWT，再用合法身份尝试越权 |
| **openid 不可信** | 仅服务端 `code2Session` 换取可信；客户端传入的任何 openid 一律忽略 |

⇒ **一切鉴权、授权、参数校验、归属判定都在服务端强制，且假设客户端会发送任意构造的请求。**

## 3 · 端侧安全基线（反向证据）

| 维度 | 结论 | 证据 |
|---|---|---|
| 传输链路 | 走 `wx.cloud.callContainer`（微信内网加密链路），token 在 `Authorization` 头而非 URL | `client/src/api/http.ts` |
| H5 回落 | 生产构建缺 `VITE_API_BASE_URL` 即拒绝启动（**fail-closed**，杜绝明文 HTTP 传 token） | `client/src/api/config.ts` |
| 身份来源 | openid 仅服务端 `code2Session` 换取，客户端从不存储明文 openid | `client/src/stores/user.ts` |
| 密码体系 | **无账号密码体系** —— 打开即静默登录，无登录页、无口令可泄露 | `func/client/README.md` |
| XSS | 全站 Vue `{{ }}` 自动转义，无 `v-html` / `eval` / 危险 `innerHTML`（唯一 `v-html` 在 `AppIcon`，源为内部常量） | client 全仓扫描 |
| 硬编码密钥 | 前端产物内**零密钥** —— 全部凭据由后端经环境变量持有 | client 全仓扫描 |
| 隐私 | 不采集定位 / 设备号；不采集与业务无关的个人信息 | `manifest.json` |
| 文件上传 | 扩展名白名单 + 魔法字节 + 5MB + 4000×4000 像素上限 + UUID 文件名（无路径穿越）+ 云端 `imgSecCheck` | `UploadServiceImpl`（见 [`secur/server/通用防护机制.md`](../server/通用防护机制.md)） |

## 4 · 残余风险（平台限制决定，明确记录而非假装不存在）

| # | 风险 | 为何暂不消除 |
|---|---|---|
| C-R1 | **token 明文落本地存储**（`uni.setStorageSync` 无加密、无 `httpOnly` 等价物） | 微信小程序平台限制；未越狱 / 未导出备份的设备上泄露面有限。缓解 = 短时效 + **全局吊销**（见 [接口安全与越权防护](./接口安全与越权防护.md) §5） |
| C-R2 | **限频与吊销计数为进程内实现**，多实例下各自计数 | 单容器云托管，重启清零可接受；**扩到 ≥2 实例前必须下沉 Redis**（见 [`secur/server/通用防护机制.md`](../server/通用防护机制.md)） |
| C-R3 | **机审对「疑似（`review`）」一律放行** | UGC 治理闭环口径：微信全量检测 + 举报兜底，MVP 内容量小；出事或量级增长后重评 |
| C-R5 | **UGC 正文草稿明文落本地存储** | 属用户自身设备上的本人草稿，暴露面低；提交成功后即清理草稿。接受现状 |

## 5 · 阅读约定

- 每篇**基准节序**：**机制 → 危险路径（识别 / 拦截 / 响应）→ 与当前代码的差异**（清零写「无」）。
- **不写落地状态**（「待实现 / 已落地」一律不写）；设计已定而代码未同步的条目，集中登记在文末「与当前代码的差异」。
- **不复述契约与库表**：端点 / 字段以 [`api/`](../../api/README.md) 为准，列定义以 [`schema/`](../../schema/README.md) 为准，本文只写**安全机制与判定口径**。
