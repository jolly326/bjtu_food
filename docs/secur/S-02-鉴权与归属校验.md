# S-02 · 鉴权与归属校验

> 返回：[安全总览](./README.md)

## 端上不传身份（红线）

- 全部接口的身份一律来自**服务端从凭证解析**（见 [S-01](./S-01-身份与凭证.md)）。
- **请求体 / query 一律不接受** `userId` / `openid` 一类用户标识字段 —— 收到即视为**参数非法**。
- 归属类端点（`/my/**`）**只操作当前凭证对应的数据**。

## 归属校验口径

| 场景 | 处置 |
|---|---|
| 操作**非本人**的记录（`PATCH` / `DELETE /my/records/{id}`） | **`4001`「资源不存在」** |
| 操作**不存在**的记录 | 同上 —— **两者同一响应** |
| 🔴 意图 | **不暴露他人数据是否存在**（避免"ID 枚举探测"） |
| 越权尝试的留痕 | **不落库**（无审计表）—— 与「管理端不做操作日志」同一口径 |

## 出参最小化

| 规则 | 说明 |
|---|---|
| 学生端出参**不含** `userId` / `openid` | 端上不需要——身份只用于服务端归属 |
| 学生端出参**含** `dishId` 与本记录的 `id` | 端上需要它们做后续 `PATCH` / `DELETE`（它们是**本人数据**的标识，不构成跨用户暴露） |
| 「我的食谱」只返回**本人**记录 | 见 [`api/client/records.md`](../api/client/records.md) |
| 运营端出参**不含**用户标识 | 全匿名（见 [`api/web/records.md`](../api/web/records.md)） |
| 学生端内容端点不返回任何用户数据 | 海报 / 推荐 / 字典均为纯内容（**同样要求凭证**，无「公开端点」态） |

## 鉴权矩阵

🔴 **学生端所有业务端点统一要求凭证** —— 海报 / 推荐 / 字典等**内容端点同样需学生凭证**，没有「公开端点」这一态。

| 端点组 | 要求 | 未满足 |
|---|---|---|
| `POST /auth/wechat-login` | 🔓 公开（**唯一例外**：换凭证本身不能要求凭证） | — |
| 学生端其余全部端点（`/posters` · `/canteens` · `/dishes` · `/dish-issue-options` · `/my/**` · `POST /dishes/{id}/issues`） | 🔑 需携带学生端凭证 | `401` |
| `POST /my/records` · `PATCH` / `DELETE /my/records/{id}` | 🔑 凭证 **+ 归属校验** | `401` / `4001` |
| `/admin/**`（除 `POST /admin/sessions`） | 🔑 运营端 bearer（**独立 secret**） | `401` |
