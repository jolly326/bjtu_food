# dish_issue_option — 菜品纠错选项字典

**用途**：菜品纠错（[`dish_issue.option_id`](./dish_issue.md)）的**选项文案真源** —— 改文案全站生效、增删选项**免发版**。

## 列定义

| 列 | 类型 | 可空 | 默认 | 键 | 说明 |
|---|---|---|---|---|---|
| `id` | BIGINT | NO | AUTO_INCREMENT | PK | 选项 ID（端上回传 `optionId`） |
| `name` | VARCHAR(32) | NO | `''` | | 选项文案（如「信息错误」） |
| `updated_at` | DATETIME | NO | `CURRENT_TIMESTAMP ON UPDATE` | | 更新时间（管理端出参） |

## 索引

| 索引名 | 列 | 类型 | 用途 |
|---|---|---|---|
| `PRIMARY` | `id` | 主键 | — |

> **无排序列** —— 选项顺序一律按 `id` 升序。
> **无启停列** —— 选项集合即有效集合；下线一个选项 = **删除该行**（仅当无提交记录引用）。

## 关键设计

- **文案锚在 ID**：`dish_issue.option_id` 引用本表 ⇒ 改名免费（含历史提交的中文翻译），零数据迁移。
- **被引用即禁删**（应用层计数拦截）；无引用时可删除。
- 端上只读端点下发**全部选项**（按 `id` 升序）；端上零硬编码、不排序。

## 种子（3 条）

| `name` | 覆盖范围 | 运营的后续动作 |
|---|---|---|
| 信息错误 | 菜名 / 位置 | 改 `dish.name` / `dish.stall_id`（或档口资料） |
| 图片不对 | 菜品大图 | 换 `dish.image` |
| 已停售关闭 | 菜品下架 / 档口关闭 | 改 `dish.status = 'off'`（或档口停用） |

> 以远程库实况为准：字典即有效集合，**行数 = 端上可见项数**；下线一项 = 删除该行（仅当无提交记录引用）。

## 关联

| 方向 | 目标表 | 关系 |
|---|---|---|
| 1→n | `dish_issue.option_id` | 被提交记录引用（**外键 `fk_issue_option`**，无级联） |

## 注意事项

- 管理端可达：选项文案（**可改**）+ 引用次数与更新时间（只读）。
