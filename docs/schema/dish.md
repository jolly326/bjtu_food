# dish — 菜品

**用途**：菜品主体 —— 美味页卡片的取数来源（大图 / 名称 / 价格 / 位置 / 评价分）。

## 列定义

| 列 | 类型 | 可空 | 默认 | 键 | 说明 |
|---|---|---|---|---|---|
| `id` | BIGINT | NO | AUTO_INCREMENT | PK | 菜品 ID |
| `stall_id` | BIGINT | NO | 无 | KEY | 所属档口；**必填、无默认值**（卡片必须能显示位置） |
| `name` | VARCHAR(64) | NO | `''` | | 菜品名称 |
| `price` | INT | NO | 0 | | **现价，单位「分」**；唯一价格数据源 |
| `image` | VARCHAR(255) | YES | NULL | | **菜品大图**（相对路径，**单张**） |
| `status` | VARCHAR(32) | NO | `'on'` | KEY | 上架状态：`on` 在售 / `off` 已下架 |
| `avg_reaction` | DECIMAL(3,1) | YES | NULL | | **评价分缓存列**：`5`/`3`/`1` 三态的算术均值，1 位小数；**零评分为 NULL**（列注释同此口径） |
| `reaction_count` | INT | NO | 0 | | **缓存列**，**投票用户数**（一人一菜一票，去重后人数） |
| `updated_at` | DATETIME | NO | `CURRENT_TIMESTAMP ON UPDATE` | | 更新时间（管理端列表出参） |

## 索引

| 索引名 | 列 | 类型 | 用途 |
|---|---|---|---|
| `PRIMARY` | `id` | 主键 | — |
| `idx_dish_stall` | `stall_id` | 普通 | 按档口取菜品（管理端）与位置联表 |
| `idx_dish_status` | `status` | 普通 | 公开列表「只查在售」的过滤（`WHERE status='on'`） |

## 关键设计

### 推荐流的排序 = 加权随机（按评价分取权重）

- 卡片按**加权随机**下发，权重取自 `avg_reaction`（评价越好越易出现）；**零评分菜按基线权重参与**，不因缺失而获得高分。
- 排序是**计算式**（非索引可加速），不为其建索引 —— 当前菜品量级下代价可忽略。

### 评价分缓存列（物化）

**`avg_reaction` / `reaction_count` 是缓存列，不是权威数据。**

| 项 | 说明 |
|---|---|
| 口径 | 🔴 **聚合真源 = [dish_rating](./dish_rating.md)（一人一菜一行）** —— 天然一人一票；三态取值 `5` / `3` / `1` 的算术均值，**1 位小数**（`ROUND(AVG(reaction), 1)`）；`reaction_count` = 评分表行数（= 投票人数） |
| 维护方 | 评分提交后**同事务同步重算**（`app/student/record/recalc.py::recalc`） |
| 零评分 | **`avg_reaction` 为 NULL 而非 0** —— 区分「无评分」与「评分为 0」（后者不可能，取值域 5/3/1，均值恒 ≥ 1.0） |
| 展示 | 端上按**群体风味评级**展示（见 [B2](../func/client/B-轻量反馈/B2-评分反馈.md)）；`NULL` 或**投票人数** < 3 ⇒「待评」；**不得兜底成任何数值**（兜底值会污染推荐权重） |

🔴 **对账纪律**：在线重算只在**应用写路径**（评分 / 清除评价）触发；**任何直连库改或删 `dish_rating` 评分的操作都必须同时重算受影响菜品** —— 否则用户会在卡片上直接看到错误评价分，而系统不报错、无告警。**删除饮食记录不在此列**（流水与口碑解耦，删记忆不撤票）。

### 不设的列（零消费即删）

| 列 | 为何不设 |
|---|---|
| `description` | 无菜品详情页，卡片不展示 |
| `attributes` | 无详情页、无属性筛选；描述维度体系整体不引入 |
| `category_id` | 筛选维度只有**食堂**，无菜品种类 |
| `images`（多图） | 卡片只需一张大图 |
| `original_price` | 卡片只显示现价，无折扣展示 |
| 风味评级 / 好评度 | 由 `avg_reaction` + `reaction_count` 实时判定（公式见 [B2](../func/client/B-轻量反馈/B2-评分反馈.md)），不落库 |

## 关联

| 方向 | 目标表 | 关系 | 级联 |
|---|---|---|---|
| N→1 | `stall.id` | 所属档口 | **无外键** |
| 1→n | `dish_rating.dish_id` | 该菜品的**评分**（口碑真源） | 见 [dish_rating.md](./dish_rating.md) |
| 1→n | `dish_record.dish_id` | 该菜品的饮食记录（流水；🔴 引用即禁删） | 见 [dish_record.md](./dish_record.md) |

## 注意事项

- `image` 存**相对路径**，出参经路径工具转绝对 URL。
- `status = 'off'`（下架）对公开接口**等价于不存在**。
- `name` 在**同一档口下**的唯一性由**应用层**保证（无 DB 唯一索引）。
- 无「售罄 / 今日供应」状态（一期不做）。
