## 项目约定与红线

> **效力**：任何新功能 / 改动若与本节冲突，**必须先修订本节（重新拍板）再动代码**。

### 产品形态（防跑偏）

- **一句话**：校园菜品展示与轻量反馈平台 —— 帮学生解决「今天吃什么」。
- **单页全屏沉浸**：无 TabBar、无全局顶栏（AppHeader 隐去）、无页标题；仅一个「美食地图」页。菜品以圆角正方形大图随机散布在可平移 + 双指缩放的 2D 平面上；点击磁贴唤起底部弹窗看详情、点赞与纠错。
- **无搜索**；**无「我的」页面**；**无菜品详情页（路由页）** —— 单品信息经底部弹窗（Sheet）承载，不新增独立路由页。
- **全匿名**：不做注册 / 登录 / 认证 / 注销；身份由微信 openid 静默识别，**不在任何界面展示**。
- **无文字与图片 UGC**：学生侧只有「点赞」「菜品纠错选项」两类动作 ⇒ **不送内容安全检测**。
- **无分享、无社区、无收藏**。

### 身份与鉴权

- 冷启动 `wx.login` 静默换取 openid → 服务端建 / 取用户行 → **下发凭证**（端上缓存 7 天）；**端上只带凭证、不传 openid**。
- 🔴 **所有端点统一要求凭证**（唯一例外是换凭证的 `POST /auth/wechat-login` 本身）—— **没有「公开端点」这一态**。
- **无权限分级**：身份只用于「归属本人数据」与频控。

### 点赞口径

- **两态点赞**（抖音式）：每用户每菜**仅可点赞一次**，再次点击 = **取消点赞**（toggle）；不区分程度。
- **点赞真源** = [`dish_rating`](../schema/dish_rating.md)（UNIQUE(user_id, dish_id) 单行，`liked` 布尔：`1` = 已赞 / `0` = 已取消）。
- **群体指标 = 点赞数** = `COUNT(liked = 1)`；菜品磁贴 / 弹窗展示该数值，**不设等级、五档、状态**。
- 🔴 **零点赞**：展示「0」或「暂无」，**不得兜底成非零值** —— 兜底会凭空抬高热度并污染排序。
- **粒度**：一人一菜一行；改赞 = 覆盖本行 `liked`；取消 = 置 `liked = 0`（保留行）；同事务重算 `dish` 点赞数缓存。
- **归属**：由当前静默识别的用户决定，**禁止信任端上标识**。
- **频控**：写入口限频（见 [`secur/S-03`](../secur/S-03-限频与接口防护.md)）。

### 合规与不做的事

- 🔴 **MP 后台必须配置《用户隐私保护指引》** —— 声明收集微信 openid（用于标识用户以保存点赞）。**未配置无法通过代码版本审核**（属填表，不是开发）。
- **不做**站内的隐私政策 / 用户协议页面，也不自绘授权弹窗 —— 协议文本由微信托管，如需展示用 `wx.openPrivacyContract()`。
- **不收集**手机号 / 邮箱 / 位置 / 相册 / 昵称头像；学生端**不调用任何需授权的隐私接口**（不出现授权弹窗）。
- **无账号体系**：不做注册、登录、认证、注销、密码。

### 数据库

库结构唯一真源 = [`schema/`](../schema/README.md)；变更**先改表文档**，再直连远程库执行，两者必须一致。

### UI 实现红线

- 事件统一 `@tap`（禁 `@click`）；按压反馈用 `background: var(--color-bg-soft)` / `opacity` 微降，禁 `transform: scale`。
- 颜色全走语义 token，禁裸 hex。
- 图片为空或加载失败一律走 `ImagePlaceholder`；图标统一 `AppIcon`，禁 emoji / 文本当图标。
