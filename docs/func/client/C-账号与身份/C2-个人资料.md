# C2 · 个人资料

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔑 需登录**（游客态可读 / 可改；未登录返回 401）
> 归属：**C 账号与身份**
> 返回：[功能总览](../README.md)

## 介绍

修改本人的**昵称**与**头像**，并读取当前账号资料（含认证状态）。**承载形态**：个人信息分为**查看**与**编辑**两段——① **查看**：由「我的主页」顶部**用户信息卡**承载（头像 / 昵称 / 副行；认证态副行 = 校园邮箱，游客态副行 = 「未完成校园认证」）；② **编辑**：**独立个人信息编辑页**，由信息卡上的「编辑个人信息」入口进入——**该入口仅认证态渲染**（编辑身份信息是认证态才具备的能力），故编辑页**仅认证态可达**（端点鉴权不变）。进编辑页以全局用户态回填；点保存调 `PUT /auth/profile`（`nickname` + `avatar`；昵称端上先行非空校验），成功后返回「我的主页」并由主页刷新信息卡；头像与 UGC 配图**同走一条上传链路**（`POST /upload/cloud-image`：内容安检 → 转存 COS），取回 COS 正式地址后再保存；昵称命中敏感内容或内容安检 `risky` → 400 提示、不保存。

> 接口 / 字段见 [api/auth.md](../../../api/client/auth.md)。

## 业务口径

| 项 | 口径 |
|---|---|
| **可编辑范围** | 仅 `nickname` / `avatar` 两项；`id` / `bindEmail` 为**只读展示项**，不参与入参 |
| **局部更新** | 未传字段不动，避免整行覆盖导致并发写丢失 |
| **头像地址限制** | 仅允许站内 `/images/`、`/uploads/` 相对路径，或**上传链路（`POST /upload/cloud-image`）产出的 COS 绝对地址** —— 防止头像沦为任意 URL 载体；**不接受 `cloud://` 等未经安检的形态** |
| **头像机审** | 与 UGC 配图同链路：图片过微信 `imgSecCheck` 并转存 COS；违规 → 400 不保存 |
| **昵称机审** | 变更时先过本地敏感词，再过微信 `msgSecCheck` v2（`scene=1` 资料场景）；`risky` → 400 不保存 |
| **可编辑性判定** | **仅认证态可进入编辑页** —— 编辑身份信息是认证态才具备的能力（入口在信息卡上，游客态不渲染） |

## 数据（落库）

| 表 / 列 | 变化 | 中文解释 |
|---|---|---|
| `user.nickname` | UPDATE（局部） | 新昵称（防敏感词 + 微信内容安检） |
| `user.avatar` | UPDATE（局部） | 新头像地址（站内相对路径，或经内容安检 + COS 转存的正式地址）|
