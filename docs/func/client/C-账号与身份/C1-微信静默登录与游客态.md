# C1 · 微信静默登录与游客态

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔓 公开**（免登录）
> 归属：**C 账号与身份**
> 返回：[功能总览](../README.md)

## 介绍

打开小程序即用，**无需注册、无登录页**。微信静默换取身份；未完成学号邮箱认证的用户即「游客」——可浏览、可搜索，但**不可写认证级 UGC**（写评价 / 重新评价 / 删除本人评价 / 查看「我的评价」）—— 举报 / 意见反馈 / 菜品问题反馈为**需登录**（静默登录后即具备，免邮箱认证）。启动时本地**有** token 仅调 `GET /auth/profile` 刷新资料（不换取新 token），**无** token 则 `wx.login` → `POST /auth/wechat-login` 静默建号；任意请求返回 401 时清本地态、自动静默重登并**自动重试原请求一次**（用户无感）。


> 接口 / 字段见 [api/auth.md](../../../api/client/auth.md)。

## 业务口径

| 项 | 口径 |
|---|---|
| **无感重登** | 任意请求收到 401 时清本地态、自动静默重登，并**自动重试原请求一次**（用户无感） |
| **启动逻辑** | 本地**有** token → 仅调 `GET /auth/profile` 刷新资料（不换新 token）；**无** token → `wx.login` + 静默建号 |
| **游客态能力** | 可浏览、可搜索；**不可写认证级 UGC**（写评价 / 重新评价 / 删除本人评价 / 查看「我的评价」）；**举报 / 意见反馈 / 菜品问题反馈可提交**（公开） |
| **认证判据** | `bindEmail` 非空即已认证；端上 `isVerified()` **单点派生**，页面 / 组件不得散写判空 |
| **邮箱单源** | `bindEmail` 是校园邮箱与认证状态的唯一来源，端上不做双源兜底 |
| **账号状态** | 禁用 / 注销在登录侧（400）与 UGC 写侧（403）拦截，端上不做分支渲染 |
| **`username` 不出参** | 学号 / 账号标识属服务端内部字段（保留在 `user` 表与 JWT 载荷供日志）—— 两处身份卡认证态副行统一渲染 `bindEmail`，按「零消费即删」移出出参 |
| **游客昵称** | 新建游客号默认「食客 + ID 尾 4 位」—— **游客态身份展示的真源**，端上不另行派生短标识 |

### 附：JWT 载荷（排障用，非业务出参）

| 字段 | 说明 |
|---|---|
| `userId` | 用户 ID（后端鉴权唯一依据，**禁止信任前端传来的 userId**） |
| `username` | 账号，仅用于日志 |
| `iat` / `exp` | 签发 / 过期时间（有效期 7 天） |

> ⚠️ **认证态不进 JWT**（后端按 `user.bind_email` 非空实时查库判定）；**不含角色**。

> ⚠️ **载荷是 base64url 编码，不是密文** —— 任何拿到 token 的人都能解出上述字段，故载荷里**不得放敏感信息**（openid、邮箱、手机号均不在其中）。签名只保证「改不了」，不保证「看不见」。

## 数据（落库）

建号流程对 **`user` 表同一行写两次**（同一事务内）：

| 步骤 | 操作 | 说明 |
|---|---|---|
| 1 | INSERT 新行 | 写入微信标识（**唯一**）、由微信标识派生的用户名、昵称先写占位值「食客新友」、状态置为活跃；邮箱绑定保持空即游客态；列定义见 [schema/user.md](../../../schema/user.md) |
| 2 | UPDATE 回填昵称 | 最终昵称含自增主键尾 4 位（「食客 + ID 尾 4 位」）；主键由 INSERT 生成、昵称列非空 ⇒ 只能先插占位值再回填 |

> **为什么必须两步**：`nickname` 非空约束 + 昵称依赖自增 id，两者无法在一条 INSERT 内同时确定。
>
> **原子性与幂等**：两步处于**同一事务**（`UserService.createWechatGuest` 抽为独立 Bean —— Spring 事务基于代理，同类自调用不生效；抽出后也可让远程 `code2Session` 调用留在事务之外）。回填前另判「昵称是否仍为占位值」，**避免覆盖任何已存在的用户昵称**；回填失败则事务回滚，不留下占位昵称的账号。
>
> 已有 openid 时只 SELECT 该行、不重复建号。

存储说明见 [schema/user.md](../../../schema/user.md)。
