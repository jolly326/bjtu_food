# 学生端约定与红线

> 本文件是**学生端（微信小程序）**的最高口径：功能文档的入口与全部红线（为什么 / 边界在哪）。
> **效力**：任何新功能 / 改动若与本文冲突，**必须先修订本文（重新拍板）再动代码**。
> 接口契约见 [`api/`](../../api/CONVENTIONS.md)，库表见 [`schema/`](../../schema/)，页面视觉见 [`ui/client/`](../../ui/client/)。

## 阅读约定

> 每份功能文档的基准节序为 **介绍 → 业务规则 → 数据（读写）**；接口与字段一律不复述，只留链接。
> 文档与代码的一致性由门禁脚本校验（`check:doc` / `check:contract`），故文档内**不另设**「与代码的差异」段。

## 项目约定与红线

### 产品形态（防跑偏）

- **一句话**：校园菜品推荐与反馈平台 —— 帮学生解决「今天吃什么」。
- **单页**：无 TabBar、无全局顶栏、无页标题；仅一个「菜品首页」。页面由 **页头**（品牌 + 日期 + 今天吃什么）· **1 列竖向滚动结果卡**（16:9 菜品图 + 菜名 + 食堂 / 楼层 / 档口 + 售价 + 描述）· **底部筛选与搜索 HUD** 三块构成；单品信息全部由卡面承载，页头之下直接是结果区。
- **卡片粒度**：一卡 = 一道菜的一个在售位置（菜品 × 位置）：图 / 描述 / 价格取自菜品本体，`食堂 · 楼层 · 档口` 取自位置；一道菜多位置即多张卡，同名不同档口是两道菜。
- **单一结果态**：首页即当前条件下的在售位置结果集。冷启动是无条件结果（全量在售），输入一句话是条件结果，清空回全量；布局与组件恒定，只有数据与文案变化。
- **一句话搜索**：输入一句话 ⇒ 语义匹配菜品，结果集整体替换（交叉淡入）；生效约束以 HUD 筛选行的约束 chip 呈现，可逐项取消。
- **无左右翻页 / 无「我的」页面 / 无菜品详情路由页** —— 单品信息由结果卡卡面承载；描述超长时在卡内展开全文。
- **不设下拉筛选器**：食堂 / 预算条件来源于 query 解析与 HUD 筛选行候选值；候选值在筛选行内就地替换、纵向换行，不横滑、不弹层、不遮挡。
- **规模闸门**：在售位置超过 60 条时评估分页 / 虚拟列表；出现分享 / 深链 / 收藏 / 评分 / 长 UGC 需求时才评估独立详情页。
- **UI 文档结构**：`docs/ui/client/` 与 `docs/ui/web/` 只放页面设计稿，页面稿自带本页视觉规格；视觉取值由 `client/src/theme/` 与 `web/src/styles/theme.css` 单点承载。
- **全匿名**：不做注册 / 登录 / 认证 / 注销；身份由微信 openid 静默识别，**不在任何界面展示**。
- **文本 UGC**：学生可提交产品 / 菜品文本反馈 ⇒ 🔴 正文必须过微信 `msgSecCheck`。
- **无分享、无社区、无收藏**。

### 身份与鉴权

- 冷启动 `wx.login` 静默换取 openid → 服务端建 / 取用户行 → **下发凭证**（端上**缓存 7 天**）；**端上只带契约、不传 openid**。
- 🔴 **所有端点统一要求凭证**（唯一例外是换凭证的 `POST /auth/wechat-login` 本身）—— **没有「公开端点」这一态**。
- **无权限分级**：身份只用于「归属本人数据」与频控。

### 反馈口径

- **两类**：产品反馈（针对小程序）与菜品反馈（针对某道菜），统一走 `POST /feedback`。
- **正文**：1–500 字纯文本；🔴 提交前过微信 `msgSecCheck`。
- **归属**：`user_id` 取自静默身份，**禁止端上传输**。
- **无回执**：提交后只给一次 Toast，不展示历史、不展示处理状态。
- **频控**：写入口限频（见 [`secur/S-03`](../../secur/S-03-限频与接口防护.md)）。

### 合规与不做的事

- 🔴 **MP 后台必须配置《用户隐私保护指引》** —— 声明收集微信 openid（用于标识用户以归属反馈）。**未配置无法通过代码版本审核**（属填表，不是开发）。
- **不做**站内的隐私政策 / 用户协议页面，也不自绘授权弹窗 —— 协议文本由微信托管，如需展示用 `wx.openPrivacyContract()`。
- **不收集**手机号 / 邮箱 / 位置 / 相册 / 昵称头像；学生端**不调用任何需授权的隐私接口**（不出现授权弹窗）。
- **无账号体系**：不做注册、登录、认证、注销、密码。

### 数据库

库结构唯一真源 = [`schema/`](../../schema/)；变更**先改表文档**，再直连远程库执行，两者必须一致。

### UI 实现红线

- 事件统一 `@tap`（禁 `@click`）；按压反馈用 `opacity` 微降，禁 `transform: scale`。
- 颜色全走语义 token，禁裸 hex；主色语义键 `--brand` 单一色相，仅用于主操作与选中态。
- 图片为空或加载失败一律走 `ImagePlaceholder`；图标统一 `AppIcon`，禁 emoji / 文本当图标。
