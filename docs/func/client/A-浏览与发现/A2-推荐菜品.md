> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔑 需登录
> 归属：**A 浏览与发现**
> 返回：[功能总览](../README.md)

## 介绍

核心 tab（**美食**）：**扑克式堆叠单卡**，一次只展示最上方一张，其下卡片露出边缘。手指**左滑或右滑**均可把最上方卡片划掉，下一张随即露出。

卡片展示 **大图 · 名称 · 风味评级 · 价格 · 位置**（食堂 / 档口）；卡片下方「**去品尝**」按钮将该菜加入[我的食谱](../B-轻量反馈/B1-品尝标记.md)。**全部信息在卡片上，无跳转、无详情页。**

> 接口 / 字段见 [`api/client/dishes.md`](../../../api/client/dishes.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| 在售过滤 | 只推荐在售菜品 |
| 排序 | **加权随机** —— 权重取自评价分（评价越高越易出现） |
| 划走 | 左滑 / 右滑均把顶部卡片划掉，两方向语义相同 |
| 划走后的处理 | **本会话内不再出现**（流末尾「重新浏览」除外）—— 纯端上内存，**不落库**（跳过只是浏览行为，不代表任何评价） |
| 去品尝 | 卡片下方按钮；点击后该菜进入「我的食谱」，按钮转为已标记态 |
| 食堂筛选 | **仅本页提供**（右上角下拉），见 [A3](./A3-食堂筛选.md) |
| 零评分菜 | 按**基线权重**参与（不给高分）—— 口径见 [B2](../B-轻量反馈/B2-评分反馈.md) |
| **流末尾** | 本批卡片**全部划完** ⇒ 卡片栈替换为「流末尾空态」，只给两个动作：**重新浏览** / **随机盲选**（形态见 [`ui/client/推荐菜品.md`](../../../ui/client/推荐菜品.md) §1） |
| 重新浏览 | **复用当前批次、按原顺序**从头再滑一遍；**不发请求**、不改变「去品尝」状态 |
| 随机盲选 | 重新 `GET /dishes` 取一批（沿用当前食堂筛选），**排除当前批次已出现的菜品 id**；若过滤后为空则退回未过滤结果。仍走**加权随机**（评价高者更易出现），无独立推荐池 |

## 数据（读取）

| 表 | 读什么 | 说明 |
|---|---|---|
| `dish` | 名称 / 价格 / 大图 / 风味评级 | 评级由 `avg_reaction` + `reaction_count` 派生，口径见 [B2](../B-轻量反馈/B2-评分反馈.md) |
| `stall` | 档口名 | 位置 |
| `canteen` | 食堂名 | 位置 |
