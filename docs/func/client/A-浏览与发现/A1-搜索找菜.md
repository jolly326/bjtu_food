# A1 · 搜索找菜

**目标**：学生输入一句话，系统匹配出符合的菜品；命中项留在网格，未命中项退场重排。

## 页面结构

| 区域 | 形态 |
|---|---|
| 上方视口 | **3 列竖向滚动**菜品图标网格：圆角矩形图标 + 下方菜名（仿手机首页 app） |
| 底部 dock | **仅搜索框**（常驻 HUD，不随网格滚动） |
| 详情 | 点击图标 ⇒ 在网格中插入**跨 3 列内联展开卡**（无遮罩），网格其余部分仍可滚动 / 点选 |

- 不做地图 / 平移 / 缩放 / 翻页；
- 不做点赞、不做主题切换、暂不做语音输入。

## 初始态

- 冷启动 `GET /dishes` 拿全量在售菜品，渲染图标网格；
- 每道菜的图标取 `imageUrl`，名称取 `name`；
- 图片缺失时用占位块。

## 搜索流程

```
用户在 dock 输入一句话 → 回车 / 点搜索
  → POST /dishes/recommend { query }
  → 返回 { dishes }
  → 网格重排：仅保留命中项
```

### 筛选动效

- 未命中图标：**缩放 + 淡出**退场；
- 命中图标：留在网格，由 CSS Grid `auto-flow` 自动重排填位；
- 不手写重排算法，不重新散落。

### 命中为空

网格区显示空状态：「没找到符合的菜，换个说法试试」，并提供「清空搜索」回到全量。

### 失败降级

- 请求失败 / 模型超时 ⇒ 展示「**稍后再试**」重试入口；
- 不把失败态渲染成「无结果」。

## 内联展开卡

- 点图标 ⇒ 在该图标所在行下方插入**跨 3 列**详情卡（整行），磁贴保留为锚点；无遮罩、无弹窗；
- 内容：菜品大图、名称、`description`、**售卖点列表**（食堂 · 楼层 · 档口 · 价格，逐项展示）；
- 展开后由 `DishGrid` 用 `scroll-into-view` 把卡片带入可视区；点另一图标切换、再点同一图标收起、卡片内「收起」也可收起；
- 展开卡内提供「**反馈这道菜**」入口（见 [B1](../B-轻量反馈/B1-文本反馈.md)）。

## 数据依赖

| 来源 | 用途 |
|---|---|
| `GET /dishes` | 初始全量网格 |
| `POST /dishes/recommend` | 一句话匹配 |
| `DishVO.locations` | 内联展开卡的多售卖点展示 |
