# A1 · 美食地图

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔑 需登录
> 归属：**A 浏览与发现**
> 返回：[功能总览](../约定与红线.md)

## 介绍

**美食地图** = 全站唯一页面（单页、全屏沉浸，无 TabBar / 顶栏 / 页标题）。

页面是一个 **2D 平面**：圆角正方形**菜品磁贴在规整网格上密铺**（固定行列、行间不错位；每次载入菜品随机映射到已确定的格子，格子结构不变）；支持**拖拽平移（带惯性）**与**双指捏合缩放**，边界为**软边界**（越界仍跟手、阻尼压缩、松手弹性回位）。**首屏落在世界几何中心**，用户进来就是随便浏览。

磁贴**纯图、无文字浮层**（无图走 `ImagePlaceholder`）。**点击磁贴**唤起底部弹窗（Sheet）承载详情、点赞与纠错；**无长按、无独立路由页**。

> 接口 / 字段见 [`api/client/dishes.md`](../../../api/client/dishes.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| 在售过滤 | 只展示在售（`activate = TRUE`）菜品 |
| 布局 | 🔴 **规整网格密铺**：固定行列逐行铺满、行与行不做水平错位；每次载入菜品随机映射到已确定的格子（结构不变、只换谁坐哪格）；🔴 **不做簇** —— 无主食区 / 甜品区、无食堂成簇、无食堂中心 / 固定锚位 / 权重；磁贴尺寸统一 |
| 卡片 | 磁贴**同尺寸、同层级、同圆角体系**；为菜品大图（纯图、无文字浮层），无图 ⇒ `ImagePlaceholder` |
| 平移 | 拖拽平移，**带惯性**（松手后按速度衰减） |
| 缩放 | 双指捏合**放大 / 缩小**；**软限位**（贴近上下限时缩放幅度被压缩） |
| 边界 | **软边界**：越过内容包围盒后画布仍跟手但位移被阻尼压缩（越界越深、跟手比例越低，超过上限几乎不动）；松手**弹性回位**（过冲缓动）后停住；惯性滑动到边界处逐渐衰减；🔴 不硬停、不瞬移回位 |
| 首屏 | 落在**世界几何中心**并收敛到合法边界（不跳、不重置） |
| 重新载入 | 菜品重新映射到格子 —— 格子结构恒为规整网格，位置不散乱 |
| 双主题 | 白天 / 夜间两套主题，页面根挂 `data-theme` 生效，选择本地持久化 |
| 点击 | 点磁贴 ⇒ 底部弹窗（详情 + 点赞 + 纠错）；**无长按** |
| 点赞 | 弹窗内两态点赞（抖音式），口径见 [B1](../B-轻量反馈/B1-点赞反馈.md) |
| 纠错 | 弹窗内提交，口径见 [B2](../B-轻量反馈/B2-菜品纠错.md) |
| 空态 | **不处理**（无 EmptyBlock） |
| 加载 | **进入即拉取** `GET /dishes`；不做下拉刷新 |
| 动效 | 尊重 `prefers-reduced-motion` |

## 数据（读取）

| 表 | 读什么 | 说明 |
|---|---|---|
| `dish` | 名称 / 大图 / 点赞数 / 个人点赞态 | 点赞数 = `COUNT(dish_rating.liked = 1)`，口径见 [B1](../B-轻量反馈/B1-点赞反馈.md) |
| `stall` | 档口名 | 位置（弹窗展示） |
| `canteen` | 食堂名 | 位置（弹窗展示）、筛选维度 |
