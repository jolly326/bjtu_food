# A1 · 美食地图

> 返回：[功能总览](../README.md)

## 介绍

**美食地图** = 全站唯一页面（单页、全屏沉浸，无 TabBar / 顶栏 / 页标题）。

页面是一个 **2D 平面**：菜品以**圆角正方形大图磁贴**在**错位方格**上密铺，支持**拖拽平移（带惯性）**与**双指捏合缩放（放大 / 缩小）**，越界**弹性停止**（rubber-band，边界外无菜品）。首屏**居中**。

磁贴**纯图、无文字浮层**（无图走 `ImagePlaceholder`）。**点击磁贴**唤起底部弹窗（Sheet）承载详情、点赞与纠错；**无长按、无独立路由页**。

> 接口 / 字段见 [`api/client/dishes.md`](../../../api/client/dishes.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| 在售过滤 | 只展示在售（`status = 'on'`）菜品 |
| 布局 | **错位方格密铺**：固定网格 + 奇偶行错位半格，**不做食堂成簇 / 食堂中心 / 固定锚位 / 权重**；每载入随机把菜品分配进固定格子 |
| 磁贴 | 圆角正方形菜品大图，**纯图无文字浮层**；无图 ⇒ `ImagePlaceholder` |
| 平移 | 拖拽平移，**带惯性**（松手后按速度衰减） |
| 缩放 | 双指捏合**放大 / 缩小**；缩放范围与阻尼由端上定 |
| 边界 | 内容包围盒外无菜品；越界**弹性停止**（rubber-band），不外溢 |
| 首屏 | **居中于世界几何中心** |
| 点击 | 点磁贴 ⇒ 底部弹窗（详情 + 点赞 + 纠错）；**无长按** |
| 点赞 | 弹窗内两态点赞（抖音式），口径见 [B2](../B-轻量反馈/B1-点赞反馈.md) |
| 纠错 | 弹窗内提交，口径见 [B2](../B-轻量反馈/B2-菜品纠错.md) |
| 空态 | **不处理**（无 EmptyBlock） |
| 刷新 | **进入即拉取**；不做下拉刷新 |
| 动效 | 尊重 `prefers-reduced-motion` |

## 数据（读取）

| 表 | 读什么 | 说明 |
|---|---|---|
| `dish` | 名称 / 大图 / 点赞数 / 个人点赞态 | 点赞数 = `COUNT(dish_rating.liked = 1)`，口径见 [B2](../B-轻量反馈/B1-点赞反馈.md) |
| `stall` | 档口名 | 位置（弹窗展示） |
| `canteen` | 食堂名 | 位置（弹窗展示） |
