# A3 · 食堂筛选

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔑 需登录
> 归属：**A 浏览与发现**
> 返回：[功能总览](../README.md)

## 介绍

**仅「推荐菜品」页**右上角提供食堂筛选（下拉控件）；切换食堂即重筛推荐流。

> 接口 / 字段见 [`api/client/canteens.md`](../../../api/client/canteens.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| 位置 | 推荐菜品页右上角，下拉控件 |
| 选项 | 食堂列表 + 「全部」（默认） |
| 生效范围 | **仅推荐菜品流**；海报页与我的食谱不受影响 |
| 切换后 | 推荐流按所选食堂重筛，卡片序列重掷（加权随机） |
| 记忆 | **不跨会话** —— 冷启动回到「全部」，选择不落库 |

## 数据（读取）

| 表 | 读什么 |
|---|---|
| `canteen` | 食堂列表（筛选项） |
| `stall` | 菜品与食堂的归属链路（经档口） |
