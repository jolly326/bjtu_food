## 介绍

**风物** tab：以**竖版海报**呈现各档口，一屏一张，左右滑动（可回看上一张）。

海报**承载全部信息** —— 档口名称 / 所属食堂 / 位置均在图上，页面**不叠加任何文本**；因此运营出图时必须把这三项画进海报。

> 接口 / 字段见 [`api/client/posters.md`](../../../api/client/posters.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| 取数 | **上架**的海报（`status = 'on'`）；一档口可多张，**不展示（`off`）的不出现** |
| 顺序 | **固定序** —— 按运营在「海报管理」排定的 `sort` 升序（同值按创建顺序）下发；**不随机、不重掷** |
| 滑动 | 左右滑动，连续顺滑；**可回看上一张** |
| 点击 | 无跳转、无点击行为 |
| 顶部问候 | 随时间变化的问候语（早 / 中 / 下午 / 晚四态），**不含姓名** |
| 海报比例 | **3:4**（竖版；素材一律按此出图） |
| 空集合 | 无任何海报 / 加载失败时，海报区渲染 **3 张占位卡**（同样可横向滑动，见 [`ui/client/风物.md`](../../../ui/client/风物.md) §4） |

## 数据（读取）

| 表 | 读什么 | 说明 |
|---|---|---|
| `poster` | `image`（相对路径）· `sort` · `status` | 只取 `status = 'on'`，按 `sort` 升序；列定义见 [schema/poster.md](../../../schema/poster.md) |
| `canteen` | — | 食堂名由海报图承载，不单独下发 |
