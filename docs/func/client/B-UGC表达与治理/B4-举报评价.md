# B4 · 举报评价

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔑 需登录**（静默登录后即可提交，无需邮箱认证）
> 归属：**B UGC 表达与治理**
> 返回：[功能总览](../README.md)

## 介绍

举报违规评价，交给管理员处置（隐藏或删除）。举报写入 `user_feedback`，是 `type=report` 的反馈记录。流程：评价卡三点菜单「举报评价」→ **底部弹出原因单选弹层**（选项实时取自后端字典，端上零硬编码）→ 点选原因 → 提交；成功后提示处理预期，管理员处理后举报人收到站内回执（**登录级，含游客**）。**不要求填写文本**——举报结论以结构化原因为准，管理员据此直接处置。

> 接口 / 字段见 [api/reviews.md](../../../api/client/reviews.md) · [api/upload.md](../../../api/client/upload.md)。

## 业务口径

| 项 | 口径 |
|---|---|
| **不要求文本** | 举报结论以**结构化原因**（`reasonId`）为准，管理员据此直接处置；`content` 仅作补充说明 |
| **原因字典** | 选项**实时取自后端**，端上**零硬编码**、不排序（展示顺序即服务端下发次序） |
| **配图为辅** | 佐证配图选填，须先经上传端点转存为 COS 地址 |
| **鉴权级别** | **需登录**（🔑）—— 写请求必须绑定账号，不要求邮箱认证 |
| **回执投递** | **有 `userId` 即投递** —— 静默登录的游客**同样收到**处理回执；仅**匿名提交**（`user_id = 0`）不投递 |

## 数据（落库）

| 表 | 变化 | 中文解释 |
|---|---|---|
| `user_feedback` | INSERT | 一条举报记录：归属用户（**匿名提交归属为 `0`**，后台显示为游客）、类型 = 举报、举报原因、内容 / 配图（可空）、关联对象 = 被举报评价、初始状态待处理；列定义见 [schema/user_feedback.md](../../../schema/user_feedback.md) |
| `notification` | 管理员处理后异步 INSERT | 投递处理回执（**有 `userId` 即投递**，含静默登录的游客）；不阻塞；列定义见 [schema/notification.md](../../../schema/notification.md) |
