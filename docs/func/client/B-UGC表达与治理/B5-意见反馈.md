# B5 · 意见反馈

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔑 需登录**（免邮箱认证）
> 归属：**B UGC 表达与治理**
> 返回：[功能总览](../README.md)

## 介绍

学生诉求提交入口：**一张表单、无页签**，反馈类型 **3 选 1**（`bug` / `suggestion` / `other`），字段固定一套 —— 具体描述 + 截图。

| 项 | 口径 |
|---|---|
| 反馈类型 | `bug`（程序功能Bug）/ `suggestion`（产品功能建议）/ `other`（其他相关问题）；**决定描述框占位文案** |
| 具体描述 | 必填；端上 ≤**600 字**（服务端上限 1000） |
| 截图 | 选填，**≤3 张**（端上 / 服务端一致） |
| 本地草稿 | 进页自动回填「类型 + 描述文本」（存储键 `feedback_draft`）；**图片不缓存**——草稿里的 COS 地址是临时转存结果，重进小程序可能已失效，缓存它只会让用户提交时报「图片地址不合法」；提交成功后清除草稿 |

入口：

- 「我的」页宫格「意见反馈」。

流程：选类型（占位随之切换）→ 填描述 → 可选截图（**≤3 张**）→ 提交。提交门禁：类型未选 / 描述为空即置灰（置灰点击 toast 缺失项）；提交中禁用防重复；成功 Toast「已提交，感谢反馈」+ 2 秒自动返回。处理结果经站内通知回执（**有 `userId` 即投递** —— 静默登录的游客同样收到；仅**匿名提交**（无 token，`user_id = 0`）不投递）。

> **与举报、菜品问题反馈的边界**：举报评价走独立端点 `POST /reviews/{id}/report`（见 [B4 举报评价](./B4-举报评价.md)），菜品问题反馈走 `POST /dishes/{id}/correction`（见 [B6 菜品问题反馈](./B6-菜品问题反馈.md)）——**均不在本页范围内**、不共用本端点。

> 接口 / 字段见 [api/feedback.md](../../../api/client/feedback.md)。

## 业务口径

| 项 | 口径 |
|---|---|
| **匿名性** | **不收集联系方式**；不要求邮箱认证 —— 反馈主路径刻意匿名 |
| **匿名提交** | 无 token 时 `user_id = 0`（等价「无身份」），后台显示为游客；**静默登录的游客带 `userId`，可收回执** |
| **端上字数** | 描述 ≤600 字（服务端上限 1000），校验在端上先做一次 |
| **本地草稿** | 进页回填「类型 + 描述文本」（`feedback_draft`）；**图片不入草稿** —— COS 地址重进可能失效，缓存只会导致提交时报「图片地址不合法」。提交成功后清除，失败时保留便于改后重试 |

> **与举报、菜品问题反馈的边界**：举报走 [api/reviews.md](../../../api/client/reviews.md)，菜品问题反馈走 [api/dishes.md](../../../api/client/dishes.md) —— **均不共用本端点**。

## 数据（落库）

| 表 | 变化 | 中文解释 |
|---|---|---|
| `user_feedback` | INSERT | 一条意见反馈：类型为三类之一、含内容与配图，**无子类、无关联对象**，初始状态待处理；列定义见 [schema/user_feedback.md](../../../schema/user_feedback.md) |
| `notification` | 管理员处理后异步 INSERT | 提交人收处理回执（**有 `userId` 即投递**，含静默登录的游客）；列定义见 [schema/notification.md](../../../schema/notification.md) |

## 跨域事件

本功能涉及的领域事件及其在本域的订阅行为。

| 事件 | 发布方 | 本域订阅行为 |
|---|---|---|
| `UserOwnershipMigratedEvent` | auth（账号归属迁移：邮箱认证时命中已绑定的其他账号） | 把本账号反馈的 `user_id` 改挂到目标账号（仅改归属，不改内容） |
| `UserAccountClosedEvent` | auth（账号注销） | **硬删**该用户全部站内通知 |

> 两个监听器均为**同步** `@EventListener` —— 在发布方事务内执行，失败则整体回滚。
> 通知随注销删除（账号维度过程性数据，注销后无读取方）；反馈与评价则保留（内容价值），口径刻意不同。
> 详见 [schema/notification.md](../../../schema/notification.md)。
