# B1 · 文本反馈

**目标**：学生提交文本反馈，分**产品反馈**与**菜品反馈**两类；提交后不回执、不提供查询入口。

## 入口

| 类型 | 入口 |
|---|---|
| 菜品反馈 | 结果卡卡面「反馈这道菜」 |
| 产品反馈 | 空状态页脚「反馈问题」 |

## 提交规则

| 项 | 口径 |
|---|---|
| 入参 | `{ type: 'product' \| 'dish', dishId?, content }` |
| 正文 | 1–500 字纯文本 |
| 内容安全 | 🔴 提交前走微信 `msgSecCheck`，命中违规拒绝并提示 |
| 身份 | `user_id` 取自静默身份，端上不传 |
| 回执 | **无** —— 提交成功只给一次 Toast，不展示历史、不展示处理状态 |

## 与菜品反馈的关联

- `type = 'dish'` ⇒ 必须带 `dishId`，指向菜品（一道菜跨位置共享反馈）（[`dish`](../../../schema/dish.md)）；
- `type = 'product'` ⇒ `dishId` 为空，反馈针对小程序本身。

## 失败处理

- 网络 / 服务失败 ⇒ 「稍后再试」重试；
- 内容安全未通过 ⇒ 提示修改后重试；
- 命中限频 ⇒ 按文案倒计时后恢复。
