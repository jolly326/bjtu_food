# B1 · 点赞反馈

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔑 需登录
> 归属：**B 轻量反馈**
> 返回：[功能总览](../README.md)

## 介绍

在「美食地图」底部弹窗内**两态点赞**（抖音式）：喜欢就点，再点取消。点赞数即群体热度指标，用于磁贴 / 弹窗展示，**不设等级、五档、状态**。

> 接口 / 字段见 [`api/client/dishes.md`](../../../api/client/dishes.md)（点赞端点）。

## 业务规则

| 项 | 口径 |
|---|---|
| 两态取值 | **点赞 = `liked = 1`** ｜ **取消 = `liked = 0`（保留行）**；个人态**仅两态** |
| 群体指标 | **点赞数** = `COUNT(liked = 1)`；磁贴 / 弹窗展示该数值 |
| 🔴 零点赞 | 展示「0」或「暂无」，**不得兜底成非零值** —— 兜底会凭空抬高热度 |
| 粒度 | 🔴 **一人一菜一行** —— 点赞真源 = [dish_rating](../../../schema/dish_rating.md)（`UNIQUE(user_id, dish_id)`，一行；`liked = 0` = 未赞）；改赞 = 覆盖本行；取消 = 置 `liked = 0` |
| 入口 | **仅「美食地图」底部弹窗**；点磁贴唤起弹窗后操作 |
| 归属 | 由当前静默识别的用户决定，**禁止信任端上标识** |
| 频控 | 写入口限频（见 [`secur/S-03`](../../../secur/S-03-限频与接口防护.md)） |

## 数据（读写）

| 表 | 变化 |
|---|---|
| `dish_rating` | upsert / 置 `liked` —— 🔴 点赞真源 |
| `dish` | 物化缓存列同步重算点赞数 |

> 列定义与对账纪律见 [schema/dish_rating.md](../../../schema/dish_rating.md) · [schema/dish.md](../../../schema/dish.md)「点赞数缓存列」。
