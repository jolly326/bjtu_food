# B1 · 品尝标记

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔑 需登录
> 归属：**B 轻量反馈**
> 返回：[功能总览](../README.md)

## 介绍

在[推荐菜品](../A-浏览与发现/A2-推荐菜品.md)卡片上点「**去品尝**」，即为该菜**创建一条饮食记录**。记录进入「我的食谱」（见 [B4](./B4-我的食谱.md)），是评分的前置条件 —— **只有点过「去品尝」的菜才可评分**。

> 接口 / 字段见 [`api/client/records.md`](../../../api/client/records.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| 粒度 | **一次品尝 = 一条记录**；同一用户对同一菜品**可以有 N 条**（每次品尝各一条，互不覆盖） |
| 重复点击 | **幂等** —— 该菜**已有未评分记录**时不新增，直接复用（端上呈已标记态）；**已评分后**再点 ⇒ **新建一条**（获得新的评分机会） |
| 归属 | 由当前静默识别的用户决定（见 [C1](../C-用户身份/C1-openid%20静默识别.md)），**禁止信任端上标识** |
| 入列时间 | `wantedAt` = 点「去品尝」的时刻，决定其在「我的食谱」中的**月份 / 日期归属** |
| 取消 | **可取消** —— **未评分**记录可由本人取消（从「我的食谱」移除、物理删除）；**已评分记录不可取消**（结论已给出，撤销会让评价分反复变动） |
| 频控 | 写入口限频（见 [`secur/S-03`](../../../secur/S-03-限频与接口防护.md)） |

## 数据（写入）

| 表 | 变化 | 说明 |
|---|---|---|
| `dish_record` | INSERT（`reaction = NULL`，`wantedAt` = 当前时间） | 一条 = 一次品尝；列定义见 [schema/dish_record.md](../../../schema/dish_record.md) |
