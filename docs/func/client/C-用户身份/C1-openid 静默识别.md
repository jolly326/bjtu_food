# C1 · openid 静默识别

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔓 公开
> 归属：**C 用户身份**
> 返回：[功能总览](../README.md)

## 介绍

产品**不做登录**。冷启动时小程序静默调用 `wx.login` 取得 code，服务端换取 openid 并据此建立 / 取得用户行，签发凭证。整个过程用户无感，**界面上不出现任何身份信息**。

> 接口 / 字段见 [`api/client/auth.md`](../../../api/client/auth.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| 触发 | 小程序冷启动，首次业务请求前 |
| 凭证 | 服务端签发；**端上不持有、不传递 openid** |
| 用户可见性 | 无登录页、无头像 / 昵称、无任何身份展示 |
| 采集信息 | **仅 openid** —— 用于归属本人数据（饮食记录 / 评分）与频控 |
| 权限分级 | **无** —— 产品为工具，不存在学生认证 / 角色 |
| 注销 | **不提供** —— 不做账号体系 |
