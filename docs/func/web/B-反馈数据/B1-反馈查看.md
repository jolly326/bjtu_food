# B1 · 反馈查看

> 所属端：**管理端（运营）** ｜ 归属：**B 反馈数据**
> 返回：[总览](../README.md)

## 介绍

查看学生的**评分数据**（只读）—— 用于了解哪道菜受欢迎、哪些菜评价偏低。

> 接口见 [`api/web/records.md`](../../../api/web/records.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **一条 = 什么** | 学生的一次「去品尝 → 评分」（**含尚未评分的记录**，`reaction` 为 `null`） |
| 入参 | 可按**菜品**筛 · 按**反应值**筛（`5` / `3` / `1`）· 分页（默认 20 / 上限 50） |
| 排序 | 按 `wantedAt` 降序 |
| 展示 | 菜品（名 / 食堂 / 档口）+ 反应（好吃 / 一般 / 踩 / 未评分）+ 去品尝时间 + 评分时间 |
| 🔴 **只读** | **不修改、不删除**学生记录 —— 本页无任何写操作 |
| 🔴 **匿名** | **不展示提交人标识**（学生端全匿名，运营端也不披露） |

### 评价分不由本页维护

- 菜品的 `avgReaction` / `reactionCount` 是 `dish` 上的**派生缓存列**，由学生评分**自动重算**；
- 运营端**改不了它**（`PUT /admin/dishes/{id}` 也不接受这两个字段）；
- 🔴 因此：**想改评价分只能靠学生的真实评分**，不存在"运营调分"的通道。
