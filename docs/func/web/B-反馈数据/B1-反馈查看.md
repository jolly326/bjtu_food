# B1 · 反馈查看（点赞数据）

> 所属端：运营端（Web） ｜ 鉴权：🔑 需登录
> 归属：**B 反馈数据**
> 返回：[功能总览](../README.md)

## 介绍

运营端查看学生对菜品的**点赞**反馈（抖音式点赞 / 取消）。数据源 = [`dish_rating`](../../../schema/dish_rating.md)（一人一菜一行，`liked`），群体指标 = [`dish.likeCount`](../../../schema/dish.md)。**只读、不修改、不删除**。

## 业务规则

| 项 | 口径 |
|---|---|
| 数据只读 | 点赞与纠错提交运营端不修改、不删除 |
| 点赞数 | 群体指标 = `dish.like_count`（= `COUNT(liked = 1)`），由学生点赞驱动重算 |
| 匿名 | 🔴 **不展示任何用户标识**（学生全匿名） |

## 接口

- `GET /admin/dishes` —— 列表出参含 `likeCount`（菜品点赞数总览；契约见 [`api/web/dishes.md`](../../../api/web/dishes.md)）。
- 单菜点赞明细（谁赞了）属匿名数据，运营端不展示；如确需，新增 `GET /admin/dish-likes`（代码阶段补）。
