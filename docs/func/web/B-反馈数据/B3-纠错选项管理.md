# B3 · 纠错选项管理

> 所属端：**管理端（运营）** ｜ 归属：**B 反馈数据**
> 返回：[总览](../README.md)

## 介绍

维护学生端纠错弹层的**选项字典** —— 学生提交纠错时**只能从这些选项里选一个**（无文字、无配图）。

> 接口见 [`api/web/issues.md`](../../../api/web/issues.md) 的「选项字典」节 · 列定义见 [schema/dish_issue_option.md](../../../schema/dish_issue_option.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **字段** | **仅选项文案**（`name`）—— 不设图标 / 排序位 / 启停位 |
| 初始数据 | 5 条：**菜名有误 / 价格有误 / 图片有误 / 位置有误 / 已经下架** |
| 列表 | **全量**（不分页 —— 量级固定小）；按 `id` 升序；展示**引用次数**（只读）与更新时间 |
| **新建** | 文案必填；即时生效 —— 🔴 **免发版、免端上改动** |
| **改名** | 🔴 **全站生效**（含**历史提交**的中文翻译） |
| **删除** | 🔴 **已被提交记录引用时拒绝**（被引用即禁删）；**引用次数为 `0` 才可删** |
| 无启停 | 🔴 **不设 `on` / `off`** —— 选项集合即有效集合 |

### 为什么"改名免费、删除受限"

- 学生提交里存的是 **`option_id`**，中文在**展示时**由字典翻译 ⇒ **改文案不触碰任何历史行**、零数据迁移；
- 反过来，一旦有历史提交引用了某选项，删掉它会让那些记录**失去中文**（外键直接拒绝）⇒ 只能删**从无引用**的选项。

> 这也是「删不掉旧选项」时的唯一出路：**改名复用**（把它改成新的语义），而不是删除。
