# C3 · 安全告警

> 所属端：**管理后台（Web）** ｜ 鉴权：管理端 JWT 登录（见 [C1](./C1-管理员登录与访问控制.md)）
> 归属：**C 账号与访问**
> 状态：**已定稿**

## 介绍

安全告警的**回看面板** —— 只读。

**为什么需要它**：告警原先只推到群消息（解决「立刻知道」），但群消息会被刷走、无法按类型回看 —— 复盘时只能靠翻聊天记录。本页把「这台机器上到底发生过什么」变成**可查询、可筛选的事实**。

**职责边界**：

- **只读**：告警记录只追加 —— 面板**不提供**新建 / 编辑 / 删除入口（能改告警的人就能抹掉自己的痕迹）。任何已登录角色（含 `viewer`）均可查看。
- **不产生告警**：何时告警、级别如何定是各能力自己的职责（登录 / 口令 / 审计 / 违规处置 / 爬取检测），本页只消费结果。
- **不配置推送通道**：地址与签名密钥只经环境变量注入（见 [secur/web/审计与告警.md](../../../secur/web/审计与告警.md)），页面不暴露、不可改。

**告警类型**：登录成功 · 登录失败达阈值 · 口令修改 · 审计写入失败 · 违规累积处置 · 爬取检测（键 / 标签 / 级别见 [api/web/alerts.md](../../../api/web/alerts.md)）。

| 表 | 读写什么 | 中文解释 |
|---|---|---|

## 备注

- **标签是快照**：类型与级别的中文标签在**写入时**落库，展示时不反查代码枚举 —— 枚举重命名不会让历史记录失去可读性。
- **级别由类型决定**：调用方只传类型，级别由枚举给出（同类事件级别恒定，筛选才有意义）。
- **未知类型键原样显示**：遇到不认识的类型键按原值展示，**不隐藏** —— 未知类型本身就是需要看到的信息。
- **不影响业务**：落库与推送都在告警线程池内完成；落库失败只记 ERROR 且**不再推送**（推送会再写一行，形成递归）。
