# C1 · 管理员登录

> 所属端：**管理端（运营）** ｜ 归属：**C 账号与访问**
> 返回：[总览](../README.md)

## 介绍

运营端的**唯一入口** —— 账密登录换取运营端凭证，与学生的 `user` 体系**完全隔离**。

> 接口见 [`api/web/auth.md`](../../../api/web/auth.md) · 安全口径见 [`secur/S-01`](../../../secur/S-01-身份与凭证.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **凭据** | 账号 + 口令；口令以 **BCrypt 哈希**存储与比对，**不存明文、不可逆** |
| **会话** | 登录成功下发**运营端 JWT**（**与学生端 secret 分离** —— 学生 token 无法冒充运营端）；此后 `/admin/**` 一律需 `Authorization: Bearer <token>` |
| **前端** | 🔴 **不持有口令**（登录后仅持 token）；**登出 = 前端清除 token**（无服务端吊销端点） |
| **账号维护** | **无注册、无自助改密** —— 账号行由**数据库直接维护**：🔴 改密须**离线用 BCrypt 生成哈希后 `UPDATE admin.password`**，**严禁写明文**（比对走 BCrypt，明文存进去将无法登录）；具体步骤见 [`schema/admin.md`](../../../schema/admin.md) |
| **角色** | **无分级**（单管理员运营）—— 不做按角色隐藏入口 |
| 失效 | `401` ⇒ 前端清 token 并跳登录页 |
| **登录防护** | **本期不展开**（运营端防护不在范围）；登录端点保留 **IP 限频兜底**，见 [secur/S-03](../../../secur/S-03-限频与接口防护.md) |

## 数据（读取）

| 表 | 读什么 | 说明 |
|---|---|---|
| `admin` | `username` + `password`（BCrypt 比对） | 列定义见 [schema/admin.md](../../../schema/admin.md) |

> `admin` 表**不被任何业务表引用** —— 运营端只做录入与查看，不留操作痕迹（无审计表）。
