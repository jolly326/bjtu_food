# C1 · 管理员登录与访问控制

> 所属端：**管理后台（Web）** ｜ 鉴权：全部 `/admin/**` 需管理员登录
> 归属：**C 账号与访问**
> 安全设计真源：[`secur/web/`](../../../secur/web/README.md)（登录与凭证 / 防爆破与限流 / 审计与告警）；契约唯一真源：[api/web/auth.md](../../../api/web/auth.md)

## 介绍

管理后台的**访问控制**。

**定位前提**：单管理员、**web 仅跑本地**、backend 因微信云托管限制**必须开公网**（本地浏览器不在云托管内网内）。

**机制**（账密登录）：

- **账号**：独立 `admin_account` 表，密码存 **BCrypt** 哈希（不可逆），不复用学生 `user` 表。
- **改密**：同弹窗内自助完成（强度：≥12 位且含大写 / 小写 / 数字 / 符号中至少三类）；**改密即让既有 token 全部失效**，本端自动换用响应回的新 token，其余端需重登。
- **携带**：前端把 token 存 `sessionStorage`，后续请求带 `Authorization: Bearer <jwt>`；**前端不持有口令**。
- **失效**：token 失效（24h 过期 / 账号停用 / 改密后版本不符）→ `401` → 前端清 token 并跳登录页。

**关键性质**：

| 项 | 说明 |
|---|---|
| 前端产物 | ✅ **不含口令** —— 口令仅在登录表单提交瞬间存在于内存 |
| 两端口令同步 | ✅ **不需要** |
| 凭证强度 | ✅ **不可伪造** —— 管理端 JWT 由独立 secret 签名 |
| 凭证吊销 | ✅ 停用账号 / **改密**即刻生效（后者经凭证版本比对） |

**角色与权限**：三档角色 —— `super` 全权（含删除类不可逆操作）/ `operator` 读写（**不含删除**）/ `viewer` 只读，由 `AdminAuthFilter` 按「HTTP 方法 + 角色」**服务端强制**判定；`GET /admin/auth/me` 下发 `role` 供端上隐显入口（前端隐显只是体验）。

**前端隐显口径**：`viewer` 不显示写入口（新增 / 编辑 / 处置 / 启停），**删除入口仅 `super` 可见**；角色缺失 / 未知按只读处理（fail-closed）。判据收敛在 `web/src/utils/permissions.ts`。


**明确不做（边界）**：**IP 白名单**（🔴 微信云托管无安全组能力，且校园网出口 IP 共享 ⇒ 白名单会退化为「全校可访问」）。


**部署形态**：web **跑本地**（`npm run dev`）；backend **微信云托管 + 开公网**（供 web 直连）；小程序走 `wx.cloud.callContainer` 内网不受影响。

> ⚠️ **必配**：`CORS_ALLOWED_ORIGINS=http://localhost:5173`，否则本地 web 全站 CORS 403。

## 接口

| 端点 | 鉴权 | 说明 |
|---|---|---|
| `GET /admin/auth/me` | ✅ 需 token | 当前管理员账号信息（含角色与安全提示） |
| `POST /admin/auth/password` | ✅ 需 token（自助） | 改密（吊销既有 token，回新 token） |

其余 `/admin/**` 统一经 `AdminAuthFilter` 校验。请求头 / 响应结构 / 错误码见 [**api/web/auth.md**](../../../api/web/auth.md)。

## 数据

| 表 | 说明 |
|---|---|
| [`admin_account`](../../../schema/admin_account.md) | `username` 唯一 / `password_hash`（BCrypt）/ `status`(on·off) / `role`(super·operator·viewer) / `last_login_at` / `credential_version` / `password_changed_at` |

**无会话表 / 令牌表** —— JWT 自包含，状态由账号 `status` 与 `credential_version` 决定。
