# A5 · 首页 Banner 管理

> 所属端：**管理后台（Web）** ｜ 鉴权：管理端 JWT 登录（见 [C1](../C-账号与访问/C1-管理员登录与访问控制.md)）
> 归属：**A 主数据维护**
> **口径要点**：**纯展示图、不做跳转**；**启用上限 6 张**；**轮播行为不可配**；**不做定时上下线**。

## 介绍

维护 client **首页顶部轮播 Banner**（[`GET /banners`](../../../api/client/banner.md) 的数据源）—— 图片、顺序、启停。

**定位**：首页唯一的**运营位**。管理端提供 **列表 / 新增 / 编辑 / 拖拽排序 / 启停 / 删除**。公开端 [`GET /banners`](../../../api/client/banner.md) 契约**完全不变**（仍只出 `{ id, imageUrl }`）。

**职责边界**：只管 Banner 自身（图片 / 顺序 / 启停）。**不做跳转**、**不做定时上下线**、**不做轮播参数配置**（见「明确不做」）。

**明确不做（边界）**：

| 不做 | 原因 |
|---|---|
| **点击跳转**（`targetType` / `targetId` / `targetUrl`） | 产品定型是「**轻运营（无运营位跳转）**」；且 client 的 `web-view` 已随「活动 / 公告」整链下线，外链不可行；跳转还要治理「目标失效」（菜品被删 → 点击报错） |
| **定时上下线**（`startAt` / `endAt`） | 会扩出 [`GET /banners`](../../../api/client/banner.md) 出参契约；真有活动诉求时再拍板（登记为演进预留） |
| **轮播行为可配**（`autoPlay` / `interval`） | 固定「多于 1 张才自动轮播，间隔由端上定死」，与「轻运营」一致，也避免间隔被调坏 |

**删除约束**：**无引用约束** —— Banner 不引用任何业务表，也不被引用；删除直接生效（UI 可加一次轻确认）。

**启用上限**：**最多 6 张启用中**（`status='on'`）—— 新增默认启用、启停时校验，超限返回 `400`。

## 数据

| 表 | 读写什么 | 中文解释 |
|---|---|---|
| `banner` | 增删改查 | Banner 本体（不动主键 / 时间列） |

> 不引用任何业务表（无外键），也不被任何表引用。列口径见 [schema/banner.md](../../../schema/banner.md)。
> **出参字段统一叫 `order`**（库列是 `banner.sort_order`，由持久层映射）—— 管理端各页的"展示顺序"出参一律用 `order`，避免同义异名。

## 素材规格（运营约束）

| 项 | 规格 | 说明 |
|---|---|---|
| 宽高比 | **统一 16:10** | 混比例会让轮播切换时**块高抖动**、吸顶阈值漂移（client 按 16:10 定高） |
| 张数 | **启用 ≤6** | 服务端强校验 |
| 大小 | 由 [api/web/upload.md](../../../api/web/upload.md) 约定约束（单张 ≤5MB，见上传契约） | —— |

> ⚠️ **16:10 不做服务端强校验**：服务端读取图片尺寸成本高、且截图/裁剪后仍可能失真；由**上传页提示 + 运营自律**承担（属 UI 侧事项）。

## 客户端可见性

[`GET /banners`](../../../api/client/banner.md) **不动**：仅返回 `status='on'`、按 `sort_order` 升序、出参仍为 `[{ id, imageUrl }]`、无启用项时返回**空数组 `[]`**。

## 备注（架构取舍）

- **不做跳转**：见「明确不做」。真要跳转，须先由 UI 文档定义点击交互，再扩出参字段。
- **不做定时上下线**：时间窗必须进 [`GET /banners`](../../../api/client/banner.md) 出参才会被端上感知，属**契约变更**；一期用「人工启停」表达。
- **轮播行为固定**：多张自动轮播、间隔端上定死；把间隔做成后台配置是**伪需求**。
- **排序一律「拖拽 + 批量端点」**：与 [A4](./A4-菜品属性维度管理.md) / [A6](./A6-首页筛选视图管理.md) 同口径；新建项默认排最后。
- **不做比例强校验**：见「素材规格」；把"尺寸不对"的责任放在上传环节提示，而不是入库拦截。
- **停在 `status` 而非删除**：临时不想露出就停用（保留素材与顺序），删除是彻底移除。
