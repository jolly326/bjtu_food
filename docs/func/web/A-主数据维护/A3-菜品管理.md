# A3 · 菜品管理

> 所属端：**管理后台（Web）** ｜ 鉴权：管理端 JWT 登录（见 [C1](../C-账号与访问/C1-管理员登录与访问控制.md)）
> 归属：**A 主数据维护**
> **口径要点**：菜品资料**唯一写入源**（含**复制**）；**允许删除**（评价级联，UI 二次确认）；种类**单值必填**（字典表 [`dish_category`](../../../schema/dish_category.md)）、描述属性**可空**；图片 **≤5 张**、有序、首图作封面。

## 介绍

维护**菜品（`dish`）主数据** —— client **首页 / 搜索 / 菜品详情**的唯一数据源。

**定位**：管理端是菜品资料的**唯一写入源**（学生端**无菜品写接口**）。提供 **列表 / 新增 / 编辑 / 复制 / 上下架 / 删除**。

**字段范围**：名称 / 所属档口 / 现价 / 原价 / 描述 / 图片 / 种类 / 描述属性 / 上架状态。
**派生只读（不可编辑）**：均分 `avgRating`、评价数 `ratingCount`、创建 / 更新时间。

**职责边界**：只管菜品**本体**。位置（食堂 · 楼层 · 档口名）由 [A2 档口管理](./A2-档口管理.md) **派生**（本页只选 `stallId`，不填名称）；菜品**种类**取自种类字典 [`dish_category`](../../../schema/dish_category.md)（独立字典表，维护入口见 [A6](./A6-首页筛选视图管理.md)）；描述属性维度与取值来自 [A4](./A4-菜品属性维度管理.md)。

**删除约束**：**允许删除**。删除为**物理删除**，其评价**级联删除**（`review` 有 `ON DELETE CASCADE`）；反馈记录**保留**（`dish_correction` 不设外键，是"用户反馈过什么"的历史痕迹）。
> ⚠️ 删除**会影响历史**（评价与均分一起消失）⇒ UI 必须**二次确认**并明示「将一并删除该菜品的 **N 条评价**」（N 取列表已有的 `ratingCount`）。

**不纳入**：售罄 / 今日供应（产品定型一期不做）；独立审核（**录入即生效**，公开可见性只看 `status`）；历史累计浏览量 `dish.view_count`（🔴 2026-10-05 已**停写**，浏览量改由 `dish_view_log` 30 天窗口承载 ⇒ 列表下发 `recentViewCount`「近 30 天浏览」，见 [A3 契约](../../../api/web/dishes.md)）。

## 数据

| 表 | 读写什么 | 中文解释 |
|---|---|---|
| `dish` | 增删改查 + 全字段 | 菜品本体 |
| `stall` | **只读**（校验存在 + 回填档口名） | 归属档口；**本页不写**（档口由 A2 维护） |
| `canteen` | **只读**（回填食堂名） | 位置展示 |
| `dish_category` | **只读**（`categoryId` 引用校验 + 回填 `categoryLabel`） | 菜品种类字典（A6 维护） |
| `dish_attribute_dimension` / `dish_attribute_value` | **只读**（维度 ID 校验 + 取值 ID ↔ 中文翻译） | 描述属性（A4） |
| `review` | **删除菜品时级联删除** | `ON DELETE CASCADE`（应用层 `ReviewDishCascadeListener` 先删，外键兜底） |
| `dish_correction` | **不设外键**，删菜品后**保留** | 用户反馈留痕 |

## 备注（架构取舍）

- **`PUT` 整体替换而非部分更新**：本页是**表单式**编辑（提交全量字段），整体替换语义明确、不会出现"漏传一个字段导致旧值残留"；上下架是**行内操作**，单独给它一个端点比让前端"只传 status"更清晰。
- **列表 / 详情 VO 分离**：列表是"扫视"场景（要小、要快），详情是"编辑回填"场景（要全）；共用 VO 会让列表为 20 行 × 512 字描述 + 属性 Map 买单。
- **归属只认 `stallId`**：与 A1 / A2 的"实体化 + 下拉"一致。按名 upsert 会让同一档口因错别字分裂成多行，是重复数据的根源。
- **图片 0~5 张**：0 张合法（client 有统一图片占位 `ImagePlaceholder`）；上限 5 支撑详情页多图，且不超过 `dish.images VARCHAR(1024)` 的承载。
- **复制副本默认 `off`（下架）**：复制出来的是**半成品**，先下架、确认内容后再上架，避免半成品直接对用户可见。
- **菜品名不唯一**：同名菜品靠档口区分；强制唯一会阻碍"两个档口都卖番茄炒蛋"这类真实情况。
- **`ratingCount` 兼作删除影响的提示值**：它是**可见**评价数（`is_hidden = 0`）；删除会一并删掉隐藏评价，实际删除数**不少于**此值，故确认文案用「**至少** N 条评价」口径。
