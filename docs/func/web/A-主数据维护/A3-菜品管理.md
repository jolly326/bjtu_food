# A3 · 菜品管理

> 所属端：**管理端（运营）** ｜ 归属：**A 主数据维护**
> 返回：[总览](../README.md)

## 介绍

维护菜品 —— 学生端「美食地图」页展示的一切都来自这里，也是点赞与纠错的**对象**。

> 接口见 [`api/web/dishes.md`](../../../api/web/dishes.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **字段** | 所属档口（必填）· 名称（必填）· 价格（必填，**单位「分」**）· 菜品图（可选）· 状态（`on` 在售 / `off` 已下架） |
| **唯一性** | **同一档口下** `name` 唯一 |
| **价格** | 一律以**分**为单位存取（如 12.00 元 = `1200`）；端上展示时转元 |
| **状态** | 缺省 `on`；🔴 **下架对学生端等价于不存在** —— 不进地图，且**不可**被「点赞」/ 纠错 |
| 图片 | 单张大图；传 `null` = 清除 |
| 列表 | 可按档口 / 食堂 / 状态筛；分页 |
| **只读列** | `likeCount`（点赞数）—— **派生缓存列**，由学生点赞自动重算，**本页不可直接改** |
| **删除** | 🔴 **引用即禁删**：该菜存在**学生点赞**或**纠错** ⇒ 拒绝删除并提示改用「**下架**」（学生数据不随菜品蒸发）；零引用才允许物理删除 |

### 明确不录的字段（学生端不消费）

| 不录 | 原因 |
|---|---|
| 描述 / 简介 | 学生端**无详情页**，弹窗不展示描述 |
| 属性维度 / 取值 | 本期不设（无筛选需求） |
| 多图 | 磁贴只有一张大图 |
| 原价 / 折扣 | 无促销语义 |
| 分类 / 种类 | 本期不设（筛选维度只有食堂） |
| 售罄 / 今日供应 | 只有「在售 / 下架」两态 |

> **点赞数从哪来**：学生端「美食地图」的两态点赞（抖音式点赞 / 取消）驱动重算；**零点赞 = 0**，不得兜底成非零值（兜底会凭空抬高热度）。`likeCount` = `COUNT(dish_rating.liked = 1)`，不落风味评级。口径见 [`schema/dish.md`](../../../schema/dish.md)。

## 数据（读写）

| 表 | 变化 | 说明 |
|---|---|---|
| `dish` | INSERT / UPDATE / DELETE | 列定义见 [schema/dish.md](../../../schema/dish.md) |
| `dish_rating` · `dish_issue` | **引用即禁删** | 菜品存在引用 ⇒ 拒绝删除（改用下架）；零引用才物理删除（CASCADE 仅兜底） |
