# A3 · 菜品管理

> 所属端：**管理端（运营）** ｜ 归属：**A 主数据维护**
> 返回：[总览](../README.md)

## 介绍

维护菜品 —— 学生端「美食」tab 刷到的一切都来自这里，也是评分与纠错的**对象**。

> 接口见 [`api/web/dishes.md`](../../../api/web/dishes.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **字段** | 所属档口（必填）· 名称（必填）· 价格（必填，**单位「分」**）· 菜品图（可选）· 状态（`on` 在售 / `off` 已下架） |
| **唯一性** | **同一档口下** `name` 唯一 |
| **价格** | 一律以**分**为单位存取（如 12.00 元 = `1200`）；端上展示时转元 |
| **状态** | 缺省 `on`；🔴 **下架对学生端等价于不存在** —— 不进推荐流，且**不可**被「去品尝」/ 评分 / 纠错 |
| 图片 | 单张大图；传 `null` = 清除 |
| 列表 | 可按档口 / 食堂 / 状态筛；分页 |
| **只读列** | `avgReaction`（平均评价度）· `reactionCount`（评分条数）—— **派生缓存列**，由学生评分自动重算，**本页不可直接改** |
| **删除** | 🔴 连带清理该菜的**饮食记录**与**纠错记录**（外键 `ON DELETE CASCADE`）—— 删前须确认 |

### 明确不录的字段（学生端不消费）

| 不录 | 原因 |
|---|---|
| 描述 / 简介 | 学生端**无详情页**，卡片不含描述 |
| 属性维度 / 取值 | 本期不设（无筛选需求） |
| 多图 | 卡片只有一张圆形图 |
| 原价 / 折扣 | 无促销语义 |
| 分类 / 种类 | 本期不设（筛选维度只有食堂） |
| 售罄 / 今日供应 | 只有「在售 / 下架」两态 |

> **评价分从哪来**：学生端「记忆」tab 的三态评分（喜欢 `5` / 一般 `3` / 不喜欢 `1`）驱动重算；**零评分存 `NULL`、展示「暂无评分」**，不得兜底成 5.0（兜底值会凭空获得高分并污染推荐权重）。学生端展示的「风味评级」（S/A/B/C/D）由 `avgReaction` + `reactionCount` 派生，不落库。口径见 [`schema/dish.md`](../../../schema/dish.md)。
