# A2 · 档口管理

> 所属端：**管理端（运营）** ｜ 归属：**A 主数据维护**
> 返回：[总览](../README.md)

## 介绍

维护档口，含**竖版海报** —— 海报是学生端「橱窗」tab 的唯一数据源。

> 接口见 [`api/web/stalls.md`](../../../api/web/stalls.md) · 上传见 [`api/web/images.md`](../../../api/web/images.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **字段** | 所属食堂（必填）· 名称（必填）· **海报**（可选）· 楼层（可选）· 窗口号（可选） |
| **唯一性** | **同一食堂下** `name` 唯一 |
| 列表 | 可按食堂筛；分页；展示**菜品数**（只读统计） |
| **海报** | **单张竖版 3:4**；经 `POST /admin/images` 上传得绝对 URL，**入库转相对路径**；入参传 `null` = 清除海报 |
| 楼层 | **受控字典**（值即汉字 `负一层`…`四层`），取值由服务端校验 |
| **删除** | 🔴 **该档口下仍有菜品时拒绝**（`400`） |
| 级联 | 删除档口**不级联**删菜品（由上述拒绝规则保证） |

### 海报的两条硬口径

1. 🔴 **只有已上传海报的档口**会出现在学生端「橱窗」tab —— **未上传 = 不上橱窗**（不是显示占位图）。
2. 🔴 海报**承载档口的全部信息** —— 学生端**不叠加任何文本**（档口名 / 食堂名 / 位置都不在页面上渲染）⇒ **出图时必须把这三项画进海报**。

> 因此海报是**运营出图规范**的一部分，不是普通配图。素材比例见 [`ui/client/档口海报.md`](../../../ui/client/档口海报.md)。
