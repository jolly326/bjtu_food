# A2 · 档口管理

> 所属端：**管理端（运营）** ｜ 归属：**A 主数据维护**
> 返回：[总览](../README.md)

## 介绍

维护档口本体 —— 菜品的位置归属。**海报不在此页**：已独立为 [A4 海报管理](./A4-海报管理.md)（学生端「发现」tab 的唯一数据源）。

> 接口见 [`api/web/stalls.md`](../../../api/web/stalls.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **字段** | 所属食堂（必填）· 名称（必填）· 楼层（可选）· 窗口号（可选） |
| **唯一性** | **同一食堂下** `name` 唯一 |
| 列表 | 可按食堂筛；分页；展示**菜品数**与**海报数**（只读统计） |
| **海报** | **不在本页维护** —— 独立于 [A4 海报管理](./A4-海报管理.md)（一档口可多张、固定序、独立上下架） |
| 楼层 | **受控字典**（值即汉字 `负一层`…`四层`），取值由服务端校验 |
| **删除** | 🔴 **该档口下仍有菜品时拒绝**（`400`） |
| 级联 | 删除档口**不级联**删菜品（由上述拒绝规则保证）；名下海报随外键 **`ON DELETE CASCADE` 一并清理**（不阻塞删除） |
