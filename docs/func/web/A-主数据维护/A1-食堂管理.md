# A1 · 食堂管理

> 所属端：**管理端（运营）** ｜ 归属：**A 主数据维护**
> 返回：[总览](../README.md)

## 介绍

维护食堂清单 —— 食堂是学生端「美食」tab 右上角**筛选**的唯一维度，也是档口 / 菜品位置链路的根。

> 接口见 [`api/web/canteens.md`](../../../api/web/canteens.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **字段** | **仅名称**（`name`）—— 不设位置 / 图片 / 描述 |
| **唯一性** | `name` **全局唯一**（应用层保证；同名 ⇒ `400`） |
| 列表 | 分页（默认 20 / 上限 50），按 `id` 升序；展示**下属档口数**（只读统计） |
| 新建 | `name` 必填；空 / 重复 ⇒ `400` |
| 修改 | 同上；`4001` 食堂不存在 |
| **删除** | 🔴 **该食堂下仍有档口时拒绝**（`400`）—— 必须先清空下属档口 |
| 级联 | 删除食堂**不级联**删档口（由上述拒绝规则保证） |

## 数据（读写）

| 表 | 变化 | 说明 |
|---|---|---|
| `canteen` | INSERT / UPDATE / DELETE | 列定义见 [schema/canteen.md](../../../schema/canteen.md) |

> 食堂被「美食」tab 的筛选与档口的归属共同引用 ⇒ **删除前务必确认没有在用的档口**。
