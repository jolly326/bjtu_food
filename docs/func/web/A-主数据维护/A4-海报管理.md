# A4 · 海报管理

> 所属端：**管理端（运营）** ｜ 归属：**A 主数据维护**
> 返回：[总览](../README.md)

## 介绍

维护档口海报 —— 学生端「风物」（橱窗）tab 的唯一数据源。一档口可挂**多张**；**上不上橱窗、先后顺序**全在本页控制。

> 接口见 [`api/web/posters.md`](../../../api/web/posters.md) · 上传见 [`api/web/images.md`](../../../api/web/images.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **字段** | 所属档口（必填）· 海报图（必填，单张竖版 3:4）· 排序（可选，整数）· 状态（`on` 上橱窗 / `off` 不展示） |
| **唯一性** | 无 —— 同档口允许多张（海报即序列） |
| **排序** | **全局序**（橱窗为一条序列，不按档口分组）：**值小靠前**，同值按创建顺序；新建不填 ⇒ 自动排到当前**最后**（全局最大值 + 1）；编辑不改 ⇒ **保持原值** |
| **状态** | 缺省 `on`；🔴 **`off` 对学生端等价于不存在** —— 不进 `GET /posters` |
| 图片 | 单张竖版 **3:4**；经 `POST /admin/images` 上传得绝对 URL，**入库转相对路径**；**必填**（无「空海报」态，移除 = 删除海报）。🔴 比例由**出图规范**保证 —— 该上传端点与菜品大图共用，**不校验宽高比**；学生端展示按 3:4 `aspectFill` 裁切 |
| 列表 | 可按食堂 / 档口 / 状态筛；分页；按 `sort` 升序展示 —— **与学生端同序，所见即学生所见** |
| **删除** | 可删；只删库记录（**COS 文件不回收**）；学生端下一次拉取即生效 |
| 级联 | 删除**档口**时其海报随外键 `ON DELETE CASCADE` 一并清理（本页无感知，也不阻塞档口删除） |

### 两条硬口径（出图规范）

1. 🔴 **只有上架（`on`）的海报**才会出现在学生端「风物」tab —— **下架 = 不上橱窗**（不是显示占位图）。
2. 🔴 海报**承载档口的全部信息** —— 学生端**不叠加任何文本**（档口名 / 食堂名 / 位置都不在页面上渲染）⇒ **出图时必须把这三项画进海报**。

> 因此海报是**运营出图规范**的一部分，不是普通配图。素材比例见 [`ui/client/风物.md`](../../../ui/client/风物.md)。
