# B1 · 反馈处理

> 所属端：**管理端（运营）** ｜ 归属：**B 反馈与纠错**
> 返回：[总览](../约定与红线.md)

## 介绍

查看学生提交的**文本反馈**（产品级 / 菜品级），并标记处理状态。

系统只记录「学生反馈了什么」，**不做自动更正**，也**不给学生回执**。

> 接口见 [`api/web/feedback.md`](../../../api/web/feedback.md) · 列定义见 [schema/feedback.md](../../../schema/feedback.md)。

## 业务规则

| 项 | 口径 |
|---|---|
| **一条 = 什么** | 一次文本提交：`type`（product / dish）+ 关联菜品（产品反馈为空）+ 正文 |
| 列表 | 🔴 **默认只查未处理**（`handledAt IS NULL`）；可按类型 / 处理状态筛；分页；按提交时间降序 |
| 展示 | 类型 · 关联菜品（名）· **正文** |
| **标记已处理** | `PATCH` 写 `handledAt`；幂等 |
| 🔴 **处置动作** | 运营**手动**去改菜品或记录产品建议（[A3 菜品管理](../A-主数据维护/A3-菜品管理.md)）—— 系统不会自动更新任何字段 |
| 🔴 **无回执** | 不给学生发通知；学生端看不到处理结果 |
| 删除 | 反馈行不提供删除入口 |
