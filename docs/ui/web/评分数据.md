# 评分数据

> 所属端：**管理端（运营）** ｜ **只读页**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[B1](../../func/web/B-反馈数据/B1-反馈查看.md) ｜ 接口：[api/web/records.md](../../api/web/records.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题「评分数据」—— 🔴 **无「新建」**（只读页） |
| 筛选区 | **菜品**下拉 · **反应**下拉（全部 / 好吃 / 一般 / 踩 / **未评分**）+ 「查询」/「重置」 |
| 表格 | 菜品 ｜ 食堂 ｜ 档口 ｜ 反应 ｜ 去品尝时间 ｜ 评分时间 |
| 分页 | `total, prev, pager, next` |

🔴 **无行内操作列**（不可改、不可删）；🔴 **无提交人列**（学生全匿名）。

## 2 · 交互

| 项 | 口径 |
|---|---|
| **反应筛选的传值** | 「全部」⇒ 不传 `reaction`；「好吃 / 一般 / 踩」⇒ 传 `5` / `3` / `1`；🔴 **「未评分」⇒ 传 `reaction=none`**（端点已支持，见 [`api/web/records.md`](../../api/web/records.md)） |
| 写操作 | **无** —— 本页只筛选 + 翻页 |
| 空态 | 「暂无数据」（一句话，见[基线](./公共组件与形态基线.md) §1.3） |
| 加载失败 | 表格区上方 `el-alert` + 「重试」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 反应列 | `el-tag`：好吃（`success`）｜一般（`warning`）｜踩（`danger`）｜**未评分（`info`）** |
| 时间列 | 按 [`api/README.md`](../../api/README.md) 的时间口径格式化 |
| 顺序 | 服务端固定按去品尝时间**降序**（🔴 客户端**不做**列表头排序，见[基线](./公共组件与形态基线.md) §1.5） |

## 4 · 说明

🔴 菜品的**评价分不在本页维护** —— 它是 `dish` 上的派生缓存列，只由学生评分驱动重算；运营端**没有调分入口**（详见 [B1](../../func/web/B-反馈数据/B1-反馈查看.md)）。
