# 评分数据

> 所属端：**运营端** ｜ **只读页**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[B1](../../func/web/B-反馈数据/B1-反馈查看.md) ｜ 接口：[api/web/records.md](../../api/web/records.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题「评分数据」—— 🔴 **无「新建」**（只读页） |
| 筛选区 | **菜品**下拉 · **反应**下拉（全部 / 喜欢 / 一般 / 不喜欢 / **未评分**）—— 两档**即选即查** |
| 列表卡片 | 菜品 + 反应 tag（主行）｜ 食堂 · 档口（归属路径行）｜ 想吃于 · 评分于（指标行） |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 |

🔴 **无操作列**（不可改、不可删）；🔴 **无提交人列**（学生全匿名）。

## 2 · 交互

| 项 | 口径 |
|---|---|
| **反应筛选的传值** | 「全部」⇒ 不传 `reaction`；「喜欢 / 一般 / 不喜欢」⇒ 传 `5` / `3` / `1`；🔴 **「未评分」⇒ 传 `reaction=none`**（端点已支持，见 [`api/web/records.md`](../../api/web/records.md)） |
| 写操作 | **无** —— 本页只筛选 + 翻页 |
| 空态 | 「暂无数据」（见[基线](./公共组件与形态基线.md) §1.3） |
| 加载失败 | `ElMessage.error`（服务端 `message`） |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 反应 tag | 主行内：喜欢 `.tag--r5`（`--el-color-success`）｜一般 `.tag--r3`（`--el-color-warning`）｜不喜欢 `.tag--r1`（`--el-color-danger`）｜**未评分（中性弱化 `.tag--none`）** |
| 时间 | 直接展示接口返回的时间字符串（格式口径见 [`api/README.md`](../../api/README.md)「时间」）；无评分时间时「评分于」整段**不显示** |
| 顺序 | 服务端按去品尝时间**降序**（无客户端排序，见[基线](./公共组件与形态基线.md) §1.6） |

## 4 · 说明

🔴 菜品的**评价分不在本页维护** —— 它是 `dish` 上的派生缓存列，只由学生评分驱动重算；运营端**没有调分入口**（详见 [B1](../../func/web/B-反馈数据/B1-反馈查看.md)）。
