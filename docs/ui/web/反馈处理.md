# 反馈处理

> 所属端：**运营端**
> 归属功能：[B1](../../func/web/B-反馈与纠错/B1-反馈处理.md) ｜ 接口：[api/web/feedback.md](../../api/web/feedback.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 内联筛选：**类型**下拉（全部 / 产品反馈 / 菜品反馈）· **处理状态**下拉（全部 / 未处理 / 已处理）—— 即选即查 |
| 列表卡片 | 类型 tag · 关联菜品（产品反馈显示「—」）｜ **正文**（多行截断，点开看全文）｜ 提交时间 · 处理时间 |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + 跳页 |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 查看正文 | 点卡片展开全文（长文本），不跳页 |
| **标记已处理** | 卡片内「标记处理」按钮 ⇒ `PATCH /admin/feedback/{id}/handled` ⇒ 刷新列表 |
| 已处理态 | 卡片整体弱化，按钮置灰不可再点 |
| 筛选 | 类型 / 处理状态即选即查，回第 1 页 |
| 无删除 | 反馈行**不提供删除入口** |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 类型 tag | 产品反馈 `--el-color-primary` 系；菜品反馈中性弱化 |
| 已处理 | `.list-card--dim`（降低不透明度） |
| 正文 | 常规正文色，长文本 `line-clamp: 3`，展开后全量 |

## 4 · 不做

- 不编辑反馈正文；
- 不做自动更正、不给学生回执；
- 不做批量处理（量小）。
