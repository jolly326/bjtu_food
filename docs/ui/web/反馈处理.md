# 反馈处理

> 所属端：**运营端**
> 归属功能：[B1](../../func/web/B-反馈与纠错/B1-反馈处理.md) ｜ 接口：[api/web/feedback.md](../../api/web/feedback.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 页头 | 标题 + 内联筛选：**类型**下拉（全部 / 产品反馈 / 菜品反馈）· **处理状态**下拉（全部 / 未处理 / 已处理）—— 即选即查 |
| 列表卡片 | 标题行（关联菜品，产品反馈显示「—」+ 类型 tag）｜ **正文**（3 行截断）｜ 未处理时卡面「标记处理」按钮 |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + 跳页 |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 正文 | 卡面 3 行截断展示，不做展开、不跳页 |
| **标记已处理** | 卡片内「标记处理」按钮 ⇒ `PATCH /admin/feedback/{id}/handled` ⇒ 刷新列表 |
| 已处理态 | 卡片整体弱化，按钮不渲染 |
| 筛选 | 类型 / 处理状态即选即查，回第 1 页 |
| 无删除 | 反馈行**不提供删除入口** |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 卡片结构 | `ListCard` 两层结构：无封面，标题与类型 tag 同行，正文与操作平铺其后 |
| 类型 tag | 产品反馈低饱和青绿；菜品反馈中性灰 |
| 已处理 | `.list-card--dim`（降低不透明度） |
| 正文 | 常规正文色，长文本 `line-clamp: 3` |
| 卡片字段 | 不含提交时间、处理时间与其它日期类信息 |

## 4 · 不做

- 不编辑反馈正文；
- 不做自动更正、不给学生回执；
- 不做批量处理（量小）。
