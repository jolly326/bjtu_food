# 纠错处理

> 所属端：**运营端**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[B1 纠错查看与选项字典](../../func/web/B-反馈与纠错/B1-纠错查看与选项字典.md) ｜ 接口：[api/web/issues.md](../../api/web/issues.md)

> **本页两段**：「纠错待办」管处置，「纠错选项」管错误类型字典 —— 同页分段切换，不另开页面。

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题「纠错处理」+ **分段切换**（`.seg`：纠错待办 / 纠错选项）+ 条件主操作（「纠错选项」段为「新建选项」；「纠错待办」段 🔴 **无「新建」** —— 纠错由学生产生，运营不建） |
| 待办段 · 筛选区 | **处理状态**下拉（**默认「未处理」**）· **菜品**下拉（可搜索）—— 即选即查 |
| 待办段 · 列表卡片 | 菜品 + 错误类型 tag（主行）｜ 食堂 · 档口（归属路径行）｜ 提交于 · 处理于（指标行）；**该菜待办 ≥ 2 条时追加「待办 N 条」tag**；🔴 **卡面无操作按钮** |
| 待办段 · 卡片操作 | 🔴 **点击浮层**（与其他页同构，见[基线](./公共组件与形态基线.md) §2.3）：未处理 ⇒ 「**去改菜品**」「标记已处理」｜ 已处理 ⇒ 「撤销处理」 |
| 待办段 · 排序 | 服务端：**该菜待办条数降序** → 提交时间降序（被多人反馈的菜顶到最前，无客户端排序） |
| 待办段 · 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + **跳页**（数字输入 + 跳转，越界自动收敛） |
| 选项段 · 列表卡片 | 选项文案（主行）｜ 被引用次数（指标行，只读）；🔴 **卡面无操作按钮** |
| 选项段 · 卡片操作 | **点击卡片直接进编辑界面**；删除入口在编辑界面内，**被引用（`refCount > 0`）时删除按钮置灰**并注明原因 |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 🔴 **去改菜品**（**就地改菜**） | 点击浮层「去改菜品」⇒ **在本页直接打开该菜的编辑弹窗**（与[菜品管理](./菜品管理.md)共用 `DishEditDialog` 组件）—— 不跨菜单跳转；保存成功后刷新纠错列表 |
| **标记已处理** | 点击浮层「标记已处理」⇒ `PATCH { handled: true }`；成功 `ElMessage.success('已标记')` ⇒ 刷新（默认视图下该行随之消失） |
| **撤销处理** | 已处理行点击浮层「撤销处理」⇒ `PATCH { handled: false }`；成功 `ElMessage.success('已撤销')` ⇒ 刷新 |
| 🔴 **系统不自动更正** | 「去改菜品」只**打开编辑弹窗** —— 字段怎么改、改不改，由运营决定；本页**不代改任何字段** |
| 🔴 **无回执** | 本页**没有任何「通知学生」的入口**（设计上就不给回执） |
| 错误类型 | **只读**展示（中文由选项字典翻译）—— 维护选项在本页「纠错选项」段 |
| **新建选项** | 文案必填；保存即生效（免发版）；改名**全站生效**（含历史提交的中文翻译） |
| **删除选项** | 🔴 **引用即禁删**：`refCount > 0` ⇒ **编辑界面内删除按钮置灰禁用** + 原因说明「已被 N 条纠错引用，无法删除」；`refCount = 0` 方可删（再走二次确认） |
| 空态 | 待办段为空 ⇒ 「暂无待处理的纠错」；选项段为空 ⇒ 「暂无选项」（各一句话） |
| 加载失败 | `ElMessage.error`（服务端 `message`） |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 分段切换 | `.seg` / `.seg__item`（胶囊底槽 + 选中项白底主色字），见[基线](./公共组件与形态基线.md) §1.6 |
| 错误类型 tag | 主行内 `.tag`（中性弱化） |
| 处理状态 | 未处理 ⇒ **无标签**，「处理于」整段**不显示**｜ 已处理 ⇒ 处理时间文本（弱化） |
| 操作入口 | 🔴 **无卡面按钮** —— 待办段点击 / 键盘唤起底部浮层（`CardActionSheet` 的 `actions` 动作列表）；选项段点击直接进编辑界面 |
| 顺序 | 待办段服务端按提交时间**降序**；选项段按 `id` 升序（均无客户端排序，见[基线](./公共组件与形态基线.md) §1.6） |

## 4 · 处置动线（一键直达）

```
本页看到纠错  →  点击卡片「去改菜品」 ⇒ 本页直接弹出该菜编辑弹窗，改对字段（菜名 / 图 / 位置 / 下架）
              →  点击「标记已处理」
```

> 「已停售关闭」这类选项 ⇒ 在编辑弹窗里把状态切到「已下架」，再标记。
> 🔴 保存成功**不自动**标记已处理 —— 两步各自留痕（部分反馈不涉及修改菜品）。
