# 档口管理

> 所属端：**运营端**
> 归属功能：[A2](../../func/web/A-主数据维护/A2-档口管理.md) ｜ 接口：[api/web/stalls.md](../../api/web/stalls.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 内联筛选（所属食堂）+「新建」 |
| 筛选区 | 已并入顶栏（所属食堂下拉，即选即查），不单独占一行 |
| 列表卡片 | **16:9 封面**（无图同形占位）｜ 名称（主行）｜ 所属食堂（归属路径行）｜ 楼层 · 窗口号 · 菜品数（指标行，只读）｜ 状态 tag（正常 / 已停用）—— 卡面无操作按钮（点击卡片进编辑，删除在编辑界面内） |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + **跳页**（`PaginationBar`） |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属食堂（下拉）· 名称 · 楼层（下拉，**前端固定常量**）· 窗口号（可选）· 状态（正常 / 已停用，默认正常）· 档口图片（16:9，选图仅本地预览、保存时上传） |
| **楼层下拉的取值** | 🔴 无字典端点 —— 选项来自**前端固定常量**，必须与**后端校验清单逐字一致**：<br>`负一层` ｜ `一层` ｜ `二层` ｜ `三层` ｜ `四层` |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 入口在**编辑界面内**（`.btn--danger`）⇒ **整卡内容切换**为「确认删除」视图（取消回到表单）；🔴 文案：「删除后不可恢复。**若该档口下仍有菜品，删除会被拒绝。**」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 楼层 | 指标行纯文本（值即汉字）；与窗口号同段「楼层 · 窗口 N」，**全空则整段不显示** |
| 窗口号 | 「窗口 N」；未填不显示（同上段落规则） |
| 菜品数 | 指标行只读统计，弱化 |
| **封面图** | 列表卡片 16:9 封面（无图同形占位）；弹窗内 16:9 预览，与食堂 / 菜品页统一 |
| 顺序 | 服务端按 `id` 升序（无客户端排序） |
