# 档口管理

> 所属端：**运营端**
> 归属功能：[A2](../../func/web/A-主数据维护/A2-档口管理.md) ｜ 接口：[api/web/stalls.md](../../api/web/stalls.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 页头 | 标题 + 内联筛选（所属食堂）+「新建」；吸顶于内容区上界 |
| 筛选区 | 已并入页头（所属食堂下拉，即选即查），不单独占一行 |
| 列表卡片 | 16:9 封面（无图同形占位）｜ 标题行（名称 + 状态 tag：正常 / 已停用）｜ 单行元信息（菜品数 · 楼层 · 窗口号）—— 卡面无操作按钮（点击卡片进编辑，删除在编辑界面内） |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + **跳页**（`PaginationBar`） |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 宽版弹窗字段：所属食堂（下拉）· 名称 · 楼层（下拉，**前端固定常量**）· 窗口号（可选）· 状态（正常 / 已停用，默认正常）· 档口图片（16:9，选图仅本地预览、保存时上传）；走 `.edit-grid` 两列栅格，三行分别为「所属食堂 / 名称」「楼层 / 窗口号」「状态 / 图片」 |
| **楼层下拉的取值** | 🔴 无字典端点 —— 选项来自**前端固定常量**，必须与**后端校验清单逐字一致**：<br>`负一层` ｜ `一层` ｜ `二层` ｜ `三层` ｜ `四层` |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 入口在**编辑界面内**（`.btn--danger`）⇒ **整卡内容切换**为「确认删除」视图（取消回到表单）；🔴 文案：「删除后不可恢复。**若该档口下仍有菜品，删除会被拒绝。**」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 卡片结构 | `ListCard` 两层结构：标题与状态同行，元信息合并为一行；视觉层级靠字号与文字色 |
| 元信息 | 菜品数、楼层、窗口号合并为一行只读统计：「窗口 N」仅在填写时出现；楼层与窗口号全空时显示「位置未填写」 |
| 封面图 | 列表卡片 16:9 封面（无图同形占位）；弹窗内 16:9 预览，与食堂 / 菜品页统一 |
| 编辑弹窗 | 与菜品编辑同构：宽版卡片 + `.edit-grid` 两列字段栅格；桌面居中 / 窄屏贴底，标题与操作区常驻、字段区在 `.dialog__body` 内单独滚动（操作区不遮挡字段与上传按钮）；≤`767px` 收为单列；输入与按钮触控目标 ≥44px、间距 ≥8px |
| 顺序 | 服务端按 `id` 升序（无客户端排序） |
