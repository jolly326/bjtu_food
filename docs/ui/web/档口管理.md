# 档口管理

> 所属端：**运营端**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A2](../../func/web/A-主数据维护/A2-档口管理.md) ｜ 接口：[api/web/stalls.md](../../api/web/stalls.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 主操作「新建」 |
| 筛选区 | **所属食堂**下拉（即选即查） |
| 列表卡片 | 名称（主行）｜ 所属食堂（归属路径行）｜ 楼层 · 窗口号 · **海报数** · 菜品数（指标行，只读）—— 卡面无操作按钮（编辑 / 删除走长按浮层） |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属食堂（下拉，必填）· 名称（必填）· 楼层（下拉，**前端固定常量**）· 窗口号（可选）—— **无海报字段**（海报在 [海报管理](./海报管理.md)） |
| **楼层下拉的取值** | 🔴 无字典端点 —— 选项来自**前端固定常量**，必须与**后端校验清单逐字一致**：<br>`负一层` ｜ `一层` ｜ `二层` ｜ `三层` ｜ `四层` |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 🔴 确认文案：「删除后不可恢复。**若该档口下仍有菜品，删除会被拒绝。**」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| **海报数** | 指标行内只读统计，弱化；海报的增删改与上下架全部在 [海报管理](./海报管理.md) |
| 楼层 | 指标行纯文本（值即汉字）；与窗口号同段「楼层 · 窗口 N」，**全空则整段不显示** |
| 窗口号 | 「窗口 N」；未填不显示（同上段落规则） |
| 菜品数 | 指标行只读统计，弱化 |
| **不出图** | 本页无缩略图 —— 规则见[基线](./公共组件与形态基线.md) §1.6：档口卡的识别物是名称与位置（位置已在指标行里） |
| 顺序 | 服务端按 `id` 升序（无客户端排序，见[基线](./公共组件与形态基线.md) §1.6） |
