# 档口管理

> 所属端：**管理端（运营）**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A2](../../func/web/A-主数据维护/A2-档口管理.md) ｜ 接口：[api/web/stalls.md](../../api/web/stalls.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 主操作「新建」 |
| 筛选区 | **所属食堂**下拉 + 「查询」/「重置」 |
| 表格 | 名称 ｜ 所属食堂 ｜ 楼层 ｜ 窗口号 ｜ **海报数**（只读）｜ 菜品数（只读）｜ 更新时间 ｜ 操作 |
| 分页 | `total, prev, pager, next` |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属食堂（下拉，必填）· 名称（必填）· 楼层（下拉，**前端固定常量**）· 窗口号（可选）—— **无海报字段**（海报在 [海报管理](./海报管理.md)） |
| **楼层下拉的取值** | 🔴 无字典端点 —— 选项来自**前端固定常量**，必须与**后端校验清单逐字一致**：<br>`负一层` ｜ `一层` ｜ `二层` ｜ `三层` ｜ `四层` |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 🔴 确认文案：「删除后不可恢复。**若该档口下仍有菜品，删除会被拒绝。**」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| **海报数列** | 只读统计，弱化；海报的增删改、排序与上下架全部在 [海报管理](./海报管理.md) |
| **为何本页不展示图片** | 🔴 规则：**列表只放「能区分行」的图片**。档口行的识别物是名称与位置（位置在列里）⇒ 本页不出图；海报缩略图只在[海报管理](./海报管理.md)（行即海报）出现；菜品图不承担识别作用 ⇒ [菜品管理](./菜品管理.md) 也不展示 |
| 楼层列 | 纯文本（值即汉字） |
| 菜品数列 | 只读统计，弱化 |
| 顺序 | 服务端固定按 `id` 升序（🔴 客户端不做表头排序） |
