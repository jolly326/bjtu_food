# 档口管理

> 所属端：**管理端（运营）**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A2](../../func/web/A-主数据维护/A2-档口管理.md) ｜ 接口：[api/web/stalls.md](../../api/web/stalls.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 主操作「新建」 |
| 筛选区 | **所属食堂**下拉 + 「查询」/「重置」 |
| 表格 | 名称 ｜ 所属食堂 ｜ 楼层 ｜ 窗口号 ｜ **海报** ｜ 菜品数（只读）｜ 更新时间 ｜ 操作 |
| 分页 | `total, prev, pager, next` |

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属食堂（下拉，必填）· 名称（必填）· **海报**（上传，可选）· 楼层（下拉，**前端固定常量**）· 窗口号（可选） |
| **楼层下拉的取值** | 🔴 无字典端点 —— 选项来自**前端固定常量**，必须与**后端校验清单逐字一致**：<br>`负一层` ｜ `一层` ｜ `二层` ｜ `三层` ｜ `四层` |
| 海报上传 | `el-upload` ⇒ 取回**绝对 URL**；已在库时显示缩略图 + 「移除」按钮（移除 = 提交 `null`） |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 🔴 确认文案：「删除后不可恢复。**若该档口下仍有菜品，删除会被拒绝。**」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| **海报列** | **缩略图**（高 40px，按 **3:4** 竖版裁切）；未上传显示「—」 |
| **为何海报在列表展示** | 🔴 规则：**列表只放「能区分行」的图片**。海报是档口的**识别物**（有海报才上「橱窗」），一眼可核对素材进度 ⇒ 保留；菜品图不承担识别作用 ⇒ [菜品管理](./菜品管理.md) 不展示 |
| 楼层列 | 纯文本（值即汉字） |
| 菜品数列 | 只读统计，弱化 |
| 顺序 | 服务端固定按 `id` 升序（🔴 客户端不做表头排序） |

## 4 · 出图提示（运营须知）

🔴 海报是**学生端「橱窗」tab 的唯一内容**，且学生端**不叠加任何文本** ⇒ **档口名称 / 所属食堂 / 楼层窗口必须画进海报图里**。

- 比例 **3:4**（竖版），素材须按此出图；
- **未上传海报的档口不会出现在「橱窗」**；
- 素材与页面口径见 [`ui/client/档口海报.md`](../client/档口海报.md)。
