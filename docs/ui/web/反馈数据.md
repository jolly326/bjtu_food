# 反馈数据（点赞数）

> 所属端：运营端（Web） ｜ 鉴权：🔑 需登录
> 返回：[UI 总览](./README.md) ｜ 功能见 [`B1-反馈查看`](../../func/web/B-反馈数据/B1-反馈查看.md)

## 页面结构

| # | 区块 | 内容 |
|---|---|---|
| 1 | 菜品列表 | 每菜一行：`菜名` ｜ `点赞数`（来自 `dish.likeCount`）｜ 纠错标记 |
| 2 | 纠错处置 | 进入 B2 纠错查看（见 [`B1`](../../func/web/B-反馈数据/B1-反馈查看.md) 同源数据） |

## 视觉规格

- 列表行：菜名（`--text-title`）＋ 点赞数（`--text-body`，前置 `heart` 图标 `tone="primary"`）＋ 纠错状态（`--text-tertiary`）。
- 🔴 不展示任何用户标识；不修改点赞数。
