## 技术形态

- 列表 / 筛选 / 表单 / 弹窗 / 标签一律为**原生 HTML + 项目内 CSS 类**（`.list-card` / `.filters` / `.dialog` / `.tag` / `.btn`），样式取值全部引用 `--el-*` 变量；公共类盒模型**唯一收口**在 [theme.css](../../../web/src/styles/theme.css)。
- **Element Plus 只消费两处**：`element-plus/dist/index.css`（主题变量与基础样式）、程序式 `ElMessage` / `ElMessageBox`。
- **列表页共用分页状态机** `web/src/composables/usePagedList.ts`：页大小 20 单点、翻页 / 筛选回第 1 页、末页删空自动回退 —— 视图只声明「取一页数据」的 fetcher。
- **构建分包**（`web/vite.config.ts` `manualChunks`）：`vendor-vue` / `vendor-element-plus` 独立 chunk，页面按路由懒加载，长缓存命中。

## 导航结构

- **全局顶层导航栏**（固定顶部，`56px`）：左侧品牌名 `知行食记`（衬线）+ 日期；右侧**操作员用户名文本**（弱化正文，非按钮、无下拉菜单；账号名随会话持久化，刷新不丢）。
- **底部应用坞**（Dock 式，固定底部居中悬浮胶囊，规格见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.3）：**七个**功能入口（食堂 / 档口 / 菜品 / 海报 ｜ 评分数据 / 纠错处理 / 纠错选项，组间分隔线）+ 分隔线 + 「退出登录」；悬停放大上浮 + 名称气泡、激活项主色 + 底部圆点指示。
- **无二级页面**（**没有详情页**）—— 所有增删改都在**居中弹窗**内完成。
- 🔴 **唯一的跨菜单跳转**：纠错处置时，从「纠错处理」**一键直达**「菜品管理」并**自动打开该菜的编辑弹窗**（带 `dishId` 参数）—— 见 [纠错处理.md](./纠错处理.md) §4。
- 未登录 ⇒ 直接跳登录页；🔴 **没有**注册 / 找回密码入口。

## 页面范式（统一「列表卡片 + 弹窗」）

```
┌ 顶栏：页面标题 + 主操作「新建」─────────────┐
├ 筛选区（可选）：下拉（即选即查）──────────┤
├ 卡片（响应式多列，窄屏单列）：业务信息（+ 只读统计）｜处置动线仅纠错页 ┤
└ 分页：共 N 条 + 上一页 / 页码 / 下一页 ──────┘
        ↑ 新建 ⇒ 顶栏按钮 → 居中弹窗
        ↑ 编辑 / 删除 ⇒ 长按 · 右键卡片 → 底部浮层（删除再走确认弹窗）
```

> 详细规格（弹窗宽度 / 删除确认文案 / 状态口径 / 分页）见 [公共组件与形态基线.md](./公共组件与形态基线.md)，**页面稿只写本页用法**。
