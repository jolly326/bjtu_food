## 导航结构

- **全局顶层导航栏**（固定顶部）：左侧品牌名 `知行食记`（衬线字体）+ 日期；右侧 `Admin` 按钮（单按钮，橙色主按钮）。
- **底部应用坞**（Dock 式，固定底部居中悬浮胶囊，规格见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.2）：**七个**功能入口（食堂 / 档口 / 菜品 / **海报** ｜ 评分数据 / 纠错处理 / **纠错选项**，组间分隔线）+ 「退出登录」；悬停放大上浮 + 名称气泡、激活项主色 + 圆点指示。
- **无二级页面**（**没有详情页**）—— 所有增删改都在**居中弹窗**内完成。
- 🔴 **唯一的跨菜单跳转**：纠错处置时，从「纠错处理」**一键直达**「菜品管理」并**自动打开该菜的编辑弹窗**（带 `dishId` 参数）—— 见 [纠错处理.md](./纠错处理.md) §4。
- 未登录 ⇒ 直接跳登录页；🔴 **没有**注册 / 找回密码入口。

## 页面范式（统一「列表 + 弹窗」）

```
┌ 顶栏：页面标题 + 主操作「新建」─────────────┐
├ 筛选区（可选）：下拉 / 输入 + 查询 / 重置 ───┤
├ 表格：业务列（+ 只读统计列）+ 行内操作 ──────┤
└ 分页：共 N 条 ─────────────────────────────┘
        ↑ 新建 / 编辑 ⇒ 居中弹窗　｜　删除 ⇒ 确认弹窗
```

> 详细规格（弹窗宽度 / 删除确认文案 / 六态 / 分页）见 [公共组件与形态基线.md](./公共组件与形态基线.md)，**页面稿只写本页用法**。
