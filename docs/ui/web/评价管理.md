# 评价管理

> 所属端：**管理后台（Web）** ｜ 页面 / 单元：**评价管理**（列表 + 隐藏 / 恢复 / 删除）｜ 目标路由：`/reviews`
> **覆盖**：B1 评价管理（`review` 的**隐藏 / 恢复显示 / 删除**）。
> **不覆盖**：列表通用骨架（六态 / 分页 / 列序 / 交互与状态）→ [列表页模板.md](./列表页模板.md) §一；组件规格 → [公共组件与形态基线.md](./公共组件与形态基线.md)；字段 / 端点 / 回执口径 → [B1 功能文档](../../func/web/B-UGC治理/B1-评价管理.md)；举报的处置在 [反馈与举报.md](./反馈与举报.md) §B3。

## 一、页面构成

```
[ h2 评价管理 ]                                    ← 无主按钮（评价由学生产生）
[ 状态▾ | 关键词 | ⨯菜品 #12 | ⨯用户 #7 ]      [ 查询 ] [ 重置 ]
┌ .table-wrap ──────────────────────────────────────────────────────────────────┐
│ 评价者(头像+昵称) │ 菜品    │ 评分    │ 内容      │ 配图     │ 状态     │ 发表时间 │ 操作              │
│ 食客1234          │ 番茄炒蛋 │ ★4.5 │ 分量足…  │ 🖼🖼    │ ●显示中  │  …      │ 隐藏 删除          │
└───────────────────────────────────────────────────────────────────────────────┘
                                          [ 共 N 条 · 页码 ]
＋ 隐藏弹窗（520）：可选附注（≤200 字）+ 投递说明
＋ 删除确认（ElMessageBox）
```

| # | 区域 | 要点 |
|---|---|---|
| 1 | **页头** | `h2`「评价管理」；**无主按钮**（本页不产生数据，只有处置动作） |
| 2 | **筛选区** | ① **状态**▾（全部 / 显示中 / 已隐藏）② **关键词**（评价正文）③ **已带入的条件 chip**：从别处深链进来的 `dishId` / `userId`（显示为「⨯ 菜品 #12」样式，点击 `⨯` 即清除并查询）④ 「查询」+「重置」 |
| 3 | **列** | `评价者`（**32×32 圆形头像 + 昵称**，头像取 `userAvatar`（绝对 URL）；无头像 → 统一占位，规格见 §二）→ `菜品`（`dishName`）→ `评分`（**内联 SVG 星形图标（`--color-star`）在数字前** + 数字（`tabular-nums`），只显本条评分；SHALL NOT 用文本字符「★」拼在数字后 —— 图形档与 `--color-star` 着色必须由图标承载，与既有 `.num` 等宽列并存）→ `内容`（**`ClampText`**：折叠 2 行、溢出时可「展开」读全文；**不设配图角标** —— 配图列缩略图直接呈现）→ `配图`（**56px 缩略图，点击开大图**）→ `状态` → `发表时间`（**本页时间列就是 `createdAt`**）→ `操作` |
| 4 | **状态列** | **恒用 `StatusTag`**（`kind='review'`，见 [基线 §2.3](./公共组件与形态基线.md)）：`hidden = false` → **显示中**（绿）；`hidden = true` → **已隐藏**（红）。**文案以 [设计变量.md 的「状态文案总表」](./设计变量.md) 为准**，页面不自写 `.tag-*` |
| 5 | **行操作** | `显示中` 行 → `隐藏` ｜ `删除`；`已隐藏` 行 → `恢复显示` ｜ `删除` |
| 6 | **详情载体** | 本页**无详情端点** ⇒ 详情用 **`BaseDrawer` + 列表行既有出参**组装（`GET /admin/reviews` 出参即全部字段）：正文**全文展示不截断**（`pre-wrap` + `overflow-wrap: anywhere`）、配图 140px 缩略图、**点击开 `ImagePreview` 大图预览**（多图左右切换 / `←` `→` / `ESC` / 遮罩关闭 / 打开时锁背景滚动）；底部复用「隐藏·恢复显示 / 删除」动作与确认文案。**列表内**正文仍以 `ClampText` 折叠、配图为 **56px 缩略图**（点击即开大图 —— 便于不进详情快速核验） |

## 二、视觉规格（引用 [公共组件与形态基线.md](./公共组件与形态基线.md)）

| 元素 | 规格 |
|---|---|
| 表格 / 六态 / 分页 / 列序 / 交互 | 沿用 [列表页模板.md](./列表页模板.md) §一 |
| 头像 | `32×32` 圆形 + `--radius-pill` + `--bg-soft` 底；无头像走统一占位（灰底 + 人形图标） |
| 星级 | `--color-star`（**独立语义色，不随主色换肤**）+ 数字（`tabular-nums`）；`1~5` |
| 配图列 | **56px 缩略图**（点击开 `ImagePreview` 大图）；无配图 → `—` |
| 隐藏弹窗 | `BaseModal`（单字段，[基线 §2.1](./公共组件与形态基线.md)） |
| 「时列」特例 | 本页**无 `updatedAt`** —— `review` 表没有该列，`createdAt` 已承载「最后活动时间」（[B1](../../func/web/B-UGC治理/B1-评价管理.md) 的明确例外），**不得为此新增列** |

## 三、交互与状态

| 动作 | 口径 |
|---|---|
| **隐藏** | 打开 `BaseModal`：标题「隐藏评价」；正文区 = **原始评价只读摘要**（昵称 + 评分 + 正文全文，供确认对象）+ **可选附注** `textarea`（≤200 字，下方 `--font-xs` 提示「附注会随站内通知发给作者」）+ 一行投递说明「将向该用户发送站内通知」；底部 `取消` + `隐藏`（`.btn-warn` 语义：驳回 / 负面但不销毁） |
| **恢复显示** | **直接执行**（无确认、无弹窗）：`PUT /admin/reviews/{id}/hidden { hidden: false }` → 成功 `ElMessage.success('已恢复显示')` → `reload()` |
| **删除** | `ElMessageBox.confirm`：「确认删除该评价？**不可恢复**，且会同步重算该菜品的均分。」→ 确认后 `DELETE` → `reload()` |
| 处置后反馈 | 成功提示后 `reload()`（状态列即时翻转）；失败原文透出（如 `4001`「评价不存在」→ 提示后 `reload()` 刷新） |
| 深链 | 支持 `/reviews?dishId=` / `?userId=`（看板或菜品页跳转带入，作为 §一 的 chip 显示）；`/reviews?id=` 定位到该行并**高亮该行**（`--color-primary-bg` 底） |
| 空态 | 三态盒「暂无数据」；有筛选时提示「没有符合条件的评价」（区别于"库里本来没有"） |
| 本页不做 | 批量处置、编辑评价内容、导出（[B1](../../func/web/B-UGC治理/B1-评价管理.md) 明确一期不做） |

## 四、组件清单（**本页用法**）

| 组件 | 本页用法 | 规格 |
|---|---|---|
| `StateBox` | 列表三态 | [基线 §2.2](./公共组件与形态基线.md) |
| `BaseModal` | 隐藏（附注输入） | [基线 §2.1](./公共组件与形态基线.md) |
| 头像 / 星级 | 页面私有呈现（**不升格**公共组件：仅本页与 B3 摘要用） | §二 |

> 本页**不使用**：`ImageUpload`、`useReorder`。**状态列恒用 `StatusTag`**（`kind='review'`：显示中 / 已隐藏，见 [基线 §2.3](./公共组件与形态基线.md)）—— **页面不自写 `.tag-*`**。
> 本页**使用**：`BaseDrawer`（评价详情抽屉）、`ImagePreview`（配图大图预览）。

## 五、数据字段

- `ReviewAdminVO`、`ReviewHiddenReq`、列表查询参数与错误码：见 [B1 功能文档](../../func/web/B-UGC治理/B1-评价管理.md) 的「字段」节。
- **`hidden` 是 boolean**（库列 `is_hidden` 由持久层映射）—— 界面不出现 `0/1`。
- **`images`**：绝对 URL 数组（≤3）；本页只消费**张数**。
- **投递口径**：隐藏 / 删除都会向作者投递站内回执（后端行为）；UI **不承诺**"发送成功"，只说明"将发送"（投递失败不阻塞处置）。
