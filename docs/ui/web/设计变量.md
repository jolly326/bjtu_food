# 设计变量（Design Tokens）

> 所属端：**管理后台（Web，Vue 3 + Vite + TypeScript + Element Plus）** ｜ 适用：本目录全部文档 + `web/src/**`
> **真源声明**：变量**取值**的唯一真源是**代码** —— 令牌声明 = `web/src/styles/variables.css`；消费与 Element Plus 映射 = `web/src/styles/shared.css`（由 `web/src/main.ts` 引入）。
> 本文档是**对照表 + 命名与使用约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0. 使用总则

1. **一律走 CSS 变量**：页面 / 组件样式内**只允许** `var(--xxx)`；**SHALL NOT** 裸写色值或尺寸。
2. **三层结构**：

| 层 | 含义 | 本项目落点 |
|---|---|---|
| Primitive（原值） | 与语义无关的原始值 | **未单独导出**（内联在各语义 token 的值里，属已知简化） |
| **Semantic（语义）** | 按用途命名（`--color-primary` / `--text-secondary` / `--space-4`） | **主用层**：页面 / 组件只消费这一层 |
| Component（组件级） | 组件私有 token（`--table-header-bg` / `--btn-secondary-*`） | 少量：表格、聚合 tab、次级按钮 —— **仅其组件消费** |

3. **同值不同语义**允许（如 `--radius` 与 `--radius-md` 同为 `8px`）—— 语义键服务于「改一处即全站生效」；**零消费即删**（见 §8）。
4. **一端一语言**：本表与 [学生端设计变量](../client/设计变量.md) **同源不同载体** —— 同名 token 尽量同值，差异项在 §5 逐条登记。

## 1. 主题与明暗

| 项 | 口径 |
|---|---|
| **默认主题** | **深色沉稳控制台**（`:root` 即深色）—— 近黑 / 深灰底 + 浅灰文字，适合长时间盯屏 |
| **浅色态** | **跟随系统**：`@media (prefers-color-scheme: light)` 覆盖同名语义 token 为浅色观感（近白底 + 深灰文字） |
| **切换方式** | **自动跟随系统**（无手动切换开关）；两态共用**同一套语义 token 名**，页面 / 组件**不写条件分支** |
| 品牌主色 | 两端同源：**暖橙**（学生端的「白字安全橙」`#B4531A`）；深色态下**文字档提亮**（见 §2.1） |

> 页面 / 组件**SHALL NOT** 针对明暗写两套样式 —— 只消费语义 token，明暗由 §1 的两态声明承担。

## 3. 非颜色

### 3.1 圆角

> **跨端同值口径**：圆角以 **px 为基准**与学生端统一 —— 同档位 client `rpx` = web `px × 2`（@375pt，`1rpx = 0.5px`）；两端同档**同名同值**（详见 [§5](#5-与小程序端的对照) 圆角行）。
> 档位层级「块越大越圆」：**微件/标签 12 < 控件 16 < 面板 20**；弹层档仅学生端单设（28px / 56rpx，底部半屏 sheet 顶部），web 弹窗仍消费 `--radius-card`。
> 全部取值落在 **4pt 栅格**（12 / 16 / 20 / 28）。

| Token | 值 | 用途 |
|---|---|---|
| `--radius-xs` | `12px` | 微件（焦点环 / 拖拽手柄焦点环等极小件） |
| `--radius-sm` | `12px` | 小件：缩略图（56/84/140px）/ 状态标签底（与 xs 同值、语义不同） |
| `--radius` / `--radius-md` | `16px` | **按钮 / 输入框 / 导航项（控件主档）** |
| `--radius-card` | `20px` | **卡片 / 表格容器 / 弹窗（面板主档）** |
| `--radius-pill` | `999px` | 胶囊（标签 / 开关）—— 形状语义，不随档位调整 |

### 3.2 间距（4pt 栅格）

`--space-1` 4 ｜ `--space-2` 8 ｜ `--space-3` 12 ｜ `--space-4` 16 ｜ `--space-5` 20 ｜ `--space-6` 24 ｜ `--space-8` 32 ｜ `--space-10` 40（单位 `px`）

**SHALL NOT** 裸写 `margin` / `padding` / `gap` 的 px 间距（一律 `--space-*`）；`1px` 边框与 ≤`2px` 的定位/发丝微调除外。组件间距经核查已收敛到 `--space-*`（仅 `ImageUpload` 删除钮 `top: 2px`、部分芯片 `padding: 1px` 等 ≤2px 微调，属允许范围）。

### 3.4 动效

| Token | 值 | 用途 |
|---|---|---|
| `--duration-fast` | `120ms` | 按压 / 微交互 |
| `--duration-base` | `200ms` | 常规过渡（hover / 边框 / 颜色） |
| `--duration-slow` | `300ms` | 较大位移 |

| `--duration-reduced` | `180ms` | 降级块的**过渡上限**（同上） |
| `--ease-out` | `cubic-bezier(.23,1,.32,1)` | **全站主缓动** |

> `prefers-reduced-transparency: reduce` 下毛玻璃（`backdrop-filter`）关闭。

| `--drag-handle-size` | 拖拽手柄**字形**尺寸（`DragHandle` 消费；热区由 `--space-1` 内距扩展） | 排序列视图（首页筛选视图 / 举报原因 / 属性维度 / 取值 / Banner）|

> **「零消费即删」已执行**（§8 #4）：`--table-row-active` / `--agg-tabs-bg` / `--card-hover-shadow` / `--nav-height` / `--nav-item-active-bg` / `--spring-damping` / `--spring-response` / `--color-price-soft` / `--color-warning-soft` **全仓无任何消费方**，已从 `variables.css` 移除（含浅色态重声明）；将来真需要时再入表。

## 4. Element Plus 主题映射

Element Plus 只作**兜底与函数式能力**（`ElMessage` / `ElMessageBox` / 少量按需组件），但其默认蓝必须**全量覆盖**为项目 token：

| EP 变量 | 映射到 |
|---|---|
| `--el-color-primary` | `--color-primary`（填充档） |
| `--el-color-primary-light-3` | **`--color-primary-text`**（本项目只把它当**文字色**消费，故指向文字档） |
| `--el-color-primary-light-5/7/8/9` | `color-mix(主色, #fff)` |
| `--el-color-primary-dark-2` | `--color-primary-dark` |
| `--el-color-success` / `--warning` / `--danger` / `--error` | 同名状态色 token |
| `--el-border-radius-base` / `-small` / `-round` | `--radius` / `--radius-sm` / `--radius-pill` |
| `--el-font-size-base` | `--font-base` |
| `--el-bg-color` / `-overlay` / `--el-fill-color-blank` / `--el-fill-color-light` / `-lighter` | `--bg-card` / `--bg-soft` |
| `--el-text-color-primary` / `-regular` / `-secondary` / `-placeholder` | `--text-primary` / `--text-secondary` / `--text-muted` / `--text-light` |
| `--el-border-color` / `-light` / `-lighter` | `--border-color` / `--border-light` |
| `--el-mask-color` | `rgba(0,0,0,.45)`（深色）/ `rgba(0,0,0,.35)`（浅色） |

**EP 弹层也走毛玻璃**：`.el-overlay` / `.el-dialog` / `.el-message-box` / `.el-popper.is-light` → `--blur-material`。
**EP 开关**：`.el-switch` 的 on/off 色指向 `--color-primary` / `--border-strong`，轨道用胶囊圆角。
**两态同步**：浅色态下 `--el-*` 需重声明一遍（不能只依赖语义 token 联动）。

## 5. 与小程序端的对照

| 项 | 学生端（小程序） | 管理端（Web） | 结论 |
|---|---|---|---|
| 主色 | `#B4531A`（暖橙） | 同值 | ✅ **同源** |
| 主色文字档 | `#B4531A` | 深色态提亮为 `#F97316` | ⚠️ **刻意不同**（深底需更亮才达标） |
| 星级色 | `#FBBF24` | 同值 | ✅ 同源（两端都不随主色换肤） |
| 状态色（语义） | `error` `#C62828` ／ `warning` `#E67E22` ／ `success` `#2E7D32` | 深色提亮 `#F87171` / `#FBBF24` / `#4ADE80`；浅色加深 `#C81E1E` / `#B45309` / `#15803D` | ⚠️ **刻意不同**：深底须提亮、实底白字须加深，两端各自按对比度实测取值（**语义同源、载体不同**） |
| 默认主题 | 浅色暖橙 | **深色控制台** + 跟随系统浅色 | ⚠️ **刻意不同**（桌面长时段盯屏） |
| 单位 | `rpx`（`1rpx = 0.5pt`） | `px` | 载体差异 |
| 圆角标度 | 微件 `--radius-xs` = `24rpx`（12px）｜控件 `--radius-btn` / `--radius-icon` = `32rpx`（16px）｜面板 `--radius-card` = `40rpx`（20px）｜弹层 `--radius-modal` = `56rpx`（28px） | 微件 / 小件 `--radius-xs` / `--radius-sm` = `12px`｜控件 `--radius` / `--radius-md` = `16px`｜面板 `--radius-card` = `20px` | ✅ **同值口径**（px 基准对齐，`1rpx = 0.5px` @375pt）：微件 12 ↔ 控件 16 ↔ 面板 20，两端逐档同值；胶囊（`999`）与正圆（`50%`）为形状语义，不设数值档。弹层档仅学生端单设（底部半屏 sheet 顶部 28px），web 弹窗消费 `--radius-card`（20px） |
| 按压反馈 | **`opacity` / 浅底微降，SHALL NOT `scale`** | **`transform: scale(0.97)`** | ⚠️ **刻意不同**：桌面指针交互下轻微缩放是通用语言；移动端禁用 `scale` 以避免列表抖动 |
| 触达下限 | `88rpx`（44pt） | 无硬性触达口径；**指针目标**按 `--space-*` 与控件高度保证 | 载体差异 |
| 缓动 | `--ease-out` 唯一 | `--ease-out` 主用 + `--ease-in-out` / `--ease-drawer` | Web 多一条抽屉曲线 |
| 动效降级 | `prefers-reduced-motion` | 同 + **`prefers-reduced-transparency`**（毛玻璃关闭） | Web 多一项 |
| 透明度弱化 | `.is-disabled` 统一令牌 | 各 `.btn-*:disabled { opacity: .5 }` | ⚠️ 见 §8 |

## 6. 红线（改 `web/` 前必查）

1. 页面 / 组件样式**SHALL NOT** 裸 hex / `rgb()` / `rgba()`（例外：`transparent` / `currentColor` / `inherit` / `color-mix()` 内部）。
2. **SHALL NOT** 裸写圆角、间距、字号、字重、时长、缓动 —— 一律 `var(--xxx)`。
3. **SHALL NOT** 页面私有页面底色 —— 一律 `--bg-page`。
4. **SHALL NOT** 用填充档 `--color-primary` 当文字色 —— 文字一律 `--color-primary-text`。
5. 明暗**不写条件分支** —— 只消费语义 token。
6. 新增 token 先入 `variables.css`（消费点入 `shared.css`），再同步本表。

## 8. 目标态约定（重构时遵守）

> 本节是**规格约定**（不是现状盘点）：`web/` 重构时按下表落地，避免同一件事出现两种值。

| # | 约定 | 内容 |
|---|---|---|
| 1 | **按钮类只此六档** | `.btn-primary` / `.btn-secondary` / `.btn-success` / `.btn-warn` / `.btn-danger` / `.link` —— **不引入** `.btn-ghost` 一类别名（[基线 §1.8](./公共组件与形态基线.md)） |
| 2 | **表格 component token 必须被消费** | `--table-header-bg` / `--table-row-hover` / `--table-border` / `--table-th-padding` / `--table-td-padding` **由表格样式直接消费**（单一真源），不另设 `--bg-soft` / `--bg-hover` 并列值 |
| 3 | **禁用态统一** | 全站一处定义（`opacity: .5` + `cursor: not-allowed`），各组件**不自设**弱化档 |
| 4 | **本期不引入** `--nav-height` / `--spring-*` | 无顶部栏、无弹簧语汇；真需要时再入表（**零消费即删**原则） |
| 5 | **EP `light-5/7/8/9` 的混色方向** | 深色态下**先按底色重算**（混背景而非混白），消费这些档前必须校验 |
| 6 | **尺寸先提炼为 component token 再消费** | 抽屉宽 / 抽屉内距 / 条件行高 / 拖拽手柄尺寸：在 `variables.css` 声明 token → 组件消费 → 回填本表（与 [基线 §2.6](./公共组件与形态基线.md) 同一笔账） |
| 7 | **「零消费即删」的适用边界**（2026-10-06 口径） | ① **成套标度保留全档**：字号 / 字重 / 行高 / 字距 / 时长 / 缓动 / 圆角 —— 属**设计系统标度**，档位成套保留（为一致的取值体系服务），**不逐档做零消费清理**；② **单点组件 token**（`--table-*` / `--agg-tab-*` / `--card-hover-*` / `--color-price` / `--color-*-bg` 等按具体组件语义命名的项）**按零消费即删**：无消费者即从 `variables.css` 与**本表**同批删除；③ **跨端对齐 token**（如 `--color-star`）以 [§5](#5-与小程序端的对照) 对照表为准，**为其「两端同名同值」的登记价值保留**，不受本条清理约束 |
