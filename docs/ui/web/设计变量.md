# 设计变量（运营端）

> 所属端：**运营端**（`web/`） ｜ 适用：本目录全部页面稿 + `web/src/**`
> **真源声明**：变量**取值**的唯一真源 = **Element Plus 主题变量（`--el-*`）** + 本项目在 `web/src/styles/theme.css` 的**单点覆盖层**。
> 本文档是**对照表 + 约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **优先用 Element Plus 自带变量**（`--el-color-primary` / `--el-border-radius-base` …），🔴 **不新建平行的自建 token 体系**（唯一自建变量见 §2.3 的 `--web-font-serif`）。
2. 自定义样式只允许走覆盖层的 CSS 变量；🔴 **SHALL NOT 裸写 hex** —— 页面 / 组件内只管引用 `var(--el-*)`，取值只在 `theme.css` 的单点覆盖处。
3. 🔴 **运营端与学生端是两套体系** —— 学生端用自建 token（[`ui/client/设计变量.md`](../client/设计变量.md)），运营端用 Element Plus 默认 + **单点暖调覆盖**；**不共用变量、不跨端复用样式**（唯一的跨端复用是线性 SVG 图标**资源**，见 §2.4）。

## 1 · 视觉基调（知行食记・暖调极简）

| 项 | 口径 |
|---|---|
| **主色** | 🔴 **与学生端逐字同值**（`#B4531A`，见 §2.1） |
| **底色** | 🔴 **纯白色 `#FFFFFF`**（`--el-bg-color-page` / `--el-bg-color`） |
| **中性色** | 暖调深灰正文、柔和灰辅助文字（`--el-text-color-*`，见 §2.1） |
| **圆角** | 基础 `12px` / 小 `8px`（`--el-border-radius-sm`） / 大 `16px` |
| **阴影** | 柔和暖投影 `0 10px 30px rgba(90,70,45,.08)`（`--el-box-shadow-light`） |
| **字体** | 标题用衬线（`--web-font-serif`）、正文与控件用系统无衬线 |
| **图标** | 复用学生端 Lucide 线性 SVG 集（细线、统一线宽、`currentColor` 继承色） |

## 2 · 覆盖层（🔴 单点：`web/src/styles/theme.css`）

### 2.1 Element Plus 变量覆盖

| 变量 | 定稿值 | 用途 |
|---|---|---|
| `--el-color-primary` | `#B4531A` | 品牌主色（与学生端 `COLOR_MAP.primary` 逐字一致） |
| `--el-color-primary-light-3/5/7/8/9`、`--el-color-primary-dark-2` | 由主色派生 | 选中态 / 浅底 |
| `--el-color-success` / `warning` / `danger` / `info` | `#2E7D32` / `#E67E22` / `#C62828` / `#1565C0` | 语义色（标签 / 提示）；`--el-color-error` 为 `danger` 别名 |
| `--el-bg-color-page` / `--el-bg-color` | `#FFFFFF` | 页面纯白基底 / 卡片底 |
| `--el-bg-color-overlay` / `--el-fill-color-blank` | `#FFFFFF` | 弹层 / 控件底 |
| `--el-text-color-primary/regular/secondary/placeholder` | `#2E2A24` / `#574F45` / `#8A7F72` / `#B4A899` | 暖调中性文字 |
| `--el-border-color(-light/-lighter/-extra-light)` | `#E6DCCF` / `#EEE5D9` / `#F3ECE2` / `#F8F2EA` | 柔和分隔线 |
| `--el-fill-color(-light/-lighter)` | `#EFE7DB` / `#F4EDE3` / `#F8F3EC` | 表头 / 弱底 |
| `--el-border-radius-base / small / large` | `12px` / `8px` / `16px` | 纸片圆角；`small` 用于次要按钮 / 小控件 |
| `--el-box-shadow-light` | `0 10px 30px rgba(90,70,45,.08)` | 卡片柔和阴影 |
| `--el-box-shadow-elevated` | `0 14px 38px rgba(90,70,45,.10)` | 悬浮层更重阴影 |

### 2.2 形态覆盖

| 形态 | 口径 |
|---|---|
| 内容区卡片 | `.page`：`#FFFFFF` 底 + 16px 圆角 + 柔和阴影 + 24px 内距 |
| 顶层导航栏 | 固定顶部 56px：左侧品牌名 `知行食记`（衬线）+ 日期；右侧 `Admin` 单按钮（暖橙主按钮） |
| 应用坞 | 悬浮胶囊（白底 + 16px 圆角 + `--el-box-shadow-elevated`）居中于底缘上方：七个功能图标（`AppIcon` 22px）+ 分组分隔线 + 退出登录；悬停放大上浮 + 黑底名称气泡、激活主色 + 底部圆点（见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.3） |
| 弹窗 | `.dialog` 暖白纸片 + 柔和描边与阴影；遮罩 `.mask` 为暖色半透明（`rgba(46,42,36,.35)`） |
| 表格 | 表头暖底（`--el-fill-color-lighter`），行分隔柔和 |
| 主按钮 | 暖橙实底，与应用坞选中态同一主色 |
| 次要按钮 | 描边式：暖橙描边（`--el-color-primary`）、透明底、圆角 `8px`（`--el-border-radius-sm`）、hover / active 浅橙实底 |
| 圆形图片 | 菜品图圆形裁切（`.img--round`：`border-radius: 50%` + `object-fit: cover`），轻拟物纸片感 |

### 2.3 自建变量

| 变量 | 定稿值 | 用途 |
|---|---|---|
| `--web-font-serif` | `'Songti SC', 'Noto Serif SC', 'Source Han Serif SC', Georgia, 'Times New Roman', serif` | 标题衬线字体（`h1` / `h2` / `h3` 统一命中） |

### 2.4 图标

- **资源**：`web/src/assets/icons/*.svg`（38 个 Lucide 线性图标，与学生端同源）。
- **渲染**：`web/src/components/AppIcon.vue`，`stroke="currentColor"` 继承所在元素颜色，`:size` 控制边长。
- 🔴 不引入图标字体 / 内联 `<svg>`；新增图标从同源 SVG 集复制。

## 3 · 红线（改 `web/` 前必查）

| 红线 | 说明 |
|---|---|
| 🔴 主题覆盖**只允许一处** | 页面 / 组件里 **SHALL NOT** 覆盖组件库变量；改值只改 `theme.css` |
| 🔴 **不裸写 hex** | 页面 / 组件样式只用 `var(--el-*)` / `var(--web-font-serif)` |
| 🔴 不引入第二套色板 | 语义色直接用 `--el-color-success / warning / danger / info` |
| 🔴 不跨端抄样式 | 学生端 token（`--bg-page` / `--module-*` / `--radius-*` 等）**不得**出现在 `web/`；仅图标**资源**可复用 |
| 🔴 主色改动**必须双端同改** | 改 `--el-color-primary` 时须同步学生端 `COLOR_MAP.primary` —— 二者是同一个品牌色 |
| 🔴 页面基底必须纯白 | `--el-bg-color-page` / `--el-bg-color` 必须为 `#FFFFFF` |
