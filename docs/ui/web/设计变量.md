# 设计变量（运营端）

> 所属端：**运营端**（`web/`） ｜ 适用：本目录全部页面稿 + `web/src/**`
> **真源声明**：变量**取值**的唯一真源 = **Element Plus 主题变量（`--el-*`）** + 本项目在 `web/src/styles/theme.css` 的**单点覆盖层**。
> 本文档是**对照表 + 约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **优先用 Element Plus 自带变量**（`--el-color-primary` / `--el-border-radius-base` …），🔴 **不新建平行的自建 token 体系**（自建变量仅两枚，见 §2.3）。
2. 自定义样式只允许走覆盖层的 CSS 变量；🔴 **SHALL NOT 裸写 hex** —— 页面 / 组件内只管引用 `var(--el-*)`，取值只在 `theme.css` 的单点覆盖处。
3. 🔴 **运营端与学生端是两套体系** —— 学生端用自建 token（[`ui/client/设计变量.md`](../client/设计变量.md)），运营端用 Element Plus 默认 + **单点暖调覆盖**；**不共用变量、不跨端复用样式**（唯一的跨端复用是线性 SVG 图标**资源**，见 §2.4）。

## 1 · 视觉基调（知行食记・暖调极简）

| 项 | 口径 |
|---|---|
| **主色** | 🔴 **与学生端逐字同值**（`#B4531A`，见 §2.1） |
| **底色** | 🔴 **页面纯白 `#FFFFFF`**（`--el-bg-color-page`）；**卡面 `#FAFAFA`**（`--web-bg-card`，与学生端 `--bg-card` 同值） |
| **中性色** | 暖调深灰正文、柔和灰辅助文字（`--el-text-color-*`，见 §2.1） |
| **圆角** | 卡片 `16px`（`--web-radius-card` / `--el-border-radius-large`）/ 控件 `12px` / 小件 `8px`（`--web-radius-sm`）/ 按钮**胶囊** `--web-radius-pill` |
| **阴影** | 双层极弱弥散（`--el-box-shadow-light` = `0 4px 14px rgba(140,120,100,.06), 0 1px 4px rgba(140,120,100,.04)`；悬浮 `--el-box-shadow-elevated`）；🔴 **卡片不画实线描边** |
| **字体** | 标题用衬线（`--web-font-serif`）、正文与控件用系统无衬线 |
| **图标** | 精选复用学生端同源 Lucide 线性 SVG 子集（10 枚；细线、统一线宽、`currentColor` 继承色，零消费即删） |

## 2 · 覆盖层（🔴 单点：`web/src/styles/theme.css`）

### 2.1 Element Plus 变量覆盖

| 变量 | 定稿值 | 用途 |
|---|---|---|
| `--el-color-primary` | `#B4531A` | 品牌主色（与学生端 `COLOR_MAP.primary` 逐字一致） |
| `--el-color-primary-light-3/5/7/8/9`、`--el-color-primary-dark-2` | 由主色派生 | 选中态 / 浅底 |
| `--el-color-success` / `warning` / `danger` / `info` | `#2E7D32` / `#E67E22` / `#C62828` / `#1565C0` | 语义色（标签 / 提示）；`--el-color-error` 为 `danger` 别名 |
| `--el-bg-color-page` / `--el-bg-color` | `#FFFFFF` | 页面纯白基底 / 弹层与控件底 |
| `--web-bg-card` | `#FAFAFA` | **卡面**（`.page` / `.list-card` / `.overview__item` / 登录卡；与学生端 `--bg-card` 同值） |
| `--el-text-color-primary/regular/secondary/placeholder` | `#44382E` / `#5C5349` / `#8A7C70` / `#B4A899` | 文字层级（与学生端 `--text-title` / `--text-tertiary` 同值） |
| `--el-border-color(-light/-lighter/-extra-light)` | `#E8E3DE` / `#EFEAE4` / `#F4F0EB` / `#F8F5F1` | **仅控件**描边（输入 / 下拉 / 次级按钮 / 分隔条）；🔴 卡片不用 |
| `--el-fill-color(-light/-lighter)` | `#F1EEEA` / `#F7F5F2` / `#FBFAF8` | 弱底 / hover / 占位底 |
| `--el-border-radius-base / large` | `12px` / `16px` | 控件 12 / 卡片 16；小件 `8px` 走 `--web-radius-sm`；按钮胶囊 `--web-radius-pill`（见 §2.3） |
| `--el-box-shadow-light` | `0 4px 14px rgba(140,120,100,.06), 0 1px 4px rgba(140,120,100,.04)` | 卡片双层极弱阴影 |
| `--el-box-shadow-elevated` | `0 12px 32px rgba(140,120,100,.10), 0 2px 8px rgba(140,120,100,.05)` | 悬浮层（弹窗 / 应用坞 / 卡片 hover） |

### 2.2 形态覆盖

| 形态 | 口径 |
|---|---|
| 内容区卡片 | `.page`：`#FAFAFA` 底 + 16px 圆角 + 双层极弱阴影 + 24px 内距，🔴 **无实线描边** |
| 顶层导航栏 | 固定顶部 56px：左侧品牌名 `知行食记`（衬线，`500`）+ 日期；右侧操作员用户名文本（`14px` 弱化正文，非按钮）；底缘用一层极弱投影代替分割线 |
| 应用坞 | 悬浮胶囊（`--el-bg-color-overlay` 底 + 20px 圆角 + `--el-box-shadow-elevated`，无描边）居中于底缘上方：七个功能图标（`AppIcon` 22px）+ 浅色短竖条分组 + 退出登录；悬停轻微上浮放大（`1.06`）+ 名称气泡、激活主色 + 底部圆点（见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.3） |
| 弹窗 | `.dialog` 白纸片 + **无描边** + `--el-box-shadow-elevated` + 20px 圆角；遮罩 `.mask` 暖色半透明（`rgba(46,42,36,.28)`） |
| 按钮 | **统一胶囊**（`--web-radius-pill`，圆角 = 半高）：主按钮暖橙实底、次按钮暖橙细描边透明底、小按钮灰边；按压仅透明度变化，不缩放 |
| 圆形图片 | 菜品图圆形裁切（`.img--round`：`border-radius: 50%` + `object-fit: cover`），轻拟物纸片感 |

### 2.3 自建变量

| 变量 | 定稿值 | 用途 |
|---|---|---|
| `--web-font-serif` | `'Songti SC', 'Noto Serif SC', 'Source Han Serif SC', Georgia, 'Times New Roman', serif` | 标题衬线字体（`h1` / `h2` / `h3` 统一命中） |
| `--web-radius-sm` | `8px` | 次要按钮 / 小控件 / 悬停气泡圆角（原 `--el-border-radius-sm` 更名：真自建变量不再冒用 `--el-` 前缀） |

### 2.4 图标

- **资源**：`web/src/assets/icons/*.svg` —— 与学生端同源取形的 **Lucide 精选子集（10 枚）**：Dock 八枚（`building-2` / `store` / `dish` / `image` / `star` / `report` / `list-checks` / `log-out`）+ 页面「新建」`plus` + 无图占位 `image-broken`。
- **渲染**：`web/src/components/AppIcon.vue`，`stroke="currentColor"` 继承所在元素颜色，`:size` 控制边长。
- 🔴 **零消费即删**：新增前先全仓查引用，无消费的不入库 —— 图标经 `import.meta.glob` 全量打进 `AppIcon` chunk，冗余即包体冗余。
- 🔴 不引入图标字体 / 内联 `<svg>`；新增图标从学生端同源集复制。

## 3 · 红线（改 `web/` 前必查）

| 红线 | 说明 |
|---|---|
| 🔴 主题覆盖**只允许一处** | 页面 / 组件里 **SHALL NOT** 覆盖组件库变量；改值只改 `theme.css` |
| 🔴 **不裸写 hex** | 页面 / 组件样式只用 `var(--el-*)` / `var(--web-font-serif)` |
| 🔴 不引入第二套色板 | 语义色直接用 `--el-color-success / warning / danger / info` |
| 🔴 不跨端抄样式 | 学生端 token（`--bg-page` / `--module-*` / `--radius-*` 等）**不得**出现在 `web/`；仅图标**资源**可复用 |
| 🔴 主色改动**必须双端同改** | 改 `--el-color-primary` 时须同步学生端 `COLOR_MAP.primary` —— 二者是同一个品牌色 |
| 🔴 页面基底必须纯白 | `--el-bg-color-page` / `--el-bg-color` 必须为 `#FFFFFF` |
| 🔴 EP 内部消费的 token 不得按「零消费即删」删除 | `--el-color-primary-light-3/5/7`、`--el-color-primary-dark-2`、`--el-color-info`、`--el-border-color-light` 由 Element Plus 组件内部消费（按钮 hover / 弹层边框 / MessageBox 图标），静态扫描不可见 —— `check:tokens` 列为「零引用」属预期，🔴 保留（theme.css 有注释） |
