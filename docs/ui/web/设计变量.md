# 设计变量（运营端）

> 所属端：**运营端**（`web/`） ｜ 适用：本目录全部页面稿 + `web/src/**`
> **真源声明**：变量**取值**的唯一真源 = **Element Plus 主题变量（`--el-*`）** + 本项目在 `web/src/styles/theme.css` 的**单点覆盖层**。
> 本文档是**对照表 + 约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **优先用 Element Plus 自带变量**（`--el-color-primary` / `--el-border-radius-base` …），🔴 **不新建平行的自建 token 体系**（少量自建变量统一列于 §2.3）。
2. 自定义样式只允许走覆盖层的 CSS 变量；🔴 **SHALL NOT 裸写 hex** —— 页面 / 组件内只管引用 `var(--el-*)`，取值只在 `theme.css` 的单点覆盖处。
3. 🔴 **运营端与学生端是两套体系** —— 学生端用自建 token（[`ui/client/设计变量.md`](../client/设计变量.md)），运营端用 Element Plus 默认 + **单点暖调覆盖**；**不共用变量、不跨端复用样式**（唯一的跨端复用是**实心 SVG 图标资源**，见 §2.4）。

### 2.2 形态覆盖

| 形态 | 口径 |
|---|---|
| 内容区卡片 | `.page`：`#FFFDF7` 底（`--web-bg-card`）+ 22px 圆角（`--web-radius-card`）+ 双层极弱弥散阴影 + 24px 内距，🔴 **无实线描边** |
| 顶层导航栏 | 固定顶部 `--web-topbar-h`（`56px`，≤`640px` 收 `52px`）：左侧品牌名 `知行食记`（无衬线圆体，`500`）+ 日期；右侧操作员用户名文本（`14px` 弱化正文，非按钮）；底缘用一层极弱投影代替分割线 |
| 应用坞 | 悬浮胶囊（`--el-bg-color-overlay` 底 + 20px 圆角 + `--el-box-shadow-elevated`，无描边）居中于底缘上方：四个功能图标（`AppIcon` 22px）+ 浅色短竖条分组（退出登录在顶栏右上角）；悬停轻微上浮放大（`1.06`）+ 名称气泡、激活主色 + 底部圆点（见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.3） |
| 弹窗 | `.dialog` 白卡片 + **无描边** + `--el-box-shadow-elevated` + 20px 圆角；遮罩 `.mask` 暖色半透明（`rgba(46,42,36,.28)`） |
| 按钮 | **统一胶囊**（`--web-radius-pill`，圆角 = 半高）：主按钮暖橙实底、次按钮暖橙细描边透明底、小按钮灰边；按压仅透明度变化，不缩放 |
| 图片字段 | 编辑弹窗内 **16:9 横向预览**（铺满表单、`object-fit: cover`，`ImageField` 组件），与列表封面统一 |

### 2.3 自建变量

| 变量 | 定稿值 | 用途 |
|---|---|---|
| `--web-font-sans` | `-apple-system, BlinkMacSystemFont, 'PingFang SC', 'HarmonyOS Sans SC', 'Helvetica Neue', 'Microsoft YaHei', sans-serif` | 全站无衬线圆体字体（`h1` / `h2` / `h3` 统一命中） |

| `--web-radius-card` | `22px` | 卡片 / 弹窗大圆角 |
| `--web-radius-pill` | `999px` | 胶囊按钮（圆角 = 半高） |
| `--web-bg-card` | `#FFFDF7` | 卡面奶白（`.page` / `.list-card` / 登录卡） |
| `--web-shadow-card` | `0 2px 8px rgba(68,56,46,.08), 0 8px 20px rgba(68,56,46,.06)` | 卡片极弱弥散阴影（与 `--el-box-shadow-light` 同值） |
| `--web-gap-tight` / `--web-gap` / `--web-gap-loose` | `10px` / `14px` / `22px` | 间距节奏（紧凑 / 常规 / 宽松） |
| `--web-page-pad` | `24px` | 页面内容外边距（≤1024 收 20px、≤640 收 14px）；**顶栏 / 页头 / 内容区三处共用同一值**，保证左右边界同一竖线 |
| `--web-topbar-h` | `56px` | 顶栏高度（≤640 收 52px）；同一值决定滚动区上界（内容区 `margin-top`），滚动边界与顶栏下沿重合 |

### 2.4 图标

- **资源**：`web/src/assets/icons/*.svg` —— **Streamline Plump Solid（实心）子集（13 枚，CC BY 4.0）**：`add` / `chevron` / `check` / `exit` / `flag` / `warning` / `help` / `loading` / `building` / `food` / `store` / `image` / `list`（11 枚取自官方 `-solid` 变体，`add` / `image` 按同一约定手绘）。
- **渲染**：`web/src/components/AppIcon.vue`，**实心填充** `fill="currentColor"` + `fill-rule="evenodd"`（🔴 挖孔靠 evenodd 子路径，不用描边；不写死色值 ⇒ 图标跟随宿主 `color` 上色：默认深棕 `#44382E`、弱化态 `#8C7B6B`、激活 / 主操作态暖橙 `#FF8A4C`），`v-html` 直接注入，`:size` 控制边长。
- 🔴 **零消费即删**：新增前先全仓查引用，无消费的不入库 —— 图标经 `import.meta.glob` 全量打进 `AppIcon` chunk，冗余即包体冗余。
- 🔴 不引入图标字体 / 内联 `<svg>`；新增图标从学生端同源集复制。

## 3 · 红线（改 `web/` 前必查）

| 红线 | 说明 |
|---|---|
| 🔴 主题覆盖**只允许一处** | 页面 / 组件里 **SHALL NOT** 覆盖组件库变量；改值只改 `theme.css` |
| 🔴 **不裸写 hex** | 页面 / 组件样式只用 `var(--el-*)` / `var(--web-font-sans)` |
| 🔴 不引入第二套色板 | 语义色直接用 `--el-color-success / warning / danger / info` |
| 🔴 不跨端抄样式 | 学生端 token（`--bg-page` / `--module-*` / `--radius-*` 等）**不得**出现在 `web/`；仅图标**资源**可复用 |
| 🔴 主色改动**必须双端同改** | 改 `--el-color-primary` 时须同步学生端 `COLOR_MAP.primary` —— 二者是同一个品牌色 |
| 🔴 页面基底必须奶米 | `--el-bg-color-page` 固定为 `#FFF7E8`（与学生端 `--bg-page` 同值），卡片 / 弹层底为 `#FFFDF7` |
| 🔴 EP 内部消费的 token 不得按「零消费即删」删除 | `--el-color-primary-light-3/5/7`、`--el-color-primary-dark-2`、`--el-color-info`、`--el-border-color-light` 由 Element Plus 组件内部消费（按钮 hover / 弹层边框 / MessageBox 图标），静态扫描不可见 —— `check:tokens` 列为「零引用」属预期，🔴 保留（theme.css 有注释） |
