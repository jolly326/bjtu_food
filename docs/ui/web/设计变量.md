# 设计变量（运营端）

> 所属端：**管理端（运营，Web）** ｜ 适用：本目录全部页面稿 + `web/src/**`
> **真源声明**：变量**取值**的唯一真源 = **Element Plus 主题变量（`--el-*`）** + 本项目在 `web/src/styles/` 的**单点覆盖层**（约定 `web/src/styles/theme.css`）。
> 本文档是**对照表 + 约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **优先用 Element Plus 自带变量**（`--el-color-primary` / `--el-border-radius-base` …），🔴 **不新建平行的自建 token 体系**。
2. 自定义样式只允许走本项目覆盖层的 CSS 变量；🔴 **SHALL NOT 裸写 hex**。
3. 🔴 **管理端与学生端是两套体系** —— 学生端用自建 token（[`ui/client/设计变量.md`](../client/设计变量.md)），管理端用组件库默认 + **单点主色覆盖**；**不共用变量、不跨端复用样式**。

## 1 · 主题

| 项 | 口径 |
|---|---|
| **主色** | 🔴 **与学生端逐字同值**（`#B4531A`，见 §2）—— 这是两套体系之间**唯一需要对齐**的一项 |
| 主色的其它档 | 🔴 **不引入**学生端的分档（`-bright` / `-orange` / `-yellow` / `-soft` …）；需要浅色档时用 Element Plus 的 `light-3/5/7/8/9` 自动派生 |
| 圆角 / 阴影 / 字号 | 一律 **Element Plus 默认**，不自定义 |
| 表格 / 表单尺寸 | 组件库默认档 |

## 2 · 本项目覆盖层（🔴 待入代码）

> 覆盖**只允许一处**；本表只登记覆盖项 —— 未列出者**一律用组件库默认**。

| 变量 | 定稿值 | 用途 |
|---|---|---|
| `--el-color-primary` | **`#B4531A`** | 🔴 品牌对齐 —— 与学生端 `--color-primary` **逐字一致**（学生端真源见 `client/src/theme/tokens.ts` 的 `COLOR_MAP.primary`） |

> **为什么只覆盖主色**：管理端是内部工具，密集表格场景下组件库默认的圆角 / 间距 / 灰度更合用；**换主色**是为了让运营端和学生端**看起来是同一个产品**，而不是两套皮肤。

## 3 · 红线（改 `web/` 前必查）

| 红线 | 说明 |
|---|---|
| 🔴 主题覆盖**只允许一处** | 页面 / 组件里 **SHALL NOT** 覆盖组件库变量 |
| 🔴 不写像素级微调 | 尊重组件库尺寸；确有必要才改，并**登记在本表** |
| 🔴 不引入第二套色板 | 语义色直接用 `--el-color-success / warning / danger / info`，**不并列学生端的 `--color-*`** |
| 🔴 不跨端抄样式 | 学生端 token（`--bg-page` / `--module-*` / `--radius-*` 等）**不得**出现在 `web/` |
| 🔴 主色改动**必须双端同改** | 改 `--el-color-primary` 时须同步学生端 `COLOR_MAP.primary` —— 二者是同一个品牌色 |
