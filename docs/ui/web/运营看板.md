# 运营看板

> 所属端：**管理后台（Web）** ｜ 页面 / 单元：**运营看板**（登录后首屏）｜ 目标路由：`/dashboard`
> **覆盖**：D1 运营看板（三区只读聚合 + 待办直达）。
> **不覆盖**：处置动作在各自页面（[评价管理](./评价管理.md) / [反馈与举报](./反馈与举报.md) / [菜品问题反馈](./菜品问题反馈.md)）；计数口径与字段 → [D1 功能文档](../../func/web/D-运营/D1-运营看板.md)；组件规格 → [公共组件与形态基线.md](./公共组件与形态基线.md)。

## 一、页面构成

```
[ h2 运营看板 ]                                  [ 刷新 ]（次级）

① 待办  ┌ 待处理反馈 N ┐┌ 待处理举报 N ┐┌ 待处理菜品问题反馈 N ┐   ← 三张计数卡（可点）
        └ 最近 5 条待办列表（跨三类合并，按提交时间倒序）┘  ← 每行可点直达

② 主数据健康度  ┌ 无图片菜品 ┐┌ 未归档口菜品 ┐┌ 无分类菜品 ┐┌ 空档口 ┐  ← 四张计数卡（不可点）

③ 概况  ┌ 用户总数 ┐┌ 已认证用户 ┐┌ 在售菜品 ┐┌ 评价总数 ┐        ← 四张计数卡（不可点）
```

| # | 区域 | 内容 |
|---|---|---|
| 1 | **页头** | `h2`「运营看板」；右侧**一枚次级按钮**「刷新」（本页**无主按钮** —— 只读页无写操作） |
| 2 | **待办区** | 三张计数卡（反馈 / 举报 / 菜品问题反馈）+ **最近 5 条待办列表**（必须项，否则看板退化为数字墙） |
| 3 | **主数据健康度** | 四项计数：无图片菜品 / 未归档口菜品 / 无分类菜品 / 空档口 —— **只收"当场能修"的项** |
| 4 | **概况** | 四项计数：用户总数（不含已注销）/ 已认证用户 / 在售菜品 / 评价总数（含已隐藏） |
| 5 | **状态承载** | 整页三态用 `StateBox`（加载 / 错误 + 重试）；**待办区为空**时列表位内联文案「暂无待办」（**不整页空态** —— 健康度与概况仍有值） |

## 二、视觉规格（引用 [公共组件与形态基线.md](./公共组件与形态基线.md)）

| 元素 | 规格 |
|---|---|
| 三区容器 | `.card`（[基线 §1.3](./公共组件与形态基线.md)）；区标题 `h3`：`--font-xl` + `semibold`，区间距 `--space-5` |
| 计数卡 | 页面私有：`--bg-soft` 底 + `--radius-card` + 内距 `--space-5`；**数字** `--font-4xl` + `tabular-nums` + `medium`；**标签** `--font-sm` + `--text-muted`（数字在上、标签在下） |
| 计数卡的网格 | `repeat(auto-fit, minmax(180px, 1fr))` + `gap: --space-4`（三卡 / 四卡自适应，窄屏自动换行） |
| 数字着色 | `= 0` → `--text-muted`（不制造焦虑）；`> 0` 且属**待办区** → `--color-primary-text`（可点）；`> 0` 且属健康度 / 概况 → `--text-primary` |
| 待办列表行 | 行高 `--space-10`；`kind` 标签（`.tag`：反馈=灰 / 举报=灰 / 菜品问题反馈=灰）+ 摘要（`.ellipsis`）+ 右侧提交时间（`--font-xs` + `--text-muted`）+ 行尾 `›` |
| 行分隔 | `1px --border-soft`，**首行无上边框、末行无下边框** |
| 可点提示 | 计数卡与待办行 `cursor: pointer` + hover `--bg-hover`；按压 `scale(0.97)`（[基线 §1.13](./公共组件与形态基线.md)） |
| 不可点项 | 健康度 / 概况计数卡**不加 hover 反馈**（不给虚假可点暗示） |

## 三、交互与状态

| 场景 | 口径 |
|---|---|
| 进入页面 | 调 `GET /admin/dashboard`（**一次请求全量**，不拆三次） |
| 失败 | `StateBox status="error"` + 「重试」= 重拉 |
| **点待办计数卡** | 跳对应菜单**列表页**（待处理筛选）：反馈数 → `/feedbacks`（`status=pending`）、举报数 → `/reports`（`status=pending`）、菜品问题反馈数 → `/corrections`（`status=pending`） |
| **点最近待办行** | 跳对应菜单并**带 `id` 定位**该条：`/feedbacks?id=`、`/reports?id=`、`/corrections?id=`；目标页打开**对应处置抽屉**（该页负责消费 `id`） |
| 点健康度项 | **不可点**（纯计数）—— A3 列表无「无图 / 未归档口」筛选项，跳过去也定位不到 → **一期不做深链**（登记为演进预留：届时先给 A3 加筛选，再放开点击） |
| 点概况项 | **不可点**（纯规模数据） |
| 「刷新」 | 重新请求；请求中按钮 `:disabled` |
| 时间 | `submittedAt` 经 `utils/datetime` 的 `formatDateTime` 渲染为 `YYYY-MM-DD HH:mm:ss`（与全站时间口径一致，见 [列表页模板 §1.6](./列表页模板.md)） |
| 空态 | 待办三数均为 0 且 `recent` 为空 → 列表位内联「暂无待办」，**计数卡仍显示 0**（"今天没事"本身是有效信息） |

## 四、组件清单（**本页用法**）

| 组件 | 本页用法 | 规格 |
|---|---|---|
| `StateBox` | 整页加载 / 错误态 | [基线 §2.2](./公共组件与形态基线.md) |
| 计数卡 | 页面私有小组件（`label` + `value` + `tone` + 可选 `to`） | §二（**不**升格为公共组件：仅本页使用） |
| 待办列表 | 页面私有列表（非 `.table`） | §二 |

> 本页**不使用**：`StatusTag`（无状态列）、`BaseModal` / `BaseDrawer`（无写操作）、`ImageUpload`、`useReorder`。

## 五、数据字段

- 三段全部字段（`todo` / `health` / `overview` 与 `recent[]`）：见 [D1 功能文档](../../func/web/D-运营/D1-运营看板.md) 的「字段」节。
- **本页零写操作**、无分页、无筛选（查询参数一个都不传）。
