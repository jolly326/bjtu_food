> **口径分工**：跨页复用的形态口径与公共组件规格以本文件为**唯一真源**；页面级布局见各页设计稿。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 整体布局 | **顶层固定导航栏**（`56px`）+ **底部居中应用坞**（Dock 式全局导航，见 §2.3）+ **内容区**（滚动，底部让位应用坞） |
| 内容区留白 | 外边距 `24px`，**底部 `104px`（让出应用坞）**；内容区为悬浮卡片（`#FAFAFA` 底、内距 `24px`、无描边，圆角 / 阴影见 [设计变量.md](./设计变量.md) §2.2）。≤`1024px`：外边距 `20px`；≤`640px`：外边距 `14px`、底部 `96px`、顶栏 `52px`（收口 `AdminLayout.vue`） |
| 页面标题 | 每页顶部一个 `<h2>` 标题（无衬线圆体） |
| 页面基底 | 🔴 奶米色 `#FFFAF3`（卡面奶白 `#FFFFFF`） |
| 最大宽度 | **不设限** —— 列表卡片需要横向空间 |
| 页面底色 / 主色 | 奶米基底 + 暖橙主色（见 [设计变量.md](./设计变量.md) §2.1） |

## 1.2 间距 / 字号 / 图标

- 间距与字号以 **Element Plus 默认变量**为基准；内容区卡片的内距 / 圆角 / 阴影 / 底色按 [设计变量.md](./设计变量.md) §2 的单点覆盖执行，🔴 页面内不另写像素级微调。
- 列表卡片主行 `15px` 标题、指标行 `12px`、正文 `14px`；卡片盒模型收口在 [theme.css](../../../web/src/styles/theme.css)。
- 图标统一用 `AppIcon` 组件（`web/src/assets/icons` **Plump 黑色轮廓 SVG**，见 [设计变量.md](./设计变量.md) §2.4）；🔴 不使用图标字体 / 内联 `<svg>`。

## 1.3 状态口径

| 状态 | 实现 |
|---|---|
| 加载中 | **不展示遮罩**；`loading` 仅用于避免请求过程中闪出空态 |
| **空** | 卡片列表内一句话 `.list-card__empty`（如「暂无数据」），**不长句、不放引导按钮** |
| 校验不通过 | `ElMessage.warning`（前端只判非空 / 格式），🔴 **弹窗不关闭** |
| 操作成功 | `ElMessage.success`（文案见各页「提交」行） |
| 操作失败 | `ElMessage.error`（**直接展示服务端 `message`**） |
| 未登录 | 路由守卫拦截 ⇒ 跳登录页；请求 `401` ⇒ 清 token 并跳登录页 |

## 1.4 表单与校验

- 前端做**非空 / 格式**基础校验（即时反馈）；
- 🔴 **服务端是最终判据** —— 唯一性、引用约束（有下属 / 被引用）**只能**在服务端判；
- 冲突时**直接展示服务端 `message`**，🔴 **不在前端重算唯一性**。
- 每个表单控件都有 `<label for>` 与控件 `id` 成对；筛选区下拉用 `aria-label` 标注用途。

## 1.5 表格（已收口为历史口径）

> 原生 `<table class="table">` 形态**整体移除**（`theme.css` 只提供现行列表相关类）。
> 现行列表形态见 §1.6。历史口径（服务端分页 20/上限 50、只读统计列弱化、操作列右置（仅纠错页）、
> 列表出图规则、不做客户端排序、无多选无批量）**全部继承**到 §1.6，统一口径单列。

## 1.6 列表与卡片（全站唯一列表形态）

- **结构**：每页一律「顶部摘要（页标题 / 统计卡） → 筛选 → 卡片列表」。
- **布局**：`.list-card-wrap` 为**响应式栅格** —— `repeat(auto-fill, minmax(min(300px, 100%), 1fr))`（≤`1199px` 收窄为 `260px`；窄屏单列不溢出），宽屏一行多卡；卡面内容整体**左对齐**；空态 `.list-card__empty` 横跨整行。
- **卡片两段结构**（全站统一，自上而下）：
  1. **图区**（`.list-card__cover`，仅出图数据渲染）：**满宽贴顶**、`aspect-ratio: 16/9`（🔴 高度恒小于宽度）、`object-fit: cover`，由卡片圆角裁切；无图时渲染同形占位 `.list-card__cover--ph`（占位图标居中）；
  2. **信息区**（`.list-card__main`，内距 `14px 16px 16px`），内部四层信息自上而下：
     - **主行**：名称（`15px`）+ 状态 tag（`.tag--on` / `.tag--off`）；
     - **归属路径**（`.list-card__path`，灰 `12px`）：体现父子层级（食堂·档口 / 食堂）；
     - **指标行**（`.list-card__stats`，`12px`）：本页不同的量化信息 —— 食堂页档口数；档口页楼层·窗口 + 菜品计数；菜品页点赞数；纠错待办段时间戳；纠错选项段被引用数。
- **出图规则**：🔴 **只有菜品有图**（后端仅 `DishVO.imageUrl`）—— 菜品卡渲染图区（无图走占位）；食堂 / 档口 / 纠错待办 / 纠错选项**一律无图，只渲染信息区**。
- **操作入口**：🔴 卡面**无任何操作按钮** —— **点击卡片（或聚焦后 `Enter` / 空格）直接进入编辑界面**，**删除入口在编辑界面内**（见 §2.3「弹窗」）。唯一例外：**纠错待办**的处置动作（去改菜品 / 标记已处理 / 撤销）仍走**卡片操作浮层**（见 §2.3「卡片操作浮层」）。
- **只读统计列弱化** / **不做客户端排序**（无表头可点，顺序一律服务端固定）：继承不变。
- **多选与批量**（仅菜品管理页）：见 §2.3「多选与批量」—— 其余列表页**一律无多选、无批量**。
- **分页状态机**：`web/src/composables/usePagedList.ts` 单点提供 `rows / total / page / loading / hasNext`（页大小 20、末页删空自动回退、筛选 `reload()` 回第 1 页）—— 视图只声明取页 fetcher，规格见 §2.3「分页」。
- **响应式五档**（共享断点收口在 `theme.css`，页面不另写）：≤`1199px` 外边距与栅格收紧；≤`767px`（手机触控档）卡片信息区内距 `12px 14px 14px`、弹窗 `20px` 内距、**按钮高 `40px`（`.btn--sm` `34px`）、筛选下拉 `40px`、弹窗输入 `44px` 且输入字号 `16px`（iOS 聚焦 `<16px` 输入框会强制缩放视口）**；≤`640px`（窄屏纵排档）筛选区与分页栏纵排整宽、**弹窗贴底成底部卡片**；触屏（`hover: none`）还原 hover 粘滞态、卡片不上浮。卡片一律**无实线描边**（轮廓 = `#FAFAFA` 底 + 双层极弱阴影）。

## 2.2 Element Plus（仅两处消费）

| 依赖 | 消费方式 |
|---|---|
| Element Plus 组件样式 | 按组件**按需引入**（`main.ts` 逐个 `import`，非全量 `dist/index.css`，见 [README](INDEX.md)） |
| `ElMessage` | 轻提示（`success` / `warning` / `error`） |

## 2.3 本项目约定

### 应用坞（`.layout__dock` —— Dock 式底部导航）

| 项 | 口径 |
|---|---|
| 形态 | **悬浮胶囊**：`--el-bg-color-overlay` 底 + 圆角 `20px` + **无描边** + `--el-box-shadow-elevated`；水平**居中**、悬浮于底缘上方 `12px + env(safe-area-inset-bottom)` |
| 入口 | **四个**功能图标（`AppIcon` `22px`，图标与名称一一对应：食堂 `building` / 档口 `store` / 菜品 `food` / 纠错处理 `flag`）+ **分组分隔线**（主数据组：食堂 / 档口 / 菜品 ｜ 反馈组：纠错处理）+ 分隔线 + 退出登录（`exit` 图标） |
| 悬停 | 图标格放大上浮（`scale(1.06) translateY(-1px)`）+ **黑底白色名称气泡**（`::after` + `attr(data-label)`，指针不穿透）；退出登录 hover 转错误色。🔴 触屏（`hover: none`）点按后 hover 不粘滞（样式还原），名称气泡在**激活项常显**（弥补无悬停时的图标识别）；各入口带 `aria-label`（图标无文本节点） |
| 激活态 | 图标项**主色**（`--el-color-primary` 图标 + `primary-light-9` 圆角底）+ **底部小横条指示**（`.dock__bar`，`16×3px` 圆角条）；退出登录**无**激活态 |
| 内容让位 | 内容区**底部留白 `104px`** —— 应用坞为 `fixed` 悬浮层，内容不得压于其下 |
| 响应式 | 🔴 **桌面 / 移动同构** —— 无隐藏态、无断点折叠，坞体**常驻水平居中**（容器 `left:0` + `right:0` + `flex` 居中；🔴 不依赖 `translateX(-50%)` ⇒ 视口宽度变化不产生横向位移跳动；容器 `pointer-events: none` 不遮挡内容点击，坞本体 `pointer-events: auto`）；仅 ≤`640px` 时图标格收窄为 **`40×44px` 触控格**（`gap: 0`、分隔线边距 `1px`；8 项 + 2 分隔 ≈ `338px`，`360px` 屏一屏不溢出且点按高 ≥ `44px`），底距改 `8px + env(safe-area-inset-bottom)` |

### 弹窗（`.mask` + `.dialog`）

| 项 | 口径 |
|---|---|
| 宽度 | **520px**（长表单 `max-height: 86vh` 内滚） |
| 遮罩 | `.mask` 暖色半透明 —— 底色在 [设计变量](./设计变量.md) §2.2 单点给出，页面不另写 |
| 标题 | 「新建 X」/「编辑 X」 |
| 字段 | 标签在上（`.dialog__label`，`13px`，上距 `14px` / 下距 `6px`）+ 输入 / 下拉 `34px`（`.dialog__input`；≤`767px` 手机档 `44px` + 字号 `16px` 防 iOS 聚焦缩放）；补充说明 `.dialog__hint` |
| 响应式 | 宽度恒为 `min(520px, 100%)`（`box-sizing: border-box`，外宽即口径、不外溢），外层 `.mask` 提供 `16px` 内距（收口 theme.css，页面不另写）；≤`767px` 内距收至 `20px`；≤`640px` **贴底成底部卡片** —— 整宽、顶圆角 `20px`、内距 `22px 16px calc(22px + env(safe-area-inset-bottom))`、`.dialog__foot` 两钮等分（拇指可达 + 软键盘不遮挡提交行；卡片浮层 `.mask--sheet` 不受影响） |
| 底部 | 编辑态左侧「删除」（`.btn--danger`；危险操作仍由视图侧走 `ElMessageBox` 二次确认，不可删时 `disabled` + `.dialog__hint` 说明原因）｜「取消」（`.btn--outline`）｜「保存」（`.btn--primary`）；新建态无删除 |
| 保存中 | 保存按钮 `disabled` + 文案「保存中…」，🔴 **禁止重复提交** |
| 打开时 | **整体重置表单**（避免残留上次的值） |
| 校验不通过 | `ElMessage.warning` 提示，🔴 **不关弹窗** |

### 卡片操作浮层（`.mask--sheet` + `.sheet` —— 卡片操作入口）

| 项 | 口径 |
|---|---|
| 触发（两通道，同一浮层） | ① **点击卡片**；② **键盘**：卡片 `tabindex="0"` 聚焦后 `Enter` / `空格`。打开后焦点落入首行，`Esc` / 点遮罩 /「取消」关闭 |
| 形态 | 遮罩（`.mask` 底边锚定变体 `.mask--sheet`，`z-index: 300` 盖过顶栏与应用坞，`padding` 使浮层**不贴边**）+ 底部卡片浮层（`.sheet`，与屏幕底缘留 `12px + env(safe-area-inset-bottom)` 间距、左右 `12px` 内缩、四角 `16px` 圆角）：可选标题行（行名，弱化 `12px` 居中）+ 纯文本行「编辑 / 删除 / 取消」（`.sheet__row`，高 `46px`，≥ `44px` 触控）—— **无图标、无红色警示**（对齐学生端底部弹窗（Sheet）口径） |
| 卡面 | 🔴 **卡面不出现编辑 / 删除按钮**；卡片 `user-select: none`（防点按误触发选中）+ `:focus-visible` 主色描边（键盘可达可见） |
| 删除禁用 | 🔴 删除已不在浮层内 —— 纠错选项被引用时，其**编辑界面**的删除按钮 `disabled` + `.dialog__hint` 弱化说明原因 |
| 范围 | 🔴 **仅纠错待办的处置动作**（「去改菜品 / 标记已处理 / 撤销」，`CardActionSheet` 的 `actions` prop）；食堂 / 档口 / 菜品 / 纠错选项**已改为点击卡片直接进编辑界面**（删除在编辑界面内），不再经浮层；各页顶栏「新建」不变 |
| 与图片预览的关系 | 🔴 卡片内图片（`v-zoomimg`）**点击不冒泡**到卡片浮层 —— 点图=放大预览，点卡片=开浮层 |
| 红线 | 浮层点选「删除」后**仍走 `ElMessageBox` 二次确认**（见下节，无例外） |
| ≤640px | 无需单独规则 —— `.sheet` 宽度 `min(420px, 100%)` 自然收窄，间距由 `.mask--sheet` 统一提供（**不贴边**） |

> 实现：`web/src/composables/useCardMenu.ts`（触发 + 状态）+ `web/src/components/CardActionSheet.vue`（浮层 UI）。

### 多选与批量（仅菜品管理页）

| 项 | 口径 |
|---|---|
| 进入 | 顶栏「批量」按钮切换多选模式（`aria-pressed` 标注状态）；再次点击「退出批量」清空选择 |
| 勾选 | 多选模式下**点行 = 勾选 / 取消勾选**（原生 `checkbox` `.list-card__check` 浮于卡片右上角，选中行加主色描边 `.list-card--checked`）；🔴 多选模式下**点卡片不进编辑界面**、**不渲染图区**（点图即勾选） |
| 全选 | 批量条内「全选本页」复选框（仅当前页） |
| 批量动作 | 批量上架 / 批量下架 / 批量改档口（改档口走弹窗选目标档口） |
| 提交方式 | 🔴 **逐条 `PUT`**（只改目标字段，其余字段随行带出），分批并发（每批 6 条）；**非原子** —— 失败项逐条列出，成功项已生效 |
| 结果反馈 | 全部成功 ⇒ `ElMessage.success('已更新 N 项')`；部分失败 ⇒ `ElMessage.warning('已更新 N 项，M 项失败（菜名…）')`；结束后清空选择并刷新列表 |
| 边界 | 🔴 **批量不含删除** —— 删除不可逆且有引用约束，只在单条浮层内操作；🔴 其余列表页无多选无批量 |

### 页内分段切换（`.seg`）

| 项 | 口径 |
|---|---|
| 用途 | 同一页承载并列的两块内容时使用（当前仅纠错处理页：纠错待办 / 纠错选项） |
| 形态 | 胶囊底槽（`.seg`）+ 分段按钮（`.seg__item`，选中 `.seg__item--on` = 白底 + 主色字）；`role="tablist"` / `role="tab"` + `aria-selected` |
| 规则 | 切换**不重置服务端数据**（两段各自持有状态）；顶栏主操作随段变化 |

### 菜品编辑弹窗（`DishEditDialog` —— 菜品管理 / 纠错处理共用）

| 项 | 口径 |
|---|---|
| 复用 | 新建 / 编辑同组件（`dish = null` 即新建）；**菜品管理**与**纠错处理（就地改菜）**两页共用，表单 / 上传 / 校验单点收口 |
| 打开时 | **整体重置表单**（避免残留上次的值） |
| 保存 | 成功 ⇒ 关弹窗 + 回抛 `saved`（父级刷新列表）；🔴 校验不通过 `ElMessage.warning` 且**不关弹窗** |

### 图片上传压缩（`utils/image.ts`）

| 项 | 口径 |
|---|---|
| 时机 | 上传前（`upload()` 之前）统一压缩 |
| 规则 | 最长边压至 `1200px`、重编码 JPEG（质量 `0.85`）；已小于阈值（≤1200px 且 ≤512KB）原样上传 |
| 保底 | 解码失败（GIF / 损坏）或压缩后反而更大 ⇒ **原样上传**，不阻塞运营操作 |

### 删除确认（`ElMessageBox.confirm`）

- 🔴 **所有删除必须二次确认**，无例外。
- 🔴 文案**必须说清后果**，尤其级联：删菜品须写明「**该菜的纠错记录将一并删除**」。
- 有下属引用时**服务端会拒绝** —— 前端**不预判**，直接展示服务端 `message`。
- 确认弹窗（`.el-message-box`）圆角 / 阴影由 `theme.css` 对齐卡片口径；≤`640px` 时按钮**纵排整宽**（高 `44px`，主操作在末位落拇指区）、遮罩内距收至 `12px`。

### 分页（`usePagedList` 状态机）

- 「共 N 条」（`.page__total`）+ 「上一页 / 当前页码 / 下一页」+ **跳页**（`.pager__jump`：数字输入 + 「跳转」按钮，越界自动收敛到 `[1, totalPages]`）；页大小 **20**（`web/src/composables/usePagedList.ts` 的 `PAGE_SIZE` 单点常量，与服务端默认一致）。
- 状态机单点提供 `rows / total / page / loading / hasNext`：第 1 页禁用「上一页」；`!hasNext`（即 `page * 20 >= total`）禁用「下一页」。
- 🔴 **末页删空自动回退**：删除导致本页查空且不在第 1 页 ⇒ 状态机自动回退一页重查 —— 全站统一，视图不另写守卫。
- 翻页 `go(page ± 1)`、筛选变化 `reload()`（回第 1 页）⇒ 服务端重新分页请求；列表加载失败的 `ElMessage.error` 同样收口在状态机。
- ≤`640px`：`.page__foot` 纵排整宽（「共 N 条」居中）、上一页 / 下一页等分拉宽（收口 theme.css，页面不另写）。

### 按钮（`.btn` / `.btn--outline` / `.btn--primary` / `.btn--sm`）

| 类名 | 形态 | 用途 |
|---|---|---|
| `.btn` | 基础形态：高 `32px`、胶囊圆角（`--web-radius-pill`）、细边框 + 白底；按压仅透明度 `0.7` | 通用按钮 |
| `.btn--primary` | 暖橙实底 + 同色描边，胶囊圆角 | 主操作（新建 / 保存） |
| `.btn--outline` | 暖橙细描边 + 透明底；hover 浅橙实底 | 次要操作（弹窗「取消」） |
| `.btn--sm` | 灰边 + 白底，高 `28px`、胶囊圆角 | 小控件（上传 / 移除） |
| 手机触控（≤`767px`） | `.btn` 高 `40px`（字号 `14px`）、`.btn--sm` 高 `34px`（字号 `13px`）；≤`640px` 弹窗脚两钮、翻页钮等分拉宽（收口 theme.css） | 移动端点按可达 |
| 图标位置 | 图标在文案左侧（`AppIcon` + 文字，`gap: 6px`） | 全站按钮统一 |

### 图片

| 位置 | 规格 |
|---|---|
| 卡片图区 | 菜品**满宽** `aspect-ratio: 16/9`（`object-fit: cover`、**无描边**，由卡片圆角裁切；无图同形占位）—— 窄屏随卡片宽度自适应，不再单独收尺寸 |
| 弹窗预览图 | 菜品图 `80×80px`（`.img--round` 圆形裁切） |

> **点击放大预览**：以上每张图片均挂 `v-zoomimg` 指令，**点击 / 回车 / 空格**弹出全屏预览（`ImageZoomOverlay`，Teleport 到 body、`z-index` 高于所有弹层）——滚轮缩放 `1–4x`、点击切换适应 / `2x`、放大后拖拽平移、`Esc` / 点遮罩 / 关闭按钮退出；🔴 事件一律 `stopPropagation`，不与列表卡片的点击浮层冲突（见 §2.3「卡片操作浮层」）。

### 图片上传

- 原生 `<input type="file" hidden>` ⇒ `upload(file)`（`POST /admin/images`）取回**绝对 URL**；表单提交时传该 URL（**入库转相对路径**由服务端负责）。
- 上传中按钮文案「上传中…」；已在库的图片以缩略图呈现，「移除」= 提交 `null`（清除）。
