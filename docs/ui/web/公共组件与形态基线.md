# 公共组件与形态基线 — 跨页唯一真源（运营端）

> 所属端：管理端（运营，Web） ｜ 技术栈：Vue 3 + TypeScript + Vite + **Element Plus**
> **口径分工**：跨页复用的形态口径与公共组件规格以本文件为**唯一真源**；页面级布局见各页设计稿。
> **页面设计稿 SHALL NOT 复述本文件的组件规格** —— 各页只写「本页用法」。

---

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 整体布局 | **左侧固定侧边栏**（导航）+ 右侧内容区（滚动） |
| 内容区留白 | `20px`，底部再留 `20px` |
| 页面标题 | 每页顶部一个标题（如「食堂管理」）+ 右侧主操作按钮「新建」 |
| 最大宽度 | **不设限** —— 表格需要横向空间 |
| 页面底色 / 主色 | 见 [设计变量.md](./设计变量.md) |

## 1.2 间距 / 字号

- 一律使用 **Element Plus 默认**间距与字号（`--el-*`）；🔴 **不自定义间距体系**、不写像素级微调。
- 表格 / 表单控件一律使用组件库默认尺寸。

## 1.3 状态口径

| 状态 | 实现 |
|---|---|
| 加载中 | 表格区 `v-loading`（遮罩） |
| **空** | `el-table` 的 `empty-text` —— **一句话**（如「暂无数据」），**不长句、不放引导按钮** |
| **失败** | 表格区上方 `el-alert`（`type="error"` + 「重试」按钮） |
| 操作成功 | `ElMessage.success`（文案见各页「提交」行） |
| 操作失败 | `ElMessage.error`（**直接展示服务端 `message`**） |
| 未登录 | 路由守卫拦截 ⇒ 跳登录页 |

## 1.4 表单与校验

- 前端做**非空 / 格式**基础校验（即时反馈）；
- 🔴 **服务端是最终判据** —— 唯一性、引用约束（有下属 / 被引用）**只能**在服务端判；
- 冲突时**直接展示服务端 `message`**，🔴 **不在前端重算唯一性**。

## 1.5 表格

| 项 | 口径 |
|---|---|
| 分页 | **服务端分页**，默认 20 条/页 |
| 列 | 只放业务需要的列；**只读统计列**（档口数 / 菜品数 / 评价分）视觉弱化 |
| 行内操作 | 右侧固定列：「编辑」｜「删除」文字按钮 |
| 排序 | 🔴 **不做客户端列排序**（禁点表头）—— 各页顺序一律由**服务端固定**（如 `id` 升序、时间降序），逐页写在页面稿的「顺序」行。二者**不矛盾**：前者禁的是"用户点表头重排"，后者说的是"服务端返什么顺序" |
| 无多选 / 无批量操作 | 一期不做 |

# 二、本设计的组件清单

## 2.1 沿用（Element Plus）

| 组件 | 用途 |
|---|---|
| `el-table` · `el-pagination` | 列表 + 分页 |
| `el-dialog` | **唯一的弹窗载体**（新建 / 编辑） |
| `el-form` · `el-input` · `el-select` · `el-input-number` | 表单 |
| `el-switch` | 菜品状态（在售 / 下架） |
| `el-upload` | 海报 / 菜品图上传 |
| `el-tag` | 状态、错误类型标签 |
| `el-message` · `el-message-box` | 轻提示 / 危险操作确认 |
| `el-alert` | 列表加载失败 |

## 2.2 本项目约定

### 弹窗（`el-dialog`）

| 项 | 口径 |
|---|---|
| 宽度 | **520px** |
| 标题 | 「新建 X」/「编辑 X」 |
| 底部 | 「取消」｜「保存」（主按钮） |
| 保存中 | 保存按钮 `loading` + 🔴 禁止重复提交 |
| 关闭后 | **重置表单**（避免残留上次的值） |
| 校验失败 | 字段下错误提示，**不关弹窗** |

### 删除确认（`el-message-box`）

- 🔴 **所有删除必须二次确认**，无例外。
- 🔴 文案**必须说清后果**，尤其级联：删菜品须写明「**该菜的饮食记录与纠错记录将一并删除**」。
- 有下属引用时**服务端会拒绝** —— 前端**不预判**，直接展示服务端 `message`。

### 分页（`el-pagination`）

- `layout="total, prev, pager, next"`；`total` 取自 `AdminPageResult.total`。
- 翻页 / 筛选变化 ⇒ 重新请求（服务端分页）。

### 图片上传（`el-upload`）

- 上传成功取得**绝对 URL**；表单提交时传该 URL（**入库转相对路径**由服务端负责）。
- 已在库的图片以缩略图 + 「移除」按钮呈现；移除 = 提交 `null`（清除）。

## 2.3 不再需要

| 组件 / 形态 | 原因 |
|---|---|
| **右侧抽屉**（旧体系 `BaseDrawer`） | 改用**居中弹窗** —— 字段少（食堂仅 1 个字段），弹窗足够 |
| 多标签页 / `el-tabs` | 无多视图切换 |
| 富文本编辑器 | 无长文本字段（菜品描述已删） |
| 批量操作 / 行多选 | 一期不做 |

1. **新公共组件**先进本文件登记，再被页面消费。
2. 页面若需偏离本文件口径，**先改本文件**（或登记该页例外）。
3. 页面设计稿**不得复述**本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
