## 1.3 卡片

- **唯一实现 = 公共类 `.card`**：`--bg-card` + `--radius-card` + `--shadow-card` + `1px --border-light` + `overflow: hidden`。
- 用法：表格外壳用 `.table-wrap`（自带同套壳，**不要再套 `.card`**）；面板 / 看板块 / 详情块用 `.card`。
- 内距由**消费方**给（`--space-5` 为常规档；表格类不给内距）。
- **SHALL NOT** 手写「背景 + 圆角 + 阴影 + 边框」四件套另起一套壳。

## 1.4 数据表格（列表页主体）

> 结构与样式**全部由公共类承担**（`.table-wrap` > `.table`），页面**SHALL NOT** 自绘表格样式。

| 部位 | 规格 |
|---|---|
| 外壳 `.table-wrap` | `--bg-card` + `--radius-card` + `--shadow-card` + `1px --border-light`；`overflow-x: auto`（窄屏横向滚动，**不塌列**） |
| 表头 `th` | 内距 `--space-3 --space-4`；底 `--bg-soft`；文字 `--text-secondary` + `medium`；下边框 `1px --border-light`；**`white-space: nowrap`** |
| 单元格 `td` | 内距 `--space-3 --space-4`；下边框 `1px --border-soft`（**最轻一档**）；文字 `--text-primary`；**`font-variant-numeric: tabular-nums`**（金额 / 计数对齐） |
| **紧凑档** `.table--compact` | 抽屉内小表复用同一结构，仅两处收窄：行高 `--space-10`、`td` 内距 `--space-2 --space-3`（消费方：A4 取值抽屉内列表）—— **SHALL NOT** 另立第三套表格样式 |
| 行 hover | `--bg-hover`，过渡 `0.15s ease`（降级下去过渡） |
| 长文本（**内容 / 回复列**） | **`ClampText` 组件**（§2.7）：折叠 2 行 + 溢出才给「展开 / 收起」，展开即全文（`pre-wrap` + `overflow-wrap: anywhere`）。🔴 **内容列 SHALL NOT 只用 `.ellipsis`** —— 单行截断会让「隐藏 / 删除 / 采纳」等处置动作无从判断（详情抽屉里才有全文，列表里必须够读到能判断「要不要进详情」） |
| 短标识列（名称 / 编号 / 时间）与**纯入口型摘要**（如看板待办行摘要） | `.ellipsis`：`max-width: 200px` + 单行省略（**全列宽不随内容抖动**；此类文本可跳转至对应处置页读全文） |
| 操作列 `.actions` | `white-space: nowrap` + `display: flex; gap: --space-2`，**恒为最后一列**、右对齐或紧跟内容列 |
| 操作列按钮 | 行内动作用 **`.link`**（文字档，`--font-sm`）+ 图标 `.act-ico`（`13×13`、`vertical-align: -2px`、`margin-right: --space-1`）；**SHALL NOT** 在行内放实底主按钮 |
| 配图角标 `.img-flag` | 胶囊（`--bg-soft` 底 + `--text-muted` + `--font-xs`）+ 12px 图标 + 张数；用于「该行有配图」提示 |

- **列顺序约定**：`主标识列（名称）` → 归属 / 分类列 → 数值列 → 状态列 → 时间列 → `操作列`。
- **列内容约定 = 「基础检索列」**：表格的职责是「快速查阅 + 定位到详情」，**只放**主标识 / 归属分类 / 计数 / 状态 / 时间 / 操作入口；长文本、配图、排序位、原文快照与**全部编辑 / 删除类操作**归**详情抽屉**（§1.15）——逐页列序见 [列表页模板.md](./列表页模板.md) §二。
- **状态列**恒用 `StatusTag`（§2.3）；**数值列**右对齐由 `tabular-nums` 保证视觉对齐（不额外加 `text-align`）。
- **时间列**恒经 `utils/datetime` 的 `formatDateTime` 渲染为 `YYYY-MM-DD HH:mm:ss`（`SHALL NOT` 直出后端字符串）。
- **无表格「选择列 / 批量操作」**：本期列表**不引入多选与批量动作**（需要时另立设计变更）。

## 1.5 列表页六态（**必查清单**）

> 任何列表页都要能回答这六态；**规格唯一**，页面稿只写「本页各态文案」。

| 态 | 呈现 | 判据 |
|---|---|---|
| ① **加载**（首屏） | `<StateBox status="loading" />` → `.state-box` + `.spin` + 「加载中…」 | 请求未返回且**尚无数据** |
| ② **错误** | `<StateBox status="error" :message="err" @retry="reload()" />` → `.state-box.state-err`（红字）+ 「重试」`.link` | 请求失败 |
| ③ **空态** | `<StateBox status="empty" message="暂无数据" />` | 成功但 `items.length === 0` |
| ④ **有数据** | `.table-wrap` > `.table` + 底部 `.pager` | `items.length > 0` |
| ⑤ **分页** | `.pager`：左「共 N 条」+ 右页码按钮组（`total = 0` 不渲染） | 见 §1.6 |
| ⑥ **会话失效** | **不渲染列表态** —— `401`（未带 / token 失效 / 账号停用）由请求层统一处理：**清 token → 跳登录页**（见 [C1](../../func/web/C-账号与访问/C1-管理员登录与访问控制.md)）| 任一读/写操作返回 `401` |

- **高优先级：错误态 > 空态 > 列表**（有错不显示空）。
- **筛选条件变化 ⇒ 必须重置到第 1 页并回到①**（`reloadFirstPage()`），**SHALL NOT** 在旧结果上追加。
- **SHALL NOT** 引入骨架屏 / 全屏 loading 遮罩 —— 三态盒 + `.spin` 已覆盖。

## 1.6 分页（**页码 + 总数**）

| 项 | 口径 |
|---|---|
| 机制 | 组合式 `usePagedList`（`web/src/composables/usePagedList.ts`）；管理端分页壳 **`AdminPageResult<T>` = `{ records, total }`**（见 [api/README §管理端分页结构](../../api/README.md)） |
| 页大小 | 固定 **20** |
| 结束判据 | **`total`**（**SHALL NOT** 用「本页条数 < `pageSize`」推断） |
| 容器 `.pager` | 表格下方**一行**：左「**共 N 条**」（`--font-sm` + `--text-muted` + `tabular-nums`）；右按钮组 `‹ 上一页` ／ `第 x / y 页` ／ `下一页 ›` |
| 页数 | `y = ceil(total / 20)`；首页 / 末页对应按钮 `disabled`；**`total = 0` 时不渲染** `.pager`（空态由 §1.5 ③ 承担） |
| 翻页 | 请求对应 `page`；翻页后**滚动回到表格顶部** |
| 按钮类 | 页码按钮用 **`.btn-secondary`**；**不引入** `.btn-ghost` 一类别名 |

## 1.7 表单

| 项 | 规格 |
|---|---|
| 字段容器 `.field` | 纵向；标签在上 |
| 标签 `.field label` | `--font-sm` + `--text-secondary` + `medium`，下留白 `--space-1` |
| 必填标记 `.required` | `*` 前缀/后缀，色 `--color-error` |
| 标签关联 | `<label for>` 与控件 `id` **成对**（屏幕阅读器可识别字段名）；组件内输入（`ImageUpload` / 动态属性行）由组件自身保证 `aria-label` 或 `for` |
| 输入控件 | `.form-input`（`max-width: 320px`）/ `.form-textarea`（`min-height: 50px`，可纵向 resize）；内距 `--space-2 --space-3`；边框 `1px --border-strong`；`--radius`；底 `--bg-card` |
| 聚焦 | 边框转 `--color-primary` + `box-shadow: var(--focus-ring)`（与按钮焦点环**同档**，键盘可达性一致） |
| 下拉 `select` | 同输入控件；`cursor: pointer` |
| 错误文案 `.field-error` | `--font-sm` + `--color-error`，紧贴控件下方（`--space-1`） |
| 字段间距 | 纵向 `--space-4`（**不写进公共类**，由表单页容器 `gap` 承担） |

- **标签在左还是在上**：**一律在上**（后台表单为纵向流，抽屉宽度有限）；`SHALL NOT` 按页混用两种排布。
- **校验时机**：**提交时校验 + 字段级即时清除** —— 提交后按字段渲染 `.field-error`；用户修改该字段即清除该字段错误（`SHALL NOT` 边输边报错）。
- **提交中去重**：提交按钮 `:disabled` + `opacity: .5`（禁用档），**SHALL NOT** 只靠 toast 防重复提交。

## 1.8 按钮族（**语义梯度是硬口径**）

| 类 | 语义 | 视觉 |
|---|---|---|
| `.btn-primary` | **唯一主操作**（新建 / 保存 / 提交） | 主色实底 + `--color-on-primary` 文字；hover `--color-primary-light` |
| **`.tag-option`** | **可选标签**（单选/多选的「选项按钮」，用于处置抽屉选结论、筛选区选值） | `.btn-secondary` 的**低强调变体**：胶囊底 `--bg-soft` + `1px --border-light` + `--font-sm`；**选中态** = 主色描边 + `--color-primary-text` 文字（**不用实底**）；高 ≥ 88rpx；可访问性 `role="radio"` + `aria-checked` |
| `.btn-secondary` / `.btn-cancel` | 次级（取消 / 刷新 / 翻页 / 行内批量） | `--btn-secondary-*` 描边；hover 描边 + 文字转 `--btn-secondary-hover-*` |
| `.btn-success` | **放行**（采纳 / 通过 / 恢复） | 描边成功色 → hover 实底 + `--text-white` |
| `.btn-warn` | **驳回**（拒绝 / 不采纳） | 描边警示色 → hover 实底 |
| `.btn-danger` | **删除 / 隐藏**（不可逆或强负向） | 描边错误色 → hover 实底 |
| `.btn-sm` | 尺寸修饰（行内 / 密集区） | `padding: --space-1 --space-4` + `--font-sm` |
| `.link` | 行内文字动作（改名 / 重试 / 详情） | **无底无边**，`--color-primary-text` + `--font-sm`；修饰：`.danger` / `.warn` / `.primary-text` |

## 1.10 弹窗与抽屉

| 形态 | 用途（**选择口径**） | 规格 |
|---|---|---|
| **`BaseModal`**（现有） | **确认 / 短表单**（≤ 4 个简单控件）、危险操作二次确认 | `max-width: 520px`；`max-height: 88vh`；遮罩 `rgba(0,0,0,.45)` + `z-index: 1000`；头部 `--space-4 --space-5` + 下描边；`×` 关闭（`22px`/`--text-muted`）；体 `--space-5` |
| **`BaseDrawer`**（§2.5） | **详情 / 表单编辑**（≥ 5 个字段，或含图片 / 动态子表单 / 只读内容区块）—— 列表页的「详情 + 编辑」**同一抽屉两态** | 右侧滑入；宽 **640px**；`--radius-card` 圆角在**左**侧；`--blur-material`；过渡 `--duration-drawer` + `--ease-drawer`；内容件见 §1.15 |

**选择规则（防冲突）**：

1. **≤ 4 个简单控件且无只读内容区块**（无图片 / 无动态子表单 / 无需横向滚动）→ **弹窗**（如 A7 新建 / 改名、A3 复制菜名、B1 隐藏附注）；
2. **≥ 5 个字段**，或含 **图片 / 动态子表单 / 条件行 / 只读内容区块** → **抽屉**；
3. **危险确认**恒用弹窗（`ElMessageBox` 或 `BaseModal`），**SHALL NOT** 在抽屉内做删除确认。

**共用口径**：

- 遮罩点击：**弹窗** `@click.self` 关闭；**抽屉**同样允许点遮罩关闭，但**表单已修改时须二次确认**（提示「放弃未保存的修改？」）。
- `ESC` 关闭（表单已修改时同上）。
- 打开期间**锁背景滚动**：由公共 `composables/useOverlayLayer.ts` 统一承担（**引用计数 + 原样还原**，非各自写 `hidden`/`'`）。浮层**可叠加**（抽屉上再开弹窗、抽屉里再开大图预览），故：`ESC` **只由栈顶（最上层）浮层响应**（一次 `ESC` 只关一层），内层关闭不破坏外层的滚动锁，退出最外层时页面原始 `overflow` 被正确还原。`BaseDrawer` / `BaseModal` / `ImagePreview` 三者**同实现**，页面不另写锁。
- 头部标题 `--font-lg`；**底部动作区**用 `.modal-actions`（右对齐 + `gap: --space-3` + 上描边 `--border-light` + `margin-top: --space-6`）—— 抽屉内放宽到 `--space-5` 内距并**吸底**。
- 提交中：主按钮禁用（§1.7），**SHALL NOT** 关窗后静默提交。

## 1.14 图标

- **唯一实现 = 公共 `AppIcon`**（`web/src/components/AppIcon.vue`）；**与学生端 `AppIcon` 同源同款**：**IconPark 官方线性主题（outline）**，**48 网格、`stroke-width 2`、圆角端点**；几何以路径数据内联（无外部 `.svg` 文件、无字体文件、无运行时网络依赖）。
- **图标来源与许可证（登记项）**：**IconPark**（https://iconpark.oceanengine.com ，字节跳动开源图标库），**Apache License 2.0**（可商用）。
- **SHALL NOT** 用 Element Plus 图标组件 / 内联手写 `<svg>` / 图标字体 / emoji 字符当图标。
- `size`：数字 = **px**，且只允许取下表档位。
- `color`：**必须传实色**（语义色变量值或 `#RRGGBB`）。本端是内联 `<svg>`（同一文档），`var(...)` 可正常解析 —— 这点与学生端不同（学生端走 data-uri 独立文档，解析不了 `var()`）。
- **尺寸档位表（唯一档位集合）**：图标边长只允许取下表档位；同一语义在不同页面**必须同档**。

  | 档位 | 语义 | 消费点 |
  |---|---|---|
  | `12px` | **胶囊角标内图标** | `.img-flag` 配图张数角标 |
  | `13px` | **行内操作按钮图标** | `.act-ico`（配 `--space-1` 间距 + `vertical-align: -2px`） |
  | `14px` | **伴随正文的辅助图标**（默认档） | 筛选区 / 表单提示行 |
  | `16px` | **标题级图标** | 卡片标题 / 抽屉头 |
  | `20px` | **空态 / 失败态大图标** | 空数据插图 |

- **两端图标体系的关系**：两端**同一套图形**（IconPark outline），各持一份同源几何 —— 两端运行环境不同（小程序 vs 浏览器），无法共享构建产物：学生端无原生 `<svg>`，走 `<image>` + data-uri；本端有原生 `<svg>`，直接渲染。**两端统一的是「图形风格 / 网格 / 档位语义」**：同一档位在两端表示同一量级，同一语义在两端取同一档。
- **零消费的图标键不登记**：新增图标须连同消费点一起登记（当前登记键：`image`）。

### 2.x `ActiveFilters` —— 已生效筛选条件回显（列表页公共件）

- **问题**：筛选区只提供「输入框 + 查询 + 重置」时，管理员无法一眼看出**当前结果被什么条件筛出来的**（翻页 / 改排序后尤其）。
- **用法**：放在 `.filters` 容器**内部**作为最后一个子元素；消费方传入**已过滤掉空值**的条件数组，并自行决定「清空单个」如何重查。
- **显示值必须是人类可读文案**，不是原始枚举 / id：状态回显「待处理」而非 `pending`，食堂回显名称而非 `3`（映射不到时回落 `#id`）。
- **文案单一真源**：状态 / 类型文案复用该页 `<option>` / `StatusTag` / `typeLabel` 的既有映射，SHALL NOT 另造一套。
- **样式**：`.filters-active`（虚线上边框与筛选控件区分成两层）+ `.filters-chip`（浅底胶囊 + 可点删除叉，命中区扩到可点下限）。

### 2.x 筛选区容器（`.filters`，**全局唯一实现**）

- 筛选区容器的样式是**全局唯一实现**（位于 `shared.css` —— scoped 样式无法跨页复用，故样式不由各页面各自声明）；页面**SHALL NOT** 再声明 `.filters { }`；控件定宽（`.filters .form-input { width: … }`）是各页差异，留在页面 scoped 内。

## 1.15 详情抽屉内容块（**公共类，唯一实现**）

> **分组 + 两栏（抽屉信息架构）**：抽屉宽 640px，单列竖排会让右侧约 500px 闲置、字段数多时失去结构感。故抽屉正文一律按**语义分组 + 组内两栏**排布：

| 值内容为**纯文本 / 插值** | 用**公共组件 `DetailMetaRow`**（`<DetailMetaRow k="标签" [num]>值</DetailMetaRow>`）—— `.meta-key` / `.meta-val` 的**唯一产出点**，标签列轴与断行规则只在此一处 |
| 值内容为**复合内容**（副说明 `<span class="muted">` / `StatusTag` / 属性行列表 / 头像格等） | 保留手写 `.meta-row` 结构 —— 这类值本就不可数据驱动 |

**SHALL NOT** 为省两行模板把复合值塞进组件再靠 `v-if` 分支 —— 那会把「标签列宽 / 对齐 / 断行」的口径重新分散回页面。
**大图预览**：凡配图（表格缩略图 / 抽屉大图）**点击即开 `ImagePreview`**（挂载即打开、`ESC` / 遮罩 / `×` 关闭、锁背景滚动）。审核判断需要看清原图，缩略图只承担「有没有图」。

# 二、公共组件视觉规格

> 公共组件：`BaseModal` / `BaseDrawer` / `StateBox` / `StatusTag` / `ImageUpload` / `ImagePreview` / `ClampText` / `DragHandle` / `Pager` / `ListState`，加公共拖拽排序机制 **`useReorder`**（组合式）与**详情抽屉内容块**（§1.15，`shared.css`）。各页设计稿只写「本页用法」。

## 2.1 `BaseModal` —— 弹窗骨架（现有）

- **规格**：见 §1.10。`overlay` 固定全屏居中，`padding: --space-4`（窄屏不贴边）。
- **props**：`title`（必填）/ `open`；**事件**：`close`；**具名槽**：`actions`（底部动作区，传了才渲染）。
- **行为**：点遮罩关闭；`×` 关闭；**`ESC` 关闭**；打开期间**锁背景滚动**（焦点陷阱可后置）。
- **消费方**：各视图的确认 / 短表单弹窗。

## 2.2 `StateBox` —— 三态盒（现有）

- **props**：`status: 'loading' | 'error' | 'empty'`、`message?`；**事件**：`retry`。
- **规格**：见 §1.14。**唯一实现**，页面**SHALL NOT** 自绘 loading / 空态。
- **消费方**：全部列表页与详情块。

## 2.3 `StatusTag` —— 状态标签（现有）

- **props**：`status: string`、`kind?: 'onoff' | 'dish' | 'user' | 'feedback' | 'correction' | 'correctionType' | 'review'`。
- **映射**：`onoff`（默认 启用 / 停用 —— Banner / 食堂 / 档口 / 视图 / 举报原因）、**`dish`（在售 / 已下架 —— 菜品）**、`user`（正常 / 已禁用 / 已注销）、`feedback` / `correction`（待处理 / 已处理 / 已采纳 / 已拒绝）、**`correctionType`（信息有误 / 已经下架 —— 菜品问题反馈的**类型列**）**、`review`（显示中 / 已隐藏 —— 评价）。
- **文案单一真源**：[设计变量.md 的「状态文案总表」](./设计变量.md) —— 页面稿**只传 `status` + `kind`**，不自定义文案。
- **规格**：见 §1.9。**文案与配色只在组件内**，页面只传 `status` + `kind`。

## 2.4 `ImageUpload` —— 图片上传（现有）

- **props**：`modelValue: ImageItem[]`（`{ url }` 对象数组，见 §2.5 #2）、`max?`（默认 5）、`ratioHint?`、`ariaLabel?`（无障碍：根 `role="group"` + 添加/删除钮 `aria-label` 取自该值，如 `'配图'` / `'Banner 图'`）、**`cover?`（默认 `true`）**；**事件**：`update:modelValue`。
- **`cover = false`**：关闭「封面」角标与「设为封面」动作 —— 用于**单图运营位**（A5 Banner），该处「封面」会与「新建时上传的就是这张图」的入口语义冲突（见 [列表页模板 §A5](./列表页模板.md)）。
- **规格**：见 §1.11。**消费方**：A1 食堂 / A2 档口 / A3 菜品 / A5 Banner。

> **落地时**：先在 `variables.css` 声明 component token，再让组件消费，最后回填本文与设计变量表。

## 2.7 `ClampText` —— 长文本展示件（长文本列唯一实现）

- **props**：`text?: string | null`、`lines?: number`（默认 `2`）、`placeholder?: string`（默认 `—`）。
- **规格**：折叠态 `-webkit-line-clamp: lines` + `overflow: hidden`；**仅当内容溢出时**才渲染「展开 / 收起」`.link`（带 `aria-expanded`；溢出由 `ResizeObserver` 判定，列宽 / 窗口变化后重判）；展开态完整呈现，且恒 `white-space: pre-wrap` + `overflow-wrap: anywhere`（保留原换行、超长无空格串可断行，不撑破列宽）。
- **消费方**：评价管理（内容）/ 反馈与举报（内容 · 回复）/ 菜品问题反馈（回复）等**长文本列**。
- **SHALL NOT**：长文本列退回 `.ellipsis`（单行截断）或私写 `line-clamp`。
