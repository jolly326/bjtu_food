# 公共组件与形态基线 — 跨页唯一真源（运营端）

> 所属端：**运营端**（`web/`） ｜ 技术栈：Vue 3 + TypeScript + Vite + **Element Plus（仅主题变量与程序式提示）**
> **口径分工**：跨页复用的形态口径与公共组件规格以本文件为**唯一真源**；页面级布局见各页设计稿。
> **页面设计稿 SHALL NOT 复述本文件的组件规格** —— 各页只写「本页用法」。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 整体布局 | **顶层固定导航栏**（`56px`）+ **底部居中应用坞**（Dock 式全局导航，见 §2.3）+ **内容区**（滚动，底部让位应用坞） |
| 内容区留白 | 外边距 `24px`，**底部 `104px`（让出应用坞）**；内容区为悬浮纸片（`#FAFAFA` 底、内距 `24px`、无描边，圆角 / 阴影见 [设计变量.md](./设计变量.md) §2.2）。≤`1024px`：外边距 `20px`；≤`640px`：外边距 `14px`、底部 `96px`、顶栏 `52px`（收口 `AdminLayout.vue`） |
| 页面标题 | 每页顶部一个 `<h2>` 标题（衬线） |
| 页面基底 | 🔴 纯白色 `#FFFFFF` |
| 最大宽度 | **不设限** —— 列表卡片需要横向空间 |
| 页面底色 / 主色 | 纯白基底 + 暖橙主色（见 [设计变量.md](./设计变量.md) §2.1） |

## 1.2 间距 / 字号 / 图标

- 间距与字号以 **Element Plus 默认变量**为基准；内容区卡片的内距 / 圆角 / 阴影 / 底色按 [设计变量.md](./设计变量.md) §2 的单点覆盖执行，🔴 页面内不另写像素级微调。
- 列表卡片主行 `15px` 标题、指标行 `12px`、正文 `14px`；卡片盒模型收口在 [theme.css](../../../web/src/styles/theme.css)。
- 图标统一用 `AppIcon` 组件（`web/src/assets/icons` 线性 SVG，见 [设计变量.md](./设计变量.md) §2.4）；🔴 不使用图标字体 / 内联 `<svg>`。

## 1.3 状态口径

| 状态 | 实现 |
|---|---|
| 加载中 | **不展示遮罩**；`loading` 仅用于避免请求过程中闪出空态 |
| **空** | 卡片列表内一句话 `.list-card__empty`（如「暂无数据」），**不长句、不放引导按钮** |
| 校验不通过 | `ElMessage.warning`（前端只判非空 / 格式），🔴 **弹窗不关闭** |
| 操作成功 | `ElMessage.success`（文案见各页「提交」行） |
| 操作失败 | `ElMessage.error`（**直接展示服务端 `message`**） |
| 未登录 | 路由守卫拦截 ⇒ 跳登录页；请求 `401` ⇒ 清 token 并跳登录页 |

## 1.4 表单与校验

- 前端做**非空 / 格式**基础校验（即时反馈）；
- 🔴 **服务端是最终判据** —— 唯一性、引用约束（有下属 / 被引用）**只能**在服务端判；
- 冲突时**直接展示服务端 `message`**，🔴 **不在前端重算唯一性**。
- 每个表单控件都有 `<label for>` 与控件 `id` 成对；筛选区下拉用 `aria-label` 标注用途。

## 1.5 表格（已收口为历史口径）

> 原生 `<table class="table">` 形态已于「去表格化」改造中**整体移除**（`theme.css` 不再提供 `.table*` 类）。
> 现行列表形态见 §1.6。历史口径（服务端分页 20/上限 50、只读统计列弱化、操作列右置（仅纠错页）、
> 列表出图规则、不做客户端排序、无多选无批量）**全部继承**到 §1.6，不再单列。

## 1.6 列表与卡片（全站唯一列表形态）

- **结构**：每页一律「顶部摘要（页标题 / 统计卡） → 筛选 → 卡片列表」。
- **布局**：`.list-card-wrap` 为**响应式栅格** —— `repeat(auto-fill, minmax(min(300px, 100%), 1fr))`（≤`1199px` 收窄为 `260px`；窄屏单列不溢出），宽屏一行多卡；卡面内容整体**左对齐**（含价格）；空态 `.list-card__empty` 横跨整行。
- **卡片四层信息结构**（全站统一，自上而下）：
  1. **主行**：名称（`15px`）+ 状态 tag（`.tag--on` / `.tag--off` / 反应 tag）；
  2. **归属路径**（`.list-card__path`，灰 `12px`）：体现父子层级（食堂·档口 / 食堂）；
  3. **指标行**（`.list-card__stats`，`12px`）：本页不同的量化信息 —— 食堂页档口数；档口页楼层·窗口 + 菜品/海报计数；菜品页评分 + 价格（`.list-card__price` 随行左贴强调）；海报页排序值；评分/纠错页时间戳；选项页被引用数；
  4. **操作入口**：🔴 卡面**无编辑 / 删除按钮** —— 编辑 / 删除经**长按浮层**唤起（三通道触发与浮层规格见 §2.3「长按操作浮层」）；`.list-card__actions` 操作列**仅纠错处理页保留**（处置动线：去改菜品 / 标记已处理 / 撤销）；评分数据页只读无操作。
- **出图规则**（继承原 §1.5「能区分行的图片」口径）：菜品卡带 `64×64px` 缩略图（`.list-card__figure`，无图占位 `.list-card__figure--ph` 同尺寸不塌陷）；海报卡带 `48×64px`（3:4 竖版 `.list-card__figure--poster`）；其余页一律不出图。
- **只读统计列弱化** / **不做客户端排序**（无表头可点，顺序一律服务端固定）/ **无多选无批量**：继承不变。
- **分页状态机**：`web/src/composables/usePagedList.ts` 单点提供 `rows / total / page / loading / hasNext`（页大小 20、末页删空自动回退、筛选 `reload()` 回第 1 页）—— 视图只声明取页 fetcher，规格见 §2.3「分页」。
- **响应式三档**（共享断点收口在 `theme.css`，页面不另写）：≤`1199px` 外边距与栅格收紧；≤`900px` 评分概览折成 2×2；≤`767px` 卡片内距 `14px`、弹窗 `20px` 内距、按钮高 `34px`；≤`640px` 缩略图缩至 `48px`、操作列换行到底部右对齐。卡片一律**无实线描边**（轮廓 = `#FAFAFA` 底 + 双层极弱阴影）。
- **评分数据页**：列表上方固定一张评分分布概览卡（`.overview*`，见 §2.1），跟随**菜品筛选**联动（不随反应筛选）；实现为 4 路并发 `pageSize=1` 只取 `total`，零后端改动。

## 2.2 Element Plus（仅两处消费）

| 依赖 | 消费方式 |
|---|---|
| `element-plus/dist/index.css` | 主题变量 `--el-*` 与基础样式（`main.ts` 引入） |
| `ElMessage` | 轻提示（`success` / `warning` / `error`） |
| `ElMessageBox.confirm` | 危险操作二次确认 |

> 🔴 不消费 Element Plus 的**数据 / 表单组件**（`el-table` / `el-form` / `el-dialog` / `el-select` / `el-tag` …）—— 表格、表单、弹窗、标签一律走 §2.1 的项目内 CSS 类。

## 2.3 本项目约定

### 应用坞（`.layout__dock` —— Dock 式底部导航）

| 项 | 口径 |
|---|---|
| 形态 | **悬浮胶囊**：`--el-bg-color-overlay` 底 + 圆角 `20px` + **无描边** + `--el-box-shadow-elevated`；水平**居中**、悬浮于底缘上方 `12px + env(safe-area-inset-bottom)` |
| 入口 | **七个**功能图标（`AppIcon` `22px`，图标与名称一一对应：食堂 `building-2` / 档口 `store` / 菜品 `dish` / 海报 `image` / 评分数据 `star` / 纠错处理 `report` / 纠错选项 `list-checks`）+ **分组分隔线**（主数据组：食堂 / 档口 / 菜品 / 海报 ｜ 反馈组：评分数据 / 纠错处理 / 纠错选项）+ 分隔线 + 退出登录（`log-out` 图标） |
| 悬停 | 图标格放大上浮（`scale(1.12) translateY(-2px)`）+ **黑底白色名称气泡**（`::after` + `attr(data-label)`，指针不穿透）；退出登录 hover 转错误色 |
| 激活态 | 图标项**主色**（`--el-color-primary` 图标 + `primary-light-9` 圆角底）+ **底部圆点指示**（macOS「运行中」语义）；退出登录**无**激活态 |
| 内容让位 | 内容区**底部留白 `104px`** —— 应用坞为 `fixed` 悬浮层，内容不得压于其下 |
| 响应式 | 🔴 **桌面 / 移动同构** —— 无隐藏态、无断点折叠，坞体**水平始终居中**（桌面 `left:50%` + `translateX(-50%)`；窄屏坞内 `justify-content: safe center`，极窄屏退化起点对齐可横滚）；仅 ≤`640px` 时图标格收窄至 `38px`（保证整坞一屏不溢出） |

### 弹窗（`.mask` + `.dialog`）

| 项 | 口径 |
|---|---|
| 宽度 | **520px**（长表单 `max-height: 86vh` 内滚） |
| 遮罩 | `.mask` 暖色半透明 —— 底色在 [设计变量](./设计变量.md) §2.2 单点给出，页面不另写 |
| 标题 | 「新建 X」/「编辑 X」 |
| 字段 | 标签在上（`.dialog__label`，`13px`，上距 `14px` / 下距 `6px`）+ 输入 / 下拉 `34px`（`.dialog__input`）；补充说明 `.dialog__hint` |
| 响应式 | 宽度恒为 `min(520px, 100%)`，外层 `.mask` 提供 `16px` 内距（收口 theme.css，页面不另写）；≤767px 内距收至 `20px` |
| 底部 | 「取消」（`.btn--outline`）｜「保存」（`.btn--primary`） |
| 保存中 | 保存按钮 `disabled` + 文案「保存中…」，🔴 **禁止重复提交** |
| 打开时 | **整体重置表单**（避免残留上次的值） |
| 校验不通过 | `ElMessage.warning` 提示，🔴 **不关弹窗** |

### 长按操作浮层（`.mask--sheet` + `.sheet` —— 卡片操作入口）

| 项 | 口径 |
|---|---|
| 触发（三通道，同一浮层） | ① **按住卡片 500ms**（触屏 / 鼠标；期间移动 > `10px` 或抬起即取消）；② 桌面**右键**（`contextmenu` 已 `preventDefault`，不弹浏览器菜单）；③ **键盘**：卡片 `tabindex="0"` 聚焦后 `Enter` / `空格` / `菜单键`。打开后焦点落入首行，`Esc` / 点遮罩 /「取消」关闭 |
| 形态 | 遮罩（`.mask` 底边锚定变体 `.mask--sheet`，`z-index: 300` 盖过顶栏与应用坞，`padding` 使浮层**不贴边**）+ 底部纸片浮层（`.sheet`，与屏幕底缘留 `12px + env(safe-area-inset-bottom)` 间距、左右 `12px` 内缩、四角 `16px` 圆角）：可选标题行（行名，弱化 `12px` 居中）+ 纯文本行「编辑 / 删除 / 取消」（`.sheet__row`，高 `44px`）—— **无图标、无红色警示**（对齐学生端记忆页长按浮层口径） |
| 卡面 | 🔴 **卡面不出现编辑 / 删除按钮**；卡片 `user-select: none`（防长按误触发选中）+ `:focus-visible` 主色描边（键盘可达可见） |
| 删除禁用 | 如纠错选项被引用：删除行 `disabled` 置灰 + `.sheet__hint` 弱化说明原因 |
| 范围 | 🔴 **仅**食堂 / 档口 / 菜品 / 海报 / 纠错选项五页；纠错处理页「去改菜品 / 标记已处理 / 撤销」为处置动线，保留卡面操作列（`.list-card__actions`）；评分数据页只读无操作；各页顶栏「新建」不变 |
| 红线 | 浮层点选「删除」后**仍走 `ElMessageBox` 二次确认**（见下节，无例外） |
| ≤640px | 无需单独规则 —— `.sheet` 宽度 `min(420px, 100%)` 自然收窄，间距由 `.mask--sheet` 统一提供（**不贴边**） |

> 实现：`web/src/composables/useCardMenu.ts`（手势 + 状态）+ `web/src/components/CardActionSheet.vue`（浮层 UI）。

### 删除确认（`ElMessageBox.confirm`）

- 🔴 **所有删除必须二次确认**，无例外。
- 🔴 文案**必须说清后果**，尤其级联：删菜品须写明「**该菜的饮食记录与纠错记录将一并删除**」。
- 有下属引用时**服务端会拒绝** —— 前端**不预判**，直接展示服务端 `message`。

### 分页（`usePagedList` 状态机）

- 「共 N 条」（`.page__total`）+ 「上一页 / 当前页码 / 下一页」；页大小 **20**（`web/src/composables/usePagedList.ts` 的 `PAGE_SIZE` 单点常量，与服务端默认一致）。
- 状态机单点提供 `rows / total / page / loading / hasNext`：第 1 页禁用「上一页」；`!hasNext`（即 `page * 20 >= total`）禁用「下一页」。
- 🔴 **末页删空自动回退**：删除导致本页查空且不在第 1 页 ⇒ 状态机自动回退一页重查 —— 全站统一，视图不另写守卫。
- 翻页 `go(page ± 1)`、筛选变化 `reload()`（回第 1 页）⇒ 服务端重新分页请求；列表加载失败的 `ElMessage.error` 同样收口在状态机。

### 按钮（`.btn` / `.btn--outline` / `.btn--primary` / `.btn--sm`）

| 类名 | 形态 | 用途 |
|---|---|---|
| `.btn` | 基础形态：高 `32px`、胶囊圆角（`--web-radius-pill`）、细边框 + 白底；按压仅透明度 `0.7` | 通用按钮 |
| `.btn--primary` | 暖橙实底 + 同色描边，胶囊圆角 | 主操作（新建 / 保存） |
| `.btn--outline` | 暖橙细描边 + 透明底；hover 浅橙实底 | 次要操作（弹窗「取消」） |
| `.btn--sm` | 灰边 + 白底，高 `28px`、胶囊圆角 | 小控件（上传 / 移除） |
| 图标位置 | 图标在文案左侧（`AppIcon` + 文字，`gap: 6px`） | 全站按钮统一 |

### 图片

| 位置 | 规格 |
|---|---|
| 列表缩略图 | 菜品 `64×64px`（方形 `object-fit: cover`、圆角 `12px`、**无描边**，无图占位同尺寸）｜海报 `48×64px`（3:4 竖版，圆角 `8px`）；≤640px 统一 `48px` 高 |
| 弹窗预览图 | 菜品图 `80×80px`（`.img--round` 圆形裁切）｜海报 `60×80px`（3:4） |

### 图片上传

- 原生 `<input type="file" hidden>` ⇒ `upload(file)`（`POST /admin/images`）取回**绝对 URL**；表单提交时传该 URL（**入库转相对路径**由服务端负责）。
- 上传中按钮文案「上传中…」；已在库的图片以缩略图呈现，「移除」= 提交 `null`（清除）。

# 三、维护口径

1. **新公共组件 / CSS 类**先进本文件登记，再被页面消费。
2. 页面若需偏离本文件口径，**先改本文件**（或登记该页例外）。
3. 页面设计稿**不得复述**本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
