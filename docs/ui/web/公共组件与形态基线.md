# 公共组件与形态基线 — 跨页唯一真源（运营端）

> 所属端：**运营端**（`web/`） ｜ 技术栈：Vue 3 + TypeScript + Vite + **Element Plus（仅主题变量与程序式提示）**
> **口径分工**：跨页复用的形态口径与公共组件规格以本文件为**唯一真源**；页面级布局见各页设计稿。
> **页面设计稿 SHALL NOT 复述本文件的组件规格** —— 各页只写「本页用法」。

---

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 整体布局 | **顶层固定导航栏**（`56px`）+ **底部居中应用坞**（Dock 式全局导航，见 §2.3）+ **内容区**（滚动，底部让位应用坞） |
| 内容区留白 | 外边距 `20px`，**底部 `104px`（让出应用坞）**；内容区为悬浮纸片卡片（内距 `24px`，圆角 / 阴影见 [设计变量.md](./设计变量.md) §2.2） |
| 页面标题 | 每页顶部一个 `<h2>` 标题（衬线） |
| 页面基底 | 🔴 纯白色 `#FFFFFF` |
| 最大宽度 | **不设限** —— 表格需要横向空间 |
| 页面底色 / 主色 | 纯白基底 + 暖橙主色（见 [设计变量.md](./设计变量.md) §2.1） |

## 1.2 间距 / 字号 / 图标

- 间距与字号以 **Element Plus 默认变量**为基准；内容区卡片的内距 / 圆角 / 阴影 / 底色按 [设计变量.md](./设计变量.md) §2 的单点覆盖执行，🔴 页面内不另写像素级微调。
- 表格单元格内距 `10px 12px`、正文 `14px`；表头暖底（`.table th`）。
- 图标统一用 `AppIcon` 组件（`web/src/assets/icons` 线性 SVG，见 [设计变量.md](./设计变量.md) §2.4）；🔴 不使用图标字体 / 内联 `<svg>`。

## 1.3 状态口径

| 状态 | 实现 |
|---|---|
| 加载中 | **不展示遮罩**；`loading` 仅用于避免请求过程中闪出空态 |
| **空** | 表格内一行 `colspan` 单元格（`.table__empty`）—— **一句话**（如「暂无数据」），**不长句、不放引导按钮** |
| 校验不通过 | `ElMessage.warning`（前端只判非空 / 格式），🔴 **弹窗不关闭** |
| 操作成功 | `ElMessage.success`（文案见各页「提交」行） |
| 操作失败 | `ElMessage.error`（**直接展示服务端 `message`**） |
| 未登录 | 路由守卫拦截 ⇒ 跳登录页；请求 `401` ⇒ 清 token 并跳登录页 |

## 1.4 表单与校验

- 前端做**非空 / 格式**基础校验（即时反馈）；
- 🔴 **服务端是最终判据** —— 唯一性、引用约束（有下属 / 被引用）**只能**在服务端判；
- 冲突时**直接展示服务端 `message`**，🔴 **不在前端重算唯一性**。
- 每个表单控件都有 `<label for>` 与控件 `id` 成对；筛选区下拉用 `aria-label` 标注用途。

## 1.5 表格

| 项 | 口径 |
|---|---|
| 结构 | 原生 `<table class="table">`（`thead` + `tbody`） |
| 分页 | **服务端分页**，默认 20 条/页（上限 50） |
| 列 | 只放业务需要的列；**只读统计列**用 `.table__muted` 弱化；数值列用 `.table__num` 右对齐 |
| 行内操作 | 右侧固定列 `.table__ops`：「编辑」｜「删除」文字按钮（`.link` / `.link--danger`） |
| 🔴 **图片列** | **列表只放「能区分行」的图片** —— 只有「行本身即图片」的 [海报管理](./海报管理.md) 出缩略图；其余页一律不出图 |
| 排序 | 🔴 **不做客户端列排序**（表头不可点）—— 各页顺序一律由**服务端固定**，逐页写在页面稿的「顺序」行 |
| 无多选 / 无批量操作 | 一期不做 |

# 二、本设计的组件清单

## 2.1 项目内 CSS 类（跨页复用）

| 类 | 用途 |
|---|---|
| `.page` · `.page__bar` · `.page__title` · `.page__foot` · `.page__total` | 内容区纸片卡片 / 顶栏 / 标题 / 分页栏 |
| `.filters` · `.filters__select` | 筛选区与筛选下拉 |
| `.table` · `.table__muted` · `.table__num` · `.table__ops` · `.table__empty` · `.table__thumb` | 表格与单元格修饰 |
| `.btn` · `.btn--primary` · `.btn--outline` · `.btn--sm` | 按钮（见 §2.3） |
| `.link` · `.link--danger` | 行内文字按钮 |
| `.tag` · `.tag--on` · `.tag--off` | 状态 / 反应标签 |
| `.mask` · `.dialog` · `.dialog__title` · `.dialog__label` · `.dialog__input` · `.dialog__hint` · `.dialog__foot` | 弹窗 |
| `.img--round` | 图片圆形裁切 |
| `.layout__topbar` · `.layout__main` · `.layout__dock` | 布局骨架（`layouts/AdminLayout.vue`） |

> 🔴 **基础控件的盒模型唯一收口**在 `web/src/styles/theme.css`（`.btn` / `.btn:disabled` / `.btn--primary` / `.table` / `.table th` / `.table td` / `.mask` / `.dialog` 的尺寸、内距、圆角、边框）—— 视图 scoped 只写页面私有差异（如 `.table__ops`），**不得**重复定义同名基础块。

## 2.2 Element Plus（仅两处消费）

| 依赖 | 消费方式 |
|---|---|
| `element-plus/dist/index.css` | 主题变量 `--el-*` 与基础样式（`main.ts` 引入） |
| `ElMessage` | 轻提示（`success` / `warning` / `error`） |
| `ElMessageBox.confirm` | 危险操作二次确认 |

> 🔴 不消费 Element Plus 的**数据 / 表单组件**（`el-table` / `el-form` / `el-dialog` / `el-select` / `el-tag` …）—— 表格、表单、弹窗、标签一律走 §2.1 的项目内 CSS 类。

## 2.3 本项目约定

### 应用坞（`.layout__dock` —— Dock 式底部导航）

| 项 | 口径 |
|---|---|
| 形态 | **悬浮胶囊**：白底（`--el-bg-color`）+ 圆角 `16px`（`--el-border-radius-large`）+ 暖灰细边框 + `--el-box-shadow-elevated`；水平**居中**、悬浮于底缘上方 `12px + env(safe-area-inset-bottom)` |
| 入口 | **七个**功能图标（`AppIcon` `22px`）+ **分组分隔线**（主数据组：食堂 / 档口 / 菜品 / 海报 ｜ 反馈组：评分数据 / 纠错处理 / 纠错选项）+ 分隔线 + 退出登录（`log-out` 图标） |
| 悬停 | 图标格放大上浮（`scale(1.12) translateY(-2px)`）+ **黑底白色名称气泡**（`::after` + `attr(data-label)`，指针不穿透）；退出登录 hover 转错误色 |
| 激活态 | 图标项**主色**（`--el-color-primary` 图标 + `primary-light-9` 圆角底）+ **底部圆点指示**（macOS「运行中」语义）；退出登录**无**激活态 |
| 内容让位 | 内容区**底部留白 `104px`** —— 应用坞为 `fixed` 悬浮层，内容不得压于其下 |
| 响应式 | 🔴 **桌面 / 移动同构** —— 无隐藏态、无断点折叠；仅 ≤`400px` 时图标格收窄至 `38px`（保证七项一坞不溢出） |

### 弹窗（`.mask` + `.dialog`）

| 项 | 口径 |
|---|---|
| 宽度 | **520px**（长表单 `max-height: 86vh` 内滚） |
| 遮罩 | `.mask` 暖色半透明 —— 底色在 [设计变量](./设计变量.md) §2.2 单点给出，页面不另写 |
| 标题 | 「新建 X」/「编辑 X」 |
| 底部 | 「取消」（`.btn--outline`）｜「保存」（`.btn--primary`） |
| 保存中 | 保存按钮 `disabled` + 文案「保存中…」，🔴 **禁止重复提交** |
| 打开时 | **整体重置表单**（避免残留上次的值） |
| 校验不通过 | `ElMessage.warning` 提示，🔴 **不关弹窗** |

### 删除确认（`ElMessageBox.confirm`）

- 🔴 **所有删除必须二次确认**，无例外。
- 🔴 文案**必须说清后果**，尤其级联：删菜品须写明「**该菜的饮食记录与纠错记录将一并删除**」。
- 有下属引用时**服务端会拒绝** —— 前端**不预判**，直接展示服务端 `message`。

### 分页

- 「共 N 条」（`.page__total`）+ 「上一页 / 当前页码 / 下一页」三个按钮；`total` 取自 `AdminPageResult.total`，页大小 20。
- 第 1 页禁用「上一页」；`page * 20 >= total` 禁用「下一页」。
- 翻页 / 筛选变化 ⇒ 重新请求（服务端分页）。

### 按钮（`.btn` / `.btn--outline` / `.btn--primary` / `.btn--sm`）

| 类名 | 形态 | 用途 |
|---|---|---|
| `.btn--primary` | 暖橙实底 + 暖橙描边，圆角 `12px` | 主操作（新建 / 保存） |
| `.btn--outline` | 暖橙描边 + 透明底，圆角 `8px`；hover / active 浅橙实底 | 次要操作（重置 / 取消） |
| `.btn--sm` | 灰边 + 暖灰底，圆角 `8px`，高 `28px` | 小控件（上传 / 移除） |
| 图标位置 | 图标在文案左侧（`AppIcon` + 文字，`gap: 6px`） | 全站按钮统一 |

### 图片

| 位置 | 规格 |
|---|---|
| 列表缩略图 | 海报 `30×40px`（3:4 竖版 `object-fit: cover`，圆角 `4px`） |
| 弹窗预览图 | 菜品图 `80×80px`（`.img--round` 圆形裁切）｜海报 `60×80px`（3:4） |

### 图片上传

- 原生 `<input type="file" hidden>` ⇒ `upload(file)`（`POST /admin/images`）取回**绝对 URL**；表单提交时传该 URL（**入库转相对路径**由服务端负责）。
- 上传中按钮文案「上传中…」；已在库的图片以缩略图呈现，「移除」= 提交 `null`（清除）。

## 2.4 不引入的形态与组件

| 组件 / 形态 | 原因 |
|---|---|
| 多标签页 / `el-tabs` | 无多视图切换 |
| 富文本编辑器 | 无长文本字段 |
| 批量操作 / 行多选 | 一期不做 |
| Element Plus 数据 / 表单组件 | 表格 / 表单 / 弹窗走原生 HTML + 项目内 CSS 类（见 §2.2） |

# 三、维护口径

1. **新公共组件 / CSS 类**先进本文件登记，再被页面消费。
2. 页面若需偏离本文件口径，**先改本文件**（或登记该页例外）。
3. 页面设计稿**不得复述**本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
