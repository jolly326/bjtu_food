# 公共组件与形态基线 — 跨页唯一真源（运营端）

> 所属端：管理端（运营，Web） ｜ 技术栈：Vue 3 + TypeScript + Vite + **Element Plus**
> **口径分工**：跨页复用的形态口径与公共组件规格以本文件为**唯一真源**；页面级布局见各页设计稿。
> **页面设计稿 SHALL NOT 复述本文件的组件规格** —— 各页只写「本页用法」。

---

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 整体布局 | **顶层固定导航栏** + **底部居中应用坞**（Dock 式全局导航，见 §2.2）+ **内容区**（滚动，底部让位应用坞） |
| 内容区留白 | 外边距 `20px`，**底部 `104px`（让出应用坞）**；内容区为悬浮纸片卡片（内距 `24px`，圆角 / 阴影见 [设计变量.md](./设计变量.md) §2.2） |
| 页面标题 | 每页顶部一个标题（衬线） |
| 页面基底 | 🔴 纯白色 `#FFFFFF`；装饰由半透明日历文字承担（仅氛围，不干扰阅读） |
| 最大宽度 | **不设限** —— 表格需要横向空间 |
| 页面底色 / 主色 | 纯白基底 + 暖橙主色（见 [设计变量.md](./设计变量.md） |

## 1.2 间距 / 字号

- 间距与字号以 **Element Plus 默认**为基准；内容区卡片的内距 / 圆角 / 阴影 / 底色按 [设计变量.md](./设计变量.md) §2 的单点覆盖执行，🔴 页面内不另写像素级微调。
- 表格 / 表单控件一律使用组件库默认尺寸。
- 图标统一用 `AppIcon` 组件（`web/src/assets/icons` 线性 SVG，见 [设计变量.md](./设计变量.md) §2.4）；🔴 不使用图标字体 / 内联 `<svg>`。

## 1.3 状态口径

| 状态 | 实现 |
|---|---|
| 加载中 | 表格区 `v-loading`（遮罩） |
| **空** | `el-table` 的 `empty-text` —— **一句话**（如「暂无数据」），**不长句、不放引导按钮** |
| **失败** | 表格区上方 `el-alert`（`type="error"` + 「重试」按钮） |
| 操作成功 | `ElMessage.success`（文案见各页「提交」行） |
| 操作失败 | `ElMessage.error`（**直接展示服务端 `message`**） |
| 未登录 | 路由守卫拦截 ⇒ 跳登录页 |

## 1.4 表单与校验

- 前端做**非空 / 格式**基础校验（即时反馈）；
- 🔴 **服务端是最终判据** —— 唯一性、引用约束（有下属 / 被引用）**只能**在服务端判；
- 冲突时**直接展示服务端 `message`**，🔴 **不在前端重算唯一性**。

## 1.5 表格

| 项 | 口径 |
|---|---|
| 分页 | **服务端分页**，默认 20 条/页 |
| 列 | 只放业务需要的列；**只读统计列**（档口数 / 菜品数 / 评价分）视觉弱化 |
| 行内操作 | 右侧固定列：「编辑」｜「删除」文字按钮 |
| 排序 | 🔴 **不做客户端列排序**（禁点表头）—— 各页顺序一律由**服务端固定**（如 `id` 升序、时间降序），逐页写在页面稿的「顺序」行。二者**不矛盾**：前者禁的是"用户点表头重排"，后者说的是"服务端返什么顺序" |
| 无多选 / 无批量操作 | 一期不做 |

# 二、本设计的组件清单

## 2.1 沿用（Element Plus）

| 组件 | 用途 |
|---|---|
| `el-table` · `el-pagination` | 列表 + 分页 |
| `el-dialog` | **唯一的弹窗载体**（新建 / 编辑） |
| `el-form` · `el-input` · `el-select` · `el-input-number` | 表单 |
| `el-switch` | 菜品状态（在售 / 下架） |
| `el-upload` | 海报 / 菜品图上传 |
| `el-tag` | 状态、错误类型标签 |
| `el-message` · `el-message-box` | 轻提示 / 危险操作确认 |
| `el-alert` | 列表加载失败 |

## 2.2 本项目约定

### 应用坞（`.layout__dock` —— Dock 式底部导航）

| 项 | 口径 |
|---|---|
| 形态 | **悬浮胶囊**：白底（`--el-bg-color`）+ 圆角 `16px`（`--el-border-radius-large`）+ 暖灰细边框 + `--el-box-shadow-elevated`；水平**居中**、悬浮于底缘上方 `12px + env(safe-area-inset-bottom)` |
| 入口 | **七个**功能图标（`AppIcon` `22px`）+ **分组分隔线**（主数据组：食堂 / 档口 / 菜品 / 海报 ｜ 反馈组：评分数据 / 纠错处理 / 纠错选项）+ 分隔线 + 退出登录（`log-out` 图标） |
| 悬停 | 图标格放大上浮（`scale(1.12) translateY(-2px)`，`transform-origin: bottom`）+ **黑底白色名称气泡**（`::after` + `attr(data-label)`，指针不穿透） |
| 激活态 | 图标项**主色**（`--el-color-primary` 图标 + `primary-light-9` 圆角底）+ **底部圆点指示**（macOS「运行中」语义）；退出登录**无**激活态，hover 转错误色 |
| 内容让位 | 内容区**底部留白 `104px`** —— 应用坞为 `fixed` 悬浮层，内容不得压于其下 |
| 响应式 | 🔴 **桌面 / 移动同构** —— 无隐藏态、无断点折叠；仅 ≤`400px` 时图标格收窄至 `38px`（保证七项一坞不溢出） |

### 弹窗（`el-dialog`）

| 项 | 口径 |
|---|---|
| 宽度 | **520px** |
| 标题 | 「新建 X」/「编辑 X」 |
| 底部 | 「取消」｜「保存」（主按钮） |
| 保存中 | 保存按钮 `loading` + 🔴 禁止重复提交 |
| 关闭后 | **重置表单**（避免残留上次的值） |
| 校验失败 | 字段下错误提示，**不关弹窗** |

### 删除确认（`el-message-box`）

- 🔴 **所有删除必须二次确认**，无例外。
- 🔴 文案**必须说清后果**，尤其级联：删菜品须写明「**该菜的饮食记录与纠错记录将一并删除**」。
- 有下属引用时**服务端会拒绝** —— 前端**不预判**，直接展示服务端 `message`。

### 分页（`el-pagination`）

- `layout="total, prev, pager, next"`；`total` 取自 `AdminPageResult.total`。
- 翻页 / 筛选变化 ⇒ 重新请求（服务端分页）。

### 按钮（`.btn` / `.btn--outline` / `.btn--primary`）

| 类名 | 形态 | 用途 |
|---|---|---|
| `.btn--primary` | 暖橙实底 + 暖橙描边，圆角 `12px` | 主操作（新建 / 保存 / 提交） |
| `.btn--outline` | 暖橙描边 + 透明底，圆角 `8px`；hover / active 浅橙实底 | 次要操作（重置 / 取消类） |
| `.btn--sm` | 灰边 + 暖灰底，圆角 `8px`，高 `28px` | 小控件（移除 / 细碎操作） |
| 图标位置 | 图标在文案左侧（`AppIcon` + 文字，`gap: 6px`） | 全站按钮统一 |

### 图片（`.img--round`）

- 海报 / 美食图圆形裁切：`border-radius: 50%` + `object-fit: cover`，轻拟物纸片感。
- 列表缩略图 `40×40px`；弹窗预览图 `80×80px`。

### 图片上传（`el-upload`）

- 上传成功取得**绝对 URL**；表单提交时传该 URL（**入库转相对路径**由服务端负责）。
- 已在库的图片以缩略图 + 「移除」按钮呈现；移除 = 提交 `null`（清除）。

## 2.3 不引入的形态与组件

| 组件 / 形态 | 原因 |
|---|---|
| 多标签页 / `el-tabs` | 无多视图切换 |
| 富文本编辑器 | 无长文本字段 |
| 批量操作 / 行多选 | 一期不做 |

# 三、维护口径

1. **新公共组件**先进本文件登记，再被页面消费。
2. 页面若需偏离本文件口径，**先改本文件**（或登记该页例外）。
3. 页面设计稿**不得复述**本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
