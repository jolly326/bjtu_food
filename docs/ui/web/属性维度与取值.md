# 属性维度与取值

> 所属端：**管理后台（Web）** ｜ 页面 / 单元：**属性维度与取值**（主从两层：维度列表 + 详情抽屉三态）｜ 目标路由：`/dimensions`
> **覆盖**：A4 菜品属性「维度与取值」管理（`dish_attribute_dimension` + `dish_attribute_value`；**所有维度一视同仁** —— `编辑` / `删除` 入口恒可点，无只读行、无置灰项）。
> **不覆盖**：列表通用骨架（基础列 / 详情抽屉 / 六态 / 交互）→ [列表页模板.md](./列表页模板.md) §一 与 §A4；组件规格 → [公共组件与形态基线.md](./公共组件与形态基线.md)；字段 / 校验 / 端点 → [A4 功能文档](../../func/web/A-主数据维护/A4-菜品属性维度管理.md)；菜品侧用法见 [菜品管理.md](./菜品管理.md)。

## 一、页面构成

```
[ h2 属性维度 ]                                        [ 新建维度 ]（主按钮）
┌ .table-wrap ───────────────────────────────────────────────────┐
│ 维度     │ 类型 │ 取值数 │ 关联菜品 │ 更新时间 │ 操作            │
│ 原料     │ 单选 │   6   │   12    │  …      │ 详情            │
│ 口味     │ 多选 │  15   │   31    │  …      │ 详情            │
└────────────────────────────────────────────────────────────────┘
   ↳ 表格脚注：「维度与取值均按 ID 升序；取值在「详情 → 管理取值」内维护。」

＋ 详情抽屉（640，**同一抽屉三态**）
     ① view   ：图片无 / 元信息表（维度 ID / 维度名 / 取值类型 /
                取值数 / 关联菜品 / 更新时间）+ 底部动作 `管理取值` `编辑` `删除`
                （三个动作在全部维度上一致可点，**无置灰项**）
     ② edit   ：维度名称 + 取值类型（底部动作 `取消` / `保存`）
     ③ values ：顶部内联新增行 + `.table--compact`
                （取值 │ 引用菜品 │ 更新时间 │ 操作：改名 / 删除）+ 底部动作 `返回维度详情`
＋ 删除确认（ElMessageBox）
```

| # | 区域 | 要点 |
|---|---|---|
| 1 | **页头** | `h2`「属性维度」+ 主按钮「新建维度」；**无筛选、无分页**（维度量级极小） |
| 2 | **维度列（基础列）** | `维度名`（`name`）→ `类型`（单选 / 多选）→ `取值数`（`valueCount`）→ `关联菜品`（`dishCount`）→ `更新时间`（`formatDateTime`）→ `操作`（`详情`） |
| 3 | **维度详情（抽屉 ①）** | 全字段只读（含**维度 ID = 维度在菜品 `attributes` 中的键**）；**全部操作在此**：`管理取值` / `编辑` / `删除` |
| 4 | **取值管理（抽屉 ③）** | 顶部**内联新增行**（输入 `name` + 「新增」；`Enter` 提交）；下方取值列表（按取值 ID 升序） |
| 5 | **取值列** | `取值`（`name`）→ `引用菜品`（`dishCount`）→ `更新时间` → `操作`（`改名` / `删除`）；行高与内距走 `.table--compact`（[基线 §1.4](./公共组件与形态基线.md)） |

## 二、视觉规格（引用 [公共组件与形态基线.md](./公共组件与形态基线.md)）

| 元素 | 规格 |
|---|---|
| 表格 / 六态 / 交互与状态 / 详情抽屉 | 沿用 [列表页模板.md](./列表页模板.md) §一 |
| 抽屉内容件 | `.detail-meta` / `.ctx` / `.num` / `.muted` / `.foot-note` 等公共类（[基线 §1.15](./公共组件与形态基线.md)）—— 页面**不自绘** |
| 维度编辑 | 在**详情抽屉的 `edit` 态**内（不新开弹窗）：2 个简单控件 + 1 条类型切换影响面提示 |
| 取值管理 | 同一个抽屉的 `values` 态（**不是**第二个浮层）：列表 + 内联新增 + 行内改名 |
| 编辑载体 | 维度字段（名称 + 取值类型）在抽屉内编辑；**无「字段键」输入项** —— 维度 ID 由后端生成 |
| 抽屉脏数据保护 | `edit` 态且表单 ≠ 快照 → 关闭前二次确认「放弃未保存的修改？」（[基线 §1.10](./公共组件与形态基线.md)） |

## 三、交互与状态

| 场景 | 口径 |
|---|---|
| **打开详情** | 行内「详情」→ `view` 态（**不回查详情端点**：维度列表出参即全部字段，无瘦身 VO） |
| **新建维度** | `view` 态 → 直接进 `edit` 态（抽屉标题变「新建维度」）：维度名（1~32）+ 取值类型 → 保存后 `load()`，**新维度排最后** |
| **编辑维度** | `view` 态点「编辑」→ `edit` 态；`维度名` 可随时改（**改名免费**，不影响任何菜品数据）；维度 ID 由后端生成、不可编辑 |
| **取消编辑** | 有历史行 → 退回 `view` 态（不关抽屉）；新建 → 关抽屉 |
| **类型切换（单选 ↔ 多选）** | 字段下固定一行提示「切换取值类型会自动迁移该维度下菜品的数据形状」；**不另做二次确认弹窗**（提交失败即原文透出） |
| **管理取值** | `view` 态点「管理取值」→ `values` 态（标题 = 「取值管理 · {维度名}」）+ 同步拉取该维度取值（`StateBox` 承担加载 / 错误态） |
| **新增取值** | 内联输入（1~32 字，**同维度下唯一**）→ 成功后追加到列表尾部并**保持抽屉打开**（连续录入）；失败原文透出；**取值与维度计数同源刷新** |
| **改名取值** | 行内编辑：点「改名」→ 该行取值变为输入框 + `保存` / `取消`；`Enter` 保存、`ESC` 取消；成功后刷新取值与维度计数 |
| **删除维度 / 取值** | 前端**不预判**，直接提交；被引用时 `400` 原文透出（如「仍有 12 个菜品使用该维度」）→ 提示改用「先改菜品，再删除」 |
| **删除确认** | 取值：`ElMessageBox.confirm`「确认删除取值「{取值}」？被菜品引用时将无法删除。」**维度**：`ElMessageBox.confirm`「确认删除维度「{维度名}」？其下 {valueCount} 个取值、{dishCount} 个菜品正在使用；被引用时将无法删除。」 |
| **删除后** | 行已不存在 ⇒ 抽屉一并关闭（不留空壳） |

## 四、组件清单（**本页用法**）

| 组件 | 本页用法 | 规格 |
|---|---|---|
| `StateBox` | 维度列表六态；**取值态的加载 / 错误 / 空** | [基线 §2.2](./公共组件与形态基线.md) |
| `BaseDrawer` | 详情（`view`）/ 编辑（`edit`）/ 取值管理（`values`） **三态复用同一个抽屉** | [基线 §1.10 / §1.15](./公共组件与形态基线.md) |

> 本页**不使用**：`StatusTag`（维度与取值都没有状态列）、`ImageUpload`、`BaseModal`（本页无短表单）、`useReorder`（维度与取值均按 ID 升序）。

## 五、数据字段

- `DishDimensionAdminVO` / `DishDimensionSaveReq`、`DishValueAdminVO` / `DishValueSaveReq` 与错误码：见 [api/web/dimensions.md](../../api/web/dimensions.md)。
- **取值没有机器键输入口**：管理员只填中文 `name`，ID 由服务端生成（这也是「改名免费」的前提）。
- **时间**：`updatedAt` 一律经 `formatDateTime`（[列表页模板 §1.6](./列表页模板.md)）。
