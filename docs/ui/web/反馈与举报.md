# 反馈与举报

> 所属端：**管理后台（Web）** ｜ 页面 / 单元：**意见反馈**（`/feedbacks`）+ **举报管理**（`/reports`）—— 两个菜单、**同构同源**
> **覆盖**：**B2 意见反馈管理** 与 **B3 举报管理**（`user_feedback` 一表两用，按 `category` 分流）。
> **不覆盖**：列表通用骨架（基础列 / 详情抽屉 / 六态 / 分页 / 交互与状态）→ [列表页模板.md](./列表页模板.md) §一 与 §B2 / §B3；组件规格 → [公共组件与形态基线.md](./公共组件与形态基线.md)；字段 / 端点 / 回执文案 → [B2 功能文档](../../func/web/B-UGC治理/B2-意见反馈管理.md) / [B3 功能文档](../../func/web/B-UGC治理/B3-举报管理.md)；对评价的**隐藏后恢复**在 [评价管理.md](./评价管理.md)。

## 一、两页的共同部分（**同构**）

| 项 | 口径 |
|---|---|
| 骨架 | 完全沿用 [列表页模板.md](./列表页模板.md) §一（页头 / 筛选区 / 六态 / 分页 / 基础列 / 详情抽屉） |
| 页头 | `h2`（「意见反馈管理」/「举报管理」）；**无主按钮**（两页都不产生数据） |
| 筛选区 | ① **状态**▾（全部 / 待处理 / 已处理）② **关键词**（**正文 或 管理员回复**）③ 页面私有的类型筛选（仅 B2 有，见 §B2）④ 「查询」+「重置」 |
| 列表列（**基础列**） | `提交人`（昵称；**匿名提交 `userId = 0` → 服务端回落「游客」**，`--text-muted`）→ **页面私有列**（见 §B2 / §B3）→ `状态`（`StatusTag kind="feedback"`）→ `提交时间`（`formatDateTime`）→ `操作` |
| 状态列 | **恒用 `StatusTag`**：`feedback`（`pending` → `待处理` 中性灰／`handled` → `已处理` 绿）。**不引入红色标「待处理」**（待处理不是错误）；**页面不自写 `.tag-*`** |
| 行操作 | `待处理` 行 → `处理` ｜ `已处理` 行 → `详情`（只读回显）—— 同一个抽屉，态由**行状态**决定 |
| 分页 | `AdminPageResult`，`pageSize` 20，**页码 + 共 N 条** |
| **进详情的内容** | 正文全文、配图、处理结论 / 回复 / 不采纳原因 / 处理时间、原文快照 —— 表格**只留能定位的检索列**（[列表页模板 §1.2](./列表页模板.md)） |

## 二、处置抽屉（两页共用结构）

**载体**：`BaseDrawer`（常规 640 —— 含**只读内容区块** ⇒ 按 [基线 §1.10](./公共组件与形态基线.md) 判据走抽屉）；同一抽屉按行状态两态。

```
┌ 抽屉头：处理反馈 / 反馈详情（B3：处置举报 / 举报详情）───────────────┐
│ ① 只读内容区块 .ctx                                            │
│    类型 · 提交人 · 状态标签                                     │
│    正文（完整，不截断）                                          │
│    配图（56px 缩略图，**点击开 ImagePreview 大图**）              │
│ ② 处置区（仅 pending）                                          │
│    结论  ● 通过 / 已处理   ○ 不采纳 / 退回                       │
│    处理回复 [textarea ≤600，可选]                               │
│    不采纳原因 [input ≤200]（选「不采纳」时才显示，必填）           │
│                                        [ 取消 ] [ 提交处置 ]     │
│ ②' 只读元信息 .detail-meta（仅已处理）                            │
│    记录 ID / 提交人 / 处理结论 / 处理回复 / 不采纳原因 /           │
│    提交时间 / 处理时间                          [ 关闭 ]         │
└──────────────────────────────────────────────────────────────┘
```

| 项 | 口径 |
|---|---|
| **结论控件** | 单选（两枚 `.tag-option` 按钮组）：`通过 / 已处理`（绿语义）与 `不采纳 / 退回`（黄语义）—— 对齐「放行绿 < 驳回黄」梯度 |
| **`reply` 可见性** | **恒显示**（可选，**≤600 字**；下方 `--font-xs --text-muted` 提示「将随站内回执下发给提交人；留空则回执用固定文案」） |
| **`rejectReason` 可见性** | **仅在结论 = 不采纳时出现**，必填（≤200 字）；切回「通过」即隐藏并清空其值 |
| **已处理（只读）** | 抽屉回显结论 / 处理回复 / 不采纳原因 / 提交时间 / 处理时间；底部只有 `关闭` |
| 提交失败 | 原文透出，抽屉不关（含 `400`「不采纳原因不能为空」） |
| 提交成功 | `ElMessage.success('已处理')` → 关抽屉 → `reload()` |
| 配图 | 只读展示；**点击缩略图开 `ImagePreview` 大图**（审核需要看清原图） |

## §B2 意见反馈（`/feedbacks`）

| 项 | 差异 |
|---|---|
| 请求参数 | `category=feedback`（**恒传**，语义 = 「所有非举报」） |
| **页面私有筛选** | **类型**▾：**只列当前写入白名单** `bug` 程序功能 Bug / `suggestion` 产品功能建议 / `other` 其他相关问题（真源 `FeedbackConst.WRITABLE_TYPES`）；下拉选项与白名单同源，见 [schema/user_feedback.md](../../schema/user_feedback.md) |
| **页面私有列** | `类型`（中文标签 + 配图角标 `.img-flag`）—— 表格只放基础列（`内容` / `回复` 全文与配图在抽屉内） |
| 抽屉标题 | 「处理反馈」（待处理）/「反馈详情」（已处理） |
| 结论文案 | 「通过 / 已处理」/「不采纳 / 退回」 |

## §B3 举报管理（`/reports`）

| 项 | 差异 |
|---|---|
| 请求参数 | `category=report`（**恒传**）；**无类型下拉**（本页恒为举报） |
| **页面私有列** | `举报原因`（`reasonLabel`，服务端按 `subReasonId` 实时翻译）—— 表格只放基础列（被举报评价 / 评价状态 / 补充说明在抽屉内） |
| **抽屉只读内容区块** | **被举报评价**（菜品名 + `#reviewId` + 正文全文 + **可见性 `StatusTag kind="review"`**）；**举报原因**（只读）；**补充说明**（未填显示「（未填写）」）+ 举报配图（56px，可点开大图） |
| **被举报评价的可见性标记** | 显示中（`.tag-green`）/ 已隐藏（`.tag-gray`）—— 让管理员一眼看出**是否已处置过**、避免重复处理 |
| **处置抽屉增量** | 处置区**顶部**多一枚复选：**「同时隐藏被举报评价」**（默认**勾选**）；若评价已隐藏 → 复选**置灰 + 已勾选**，附文案「该评价已隐藏」；未隐藏时附「（默认勾选）」 |
| 抽屉标题 | 「处置举报」/「举报详情」 |
| 结论文案 | 「成立 / 已处理」/「不成立 / 不予处理」 |
| 表格脚注 | 「举报原因 / 举报人 / 状态」是快速查阅列；被举报评价原文与可见性、补充说明与处置入口都在行内「处置 / 详情」内。」 |

## 四、数据字段

- `FeedbackAdminVO`、`FeedbackHandleReq`（`outcome` / `reply` / `rejectReason` / `hideReview`）与错误码：见 [B2](../../func/web/B-UGC治理/B2-意见反馈管理.md) / [B3](../../func/web/B-UGC治理/B3-举报管理.md) 的「字段」节。
- **`outcome` 不落列**：由 `status` + `rejectReason` 派生（`rejected ⇒ rejectReason 非空`）—— 界面按此回显结论。
- **`status` 只有两态**（`pending` / `handled`）；B3 的「受理 / 不予处理」是 `outcome`，**不要**与 `status` 混用。
- **`images`**：绝对 URL 数组（≤3），只读展示、可点开大图。
- **匿名提交**：`userId = 0`（反馈 / 举报 / 菜品问题反馈**同口径**，见 [schema/user_feedback.md](../../schema/user_feedback.md)）→ 昵称回落显示「游客」，且**无回执投递**（UI 不显示「已通知」承诺）。
- **时间**：`createdAt` / `handledAt` 一律经 `formatDateTime`（[列表页模板 §1.6](./列表页模板.md)）。
