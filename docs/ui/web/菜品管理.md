# 菜品管理

> 所属端：**运营端**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A3](../../func/web/A-主数据维护/A3-菜品管理.md) ｜ 接口：[api/web/dishes.md](../../api/web/dishes.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 操作组：**「批量」**（切换多选模式）+ **「新建」** |
| 筛选区 | **名称搜索框**（模糊匹配，输入防抖 350ms 即查）· **食堂**下拉（`el-select`）· **档口**下拉（**随食堂联动**，未选食堂时列全部）· **状态**下拉（全部 / 在售 / 已下架）—— 即选即查 |
| 批量条 | **仅多选模式出现**：全选本页复选框 · 「已选 N 项」· 批量上架 / 批量下架 / 批量改档口 |
| 列表卡片 | 名称 + 状态 tag（主行）｜ 食堂 · 档口（归属路径行）｜ **点赞数**（`heart` 图标 `N 人赞`，指标行，只读）—— 卡面无操作按钮；多选模式下行首出勾选框 |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + **跳页**（数字输入 + 跳转，越界自动收敛） |

> 筛选与端点参数一一对应：`name?` · `canteenId?` · `stallId?` · `activate?`（见 [`api/web/dishes.md`](../../api/web/dishes.md)）。
> **点赞数在本页展示**（群体热度 = `COUNT(dish_rating.liked = 1)`，只读派生列）—— 不单列反馈页。

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属档口（下拉，按食堂分组，必填）· 名称（必填）· 菜品大图（上传，可选）· 状态（下拉） |

| 状态 | 下拉（在售 / 已下架）；🔴 **不做列表行内快捷切换** |
| 菜品大图 | 上传得绝对 URL（**上传前前端压缩**：最长边 1200px、JPEG 0.85，解码失败保底原图）；「移除」= 提交 `null` |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 入口在**编辑界面内**（`.btn--danger`）⇒ 二次确认后提交；🔴 **引用即禁删**：存在学生纠错 ⇒ 服务端拒绝（确认文案：「删除后不可恢复。若该菜已有学生纠错记录，删除会被拒绝（请先改用下架）。」） |
| **多选模式** | 顶栏「批量」进入 ⇒ 勾选框浮于卡片右上角，**点行 = 勾选 / 取消勾选**（此时点卡片**不**进编辑界面）；「退出批量」或提交后清空选择 |
| **批量上架 / 下架** | 逐条 `PUT`（只改 `activate`，其余字段随行带出）；分批并发（每批 6 条） |
| **批量改档口** | 弹窗选目标档口 ⇒ 逐条 `PUT`（只改 `stallId`，名称与图片不变） |
| **批量结果** | 成功 ⇒ `ElMessage.success('已更新 N 项')`；部分失败 ⇒ `ElMessage.warning('已更新 N 项，M 项失败（菜名…）')`；🔴 **批量为逐条提交、非原子** —— 失败项逐条列出，成功项已生效 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|

| 状态 | `.tag`：在售（`--el-color-success` 系）｜ 已下架（中性弱化 `.tag--off`） |
| 点赞数 | **只读统计**（派生缓存列），指标行弱化展示（`heart` 图标 + `N 人赞`） |
| 批量条 | `.batch-bar`（浅底胶囊条）：全选复选框 + 已选计数 + 操作组（靠右） |
| 勾选态 | 行首 `.list-card__check`（原生 `checkbox`，`accent-color` 为主色）；选中行加主色描边 `.list-card--checked` |
| 多选行 | `.list-card--selectable`（指针手型）；🔴 多选模式下**不渲染图区**（点图即勾选，不放大预览） |
| **菜品图** | 列表卡片**上半部为满宽图区**（`aspect-ratio: 16/9`，高度小于宽度；无图走同形占位，见[基线](./公共组件与形态基线.md) §1.6）；弹窗内 `80×80px` 圆形预览（`.img--round`）；🔴 两处图片**点击可全屏放大预览**，且**不冒泡**到卡片点击（见[基线](./公共组件与形态基线.md) §2.3） |

## 4 · 不可编辑的项

| 列 | 原因 |
|---|---|
| 点赞数 | **派生缓存列** —— 由学生点赞自动重算（见 [A3](../../func/web/A-主数据维护/A3-菜品管理.md)）🔴 运营端**没有**调数通道 |
| 所属食堂 | 由档口间接决定（改归属 = 改档口） |
