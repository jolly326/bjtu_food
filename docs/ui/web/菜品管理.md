# 菜品管理

> 所属端：**运营端**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A3](../../func/web/A-主数据维护/A3-菜品管理.md) ｜ 接口：[api/web/dishes.md](../../api/web/dishes.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 主操作「新建」 |
| 筛选区 | **食堂**下拉 · **档口**下拉（**随食堂联动**，未选食堂时列全部）· **状态**下拉（全部 / 在售 / 已下架）—— 三档**即选即查** |
| 列表卡片 | 名称 + 状态 tag（主行）｜ 食堂 · 档口（归属路径行）｜ 点赞数（`heart` 图标 `N 人赞`）· 价格（指标行）—— 卡面无操作按钮 |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 |

> 筛选三档与端点参数一一对应：`canteenId?` · `stallId?` · `status?`（见 [`api/web/dishes.md`](../../api/web/dishes.md)）。

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属档口（下拉，按食堂分组，必填）· 名称（必填）· 价格（必填，单位**元**）· 菜品大图（上传，可选）· 状态（下拉） |
| 🔴 **从纠错页直达** | 携 `?dishId=` 进入本页时，**自动打开该菜的编辑弹窗**（列表加载完成后）—— 这是[纠错处理](./纠错处理.md) §4 动线的落点 |
| **价格** | 🔴 界面用「元」，接口用「分」 —— 转换**只允许在一处**（`web/src/utils/money`），页面内禁裸算 |
| 状态 | 下拉（在售 / 已下架）；🔴 **不做列表行内快捷切换** |
| 菜品大图 | 上传得绝对 URL；「移除」= 提交 `null` |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 🔴 **引用即禁删**：存在学生纠错 ⇒ 提交后 Toast「该菜品已有学生纠错记录，无法删除，请改用『下架』」（删除确认文案：「删除后不可恢复。若该菜已有学生纠错记录，删除会被拒绝（请先改用下架）。」） |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 价格 | 展示为 `¥12.00`（元），随指标行**左贴**强调（`.list-card__price`，卡面整体左对齐，见[基线](./公共组件与形态基线.md) §1.6） |
| 状态 | `.tag`：在售（`--el-color-success` 系）｜ 已下架（中性弱化 `.tag--off`） |
| 点赞数 | **只读统计**（派生缓存列），指标行弱化展示（`heart` 图标 + `N 人赞`） |
| **菜品图** | 列表以 `64×64px` 缩略图展示（无图占位同尺寸，见[基线](./公共组件与形态基线.md) §1.6）；弹窗内 `80×80px` 圆形预览（`.img--round`）；🔴 两处图片**点击可全屏放大预览**（见[基线](./公共组件与形态基线.md) §2.3） |

## 4 · 不可编辑的项

| 列 | 原因 |
|---|---|
| 点赞数 | **派生缓存列** —— 由学生点赞自动重算（见 [A3](../../func/web/A-主数据维护/A3-菜品管理.md)）🔴 运营端**没有**调数通道 |
| 所属食堂 | 由档口间接决定（改归属 = 改档口） |
