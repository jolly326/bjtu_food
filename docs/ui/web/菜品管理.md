# 菜品管理（运营端）

> 页面 UI 唯一真源。契约见 [`docs/api/web/dishes.md`](../../api/web/dishes.md)，业务规则见 [`docs/func/web/A-主数据维护/A3-菜品管理.md`](../../func/web/A-主数据维护/A3-菜品管理.md)。

## 1 · 列表

| 项 | 口径 |
|---|---|
| 数据单位 | **菜品本体 + N 个位置**；同一道菜多位置只占一行卡片 |
| 列表卡片 | 封面图 + 标题行（菜名）｜ 单行元信息（`N 处售卖` · 价格）｜ 描述（单行省略）｜ 售卖位置标签（`食堂 · 楼层 · 档口` + 在售状态，多个位置同行并列、可换行） |
| 筛选 | 名称搜索（防抖 350ms）、食堂、档口；分页 |
| 操作 | 卡面无操作按钮，点击卡片（或键盘 `Enter` / `空格`）直接进入编辑弹窗 |

## 2 · 编辑弹窗

| 项 | 口径 |
|---|---|
| 弹窗尺寸 | 食堂 / 档口 / 菜品三页编辑弹窗统一为宽版卡片（`min(880px, 100%)`），字段共用 `theme.css` 的 `.edit-grid` 两列栅格，位置行单行排布以压低整体高度 |
| 弹窗结构 | flex 列三行：标题行 / 表单主体 `.dialog__body`（唯一滚动区）/ 操作区行；标题与操作区常驻且不覆盖字段，操作区恒填满卡片底缘 |
| 菜品本体 | 名称 · 价格（元）· 描述 · 菜品图片，两列网格；图片预览 16:9、最大宽 `320px` |
| 层级 | 弹窗挂载到 `#overlay-root` 全局覆盖层，层级高于固定顶栏与吸顶页头 |
| 位置表格 | 可增删行；**一行五列** = 食堂下拉 · 楼层下拉 · 档口下拉 · 在售状态 ·「删除本行」；价格与图文不在此处 |
| 楼层 | 可选（选项取自档口数据，另含「全部楼层」）；选楼层收窄档口下拉，选档口反向同步楼层；楼层不随位置落库 |
| 食堂切换 | 重置该行档口与楼层；档口下拉只列该食堂下的档口 |
| 保存 | 菜品本体 + 位置**整表替换**；同一菜品位置重复 → `400`；档口不属于所选食堂 → `400` |
| 删除 | 弹窗内切换整卡确认，提示「位置、向量与反馈将一并清除」 |
| 窄屏 | ≤`767px` 字段栅格收为单列、位置行折为两列且删除按钮跨整行；≤`640px` 位置行为单列；弹窗贴底、标题与操作区常驻、字段区独立滚动，输入与按钮触控目标 ≥44px |

## 3 · 视觉

- 与食堂 / 档口管理同构：`ListCard` 两层结构，主色只用于主操作与选中态。
- 售卖位置以 1px 分隔线与上方内容分组（`.card-lines`）：每个位置是一枚紧凑标签，多个标签同行并列、超宽换行，文字单行省略；在售状态统一用 `.tag--sm` + `.tag--on` / `.tag--off`（文案「在售 / 已下架」），不在标签内堆叠独立行。
