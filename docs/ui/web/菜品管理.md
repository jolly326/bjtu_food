# 菜品管理

> 所属端：**管理端（运营）**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A3](../../func/web/A-主数据维护/A3-菜品管理.md) ｜ 接口：[api/web/dishes.md](../../api/web/dishes.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 主操作「新建」 |
| 筛选区 | **食堂**下拉 · **档口**下拉（**随食堂联动**，未选食堂时列全部）· **状态**下拉（全部 / 在售 / 已下架）+ 「查询」/「重置」 |
| 表格 | 名称 ｜ 所属档口 ｜ 价格 ｜ 状态 ｜ 评价分（只读）｜ 评分条数（只读）｜ 更新时间 ｜ 操作 |
| 分页 | `total, prev, pager, next` |

> 筛选三档与端点参数一一对应：`canteenId?` · `stallId?` · `status?`（见 [`api/web/dishes.md`](../../api/web/dishes.md)）。

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属档口（下拉，按食堂分组，必填）· 名称（必填）· 价格（必填）· 菜品图（上传，可选）· 状态（`el-switch`） |
| 🔴 **从纠错页直达** | 携 `?dishId=` 进入本页时，**自动打开该菜的编辑弹窗**（数据加载完成后）—— 这是[纠错处理](./纠错处理.md) §4 动线的落点 |
| **价格** | 🔴 界面用「元」，接口用「分」 —— 转换**只允许在一处**（`web/src/utils/money`），页面内禁裸算 |
| 状态 | `el-switch`（开 = 在售 / 关 = 已下架）；🔴 **不做列表行内快捷切换** |
| 菜品图 | 上传得绝对 URL；「移除」= 提交 `null` |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 🔴 确认文案：「删除后不可恢复。**该菜的饮食记录与纠错记录将一并删除。**」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 价格列 | 展示为**元**（如 `12.00`），**右对齐** |
| 状态列 | `el-tag`：在售（`success`）｜ 已下架（`info`） |
| 评价分 / 评分条数 | **只读统计**，弱化；零评分显示「暂无评价」 |
| **菜品图** | 🔴 **表格不展示** —— 与[档口管理](./档口管理.md) 的规则一致：**列表只放「能区分行」的图片**。海报是档口的识别物（有海报 = 上橱窗）；菜品图不承担识别作用，且会挤占表格密度 ⇒ 只在弹窗内预览 |

## 4 · 不可编辑的列

| 列 | 原因 |
|---|---|
| 评价分 / 评分条数 | **派生缓存列** —— 由学生评分自动重算（见 [A3](../../func/web/A-主数据维护/A3-菜品管理.md)）🔴 运营端**没有**调分通道 |
| 所属食堂 | 由档口间接决定（改归属 = 改档口） |
