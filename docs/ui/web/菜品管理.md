# 菜品管理

> 所属端：**运营端**
> 返回：[UI 总览](INDEX.md) ｜ 归属功能：[A3](../../func/web/A-主数据维护/A3-菜品管理.md) ｜ 接口：[api/web/dishes.md](../../api/web/dishes.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + **内联筛选** + 操作组：**「批量」**（切换多选模式）+ **「新建」** —— 筛选不单独占行 |
| 筛选区 | 已并入顶栏：**名称搜索框**（模糊匹配，输入防抖 350ms 即查）· **食堂**下拉（`el-select`）· **档口**下拉（**随食堂联动**，未选食堂时列全部）· **「仅看未指定档口」**开关 · **状态**下拉（全部 / 在售 / 已下架）—— 即选即查 |
| 批量条 | **仅多选模式出现**：全选本页复选框 · 「已选 N 项」· 批量上架 / 批量下架 / 批量改档口 |
| 列表卡片 | 名称 + 状态 tag（主行）｜ 食堂 · 档口（归属路径行；**档口为空显示占位「暂无」，置灰**）｜ **点赞数**（`heart` 图标 `N 人赞`，指标行，只读）—— 卡面无操作按钮；多选模式下行首出勾选框 |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + **跳页**（数字输入 + 跳转，越界自动收敛） |

> 筛选与端点参数一一对应：`name?` · `canteenId?` · `stallId?` · `activate?`（见 [`api/web/dishes.md`](../../api/web/dishes.md)）。
> **点赞数在本页展示**（群体热度 = `COUNT(dish_rating.liked = 1)`，只读派生列）—— 不单列反馈页。

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：**名称** · **所属食堂**（下拉，必选）· **所属档口**（下拉，随食堂联动 + 「未归位档口」分组，含「不指定档口」）· **楼层**（下拉，含「不指定」）· **状态**（与楼层同排两列栅格，不独占一行）· **菜品图片**（16:9，选图仅本地预览、保存时上传）；标签只写字段名，不写「必填 / 选填」 |

| 状态 | 下拉（在售 / 已下架）；🔴 **不做列表行内快捷切换** |
| 菜品大图 | 选图后**仅本地预览**（**上传前前端压缩**：最长边 1200px、JPEG 0.85，解码失败保底原图），**保存时才真正上传 COS** 取回绝对 URL；「移除」= 提交 `null`（不落桶） |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 入口在**编辑界面内**（`.btn--danger`）⇒ **整卡内容切换**为「确认删除」视图（标题 / 说明 / 按钮整体替换，取消回到表单；不再用独立浮层）；确认后提交，管理员可物理删除，引用项（纠错 / 点赞）随 `CASCADE` 一并清除，说明「纠错 / 点赞将一并清除」 |
| **多选模式** | 顶栏「批量」进入 ⇒ 勾选框浮于卡片右上角，**点卡片 = 勾选 / 取消勾选**（此时点卡片**不**进编辑界面）；🔴 **页面与卡片排版不变，封面保留且点图仍可放大**；「退出批量」或提交后清空选择 |
| **批量上架 / 下架** | 逐条 `PUT`（只改 `activate`，其余字段随行带出）；分批并发（每批 6 条） |
| **批量改档口** | 弹窗选目标档口（**含「清空档口」按钮**）⇒ 逐条 `PUT`（只改 `stallId`，名称与图片不变） |
| **批量结果** | 成功 ⇒ `ElMessage.success('已更新 N 项')`；部分失败 ⇒ `ElMessage.warning('已更新 N 项，M 项失败（菜名…）')`；🔴 **批量为逐条提交、非原子** —— 失败项逐条列出，成功项已生效 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|

| 状态 | `.tag`：在售（`--el-color-success` 系）｜ 已下架（中性弱化 `.tag--off`） |
| 点赞数 | **只读统计**（派生缓存列），指标行弱化展示（`heart` 图标 + `N 人赞`） |
| 批量条 | `.batch-bar`（浅底胶囊条）：全选复选框 + 已选计数 + 操作组（靠右） |
| 勾选态 | 行首 `.list-card__check`（原生 `checkbox`，`accent-color` 为主色）；选中行加主色描边 `.list-card--checked` |
| 多选行 | `.list-card--selectable`（指针手型）；🔴 多选模式下**保留图区**（点图仍放大预览、不触发勾选），仅右上角多一个勾选框 |
| **菜品图** | 列表卡片**上半部为满宽图区**（`aspect-ratio: 16/9`，高度小于宽度；无图走同形占位，见[基线](./公共组件与形态基线.md) §1.6）；弹窗内 **16:9 横向预览**（铺满表单、`object-fit: cover`，`ImageField` 组件）；🔴 两处图片**点击可全屏放大预览**，且**不冒泡**到卡片点击（见[基线](./公共组件与形态基线.md) §2.3） |

## 4 · 不可编辑的项

| 列 | 原因 |
|---|---|
| 点赞数 | **派生缓存列** —— 由学生点赞自动重算（见 [A3](../../func/web/A-主数据维护/A3-菜品管理.md)）🔴 运营端**没有**调数通道 |
| 所属食堂 | **菜品自身必填字段**（改归属直接改 `canteenId`）；档口仅作可选细化，档口所属食堂须与之一致 |
