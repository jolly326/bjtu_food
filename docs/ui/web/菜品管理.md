# 菜品管理

> 所属端：**运营端**
> 归属功能：[A3](../../func/web/A-主数据维护/A3-菜品管理.md) ｜ 接口：[api/web/dishes.md](../../api/web/dishes.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 内联筛选 + 操作组：「新建」 |
| 筛选区 | **名称搜索框**（防抖 350ms）· **食堂**下拉 · **档口**下拉（随食堂联动）· **状态**下拉（全部 / 在售 / 已下架）—— 即选即查 |
| 列表卡片 | 菜品本体 + **售卖点列表**（本页重点） |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 + 跳页 |

## 2 · 列表卡片（多售卖点必须展示清楚）

```
┌──────────────────────────────────────────────┐
│ [图 16:9]  辣子鸡            [在售]  [3 处售卖] │
│            川味 重辣 下饭 够味 解馋（描述摘要）    │
│ ──────────────────────────────────────────── │
│ 售卖点                                        │
│  东区 · 2F · A档口 · ¥12 · 在售                │
│  西区 · 1F · B档口 · ¥15 · 在售                │
│  学校自营大食堂 · — · 无档口 · ¥10 · 在售        │
└──────────────────────────────────────────────┘
```

| 项 | 口径 |
|---|---|
| 菜名 / 状态 | 主行；状态 tag（在售 / 已下架） |
| 图 | 卡片左侧或上部 16:9 预览，点图可放大（不冒泡） |
| 描述 | 单行省略，完整描述在编辑弹窗内 |
| **售卖点** | 🔴 **逐行展示**：食堂 · 楼层 · 档口 · 价格 · 在售状态；一菜多行 |
| 无档口 | 档口 / 楼层显示「无档口」「—」 |
| 价格缺失 | 显示「价格待定」 |
| 角标 | `N 处售卖`（`offerings.length`），一眼看出多售卖点 |
| 卡面无操作按钮 | 点卡片进编辑弹窗 |

## 3 · 编辑弹窗

### 3.1 菜品本体

| 字段 | 控件 |
|---|---|
| 名称 | 输入（必填，全库唯一） |
| 描述 | 多行文本（建议「名称 + 口味 + 场景 + 特点」） |
| 菜品图 | `ImageField`（16:9，选图本地预览，保存时上传） |
| 在售 | 下拉（在售 / 已下架） |

### 3.2 售卖点表格（可增删行）

| 列 | 控件 | 口径 |
|---|---|---|
| 食堂 | `el-select`（必选） | 来源食堂管理 |
| 档口 | `el-select`（随食堂联动，含「不指定档口」） | 选「不指定」⇒ `stallId = null` |
| 楼层 | **只读**（随档口带出 `floor`） | 无档口显示「—」 |
| 价格（元） | 数字输入 | 保存时 ×100 转分；留空 = `null` |
| 在售 | 开关 | 每个售卖点独立 |
| 操作 | 「删除本行」 | 至少保留 0 行（允许暂无售卖点） |

- 顶部「+ 添加售卖点」追加空行；
- 🔴 **归属校验**：档口所属食堂必须等于本行食堂，否则行内报错、禁止保存；
- 保存语义：**整表替换**（未出现的旧行删除，带 `id` 更新，新行新增）。

## 4 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗；保存成功 ⇒ 关弹窗 + 刷新列表 |
| **删除菜品** | 编辑弹窗内 `.btn--danger` ⇒ 整卡切换确认视图；说明「售卖点与菜品反馈将一并清除，不可恢复」 |
| 校验提示 | 重名 / 档口归属不一致 ⇒ 字段级红字提示 |
| 图片 | 选图压缩后保存时上传；「移除」提交 `null` |

## 5 · 视觉规格

| 项 | 取值 |
|---|---|
| 售卖点行 | 浅底分组（`.offering-row`），每行上下 `--el-spacing-sm`，`font-size: 13px` |
| 无档口 / 价格待定 | `--el-text-color-placeholder` 弱化 |
| 角标 | `.tag--count`（中性浅色，显示 `N 处售卖`） |
| 在售 / 下架 | 沿用 `.tag` 与 `.tag--off` |

## 6 · 不可编辑

| 列 | 原因 |
|---|---|
| `embedding` | 由服务端根据 `description` 自动重算，运营端无入口 |
