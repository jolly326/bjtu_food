# 登录页

> 所属端：**管理后台（Web）** ｜ 页面 / 单元：**管理员登录** ｜ 目标路由：`/login`
> **覆盖**：管理员登录（登录前首屏）—— 账号 + 密码，**单步**完成。
> **不覆盖**：登录与鉴权的完整口径 → [C1](../../func/web/C-账号与访问/C1-管理员登录与访问控制.md)；端点 / 入参 / 出参 / 错误码 → [api/web/auth.md](../../api/web/auth.md)；表单 / 按钮 / 反馈 / 聚焦规格 → [公共组件与形态基线.md](./公共组件与形态基线.md)；token 取值 → [设计变量.md](./设计变量.md)；**改密**入口在骨架侧栏底部的「账号安全」弹窗（见 [基线 §1.1](./公共组件与形态基线.md)）。

## 页面构成

**登录页在管理骨架（侧栏 + 内容区）之外** —— 全屏居中，不含侧栏、页头与导航。

| 单元 | 构成 |
|---|---|
| 根容器 | 全屏居中（垂直 + 水平），底色 `--bg-page` |
| 登录卡片 | `.card`，宽 `360px`，内距 `--space-6` |
| 品牌区 | 主色方块「食」+「食在交大 / 管理后台」两行（同侧栏品牌区语汇） |
| 表单（第一步） | 两个 `.field`（账号 / 密码）+ 一枚主按钮 `.btn-primary` |

- 卡片 / 表单 / 按钮 / 聚焦环 / 反馈：见 [公共组件与形态基线.md](./公共组件与形态基线.md) §1.3 · §1.7 · §1.8 · §1.12 · §1.13。
- 色彩 / 间距 / 圆角 / 层级 token：见 [设计变量.md](./设计变量.md) §2 · §3 · §6。

## 交互与状态

| 场景 | 行为 |
|---|---|
| 初始 | 账号字段自动聚焦；两字段空 |
| 提交 | 前端校验非空 → `POST /admin/auth/login`；提交中主按钮 `:disabled`（禁用档）|
| 回车 | 任一输入框按 `Enter` 等同提交 |
| 成功 | token 存 `sessionStorage` → 跳转 `/dashboard`；角色由路由守卫的 `GET /admin/auth/me` 回填 |
| 失败 | `ElMessage.error(message)`，服务端统一为「账号或密码错误」（不区分账号不存在 / 密码错误）|
| 已登录访问本页 | 直接跳转 `/dashboard` |
| 未登录访问其它页 | 路由守卫重定向本页 |
| 明暗 | 跟随系统（见 [设计变量.md](./设计变量.md) §1）|

## 组件清单

| 组件 / 类 | 用途 |
|---|---|
| `.card` | 登录卡片壳 |
| `.field` + `.form-input` | 账号 / 密码字段 |
| `.btn-primary` | 主操作：登录 / 验证并登录 |
| `ElMessage` | 登录失败提示 |

## 数据字段

登录请求 / 响应字段（`username` / `password` / `code` / `token` / `expiresIn`）以 [api/web/auth.md](../../api/web/auth.md) 为唯一真源，本页不复述。
