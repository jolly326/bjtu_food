# 登录页

> 所属端：**运营端** ｜ 鉴权：🔓 公开（登录动作本身）
> 返回：[UI 总览](./README.md) ｜ 归属功能：[C1](../../func/web/C-账号与访问/C1-管理员登录.md) ｜ 接口：[api/web/auth.md](../../api/web/auth.md)

## 1 · 页面结构

**居中卡片**（`.login__card`，宽 `400px`），视口水平垂直居中：

| 部件 | 内容 |
|---|---|
| 标题 | 「知行食记 · 运营端」（`h2`，无衬线圆体居中） |
| 账号 | `<input>`，label「账号」+ placeholder「账号」 |
| 口令 | `<input type="password">`，label「密码」+ placeholder「密码」 |
| 提交 | 主按钮「登录」，**撑满卡片宽** |

🔴 **无注册入口、无「忘记密码」、无验证码、无第三方登录**。

## 2 · 交互

| 项 | 口径 |
|---|---|
| 提交 | 回车（`form submit`）或点按钮 ⇒ `POST /admin/sessions` |
| 提交前校验 | 账号或口令为空 ⇒ 卡片内提示「请输入账号和密码」 |
| 提交中 | 按钮文案「登录中…」+ `disabled`，**禁止重复提交** |
| 成功 | token 存 **`sessionStorage`** ⇒ 跳「食堂管理」（`canteens`） |
| 失败 | 卡片内 `.login__error` 展示服务端 `message`（错误色），**保留已填内容** |
| 已登录访问本页 | 直接重定向到首屏（不重复登录） |
| token 失效 | 请求 `401` ⇒ 清 token 并跳回本页 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | `--el-bg-color-page`（**纯白**）—— 🔴 不引入学生端 `--bg-page`（两套体系，见 [设计变量](./设计变量.md) §3） |
| 卡片 | 原生 `.login__card`：宽 `min(400px, 92vw)`、内距 `32px`、圆角 `20px`、`#FAFAFA` 卡面 + 双层极弱阴影、**无描边** |
| 表单 | 原生 `label` + `input`（标签在上）；`<label for>` 与控件 `id` 成对 |
| 主按钮 | 暖橙实底 + **胶囊圆角**（高 `40px`），撑满卡片宽；hover/active 仅透明度变化（`submit` 态 `opacity: .6` + `not-allowed`） |
| 手机（≤`640px`） | 卡片内距 `28px 22px`；输入 `44px` + 字号 `16px`（iOS 聚焦 `<16px` 输入框会强制缩放视口）、按钮 `46px`；`min-height: 100dvh` 保持垂直居中不被浏览器动态工具栏裁切；`.login__card` 定 `box-sizing: border-box`（无全局重置，否则 `92vw` + 内距外溢出视口） |
