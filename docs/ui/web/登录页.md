# 登录页

> 所属端：**管理端（运营）** ｜ 鉴权：🔓 公开（登录动作本身）
> 返回：[UI 总览](./README.md) ｜ 归属功能：[C1](../../func/web/C-账号与访问/C1-管理员登录.md) ｜ 接口：[api/web/auth.md](../../api/web/auth.md)

## 1 · 页面结构

**居中卡片**（宽 400px），视口水平垂直居中：

| 部件 | 内容 |
|---|---|
| 标题 | 「知行食记 · 运营端」 |
| 账号 | `el-input`，placeholder「账号」 |
| 口令 | `el-input type="password"`，placeholder「密码」，`show-password` |
| 提交 | 主按钮「登录」，**撑满卡片宽** |

🔴 **无注册入口、无「忘记密码」、无验证码、无第三方登录**。

## 2 · 交互

| 项 | 口径 |
|---|---|
| 提交 | 回车或点按钮 ⇒ `POST /admin/sessions` |
| 提交中 | 按钮 `loading` + **禁止重复提交** |
| 成功 | token 存 **`sessionStorage`** ⇒ 跳「食堂管理」 |
| 失败 | `ElMessage.error(服务端 message)`；**保留账号、清空口令** |
| 已登录访问本页 | 直接重定向到首屏（不重复登录） |
| 无权限 / token 失效 | 路由守卫拦截 ⇒ 跳回本页 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 卡片 | `el-card` 默认形态，宽 **400px**，居中 |
| 表单 | `el-form label-position="top"`（标签在上，窄卡片更整齐） |
| 页面底色 | **组件库默认** —— 🔴 不引入学生端 `--bg-page`（两套体系，见 [设计变量](./设计变量.md) §3） |
