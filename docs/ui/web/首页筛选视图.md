# 首页筛选视图

> 所属端：**管理后台（Web）** ｜ 页面 / 单元：**首页筛选视图**（单页：视图列表 + 详情抽屉三态 + 拖拽排序）｜ 目标路由：`/views`
> **覆盖**：A6 首页筛选视图管理（`dish_filter_view` 的文案 / 顺序 / 启停 / **筛选条件** / **排序口径**，含**新建 / 删除**）。
> **不覆盖**：列表通用骨架（基础列 / 详情抽屉 / 六态 / 交互）→ [列表页模板.md](./列表页模板.md) §一 与 §A6；组件规格（`useReorder` / `BaseDrawer`）→ [公共组件与形态基线.md](./公共组件与形态基线.md)；条件语言与白名单 → [api/web/views.md](../../api/web/views.md)。

## 一、页面构成

```
[ h2 首页筛选视图 ]                                    [ 新建视图 ]（主按钮）
┌ .table-wrap ──────────────────────────────────────────────────────────────┐
│ ⠿ │ tab 文案   │ 条件            │ 匹配 │ 状态 │ 更新时间 │ 操作  │
│ ⠿ │ 为你推荐   │ 不筛选          │ 128 │ ●on  │  …      │ 详情  │
│ ⠿ │ 面食粉类   │ 种类 = 面食粉类  │  12 │ ●on  │  …      │ 详情  │
└────────────────────────────────────────────────────────────────────────────┘
   ↳ 表格脚注：「下发规则：启用中且匹配数不为 0 的视图才会出现在首页筛选栏；
      顺序在行首手柄上拖拽调整。」
＋ 详情抽屉（640，**同一抽屉三态**）
     ① view   ：视图 ID / tab 文案 / 条件（逐条只读）/ 排序口径 / 顺序 / 状态 /
                匹配菜品数 / 更新时间 + 底部动作 `编辑` `启用·停用` `删除`
     ② edit   ：tab 文案（1~32 字）+ 排序口径▾ + 条件编辑（逐条：字段▾ / 操作符▾ / 取值）
                + 底部动作 `取消` / `保存`
＋ 删除确认（ElMessageBox）
```

| # | 区域 | 要点 |
|---|---|---|
| 1 | **页头** | `h2`「首页筛选视图」+ 主按钮「新建视图」（打开抽屉 `edit` 态）；**无筛选、无分页**（视图量级极小） |
| 2 | **列（基础列）** | `⠿` → `tab 文案`（`label`）→ `条件`（条件摘要，`[]` 显示「不筛选」）→ `匹配`（`matchedCount`）→ `状态`（`StatusTag` `onoff`）→ `更新时间`（`formatDateTime`）→ `操作`（`详情`） |
| 3 | **详情（抽屉 ①）** | 全字段只读 + **全部操作**（`编辑` / `启用·停用` / `删除`）；条件与排序口径**逐条展示**（可读文案，不显示机器键） |
| 4 | **排序** | 行拖拽（`useReorder`）→ 整体提交 `PUT /admin/dish-views/sort`；**编辑表单内不手填 `order`** |
| 5 | **匹配数自证** | `匹配 = 0` 的视图 → 该行「匹配」旁附 `--font-xs --text-muted`「无匹配，客户端不显示」；详情内附「为 0 时客户端不显示该 tab」 |

## 二、新建

| 项 | 规格 |
|---|---|
| 入口 | 页头主按钮「新建视图」→ 抽屉直接进 `edit` 态（标题「新建视图」） |
| 字段 | `tab 文案`（1~32 字，必填）、`排序口径`▾（白名单单选，必填）、`条件`（可空 = 不筛选） |
| 提交 | `POST /admin/dish-views`；成功后 `load()` + 关抽屉（新视图默认启用、排最后） |
| 取消 | 关抽屉（无历史行，不做脏数据确认） |

## 三、编辑（文案 / 启停 / 条件 / 排序口径）

| 项 | 规格 |
|---|---|
| 载体 | 详情抽屉的 `edit` 态 —— 四组字段一次提交（**整体替换语义**） |
| 提交 | `PUT /admin/dish-views/{id}`（`{ label, enabled, conditions, sortKind }`）；成功后 `load()` → **退回 `view` 态并按 id 回填** |
| 取消 | 退回 `view` 态（抽屉不关） |
| 启停 | 详情内文字动作「启用 / 停用」（`enabled` 翻转，其余字段原样回传） |
| 约束 | **不允许停用「最后一个启用的视图」** → 服务端 `400`，原文透出、状态不变 |

## 四、条件编辑（白名单语言）

条件是一组 **AND** 的行式编辑器：每行 = `字段`▾ / `操作符`▾ / 取值控件；行尾提供「删除本行」，底部提供「＋ 添加条件」。

| 项 | 规格 |
|---|---|
| 字段 | 白名单单选（种类 / 折扣 / 现价 / 档口 / 食堂 / 均分 / 上新），中文标签端上直出 |
| 操作符 | 随字段联动（唯一真源 = [api/web/views.md](../../api/web/views.md) 的字段白名单表） |
| 取值控件 | `种类`▾ / `档口`▾ / `食堂`▾ 用**实体下拉**（值 = ID，候选来自 A6 种类字典 / A2 档口 / A1 食堂）；`现价` / `均分` / `上新` 用**数值输入**；`折扣` 操作符**无取值**（控件隐藏） |
| 多值 | `in` 用**多选**控件；`between` 用两个数值输入（下界 / 上界） |
| 校验 | 端上只做「必填 + 数值形态」提示；白名单与取值形态以服务端 `400` 原文为准 |

> 条件与排序口径**全部来自服务端出参**（列表 / 详情同一份 `conditions` / `sortKind`），端上不写死任何字段清单之外的语义。

## 五、删除

| 项 | 规格 |
|---|---|
| 载体 | 详情抽屉底部文字动作「删除」（`.link.danger`，恒最后） |
| 确认 | `ElMessageBox.confirm`「确认删除视图「{tab 文案}」？该 tab 将从首页筛选栏移除。」 |
| 提交 | `DELETE /admin/dish-views/{id}`；成功后关抽屉 + `load()` |
| 约束 | **不允许删除「最后一个启用的视图」** → 服务端 `400`，原文透出 |
| 失败 | 行已不存在 → 抽屉一并关闭（不留空壳） |

## 六、交互与状态

| 场景 | 口径 |
|---|---|
| 保存后 | `load()`；**匹配数即时刷新**（写后失效缓存，保存即生效） |
| 校验失败 | 服务端 `400` 原文透出，抽屉内的输入与既有状态不误改 |
| 脏数据保护 | `edit` 态且表单 ≠ 快照 → 关闭前二次确认「放弃未保存的修改？」 |
| 排序提交失败 | **回滚顺序** + `ElMessage.error`（[基线 §1.4 排序口径](./公共组件与形态基线.md)） |

## 七、组件清单（**本页用法**）

## 八、数据字段

- `DishViewAdminVO` / `DishViewCreateReq` / `DishViewUpdateReq` / `SortItemsReq` 与错误码：见 [api/web/views.md](../../api/web/views.md)。
- **`matchedCount`** 只读展示（服务端按 `status='on'` 计数），供管理员判断该 tab 是否有效。
- **条件取值的可读名**：种类 / 档口 / 食堂的 ID 在端上换成中文名展示（候选来自各自列表接口），**列表行与详情同一套渲染**。
