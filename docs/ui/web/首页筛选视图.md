# 首页筛选视图

> 所属端：**管理后台（Web）** ｜ 页面 / 单元：**首页筛选视图**（单页：视图列表 + 详情抽屉两态）｜ 目标路由：`/views`
> **覆盖**：A6 首页筛选视图管理（`dish_filter_view` 的 tab 文案 / 筛选种类 / 启停，含**新建 / 删除**）。
> **不覆盖**：列表通用骨架（基础列 / 详情抽屉 / 六态 / 交互）→ [列表页模板.md](./列表页模板.md) §一 与 §A6；组件规格（`BaseDrawer`）→ [公共组件与形态基线.md](./公共组件与形态基线.md)；字段与端点 → [api/web/views.md](../../api/web/views.md)。

## 一、页面构成

```
[ h2 首页筛选视图 ]                                    [ 新建视图 ]（主按钮）
┌ .table-wrap ──────────────────────────────────────────────────────────────┐
│ tab 文案   │ 筛选种类        │ 匹配 │ 状态 │ 更新时间 │ 操作  │
│ 为你推荐   │ 为你推荐        │ 128 │ ●on  │  …      │ 详情  │
│ 面食粉类   │ 面食粉类        │  12 │ ●on  │  …      │ 详情  │
└────────────────────────────────────────────────────────────────────────────┘
   ↳ 表格脚注：「下发规则：启用中且匹配数不为 0 的视图才会出现在首页筛选栏；
      列表与首页筛选栏的顺序均为视图 ID 升序。」
＋ 详情抽屉（640，**同一抽屉两态**）
     ① view   ：视图 ID / tab 文案 / 筛选种类 / 状态 / 匹配菜品数 / 更新时间
                + 底部动作 `编辑` `启用·停用` `删除`
     ② edit   ：tab 文案（1~32 字）+ 筛选种类▾
                + 底部动作 `取消` / `保存`
＋ 删除确认（ElMessageBox）
```

| # | 区域 | 要点 |
|---|---|---|
| 1 | **页头** | `h2`「首页筛选视图」+ 主按钮「新建视图」（打开抽屉 `edit` 态）；**无筛选、无分页**（视图量级极小） |
| 2 | **列（基础列）** | `tab 文案`（`name`）→ `筛选种类`（种类中文名，不筛种类显示「为你推荐」）→ `匹配`（`matchedCount`）→ `状态`（`StatusTag` `onoff`）→ `更新时间`（`formatDateTime`）→ `操作`（`详情`） |
| 3 | **详情（抽屉 ①）** | 全字段只读 + **全部操作**（`编辑` / `启用·停用` / `删除`） |
| 4 | **匹配数自证** | `匹配 = 0` 的视图 → 该行「匹配」旁附 `--font-xs --text-muted`「无匹配，客户端不显示」；详情内附「为 0 时客户端不显示该 tab」 |

## 二、新建

| 项 | 规格 |
|---|---|
| 入口 | 页头主按钮「新建视图」→ 抽屉直接进 `edit` 态（标题「新建视图」） |
| 字段 | `tab 文案`（1~32 字，必填）、`筛选种类`▾（默认「为你推荐（不筛种类）」） |
| 提交 | `POST /admin/dish-views`；成功后 `load()` + 关抽屉（新视图默认启用） |
| 取消 | 关抽屉（无历史行，不做脏数据确认） |

## 三、编辑（文案 / 筛选种类 / 启停）

| 项 | 规格 |
|---|---|
| 载体 | 详情抽屉的 `edit` 态 —— 两组字段一次提交（**整体替换语义**） |
| 提交 | `PUT /admin/dish-views/{id}`；成功后 `load()` → **退回 `view` 态并按 id 回填** |
| 取消 | 退回 `view` 态（抽屉不关） |
| 启停 | 详情内文字动作「启用 / 停用」（`enabled` 翻转，其余字段原样回传） |
| 约束 | **不允许停用「最后一个启用的视图」** → 服务端 `400`，原文透出、状态不变 |

## 四、筛选种类（唯一筛选配置）

| 项 | 规格 |
|---|---|
| 控件 | 普通下拉（`.form-input` 语义），标签在上（[基线 §1.7](./公共组件与形态基线.md)） |
| 选项 | **菜品种类字典**（[菜品管理.md](./菜品管理.md) 的「管理分类」抽屉内维护，顺序 = 种类 `id` 升序）+ 固定首项「**为你推荐（不筛种类）**」 |
| 默认值 | 「为你推荐（不筛种类）」 |
| 取值呈现 | 列表与详情都把取值渲染为**种类中文名**（「不筛种类」渲染为「为你推荐」），**列表行与详情同一套渲染** |

> 本页只有这一项筛选配置（无多条件组合）：视图 = 一个 tab 文案 + 一个种类。

## 五、删除

| 项 | 规格 |
|---|---|
| 载体 | 详情抽屉底部文字动作「删除」（`.link.danger`，恒最后） |
| 确认 | `ElMessageBox.confirm`「确认删除视图「{tab 文案}」？该 tab 将从首页筛选栏移除。」 |
| 提交 | `DELETE /admin/dish-views/{id}`；成功后关抽屉 + `load()` |
| 约束 | **不允许删除「最后一个启用的视图」** → 服务端 `400`，原文透出 |
| 失败 | 行已不存在 → 抽屉一并关闭（不留空壳） |

## 六、交互与状态

| 场景 | 口径 |
|---|---|
| 保存后 | `load()`；**匹配数即时刷新**（写后失效缓存，保存即生效） |
| 校验失败 | 服务端 `400` 原文透出，抽屉内的输入与既有状态不误改 |
| 脏数据保护 | `edit` 态且表单 ≠ 快照 → 关闭前二次确认「放弃未保存的修改？」 |

## 七、组件清单（**本页用法**）

| 组件 | 本页用法 | 规格 |
|---|---|---|
| `StateBox` | 视图列表三态 | [基线 §2.2](./公共组件与形态基线.md) |

## 八、数据字段

- `DishViewAdminVO` / `DishViewCreateReq` / `DishViewUpdateReq` 与错误码：见 [api/web/views.md](../../api/web/views.md)。
- **`matchedCount`** 只读展示：该 tab 当前匹配的**在售菜品数**（「为你推荐」按全量在售计），供管理员判断该 tab 是否有效。
- **筛选种类的可读名**：种类 ID 在端上换成中文名展示（候选来自菜品种类字典，[菜品管理.md](./菜品管理.md)）。
