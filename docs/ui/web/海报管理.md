# 海报管理

> 所属端：**管理端（运营）**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A4](../../func/web/A-主数据维护/A4-海报管理.md) ｜ 接口：[api/web/posters.md](../../api/web/posters.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 主操作「新建」 |
| 筛选区 | **食堂**下拉 · **档口**下拉（**随食堂联动**，未选食堂时列全部）· **状态**下拉（全部 / 上橱窗 / 不展示）+ 「查询」/「重置」 |
| 表格 | **海报**（缩略图）｜ 所属档口 ｜ 所属食堂 ｜ 排序 ｜ 状态 ｜ 更新时间 ｜ 操作 |
| 分页 | `total, prev, pager, next` |

> 筛选三档与端点参数一一对应：`canteenId?` · `stallId?` · `status?`（见 [`api/web/posters.md`](../../api/web/posters.md)）。
> **列表默认序 = `sort` 升序（与学生端橱窗同序）** —— 所见即学生所见；🔴 客户端不做表头排序。

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属档口（下拉，按食堂分组，必填）· 海报（上传，**必填**）· 排序（数字输入，**留空 = 新建排到最后 / 编辑保持原值**）· 状态（`el-switch`） |
| 状态 | `el-switch`（开 = 上橱窗 / 关 = 不展示）；🔴 **不做列表行内快捷切换** |
| 海报上传 | 复用 `POST /admin/images` ⇒ 取回**绝对 URL**；弹窗内显示缩略图，再传即替换（**无「移除」**—— 无图海报无意义，要下橱窗用状态，要删就删除行） |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 🔴 确认文案：「删除后不可恢复，学生端将不再展示该海报。」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| **海报列** | **缩略图**：高 40px、宽 30px（**3:4** 竖版 `object-fit: cover` 裁切），圆角 4px —— 🔴 规则：**列表只放「能区分行」的图片**，本页的行就是海报本身，缩略图即识别物 |
| 排序列 | 纯数字，**右对齐**；弱化 |
| 状态列 | `el-tag`：上橱窗（`success`）｜ 不展示（`info`） |
| 档口 / 食堂列 | 纯文本（食堂列弱化） |
| 顺序 | 服务端按 `sort` 升序、同值按 `id` 升序 |

## 4 · 出图提示（运营须知）

🔴 海报是**学生端「橱窗」tab 的唯一内容**，且学生端**不叠加任何文本** ⇒ **档口名称 / 所属食堂 / 楼层窗口必须画进海报图里**。

- 比例 **3:4**（竖版），素材须按此出图；
- **`不展示`（off）的海报不会出现在「橱窗」**；
- 素材与页面口径见 [`ui/client/档口海报.md`](../client/档口海报.md)。
