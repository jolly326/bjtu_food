# 海报管理

> 所属端：**运营端**
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A4](../../func/web/A-主数据维护/A4-海报管理.md) ｜ 接口：[api/web/posters.md](../../api/web/posters.md)

## 1 · 页面结构

| 区块 | 内容 |
|---|---|
| 顶栏 | 标题 + 主操作「新建」 |
| 筛选区 | **食堂**下拉 · **档口**下拉（**随食堂联动**，未选食堂时列全部）· **状态**下拉（全部 / 上橱窗 / 不展示）—— 三档**即选即查** |
| 列表卡片 | 左置海报缩略图（48×64，3:4）+ 档口名 + 状态 tag（主行）｜ 食堂（归属路径行）｜ 排序（指标行）—— 卡面无操作按钮 |
| 分页 | 共 N 条 + 上一页 / 页码 / 下一页 |

> 筛选三档与端点参数一一对应：`canteenId?` · `stallId?` · `status?`（见 [`api/web/posters.md`](../../api/web/posters.md)）。
> **列表默认序 = `sort` 升序（与学生端橱窗同序）**，同值按 `id` 升序 —— 所见即学生所见。

## 2 · 交互

| 动作 | 口径 |
|---|---|
| 新建 / 编辑 | 弹窗字段：所属档口（下拉，按食堂分组，必填）· 海报（上传，**必填**）· 排序（数字输入，**留空 = 新建排到最后 / 编辑保持原值**）· 状态（下拉） |
| 状态 | 下拉（上橱窗 / 不展示）；🔴 **不做列表行内快捷切换** |
| 海报上传 | 复用 `POST /admin/images` ⇒ 取回**绝对 URL**；弹窗内显示缩略图，再传即替换（**无「移除」**—— 无图海报无意义，要下橱窗用状态，要删就删除行） |
| 保存 | 成功 ⇒ 关弹窗 + 刷新列表 |
| **删除** | 🔴 确认文案：「删除后不可恢复，学生端将不再展示该海报。」 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| **海报缩略图** | 卡片左置：**48×64px**（**3:4** 竖版 `object-fit: cover`，圆角 `4px`，`.list-card__figure--poster`；无图占位同尺寸不塌陷）；🔴 **点击可全屏放大预览**（见[基线](./公共组件与形态基线.md) §2.3） |
| 排序 | 指标行内纯数字，弱化左贴 |
| 状态 tag | 主行内：上橱窗 `.tag--on`（`--el-color-success` 系）｜ 不展示 `.tag--off`（中性弱化） |
| 主行 / 路径行 | 档口名（主行标题）｜ 食堂（`.list-card__path`，灰 `12px` 弱化） |
| 弹窗预览 | `60×80px`（3:4 竖版） |

## 4 · 出图提示（运营须知）

🔴 海报是**学生端「橱窗」tab 的唯一内容**，且学生端**不叠加任何文本** ⇒ **档口名称 / 所属食堂 / 楼层窗口必须画进海报图里**。

- 比例 **3:4**（竖版），素材须按此出图；
- **`不展示`（off）的海报不会出现在「橱窗」**；
- 素材与页面口径见 [`ui/client/风物.md`](../client/风物.md)。
