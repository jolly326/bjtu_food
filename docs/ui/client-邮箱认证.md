# 邮箱认证 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-邮箱认证.md](../feature/client-邮箱认证.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 落点：**无独立页面** —— 认证弹层 `AuthSheet`（学号邮箱 + 验证码）；入口 = 「我的」页用户卡 / 写评价等需认证操作（**不置灰、点击弹认证、认证后继续原动作**）。


- **弹层形态**：`AuthSheet`（无独立认证页）。
- 步骤：输入学号 → 点「发送验证码」→ 输入 6 位验证码 → 提交。
- 页面提示：认证后可用哪些能力（写评价等），以及验证码有效期。
