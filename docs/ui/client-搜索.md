## 0. 与首页的一致性对照（跨页同源，禁各画一套）

| 维度 | 首页 | 搜索页（本页） | 一致性 |
|---|---|---|---|
| 固定标题带 | 左上角「知行食记」（`--font-title` 黑色粗体） | 左上角**返回 icon**（同位置 / 同高度 / 同水平带，与胶囊同线） | ✅ **同口径，仅替换内容物**：带高 = 状态栏 + `navBarHeight`，右侧同样按胶囊避让 |
| 搜索行 | 左搜索胶囊 + 右「搜索」按钮 | **左搜索胶囊 + 右「搜索」按钮（完全同款）** | ✅ 高度 / 圆角 / 内距 / 间距 / 字号 / 颜色全部相同（见 §2，引用首页 §1.2） |
| 页面底色 / 主色 / 文字色 | 首页 §4 全站色板 | 同 | ✅ |
| 顶部滚动行为 | Banner 正常流 + 搜索区/标签栏吸顶 | **无 Banner**：标题带与搜索行**常驻固定**（不吸顶、不滚动、不做纱式过渡） | 差异（本页没有可滚出屏幕的顶部大图） |

> **为什么返回 icon 占标题位**：全站「左上角固定标题带」是同一视觉锚点，位置一致用户才不会在页面切换时「找不到自己在哪里」——首页把它用作页面标题，二级页把它用作返回入口（**不额外增加一行 header**，避免顶部被两行挤占）。

## 1. 页面结构（自上而下）

1. **固定标题带（左上角 = 返回 icon）**：`position: fixed`、永久固定在页面左上角、与微信胶囊同一水平带；**不含标题文字**；带表面**始终为页面底**（本页无 Banner，无需透明态）；
2. **搜索行**（标题带下方）：**左 = 搜索胶囊**（白底、放大镜 + 灰色占位「搜索菜品、食堂、套餐」）+ **右 = 「搜索」按钮**（填充档主色 + 白字）；点击胶囊或按钮均进入可输入态并聚焦；
3. **搜索记录**（未输入关键词时显示）：
   - 数据**纯本地**（`uni.setStorageSync`，键 `find_search_history`），**不上服务端、不做跨设备同步**；
   - 上限 **4 条**（`HISTORY_MAX`），**去重、最新在前**，超过后淘汰最旧；
   - 交互：点条目 → 以该词发起搜索；提供**清空**动作（二次确认不做弹窗，直接清空 + 轻提示）；无记录时**整块不渲染**（不显示空标题）；
4. **猜你喜欢**（未输入关键词时显示，位于搜索记录之下）：
   - 数据来自 **`GET /dishes/for-you`**（2026-09-22 由 `GET /dishes/hot-search` 改名，语义升为「**猜你喜欢**」）——**当前实现 = 每次随机推送在售菜品名**（无推荐算法、无热度排序、无个性化，**完全随机**）；**契约留扩展位**：将来升级为个性化 / 推荐算法时，**端上契约不变**（仍 `keyword` 列表），只换服务端取数逻辑；
   - 形态：**chip 组**（换行排列）；chip 文案 = 返回的 `keyword`，**端上不写死词条、不排序、不限制条数**（按返回渲染）；
   - 交互：点 chip → 以该词发起搜索（并写入本地记录）；
   - 返回空数组 / 请求失败 → **整块不渲染**（不显示标题、不做骨架）；
5. **结果列表**（输入关键词并搜索后显示）：单列结果行（`FindResults`），左缩略图 + 右信息（菜名 / 评分 / 价格 / 位置行），复用首页菜品视觉语言；
6. 页面最底部：**TabBar 不出现**（本页为二级页，返回靠左上角返回 icon / 系统手势）。

## 4. 状态

| 状态 | 呈现 |
|---|---|
| 未输入（发现态） | 搜索记录（有则显示）+ 猜你喜欢（有则显示）；**两者都空 → 内容区留空**（不显示空文案、不做骨架） |
| 输入中 | 仅结果区变化；搜索行文案不截断（超长省略） |
| 结果态（有结果） | 单列结果行列表 |
| 结果态（无结果） | **静默**（沿用既有「失败 ≠ 空结果」口径：空结果不显示误导文案） |
| 失败态 | 结果区渲染「加载失败 · 点击重试」块（`searchFailed`，MP-012），与「没搜到」区分 |
| 猜你喜欢请求失败 | **整块不渲染**（不阻塞搜索能力） |

## 5. 硬性约束（回归检查清单）

1. 左上角**必须是返回 icon**（占原「知行食记」位置），与微信胶囊同水平带、同高、互不遮挡；
2. **搜索行必须与首页完全同位同款**（左胶囊 + 右「搜索」按钮；高度 / 圆角 / 内距 / 间距 / 字号全部引用首页 §1.2）——**不得**再使用「橙色整条 header + 内嵌输入框」的旧头部；
3. 主题色**必须与首页同源**（首页 §4 / §4.1）——不得在本页自建第二套色值；
4. 「搜索记录」**只能存本地**，不得上传服务端、不得跨设备同步；上限 4 条、去重、最新在前；
5. 「猜你喜欢」文案与条数**全部来自后端**，端上不写死、不排序；**不得**引入推荐算法 / 个性化口径；
6. 本页**无筛选入口**（食堂 / 价格筛选已于 2026-09-22 全量下线，见首页功能文档 K 项）；
7. 顶部**不做纱式淡出 / 不做吸顶切换**（本页没有可滚出屏幕的顶部大图）。
