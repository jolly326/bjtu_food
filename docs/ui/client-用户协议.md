# 用户协议 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-隐私政策与用户协议.md](../feature/client-隐私政策与用户协议.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。


- 入口：「我的」页「其他」分组列表第 1 行「用户协议」。
- 页面：`pages/privacy/agreement`，承载《用户协议》单份文本。
- 纯展示：无表单、无按钮交互（仅纵向滚动）。
- 两页共用同一文本版式（卡片承载：标题 + 生效日期 + 分节标题 / 正文），各自独立页面、互不切换。

## 接口数据字段（UI 精修用）

**页面**：`pages/privacy/agreement`（入口 = 「我的」页「其他」分组列表第 1 行；二级页，**无 TabBar**）

### 组件清单（本界面需要哪些组件）

| # | 组件 | 来源 | 在本页做什么 |
|---|---|---|---|
| 1 | `AppHeader` | 公共 `components/AppHeader.vue` | 页头：居中标题「用户协议」+ 左侧返回箭头（`@back` → `backToHome`） |
| 2 | `scroll-view`(scroll-y) | uni 内置控件 | 整页纵向滚动容器 |
| 3 | 文档卡（`.doc` / `.doc-title` / `.doc-meta` / `.doc-h` / `.doc-p`） | `pages/privacy/agreement.vue` 页内内联结构 | 承载单份静态文本（与隐私政策**同一文本版式**） |

> **无**数据类组件：无列表、无表单、无弹层、无 `IconSvg`、无网络请求组件。

### 有哪些数据要显示、显示在哪个组件

| 数据 | 来源 | 显示在哪个组件 | 呈现形式 |
|---|---|---|---|
| 标题「知行食记用户协议」 | 端内静态文案（随包发布，非接口） | 文档卡 `.doc-title` | 一级标题 |
| 生效日期「2026 年 9 月 12 日」 | 端内静态文案 | 文档卡 `.doc-meta` | 次级小字 |
| 五节正文（服务说明 / 账号与认证 / 内容规范 / 信息准确性 / 免责与协议变更） | 端内静态文案 | 文档卡 `.doc-h`（分节标题）+ `.doc-p`（段落） | 只读长文 |

**出参消费**：无（本页不发起任何网络请求）
**入参提交**：无（无表单、无按钮交互）
**控件类型**：`scroll-view`(scroll-y) + 卡片承载文本（纯展示，无交互；两页互不切换）
