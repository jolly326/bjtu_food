# 我的评价 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-我的评价.md](../feature/client-我的评价.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。


- 入口：「我的」页宫格「我的评价」（一行 3 列：意见反馈 / 系统通知 / 我的评价）。
- 页面：`pages/my-reviews/index`——列表行展示：菜品名、星级、评价内容、配图、时间；被隐藏的行显示「已被隐藏」标记；行尾「删除」。
- 空态：未发过评价时给空态引导（去首页看看）。
