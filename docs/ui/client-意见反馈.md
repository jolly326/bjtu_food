# 意见反馈 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-意见反馈.md](../feature/client-意见反馈.md)
> 拆分说明（2026-09-22）：本节自功能文档 docs/feature/ 拆出；**UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径仍以功能文档为准。


- 入口：「我的」页宫格「意见反馈」。
- 页面：`pages/feedback/index`
  - 类型区域：3 类等宽卡片（左侧图标 + 右侧标题 + 说明文案）
  - 动态表单（随类型切换，切换即清空）：
    - 提个想法：二级选项（想法 / 问题）+ 文字 + 配图
    - 推荐菜品：菜名、价格、楼层（必填）、食堂/档口（两级联动，可选「其他」自定义）、描述、配图
    - 信息不对：选菜品（底部弹窗搜索）→ 勾选「哪里不对」（价格/名字/位置/图片属性/已下架/其他，多选）→ 填正确值 → 证据说明 + 配图
  - 提交区：`canSubmit` 门禁 + 置灰点击 toast 提示缺失项
