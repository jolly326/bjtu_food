# 菜品详情查看 — 页面 UI 设计稿

> 所属端：管理端（Web 后台） ｜ 归属功能文档：[web-菜品详情查看.md](../feature/web-菜品详情查看.md)
> 拆分说明（2026-09-22）：本节自功能文档 docs/feature/ 拆出；**UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径仍以功能文档为准。


- 入口：菜品列表（[菜品管理](./web-菜品管理.md)）行点击 → `/dashboard/content/dishes/{id}`。
- 页头：返回按钮 + 菜名 + 副标题（食堂 · 档口 · ★评分（N 人））+ 编辑 / 删除操作。
- 信息卡：菜品图（多图）、价格 / 原价（有值且高于现价时划线）、描述、荤素 / 主料 / 口味 / 冷热、标签、位置、信息更新时间。
- 评价列表：该菜全部评价（含已隐藏），点行开 `ReviewDetailDialog` 查看详情。
