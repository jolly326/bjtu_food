# 菜品详情查看 — 页面 UI 设计稿

> 所属端：管理端（Web 后台）
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 落点：`/dashboard/content/dishes/:dishId`（`DishDetailView`，**菜品管理的子路由**，非一级导航）；入口 = 菜品列表行点击。页内编辑统一走列表页同一个 `DishFormDialog`（同一实体不得两套编辑实现）。


- 入口：菜品列表（[菜品管理](./web-菜品管理.md)）行点击 → `/dashboard/content/dishes/{id}`。
- 页头：返回按钮 + 菜名 + 副标题（食堂 · 档口 · ★评分（N 人））+ 编辑 / 删除操作。
- 信息卡：菜品图 + 名称 / 价格 / 状态 / 荤素 / 主料 / 口味 / 冷热 / 介绍（**位置在页头副标题**；无标签、无信息更新时间）。
- 评价列表：该菜全部评价（含已隐藏）；**行不可点**，经操作列「**查看**」按钮开 `ReviewDetailDialog`。
