# 注销账号 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-注销账号.md](../feature/client-注销账号.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。


- 入口：**「我的」页「其他」分组列表**末行「注销账号」（危险弱化：文字取 `--color-error`，非主行动）。
- 点击 → **二次确认**弹窗（确认按钮取危险色实值，确认文案「确认注销」；说明后果：昵称头像清空、评价与反馈保留但去身份化、**不可恢复**——重新登录将创建全新账号，旧数据不会回到新账号）。

## 接口数据字段（UI 精修用）

**页面**：无独立页面（入口 = 「我的」页 `pages/mine/index` 「其他」分组列表**末行「注销账号」**）

### 组件清单（本界面需要哪些组件）

| # | 组件 | 来源 | 在本页做什么 |
|---|---|---|---|
| 1 | 危险弱化列表行 `.more-row--danger` | `pages/mine/index.vue` 页内内联结构 | 「注销账号」行：文字取 `--color-error` + 右箭头 `IconSvg name="arrow"`；**非主行动** |
| 2 | `uni.showModal` | uni 内置控件 | 二次确认弹窗（标题「注销账号」/ 确认文案「确认注销」/ 确认钮取危险色实值） |
| 3 | `useUserStore.forceLogout()` | `stores/user` | 注销成功后清本地 token 与用户态（页面回落游客态；旧 token 已被服务端拉黑） |

> 本功能**无专属组件、无独立弹层组件**（复用系统 `showModal`）；`IconSvg` / `TabBar` 等归宿主「我的」页所有。

### 有哪些数据要显示、显示在哪个组件

| 数据 | 来源 | 显示在哪个组件 | 呈现形式 |
|---|---|---|---|
| 弹窗后果说明 | **端内静态文案**（非接口） | `uni.showModal` 弹窗正文 | 「注销后账号将匿名化且不可恢复：重新登录将创建全新账号，你的评价与反馈会保留但不再关联身份，也不会回到新账号。」 |
| 行文案「注销账号」 | 端内静态文案 | `.more-row--danger` | 错误色文字 + 右箭头 |
| 注销结果 | `DELETE /auth/account` 成功（`data` = null） | 无界面（Toast「账号已注销」） | — |
| 失败提示 | `400` / `401` 响应的 `message` | 无界面（Toast 直透 `message`，兜底「注销失败，请稍后重试」） | — |

**出参消费**：无（`Result<Void>`，`data` 为 null，成功即 `code=200`）
**入参提交**：`DELETE /auth/account` → **无请求体、无参数**（注销对象 = JWT 当前用户，端上**不传 userId**；且该请求**跳过 401 静默登录重试**——静默登录会建出新游客号，重试会误删新账号）
**错误码**：`400` 账号已注销（终态保护）/ 账号已被禁用，无法注销｜`401` 请先登录
**控件类型**：危险弱化文字行（`--color-error`）+ `uni.showModal` 二次确认（确认钮取危险色实值）
