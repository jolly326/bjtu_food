# 浏览计数 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-浏览计数.md](../feature/client-浏览计数.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 落点：**无独立界面** —— 纯计数（获取菜品详情即计），无任何可见 UI；本文档记录「为什么没有界面」与计数口径。


无独立界面（获取菜品详情自动触发，用户无感知）。

> **计数口径（见功能文档）**：计数由 `GET /dishes/{id}` 承担，**每次成功响应即 +1**
> （PV 口径，不做人员 / 时间限制），**端上无须发起任何上报请求**；
> 唯一的服务端兜底是 **IP 维度限频**，正常浏览速率下**用户无感** —— 故本页仍**无任何可见 UI**。

## 接口数据字段（UI 精修用）

**页面**：无独立界面（副作用内聚于菜品详情）

**出参消费**：无（计数为 `GET /dishes/{id}` 的响应副作用，成功即 +1，不返回计数值）
**入参提交**：无（端上不发起任何上报请求）
**错误码**：`4001` 菜品不存在（**不计数**）｜`400` IP 限频「操作过于频繁，请 X 秒后再试」（**不计数**）

**UI 组件 / 控件**：无（用户无感知）
