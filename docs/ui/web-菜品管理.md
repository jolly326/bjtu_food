# 菜品管理 — 页面 UI 设计稿

> 所属端：管理端（Web 后台）
> 落点：`/dashboard/content`（`DishManageView`，**后台默认落地页**）；新增 / 编辑走 `DishFormDialog` 弹窗（不跳页）。

- 导航「菜品」→ `/dashboard/content`（**管理端默认落地页**）。
- 页头：H1「菜品」+ [新增菜品] 按钮。
- 筛选条：大类 / 食堂 / 档口 / 状态 + 关键词搜索（**当前为前端本地过滤**；服务端加参数的建议见 `README.md`「需拍板的待办清单」第 7 项）。
- 表格列：图片 / 名称 / 位置（食堂·档口）/ 价格 / 评分 / 大类 / 状态（行内 switch 上下架）/ 操作（编辑 · 删除）。
- 批量动作：勾选多行后可**批量上架 / 下架 / 删除**（执行中禁用，结束统一刷新一次并回报成功 / 失败条数）。
- 弹窗：`DishFormDialog`（新增与编辑共用）——菜名、价格、原价（有值且高于现价即端上划线）、描述、图片（多图）、荤素、主料、口味、冷热、食堂·档口。

## 表单内组件：图片上传（无独立路由）

> **合并说明（2026-09-27）**：原 `web-图片上传.md` 合并至本节 —— 它**没有独立路由**，只是表单内的组件，单独占一份「页面设计稿」粒度偏细。

- 形态：**无独立页面**，内嵌在表单弹窗里随宿主渲染，不占导航项。
- 唯一消费方：`DishFormDialog`（菜品图，多图）——即上方「弹窗」一节中的「图片」字段。
- 交互要点：多图选择 / 预览 / 删除、上传中占位（图缺失或失败一律走统一占位）、数量上限与失败提示。
