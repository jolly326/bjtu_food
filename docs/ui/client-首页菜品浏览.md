### 1. 页面结构（自上而下）

1. **顶部通栏 Banner**：左右无间隙、占据页面最顶部区域（含状态栏背后），作为「知行食记」标题的**背景**（标题叠加左上角，黑色粗体大号）。**那个位置就是一张图，无任何文案层**（2026-09-21 定稿：不渲染「今日推荐」等硬编码文本）；背景图用 `<image>` **单独加载**（URL 由页面常量 `BANNER_BG_SRC` 承载，正式资产到位只改该常量；`aspectFill` 铺满；未配置 / 加载失败 → **占位图**：灰底 + 居中「餐具」图标 + 「Banner 占位图」说明，与菜品卡占位**同款**——禁止只留纯色底 / 渐变）。**静态运营位**，动态推荐另立 change；
2. **搜索组件**：圆角白底输入框，灰色占位「搜索菜品、食堂、套餐」，左侧放大镜；右侧「筛选」文字按钮（下拉箭头）→ 展开食堂 / 价格筛选面板（白底、锚定按钮正下方、点外关闭），与标签栏**可叠加**；
3. **横向大类标签栏**（见 §2）；
4. **双列菜品卡片网格**（四段排版见 §3）；
5. **底部 TabBar**：仅「首页（橙色激活）/ 我的（灰色）」，常驻底部不随滚动，预留手势条安全区。

### 2. 横向大类标签栏

- **标签集合（7 项）**：`全部` ｜ `套餐盖饭` ｜ `家常小炒` ｜ `面食粉类` ｜ `香锅干锅` ｜ `风味小吃` ｜ `汤饮甜品`
- 由 `GET /dishes/meal-types` 下发（`[{ key, label, order }]`）：文案、顺序、子集、增删**全由后端决定，端上一个不写死**；首项「全部」= 不传 `mealType`，端上固定渲染；
- **空类自动隐藏**：后端只下发当前有在售菜品的大类（某类空了隐藏、有菜自动出现），端上零改动；
- 横向可滑动；**UI 为单选模式**，同一时间仅选中一个大类标签（菜品归属大类由后端定义）；选中项下方**橙色短下划线**高亮；点击切换 → 列表刷新；v1 不显示计数。

### 3. 菜品卡片（四段固定排版，自上而下）

|---|---|---|
| 1 | 菜品实拍图 | 圆角与卡片一致，高约占卡片 **52%**；无图 / 加载失败 → 「餐具」占位图标 |

### 4. 视觉规范

- **主色 = 橙色两档**：填充档 `--color-primary` `#C2410C`（按钮 / 图标 / TabBar 激活图标）、文字档 `--color-primary-text` `#B93A0A`（价格 / TabBar 激活文字）；标签下划线取 `--color-primary-bright` `#EA580C`；
- 页面背景：**浅米白 → 淡橙顶部渐变**（`#FFF9F3` → `#FFEFE0`）；星色 = **黄色** `--color-star` `#F5A623`（不随主色换肤）；
- 文字层级：标题 / 菜名黑色粗体 > 正文黑色常规 > 次要信息浅灰。

### 5. 滚动交互（初始静止态 ↔ 吸顶静止态，垂直滑动触发）

**触发规则**：仅页面**垂直上下滑动**会触发吸顶状态切换；在标签栏内部横向左右拖动，仅滚动标签条目，**不修改页面 `scrollTop`，不触发页面吸顶状态变更**。两态：【初始静止态（未触发吸顶）】、【吸顶静止态（已触发吸顶）】。

**滚动阈值 = Banner 区块可视高度**：即 Banner 下边缘**刚好对齐吸顶容器底部**时对应的滚动距离（示例：Banner 可视高 320px，则 `scrollTop < 320px` 维持初始态）。

**初始静止态（`scrollTop` ≤ 阈值）**——组件自上而下：

1. 最顶部：Banner 图层完整展示，铺满页面顶部区域（含状态栏下方）；左上角叠加「知行食记」标题文字；Banner 为**独立背景图层**（纯图片 / 占位图，无文案层）；
2. Banner 下方：搜索组件（搜索输入框 + 右侧「筛选」下拉按钮）；
3. 搜索组件下方：横向大类标签栏（标签横向排列，可左右滑动）；
4. 标签栏下方：双列菜品卡片网格列表；
5. 页面最底部：TabBar（首页 / 我的）永久固定，不随页面滚动移动。

> 初始态下，Banner、标题、搜索框、标签栏**全部属于页面正常流**，不固定，跟随页面同步滚动。

**向上滑动操作（`scrollTop` 逐步变大）**：

1. 滑动过程：Banner 图层、标题、搜索框、标签栏**作为整体刚体同步向上移动**，菜品列表跟随同步上移；
2. `scrollTop < 阈值`：持续保持初始态，所有组件一起向上移动；
3. `scrollTop ≥ 阈值`：到达临界点，**Banner 图层停止继续向上移动，定格锁定在吸顶头部容器的背后作为背景**，不再跟随内容继续上滑：
   - 「知行食记标题 + 搜索框 + 大类标签栏」组合成**粘性吸顶容器**，锁定固定在屏幕视口最顶端；
   - 吸顶容器下方的菜品卡片列表**不受锁定影响，继续正常向上滚动**，可上拉加载更多；
   - TabBar 依旧固定在页面底部，位置不变；
   - 吸顶容器内部结构不变（标题、搜索框、筛选按钮、标签栏完整保留）：标签栏依旧支持左右横向拖动，标签点击筛选、搜索、筛选下拉功能全部可用。

**吸顶静止态（`scrollTop` ≥ 阈值，停留在吸顶状态）**：

1. 屏幕视口最顶部：粘性吸顶容器固定不动。容器内部：背景为**定格不动的 Banner 图层**，上层叠加左上角「知行食记」标题、搜索框、筛选按钮、横向大类标签栏；
2. 吸顶容器下方：菜品列表区域，可继续上下滚动；
3. 页面最底部：TabBar 保持固定。

**向下滑动操作（`scrollTop` 逐步变小）**：

1. 滑动过程：菜品列表向下移动，`scrollTop` 不断减小；吸顶容器暂时保持在屏幕顶部不动；
2. `scrollTop < 阈值`：退出吸顶态，切回初始态——
   - Banner 图层**解除定格**，恢复加入页面文档流，跟随页面整体向下移动；
   - 「知行食记标题 + 搜索框 + 标签栏」不再固定，跟随页面内容同步向下滚动；
   - 页面恢复完整自上而下结构：Banner 完整展示 → 搜索框 → 标签栏 → 菜品列表。

**边界行为（必须处理）**：

1. **快速猛滑**：状态切换仅判断 `scrollTop` 是否跨过阈值，**无额外过渡动画**；跨过阈值瞬间完成状态切换；
2. **横向拖动标签栏**：仅标签栏内部横向滚动，页面 `scrollTop` 不变，不改变吸顶 / 初始状态；
3. **点击标签切换分类**：仅重新请求并刷新菜品列表，**不重置页面滚动位置**，维持当前吸顶 / 初始状态不变；
4. **下拉刷新**：强制重置 `scrollTop = 0`，页面直接回到【初始静止态，Banner 完整展示】；
5. **上拉加载更多菜品**：新增卡片追加在列表底部，页面滚动位置与吸顶状态均保持不变。

> ✅ **代码已落地（2026-09-21，change `home-scroll-interaction`）**：本节全部条款已实现——初始态 Banner / 标题 / 搜索框 / 标签栏属页面正常流，上滑时**整体刚体同步上移**（吸顶组位移 = 图层高 − 标题带高，随滚动归零后锁定）；Banner 图层至「下缘 = 吸顶容器底缘」后**定格为吸顶容器背景**（`onReady` 实测头部高）；点标签不回顶、下拉刷新强制回顶、横向拖动不改 `scrollTop`、猛滑无过渡均已落地。原「裁剪窗口折叠收起」「头部行恒不位移」「筛选变更回顶（D6）」均已废止。

**一句话精简版**：页面停在顶部初始态时，Banner、标题、搜索框、标签栏依次从上到下排布，全部跟随页面滚动；手指向上滑动，滚动距离达到 Banner 高度阈值后，Banner 定格在顶部背景不再上移，标题 + 搜索框 + 标签栏固定在屏幕顶端形成吸顶容器，菜品列表继续滚动；向下回滚至小于阈值，取消吸顶，Banner、标题、搜索框、标签栏恢复跟随页面滚动。横向拖动标签仅滚动标签，不改变页面吸顶状态。

### 6. 硬性约束（回归检查清单）

1. 永远**双列**菜品网格，拒绝三列；
2. 食堂档口只用**浅灰纯文字**，禁用绿色 / 彩色标签块；
3. 上滑后搜索框**必须常驻吸顶**，不能消失；
4. 所有菜品卡片**完整显示**，禁止半截截断；
5. 底部导航只保留**首页、我的**；
6. UI 布局**不得遮挡**右上角微信胶囊原生控件；
7. 首页内容流**无引导 / 补录类组件**（2026-09-21 新增）。

> **图片占位策略（本期所有图片先占位，禁止无限空转加载）**：① 菜品图——失败立即回退「餐具」占位图标；② Banner 背景图——未配置 / 失败 → **占位图**（同菜品占位，见 §1）；③ 列表请求失败 → 失败重试块（`RetryBlock`）。**预览排查（2026-09-21 走查）**：若标签栏只剩「全部」或不出现 → 字典请求失败，依次检查：后端是否在线（`GET /dishes/meal-types` 应返回 6 项）、开发者工具是否勾选「不校验合法域名」、是否使用了最新构建产物（`dist/build/mp-weixin`）。
