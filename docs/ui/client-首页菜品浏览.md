# 首页菜品浏览 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-首页菜品浏览.md](../feature/client-首页菜品浏览.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 落点：`pages/home/index`（主包 · **TabBar 页**，经 `reLaunch` 切换，恒不显示返回箭头）。


> **顶部结构（本文档为 UI 唯一真源）**：Banner = **页面最顶端一整块图片区（轮播容器，素材由后端 `GET /banners` 接口下发）**。**页面标题走「固定标题带」**（§1.0）：左上角、与微信右上角**原生胶囊处于同一水平带、同高对齐**，且**永久固定在页面左上角、不随页面滚动移动**（跨页统一位置、文案按页配置——首页为「知行食记」，搜索页等各自填写）。自上而下恒为「**固定标题带（常驻，叠在 Banner 上）** → Banner（正常流首块，含状态栏背后）→ 搜索区 → 横向大类标签栏 → 双列网格」。**Banner 滚出即消失（不折叠、不定格）；吸顶容器只由「搜索区 + 标签栏」组成、背后无图片，锁定位置在固定标题带下沿之下**。Banner 宽高比定为 **16:10**（论证见 §1.1）；顶部各块间距见 **§1.2**；**顶部两带的透明 / 不透明过渡采用「纱式淡出」（见 §1.3）**。
>
> **筛选维度口径**：**首页无任何筛选入口**（无「筛选」按钮、无筛选面板）；搜索页（find）无食堂 / 价格筛选胶囊（见 §2.1）。功能 / 接口口径见功能文档。
>
> **吸顶实现口径**：① 吸顶容器（搜索区 + 标签栏）写在**滚动容器内部的内容流里、用 `position: sticky` 吸顶**——位移完全由渲染层原生滚动驱动、不经逻辑层（见 §1.3 / §5 / §6 第 17 条）；② 容器表面**恒为「与页面底同源」的渐变切片**（切片基准 = 容器顶边在页面坐标中的位置），无「透明 ↔ 不透明」硬切（见 §1.3）；③ 标签栏纵向留白只由「标签行内偏置」与「容器下 padding」各承担一次（行外不叠加），得「搜索区 → 标签文字」≈ **12px**、「下划线 → 卡片首行」≈ **16px**。

### 1.0 固定标题带（跨页统一）

- **定位**：`position: fixed`——**永久固定在页面左上角**，不随页面滚动、不随 Banner 滚出、不参与任何吸顶位移。页面滚动到任意位置，它都在同一处；
- **垂直对齐**：与微信右上角**原生胶囊同一条水平线**——标题带高 = 状态栏高 + 与胶囊同高的一行（`--capsule-h`），标题垂直中心 = 胶囊中心（同一水平带，互不遮挡）；
- **水平起点**：页面级 gutter（`--spacing-md`，与搜索行、标签栏、卡片网格同轴）；右侧为胶囊避让区，标题**不得进入胶囊水平范围**（超长省略号截断）；
- **文案：跨页统一位置、按页配置**——首页 = 「知行食记」，搜索页 / 我的等其他页面各填自己的文案（本文件只定义首页文案）。**位置、高度、对齐方式、配色全站一致**，各页只换文案；
- **配色**：`--text-primary` 黑色粗体大号（`--font-title` / `--weight-bold`）；**不做白字、不描边、不加遮罩层**——初始态它叠在 Banner 图上，**素材标题带区域必须是浅色暖底**（§1.1），深浅对比由素材保证；
- **交互**：纯文本，**无点击行为**（不做返回 / 菜单入口）；
- **层叠**：`z-index` 高于 Banner 与吸顶容器——**任何滚动位置都保证标题可读**（Banner 从其下方滑过、被它遮住属预期）；
- **吸顶态**：**标题带仍常驻显示**；吸顶容器（搜索区 + 标签栏）锁定在**标题带下沿之下**，两者不重叠、不叠图；
- **表面（透明 ↔ 不透明）**：初始态**完全透明**（Banner 从状态栏到标题带整块透出）；随滚动由**与页面底同源的渐变切片**（“纱”）渐显 → 挡住滚上来的网格。完整口径（区间、常量、理由）见 **§1.3**；**纱只柔化 Banner，绝不淡化标题**。

### 1. 页面结构（自上而下）

1. **顶部通栏 Banner（页面最上方一整块大图 = 顶部 Header 的背景）**：
   - 从屏幕**物理顶端 y=0** 起算、**含状态栏背后**，左右**无间隙通栏**，把屏幕上部一整块区域全部占满（图片铺满，两侧与上方不留渐变 / 留白边）；
   - **固定标题带叠在 Banner 之上**（§1.0）：Banner 顶部「状态栏 + 标题带」两带区域即该标题的**背景**；标题**固定不动**——Banner 滚动时从标题带下方滑过（顶部被标题带遮住属预期）；
   - **那个位置就是一张图，无任何文案层**（端上不渲染「今日推荐」等硬编码文本；素材里的「今日推荐 / 副标题 / 菜品插画」均为**图片素材自身内容**，由设计出图，端上零文本）；
   - **轮播容器（接口下发）**：整块 Banner 即一个 `<swiper>` 图片轮播，每一项是一个 `<image mode="aspectFill">` 铺满；**图片清单来自后端 `GET /banners`**（服务端已按 `sort_order` 升序、只返回启用项），端上**严格按返回顺序渲染、不排序、不写死任何 URL**；
     - **多张**：自动轮播（间隔 `BANNER_AUTOPLAY_INTERVAL = 4000ms`）、循环、底部居中指示点；手动左右滑动可切换；
     - **仅一张**：不自动轮播、**不显示指示点**（避免「只有一个点」的假轮播）；
     - **空数组 / 请求失败**：整块退化为**与首页菜品卡图片占位同款灰底的空态**——`var(--bg-soft)` 灰底 + 居中**中性 `empty` 图标**（`IconSvg name="empty"`，色 `--text-tertiary`，尺寸按 Banner 整块等比放大，建议 120）；**图标键取中性 `empty`、不得用 `dish`**（Banner 是运营位轮播，容器语义 ≠ 菜品，依 `project_spec.md` §4.9）；**不渲染「Banner 占位图」等任何文字说明、不加白卡 / 投影 / 渐变**；Banner 请求与菜品列表**并行发起**，Banner 失败**不阻塞**首屏网格；
     - **单张图加载失败**：**该张**显示同一套灰底 + 中性 `empty` 空态（无须整块回退，可随重试恢复），其余张不受影响、轮播继续；
   - **Banner 上无点击交互**（v1 纯展示、无跳转；出参无 `targetType` / `targetId` / `targetUrl`；要做跳转须先在本文件定义交互并另立 change）；
   - **宽高比 = 16:10**（`aspect-ratio: 16 / 10`，理由见 §1.1）：Banner **总高 = 屏宽 × 10/16**（375 宽机型 ≈ 234px），并设**最小高度兜底**（`≥ 状态栏高 + 标题带高 + 运营内容最小可视高`），超宽 / 超窄屏由 `aspectFill` 裁切兜底；**素材一律按 16:10 出图**（混比例会在切换时撑高 / 压扁 Banner）；**加载中 / 失败一律用同高的灰底 + 中性 `empty` 空态**（见下），块高恒定、不因加载状态变化；
2. **搜索区**（**位于 Banner 之下**，页面第二块；**属吸顶容器上半部**）：一行两件——**左侧 = 搜索胶囊**（圆角白底、左侧放大镜、灰色占位「**搜索菜品、食堂、档口**」），**右侧 = 独立「搜索」按钮**（填充档主色圆角按钮 + 白字，宽度按文字定宽，**不与胶囊等分**）；两者**同高、同一行、间距 `--spacing-sm`**（完整间距表见 §1.2）。**页面不存在任何筛选入口与筛选面板**（见 §2.1）；点击**搜索胶囊或右侧「搜索」按钮**均进入搜索页（A-03）；
   - **占位文案口径（两页同源）**：占位**只列真实可搜的维度**。搜索走 `GET /dishes?keyword`，服务端**只匹配「菜名 / 档口名 / 食堂名」三处**（`project_spec.md` §7.35 第 1 条）；**「套餐」不是可搜维度**——项目无套餐实体，「套餐盖饭」只是 `meal_type` 大类，而**大类不参与关键词匹配**，故**不得**写入占位文案。该文案由 **`components/SearchBar.vue` 的默认 `placeholder` 单点承载**，首页与搜索页共用，**改动须两页同批**；
3. **横向大类标签栏**（**位于搜索区正下方**，见 §2）——自上而下顺序恒为「Banner → 搜索区 → 标签栏 → 网格」，不得颠倒；
4. **双列菜品卡片网格**（四段排版见 §3）；
5. **底部 TabBar**：仅「首页（橙色激活）/ 我的（灰色）」，常驻底部不随滚动，预留手势条安全区。

### 1.1 Banner 宽高比为什么取 16:10（而非 16:9）

- **顶部标题带是「不可压缩的固定开销」**：Banner 顶部「状态栏 + 与胶囊同高的标题带」≈ **88px**（iPhone X 类：状态栏 44px + 行高 44px；Android 常见 24–32px + 44px）会被**固定标题带覆盖并承载黑色标题**（§1.0）。比例越扁，这两带在 Banner 内占比越高：
  - 16:9（375 宽 → ≈211px 高）：标题带占比 **≈42%**，留给运营内容（主文案 / 菜品插画）的净高仅 **≈123px**，素材构图稍高就会顶到搜索框、被 `aspectFill` 裁掉；
  - **16:10（375 宽 → ≈234px 高）：标题带占比 ≈38%**，运营内容净高 **≈146px**，构图舒展、主文案不必贴边；
- **首屏菜品曝光仍达标**：16:10 下 Banner 234px + 吸顶块（上间距 16 + 搜索行 32 + 块内 8 + 标签行 44 + 下间距 16 = **116px**）≈ **350px**，在 812px 高机型上首屏仍能露出**第一行双列菜品卡**（卡片 ≈300px+）；若取更高的 4:3（281px），首屏只剩 Banner 与搜索区、第一行卡片完全不可见，与「信息展示优先」的 §0.0 定位相悖；
- **与素材生产约定一致**：设计按 **16:10** 出图（如 1500×938 / 1200×750）；**标题带区域一律保持浅色暖底**，以保证黑色标题可读（若轮播某张图标题带为深色底，须在**素材上**叠浅色蒙版，端上不加蒙版层）；
- **实现口径**：`BANNER_ASPECT = 16 / 10` 为页面常量，Banner 总高 = 屏宽 × 10/16，且不低于「状态栏 + 标题带 + 运营内容最小可视高（≈120px）」；素材仍 `aspectFill`，端上不预留 letterbox 空白。
- **接口化后更须锁定单一比例**：多张轮播图若各按自身比例定高，切换时会撑高 / 压扁 Banner，导致下方搜索区、标签栏与整个网格位移抖动 → 出图规范统一 **16:10**，端上**恒定按 `BANNER_ASPECT` 定高**、绝不按图片真实比例自适应；加载中 / 失败用**同高占位图**，保证吸顶切换点不漂移。

### 1.2 顶部各块间距 / 尺寸规范

> **本节是顶部区域间距的唯一真源**：全部用 token 表达，**禁止裸值近似**。左右外边距恒为页面级 gutter `--spacing-md`（与标签栏首项文字缘、双列网格同轴）。

| 相邻关系 | 间距 | 说明 |
|---|---|---|
| Banner 上缘 → 屏幕顶端 | **0** | Banner 自 `y=0` 起（含状态栏背后） |
| 固定标题带内：标题行 → 状态栏 | 标题带自带状态栏内边距 | 标题带高 = 状态栏高 + `navBarHeight`（§1.0，保证标题与胶囊同中心） |
| **Banner 下缘 → 搜索区上沿** | **`--spacing-lg`**（32rpx / 16px） | **块间**间距：两大块之间的呼吸感 |
| **搜索胶囊 ↔ 右侧「搜索」按钮** | `--spacing-sm` | **块内**横向间隙 |
| 搜索胶囊 / 按钮的左右外侧 → 屏幕左右缘 | `--spacing-md` | 与网格、标签栏同轴对齐 |
| **搜索区下沿 → 标签栏上沿（行盒）** | **0** | 不另设间距；纵向留白全部落在标签行内部（见下两行） |
| **搜索区下沿 → 标签文字** | **≈12px**（标签行 `padding-top` 24rpx） | **块内**间隙（两者是同一组控件） |
| **标签栏下沿 → 网格首行上沿** | 容器 `--spacing-sm`(8px) **+ 标签行自身 ≈8px 行底余量 = 视觉 ≈16px** | **块间**间距：吸顶块与内容的切分 |
| 吸顶容器锁定位置 | `top = 状态栏高 + navBarHeight`（标题带下沿） | **不得压到标题带** |

> **间距层级规则**：**块之间 > 块内部**，且**块之间 > 卡片间距**——
> 块间 = `--spacing-lg`(16px)、块内 = `--spacing-sm`(8px)、卡片间距 = `--spacing-md`(12px)。
>
> **标签栏纵向留白规则**：**行内偏置 / 行底余量与行外 padding 不叠加**——
> 标签行自身高 88rpx（触达下限，不可压低）内含 24rpx 行内上偏置 + ≈16rpx 行底余量；**行外上间距 = 0、行外下间距 = `--spacing-sm`(8px)**，
> 由行内偏置与行底余量补足 → 实测 **12px / ≈16px**，满足「块间 ≥ 块内」「下行距 ≥ 上行距」。

- **高度**：搜索胶囊 = `--capsule-h`（与微信胶囊同高）；右侧「搜索」按钮**同高**；标签栏行高按 §2 既有口径；
- **圆角**：搜索胶囊与「搜索」按钮**同为 `--radius-pill`**（同族语言）；
- **内距**：搜索胶囊左右内距 = `--spacing-md`，其内「放大镜 ↔ 占位文字」间距 = **`--spacing-sm`（16rpx / 8px）**——**不得用 `--spacing-xs`**（4px 会让图标与文字贴在一起）；「搜索」按钮左右内距 = **`--spacing-lg`（32rpx / 16px）**，使按钮宽度 ≈60px、胶囊形饱满（宽度不做等分，随文案定宽）；
- **字号**：「搜索」按钮文案 = **`--font-body`（28rpx / 14px）**，**不得小于**其相邻的搜索占位字号（CTA 文案比输入占位还小会读作「次要标签」）；占位文案同为 `--font-body`；标签栏 = `--font-body`（未选中 `--weight-regular`／选中 `--weight-semibold`）；标题带 = `--font-title`（44rpx）；
- **颜色**：搜索胶囊 = `--bg-card` 白底 + `--shadow-float` + 放大镜 / 占位均 `--text-tertiary`；「搜索」按钮 = `--color-primary` 填充底 + `--color-on-primary` 白字（对比度达标，见 §4.1）；
- **触达**：搜索胶囊与「搜索」按钮的可点区域均 ≥ 88rpx 高（`::after` 透明扩张，不改变视觉尺寸）。

### 1.3 顶部表面过渡：纱式淡出

> **为什么要过渡**：Banner 必须完整占满顶部 → **标题带**在滑动前必须真透明（透出 Banner）、吸顶后必须不透明，否则滚上来的网格会透到「知行食记」后面。**硬切会产生可见的“刷一下变色”**，故采用纱式淡出。
>
> **吸顶容器不需要过渡**：它在正常流中**永远紧贴 Banner 下缘、从不与 Banner 重叠**，因此没有「必须真透明」的约束。把它的表面直接做成**与页面底同源的渐变切片**，并让切片基准 = **容器顶边在页面坐标中的位置**（未吸顶随滚动连续变化、吸顶后夹紧为标题带下沿），表面便**在任何滚动位置都与身后页底逐像素一致**——既等价于「永远透明」，又天然不透出滚上来的网格。**没有「透明 ↔ 不透明」硬切，就没有切换瞬间的穿帮**。
>
> **口径**：**标题带的表面为与页面底同源的渐变切片**（“纱”）随 `scrollTop` **由 0 → 1 渐显**，**不做硬切**——Banner 尾部平滑「融入页面底色」，而不是被一条硬边切掉；**吸顶容器**恒为同源切片（基准随位置对齐，见上），不参与纱式淡出。

**常量（全部由页面常量推导，禁硬编码裸值）**

| 常量 | 定义 | 375 宽 iPhone X 类机型 |
|---|---|---|
| `H_t` 标题带高 | 状态栏高 + `navBarHeight`（`(胶囊.top − 状态栏高) × 2 + 胶囊高`） | ≈ **88px**（标题在行内居中 → 与胶囊同水平线） |
| `H_b` Banner 总高 | `max(屏宽 × 10/16, H_t + 120px)` ⚠️ **兜底项不得再加状态栏高**（`H_t` 已含） | ≈ **234px**（= 16:10，兜底不生效；兜底只在窄屏如 320 宽时接管） |
| `H_s` 吸顶容器高 | 上 padding 16 + 搜索行 32 + 标签行 44 + 下 padding 8（标签行自身已含行内偏置与余量，不叠加） | ≈ **100px**（§1.2 间距表：块间 16 / 视觉下间距 ≈16） |
| `L` 锁定点 | `H_b − H_t` | ≈ **146px**（容器顶边抵达标题带下沿） |
| `VEIL_PX` 纱窗长度 | **60px**（可调区间 48–72） | 纱区间 = `[H_b − 60, H_b]` ≈ **[174, 234]** |

**时序表（上滑；数字随屏宽 / 机型由上述常量推导，非硬编码）**

| `scrollTop` | 标题带（纱） | Banner | 吸顶容器 | 网格 |
|---|---|---|---|---|
| `0` | 完全透明 | 完整铺满 `0..234`（含状态栏背后） | 坐在 Banner 下缘（顶边 = 234）；表面 = 同源切片，切片基准 = 234（该区间页底本就是纯色，逐像素一致） | 在容器下沿起排 |
| `0 → 146` | 完全透明（Banner 从带下划过） | 随滚动 1:1 上移、顶部被标题带遮住 | **原生粘性定位**：1:1 随滚动上移、恒贴 Banner 下缘（间隙恒 = `--spacing-lg`）；切片基准 = `234 − scrollTop` 连续跟随 → 表面与身后页底**始终**逐像素一致（**无任何透明/不透明切换**） | 静止 |
| `146`（`L`） | 透明 | Banner 下缘 = 标题带下沿 | **粘住**在标题带下沿（`top` 触发，非 JS 位移）；切片基准夹紧为标题带下沿 | 首行**恰好贴到**容器下沿（重叠 0） |
| `146 → 174` | 透明 | 仅剩标题带后面那段在缩（带内仍可见图） | 固定不动（粘住） | 从容器背后上移、被**干净裁切** |
| `174 → 234` | **纱 opacity 0 → 1 线性渐显** | 尾部被同色纱**柔化**、同时继续缩短 | 固定不动 | 同上 |
| `234`（`H_b`） | 纱 = **1**（表面完全成形） | **完全滚出**屏幕 | 固定不动 | 同上 |
| `234 → 246`（`H_b + H_s − H_t`） | 纱 = 1 | 无 | 固定不动 | 仍在容器背后（**零内容窗口** ≈12px） |
| `≥246` | 纱 = 1 | 无 | 固定不动 | 首行抵达标题带下沿 → 进入带背后、被**裁切** |

**为什么这样最丝滑（三条硬理由）**

1. **没有「切换」这个动作**：容器表面**恒为同源切片**、基准随位置连续对齐，不存在「透明 → 不透明」的时刻，也就没有可被察觉的突变；纱的完成点在 `H_b`（带内已无图像像素），而网格要到 `H_b + H_s − H_t ≈ 246` 才抵达标题带下沿（窗口 ≈12px，仍为正值 → 不会「内容已到、纱还没到」）；
2. **表面与页面底同源**：纱 = `--home-page-grad`（与页面底同一变量 + 同一段停点 + 同一坐标基准），因此它不是「蒙一层灰」，而是「**融入页面底色**」——纱到位时与页面底逐像素一致，切换无可被察觉的色差；
3. **进度只由 `scrollTop` 推导（不用计时器 / CSS 时长动画）**：无论多猛的滑动，纱的进度与滚动位置**严格同步**，绝不会出现「内容已到、纱还没到」的半透明穿帮；**反向滚动自动对称**——纱按 `scrollTop` 反算，Banner 重新滚入时尾部由「已柔化」逐步回到「完整显示」，不会出现「上滑顺、下滑跳」。

**硬性要求**

1. 纱必须 = **与页面底同源的渐变切片**（`--home-page-grad` + `background-size: 100% 720rpx` + `background-position-y: 0`）；**禁止纯灰 / 纯白 / 黑色蒙版**（那是「蒙灰」不是「融入底色」）。**吸顶容器的表面用同一变量 + 基准 `background-position-y = −(容器顶边页面坐标)`**，同样是同源切片；
2. **纱只柔化 Banner，绝不淡化标题**：纱层与标题分属两层，标题恒在纱之上、字色与不透明度恒定（否则标题会跟着变浅，读作“糊了”）；
3. 纱进度**只能由 `scrollTop` 推导**；**禁止** `setTimeout`、CSS `transition` / `animation` 驱动；
4. **吸顶容器的位移 SHALL 由原生粘性定位承担**（`position: sticky` + `top` = 标题带下沿，写在滚动容器内部的内容流里），**SHALL NOT** 用「滚动回调 + `setData` 下发 `transform` / `top`」模拟位移——小程序逻辑层与渲染层跨线程通信有延迟，容器会比内容慢半拍，表现为「位置像临时算出来的」且容易闪现；
5. **吸顶容器 SHALL NOT 做「透明 ↔ 不透明」切换**（也不参与纱式淡出）：其表面恒为同源切片，基准 = `max(H_b − scrollTop, H_t)`，任何滚动位置都与身后页底逐像素一致；
6. **纱区间常量必须满足 `VEIL_PX ≤ H_t`**（当前 `60 ≤ 88` ✅）——纱窗开启时 Banner 的可见残段高度恰为 `VEIL_PX`，而纱只铺在标题带内；若 `VEIL_PX > H_t`，残段会有一截落在标题带下缘之外**不被纱覆盖** → 出现「半柔化」的硬接缝。可调区间 **48–72**；`VEIL_PX` 越大，Banner 尾部柔化越早、越柔和，但可读的 Banner 内容也越少。

### 2. 横向大类标签栏

- **标签集合（7 项）**：`全部` ｜ `套餐盖饭` ｜ `家常小炒` ｜ `面食粉类` ｜ `香锅干锅` ｜ `风味小吃` ｜ `汤饮甜品`

- **空类自动隐藏**：后端只下发当前有在售菜品的大类（某类空了隐藏、有菜自动出现），端上零改动；
- 横向可滑动；**UI 为单选模式**，同一时间仅选中一个大类标签（菜品归属大类由后端定义）；**选中 / 未选中字色同为 `--text-primary` 黑色**，区分靠**字重（选中 `--weight-semibold`）+ 橙色短下划线**（`--color-primary-bright`）；点击切换 → 列表刷新；v1 不显示计数。
- **光学间距**：标签行高 **88rpx（触达下限，不得压低）**；标签文字在行内**上偏置 24rpx**（`padding-top`），下划线紧随文字 **4px**（`--spacing-xs`）。行内偏置是「搜索区 → 标签文字」间距的**唯一来源**（≈ **12px**）；「下划线 → 卡片首行」= 容器下 padding（`--spacing-sm` 8px）+ 行底余量（≈8px）≈ **16px**。两者满足「下行距 ≥ 上行距」，且**不与标签行外 padding 叠加**。**下划线不得吸到行底**——那会让它离文字 ≈16px、与标签脱开。标签栏行高不变 → §1.3 的 `H_s` 不受影响。

> **取色应用**：按上文「取色边界」，**所有「主色压浅底」处用文字档 `#B4531A`**，**所有填充底白字处用 `#B4531A`**（**不得**用 `#E67E22` / `#D35400`）；品牌色阴影通道 = `rgba(180, 83, 26, α)`；**星标一律 `--color-star`**（含搜索页结果卡）。

### 5. 滚动交互（初始静止态 ↔ 吸顶静止态，垂直滑动触发）

**结构前提**：顶部恒有**三层**——① **固定标题带**（`position: fixed`，永久固定左上角、**不随滚动移动**，§1.0）；② **Banner**（页面正常流第一块，含状态栏背后，**不参与吸顶、不折叠、不做定格背景**，滚动即滚出）；③ **吸顶容器 = 搜索区 + 横向大类标签栏**（其背后无任何图片）。内容流顺序：Banner → 搜索区 → 标签栏 → 双列网格。

**触发规则**：仅页面**垂直上下滑动**触发吸顶状态切换；在标签栏内部横向拖动、在 Banner 轮播内左右滑动切换图片，**均不修改页面 `scrollTop`、不触发吸顶状态变更**。两态：【初始静止态（未吸顶）】、【吸顶静止态（已吸顶）】。**固定标题带在两态下都常驻显示，不参与状态切换。**

**滚动阈值 = Banner 总高 − 标题带高**：即 Banner 下边缘刚好抵达**固定标题带下沿**（= 吸顶容器锁定位置）时的滚动距离。Banner 总高 = **屏宽 × 10/16**（375 宽 / 16:10 ≈ 234px）、标题带高 = **状态栏高 + `--capsule-h`**（≈88px）→ 阈值 ≈146px；两值均由页面常量推导，**非硬编码**。

**初始静止态（`scrollTop` ≤ 阈值）**——组件自上而下：

1. **固定标题带**：「知行食记」固定在页面左上角，与微信胶囊同一水平带（文案按页配置，§1.0）；
2. 屏幕自 `y=0` 起：Banner 整块大图铺满（**含状态栏背后**，故标题带叠在其上）；块内为图片轮播（多张自动播放 + 底部指示点）；
3. Banner 下方（间距 `--spacing-lg`，见 §1.2）：搜索区 = **左侧搜索胶囊 + 右侧独立「搜索」按钮**（见 §1.2）——**属吸顶容器**，本态下仍在正常流中、随页面滚动；
4. 搜索区下方：横向大类标签栏（标签横向排列，可左右滑动）——**同属吸顶容器**；两者间距全部落在**标签行内部**（§2 光学间距），行外不补 padding；
5. 标签栏下方（视觉 ≈16px = 容器下 padding + 标签行行底余量，见 §1.2）：双列菜品卡片网格列表；
6. 页面最底部：TabBar（首页 / 我的）永久固定，不随页面滚动移动。

> 初始态下，Banner、搜索区、标签栏**属于页面正常流**，跟随滚动同步上移；**唯一固定的是标题带**——它始终在左上角，Banner 从它下方滑过。

**向上滑动操作（`scrollTop` 逐步变大）**：

1. `scrollTop < 阈值`：Banner、搜索区、标签栏、网格**整体同步上移**（1:1 跟手，无折叠动画、无缩放），Banner 逐渐滚出视口（其顶部从**固定标题带下方**滑过、被标题带遮住）；吸顶容器的位移由**渲染层原生粘性定位**完成（不经滚动回调 / `setData`），与内容严格同步、无滞后闪现；
2. `scrollTop ≥ 阈值`：Banner 已**整块滚出视口**（仅剩固定标题带常驻）→ **「搜索区 + 标签栏」吸顶容器锁定在固定标题带下沿**（搜索区在上、标签栏在下）：
   - 吸顶容器**无图片背景**——它不承载 Banner 图、不与 Banner 图叠加，是独立的页底 / 白卡表面；
   - 吸顶容器**不得压到固定标题带**：锁定位置 `top = 状态栏高 + --capsule-h`（§1.2）；
   - 吸顶容器下方菜品卡片列表**继续正常向上滚动**，可上拉加载更多；TabBar 依旧固定在页面底部，位置不变；
   - 吸顶容器内部功能齐全：搜索胶囊 / 搜索按钮、标签点击筛选、标签横向拖动全部可用（**无筛选下拉**）。

**吸顶静止态（`scrollTop` ≥ 阈值，停留在吸顶状态）**：

1. 视口最顶端：**固定标题带**（「知行食记」，与微信胶囊同带）——**常驻显示**；
2. 标题带正下方：吸顶容器（搜索区 + 横向大类标签栏）固定不动，**其背后无任何 Banner 图层 / 图片背景**；
3. 吸顶容器下方：菜品列表区域，可继续上下滚动；
4. 页面最底部：TabBar 保持固定。

**向下滑动操作（`scrollTop` 逐步变小）**：

1. 滑动过程：菜品列表向下移动，`scrollTop` 不断减小；吸顶容器暂时保持在标题带下沿不动；
2. `scrollTop < 阈值`：退出吸顶态，切回初始态——
   - 搜索区与标签栏**解除锁定、回归正常流**，跟随页面内容同步向下滚动；
   - Banner **自固定标题带下方重新滚入**（含状态栏背后区域），标题带始终固定在其左上角；
   - 页面恢复完整自上而下结构：固定标题带（常驻）→ Banner → 搜索区 → 标签栏 → 菜品列表。

**边界行为（必须处理）**：

1. **快速猛滑**：吸顶切换由粘性定位在**渲染层原生完成**（触发条件 = 容器自然位置抵达标题带下沿），不经过逻辑层判断、**无额外过渡动画**；猛滑多快都跟手，不会出现「内容已到、容器还没到」；
2. **横向拖动标签栏 / Banner 轮播左右滑动**：仅内部横向滚动 / 切换图片，页面 `scrollTop` 不变，不改变吸顶 / 初始状态；
3. **点击标签切换分类**：仅重新请求并刷新菜品列表，**不重置页面滚动位置**，维持当前吸顶 / 初始状态不变；
4. **上拉加载更多菜品**：新增卡片追加在列表底部，页面滚动位置与吸顶状态均保持不变；
5. **Banner 数据未到手 / 加载失败**：占位图**高度仍按 16:10 计算**，不得因加载状态改变块高（否则吸顶阈值与切换点漂移）。

> ⛔ **页面级下拉刷新：本页不提供**（搜索页 / 系统通知 / 我的评价同）——下拉表现为普通滚动回弹。数据更新走「首屏拉取 + 进入页面（`onShow`）兜底 + 失败时『加载失败 · 点击重试』块」。如需「回到顶部」入口，须另立 change 单独拍板。

**一句话精简版**：屏幕左上角的「知行食记」是**固定标题带**（永久不动，与微信胶囊同一水平线，其他页面换成各自文案）；它下面是 Banner 整块大图（正常流、随页面滚出）→ 搜索区（左搜索胶囊 + 右「搜索」按钮）→ 大类标签栏 → 菜品网格。上滑满「Banner 高 − 标题带高」后，搜索区 + 标签栏锁定在**标题带下沿**形成吸顶容器（背后无图片），网格继续滚动；回滚不足一个阈值即取消吸顶，Banner 自标题带下方重新滚回。Banner 轮播左右滑动与标签栏横向拖动均不改变页面吸顶状态。

### 6. 硬性约束（回归检查清单）

1. 永远**双列**菜品网格，拒绝三列；
2. 食堂档口只用**浅灰纯文字**，禁用绿色 / 彩色标签块；
3. 上滑超过阈值（Banner 高 − 标题带高）后，**「搜索区 + 标签栏」必须同组常驻吸顶**、不能消失，且**锁定位置在固定标题带下沿**（不得压到标题带）；
4. 所有菜品卡片**完整显示**，禁止半截截断；
5. 底部导航只保留**首页、我的**；
6. UI 布局**不得遮挡**右上角微信胶囊原生控件；
7. 首页内容流**无引导 / 补录类组件**；
8. **顶部顺序固定为「Banner 整块大图（含状态栏背后）→ 搜索区 → 横向大类标签栏 → 双列网格」**，不得插入其它块、不得颠倒；
9. **固定标题带**（左上角、**常驻不随滚动移动**、与微信右上角胶囊同水平带 / 同高、互不遮挡）是顶部**唯一由端上渲染的文本**；文案按页配置（首页 = 「知行食记」），位置 / 高度 / 对齐 / 配色跨页一致；Banner 图上不出现任何端上文本（§1.0）；
10. **Banner 宽高比锁定 16:10**（`aspect-ratio: 16 / 10`，总高 = 屏宽 × 10/16 + 最小高度兜底），不得用自由高度或 16:9 / 4:3；
11. **Banner 是页面正常流首块**：滚出视口后不得在吸顶容器背后残留图片 / 不得做定格背景；**固定标题带是独立固定层，不因 Banner 滚出而消失、也不随 Banner 一起移动**；
12. **Banner 素材一律 16:10**，且加载中 / 失败时**块高不变**（恒定按 `BANNER_ASPECT` 定高，禁按图片真实比例自适应）；**空 / 失败占位沿用首页菜品卡图片占位的灰底样式**——`var(--bg-soft)` 灰底 + 居中**中性 `IconSvg name="empty"`**（`--text-tertiary`），**无文字说明、无白卡、无渐变**（图标键取中性 `empty` —— Banner 为运营位容器、语义 ≠ 菜品，依 `project_spec.md` §4.9 不得用 `dish` 冒充中性占位）；
13. **首页不得存在任何筛选入口**（无「筛选」按钮、无筛选面板、无食堂 / 价格筛选维度）；搜索页无食堂 / 价格筛选胶囊（见 §2.1）；
14. **搜索区必须保持「左搜索胶囊 + 右独立『搜索』按钮」两件结构**：胶囊与按钮同高、间距 `--spacing-sm`、同为 `--radius-pill`，按钮为填充档主色 + 白字；**不得合并为一颗输入框、不得等分为两块**（见 §1 / §1.2）；
15. **顶部各块间距以 §1.2 表格为唯一真源**（Banner→搜索区 `--spacing-lg`(16px)、搜索区→标签文字 ≈12px（行内偏置）、标签栏→网格 视觉 ≈16px、左右 gutter `--spacing-md`）——**不得用裸值近似**；**纵向间距不得在标签行内外各叠一层 padding**；
16. **顶部表面过渡按 §1.3 执行**：纱 = 与页面底**同源渐变切片**（禁纯色蒙版）、进度**只由 `scrollTop` 推导**（禁计时器 / CSS 时长动画）、**只柔化 Banner 不淡化标题**；**吸顶容器恒为同源切片、不参与纱、不做「透明 ↔ 不透明」切换**；
17. **吸顶容器的位移 SHALL 由原生粘性定位承担**（`position: sticky`，写在滚动容器内部的内容流 + `top` = 标题带下沿）；**SHALL NOT** 用「滚动回调 + `setData` 下发 `transform` / `top`」模拟位移——跨线程延迟会让容器比内容慢半拍，读作「位置是临时算出来的」并易闪现；
18. **字号 / 间距刻度**：① 卡片三段字号固定为「菜名 `--font-subtitle` 32rpx > 位置行 = 评分 `--font-body` 28rpx > 」（价格 `--font-h3` 36rpx）；② 任何正文级文本**不得低于 12px**（`--font-small` 24rpx 已是下限，窄屏场景须按 §3 用 `--font-body`）；③ 搜索区控件内距按 §1.2（图标↔文字 8px、按钮左右 16px）；④ 标签栏光学间距按 §2（上行距 ≈12px / 下行距 ≈16px，下划线紧随文字 4px、**不得吸底**）。

> **图片占位策略（本期所有图片先占位，禁止无限空转加载）**：① 菜品图——失败立即回退**灰底 + 菜品 icon** 空态（`var(--bg-soft)` + `IconSvg name="dish"`，**菜品图占位口径**唯一真源 = `pages/home/DishCard.vue`）；② Banner 轮播图——`GET /banners` 返回空 / 请求失败 / 单张加载失败 → **复用同一灰底 + 中性 `empty` 图标**（见 §1，**不写文字说明**），**占位块高仍按 16:10**；③ 列表请求失败 → 失败重试块（`RetryBlock`）。**预览排查**：若标签栏只剩「全部」或不出现 → 字典请求失败，依次检查：后端是否在线（`GET /dishes/meal-types` 应返回 6 项）、开发者工具是否勾选「不校验合法域名」、是否使用了最新构建产物（`dist/build/mp-weixin`）；若 Banner 恒为占位图 → 检查 `GET /banners` 是否返回非空数组、图片 URL 是否可达。
