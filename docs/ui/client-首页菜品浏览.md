# 首页菜品浏览 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-首页菜品浏览.md](../feature/client-首页菜品浏览.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 落点：`pages/home/index`（主包 · **TabBar 页**，经 `reLaunch` 切换，恒不显示返回箭头）。
> **效果图**：`docs/ui/client-首页菜品预览-精修稿.png`（按本方案重绘的页面设计稿；**本地预览、不入库**——`docs/*` 已在 `.gitignore`。仅供观感对照，**实现口径以本文档正文为准**）。

> **顶部结构（本文档为 UI 唯一真源）**：Banner = **页面最顶端一整块图片区（轮播容器，素材由后端 `GET /banners` 接口下发）**。**页面标题走「固定标题带」**（§1）：左上角、与微信右上角**原生胶囊处于同一水平带、同高对齐**，且**永久固定在页面左上角、不随页面滚动移动**（跨页统一位置、文案按页配置——首页为「知行食记」）。自上而下恒为「**固定标题带（常驻，叠在 Banner 上）** → Banner（正常流首块，含状态栏背后）→ 搜索区 → 横向大类标签栏 → 双列网格」。**Banner 滚出即消失（不折叠、不定格）；吸顶容器只由「搜索区 + 标签栏」组成、背后无图片，锁定位置在固定标题带下沿之下**。Banner 宽高比定为 **16:10**；顶部各块间距见 **§7**；**顶部两带的透明 / 不透明过渡采用「纱式淡出」（见 §11.2）**。
>
> **筛选维度口径**：**首页无任何筛选入口**（无「筛选」按钮、无筛选面板）；搜索页（find）无食堂 / 价格筛选胶囊（见 §5.2）。功能 / 接口口径见功能文档。
>
> **吸顶实现口径**：① 吸顶容器（搜索区 + 标签栏）写在**滚动容器内部的内容流里、用 `position: sticky` 吸顶**——位移完全由渲染层原生滚动驱动、不经逻辑层（见 §11 / §13 第 17 条）；② 容器表面**恒为「与页面底同源」的渐变切片**（切片基准 = 容器顶边在页面坐标中的位置），无「透明 ↔ 不透明」硬切（见 §11.1）；③ 标签栏纵向留白只由「标签行内偏置」与「容器下 padding」各承担一次（行外不叠加），得「搜索区 → 标签文字」≈ **12px**、「下划线 → 卡片首行」≈ **16px**。

## 0. 设计判断与目标

### 0.1 原页面主要问题（本版要修的 5 点）

| # | 问题 | 本版处置 |
|---|---|---|
| 1 | **顶部信息层偏平**——标题带 / Banner / 搜索 / 标签四块平铺，缺少主次节奏，读作「模块堆叠」 | §0.3 定义 4 档视觉强度：搜索区 = 高、Banner = 中高、网格 = 中、标签栏 = 低 |
| 2 | **搜索区与标签栏关系不够紧**——两者视觉边界模糊，用户不知「搜索完下一步该干嘛」 | 搜索区与标签栏**同属一个吸顶容器**、以「块内 12px / 块间 16px」的间距层级区分（§4 / §7） |
| 3 | **卡片信息密度偏高**——菜名 / 食堂 / 档口 / 评分 / 价格同现，字号层级不清则第一眼无落点 | §6 固定四段阅读顺序与字号刻度（菜名 32 > 位置 = 评分 28，价格 36 右对齐） |
| 4 | **暖橙主题容易做成廉价感**——橙面积失控、或星级 / 价格 / 按钮共用同一档橙 | §10 **主色语义分档**：按钮 = 填充档、价格 / 选中态 = 文字档、下划线 = 图形档、星 = 独立语义色（各司其职，禁止混用） |
| 5 | **缺少可开发的细节感**——胶囊高度、下划线位置、卡片内边距、字基线、阴影层级 | §7 间距 / §8 字体 / §9 圆角阴影 / §12 组件拆分全部 token 化 |

### 0.2 设计原则（保留 / 不新增 / 不改字段）

- **保留**：固定标题带、16:10 Banner、搜索胶囊 + 搜索按钮、大类标签栏、双列菜品卡、底部 TabBar；
- **不新增**：筛选入口、食堂列表、推荐模块、活动入口、底部安全区之外的功能；
- **不改变字段**：菜名 / 食堂 / 档口 / 评分 / 价格 / 分类 / Banner / 标签均沿用既有接口（见文末「接口数据字段」）；
- **本版目标只有 4 个**：① 顶部更清爽 ② 搜索更突出 ③ 卡片更有食欲与秩序 ④ 整套视觉像真实校园信息小程序，而非练习稿。

### 0.3 页面视觉节奏（4 档，不平均用力）

| 区域 | 角色 | 视觉强度 | 承担手法 |
|---|---|---|---|
| Banner | 氛围入口 | 中高 | 16:10 实拍大图（唯一「整块图」） |
| **搜索区** | **主要行动入口** | **高** | 白胶囊浮起 + **唯一填充色按钮**（全页唯一实心主色块） |
| 大类标签栏 | 分类导航 | 低 | 纯文字 + 短下划线，无底色、无边框 |
| 菜品网格 | 信息主体 | 中 | 白卡 + 极轻投影 + 大图占 52% |

> 用户进入首页的自然读序：**Banner → 搜索 → 分类 → 菜品列表**。

## 1. 固定标题带（跨页统一）

- **定位**：`position: fixed`——**永久固定在页面左上角**，不随页面滚动、不随 Banner 滚出、不参与任何吸顶位移。页面滚动到任意位置，它都在同一处；
- **垂直对齐**：与微信右上角**原生胶囊同一条水平线**——标题带高 = 状态栏高 + 与胶囊同高的一行（`--capsule-h`），标题垂直中心 = 胶囊中心（同一水平带，互不遮挡）；
- **水平起点**：页面级 gutter（`--spacing-md`，与搜索行、标签栏、卡片网格同轴）；右侧为胶囊避让区，标题**不得进入胶囊水平范围**（超长省略号截断）；
- **文案：跨页统一位置、按页配置**——首页 = 「知行食记」，搜索页 / 我的等其他页面各填自己的文案（本文件只定义首页文案）。**位置、高度、对齐方式、配色全站一致**，各页只换文案；
- **配色**：`--text-primary` **`#2D1F14`** 粗体大号（`--font-title` 44rpx / `--weight-bold`）；**不做白字、不描边、不加遮罩层**——初始态它叠在 Banner 图上，**素材标题带区域必须是浅色暖底**（§3），深浅对比由素材保证；
- **交互**：纯文本，**无点击行为**（不做返回 / 菜单入口）；
- **层叠**：`z-index` 高于 Banner 与吸顶容器——**任何滚动位置都保证标题可读**（Banner 从其下方滑过、被它遮住属预期）；
- **吸顶态**：**标题带仍常驻显示**；吸顶容器（搜索区 + 标签栏）锁定在**标题带下沿之下**，两者不重叠、不叠图；
- **表面（透明 ↔ 不透明）**：初始态**完全透明**（Banner 从状态栏到标题带整块透出）；随滚动由**与页面底同源的渐变切片**（“纱”）渐显 → 挡住滚上来的网格。完整口径（区间、常量、理由）见 **§11.2**；**纱只柔化 Banner，绝不淡化标题**。

## 2. 页面结构（自上而下）

1. **顶部通栏 Banner**（页面最上方一整块大图 = 顶部 Header 的背景，详见 §3）；
2. **搜索区**（位于 Banner 之下，**属吸顶容器上半部**，详见 §4）；
3. **横向大类标签栏**（位于搜索区正下方，详见 §5）；
4. **双列菜品卡片网格**（四段排版见 §6）；
5. **底部 TabBar**：仅「首页（橙色激活）/ 我的（灰色）」，常驻底部不随滚动，预留手势条安全区。

> 自上而下顺序**恒定**，不得颠倒、不得插入其它块（§13 第 8 条）。

## 3. Banner 区

### 3.1 定位与结构

- 从屏幕**物理顶端 y=0** 起算、**含状态栏背后**，左右**无间隙通栏**，把屏幕上部一整块区域全部占满；
- **固定标题带叠在 Banner 之上**（§1）：Banner 顶部「状态栏 + 标题带」两带区域即该标题的**背景**；标题**固定不动**——Banner 滚动时从标题带下方滑过（顶部被标题带遮住属预期）；
- **那个位置就是一张图，无任何文案层**（端上不渲染「今日推荐」等硬编码文本；素材里的「今日推荐 / 副标题 / 菜品插画」均为**图片素材自身内容**，由设计出图，端上零文本）；
- **Banner 上无点击交互**（v1 纯展示、无跳转；出参无 `targetType` / `targetId` / `targetUrl`；要做跳转须先在本文件定义交互并另立 change）。

### 3.2 素材方向（设计约定）

| 项 | 约定 |
|---|---|
| 主体 | 热气腾腾的牛肉面 / 奶茶 / 家常菜等**真实校园食堂感食物摄影** |
| 氛围 | 暖橙光线、干净桌面、轻微景深 |
| 构图 | 食物主体偏中下部，**顶部留出干净暖底区域**（供标题带压字） |
| 质感 | 真实摄影感，**不做插画式营销海报**（本产品是校园美食**信息**工具，不是外卖平台） |
| 比例 | **一律 16:10**（如 1500×938 / 1200×750）；混比例会导致切换时撑高 / 压扁 Banner |
| 标题带区域 | **一律保持浅色暖底**；若某张图该区域为深色底，须在**素材上**叠浅色蒙版，端上不加蒙版层 |

### 3.3 宽高比为什么取 16:10（而非 16:9）

- **顶部标题带是「不可压缩的固定开销」**：Banner 顶部「状态栏 + 与胶囊同高的标题带」≈ **88px** 会被**固定标题带覆盖并承载标题**（§1）。比例越扁，这两带在 Banner 内占比越高：
  - 16:9（375 宽 → ≈211px 高）：标题带占比 **≈42%**，留给运营内容的净高仅 **≈123px**，素材构图稍高就会顶到搜索框、被 `aspectFill` 裁掉；
  - **16:10（375 宽 → ≈234px 高）：标题带占比 ≈38%**，运营内容净高 **≈146px**，构图舒展、主文案不必贴边；
- **首屏菜品曝光仍达标**：16:10 下 Banner 234px + 吸顶块 ≈116px ≈ **350px**，在 812px 高机型上首屏仍能露出**第一行双列菜品卡**；若取 4:3（281px），首屏只剩 Banner 与搜索区、第一行卡片完全不可见，与「信息展示优先」的定位相悖。

### 3.4 轮播容器（接口下发）

- 整块 Banner 即一个 `<swiper>` 图片轮播，每一项是一个 `<image mode="aspectFill">` 铺满；**图片清单来自后端 `GET /banners`**（服务端已按 `sort_order` 升序、只返回启用项），端上**严格按返回顺序渲染、不排序、不写死任何 URL**；
  - **多张**：自动轮播（间隔 `BANNER_AUTOPLAY_INTERVAL = 4000ms`）、循环、底部居中指示点；手动左右滑动可切换；
  - **仅一张**：不自动轮播、**不显示指示点**（避免「只有一个点」的假轮播）；
  - **空数组 / 请求失败**：整块退化为**与首页菜品卡图片占位同款灰底的空态**——`var(--bg-soft)` 灰底 + 居中**中性 `empty` 图标**（`IconSvg name="empty"`，色 `--text-tertiary`，尺寸按 Banner 整块等比放大，建议 120）；**图标键取中性 `empty`、不得用 `dish`**（Banner 是运营位轮播，容器语义 ≠ 菜品，依 `project_spec.md` §4.9）；**不渲染「Banner 占位图」等任何文字说明、不加白卡 / 投影 / 渐变**；Banner 请求与菜品列表**并行发起**，Banner 失败**不阻塞**首屏网格；
  - **单张图加载失败**：**该张**显示同一套灰底 + 中性 `empty` 空态（无须整块回退，可随重试恢复），其余张不受影响、轮播继续。
- **块高恒定**：总高 = `max(屏宽 × 10/16, 标题带高 + 运营内容最小可视高 ≈120px)`（`BANNER_ASPECT_RATIO` / `BANNER_MIN_CONTENT_PX` 为页面常量）；加载中 / 失败一律用**同高**占位，**不因加载状态改变块高**（否则吸顶阈值与切换点漂移）。

## 4. 搜索区

> 本区是首页的**第二视觉中心**，也是全页**唯一的行动号召**（唯一实心主色块）。

### 4.1 结构（恒为两件，不得合并）

| 项 | 设计值 |
|---|---|
| 结构 | 左侧搜索胶囊 + 右侧独立「搜索」按钮，**同高、同一行、间距 `--spacing-sm`** |
| 搜索胶囊 | 白底 `--bg-card` + `--radius-pill` + `--shadow-float`（轻阴影）；左放大镜图标 `--text-tertiary` |
| 胶囊占位文案 | 「**搜索菜品、食堂、档口**」（`--text-placeholder` `#B5A594`） |
| 搜索按钮 | 填充档主色 `--color-primary-fill` **`#B4531A`** + 白字 `--color-on-primary`，`--radius-pill`，**按文字定宽、不与胶囊等分** |
| 高度 | 两者均 = `--capsule-h`（与微信原生胶囊同高） |
| 触达 | 胶囊与按钮的可点区域均 ≥ 88rpx 高（`::after` 透明扩张，不改变视觉尺寸） |

### 4.2 关键设计调整（三条）

1. **胶囊宽度更大**——`flex: 1` 占满剩余宽度，明显承担「主要搜索入口」，不做窄小输入框；
2. **按钮保持独立胶囊形**——不做矩形、不与输入框贴死；「左胶囊 + 右胶囊」并列结构（§13 第 14 条）；
3. **搜索区与标签栏之间加视觉切分**——两者同属吸顶容器，靠**间距层级**（块内 12px / 块间 16px，§7）与标签栏的无底色纯文字形态区分，**不加分隔线、不加容器底色**。

### 4.3 占位文案口径（两页同源）

占位**只列真实可搜的维度**。搜索走 `GET /dishes?keyword`，服务端**只匹配「菜名 / 档口名 / 食堂名」三处**；**「套餐」不是可搜维度**——项目无套餐实体，「套餐盖饭」只是 `meal_type` 大类，而**大类不参与关键词匹配**，故**不得**写入占位文案。该文案由 **`components/SearchBar.vue` 的默认 `placeholder` 单点承载**，首页与搜索页共用，**改动须两页同批**。

### 4.4 取色说明（按钮填充底为何取「深橙」）

设计稿明确按钮为**深橙**填充 + 白字；本页取**填充档 `#B4531A`**——与实测对比度互相印证，**无偏差**：

| 组合 | 实测 | 门槛 | 判定 |
|---|---|---|---|
| 白字 on `#B4531A`（本版采用） | **5.01:1** | 4.5:1 | ✅ |
| 白字 on `#E67E22`（亮橙，**不采用**） | **2.85:1** | 4.5:1 | ❌ 不可作填充底 |

→ 「行动 = 橙」由**唯一实心主色块**（全页仅此一处实心填充）承担；亮橙 `#E67E22` 保留给**关键图标**（图形档，不承载文字）。详见 §10.2「取色边界」。

## 5. 大类标签栏

### 5.1 规格

| 项 | 设计值 |
|---|---|
| 标签集合（7 项） | `全部` ｜ `套餐盖饭` ｜ `家常小炒` ｜ `面食粉类` ｜ `香锅干锅` ｜ `风味小吃` ｜ `汤饮甜品` |
| 数据来源 | `GET /dishes/meal-types` 下发（`[{ value, label, order }]`）：文案、顺序、子集、增删**全由后端决定，端上一个不写死**；首项「全部」= 不传 `mealType`，端上固定渲染 |
| 空类自动隐藏 | 后端只下发当前有在售菜品的大类（某类空了隐藏、有菜自动出现），端上零改动 |
| 标签样式 | **纯文字导航**——无胶囊底色、无边框、无背景块 |
| 未选中 | 字色 `--text-body` **`#4A3520`**、`--weight-regular` |
| 选中 | 字色 `--text-title` **`#2D1F14`**、`--weight-semibold` |
| 选中下划线 | `--color-primary-amber` **`#F5A623`**，高 6rpx、全圆角、**长度贴合文字宽度**（`width: 100%`）、紧随文字 4rpx（`--spacing-xs`） |
| 交互 | 横向可滑动 + **单选**；点击切换 → 列表刷新；点击已选中项不发请求；v1 不显示计数 |
| 背景 | 无自身底色（与吸顶容器表面同源，见 §11.1） |

### 5.2 光学间距（唯一来源）

- 标签行高 **88rpx（触达下限，不得压低）**；标签文字在行内**上偏置 24rpx**（`padding-top`），下划线紧随文字 **4px**（`--spacing-xs`）。行内偏置是「搜索区 → 标签文字」间距的**唯一来源**（≈ **12px**）；「下划线 → 卡片首行」= 容器下 padding（`--spacing-sm` 8px）+ 行底余量（≈8px）≈ **16px**。两者满足「下行距 ≥ 上行距」，且**不与标签行外 padding 叠加**。**下划线不得吸到行底**——那会让它离文字 ≈16px、与标签脱开。标签栏行高不变 → §11 的 `H_s` 不受影响。

### 5.3 设计判断

首页**没有筛选面板**，标签栏是唯一的分类导航，故取**轻**形态（纯文字 + 短下划线）：胶囊按钮式标签会让它显得「在频繁切换功能」，与信息导航的语义不符。横向可滑动的首 / 末项文字缘 = 页面级 gutter `--spacing-md`（与搜索行、网格同轴）。

### 5.4 筛选维度口径（首页与搜索页均无筛选）

- **首页**：**无任何筛选入口**（无「筛选」按钮、无筛选面板），**唯一筛选维度是大类标签栏**（§5.1）；
- **搜索页（find）**：头部为「输入框 + 结果」，**无食堂 / 价格筛选胶囊**；
- **保留项**：搜索关键词**同时匹配菜名 / 档口名 / 食堂名**；卡片上的 `食堂名 | 档口名` 展示不变；
- **接口侧**（详见功能文档）：`GET /dishes` 参数集恰为 `page` / `pageSize` / `keyword` / `mealType`；
- **防回退**：首页不得出现筛选入口，搜索页不得出现食堂 / 价格筛选胶囊（§13 第 13 条）。

## 6. 菜品卡片（四段固定排版）

### 6.1 阅读顺序与视觉权重

**菜品图 → 菜名 → 食堂/档口 → 评分/价格**

| 层级 | 元素 | 处理方式 |
|---|---|---|
| 第一 | 菜品图 | 大图、真实摄影，占卡片 ≈**52%** 高 |
| 第二 | 菜名 | 卡片内最大字号、粗体、`--text-title` |

### 6.2 四段规格（自上而下）

| 段 | 内容 | 样式 |
|---|---|---|
| 1 | 菜品实拍图 | 圆角与卡片一致；比例 **3:2**（≈卡片高 52–55%，介于 4:3 与 16:10 之间，兼顾信息密度与 CLS=0）；无图 / 加载失败 → **灰底（`var(--bg-soft)`）+ 居中菜品 icon（`IconSvg name="dish"`，`--text-tertiary`）** 空态（**菜品图语义 → `dish` 键合法**；Banner 失败占位复用同款**灰底**、但图标取中性 `empty`，见 §3.4） |
| 2 | 菜品名称 | `--font-subtitle`（**32rpx / 16px**）**粗体**、`--text-title` `#2D1F14`，本卡片最大字号（超 2 行省略）；**不压在图片上** |

### 6.3 容器与按压

- 卡片表面 = `--bg-card` 白底 + `--radius-card`（32rpx）+ `--shadow-card`（**极轻**，`0 2px 12px rgba(0,0,0,.04)`）；`overflow: hidden`（图片裁进圆角）；

- **不引入「月售 XXX 份」**（无订单 / 销量数据源）；列表末尾**无引导 / 补录类组件**。

## 7. 间距系统（唯一真源）

> 全部用 token 表达，**禁止裸值近似**。左右外边距恒为页面级 gutter `--spacing-md`（与标签栏首项文字缘、双列网格同轴）。

### 7.1 顶部各块

| 相邻关系 | 间距 | token |
|---|---|---|
| Banner 上缘 → 屏幕顶端 | **0** | Banner 自 `y=0` 起（含状态栏背后） |
| **Banner 下缘 → 搜索区上沿** | **16px** | `--spacing-lg`（吸顶容器 `padding-top`） |
| **搜索胶囊 ↔ 右侧「搜索」按钮** | 8px | `--spacing-sm` |
| 搜索胶囊 / 按钮的左右外侧 → 屏幕左右缘 | 12px | `--spacing-md` |
| **搜索区下沿 → 标签文字** | **≈12px** | 标签行 `padding-top` 24rpx（行内偏置，**唯一来源**） |
| **标签栏下沿 → 网格首行上沿** | **≈16px** | 容器 `padding-bottom` `--spacing-sm`(8px) + 标签行自身 ≈8px 行底余量 |
| 网格左右外边距 | 12px | `--spacing-md` |
| **卡片间距（行 / 列）** | **12px** | `--spacing-md` |
| 吸顶容器锁定位置 | `top = 状态栏高 + 标题带行高` | 见 §11 |

> **间距层级规则**：**块之间 > 块内部**，且**块之间 > 卡片间距** —— 块间 = 16px（`--spacing-lg`）、块内 = 8px（`--spacing-sm`）、卡片间距 = 12px（`--spacing-md`）。
>
> **标签栏纵向留白规则**：**行内偏置 / 行底余量与行外 padding 不叠加** —— 标签行自身高 88rpx（触达下限，不可压低）内含 24rpx 行内上偏置 + ≈16rpx 行底余量；**行外上间距 = 0、行外下间距 = `--spacing-sm`(8px)**，由行内偏置与行底余量补足 → 实测 **12px / ≈16px**。

### 7.2 卡片内间距

| 位置 | 间距 | token |
|---|---|---|
| 图片底 → 菜名 | **8px** | 信息区 `padding-top` `--spacing-sm` |
| 菜名 → 食堂 / 档口 | **4px** | `--spacing-xs` |
| 食堂 / 档口 → 评分 / 价格 | **8px** | `--spacing-sm` |
| 卡片左右内边距 | **12px** | `--spacing-md` |
| 卡片底部内边距 | **12px** | `--spacing-md` |

> **卡片内部不平均留白**：图片区最大 → 文字区紧凑 → 底部留出舒适安全区。

### 7.3 触达尺寸

| 可点件 | 视觉尺寸 | 命中区 |
|---|---|---|
| 搜索胶囊 / 「搜索」按钮 | 高 = `--capsule-h` | `::after` 上下各扩 16rpx → ≥88rpx |
| 大类标签 | 高 88rpx（含行内偏置） | 即本体（宽 = 文字 + 左右各 24rpx；最短「全部」≈52px ≥ 44px） |
| 菜品卡片 | 整卡 | 即本体（`role="button"`） |

## 11. 吸顶容器与滚动交互（初始静止态 ↔ 吸顶静止态）

**结构前提**：顶部恒有**三层**——① **固定标题带**（`position: fixed`，永久固定左上角、**不随滚动移动**，§1）；② **Banner**（页面正常流第一块，含状态栏背后，**不参与吸顶、不折叠、不做定格背景**，滚动即滚出）；③ **吸顶容器 = 搜索区 + 横向大类标签栏**（其背后无任何图片）。内容流顺序：Banner → 搜索区 → 标签栏 → 双列网格。

**触发规则**：仅页面**垂直上下滑动**触发吸顶状态切换；在标签栏内部横向拖动、在 Banner 轮播内左右滑动切换图片，**均不修改页面 `scrollTop`、不触发吸顶状态变更**。两态：【初始静止态（未吸顶）】、【吸顶静止态（已吸顶）】。**固定标题带在两态下都常驻显示，不参与状态切换。**

**滚动阈值 = Banner 总高 − 标题带高**：即 Banner 下边缘刚好抵达**固定标题带下沿**（= 吸顶容器锁定位置）时的滚动距离。两值均由页面常量推导（§11.2 常量表），**非硬编码**。

### 11.1 容器表面：恒为「与页面底同源」的渐变切片

> **为什么不需要过渡**：容器在正常流中**永远紧贴 Banner 下缘、从不与 Banner 重叠**，因此没有「必须真透明」的约束。把它的表面直接做成**与页面底同源的渐变切片**，并让切片基准 = **容器顶边在页面坐标中的位置**（未吸顶随滚动连续变化、吸顶后夹紧为标题带下沿），表面便**在任何滚动位置都与身后页底逐像素一致**——既等价于「永远透明」，又天然不透出滚上来的网格。**没有「透明 ↔ 不透明」硬切，就没有切换瞬间的穿帮**。

**硬性要求**：

1. 容器表面 SHALL = 与页面底**同源**的渐变切片（`--home-page-grad` + `background-size: 100% 720rpx` + `background-position-y: −(容器顶边页面坐标)`）；**禁止纯灰 / 纯白 / 黑色蒙版**，也**禁止做「透明 ↔ 不透明」切换**；
2. 容器**背后无任何图片**（Banner 是正常流首块，滚出即消失、不定格为背景）；
3. 容器**锁定位置 = 固定标题带下沿**（`top = 状态栏高 + 标题带行高`），**不得压到标题带**。

### 11.2 顶部表面过渡：纱式淡出（仅标题带）

> **为什么需要**：标题带初始态必须真透明（透出 Banner）、纱到位后必须不透明，否则滚上来的网格会透到「知行食记」后面。**硬切会产生可见的「刷一下变色」**，故用纱式淡出。
>
> **口径**：**标题带的表面为与页面底同源的渐变切片**（“纱”）随 `scrollTop` **由 0 → 1 渐显**，**不做硬切**——Banner 尾部平滑「融入页面底色」；**吸顶容器不参与纱**（其表面恒为同源切片，见 §11.1）。

**常量（全部由页面常量推导，禁硬编码裸值）**

| 常量 | 定义 | 375 宽 iPhone X 类机型 |
|---|---|---|
| `H_t` 标题带高 | 状态栏高 + `navBarHeight`（`(胶囊.top − 状态栏高) × 2 + 胶囊高`） | ≈ **88px** |
| `H_b` Banner 总高 | `max(屏宽 × 10/16, H_t + 120px)` ⚠️ **兜底项不得再加状态栏高** | ≈ **234px** |
| `H_s` 吸顶容器高 | 上 padding 16 + 搜索行 32 + 标签行 44 + 下 padding 8 | ≈ **100px** |
| `L` 锁定点 | `H_b − H_t` | ≈ **146px** |
| `VEIL_PX` 纱窗长度 | **60px**（可调区间 48–72） | 纱区间 = `[H_b − 60, H_b]` ≈ **[174, 234]** |

**时序表（上滑；数字随屏宽 / 机型由上述常量推导）**

| `scrollTop` | 标题带（纱） | Banner | 吸顶容器 | 网格 |
|---|---|---|---|---|
| `0` | 完全透明 | 完整铺满 `0..234`（含状态栏背后） | 坐在 Banner 下缘（顶边 = 234）；表面 = 同源切片，基准 = 234 | 在容器下沿起排 |
| `0 → 146` | 完全透明（Banner 从带下划过） | 随滚动 1:1 上移、顶部被标题带遮住 | **原生粘性定位**：1:1 随滚动上移、恒贴 Banner 下缘（间隙恒 = `--spacing-lg`）；切片基准连续跟随 → 表面与身后页底**始终**逐像素一致 | 静止 |
| `146`（`L`） | 透明 | Banner 下缘 = 标题带下沿 | **粘住**在标题带下沿（`top` 触发，非 JS 位移）；切片基准夹紧为标题带下沿 | 首行**恰好贴到**容器下沿（重叠 0） |
| `146 → 174` | 透明 | 仅剩标题带后面那段在缩 | 固定不动 | 从容器背后上移、被**干净裁切** |
| `174 → 234` | **纱 opacity 0 → 1 线性渐显** | 尾部被同色纱**柔化**、同时继续缩短 | 固定不动 | 同上 |
| `234`（`H_b`） | 纱 = **1**（表面完全成形） | **完全滚出**屏幕 | 固定不动 | 同上 |
| `234 → 246`（`H_b + H_s − H_t`） | 纱 = 1 | 无 | 固定不动 | 仍在容器背后（**零内容窗口** ≈12px） |
| `≥246` | 纱 = 1 | 无 | 固定不动 | 首行抵达标题带下沿 → 进入带背后、被**裁切** |

**为什么这样最丝滑（三条硬理由）**

1. **没有「切换」这个动作**：容器表面恒为同源切片、基准随位置连续对齐，不存在「透明 → 不透明」的时刻；纱的完成点在 `H_b`（带内已无图像像素），而网格要到 ≈246 才抵达标题带下沿（窗口 ≈12px，仍为正值 → 不会「内容已到、纱还没到」）；
2. **表面与页面底同源**：纱 = `--home-page-grad`（同一变量 + 同一段停点 + 同一坐标基准），因此它不是「蒙一层灰」，而是「**融入页面底色**」——纱到位时与页面底逐像素一致，切换无可被察觉的色差；
3. **进度只由 `scrollTop` 推导**（不用计时器 / CSS 时长动画）：无论多猛的滑动，纱的进度与滚动位置**严格同步**；反向滚动自动对称——纱按 `scrollTop` 反算，Banner 重新滚入时尾部由「已柔化」逐步回到「完整显示」。

**硬性要求**：

1. 纱必须 = **与页面底同源的渐变切片**；**禁止纯灰 / 纯白 / 黑色蒙版**；
2. **纱只柔化 Banner，绝不淡化标题**：纱层与标题分属两层，标题恒在纱之上、字色与不透明度恒定；
3. 纱进度**只能由 `scrollTop` 推导**；**禁止** `setTimeout`、CSS `transition` / `animation` 驱动；
4. **吸顶容器的位移 SHALL 由原生粘性定位承担**（`position: sticky` + `top` = 标题带下沿，写在滚动容器内部的内容流里），**SHALL NOT** 用「滚动回调 + `setData` 下发 `transform` / `top`」模拟位移；
5. **吸顶容器 SHALL NOT 做「透明 ↔ 不透明」切换**（也不参与纱式淡出）；
6. **纱区间常量必须满足 `VEIL_PX ≤ H_t`**（当前 `60 ≤ 88` ✅）——否则 Banner 残段会有一截落在标题带下缘之外**不被纱覆盖**，出现「半柔化」的硬接缝。

### 11.3 两态组件清单

**初始静止态（`scrollTop` ≤ 阈值）**：

1. **固定标题带**：「知行食记」固定在页面左上角，与微信胶囊同一水平带；
2. 屏幕自 `y=0` 起：Banner 整块大图铺满（**含状态栏背后**，故标题带叠在其上）；块内为图片轮播（多张自动播放 + 底部指示点）；
3. Banner 下方（间距 `--spacing-lg`）：搜索区 = **左侧搜索胶囊 + 右侧独立「搜索」按钮**——**属吸顶容器**，本态下仍在正常流中、随页面滚动；
4. 搜索区下方：横向大类标签栏（横向排列、可左右滑动）——**同属吸顶容器**；
5. 标签栏下方（视觉 ≈16px）：双列菜品卡片网格；
6. 页面最底部：TabBar 永久固定。

**吸顶静止态（`scrollTop` ≥ 阈值）**：

1. 视口最顶端：**固定标题带**（常驻显示）；
2. 标题带正下方：吸顶容器（搜索区 + 标签栏）固定不动，**其背后无任何 Banner 图层 / 图片背景**；
3. 吸顶容器下方：菜品列表区域，可继续上下滚动（可上拉加载更多）；
4. 页面最底部：TabBar 保持固定；
5. 容器内部功能齐全：搜索胶囊 / 搜索按钮、标签点击筛选、标签横向拖动全部可用（**无筛选下拉**）。

**向下滑动操作**：`scrollTop` 不断减小，容器暂时保持在标题带下沿不动；`scrollTop < 阈值` 时退出吸顶态——搜索区与标签栏**解除锁定、回归正常流**，Banner **自固定标题带下方重新滚入**，页面恢复完整结构。

**边界行为（必须处理）**：

1. **快速猛滑**：吸顶切换由粘性定位在**渲染层原生完成**，不经过逻辑层判断、**无额外过渡动画**；
2. **横向拖动标签栏 / Banner 轮播左右滑动**：页面 `scrollTop` 不变，不改变吸顶 / 初始状态；
3. **点击标签切换分类**：仅重新请求并刷新列表，**不重置页面滚动位置**；
4. **上拉加载更多菜品**：新增卡片追加在列表底部，滚动位置与吸顶状态均不变；
5. **Banner 数据未到手 / 加载失败**：占位**高度仍按 16:10 计算**，不得因加载状态改变块高。

> ⛔ **页面级下拉刷新：本页不提供**（搜索页 / 系统通知 / 我的主页同）——下拉表现为普通滚动回弹。数据更新走「首屏拉取 + 进入页面（`onShow`）兜底 + 失败时『加载失败 · 点击重试』块」。如需「回到顶部」入口，须另立 change 单独拍板。

**一句话精简版**：屏幕左上角的「知行食记」是**固定标题带**（永久不动，与微信胶囊同一水平线）；它下面是 Banner 整块大图（正常流、随页面滚出）→ 搜索区（左搜索胶囊 + 右「搜索」按钮）→ 大类标签栏 → 菜品网格。上滑满「Banner 高 − 标题带高」后，搜索区 + 标签栏锁定在**标题带下沿**形成吸顶容器（背后无图片），网格继续滚动；回滚不足一个阈值即取消吸顶，Banner 自标题带下方重新滚回。

## 13. 硬性约束（回归检查清单）

1. 永远**双列**菜品网格，拒绝三列；
2. 食堂档口只用**浅灰纯文字**，禁用绿色 / 彩色标签块；
3. 上滑超过阈值（Banner 高 − 标题带高）后，**「搜索区 + 标签栏」必须同组常驻吸顶**、不能消失，且**锁定位置在固定标题带下沿**（不得压到标题带）；
4. 所有菜品卡片**完整显示**，禁止半截截断；
5. 底部导航只保留**首页、我的**；
6. UI 布局**不得遮挡**右上角微信胶囊原生控件；
7. 首页内容流**无引导 / 补录类组件**；
8. **顶部顺序固定为「Banner 整块大图（含状态栏背后）→ 搜索区 → 横向大类标签栏 → 双列网格」**，不得插入其它块、不得颠倒；
9. **固定标题带**（左上角、**常驻不随滚动移动**、与微信右上角胶囊同水平带 / 同高、互不遮挡）是顶部**唯一由端上渲染的文本**；文案按页配置（首页 = 「知行食记」），位置 / 高度 / 对齐 / 配色跨页一致；Banner 图上不出现任何端上文本；
10. **Banner 宽高比锁定 16:10**（总高 = 屏宽 × 10/16 + 最小高度兜底），不得用自由高度或 16:9 / 4:3；
11. **Banner 是页面正常流首块**：滚出视口后不得在吸顶容器背后残留图片 / 不得做定格背景；**固定标题带是独立固定层**，不因 Banner 滚出而消失、也不随 Banner 一起移动；
12. **Banner 素材一律 16:10**，且加载中 / 失败时**块高不变**；**空 / 失败占位沿用首页菜品卡图片占位的灰底样式**——`var(--bg-soft)` 灰底 + 居中**中性 `IconSvg name="empty"`**（`--text-tertiary`），**无文字说明、无白卡、无渐变**（图标键取中性 `empty`，依 `project_spec.md` §4.9 不得用 `dish` 冒充中性占位）；
13. **首页不得存在任何筛选入口**（无「筛选」按钮、无筛选面板、无食堂 / 价格筛选维度）；搜索页无食堂 / 价格筛选胶囊；
14. **搜索区必须保持「左搜索胶囊 + 右独立『搜索』按钮」两件结构**：胶囊与按钮同高、间距 `--spacing-sm`、同为 `--radius-pill`，按钮为**填充档**主色 + 白字；**不得合并为一颗输入框、不得等分为两块**；
15. **顶部各块间距以 §7 为唯一真源**（Banner→搜索区 16px、搜索区→标签文字 ≈12px（行内偏置）、标签栏→网格 视觉 ≈16px、左右 gutter 12px、卡片间距 12px）——**不得用裸值近似**；**纵向间距不得在标签行内外各叠一层 padding**；
16. **顶部表面过渡按 §11 执行**：纱 = 与页面底**同源渐变切片**（禁纯色蒙版）、进度**只由 `scrollTop` 推导**（禁计时器 / CSS 时长动画）、**只柔化 Banner 不淡化标题**；**吸顶容器恒为同源切片、不参与纱、不做「透明 ↔ 不透明」切换**；
17. **吸顶容器的位移 SHALL 由原生粘性定位承担**（`position: sticky`，写在滚动容器内部的内容流 + `top` = 标题带下沿）；**SHALL NOT** 用「滚动回调 + `setData` 下发 `transform` / `top`」模拟位移——跨线程延迟会让容器比内容慢半拍，读作「位置是临时算出来的」并易闪现；
18. **字号 / 间距刻度**：① 卡片字号固定为「菜名 32rpx > 位置行 = 评分 28rpx（价格 36rpx）」；② 任何正文级文本**不得低于 12px**；③ 搜索区控件内距按 §4（图标↔文字 8px、按钮左右 16px）；④ 标签栏光学间距按 §5.2（上行距 ≈12px / 下行距 ≈16px，下划线紧随文字 4px、**不得吸底**）；
19. **色彩必须语义分档**（§10.1 三条硬规则）：价格不得用 `#E67E22`、星不得用 `#F5A623`、「搜索」按钮填充底不得用 `#E67E22`（白字对比度不足）。

> **图片占位策略（本期所有图片先占位，禁止无限空转加载）**：① 菜品图——失败立即回退**灰底 + 菜品 icon** 空态（`var(--bg-soft)` + `IconSvg name="dish"`，唯一真源 = `pages/home/DishCard.vue`）；② Banner 轮播图——`GET /banners` 返回空 / 请求失败 / 单张加载失败 → **复用同一灰底 + 中性 `empty` 图标**（不写文字说明），**占位块高仍按 16:10**；③ 列表请求失败 → 失败重试块（`RetryBlock`）。**预览排查**：若标签栏只剩「全部」或不出现 → 字典请求失败，依次检查：后端是否在线（`GET /dishes/meal-types` 应返回 6 项）、开发者工具是否勾选「不校验合法域名」、是否使用了最新构建产物（`dist/build/mp-weixin`）；若 Banner 恒为占位图 → 检查 `GET /banners` 是否返回非空数组、图片 URL 是否可达。

## 14. 不建议做的设计（防回退）

1. **不做彩色标签块**——标签栏保持纯文字 + 短下划线；
2. **不做多种橙色混用**——按钮 / 价格 / 星级 / 下划线各司其职（§10.1）；
3. **不做强阴影卡片**——校园工具要轻，不做电商促销卡；
4. **不做满屏渐变**——渐变只用于顶部纱层与吸顶容器表面；
5. **不把菜名压在图片上**——图片就是图片，文字就是文字。
