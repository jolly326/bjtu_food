# 删除本人评价 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-删除本人评价.md](../feature/client-删除本人评价.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 落点：**无独立页面** —— 两处页内入口：① 菜品详情页评价卡三点菜单「删除评价」；② 我的评价列表行尾「删除」。均经**二次确认**后执行。


两个入口：
1. 「我的评价」列表（`pages/my-reviews/index`）行内「删除」。
2. 菜品详情页中**自己的**评价卡上的删除入口。

删除前有**二次确认**弹窗（不可恢复，故必须确认）。
