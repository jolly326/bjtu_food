# 隐私政策 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 归属功能文档：[client-隐私政策与用户协议.md](../feature/client-隐私政策与用户协议.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。


- 入口：「我的」页「其他」分组列表第 2 行「隐私政策」。
- 页面：`pages/privacy/index`，承载《隐私政策》单份文本。
- 纯展示：无表单、无按钮交互（仅纵向滚动）。
- 文本覆盖：采集的信息类型、采集目的、存储与保护方式、用户对本人评价的删除权利、注销账号自助入口、联系方式。

## 接口数据字段（UI 精修用）

**页面**：`pages/privacy/index`

**出参消费**：无（纯静态文案，随包发布）
**入参提交**：无

**UI 组件**：公共 `AppHeader`（标题「隐私政策」）
**控件类型**：`scroll-view`(scroll-y)、卡片承载（标题 + 生效日期 + 分节标题 / 正文）
