# 反馈处理 — 页面 UI 设计稿

> 所属端：管理端（Web 后台） ｜ 归属功能文档：[web-反馈处理.md](../feature/web-反馈处理.md)
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 落点：`/dashboard/feedback`（`FeedbackView`）；导航名为「**反馈**」。

- 导航「反馈」→ `/dashboard/feedback`（导航项带**待处理徽标**）；支持 `?fid=<id>` 深链直达单条（列表落地后按 id 定位并自动打开处理抽屉；不在当前页时按摘要关键词服务端检索）。
- 筛选：状态（**默认待处理** / 已处理 / 全部状态）+ 类型（**问题反馈**置顶；存量历史类型保留筛选项）+ 关键词（300ms 防抖、服务端模糊匹配）。
- 表格列：类型（类型标 pill；存量历史类型未登记值回落原值展示）/ 关联对象（存量举报 = 「评价 #id →」去评价管理深链 `?rid=`；其他 = —）/ 内容（超长截断 + 配图数角标）/ 提交人（昵称或「游客」）/ 提交时间（可排序）/ 状态（`StatusTag`）。
- 处理抽屉（`FormDialog`）：
  - 元信息块（类型标 / 提交人 / 提交时间 / 关联对象）+ 内容 + 配图（点击放大）+ 处理结论单选（已处理 / 不采纳 / 退回）+ 处理说明 / 回复（**必填**，1~1000 字，学生将收到）+ 不采纳原因（选不采纳时必填 1~200 字）；提交前二次确认（匿名提交不承诺站内回执）。
  - 已处理：只读回看（处理时间 / 历史回复 / 不采纳原因回显）+「关闭」。
