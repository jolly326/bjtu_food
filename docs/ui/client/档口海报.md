# 档口海报

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔑 需登录
> 返回：[UI 总览](./README.md) ｜ 归属功能：[A1 档口海报](../../func/client/A-浏览与发现/A1-档口海报.md)

## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | `max(statusBarHeight, env(safe-area-inset-top))` |
| 2 | **问候语** | 随时间三态切换；**对象统一称「小红果」**；**水平居中** | `--font-display` + `--weight-bold` + `--text-title`；上下留白 `--spacing-xl` |
| 3 | **板块标题** | 固定文案「**今天吃什么**」（承接上方问候语）；**左对齐** | `--font-title`(44rpx) + `--weight-bold` + `--text-title`；左右 `--page-gutter`；与海报区间距 `--spacing-md` |
| 4 | **海报区** | 一屏一张，横向滑动；**默认第一张完整可见、第二张右侧露出**；**空 / 失败时渲染 3 张占位卡**（同样可横向滑动） | 卡宽 `calc(100vw - 2 × --page-gutter - --poster-peek)`；**高 = 填满至底部 TabBar 的剩余空间**（不锁比例）；圆角 `--radius-card` |
| 5 | 底部 TabBar | 三项 | 见 [基线](./公共组件与形态基线.md) §2.1 |

**问候语三态**

| 时段（本地时间） | 文案 |
|---|---|
| `< 11:00` | 早上好，小红果 |
| `11:00 – 17:00` | 中午好，小红果 |
| `≥ 17:00` | 晚上好，小红果 |

> 「小红果」是**固定的群体称谓** —— **不读取**用户名 / 昵称 / 头像（全匿名）。
> 页面**不渲染品牌名** —— 海报已涵盖档口的全部信息。

🔴 **海报卡内零文本** —— 无标题、无按钮、无蒙层；档口名称 / 所属食堂 / 位置**全部由海报图自身承载**。

## 2 · 交互

| 项 | 口径 |
|---|---|
| 滑动 | 横向原生滑动（跟手）、**可回看上一张**、无循环 |
| 露边 | 右侧露出下一张 `--poster-peek`(48rpx) 的窄条 —— **默认即露出**（无需滑动）；换行由 `swiper` 的 `next-margin` 实现 |
| 点击 | **无任何点击行为**（纯展示） |
| 加载中 / 失败 / 为空 | 海报区渲染 **3 张占位卡**（各占一个海报位：`--radius-card` + 底 `--bg-placeholder` + 内嵌 `ImagePlaceholder`），**同样可横向滑动**—— **不留空白、不用文字失败块** |
| 页内恢复入口 | **不提供**（无按钮 / 无下拉刷新 / 无骨架屏）—— 数据需重取时由用户**重进小程序** |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page` |
| 问候语 | `--font-display` · `--weight-bold` · `--text-title`（水平居中） |
| 板块标题 | `--font-title`(44rpx) · `--weight-bold` · `--text-title`（**左对齐**） |
| 海报卡 | 圆角 `--radius-card`(40rpx) · 阴影 `--module-shadow` · 底 `--bg-placeholder`（图未就绪时） · **高填满至 TabBar 上沿** |
| 左侧内距 | `--page-gutter`(32rpx)；右侧为下一张的露边（见 §2） |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **无任何海报** | 海报区渲染 **3 张占位卡**（同「加载中 / 失败 / 为空」） |
| **数据加载失败** | 海报区渲染 **3 张占位卡**（同「加载中 / 失败 / 为空」）；**不出现**文字失败块 / 空态文案 |
| **仅 1 张海报** | 正常展示，不出现露边 |
| **图比例不符** | 按卡位 `aspectFill` **填满裁切**（卡片不锁比例），**不做留白** |
