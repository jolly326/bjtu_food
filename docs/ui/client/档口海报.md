> 返回：[UI 总览](./README.md) ｜ 归属功能：[A1 档口海报](../../func/client/A-浏览与发现/A1-档口海报.md)

## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | `max(statusBarHeight, env(safe-area-inset-top))` |
| 2 | **问候语（独立板块）** | 随时间三态切换；**对象统一称「小红果」**；**水平居中**（一级信息，轻字重）；**独立头部板块**，顶部预留充足边距 | `--font-display`(48rpx) + `--weight-regular` + `--text-title` + 衬线；上 `--spacing-2xl`(48rpx)；左右 `--page-gutter`(48rpx) |
| 3 | **板块标题（独立板块）** | 固定文案「**为你推荐**」（板块起始标记）；**左对齐**、唯一加粗项；与问候区之间的弹性留白由布局承担，**紧贴海报卡顶部**（间距 `--spacing-sm`(16rpx)） | `--font-title`(40rpx) + `--weight-bold` + `--text-title` + 衬线；左右 `--page-gutter` |
| 4 | **海报区** | 一屏一张，横向滑动；**区高 = 3:4 卡高（可收缩）**，卡片**贴区域底部、靠近 TabBar**；**左侧 48rpx、右侧露出下一张边缘（peek）**；**空 / 失败时渲染 3 张占位卡**（同样可横向滑动） | 区高 = 卡高 `calc((100vw - gutter - 24 - 48) × 4/3)`；卡宽 `calc(100vw - --page-gutter - --spacing-md - 48rpx)`；圆角 `--radius-card-stack`(24rpx) + `--shadow-card-stack` |
| 5 | 底部 TabBar | 三项 | 见 [基线](./公共组件与形态基线.md) §2.1 |

**问候语三态**

| 时段（本地时间） | 文案 |
|---|---|
| `< 11:00` | 早上好，小红果 |
| `11:00 – 17:00` | 中午好，小红果 |
| `≥ 17:00` | 晚上好，小红果 |

> 「小红果」是**固定的群体称谓** —— **不读取**用户名 / 昵称 / 头像（全匿名）。
> 页面**不渲染品牌名** —— 海报已涵盖档口的全部信息。

🔴 **海报卡内零文本** —— 无标题、无按钮、无蒙层；档口名称 / 所属食堂 / 位置**全部由海报图自身承载**。

> 卡片内**左上 / 右上为 `FlavorRating` 预留信息位**（位置口径与美食卡一致：左上字母 / 右上两行）；发现页数据源是海报、**无评级字段** ⇒ 当前不渲染；接入评级数据后直接挂载该组件。

## 2 · 交互

| 项 | 口径 |
|---|---|
| 滑动 | 横向原生滑动（跟手）、**可回看上一张**、无循环 |
| 左右边距 | 左侧 `--page-gutter`(48rpx)；**右侧 peek 48rpx 露出下一张边缘**（`next-margin`），卡片右缘再留 `--spacing-md`(24rpx) 呼吸位 |
| 点击 | **无任何点击行为**（纯展示） |
| 加载中 / 失败 / 为空 | 海报区渲染 **3 张占位卡**（各占一个海报位：`--radius-card-stack` + 底 `--bg-placeholder` + 内嵌 `ImagePlaceholder`（图标 **48rpx**、卡片内垂直居中）），**同样可横向滑动**—— **不留空白、不用文字失败块** |
| 页内恢复入口 | **不提供**（无按钮 / 无下拉刷新 / 无骨架屏）—— 数据需重取时由用户**重进小程序** |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page` = **`#FFF9ED`**（奶米色，见 [设计变量](./设计变量.md) §1.1） |
| 问候语 | `--font-display`(48rpx) · `--weight-regular` · `--text-title` · 衬线（**水平居中**） |
| 板块标题 | `--font-title`(40rpx) · `--weight-bold` · `--text-title`（**水平居中**，紧贴卡片） |
| 海报卡 | 圆角 `--radius-card-stack`(24rpx) · 阴影 `--shadow-card-stack`（**与美食页单卡同规范**） · 底 `--bg-placeholder`（图未就绪时） · **高 = 卡宽 × 4/3**（不占满屏幕） |
| 左右内距 | 左 `--page-gutter`(48rpx) / 卡间 `--spacing-md`(24rpx) / 右 peek `48rpx` |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **无任何海报** | 海报区渲染 **3 张占位卡**（同「加载中 / 失败 / 为空」） |
| **数据加载失败** | 海报区渲染 **3 张占位卡**（同「加载中 / 失败 / 为空」）；**不出现**文字失败块 / 空态文案 |
| **仅 1 张海报** | 正常展示（左右等距，无露边设计） |
| **图比例不符** | 按卡位 `aspectFill` **填满裁切**（卡片不锁比例），**不做留白** |
