# 用户协议 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 页面：`pages/privacy/agreement`（分包 `pages/privacy/`） ｜ 代码落点：`pages/privacy/agreement.vue`、`pages/privacy/DocPage.vue`（共用文档外壳）
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 视觉口径真源：[公共组件与形态基线.md](./公共组件与形态基线.md)（形态 §一 / 组件 §二）· [设计变量.md](./设计变量.md)（设计变量）


- 入口：「我的」页「其他」分组列表第 1 行「用户协议」。
- 页面：`pages/privacy/agreement`，承载《用户协议》单份文本。
- 纯展示：无表单、无按钮交互（仅纵向滚动）。
- 两页共用同一文本版式（**单块模块承载**：标题 + 生效日期 + 分节标题 / 正文），各自独立页面、互不切换。
- **本期不做版本化（已拍板）**：不设版本号与变更记录，仅保留页内**静态生效日期**。

## 接口数据字段（UI 精修用）

**页面**：`pages/privacy/agreement`（入口 = 「我的」页「其他」分组列表第 1 行；二级页，**无 TabBar**）

### 组件清单（本界面需要哪些组件）

> 组件自身规格（尺寸 / 圆角 / 颜色 / 状态 / 交互）以 [公共组件与形态基线.md](./公共组件与形态基线.md) §二 为唯一真源；**本表只写「本页用法」**。

| # | 组件 | 在本页做什么 |
|---|---|---|
| 1 | `AppHeader` | 页头：居中标题「用户协议」+ 返回（`@back` → `backToHome`） |
| 2 | `scroll-view` | 整页纵向滚动容器 |
| 3 | 文档模块 `.doc.module-wrap`（基线 §1.8.1 全局模块 + 页内 `.doc` 排版类；与 [隐私政策.md](./隐私政策.md) 同一文本版式） | 承载单份静态文本（连续长文本不拆块） |

> **无**数据类组件：无列表、无表单、无弹层、无 `AppIcon`、无网络请求组件。

### 有哪些数据要显示、显示在哪个组件

| 数据 | 来源 | 显示在哪个组件 | 呈现形式 |
|---|---|---|---|
| 标题「知行食记用户协议」 | 端内静态文案（随包发布，非接口） | 文档卡 `.doc-title` | 一级标题 |
| 生效日期「2026 年 9 月 12 日」 | 端内静态文案 | 文档卡 `.doc-meta` | 次级小字 |
| 五节正文（服务说明 / 账号与认证 / 内容规范 / 信息准确性 / 免责与协议变更） | 端内静态文案 | 文档卡 `.doc-h`（分节标题）+ `.doc-p`（段落） | 只读长文 |

**控件类型**：`scroll-view`(scroll-y) + 卡片承载文本（纯展示，无交互；两页互不切换）
