# 图标资源清单（学生端）

> **唯一图标族 = Phosphor（Bold 字重；选中态另用 Fill 字重）**。所有图标**一律下载现成资源**，**严禁自行绘制 / 手写路径**。
> **渲染方式**：`AppIcon` 引用**本地 SVG 文件** `src/assets/icon-variants/<key>--<tone>.svg` —— 微信 `<image>` 支持 SVG 文件，但**不支持运行时换色**（`currentColor` 落到黑色），故按色调**预生成着色变体**。

## 2 · 色调（`tone`）

`AppIcon` 以 `tone` 选择预生成变体（定义见 `client/src/theme/icons.generated.ts`）：

| tone | 浅色色值 | 深色色值 | 用途 |
|---|---|---|---|
| `default` | `#8A5A2B` | `#E8D9C4` | 未选中 / 常规（浅色暖棕；深色奶油色，对位 `--text-body`） |
| `primary` | `#FF8A4C` | `#FFA76B` | 选中 / 强调（Q 版暖橙；深色取晚霞橙提亮） |
| `muted` | `#C9B49C` | `#A08D78` | 弱化（对位 `--text-placeholder` / `--text-secondary`） |

> 深色色值与语义色深色组同源（见 [设计变量.md](./设计变量.md) §1.2）；`AppIcon` 按当前主题取对应色值组。

## 5 · 新增图标的流程

1. **下载**：从 `@phosphor-icons/core` 取对应字重的 SVG（Bold 为默认，`Fill` 用于选中态）；
2. **落盘**：存入 `client/src/assets/icons/<key>.svg`（**去掉 `-bold` / `-fill` 后缀**）；运营端需同步放一份到 `web/src/assets/icons/`；
3. **生成**：`cd client && npm run gen:icons`（`dev` / `build` 前自动执行）；
4. **登记**：在本表补「键 / Phosphor 名（字重） / 用途 / 消费点」；
5. **门禁**：跑 `npm run verify`。

> **构建机制**：着色变体由 `src/theme/icons.generated.ts` 以显式 `import` 引用，属**模块图资产** —— dev / build 两种模式都会把它产出到包内 `assets/`，图标随模块图打包，不会漏拷。

> **为何不用 `?raw` / data-uri**：uni-app 会把 `.svg?raw` 解析为 URL 资源而非字符串；而 URL 编码的 `data:image/svg+xml,…` 不被微信 `<image>` 接受 —— 故用**本地 SVG 文件 + 构建期着色**。
> 运营端（H5）无此限制，直接 `import.meta.glob(..., { query: '?raw' })` 注入并由 `fill="currentColor"` 继承 `color`，**无需**着色变体。
