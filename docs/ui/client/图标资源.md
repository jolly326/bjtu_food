## 2 · 配色（实心填充，只用中性棕）

图标取 Plump **Solid 实心版**：整块填充中性棕、不描边 —— 轮廓版在 40rpx 及以下会把 Plump 的粗线条糊成一团。

| 项 | 口径 |
|---|---|
| 填充 | `fill="#8C7B6B"`（中性浅棕，`--text-body` 同值） |
| 描边 | 无（不保留 `stroke`） |

> 颜色写死在 SVG 的 `fill` 里（`<image>` 不支持 `currentColor`），全站单一色板下用同一批文件与同一颜色。

## 4 · 预置资源库

两端**同源**（Streamline Plump Solid）但**各自入库**：学生端 `icons.ts` 引入实际消费的 7 个（`check` / `chevron` / `image` / `loading` / `search` / `warning` / `help`）；运营端独立精选 **14 枚**（`fill="currentColor"` 着色），不进入小程序主包。

`check` · `chevron` · `image` · `loading` · `search` · `warning` · `help` · `building` · `store` · `food` · `flag` · `list` · `exit` · `add`

> `check:icon` 对未被源码消费的键**只提示、不阻断**；新键先登记在 `icons.ts` 或运营端引用后再纳入。
>

## 5 · 新增图标的流程

1. **下载**：从 `plump/solid/<category>/<name>.svg` 取对应 SVG；确无同义资源才按同族风格手绘（仅实心填充、无描边）；
2. **统一填色**：把源文件的 `fill` 改为 `#8C7B6B`，并去掉 `stroke`；
3. **落盘**：存入 `client/src/assets/icons/<key>.svg`（文件名即键名）；
4. **登记**：学生端消费的键补进 `client/src/theme/icons.ts`；运营端消费的键**独立**从 Solid 源入库到 `web/src/assets/icons/`（`currentColor` 着色，不复制学生端写死色文件）；
5. **校验**：`cd web && npm run verify`（图标零消费即删）；
6. **入表**：在本文件 §3 补「键 / 源文件 / 用途 / 消费点」；
7. **门禁**：`cd client && npm run verify`；运营端 `cd web && npm run verify`。
