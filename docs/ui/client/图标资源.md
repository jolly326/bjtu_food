## 2 · 配色（单色棕描边）

动森风的功能小图标一律**单色描边、无填充**：把 Plump 源文件的填充路径转为描边路径，几何**保持源文件轮廓不变**，颜色统一为浅棕 `#8C7B6B`：

| 场景 | 色值 | 用途 |
|---|---|---|
| 描边（主体 / 细节同色） | `#8C7B6B` | 全部功能小图标（`fill: none` + `stroke`） |
| 点赞未赞 | `#8C7B6B` | `heart` 浅棕空心描边 |
| 点赞已赞 | `#8C7B6B` | `heart-fill` 浅棕填充（唯一填充态） |

> 描边宽度：`48` 网格用 `stroke-width 2`，心形 / 加号紧致 `viewBox` 用 `1.2`；圆角收口（`stroke-linejoin: round`）。
> 颜色直接写入 SVG 的 `stroke` / `fill`，不依赖 `currentColor` / CSS 变量；因此 `<image>` 与运营端 `v-html` 都能稳定显示。

## 5 · 新增图标的流程

1. **下载**：从 `plump/flat/<category>/<name>.svg` 取对应 SVG；
2. **单色化**：把填充路径转为描边路径（`fill: none` + `stroke: #8C7B6B` + `stroke-linejoin: round`），几何保持源文件轮廓；
3. **提取（仅心形 / 加号）**：保留 `user-feedback-heart` 的 `Union_3` 心形路径或 `application-add` 的 `Union_4` 加号路径，使用 §3 的紧致 `viewBox`；
4. **落盘**：存入 `client/src/assets/icons/<key>.svg`；
5. **登记**：学生端消费的键补进 `client/src/theme/icons.ts`；运营端消费的键由同步脚本复制到 `web/src/assets/icons/`；
6. **同步**：根目录执行 `node scripts/sync-icons.mjs`；
7. **入表**：在本文件 §3 补「键 / 源文件 / 用途 / 消费点」；
8. **门禁**：`cd client && npm run verify`；运营端 `cd web && npm run verify`。
