## 2 · 配色（只保留黑色轮廓，不上色）

图标从 Plump 源文件**只提取图形轮廓**：去掉源文件的彩色填充（`#8fbffa` / `#2859c5`），统一为**黑色描边、无填充**。

| 项 | 口径 |
|---|---|
| 填充 | `fill="none"`（不保留源文件彩色块） |
| 描边 | `stroke="#44382E"`（深棕）、`stroke-width="2"`、圆角收口（`stroke-linecap/linejoin: round`） |
| 点赞两态 | `heart` 空心轮廓 / `heart-on` 同路径 + 实心黑，**用不同文件区分** |

> 颜色写死在 SVG 的 `stroke` 里（`<image>` 不支持 `currentColor`），因此小程序与运营端显示一致。

## 4 · 预置资源库

两端**同源共用**下列 15 个键。学生端 `icons.ts` 只引入实际消费的 8 个（`check` / `chevron` / `heart` / `heart-on` / `image` / `loading` / `warning` / `help`）；运营端另有 7 个导航/操作图标，不进入小程序主包。

`check` · `chevron` · `heart` · `heart-on` · `image` · `loading` · `warning` · `help` · `building` · `store` · `food` · `flag` · `list` · `exit` · `add`

> `check:icon` 对未被源码消费的键**只提示、不阻断**；新键先登记在 `icons.ts` 或运营端引用后再纳入。
>

## 5 · 新增图标的流程

1. **下载**：从 `plump/flat/<category>/<name>.svg` 取对应 SVG；
2. **原样落盘**：不做颜色 / 几何 / `viewBox` 改动，直接保存源文件；
3. **落盘**：存入 `client/src/assets/icons/<key>.svg`（文件名即键名）；
4. **登记**：学生端消费的键补进 `client/src/theme/icons.ts`；运营端消费的键由同步脚本复制到 `web/src/assets/icons/`；
5. **同步**：根目录执行 `node scripts/sync-icons.mjs`；
6. **入表**：在本文件 §3 补「键 / 源文件 / 用途 / 消费点」；
7. **门禁**：`cd client && npm run verify`；运营端 `cd web && npm run verify`。
