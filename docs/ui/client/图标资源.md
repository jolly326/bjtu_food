# 图标资源清单（学生端）

> **唯一图标族 = Lucide（线性）**。所有图标**一律下载现成资源**，**严禁自行绘制 / 手写路径**。
> **渲染方式**：`AppIcon` 引用**本地 SVG 文件** `src/assets/icon-variants/<key>--<tone>.svg` —— 微信 `<image>` 支持 SVG 文件，但**不支持运行时换色**（`currentColor` 落到黑色），故按色调**预生成着色变体**。

## 5 · 新增图标的流程

1. **下载**：`https://unpkg.com/lucide-static@1.58.0/icons/<lucide-name>.svg`；
2. **落盘**：存入 `client/src/assets/icons/<key>.svg`；
3. **生成**：`cd client && npm run gen:icons`（`dev` / `build` 前自动执行）；
4. **登记**：在本表补「键 / Lucide 名 / 用途 / 消费点」；
5. **门禁**：跑 `npm run verify`。

> **构建机制**：着色变体由 `src/theme/icons.generated.ts` 以显式 `import` 引用，属**模块图资产** —— dev / build 两种模式都会把它产出到包内 `assets/`，图标随模块图打包，不会漏拷。

> **为何不用 `?raw` / data-uri**：uni-app 会把 `.svg?raw` 解析为 URL 资源而非字符串；而 URL 编码的 `data:image/svg+xml,…` 不被微信 `<image>` 接受 —— 故用**本地 SVG 文件 + 构建期着色**。
