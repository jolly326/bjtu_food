## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | — |
| 2 | **页头** | 左：页标题 + 当前日期；右：**食堂筛选下拉** | 高 `--tap-target-size`(88rpx)；左右 `--page-gutter` |
| 3 | **卡片区** | 扑克式堆叠，一次只显最上方一张 | 宽 = 屏宽 − 2 × `--page-gutter`；圆角 `--radius-card` |
| 4 | 底部 TabBar | 三项 | 见 [基线](./公共组件与形态基线.md) §2.1 |

**卡片内容（自上而下，居中排布）**

| 部件 | 口径 |
|---|---|
| **圆形菜品图** | 直径 `--dish-photo-size`(360rpx)、`--radius-circle` 裁切；空 / 失败走 `ImagePlaceholder` |
| **菜名** | `--font-h3`(36rpx) + `--weight-semibold` + `--text-primary`；最多 2 行，超长 `overflow-wrap: anywhere` |
| **元信息行** | **评价分 · 价格 · 位置**，`--font-body`(28rpx)；评价分 `--text-secondary`（`null` → 「暂无评价」）、价格 `--color-price`、位置（`食堂 \| 档口`）`--text-tertiary`；三者间距 `--spacing-sm` |
| **去品尝按钮** | 规格见 [基线](./公共组件与形态基线.md) §2.2 `WantButton`；宽度撑满卡内距 |

- **卡内距**：`--spacing-lg`(32rpx)；部件纵向间距 `--spacing-md`(24rpx)。
- **卡表面**：`--radius-card` + `--module-shadow` + `--module-bg`。

## 2 · 交互

| 项 | 口径 |
|---|---|
| **划走** | **左滑或右滑**均可（**两方向语义相同**）；卡片位移 + 淡出（`--duration-base` 200ms + `--ease-out`），下一张上浮补位 |
| **本会话不去重** | 划走的卡片**本会话内不再出现**（端上内存，**不落库**） |
| **去品尝** | 点按 ⇒ `POST /my/records`；成功后按钮转**已品尝态**（不可重复点） |
| **食堂筛选** | 右上角**下拉**（原生 `picker`）；选中即重筛，卡片序列**重掷** |
| **排序** | 服务端加权随机（见 [A2](../../func/client/A-浏览与发现/A2-推荐菜品.md)） |
| **无跳转** | 全部信息在卡片上，**无详情页** |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页头标题 | `--font-title`(44rpx) + `--weight-bold` + `--text-primary` |
| 页头日期 | `--font-small`(24rpx) + `--text-tertiary` |
| 堆叠露出 | 下方卡片向上露出 `--spacing-sm`(16rpx) 边缘 |
| 卡片高度 | 自适应内容（不写死） |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **卡片耗尽** | 卡区换为 `EmptyState`（形态见[基线](./公共组件与形态基线.md) §2.1）：标题「**今天就这些了**」+ 副文案「明天再来看看吧」+ **两个动作按钮** —— **「换一批」**（重新请求、重掷序列）｜ **「重看」**（重置本会话划走记录，从头开始） |
| **首屏加载** | 卡区渲染 `ImagePlaceholder` + 元信息占位（**不引入骨架屏**） |
| **加载失败** | 卡区内 `RetryBlock`（整块可点重试） |
| **食堂筛选为空集** | 同「卡片耗尽」的空态 |
