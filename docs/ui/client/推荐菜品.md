**卡片内容（自上而下，居中排布）**

| **菜品图** | `--dish-photo-size`(440rpx) **圆形**（`--radius-circle`），卡片视觉重心；🔴 圆角须**直接落在 `<image>` 上**（微信原生 `<image>` 不被父级 `overflow: hidden` 裁切，只给容器加圆角会露方角）；空 / 失败走 `ImagePlaceholder` |
| **菜名** | `--font-h2`(40rpx) + `--weight-semibold` + `--text-title` + **衬线** `font-family: var(--font-serif)`；最多 2 行，超长 `overflow-wrap: anywhere` |
| **元信息行** | **价格 · 位置**（评价分已上移到右上标签），`--font-body`(28rpx)；价格 `--color-price`、位置（`食堂 \| 档口`）`--text-tertiary`；两者间距 `--spacing-sm` |

- **卡内距**：左右 `--spacing-xl`(48rpx)、**上** `--spacing-lg`(32rpx)、**下** `--spacing-2xl`(64rpx) —— 🔴 **上小下大** ⇒ 整块内容（含大图）落在**中间偏上**（约 16rpx 位移）；部件纵向间距 `--spacing-lg`(32rpx)。
- **卡表面**：`--radius-card` + `--bg-card` + `1rpx var(--border-color)` **描边** + `--module-shadow`（页底色偏浅，仅靠阴影时卡片边界几乎不可见 ⇒ **必须有描边**）。

## 2 · 交互

| 项 | 口径 |
|---|---|
| **划走（拖拽翻卡）** | **左拖或右拖**均可（**两方向语义相同**），由 `DishCardStack` 管理（规格见[基线](./公共组件与形态基线.md) §2.2）：① **跟手** —— 顶层卡随手指平移 + 轻微旋转（≤8°）+ 微缩放；② **阈值** —— 位移 ≥ **卡宽 28%** ⇒ 沿该方向滑出并淡出（`--duration-base` 200ms + `--ease-out`），随后派发 `swipe`，下一张上浮补位；③ **回弹** —— 未达阈值则弹回原位；④ **下层预显** —— 拖拽过程中下层卡按进度放大、提亮，做好"上台"过渡 |
| **本会话不去重** | 划走的卡片**本会话内不再出现**（端上内存，**不落库**） |
| **去品尝（切换）** | 未品尝 ⇒ 点按 `POST /my/records`（成功后文案转「**取消品尝**」）；已品尝 ⇒ 点按 `DELETE /my/records/{id}`（**取消品尝**，文案转回「去品尝」）。🔴 记录 id：优先用本会话 `POST` 返回的 id，否则回查 `GET /my/records` 按 `dishId` 找。🔴 **边界**：已评分（`reaction` 非空）的记录**不可撤销**（后端 `400`），此时提示并保持已品尝态 |
| **食堂筛选** | 右上角**下拉**（原生 `picker`）；选中即重筛，卡片序列**重掷** |
| **排序** | 服务端加权随机（见 [A2](../../func/client/A-浏览与发现/A2-推荐菜品.md)） |
| **无跳转** | 全部信息在卡片上，**无详情页** |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页头标题 | `--font-display`(56rpx) + `--weight-bold` + `--text-title` |
| 页头日期 | `--font-small`(24rpx) + `--text-tertiary` |
| 堆叠景深 | 下方叠 **3 层**：逐层 `scale` 递减 0.05、透明度递减 0.3、**向下偏移**（每层 ≈ 16rpx）露出下沿；下层卡 `pointer-events: none`（不抢焦点） |
| 卡片高度 | 自适应内容（不写死） |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **卡片耗尽** | 卡区换为 `EmptyState`（形态见[基线](./公共组件与形态基线.md) §2.1）：标题「**今天就这些了**」+ 副文案「明天再来看看吧」+ **两个动作按钮** —— **「换一批」**（重新请求、重掷序列）｜ **「重看」**（重置本会话划走记录，从头开始） |
| **首屏加载** | 卡区渲染**占位卡**：与 `DishSwipeCard` **同构**（描边 + 圆角 + 阴影、**同吊孔 + 同顶行位置**、**同圆形图位**、同内距与部件间距）—— 图位走 `ImagePlaceholder`、**文本区留空不画横条**（序号 / 标签 / 菜名 / 元信息只留高度）、**按钮照常显示**（复用 `WantButton` 的 `disabled` 态，文案与真实卡同源）；**不引入骨架屏** |
| **加载失败** | 同「首屏加载」（占位卡）；**不出现**文字失败块 |
| **食堂筛选为空集** | 同「卡片耗尽」的空态 |
