## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | — |
| 2 | **页头** | 左：衬线标题「美食」+ 日期；右：**食堂筛选下拉** | 标题 `--font-display`(48rpx) 衬线；日期 `--font-small`；左右 `--page-gutter` |
| 3 | **Z 轴堆叠卡片栈** | 顶层完整卡 + 下层预览；水平拖拽翻页；**整卡作为页面主容器** | 栈槽左右 `--page-gutter`(48rpx) 对称；上 `--spacing-2xl`(48rpx) / 下 `--spacing-xl`(40rpx)，卡片占满剩余区域 |
| 4 | 底部 TabBar | 三项 | 见 [基线](./公共组件与形态基线.md) §2.1 |

**卡片栈（Idle）**

| 层 | 口径 |
|---|---|
| 顶层 | **实色底、不写 `opacity`**（不能透出下层）；完整展示、居中；所有按钮可点 |
| 第二层 | `scale 0.88` + `opacity 0.45` + 轻微下偏移；仅露出边缘 |
| 更深层 | 继续缩小、透明度持续降低，营造 Z 轴景深 |
| 下层交互 | `pointer-events: none`（触摸穿透、不可点） |

**卡片流末尾空态（本批划完才出现）**

| 部件 | 口径 |
|---|---|
| 承载 | 与栈卡**同卡面**（同卡位、同圆角 / 阴影），整卡一块，居中纵向排布 |
| 标题 | **「今天的推荐就到这里」**——`--font-h2` + `--weight-semibold` + `--text-title` + 衬线 |
| 副文案 | 「都看完啦，换种方式再来一轮」——`--font-small` + `--text-tertiary` |
| 动作按钮 | **两个等宽线性按钮并排**（间距 `--spacing-md`，各 `flex: 1`）：**重新浏览**（`refresh-cw`，中性灰描边）｜**随机盲选**（`shuffle`，暖橙描边）；高 `--tap-target-size`、圆角 `--radius-btn`、图标 `28rpx` 在文案左侧 |
| 出现时机 | **仅当本批卡片全部划完**；正常滑动阶段不渲染；首屏无菜品走「无菜品」空态，**不出现**这两个按钮 |

**单卡内容（自上而下）**

| 部件 | 口径 |
|---|---|
| 顶部左右信息位 | **绝对定位** `top: --spacing-lg`(32rpx)、左 / 右 `--spacing-xl`(40rpx)；**左 = 群体评级字母、右 = 风味评级两行**（见[基线](./公共组件与形态基线.md) §2.2 `FlavorRating`） |
| 圆形菜品图 | `--dish-photo-size`(420rpx) **圆形**（`--radius-circle`）；🔴 圆角须**直接落在 `<image>` 上**；视觉重心、四周留白充足；空 / 失败走 `ImagePlaceholder`(48rpx) |
| 菜名 | `--font-display`(48rpx) + `--weight-semibold` + `--text-title`(`#44382e`) + **衬线**；居中；最多 2 行 |
| 价格 · 食堂/档口 | **整行浅灰小字**：`¥38.00 · 食堂\|档口` —— `--font-small`(22rpx) + `--text-tertiary`；居中、与菜名固定间距 |
| 去品尝按钮 | **胶囊描边**：细橙描边 + 暖白填充（`--bg-page`）+ `check` 图标在左；`--radius-pill`、高 96rpx；贴底 |

- **卡表面（双层）**：**外层容器**仅 `1rpx` 描边 + `--radius-card`(36rpx) + `--module-shadow`（内边距 `--spacing-xs`，营造悬浮层）；**内层白卡** `--bg-card` + `--radius-card-stack`(24rpx) 承载全部内容；🔴 **顶层不透明、不写 `opacity`**。
- **卡内距**：内层白卡上 `calc(var(--spacing-2xl) * 2)`(96rpx，预留顶部信息位)、左右 `--spacing-xl`(40rpx)、下 `--spacing-md`(24rpx)。
- **页面间距**：页头左右 `--page-gutter`(48rpx)；标题到卡片 = 页头下距 16rpx + 栈槽上距 48rpx = **64rpx**；卡片底部 40rpx（与发现页海报一致）。
- 内容**居中偏上**、按钮贴底；不溢出卡片。

## 2 · 交互（Drag / Release）

| 阶段 | 口径 |
|---|---|
| **Idle** | 顶层完整；下层缩小低透明；下层触摸穿透 |
| **Drag** | 仅顶层响应**水平**拖拽；跟手带 `0.9` 轻微阻尼；旋转 `≤ ±3°`；**垂直滑动不触发**；拖拽时「去品尝」禁用；下层同步放大、提亮、向居中靠拢 |
| **Release：回弹** | 位移 `< 卡宽 22%` ⇒ 沿原路回弹，**`--duration-base`**；下层恢复堆叠 |
| **Release：翻页** | 位移 `≥ 卡宽 22%` ⇒ 沿拖拽方向飞出（**`--duration-slow`**，`ease-out`），派发 `swipe(id)`；下一张晋升顶层，栈重排，旧卡销毁 |
| **去品尝** | `POST /my/records`（**自动写入记忆页当日记录**）；Toast「已记录到记忆」，独立于卡片、3s 消失；已品尝 ⇒ `DELETE /my/records/{id}`（仅未评分可撤销） |
| **食堂筛选** | 右上角原生 `picker`；选中即重筛 |
| **重新浏览** | 本批卡片按**原顺序**重新入栈（无网络请求），卡片上浮淡入 |
| **随机盲选** | 重新请求一批（沿用当前食堂筛选、排除本批已出现的菜）；在途时按钮禁用；切回卡片栈时走同一入场动画 |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页头标题 | `--font-display`(48rpx) + `--weight-bold` + `--text-title` + **衬线** |
| 页头日期 | `--font-small` + `--text-tertiary` |
| 卡片表面 | 外层 `1rpx var(--border-color)` + `--radius-card`(36rpx) + `--module-shadow`；内层 `--bg-card` + `--radius-card-stack`(24rpx)；顶层不透明 |
| 栈槽 | 左右 `--page-gutter`(48rpx) 对称；上 `--spacing-2xl`(48rpx) / 下 `--spacing-xl`(40rpx) |
| 卡内距 | 内层上 96rpx / 左右 40rpx / 下 24rpx |
| 去品尝按钮 | `--radius-pill` · 高 `calc(--tap-target-size + --spacing-xs)` · 左右留白 `--spacing-xl` |
| 圆形图 | `--dish-photo-size`(420rpx)；距顶 120rpx、距下 48rpx |
| 菜名 | `--font-display`(48rpx) 衬线 |
| 风味评级 | 见[基线](./公共组件与形态基线.md) §2.2 `FlavorRating` |
| 动效 | 拖拽跟手；回弹 `--duration-base`；翻页 `--duration-slow`；`--ease-out`；🔴 无弹跳 / 闪光 |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **首屏加载** | 栈位渲染**骨架卡**（同卡圆角 + 圆形图占位 + 淡占位块 + 底部禁用按钮）；**不启用滑出旋转** |
| **无菜品** | 栈位渲染**空态占位卡**：衬线「**暂无菜品推荐**」+ 浅灰小字「等待食堂上新美食」；无复杂插画（**不出**重新浏览 / 随机盲选） |
| **流末尾** | 本批全部划完 ⇒ 同卡位换成「今天的推荐就到这里」+ 两个动作按钮 |
| **随机盲选无新菜** | 退回本批过滤前的结果；若仍为空（该食堂无菜）⇒ 走「无菜品」空态 |
| **数据首次到达** | 第一张卡片从栈位上浮淡入 |
| **加载失败** | `RetryBlock` |
| **食堂筛选为空集** | 同「无菜品」 |
| **评级待评** | 评分条数 < 3 ⇒ 左上**不渲染字母**、右上第二行为「待评」 |
