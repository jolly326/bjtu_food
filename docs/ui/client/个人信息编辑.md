# 个人信息编辑 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 页面：`pages/profile/index`（分包 `pages/profile/`） ｜ 代码落点：`pages/profile/index.vue`
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 视觉口径真源：[公共组件与形态基线.md](./公共组件与形态基线.md)（形态 §一 / 组件 §二）· [设计变量.md](./设计变量.md)（设计变量）

- 入口：**「我的主页」用户信息卡右侧「编辑个人信息」**（**仅认证态可达** —— 编辑身份信息是认证态才具备的能力，该胶囊仅认证态渲染，见 [README §身份卡](./公共组件与形态基线.md#三跨页版面身份卡用户信息模块)）。宿主主页见 [我的主页.md](./我的主页.md)。
- 页面形态：**独立页面**，`AppHeader` 页头标题「**个人信息**」+ 可滚动表单区 + **底部固定操作栏**；**返回**（文字） = `navigateBack`。二级页，**无 TabBar**。

### 1. 页面构成

- 自上而下：页头（**居中标题「个人信息」+ 返回，无右操作**）→ **头像行**（可改）→ **昵称行**（可改）→ **校园邮箱**（只读）→ **底部固定操作栏**（通栏「保存」，仅「有改动且不在途」时可用）。主操作位置按 [公共组件与形态基线.md](./公共组件与形态基线.md) §1.1「主操作位置通则」：**页头恒不承载业务操作**，本页主操作固定底部常驻。
- 表单区为**一张分组卡**（`--radius-card` + `--shadow-card`），行间细分隔线（`--border-color`）；**无弹层、无 `ActionSheet`、无 `RetryBlock`**。

### 2. 字段区

- 可改行的**昵称输入**取全站表单**下划线语言**（透明底 + 仅底部 `1rpx` `--border-color` 细线；聚焦时底线转 `--color-primary`）。每行触控目标 ≥ 88rpx。

| 行 | 左侧 | 右侧 | 可编辑 |
|---|---|---|---|
| 头像 | 标签「头像」（`--font-body`） | 104rpx 圆角方图（`--radius-icon`；无头像 `ImagePlaceholder name="user"` 灰底占位、**图标 52rpx = 边长 50%**）+ `arrow` | **是**（换图） |
| 昵称 | 标签「昵称」 | `input`（**下划线语言**，右对齐），占位「请输入昵称」，`maxlength=20`（与服务端 `PUT /auth/profile` 的「≤20 字」一致） | **是** |
| 校园邮箱 | 标签「校园邮箱」 | 只读：`bindEmail`（空值回落 `--`） | 否 |

- 只读行**不放任何跳转入口**（身份认证动作单一入口 = 「我的」页宫格「身份认证」格）。

### 3. 头像更换

- 点整行 → **直接调 `uni.chooseImage`**（系统自带拍照 / 相册选择面板，**不经 `ActionSheet`**）→ 选图（单张）→ 本地压缩（≤1MB、≤750×1334）→ 经 UGC 图片上传链路取回地址后**就地刷新预览**，地址暂存、随「保存」写库。
- 上传中给进行时反馈（头像位 loading），**禁止静默等待**；失败 → Toast 展示后端 `message`，**保留原头像**。

### 4. 保存链路

- 主操作：**底部固定操作栏**内的通栏 `AppButton`「**保存**」（`action-bar` mixin：`--module-bg-strong` + `--shadow-bar-soft` + safe-area 内距，左右内距与页面 gutter 同轴）。**无改动或提交中时禁用** ⇒ `AppButton` 禁用档（灰底 `--bg-input` + 灰字 `--text-tertiary`，不降透明）；提交中 ⇒ `loading`（转环 + 忽略点击 + `opacity: .6`），文案恒「保存」。
- **键盘避让（必声明）**：昵称 `input` 聚焦时微信默认 `adjust-position` 会把整页上顶 ⇒ **固定底栏须随之抬升**（底栏容器 `bottom` = 键盘高度 + 安全区），保证「保存」**不被键盘遮挡**；键盘收起归零、不残留悬空。
- 点击 → `PUT /auth/profile`（`nickname` + `avatar`；昵称端上先行非空校验）→ 成功 Toast「已保存」→ 延迟 `navigateBack` 返回我的主页，由主页 `onShow` 刷新信息卡。
- 失败 → Toast 提示 `message`，**停留本页**并保留已填内容；昵称命中敏感内容或内容安检 `risky` → 后端 `400`，同按 `message` 提示、不保存。

### 5. 数据回填与状态

- 进入即以全局 `stores/user` 的 `UserInfoVO` 回填（`watch` + `immediate`）；**加载中不呈现骨架屏 / loading 指示**（数据未返回时表单区静默空白）。
- **无加载失败态**：资料由全局 `stores/user` 回填（页面本身不发 `GET /auth/profile`），故无 `RetryBlock` 分支。

### 6. 无障碍与动效

- 头像行 `role="button"` + `aria-label="更换头像"`；昵称输入带 `aria-label="昵称"`；右侧 `arrow` 图标 `aria-hidden="true"`。
- `prefers-reduced-motion: reduce` 下取消可点行的 `background-color` 过渡（按压反馈退化为**直接换色**）；按压取 `--bg-soft`，**非** scale。

### 7. 组件清单（本界面需要哪些组件）

> 组件自身规格（尺寸 / 圆角 / 颜色 / 状态 / 交互）以 [公共组件与形态基线.md](./公共组件与形态基线.md) §二 为唯一真源；**本表只写「本页用法」**。

| # | 组件 | 在本页做什么 |
|---|---|---|
| 1 | `AppHeader` | 页头：居中标题「个人信息」+ 返回（`@back` → `backToHome`）；**无右操作** |
| 2 | `AppButton` | 底部固定操作栏内的通栏「保存」（禁用 = 灰底灰字；提交中 `loading` → 转环 + 忽略点击） |
| 3 | `ImagePlaceholder` / `AppIcon` | 无头像时的 `user` 占位；头像行右箭头 `arrow` |
| 4 | `.module-wrap`（基线 §1.8.1；行内结构页内自有） | 信息模块（暖奶米半透），三行结构：头像 / 昵称 / 校园邮箱 |
| 5 | `scroll-view` | 表单滚动区（底部留 `--action-bar-height` + 安全区避让） |
| 6 | `input` | 昵称录入（占位「请输入昵称」） |
| 7 | `uni.chooseImage` | 头像选图（单张、压缩；`album` + `camera`） |
| 8 | `uploadUgcImage` | 头像上传链路（与 UGC 配图同一条：安检 + 转存 COS）→ 取回地址 → 本地暂存（随「保存」才落库） |

> **无** `ActionSheet`、**无** `RetryBlock`、**无** 独立弹层：本页为单一信息模块 + 固定底栏结构。

### 8. 数据字段（有哪些数据要显示、显示在哪个组件）

| # | 数据（字段） | 来源 | 中文含义 | 显示在哪个组件 | 呈现位置 / 形式 |
|---|---|---|---|---|---|
| 1 | `avatar` | `GET /auth/profile`（`UserInfoVO`，经 `stores/user`） | 头像地址 | 头像行右侧（`image` + `getImageUrl`） | 104rpx 圆角方图（`--radius-icon`）；空 / 失败 → `ImagePlaceholder name="user"` 灰底；上传中半透明 |
| 2 | `nickname` | 同上 | 昵称 | 昵称行 `input`（**回填**） | 右对齐输入（**下划线语言**，聚焦主色底线）；占位「请输入昵称」 |
| 3 | `bindEmail` | 同上 | 校园邮箱 | 校园邮箱行右侧只读文本（`.info-value-email`） | 唯一来源；空值回落 `--`，长文本可换行不溢出 |
| 4 | 上传结果 `url` | `POST /upload/cloud-image`（经云存储中转） | 头像新地址 | 头像行**就地刷新预览**（本地暂存，未落库） | Toast「上传成功，请点击保存」 |
| 5 | 保存中态 | 端上 `saving` | 提交在途 | `AppButton`（`loading`） | 防重复提交 |
| 6 | 失败提示 | `400` / `401` 响应 `message` | 失败原因 | 无界面（Toast 直透，兜底「保存失败」） | 停留本页并保留已填内容 |

**控件类型**：`scroll-view`、`input`、`uni.chooseImage` 单张选图、固定底部 `submit-bar` + `AppButton`
