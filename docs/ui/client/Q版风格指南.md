# Q 版动森 UI 指南 — 学生端风格宪法

> 所属端：学生端（微信小程序，uni-app）
> 定位：**「为什么这样设计」与「什么不能做」的唯一出处**；取值以 [设计变量.md](./设计变量.md) 与 [公共组件与形态基线.md](./公共组件与形态基线.md) 为准，本文件不重复数值表。
> 适用：全站唯一页面（菜品首页）与全部组件。**新增 / 改动 UI 前先读本文件，再读对应页面稿。**

---

## 0 · 调研来源（事实基础）

| 项 | 内容 |
|---|---|
| 参考产品 | **Q 版动森: A Smarter Cookbook**（Afternoon Labs，iOS，2025 年 4 月上架，v1.3.x） |
| 产品主张 | 「Discover the joy of cooking」· 「A smarter cookbook」——把 AI 包装成**更聪明的菜谱书**，而非工具 |
| 调性关键词 | confidence（信心）、inspiration（灵感）、joy（乐趣）——**温和、克制、不炫技** |
| 调研样本 | App Store 官方 9 张界面截图（Cookbook 列表 / Discover 首页 / Shopping List 等）+ 商店描述文案 |
| 品牌隐喻 | 名称来自刀法「切丝」，副标是「书」——**厨具 × 书**，直接决定「纸质手账」的视觉方向 |

**一句话**：把界面当成一本**安静的奶米手账**——奶米纸底、深棕墨色、极细描边、大留白，所有装饰都收敛到「恰好够用」。

## 1 · 风格内核（六条不可让渡）

| # | 原则 | 正确做法 | 反面 |
|---|---|---|---|
| 1 | **纸感** | **奶米纸底 `#FFF7E8` + 奶白卡面 + 极细描边**分层；卡片内用短横线虚线分组 | 重投影、渐变、玻璃拟态、纯黑装饰 |
| 2 | **编辑感** | 无衬线圆体大字做标题 + 小号无衬线圆体做元信息（标签 / 时长），像刊物标题与说明 | 全站无衬线圆体、靠字重堆层级 |
| 3 | **单一重心** | 一屏只有一个视觉主元素（菜品图标网格），其余退到灰 | 多个同级强调、彩色块争抢注意力 |
| 4 | **留白排版** | 用间距与底色差分组；卡片内信息段用短横线虚线隔离 | 分割线切块、边框套边框（卡片短横线虚线除外） |
| 5 | **克制动效** | `--ease-out` 为主；磁贴 / 按钮按压用 `--ease-bounce` 轻微回弹；位移 / 缩放克制 | 大幅弹跳、闪烁、循环动画 |
| 6 | **低饱和暖调** | 奶米底 + 深棕字 + 浅杏胶囊；🔴 学生端不使用暖橙主色 | 高饱和色块、纯黑、彩色渐变 |

## 2 · 色彩（Q 版动森 实测 → 我们的取值）

### 2.1 Q 版动森 的实际用色（截图取样，仅供对齐语义）

| 角色 | 观感 | 用法 |
|---|---|---|
| 画布 | **白色 / 近白**（干净克制，不是暖米黄） | 全页底色 |
| 卡面 | 白色或**极浅灰白**（与画布区分极弱） | 卡片、列表行；**2rpx 极浅描边（纸张边缘）、极弱弥散阴影**，靠留白与阴影浮起 |
| 墨色 | 近黑深棕 | 标题、菜名 |
| 元信息灰 | 暖灰 | 时长、食材数、副标题 |
| 桃色（soft peach） | 低饱和柔桃 | **小面积填充**：分类徽标、"Pro"标、复选框、Clear chip（文字仍是深棕） |
| 深棕（反白 pill） | 近黑棕 | **选中筛选项**：实底 pill + 白字 |
| 强调橙 | 偏亮的暖橙 | Tab 选中图标与文案、少量主操作 |

### 2.2 我们的落地与比例尺

| 层 | 占比 | 取值 |
|---|---|---|
| **纸** | ~90% | `--bg-page` 奶米纸色 `#FFF7E8` + `--bg-card` 奶白 `#FFFDF7`（卡片）+ `--bg-placeholder` 浅米 `#F3E7D3`（图片位） |
| **墨** | ~8% | `--text-title` 深棕 `#44382E`、`--text-body` 可读浅棕 `#8C7B6B` |
| **印** | ~2% | 浅杏 `--pill-bg` `#F9E9D8`（页内胶囊）；暖橙主色只在运营端出现 |

### 2.3 硬规则

- 🔴 **学生端不用暖橙**：页内可点件一律浅杏胶囊 + 深棕字，不做橙色按钮底 / 描边 / 文字。
- 🔴 **不使用纯黑**：正文最深到 `--text-title`；🔴 **不做纯黑**（非脏蓝）。
- 🔴 **禁硬阴影 / 渐变 / 3D 堆叠**：仅允许 `--shadow-soft` / `--shadow-up` 极弱弥散阴影，层级主要靠底色（胶囊）、描边、圆角区分。
- **弱化 = 换 token 档位，不叠加 `opacity`**；禁用态可用 `opacity: .5`；页面胶囊置灰用**暖灰棕 `--text-disabled`**（描边 + 文字，🔴 不用冷灰、不用灰度滤镜）。

## 3 · 字体与排版

### 3.1 Q 版动森 的做法

- **所有标题用圆润无衬线体**（气质接近 Quicksand / Nunito 一类圆体字），**常规字重**，靠**字号**立威，不靠加粗；
- 关键词用**圆体斜体**强调（如「What are we making for *Dinner*?」）；
- 元信息 / 标签 / 按钮用**无衬线圆体**，小、灰、字距略开；
- 行高宽松，标题多行左对齐，不强行居中。

### 3.2 我们的分工（已按项目编辑口径收敛）

| 用途 | 字族 |
|---|---|
| 菜名（弹窗主标题）、加载态文案 | **无衬线圆体** `--font-sans` |
| 食堂·档口等**参数型元信息**、按钮文案、弹层选项、引导小字 | **无衬线圆体** `--font-sans` |

> **字体落地**：动森同款圆体（M PLUS Rounded 1c / 思源圆体）需经 `wx.loadFontFace` 远程加载，受**域名白名单 + 中文字体包体**限制 —— 端上用**系统圆体**（`--font-sans`：`-apple-system` / `PingFang SC` / `HarmonyOS Sans SC`）命中圆润字形，**不引入自定义字体文件**（取舍见 [`ARCHITECTURE.md`](../../ARCHITECTURE.md)「已知取舍」）。

### 3.3 字号梯度（封闭标度，禁止自造）

`--font-hero` 64 → `--font-display` 48 → `--font-title` 40（弹窗菜名）→ `--font-h2` 36（加载态文案）→ `--font-h3` 32 → `--font-body` 28（正文 / 辅助信息）→ `--font-subtitle` 26（位置等辅助）→ `--font-small` 22（辅助）。

- 🔴 **字重规则**：**无衬线圆体标题一律 `regular`**（含弹窗主标题 / 菜名）—— 层级主要由**字号 + 颜色**承担；🔴 **禁 `bold` / heavy**；`semibold` 只留给无衬线圆体状态标签。
- **行高**：标题 1.2–1.3；正文 1.5–1.6；标签 `line-height: 1`。
- **字距**：小号标签 `0.08em`（状态标签类）；其余为 0。
- **层级表达顺序**：**尺寸 → 颜色 → 位置**；字重不作为层级手段。

## 4 · 留白与网格

| 规则 | 口径 |
|---|---|
| 页面左右 | 全站唯一档 `--page-gutter`(32rpx)，所有模块左基准线对齐 |
| 间距节奏 | 只用 `--spacing-*`（2/4/8/16/24/32/40/48…，8 的倍数系） |
| 垂直节奏 | 同级区块间 `--spacing-2xl`(48)；元素间 `--spacing-md/lg`；紧密组内 `--spacing-xs`(8) |
| 呼吸优先 | 拿不准时**加大间距**，而不是加装饰（加线 / 加底 / 加图标） |
| 卡内距 | 底部弹窗信息区 48/40/48 |

🔴 **禁止**：为「充实」填内容、为「层次」加底色；sheet 主信息 / 反馈的短横线虚线隔离除外。

## 5 · 形状 / 描边 / 层次

| 元素 | 口径 |
|---|---|
| 圆角 | `--radius-card`(44rpx) 全部卡片 / 图标框 ｜ `--radius-modal`(56rpx) 弹层顶 ｜ `--radius-pill`(999rpx) 胶囊（按钮 / 可点胶囊）；🔴 全站节奏统一，**不混用直角 / 小圆角 / 大圆角**，交互元素圆角均 ≥ 12px |
| 描边 | 卡片 / 面板以浅底色 + `var(--border-width) --border-color` 细描边分层；不要彩色描边 |
| 阴影 | 仅 `--shadow-soft`（向下）/ `--shadow-up`（向上）极弱弥散阴影（卡片 / 弹层）；🔴 禁用硬阴影 / 渐变 / 3D 堆叠 |
| 留白 | 卡片内距 ≥ `--spacing-xl`(40rpx) 档、左右 ≥ `--page-gutter`(32rpx)；文字 / 图片 / 按钮**不贴卡缘**，模块之间只用留白分组 |
| 散布 | 菜品图标在 3 列网格上排布（行列对齐、不重叠、不过近），无层叠、无景深阴影堆叠；🔴 不用透明淡化、不用模糊 |
| 图片 | 菜品图标用**圆角方**；弹窗大图用**圆角矩形** `--radius-card`；列表缩略可用圆角方 |

## 6 · 图标（实心填充语汇）

| 项 | 口径 |
|---|---|
| 来源 | Streamline Plump（**Solid**）**实心填充 SVG**（`client/src/assets/icons/`），**单一来源**；禁 emoji / 自绘 / 图标字体 |
| 填充 | 一律 `fill="#8C7B6B"` 中性棕实心、无描边（Solid 变体；去掉源文件 `stroke`），圆角由路径自带 |
| 色调 | 全部图标浅棕 `#8C7B6B`；无 tone / 主题变体 |
| 尺寸 | 封闭档位表（见基线 §1.8）；同级图标同尺寸 |
| 形态 | 无圆形底、无描边外框；命中区仍须 ≥ 96rpx |
| 语义 | 一图标一含义；同含义跨页复用同一键 |

**图标键选择遵循「物象而非抽象」**（Q 版动森 用图像 / 餐具 / 书 / 星芒这类具象物）：

| 位置 | 键 | 语汇 |
|---|---|---|
| 弹窗反馈 | 浅杏软胶囊「反馈」 | 反馈 = 软胶囊入口 |

## 7 · 组件气质

| 组件 | 该有的样子 | 不该有的样子 |
|---|---|---|
| **磁贴** | 圆角矩形菜品图（`--bg-placeholder` 底 + `--radius-card` 大圆角 + `var(--border-width)` 细描边）+ 下方菜名 | 文字浮层压图、重投影、渐变、多重描边 |

| **按钮** | 胶囊：浅杏底 + 深棕描边 + 深棕文字；按压轻微收缩回弹 | 高饱和实底、双图标、直角 |
| **展开卡** | 内联跨 3 列卡、`--radius-modal`、奶白卡面、反馈入口胶囊 | 居中对话框、遮罩、红色警示 |

## 8 · 动效

| 项 | 口径 |
|---|---|
| 时长 | `--duration-fast`(140) / `--duration-base`(240) / `--duration-slow`(420) |
| 缓动 | `--ease-out`（进入 / 位移）；`--ease-bounce`（sheet 按压 / 磁贴点按 Q 弹） |
| 允许 | 位移、淡入、`scale(.96)` 按压、旋转（≤3°）、高度过渡 |
| 禁止 | 大幅弹跳、闪烁、循环动画、视差 |

## 9 · 与 Q 版动森 的**有意差异**（须知晓，勿"纠正"）

| 维度 | Q 版动森 实际做法 | 我们的落地 | 说明 |
|---|---|---|---|
| 标题字重 | 标题中等偏粗但不厚重 | **无衬线圆体标题一律 `regular`** | 禁 `bold` / heavy，靠字号与颜色立层级 |
| 画布色 | 白色 / 近白 | 奶米纸色 `#FFF7E8` | 当前规范采用奶米纸底 |
| 卡面与画布 | 卡片白色或极浅灰白，区分很弱 | 卡面 `#FFFDF7`，细棕描边（极弱弥散阴影） | 层次由色阶 + 描边 + 留白承担 |
| 筛选选中态 | 深棕实底 pill + 白字 | 页内浅杏胶囊 + 深棕描边 + 深棕文字 | 🔴 学生端不用暖橙 |
| hover / 按压 | 无 | sheet 胶囊 `scale(.96)` / 其余 `opacity` 微降 | 小程序需要触觉反馈 |

> 若某轮要「回到 Q 版动森 原版」，改动点是 **token 单值**（画布色、卡面色），不涉及业务逻辑。

## 10 · 反例清单（评审红线）

1. 出现**纯黑文字**、**重投影 / 渐变**或**高饱和色块**；奶米纸底是当前规范。
2. 出现**无意义分割线**、**卡片边框套边框**；sheet 短横线虚线隔离除外。
3. 出现**高饱和色块 / 渐变 / 阴影过重**。
4. **图标带圆形底、多色贴纸或 emoji**；图标尺寸超出档位表。
5. 文案层级靠**加粗堆叠**而非尺寸 / 颜色分层。
6. 页面出现**第二个视觉重心**（两个大图 / 两个主 CTA）。
7. 动效**大幅弹跳 / 闪烁 / 循环**。
8. 自造 token（裸色值 / 裸 rpx 尺寸）—— 门禁 `check:ui` 直接拦。

## 11 · 落地与校验

- **token 唯一真源**：颜色 `theme/tokens.ts` + `generated-colors.css`；非颜色 `design-tokens.css`；对照表见 [设计变量.md](./设计变量.md)。
- **形态唯一真源**：[公共组件与形态基线.md](./公共组件与形态基线.md)（§0 设计语言 / §1 形态基线 / §2 组件规格）。
- **目录规范**：跨页公共件 `client/src/components/`；页面私有件 `pages/home/components/`（见基线 §2.0）；魔法数字 `client/src/constants.ts`。
- **图标**：新键落 `client/src/assets/icons/<key>.svg` → 登记 `client/src/theme/icons.ts` / [图标资源.md](./图标资源.md) §3；运营端按需**独立**从 Solid 源入库（`currentColor` 着色）。
- **门禁**：`npm run verify` = `check:contract`（契约）+ `check:icon`（图标体系）+ `check:ui`（裸值）+ `check:events`（事件命名）+ `check:doc`（文档一致 / 断链）+ lint + type-check + 单测 + 构建，全绿才算可交付。
