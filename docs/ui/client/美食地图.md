> 返回：[UI 总览](./README.md) ｜ 归属功能：[A1 美食地图](../../func/client/A-浏览与发现/A1-美食地图.md) · [B1 点赞反馈](../../func/client/B-轻量反馈/B1-点赞反馈.md) · [B2 菜品纠错](../../func/client/B-轻量反馈/B2-菜品纠错.md)

## 1 · 页面结构（全屏沉浸）

| # | 区块 | 内容 |
|---|---|---|
| 1 | **全屏画布（唯一内容）** | 2D 可平移 + 双指缩放平面；菜品以圆角正方形大图磁贴随机散布；首屏随机落点 |
| 2 | 底部弹窗（点磁贴唤起） | 半屏 peek：详情 + 点赞 + 纠错 |

🔴 **无 TabBar、无全局 AppHeader、无页标题（hero）** —— 全站仅此一页，去掉一切导航 chrome，让菜品大图铺满视口。页面根 = 纯画布 + 弹窗层；安全区由画布自身内距承担（顶部状态栏避让、底部 `env(safe-area-inset-bottom)`）。

## 2 · 画布与磁贴

| 项 | 口径 |
|---|---|
| 画布 | 一个**内容包围盒**（所有磁贴的几何边界）；支持拖拽平移 + 双指缩放；边界**弹性停止**（rubber-band，越界不外溢） |
| 磁贴 | **圆角正方形菜品大图**（`aspect-ratio: 1`，圆角 `--radius-card`）；**纯图、无文字浮层**；图位加载中 / 失败 / 为空走 `ImagePlaceholder` |
| 排布 | **全量洗牌随机散布**：所有在售菜品铺在平面上，非固定、无食堂成簇 / 中心 / 权重；每次进入重新随机 |
| 首屏 | 视口**随机落点**（不预设中心） |
| 缩放 | 双指捏合**放大 / 缩小**；范围与阻尼由端上定（缩放态下磁贴不重排） |
| 平移 | 单指拖拽**平移**，松手**带惯性**（按松手速度衰减） |

## 3 · 底部弹窗（DishSheet · 点磁贴唤起）

| 部件 | 口径 |
|---|---|
| 容器 | 半屏 peek（`--radius-modal` 顶圆角 + `--overlay-panel-bg` + `--shadow-modal`）；上滑开合 `--duration-slow`；下拉 / 点遮罩关闭 |
| 大图 | 顶部菜品大图（圆角 `--radius-card`），失败走 `ImagePlaceholder` |
| 信息行 | 菜名（无衬线圆体 `--font-title` + `--weight-regular` + `--text-title`）｜ 价格（无无衬线圆体 `--font-body` + `--weight-medium` + `--text-body`，比位置重一档）｜ 位置（`map-pin` 图标 + `食堂 档口`，无无衬线圆体 `--text-tertiary`） |
| 点赞 | **两态点赞按钮**：显示点赞数；`heart` 图标（已赞 `tone="primary"`，未赞 `tone="default"`）+ 数字；点即 toggle（见 [B2](../../func/client/B-轻量反馈/B1-点赞反馈.md)） |
| 纠错 | 文字按钮「纠错反馈」（`tone="default"`，无底色）；点开**在同一弹窗内展开 5 选项**（单行单选、无图标 ⇒ 直排选项行，每行高 `--tap-target-size`、文案 `--font-body` + `--text-title`、行间 `1rpx --border-color`）；点选即提交并轻 Toast，弹窗不自动关闭（见 [B2](../../func/client/B-轻量反馈/B2-菜品纠错.md)） |
| 交互 | **无长按**（全页无長按手势） |

## 4 · 手势规格（Apple 式物理感）

| 阶段 | 口径 |
|---|---|
| 平移 | 单指拖拽跟手；松手**惯性衰减**（速度 × 阻尼系数）；接近 / 越过边界时**弹性回弹**（rubber-band，不硬停、不外溢） |
| 缩放 | 双指捏合；以双指中点为锚缩放；范围限幅（最小 / 最大缩放比由端上定） |
| 点击判定 | 位移 < 阈值（端上定，建议 ≤ 10rpx）且时长 < 阈值 ⇒ **点击磁贴**唤起弹窗；否则判为平移 / 缩放手势，避免误触 |
| 动效 | 过渡轻柔低速、`--ease-out`；🔴 **尊重 `prefers-reduced-motion: reduce`**：惯性 / 弹性 / 缩放过渡降级为即时，无弹跳闪光 |

## 5 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | 纯白 `--bg-page`（`#FFFFFF`） |
| 磁贴 | 圆角正方形 `aspect-ratio: 1` + 圆角 `--radius-card`(32rpx)；图直接落在 `<image>` 上（原生 `<image>` 不吃父级 `overflow` 裁切） |
| 弹窗面板 | `--overlay-panel-bg` + `--radius-modal`(40rpx) 顶圆角 + `--shadow-modal`；`padding-bottom: env(safe-area-inset-bottom)` |
| 点赞按钮 | 图标 `heart` 28rpx + 点赞数（`--font-body` + `--text-title`）；已赞 `tone="primary"` |
| 纠错选项行 | 高 `--tap-target-size`、文案 `--font-body` + `--text-title`、行间 `1rpx --border-color`、首末行无线 |
| 主色 | 暖橙 `#B4531A` 仅用于**选中态**（已赞图标）与**唯一关键 CTA 描边**（纠错提交等），装饰性一律不用 |
| 字体 | 标题 / 菜名无衬线圆体（`--weight-regular`，不靠加粗）；价格 / 辅助信息无无衬线圆体 |

## 6 · 边界与状态

| 场景 | 表现 |
|---|---|
| **首屏加载** | 画布区居中 `PageLoading`（64rpx `refresh-cw` 慢速旋转、`muted`、主题跟随；不整页覆盖） |
| **加载失败** | 画布区只渲染 `RetryBlock`（点此重试），不渲染磁贴 |
| **空态** | 🔴 **不处理**（无 EmptyBlock；零在售菜品时画布留白，无提示无按钮） |
| **图片失败 / 缺失** | 磁贴图位走 `ImagePlaceholder`（§1.9） |
| **点赞 / 纠错提交** | 轻 Toast（3s 消失），弹窗不自动关闭 |
