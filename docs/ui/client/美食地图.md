## 1 · 页面结构（全屏沉浸）

| # | 区块 | 内容 |
|---|---|---|
| 1 | **全屏画布（唯一内容）** | 2D 可平移 + 双指缩放平面；圆角正方形菜品磁贴在**均匀错位方格**上密铺；首屏落在世界几何中心 |
| 2 | **底部弹窗（点磁贴唤起）** | 半屏 peek：详情 + 点赞 + 纠错 |

🔴 **无 TabBar、无全局 AppHeader、无页标题（hero）** —— 全站仅此一页，去掉一切导航 chrome，让菜品大图铺满视口。页面根 = 纯画布 + 弹窗层；安全区由画布自身内距承担（顶部状态栏避让、底部 `env(safe-area-inset-bottom)`）。

## 2 · 画布（均匀错位方格）

| 项 | 口径 |
|---|---|
| 世界 | 一个**内容包围盒**（所有磁贴几何边界）；平移 / 缩放作用于该盒 |
| 排布 | 🔴 **均匀错位方格密铺**（非随机散布）：固定网格**行优先**落格，**奇偶行水平错开半格**形成砖墙式结构 —— 结构可预测、行列整齐错开，**不重叠、不过近、无空隙堆叠**；🔴 **不做簇**（无主食区 / 甜品区、无食堂成簇、无食堂中心 / 固定锚位 / 权重）；磁贴尺寸统一（240rpx 边长，步长 300rpx，净距约 `60rpx`），保持「一个接一个」的紧凑感 |
| 落位 | 每次载入菜品**随机映射到已确定的格子**（`shuffled`：格子结构不变、只换谁坐哪格）—— 位置恒为均匀错位，不因重掷而散乱；窗口尺寸变化后重算格位并保持同一结构 |
| 首屏 | 首屏落在**世界几何中心**并收敛到合法边界（不跳、不越界） |
| 缩放 | 双指捏合**放大 / 缩小**；**软限位**（贴近上下限时缩放幅度被压缩） |
| 平移 | 单指拖拽**平移**，松手**带惯性**（按松手速度衰减） |

## 3 · 卡片

画布上的每个格子都是**同尺寸、同圆角体系、同层级**的圆角正方形菜品磁贴 —— 一律是菜品大图，格子内不插按钮、不设功能位。

### 3.1 菜品磁贴

| 项 | 口径 |
|---|---|
| 形态 | **圆角正方形菜品大图**（`aspect-ratio: 1`，圆角 `--radius-card`）；**纯图、无文字浮层**；图位加载中 / 失败 / 为空走 `ImagePlaceholder` |
| 描边 | `1rpx --border-color` 极细浅棕描边（夜间由描边承担微弱夜光边缘）；🔴 **无阴影** |

## 4 · 底部弹窗（DishSheet · 点磁贴唤起）

| 部件 | 口径 |
|---|---|
| 容器 | 半屏 peek（`--radius-modal` 顶圆角 + `--overlay-panel-bg` + 顶部 `1rpx` 细描边，🔴 无阴影）；弹起 `--duration-slow` + `--ease-out`；手柄下拉跟手（超过 120rpx 关闭、未超过回弹）/ 点空白关闭；🔴 **无背景蒙版**（背景透明、不变暗、不加滤镜）；大图固定，只有下方信息区切换 |
| 大图 | 顶部菜品大图（圆角 `--radius-card` + **极细浅棕描边** `1rpx --border-color`），失败走 `ImagePlaceholder` |
| 主信息块 | 第 1 行左菜品名（`--font-title` / `--text-title`）、右点赞（`heart` 40rpx + 数字 `--font-title`，基线对齐）；第 2 行档口名（`--font-body` / `--text-body`，空则不渲染）；短虚线（`--sheet-divider`，8rpx 实线 + 8rpx 间隔）；虚线下方左「食堂名 + 可选楼层」（食堂 `--font-body`、楼层 `--font-subtitle`，楼层空只渲染食堂名），右「纠错反馈 ›」文字入口（`--font-subtitle` / `--text-body`，箭头 `--color-muted`，不加胶囊、不显示 `flag` 图标）；🔴 **不展示价格** |
| 点赞 | **文字化两态点赞**：未赞 `heart` 浅棕空心、已赞 `heart-fill` 浅棕填充，均 40rpx；数字 `--font-title` / `--text-title`；🔴 **无白底胶囊 / 无圆框**，与菜名基线对齐；点即 toggle 并有 Q 弹（见 [B1](../../func/client/B-轻量反馈/B1-点赞反馈.md)） |
| 反馈分页 | 每页最多 3 个 `SheetPill`（浅杏底 + 2rpx 深棕描边 + 深棕文字，`--radius-pill`）；虚线下方为导航胶囊：第 1 页左侧「返回」、其余页「上一页」，右侧固定「下一页」，末页置灰（暖灰棕描边与文字）且无按压/无响应；点胶囊先按压回弹，再淡入「要提交这条反馈吗？」确认气泡（「确认提交」为主操作 = 加深杏色）；取消留在当前页，确认提交成功提示约 1.2s 后自动回主信息块（见 [B2](../../func/client/B-轻量反馈/B2-菜品纠错.md)） |
| 交互 | **无长按**（全页无長按手势）；只保留按钮操作（点「纠错反馈 ›」进入反馈页、点「返回」「上一页」回主信息块），🔴 无左右横滑手势；大图固定，反馈翻页只切选项行，导航行固定；手柄下拉跟手关闭 / 点空白关闭均生效 |

## 5 · 手势规格（Apple 式物理感 · 软边界）

| 阶段 | 口径 |
|---|---|
| 平移 | 单指拖拽跟手；松手**惯性衰减**（速度 × 阻尼系数） |
| **软边界** | 越过内容包围盒时**画布仍可继续跟手，但位移被阻尼压缩**（越界越深、跟手比例越低；超过上限后画布几乎不动）—— 🔴 **不做硬停、不做瞬移回位** |
| 回弹 | 松手后画布**弹性回位**（`--ease-bounce` 带过冲的缓动），落回合法范围后自然停住；惯性滑动到边界处**逐渐衰减**而非硬停 |
| 缩放 | 双指捏合；以双指中点为锚缩放；**软限位**（贴近最小 / 最大缩放比时缩放幅度被压缩，不生硬卡死） |
| 点击判定 | 位移 < 阈值（端上定，建议 ≤ 10rpx）且时长 < 阈值 ⇒ **点击卡片**唤起弹窗；否则判为平移 / 缩放手势，避免误触 |
| 动效 | 过渡轻柔低速、`--ease-out`；🔴 **尊重 `prefers-reduced-motion: reduce`**：惯性 / 弹性 / 缩放过渡降级为即时，无弹跳闪光 |

## 6 · 视觉规格（昼夜双主题 · 动森风）

> 两套主题共用同一套**形态语言**（大圆角、松弛手绘细描边、无阴影、柔和回弹、圆润无衬线），只换**色温与明度** —— 白天是奶米纸色，夜里是低饱和夜色。

| 项 | 取值 |
|---|---|
| 页面底色 | **白天** 奶米纸色 `--bg-page`（`#FFFAF3`）；**夜间** 低饱和夜色 `--bg-page`（`#2B3A4A`，不做纯黑） |
| 磁贴 | 圆角正方形 `aspect-ratio: 1` + 圆角 `--radius-card`(44rpx) + `1rpx` 细描边（🔴 无阴影）；磁贴 240rpx、净距约 `60rpx`；图直接落在 `<image>` 上（原生 `<image>` 不吃父级 `overflow` 裁切） |

| 弹窗面板 | `--overlay-panel-bg` + `--radius-modal`(56rpx) 顶圆角 + 顶部 `1rpx --border-color` 细描边；`padding-bottom: env(safe-area-inset-bottom)` |
| 点赞按钮 | **文字化**：未赞 `heart` 浅棕空心、已赞 `heart-fill` 浅棕填充，40rpx；数字 `--font-title` / `--text-title`；基线对齐、**无底色无胶囊** |
| 纠错入口 | 第二行右侧「纠错反馈」`--font-subtitle` + 柔和 `›`（`--color-muted`）；文字行入口、整行右侧可点、**不加胶囊** |
| 反馈/导航胶囊 | `SheetPill`：`--sheet-pill-bg` 浅杏底 + `2rpx --sheet-pill-border` 深棕描边 + `--text-title` 字 + `--radius-pill`；高 `--tap-target-size`、文案 `--font-subtitle`；按压 `scale(.96)` 回弹，置灰取暖灰棕 `--text-disabled` 且无动画/无响应 |
| 分割线 | 主信息 / 附属信息之间、反馈选项 / 导航之间使用短虚线（`--sheet-divider`，8rpx 实线 + 8rpx 间隔） |
| 主色 | 暖橙 `--color-primary` 用于**非 sheet 品牌 CTA**；sheet 内不使用橙色，点赞与胶囊统一棕色 / 浅杏 |
| 字体 | 标题 / 菜名 / 餐厅 / 楼层均无衬线圆体（`--weight-regular`，不靠加粗）；辅助信息无衬线圆体 |
| **夜间口径** | 夜色低饱和（`#2B3A4A` 系），奶米字改**冷调奶白**；晚霞橙主色保留作暖点缀；**卡片带微弱夜光边缘**（由描边色提亮承担，🔴 不引入阴影）；夜间不做纯黑、不做高对比描边，圆角与描边宽度与白天一致 |

## 7 · 边界与状态

| 场景 | 表现 |
|---|---|
| **首屏加载** | 画布区居中 `PageLoading`（64rpx `arrows-clockwise` 慢速旋转、`opacity .55`、主题跟随；不整页覆盖） |
| **加载失败** | 画布区只渲染 `RetryBlock`（点此重试），不渲染磁贴 |
| **空态** | 🔴 **不处理**（无 EmptyBlock；零在售菜品时画布留白，无提示无按钮） |
| **图片失败 / 缺失** | 磁贴图位走 `ImagePlaceholder`（§1.9） |
| **重新载入** | 菜品**重新映射到格子**（格子结构恒为均匀错位 ⇒ 位置不散乱）；首屏落在世界几何中心 |
| **点赞提交** | 轻 Toast（3s 消失），弹窗保持打开 |
| **反馈确认** | 点反馈胶囊 → 按压回弹 → 奶色确认气泡；取消留在当前反馈页；确认提交成功 → 「反馈已提交」提示约 1.2s → 自动回主信息块，弹窗保持打开 |
