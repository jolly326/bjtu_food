## 1 · 页面结构（全屏沉浸）

| # | 区块 | 内容 |
|---|---|---|
| 1 | **背景动森层** | 画布之下的氛围层 = 页面 `--bg-page` 纯色底；除纯色底外不叠加额外纹理（纯装饰、不可点） |
| 2 | **全屏画布** | 2D 可平移 + 双指缩放平面；圆角正方形菜品磁贴在**规整对齐网格**上排布（含若干 2×2 大图（数量随菜品数，约 12%）+ 散布空位（互不相邻、不扎堆））；首屏落在世界几何中心 |
| 3 | **底部弹窗（点磁贴唤起）** | 半屏 peek：详情 + 点赞 + 纠错 |

🔴 **无 TabBar、无全局 AppHeader、无页标题（hero）** —— 全站仅此一页，去掉一切导航 chrome，让菜品大图铺满视口。页面根 = 纯画布 + 弹窗层；安全区由画布自身内距承担（顶部状态栏避让、底部 `env(safe-area-inset-bottom)`）。

## 2 · 画布（规整网格）

| 项 | 口径 |
|---|---|
| 世界 | 一个**内容包围盒**（所有磁贴几何边界）；平移 / 缩放作用于该盒 |
| 排布 | 🔴 **规整对齐网格**：行列对齐、**不重叠、不过近**；🔴 **不做簇**（无主食区 / 甜品区、无食堂成簇、无食堂中心 / 固定锚位 / 权重）；基础磁贴尺寸统一（240rpx 边长，步长 300rpx，净距约 `60rpx`），每载入按菜品数比例**随机选若干（约 12%）菜品放大为 2×2 跨度大图**（纯视觉点缀），并在网格中**散布少量空位（互不相邻、不扎堆）**（非密铺，留作呼吸）；格位与空位随每次载入重新生成，菜品随机填入剩余格 |
| 落位 | 每次载入**重新生成网格结构**（按菜品数比例选若干 2×2 跨度位 + 散布少量空位（互不相邻）），菜品随机填入剩余格 —— 位置恒为规整对齐网格，不因重掷而散乱；窗口尺寸变化后重算格位并保持同一结构 |
| 首屏 | 首屏落在**世界几何中心**并收敛到合法边界（不跳、不越界） |
| 缩放 | 双指捏合**放大 / 缩小**；**软限位**（贴近上下限时缩放幅度被压缩） |
| 平移 | 单指拖拽**平移**，松手**带惯性**（按松手速度衰减） |

## 3 · 卡片

画布上的格子绝大多数是圆角正方形菜品大图；另有**功能网格按钮**（日月切换，见 §3.3）作为特殊格子，形态区别于菜品磁贴；**绝大多数格为 1×1 统一磁贴**，另有**若干 2×2 跨度大图**（见 §3.2）。

### 3.1 菜品磁贴

| 项 | 口径 |
|---|---|
| 形态 | **圆角正方形菜品大图**（`aspect-ratio: 1`，圆角 `--radius-card`）；**纯图、无文字浮层**；图位加载中 / 失败 / 为空走 `ImagePlaceholder` |
| 描边 | `var(--border-width) --border-color` 极细浅棕描边（夜间由描边承担微弱夜光边缘）；卡片 / 大图可加 `--shadow-soft` 极弱弥散阴影 |

### 3.2 2×2 跨度大图磁贴

| 项 | 口径 |
|---|---|
| 形态 | 每载入按菜品数比例**随机选若干（约 12%）菜品**放大为 **2×2 跨度大图**（占 2×2 格，边长 = `TILE_RPX + CELL_RPX` ≈ 540rpx，圆角 `--radius-card`）；**纯视觉点缀**，与 1×1 磁贴同圆角体系、同描边、可加 `--shadow-soft` 极弱弥散阴影、纯图无文字浮层 |
| 选取 | 随机（不按热度 / 不人工标记）；数量随菜品数（约 12%），每载入都出现 |
| 图位 | 加载中 / 失败 / 为空走 `ImagePlaceholder`（按 2×2 区尺寸渲染） |

### 3.3 功能网格按钮（日月切换）

| 项 | 口径 |
|---|---|
| 定位 | 与菜品磁贴**同为网格单元**：占用一个格子、随画布平移 / 缩放**滑动**；仅当按钮**滑入可视区**时才可点，不在固定位常驻 |
| 形态 | = **直接落在背景上的 plump 图标**（无菜品磁贴的圆角矩形框）；既是装饰点缀、也是交互功能网格；占格、退到灰、不争视觉重心 |
| 交互 | 点按切换日 / 夜主题（页面根 `data-theme`），带 `--ease-bounce` 轻微 Q 弹；命中由画布全局手势判定，不在按钮自身挂 tap |
| 范式 | 🔴 **所有功能型网格按钮均沿用此范式**（占格、随滑动、仅屏内可点、以 plump 图标直接落在背景上、无圆角矩形框）；日月切换为首个实例 |

## 4 · 底部弹窗（DishSheet · 点磁贴唤起）

| 部件 | 口径 |
|---|---|
| 容器 | 半屏 peek（`--radius-modal` 顶圆角 + `--overlay-panel-bg` + 顶部 `var(--border-width)` 细描边，可加 `--shadow-up` 极弱弥散阴影）；升起 / 退出均用 `--duration-base` + `--ease-out` **推入 / 推出**（无过冲、不来回弹）；**保留顶部压痕 grabber**（80×8rpx）作为把手；🔴 **无背景蒙版**（背景透明、不变暗、不加滤镜），scrim 不接收事件 ⇒ **弹层架起时画布仍可点选 / 拖动**；**底部留白只保留 `env(safe-area-inset-bottom, 0px)`**（不叠加额外间距）；横线下方块高度取 `--sheet-block-bottom` = `--spacing-xl`(40rpx)；大图固定，只有下方滑动区切换 |
| 大图 | 顶部菜品大图为**圆角矩形**：四周 gap `--spacing-lg`（顶部由把手区提供，压痕在其中居中），圆角 `--radius-modal` 与弹层顶角**同半径 ⇒ 同心圆弧**，`var(--border-width) --border-color` 细描边（可加 `--shadow-soft` 极弱弥散阴影，与弹层一致）；**宽高比 16:9**（`padding-bottom: calc((100% - 2 × --spacing-lg) × 9 / 16)` —— padding 百分比以**父容器宽度**为基准，须先扣掉左右 margin 才等于图片自身宽度）；失败走 `ImagePlaceholder`；**信息区文本左缘与图片左缘对齐** |
| 主信息块 | 第 1 行左菜品名（`--font-title` / `--text-title`）、右点赞（`heart` 40rpx + 数字 `--font-title`，**两者同一水平中线**）；第 2 行档口名（`--font-body` / `--text-body`，行高 `--spacing-lg`）—— **档口未知时显示占位「暂无」，取 `--text-disabled`**（置灰，与真实档口名区分）；**短横线虚线**（`--sheet-divider`，线 16rpx + 空 16rpx，上下各 `--spacing-sm`）；虚线下方左「食堂名 + 楼层」（食堂 `--font-body`，**恒有值**；楼层 `--font-subtitle`，**缺失时同样显示占位「暂无」+ `--text-disabled`**），右「纠错」浅杏软胶囊入口（`--radius-pill` + `--pill-bg` 浅杏底 + `var(--border-width) --border-color` 细描边，含 `chevron` 24rpx 右箭头，不含暖橙）；🔴 **不展示价格** |
| 点赞 | **图标 + 数字纯组件**：`heart` 空心 / `heart-on` 实心黑（40rpx）+ 数字 `--font-title`，🔴 **无底色、无边框**；与菜名**同一水平中线**，行内 space-between；点即 toggle 并有 Q 弹（见 [B1](../../func/client/B-轻量反馈/B1-点赞反馈.md)） |
| 纠错页三态 | **pick**：虚线上方 3 个选项横排（浅杏软胶囊 `--radius-pill`，无图标），下方左「‹返回」右「下一页›」（`chevron` 24rpx）；**confirm**：上方只留选中项居中（浅杏胶囊），下方左「取消」右「确认提交」（软胶囊，确认提交用 `--text-title` 深棕字强调）；**success**：上方 `check` 32rpx + 「反馈已收到」，下方居中「关闭」⇒ 滑回菜品信息页。三态在虚线上下两块内切换，**虚线位置全程不动**（见 [B2](../../func/client/B-轻量反馈/B2-菜品纠错.md)） |
| 交互 | **无长按**（全页无長按手势）；点纠错入口 ⇒ 信息块整体**左滑出**、纠错块**右滑入**（`--ease-bounce` 过冲，果冻感）；点「返回」反向滑回。**大图固定不参与滑动、两页短横线虚线同一垂直位置、弹层高度不变**；反馈页内部翻页只切选项行；点空白关闭生效 |

## 5 · 手势规格（Apple 式物理感 · 软边界）

| 阶段 | 口径 |
|---|---|
| 平移 | 单指拖拽跟手；松手**惯性衰减**（速度 × 阻尼系数） |
| **软边界** | 静止边界以「**最边缘卡片中心能到视口中心**」为准（不要求世界边缘贴住视口边缘）⇒ 内容与视口同宽时仍可拖动；单张卡片时两侧边界收敛为同一点 ⇒ 自动居中锁定。越过该边界后**画布仍可继续跟手，但位移被阻尼压缩**（越界越深、跟手比例越低）—— 🔴 **不做硬停、不做瞬移回位** |
| 回弹 | 松手后画布**弹性回位**（`--ease-bounce` 带过冲的缓动），落回合法范围后自然停住；惯性滑动到边界处**逐渐衰减**而非硬停 |
| 缩放 | 双指捏合；以双指中点为锚缩放；**软限位**（贴近最小 / 最大缩放比时缩放幅度被压缩，不生硬卡死） |
| 点击判定 | 位移 < 阈值（端上定，`TAP_MOVE_THRESHOLD_PX` = 8px）且时长 < 阈值（`TAP_DURATION_MS` = 320ms）⇒ **点击卡片**唤起弹窗并触发 **camera 聚焦**；否则判为平移 / 缩放手势，避免误触。命中空白 ⇒ 关闭已架起的弹层 |
| **camera 聚焦** | 点选磁贴后把该磁贴中心送到**弹层顶边以上可视区**的中心（不是整屏中心 —— 否则会被弹层压住一半）。🔴 **平移边界与聚焦必须共用同一「有效视口高度」**（弹层架起 = 净空区，否则 = 整屏）：否则聚焦目标会被按整屏算的边界夹住，偏差正好半个弹层高度；弹层已开但尚未实测高度时，按弹层内容高度（以 rpx 计恒定，`SHEET.ESTIMATE_HEIGHT_RPX`）折算净空区 —— 固定屏高比例会在小屏偏下、大屏偏上。点选瞬间若净空区未就绪，先记下目标、等实测回传后再动（避免「先居中整屏、再被拽回」的双段位移）。动画用三次 **ease-in-out** 320ms（起止柔和；回弹收敛仍用 ease-out） |

## 6 · 视觉规格（昼夜双主题 · 动森风）

> 两套主题共用同一套**形态语言**（大圆角、松弛手绘细描边、极弱弥散阴影、柔和回弹、圆润无衬线），只换**色温与明度** —— 白天是奶米纸色，夜里是灰黑（deepseek harness 风）。

| 项 | 取值 |
|---|---|
| 页面底色 | **白天** 奶米纸色 `--bg-page`（`#FFFAF3`）；**夜间** 灰黑 `--bg-page`（`#1E1E1E`，不做纯黑、非脏蓝） |
| 磁贴 | 圆角正方形 `aspect-ratio: 1` + 圆角 `--radius-card`(44rpx) + `var(--border-width)` 细描边（可加 `--shadow-soft` 极弱弥散阴影）；基础磁贴 240rpx、净距约 `60rpx`；另有少量 2×2 跨度大图（§3.2）；图直接落在 `<image>` 上（原生 `<image>` 不吃父级 `overflow` 裁切） |
| 背景动森层 | 画布之下的氛围层 = 纯色 `--bg-page` 底（不争视觉重心的主题切换按钮已作为网格单元落在画布内，见 §3.3）；🔴 **不叠加额外纹理**（遵守 Q 版 §1#3 单一重心，整体退到灰、低饱和） |
| 主题切换组件 | 画布内的**功能网格按钮**（如日/夜 totem）：占用一个格子、随画布滑动、仅滑入屏内可点；**全站唯一功能入口**；点击切换 `data-theme` 并带 `--ease-bounce` 轻微 Q 弹；低饱和、退到灰，不与菜品大图争注意力；🔴 直接以 plump 图标落在背景上（无圆角矩形框） |

| 弹窗面板 | `--overlay-panel-bg` + `--radius-modal`(56rpx) 顶圆角 + 顶部 `var(--border-width) --border-color` 细描边（可加 `--shadow-up` 极弱弥散阴影）；🔴 **收紧底部留白**（`padding-bottom: calc(var(--spacing-md) + env(safe-area-inset-bottom))`，不额外堆叠一档），大图高度取宽度的 `42%` ⇒ 整体约 **45% 屏高** |
| 点赞按钮 | **文字化**：未赞 `heart` 中性棕填充、已赞 `heart-on` 珊瑚红填充，40rpx；数字 `--font-title` / `--text-title`；基线对齐、**无底色无胶囊** |
| 纠错入口 | 最下行右侧「纠错」浅杏软胶囊（`--radius-pill` + `--pill-bg` 浅杏底 + `var(--border-width) --border-color` 细描边）+ `chevron` 24rpx 右箭头；整行右侧可点 |
| 反馈 / 导航入口 | **浅杏软胶囊**（`--radius-pill` + `--pill-bg` 浅杏底 + `var(--border-width) --border-color` 细描边）+ `chevron` 24rpx 箭头（返回/上一页在左、下一页在右），整块可点，🔴 **不用暖橙主色**；置灰取 `--text-disabled` 且无按压响应 |
| 分割线 | 主信息 / 附属信息之间、反馈选项 / 导航之间使用**短横线虚线**（`--sheet-divider`，`4rpx dashed`） |
| 主色 | 暖橙 `--color-primary` 用于**非 sheet 品牌 CTA**；sheet 内不使用橙色，点赞与胶囊统一棕色 / 浅杏 |
| 字体 | 标题 / 菜名 / 餐厅 / 楼层均无衬线圆体（`--weight-regular`，不靠加粗）；辅助信息无衬线圆体 |
| **夜间口径** | 夜色为灰黑（`#1E1E1E` 系），字改**中性浅灰**；晚霞橙主色保留作暖点缀；**卡片带微弱边缘**（由描边色承担，可加 `--shadow-soft` 极弱弥散阴影）；夜间不做纯黑、不做高对比描边，圆角与描边宽度与白天一致 |

## 7 · 边界与状态

| 场景 | 表现 |
|---|---|
| **首屏加载** | 画布区居中 `PageLoading`（56rpx `loading` 慢速旋转、`opacity .55`、主题跟随；不整页覆盖） |
| **加载失败** | 画布区只渲染 `RetryBlock`（点此重试），不渲染磁贴 |
| **空态** | 🔴 **不处理**（无 EmptyBlock；零在售菜品时画布留白，无提示无按钮） |
| **图片失败 / 缺失** | 磁贴图位走 `ImagePlaceholder`（§1.9） |
| **重新载入** | **重新生成网格结构**（随机选 1–2 个 2×2 跨度位 + 随机散布少量空位），菜品随机填入剩余格；首屏落在世界几何中心 |
| **点赞提交** | 轻 Toast（3s 消失），弹窗保持打开 |
| **反馈确认** | 点选项 ⇒ 选中项单独居中（confirm）→ 取消回列表 / 确认提交 ⇒ 成功态（check + 「反馈已收到」）→ 点「关闭」滑回菜品信息页；🔴 **全程无独立弹窗、无深色遮罩**，成功态不可返回列表 |
