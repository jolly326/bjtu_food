> 返回：[UI 总览](./README.md) ｜ 归属功能：[A1 美食地图](../../func/client/A-浏览与发现/A1-美食地图.md) · [B1 点赞反馈](../../func/client/B-轻量反馈/B1-点赞反馈.md) · [B2 菜品纠错](../../func/client/B-轻量反馈/B2-菜品纠错.md)

## 1 · 页面结构（全屏沉浸）

| # | 区块 | 内容 |
|---|---|---|
| 1 | **全屏画布（唯一内容）** | 2D 可平移 + 双指缩放平面；菜品以圆角正方形大图磁贴在**错位方格**上密铺；首屏居中 |
| 2 | 底部弹窗（点磁贴唤起） | 半屏 peek：详情 + 点赞 + 纠错 |

🔴 **无 TabBar、无全局 AppHeader、无页标题（hero）** —— 全站仅此一页，去掉一切导航 chrome，让菜品大图铺满视口。页面根 = 纯画布 + 弹窗层；安全区由画布自身内距承担（顶部状态栏避让、底部 `env(safe-area-inset-bottom)`）。

## 2 · 画布与磁贴

| 项 | 口径 |
|---|---|
| 画布 | 一个**内容包围盒**（所有磁贴的几何边界）；支持拖拽平移 + 双指缩放；边界**弹性停止**（rubber-band，越界不外溢） |
| 磁贴 | **圆角正方形菜品大图**（`aspect-ratio: 1`，圆角 `--radius-card`）；**纯图、无文字浮层**；图位加载中 / 失败 / 为空走 `ImagePlaceholder` |
| 排布 | **错位方格密铺**：固定网格（行优先）+ 奇偶行水平错位半格，磁贴 240rpx、网格步长 300rpx（净距约 `60rpx`）；**每载入把菜品随机分配进固定格子**（结构可预测、落点每次新鲜），无食堂成簇 / 权重 |
| 首屏 | 首屏**居中于世界几何中心**，进入即见地图中心区 |
| 缩放 | 双指捏合**放大 / 缩小**；范围与阻尼由端上定（缩放态下磁贴不重排） |
| 平移 | 单指拖拽**平移**，松手**带惯性**（按松手速度衰减） |

## 3 · 底部弹窗（DishSheet · 点磁贴唤起）

| 部件 | 口径 |
|---|---|
| 容器 | 半屏 peek（`--radius-modal` 顶圆角 + `--overlay-panel-bg` + `--shadow-modal`）；弹起 `--duration-slow` + `--ease-out`（无过冲，避免抬离底边露出背景）；下拉 / 点空白关闭；🔴 **无背景蒙版**（背景透明、不变暗、不加滤镜） |
| 大图 | 顶部菜品大图（圆角 `--radius-card` + **极细浅棕描边** `1rpx --border-color`），失败走 `ImagePlaceholder` |
| 信息区（第 1 页） | **两行大字、无横线**：第 1 行左「菜品名 + 档口名」（同 `--font-title`、间距分隔、超长省略），右点赞 `heart` 40rpx + 数字 `--font-title`；第 2 行左「餐厅名 + 楼层」（同 `--font-title`、间距分隔，楼层空只显示餐厅名），右 `flag` 图标 22rpx +「纠错」（`--font-subtitle`、热区缩小、右下错开）；🔴 **不展示价格** |
| 点赞 | **文字化两态点赞**：`heart` 图标 40rpx（已赞实心 `heart-fill` + `tone="primary"`，未赞 `tone="default"`）+ 数字紧贴右侧（`--font-title`）；🔴 **无白底胶囊 / 无圆框**、同色系棕色；与菜名基线对齐；点即 toggle 并有 Q 弹（见 [B1](../../func/client/B-轻量反馈/B1-点赞反馈.md)） |
| 纠错（信息区切换） | 第 1 页第二行右侧「纠错」；点击或**左滑** → 信息区整体以 `--duration-slow` + `--ease-bounce` **向左滑**，第 2 页（反馈）**从右侧进入**，露出 3 枚纯色圆角按钮（信息错误 / 图片不对 / 已停售关闭）+「返回菜品信息 ›」；点返回 / 右滑 / 点大图 → 回到第 1 页；点按钮 → 轻确认卡片 → 提交并轻 Toast、自动回到第 1 页（见 [B2](../../func/client/B-轻量反馈/B2-菜品纠错.md)）。🔴 **无分割线**，用间距分层 |
| 交互 | **无长按**（全页无長按手势）；信息区横向切换（左滑进反馈 / 右滑回菜品信息）仅作用于图文信息区，大图与画布不受影响 |

## 4 · 手势规格（Apple 式物理感）

| 阶段 | 口径 |
|---|---|
| 平移 | 单指拖拽跟手；松手**惯性衰减**（速度 × 阻尼系数）；接近 / 越过边界时**弹性回弹**（rubber-band，不硬停、不外溢） |
| 缩放 | 双指捏合；以双指中点为锚缩放；范围限幅（最小 / 最大缩放比由端上定） |
| 点击判定 | 位移 < 阈值（端上定，建议 ≤ 10rpx）且时长 < 阈值 ⇒ **点击磁贴**唤起弹窗；否则判为平移 / 缩放手势，避免误触 |
| 动效 | 过渡轻柔低速、`--ease-out`；🔴 **尊重 `prefers-reduced-motion: reduce`**：惯性 / 弹性 / 缩放过渡降级为即时，无弹跳闪光 |

## 5 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | 暖奶油 `--bg-page`（`#FFF7E8`） |
| 磁贴 | 圆角正方形 `aspect-ratio: 1` + 圆角 `--radius-card`(44rpx)；错位密铺、磁贴 240rpx、净距约 `60rpx`；图直接落在 `<image>` 上（原生 `<image>` 不吃父级 `overflow` 裁切） |
| 弹窗面板 | `--overlay-panel-bg` + `--radius-modal`(56rpx) 顶圆角 + `--shadow-modal`（贴纸式）；`padding-bottom: env(safe-area-inset-bottom)` |
| 点赞按钮 | **文字化**：`heart` 40rpx（已赞 `heart-fill`）与数字（`--font-title`）基线对齐、同色系棕色，**无底色无胶囊**；已赞 `--color-primary-text` |
| 纠错入口 | 第二行右侧 `flag` 22rpx +「纠错」`--font-subtitle`；热区缩小、右下错开、与点赞拉开垂直间距 |
| 纠错按钮组 | 反馈页横向 3 枚纯色圆角按钮（`--color-primary-soft` 底 + `--text-title` 字 + `--radius-btn`，高 `--tap-target-size`、文案 `--font-subtitle`）；无渐变、无发光 |
| 分割线 | 🔴 信息区**不设横线**，层级由字号 / 间距承担 |
| 主色 | 暖橙 `--color-primary` 仅用于**选中态**（已赞图标）与**关键 CTA**（纠错确认「提交」按钮），装饰性一律不用 |
| 字体 | 标题 / 菜名 / 餐厅 / 楼层均无衬线圆体（`--weight-regular`，不靠加粗）；辅助信息无衬线圆体 |

## 6 · 边界与状态

| 场景 | 表现 |
|---|---|
| **首屏加载** | 画布区居中 `PageLoading`（64rpx `arrows-clockwise` 慢速旋转、`muted`、主题跟随；不整页覆盖） |
| **加载失败** | 画布区只渲染 `RetryBlock`（点此重试），不渲染磁贴 |
| **空态** | 🔴 **不处理**（无 EmptyBlock；零在售菜品时画布留白，无提示无按钮） |
| **图片失败 / 缺失** | 磁贴图位走 `ImagePlaceholder`（§1.9） |
| **点赞 / 纠错提交** | 轻 Toast（3s 消失），弹窗不自动关闭 |
