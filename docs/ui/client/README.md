## 导航结构

🔴 **TabBar 固定底部**，五项：**发现** ｜ **菜谱** ｜ **添加** ｜ **提问** ｜ **设置**。

### TabBar 显示名 ↔ 文档名对照

| TabBar 显示名 | 页面文档 | 归属功能 |
|---|---|---|
| **发现**（Discover） | [档口海报.md](./档口海报.md) | [A1](../../func/client/A-浏览与发现/A1-档口海报.md) |
| **菜谱**（Recipes） | [推荐菜品.md](./推荐菜品.md) | [A2](../../func/client/A-浏览与发现/A2-推荐菜品.md) · [A3](../../func/client/A-浏览与发现/A3-食堂筛选.md) · [B1](../../func/client/B-轻量反馈/B1-品尝标记.md) |
| **添加**（Add） | （建设中，功能 / 接口待定义） | — |
| **提问**（Ask） | （建设中，功能 / 接口待定义） | — |
| **设置**（Settings） | （建设中；内含「我的食谱」子页） | [B4](../../func/client/B-轻量反馈/B4-我的食谱.md) · [B2](../../func/client/B-轻量反馈/B2-评分反馈.md) · [B3](../../func/client/B-轻量反馈/B3-菜品纠错.md) |

> **文档名保持描述性**（`档口海报` / `推荐菜品` / `我的食谱`），**TabBar 显示名是为在底部栏里等长、齐整而另起的名字** —— 二者刻意不同，改动显示名**不影响**库表 / 接口 / 代码。其中「我的食谱」不再独占 tab，改为「设置」内的二级页（从设置进入、可返回）。

- **唯一二级页**：「我的食谱」由「设置」进入（`navigateTo`），页内自带返回键；其余 tab 之间**不互相跳转**，全部切换只经底部 TabBar。
- 🔴 **TabBar 完整规格见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.1.1**（位置 / 高度 / 图标键 / 选中态 / 内容让位）。**五个 tab 页恒显示**，无隐切换逻辑。
- 底部胶囊让位：无滚动区的页（发现 / 菜谱）由**页面根**让出 `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`（末项 = 与胶囊的**呼吸位**）；「我的食谱」子页由**滚动区底部留白**让出同一高度。

## 页面骨架（五 tab 共用）

| 区块 | 口径 |
|---|---|
| 顶部安全区 | `max(statusBarHeight, env(safe-area-inset-top))` |
| 页头 | 左右内距 `--page-gutter`；页头**不承载业务操作**（除推荐页的食堂筛选，见该页） |
| 主内容区 | `.scroll-wrap`（`min-height: 0`）；底部留白 = `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)` |
| 底部 TabBar | **悬浮胶囊**（非沉底 bar）：底距 `--tabbar-gap + env(safe-area-inset-bottom)`、左右各留 `--spacing-md`、高 `--tabbar-height`；完整样式见 §2.1.1 |
| 页面底色 | `--bg-page` = **`#FFFDFE`**（🔴 全站统一；三个 tab 页共用） |

> 页面级视觉取值一律见 [设计变量.md](./设计变量.md)；跨页形态口径与组件规格见 [公共组件与形态基线.md](./公共组件与形态基线.md)。**页面稿只写「本页用法」，不复述基线规格。**
