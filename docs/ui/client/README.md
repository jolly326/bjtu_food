## 导航结构

🔴 **TabBar 固定底部**，三项：**风物** ｜ **美味** ｜ **记忆**。

### TabBar 显示名 ↔ 文档名对照

| TabBar 显示名 | 页面文档 | 归属功能 |
|---|---|---|
| **风物** | [风物.md](./风物.md) | [A1](../../func/client/A-浏览与发现/A1-风物.md) |
| **美味** | [美味.md](./美味.md) | [A2 美味](../../func/client/A-浏览与发现/A2-美味.md) · [A3](../../func/client/A-浏览与发现/A3-食堂筛选.md) · [B1](../../func/client/B-轻量反馈/B1-品尝标记.md) |
| **记忆** | [记忆.md](./记忆.md) | [B4](../../func/client/B-轻量反馈/B4-记忆.md) · [B2](../../func/client/B-轻量反馈/B2-评分反馈.md) · [B3](../../func/client/B-轻量反馈/B3-菜品纠错.md) |

> **文档名即页面名，与 TabBar 显示名一致**（`风物` / `美味` / `记忆`，三处同名）—— 显示名与服务端接口 / 库表解耦，**改动显示名不影响**库表 / 接口 / 代码。

- **无二级页面** —— 没有详情页；三个 tab 之间**不互相跳转**，全部切换只经底部 TabBar。
- 🔴 **TabBar 完整规格见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.1.1**（位置 / 高度 / 图标键 / 选中态 / 内容让位）。**三个 tab 页恒显示**，无隐切换逻辑。
- 底部胶囊让位：无滚动区的页（风物 / 美味）由**页面根**让出 `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`（= TabBar 容器内容区高 + 安全区，内容不紧贴容器）；记忆页由**滚动区底部留白**让出同一高度。

## 页面骨架（三 tab 共用）

| 区块 | 口径 |
|---|---|
| 顶部安全区 | `max(statusBarHeight, env(safe-area-inset-top))` |
| 页头 | 左右内距 `--page-gutter`；页头**不承载业务操作**（除美味页的食堂筛选、风物页的明暗切换，见该页） |
| 主内容区 | 记忆页滚动区 `.body`（`flex: 1` + `min-height: 0`）；底部留白 = `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)` |
| 底部 TabBar | **全宽通栏容器**底置（`bottom: 0` + `env(safe-area-inset-bottom)` 内距）；胶囊高 `--tabbar-height`、宽 = 海报卡宽、左缘与海报卡左缘对齐、容器内垂直居中；完整样式见 §2.1.1 |
| 页面底色 | `--bg-page` = **`#FFFDFE`**（🔴 全站统一；三个 tab 页共用） |
