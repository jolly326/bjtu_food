**卡片栈（Idle）—— 三层 Z 轴堆叠**

| 层 | 口径 |
|---|---|
| 上层主卡 | **卡面与页面同色、不写 `opacity`**；完整展示、居中；所有按钮可点；圆角 `--dish-card-radius`(28rpx) + 弥散软阴影 `0 8rpx 24rpx rgba(0,0,0,.06)` |
| 中层 / 下层 | **真实后续卡片**（自己的卡面与描边）：中层 `scale 0.96` + 下坠 `32rpx`，下层 `scale 0.92` + 下坠 `64rpx`；🔴 缩放围绕**底边** ⇒ 下坠量 = 真实露出量（32rpx ≈ 圆角 28rpx 的 1.1 倍，露出的是一段平坦卡边 + 圆角，不是纯圆弧）；`pointer-events: none` |
| 层数 | 🔴 **恒定三层**：真实卡按队列取前 3 张；不足 3 张时用**同卡面虚影层**补齐（无内容）⇒ 划走一张后底部永远补回一层，不会塌成两层 |
| 补位 | 划走上层 ⇒ 中层由 key 复用**从「小且低」放大上移成为上层**（`--duration-slow` 弹出感）；下层升为中层；尾部补入新卡（不足则补虚影层） |

## 2 · 交互（Drag / Release）

| 阶段 | 口径 |
|---|---|
| **Idle** | 三层真卡：上层完整（32rpx 圆角 + 弥散软阴影）、中层缩 4% 下坠 32rpx（阴影降一档）、下层缩 8% 下坠 64rpx（阴影再降一档）；只露下坠出来的卡边；下层触摸穿透 |
| **Drag** | 仅上层响应**水平**拖拽；跟手带 `0.9` 轻微阻尼；旋转 `≤ ±3°`；**垂直滑动不触发**；拖拽时「加入记忆」禁用；🔴 drag 期间**后方两层完全静止**（不跟手、不缩放）——只有顶层跟手；松手划走后两层各**升一档**（缩放 +1 档、下坠 −1 档），底层补入新卡 |
| **Release：回弹** | 位移 `< 卡宽 22%` ⇒ 沿原路回弹，**`--duration-base`**；下层恢复堆叠 |
| **Release：翻页** | 位移 ≥ 卡宽 22% ⇒ 沿拖拽方向飞出（**--duration-slow**，ease-out），派发 swipe(id)；**中层上移放大成为新的上层**，下层补位成中层，尾部补入新卡 |
| **加入记忆** | `POST /my/records`（**自动写入记忆页当日记录**）；Toast「已记录到记忆」，独立于卡片、3s 消失；撤销不走上卡按钮（去「记忆」tab 长按记录删除，未评分 / 已评分均可删） |
| **食堂筛选** | 右上角**自定义下拉框**（非原生 `picker`）：触发器展开暖白下拉面板，点选项即选中并重筛；见[基线](./公共组件与形态基线.md) §2.2 `CanteenFilter` |
| **重新浏览** | 本批卡片按**原顺序**重新入栈（无网络请求），卡片上浮淡入 |
| **随机盲选** | 重新请求一批（沿用当前食堂筛选、排除本批已出现的菜）；在途时按钮禁用；切回卡片栈时走同一入场动画 |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **首屏加载** | **加载块居中于卡片栈区域**（`PageLoading`：64rpx 图标（`muted` 不上主题色）+ 2s 匀速旋转、主题跟随夜间模式；页头标题 / 日期 / 筛选器照常显示，不整页覆盖） |
| **无菜品** | 🔴 **不用空卡片容器** —— 栈区直接渲染**统一空态块 `EmptyBlock`**（三页同一实现）：线性图标 `dish`（`64rpx`、`muted`、`opacity .55`）+ 衬线「**暂无菜品推荐**」，居中于**卡片栈区域中心**；🔴 无引导文案、无按钮；无复杂插画（**不出**重新浏览 / 随机盲选）。🔴 与风物 / 记忆页空态同一套语言（细线图标 + 衬线标题） |
| **流末尾** | 本批全部划完 ⇒ 同卡位换成「今天的推荐就到这里」+ 两个动作按钮 |
| **随机盲选无新菜** | 退回本批过滤前的结果；若仍为空（该食堂无菜）⇒ 走「无菜品」空态 |
| **数据首次到达** | 第一张卡片从栈位上浮淡入 |
| **加载失败** | **保留 hero（标题 + 日期 + 筛选器）**，内容区只渲染 `RetryBlock`（点此重试）并在 hero 下方区域**竖直居中**（三页同构基准），不渲染卡片栈 |
| **食堂筛选为空集** | 同「无菜品」 |
| **评级待评** | 投票人数 < 3 ⇒ 左上**不渲染字母**、右上第二行为「待评」 |
