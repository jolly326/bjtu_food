## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | — |
| 2 | **顶部信息区块（通栏矩形）** | 左：衬线**大标题「美味」**（加粗）+ 下方小号日期（`10月18日 星期六`）；右：**食堂筛选下拉**（轻量化，不抢视觉重心） | 标题 `--font-hero`(64rpx) + `--weight-medium` + `--text-title` + 衬线（与风物页标题字重统一）；日期 `--font-small` + `--text-tertiary`；左右 `--page-gutter` |
| 3 | **Z 轴堆叠卡片栈** | **恒定 3 层纸片堆叠**：顶层完整卡（最宽）+ 后方两层**依次收窄并向上错位**；水平拖拽翻页；**整卡作为页面主容器**；三层堆叠在信息区块与 TabBar 容器之间**垂直居中** | 栈槽左右 `--page-gutter`(32rpx) 对称；卡片规格见 [基线](./公共组件与形态基线.md) §2.2 `DishSwipeCard`，堆叠口径见 §2.2 `DishCardStack` |
| 4 | 底部 TabBar | 三项 | 见 [基线](./公共组件与形态基线.md) §2.1 |

**卡片栈（Idle）—— 一叠纸片，非每卡自带多层纹路**

| 层 | 口径 |
|---|---|
| 顶层 | **卡面与页面同色（无白卡感）、不写 `opacity`**（不能透出下层）；**宽度最大**，完整展示、居中；所有按钮可点 |
| 第二 / 三层 | 依次**收窄**（`scale 0.96` / `0.92`）并**向上错位 10 / 20rpx** —— 从顶层卡上方露出层叠纸边；🔴 **不透明、无边缘虚化**，立体感仅由**宽度差异 + 上移位移 + 卡面柔和浅阴影**承担；圆角与顶层统一 |
| 补位 | 队列尾部不足 3 张时，空位渲染**纸片虚影**（同卡面轮廓 + 阴影、无内容）—— 页面内**恒定维持 3 层堆叠视觉** |
| 下层交互 | `pointer-events: none`（触摸穿透、不可点） |

**卡片流末尾空态（本批划完才出现）**

| 部件 | 口径 |
|---|---|
| 承载 | 与栈卡**同卡面**（同卡位、同描边 / 圆角 / 吊孔），整卡一块，居中纵向排布 |
| 标题 | **「今天的推荐就到这里」**——`--font-h2` + `--weight-semibold` + `--text-title` + 衬线 |
| 副文案 | 「都看完啦，换种方式再来一轮」——`--font-small` + `--text-tertiary` |
| 动作按钮 | **两个等宽线性按钮并排**（间距 `--spacing-md`，各 `flex: 1`）：**重新浏览**（`refresh-cw`，中性灰描边）｜**随机盲选**（`shuffle`，暖橙描边）；高 `--tap-target-size`、圆角 `--radius-btn`、图标 `28rpx` 在文案左侧 |
| 出现时机 | **仅当本批卡片全部划完**；正常滑动阶段不渲染；首屏无菜品走「无菜品」空态，**不出现**这两个按钮 |

**单卡内容（自上而下）**

| 部件 | 口径 |
|---|---|
| 顶部吊孔 | 卡片上沿**中线**小圆镂空，直径 `--spacing-xl`(40rpx)；`1rpx` `--border-color` 圆环 + 环内填 `--bg-page`；🔴 **完全约束在卡片边框内部**（不溢出上边界） |
| 顶部左右信息位 | **绝对定位** `top: --spacing-2xl`(48rpx)、左 / 右 `--spacing-xl`(40rpx)，作**卡片背景层**（z-index 低于内容层）；**左 = 大号浅灰等级字母水印**（`calc(--font-hero + --font-display + --spacing-md)` 136rpx + `--weight-bold` + `--text-tertiary` + `opacity .45`，衬线，不遮挡上层内容）；**右 = 风味评级两行、整体右对齐**（标签小字 + 档位词 `--font-title` 40rpx + `--weight-bold`，全衬线）；见[基线](./公共组件与形态基线.md) §2.2 `FlavorRating` |
| 圆形菜品图 | `--dish-photo-size`(420rpx) **圆形**（`--radius-circle`）；🔴 圆角须**直接落在 `<image>` 上**；**上方留白加大、不贴卡片顶部**（图片上缘到吊孔预留 `--spacing-2xl × 2 + --font-hero`，内容整体居中排布）；空 / 失败走 `ImagePlaceholder`(48rpx) |
| 菜名 | **`--font-hero`(64rpx) + `--weight-bold` + `--text-title` + 衬线**（加粗放大，卡片主标题）；居中；最多 2 行；与图间距 `--spacing-xl`(40rpx) |
| 价格 · 食堂/档口 | **整行无衬线正文档**：`¥38.00 · 食堂\|档口` —— `--font-sans` + `--font-body`(26rpx) + `--weight-medium` + `--text-body`（中度深灰，阅读清晰但不抢菜名重心）；居中；与菜名间距 `--spacing-lg`(32rpx) |
| 去品尝按钮 | **胶囊描边（无图标）**：细橙描边 + 暖白填充（`--bg-page`）；圆角 `--radius-btn`（小幅度柔和圆角，非全圆）、高 96rpx；与价格行间距 `--spacing-xl`(40rpx)，**按钮下留白 `--spacing-2xl`(48rpx) —— 不贴卡片底边** |

- **卡表面（Julienne 纸片卡，单层）**：填充 **`--bg-page`**（与页面同色 ⇒ 无白卡、融于页面；同时不透明，挡住所下层卡片）+ `1rpx` `--border-color` 细描边 + `--radius-card`(36rpx) + **`--shadow-card-stack` 低透明柔和浅阴影**（悬浮轻盈感；🔴 禁高对比深色阴影）；🔴 **无自带多层纹路** —— 层叠立体感由**卡片栈三层堆叠**与**顶部吊孔**承担。
- **卡内距**：上 `--spacing-2xl`(48rpx)、左右 `--spacing-xl`(40rpx)、下 `--spacing-2xl`(48rpx)。
- **页面间距**：三层堆叠整体在顶部信息区块与 TabBar 容器之间**留白均衡**（垂直居中，消除偏上）。
- 内容水平居中、纵向按上表节奏排布；不溢出卡片。

## 2 · 交互（Drag / Release）

| 阶段 | 口径 |
|---|---|
| **Idle** | 顶层完整（宽度最大）；后方两层收窄上移、**不透明无虚化**；下层触摸穿透 |
| **Drag** | 仅顶层响应**水平**拖拽；跟手带 `0.9` 轻微阻尼；旋转 `≤ ±3°`；**垂直滑动不触发**；拖拽时「去品尝」禁用；后方两层同步放大归位 |
| **Release：回弹** | 位移 `< 卡宽 22%` ⇒ 沿原路回弹，**`--duration-base`**；下层恢复堆叠 |
| **Release：翻页** | 位移 `≥ 卡宽 22%` ⇒ 沿拖拽方向飞出（**`--duration-slow`**，`ease-out`），派发 `swipe(id)`；**剩余两层向上小幅上移**，尾部补入新卡（队列有货）或纸片虚影（恒定 3 层） |
| **去品尝** | `POST /my/records`（**自动写入记忆页当日记录**）；Toast「已记录到记忆」，独立于卡片、3s 消失；已品尝 ⇒ `DELETE /my/records/{id}`（仅未评分可撤销） |
| **食堂筛选** | 右上角原生 `picker`；选中即重筛 |
| **重新浏览** | 本批卡片按**原顺序**重新入栈（无网络请求），卡片上浮淡入 |
| **随机盲选** | 重新请求一批（沿用当前食堂筛选、排除本批已出现的菜）；在途时按钮禁用；切回卡片栈时走同一入场动画 |

| 项 | 取值 |
|---|---|

| 卡片表面 | `--bg-page` 填充（同页面色）+ `1rpx var(--border-color)` + `--radius-card`(36rpx) + **`--shadow-card-stack` 低透明柔和浅阴影**（悬浮感）；无自带多层纹路；顶部吊孔（卡内） |
| 栈槽 | 左右 `--page-gutter`(32rpx) 对称；三层堆叠在信息区块与 TabBar 容器间垂直居中 |
| 卡内距 | 上 48rpx / 左右 40rpx / 下 48rpx |
| 去品尝按钮 | `--radius-btn` · 高 `calc(--tap-target-size + --spacing-xs)` · **无图标** · 左右留白 `--spacing-xl` |
| 圆形图 | `--dish-photo-size`(420rpx)；上方预留 `--spacing-2xl × 2 + --font-hero`（下移不贴顶） |
| 菜名 | `--font-hero`(64rpx) + `--weight-bold` 衬线 |
| 副标题行（价格 · 食堂｜档口） | `--font-sans` + `--font-body`(26rpx) + `--weight-medium` + `--text-body`（中度深灰）；一行居中 |
| 风味评级 | 左：136rpx 加粗衬线水印字母（浅灰 `opacity .45`）；右：两行右对齐全衬线；见[基线](./公共组件与形态基线.md) §2.2 `FlavorRating` |
| 动效 | 拖拽跟手；回弹 `--duration-base`；翻页 `--duration-slow`；层叠晋升过渡 `--duration-base`；`--ease-out`；🔴 无弹跳 / 闪光 |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **首屏加载** | 栈位渲染**骨架卡**（同新卡面：吊孔 + 圆形图占位 + 淡占位块 + 底部禁用按钮）；**不启用滑出旋转** |
| **无菜品** | 栈位渲染**空态占位卡**：衬线「**暂无菜品推荐**」+ 浅灰小字「等待食堂上新美食」；表面同栈卡；无复杂插画（**不出**重新浏览 / 随机盲选） |
| **流末尾** | 本批全部划完 ⇒ 同卡位换成「今天的推荐就到这里」+ 两个动作按钮 |
| **随机盲选无新菜** | 退回本批过滤前的结果；若仍为空（该食堂无菜）⇒ 走「无菜品」空态 |
| **数据首次到达** | 第一张卡片从栈位上浮淡入 |
| **加载失败** | `RetryBlock` |
| **食堂筛选为空集** | 同「无菜品」 |
| **评级待评** | 评分条数 < 3 ⇒ 左上**不渲染字母**、右上第二行为「待评」 |
