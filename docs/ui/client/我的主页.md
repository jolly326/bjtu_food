# 我的主页 — 页面 UI 设计稿

> 所属端：学生端（微信小程序） ｜ 页面：`pages/my-reviews/index`（分包 `pages/my-reviews/`） ｜ 代码落点：`pages/my-reviews/index.vue`
> **口径分工**：**页面 UI 设计口径以本文件为唯一真源**，功能流程 / 接口 / 字段 / 数据落库口径以功能文档为准。
> 视觉口径真源：[公共组件与形态基线.md](./公共组件与形态基线.md)（形态 §一 / 组件 §二 / 身份卡 §三）· [设计变量.md](./设计变量.md)（设计变量）


- 入口：「我的」页**用户卡点击**（**游客直接进入**，无认证拦截；认证要求仅在发表 / 删除评价时给出）。
- 页面构成（自上而下，**页头 + 用户信息卡 + 评价区**）：`AppHeader`（标题「**我的主页**」+ **返回**（文字））→ **用户信息卡** → **评价区**（区块标题「我的评价」+ 本人评价列表）。
- 滚动承载：页根定高 + **`scroll-view`（`flex: 1`）** 承载内容，触底由滚动区 `@scrolltolower` 触发评价列表加载更多（页面自身不滚动，`onReachBottom` 不触发）；底部留 `env(safe-area-inset-bottom)` 安全区留白。二级页，**无 TabBar**。

### 1. 用户信息卡

- 形态：**暖奶米半透一级内容块**（`CardSection` 壳：`--module-bg` + `--radius-card` + `--module-shadow`），顶部 **6rpx 主色软条纹**（`--color-primary-soft`，**仅认证态着色**；游客态 transparent 占位 ⇒ **两态等高**）。
- 内容与排版参数（头像 / 主行 / 副行 / 右侧动作位）**以 [README §身份卡](./公共组件与形态基线.md#三跨页版面身份卡用户信息模块) 为唯一真源**；本页差异仅两处：① 右侧动作位 = 「**编辑个人信息**」描边胶囊（「我的」页为 `arrow`）；② 信息块为**独立一级内容块**（`CardSection` 壳通栏；「我的」页为模块 A 内第 1 段）。
- 实现：卡壳 = `CardSection`（`flush` + 内距归零 + `overflow: hidden` 裁条纹），身份版面 = 公共组件 `IdentityCard`（`mode="edit"`，基线 §2.17）；本页**不持有**身份版面样式。
- 交互：**胶囊为唯一热区**（`role="button"`、`aria-label="编辑个人信息"`），点击 → 个人信息编辑页 `pages/profile/index`（见 [个人信息编辑.md](./个人信息编辑.md)）；**卡片本体不可点**（避免与编辑入口语义重叠）。按压反馈 = `--bg-soft` 底色（**非** scale）。
- **「编辑个人信息」胶囊仅认证态渲染** —— 编辑身份信息是认证态才具备的能力，游客态不渲染任何动作位；认证动作**单一入口 = 「我的」页宫格「身份认证」格**，信息卡不放「去认证」按钮。

### 2. 评价区

- **区块标题「我的评价」仅在评价列表有数据时渲染**（`SectionTitle` 组件）；列表无数据时**标题与列表卡一并不渲染**，评价区整体退化为空态（三种空态的区分见 §3「空态」表）。
- 评价卡复用**公共组件 `ReviewItem`**（与菜品详情评价区**同一实现**，视觉与交互完全一致：头像 / 昵称 / 星级 / 正文 / 配图网格 / 时间 / 右上角三点），本人视角专属信息经组件可选 props 注入；**本页以 `flat` 模式嵌入单张列表卡**（`CardSection` 壳：`--module-bg` + `--radius-card`（20rpx）+ `--module-shadow`），评价行之间以 `1rpx` `--border-color` 分隔线分隔（最上 / 最下无线）——**与系统通知页同语言**：
  - **头像 / 昵称的数据来源**：`MyReviewVO` 不含作者字段（本人视角恒为本人），组件在 `mine` 模式下取**当前登录用户资料**（`userStore.userInfo`）渲染头像与昵称 ⇒ 两视角**版式完全一致**；资料未回填时回落头像占位 + 「用户」昵称。
  - **菜名行**（`dishName`）：meta 行下展示关联菜品名，辨识是哪道菜的评价。
- 删除链路（与菜品详情评价区同款）：卡片右上角**三点** → 底部 `ActionSheet`「删除评价」（危险红动作项）→ **二次确认**弹窗 → 调 `DELETE /reviews/{id}`，成功后卡片本地移除；**删空列表后区块标题随之下线**，评价区退化为 §3 表中的「认证态 · 删除清空」空态（说明文案变为「去菜品详情写一条吧」）。
- 分页：上滑触底加载更多（**时间倒序**，唯一排序、无切换）；加载中**不呈现骨架屏**。
- 失败态：列表区渲染 `RetryBlock`「加载失败 · 点击重试」。

### 3. 空态（评价区）

| 状态 | 呈现 |
|---|---|
| 游客态（未认证） | **无底色居中空态**（`EmptyState card` 变体 = 仅放宽内距）：`comment` 图标（`64rpx`、`--text-tertiary`）+ 主标题「暂无评价」+ 说明「完成身份认证后可发表评价」（图标→标题 `--spacing-sm`、标题→说明 `--spacing-xs`）+ **CTA「去认证」**（跳认证页） |
| 认证态 · 无评价（**从未发表 / 删除最后一条 同为此态**） | 同上无底色居中空态，说明为「去菜品详情写一条吧」+ **CTA「去找一道菜」**（切到首页 tab）；两态合一，**页面不区分「删空」** |

> **渲染优先级**：加载失败（`RetryBlock`）> **在途（轻量文字行「加载中…」）** > 空态 > 评价列表。
> **空态必须显式（禁静默）**；**判据须待首屏返回后**（`loaded` 为真且 `records` 为空才渲染空态），在途期间只渲染文字行 —— 否则用户会看到空态一闪而过又被数据替换。

### 4. 展示内容口径（派生值）

| 展示项 | 来源 | 说明 |
|---|---|---|
| 头像 | `UserInfoVO.avatar` | 信息卡头像（120rpx 圆形）；无值时 → `ImagePlaceholder name="user"`（灰底 `--bg-placeholder`） |
| 昵称 | `UserInfoVO.nickname` | 信息卡主行（**直接渲染后端昵称、端上不做兜底**：后端保证非空，新游客号默认「食客 + ID 尾 4 位」） |
| 绑定邮箱 | `UserInfoVO.bindEmail` | 认证态信息卡副行（**本页渲染完整邮箱**；「我的」页用户卡同样渲染 `bindEmail`，两页同源同字符串；`username` 已移出出参）。非副行的**只读展示**见 `个人信息编辑.md` |
| 游客态副行 | **端内静态文案**「未完成校园认证」 | 游客态信息卡副行（不派生内部编号） |
| 认证态判据 | `bindEmail` 非空（单点收敛） | 决定信息卡条纹**着色**、副行内容与「编辑个人信息」胶囊显隐 |
| 本人评价列表 | `GET /my/reviews` 的 `PageResult<MyReviewVO>`（**分页壳仅 `records` 一项**，`MyReviewVO` 字段口径见功能文档） | 评价区数据源；分页结束判据 = 本页返回条数 < `pageSize`（`PageResult` 不回传 `total`，端上不读总条数） |

### 4.1 间距与留白

| 位置 | 间距 |
|---|---|
| `AppHeader` 底部 → 用户信息卡顶部 | `--spacing-lg` |
| 用户信息卡**内部排版**（头像 / 主副行 / 内距 / 右侧动作位） | 见 [README §身份卡](./公共组件与形态基线.md#三跨页版面身份卡用户信息模块)（跨页唯一真源） |

| 评价卡片内部上下内边距 | `--spacing-lg` |
| 空态图标 → 主标题 | `--spacing-sm` |
| 空态主标题 → 辅助文案 | `--spacing-xs` |
| 页面底部 | `env(safe-area-inset-bottom)` |

### 5. 动效

- `prefers-reduced-motion: reduce` 下取消胶囊行的 `background-color` 过渡（按压反馈退化为**直接换色**）。
- 不引入装饰性入场动效；进入页面内容立即可见。

### 6. 接口数据字段（UI 精修用）

**页面**：`pages/my-reviews/index`（分包 `pages/my-reviews/`；二级页，**无 TabBar**）

#### 组件清单（本界面需要哪些组件）

> 组件自身规格（尺寸 / 圆角 / 颜色 / 状态 / 交互）以 [公共组件与形态基线.md](./公共组件与形态基线.md) §二 为唯一真源；**本表只写「本页用法」**。

| # | 组件 | 在本页做什么 |
|---|---|---|
| 1 | `AppHeader` | 页头：居中标题「我的主页」+ 返回（`@back` → `backToHome`） |
| 2 | 头像渲染范式（基线 §1.15） | 信息卡头像：由 `IdentityCard` 自持（定尺圆盒 + 原生 `<image>` + `@error` 回退 `ImagePlaceholder name="user"`，禁裂图） |
| 3 | `ImagePlaceholder` | 无头像时的 `user` 占位；**本页不自绘占位** |
| 4 | `ReviewItem` | 评价卡（`flat` 模式，与菜品详情评价区同一实现）；本人视角专属菜名经 `dish-name` prop 注入；`@more` 上抛三点动作；嵌入单张列表卡（`CardSection` 壳） |
| 5 | `ActionSheet` | 三点菜单「删除评价」（危险红动作项） |
| 6 | `RetryBlock` | 首屏加载失败「加载失败 · 点击重试」 |
| 7 | 信息卡 `.profile-strip` / 区块标题（页内内联） | 头像 + 主行 / 副行 +（**仅认证态**）「编辑个人信息」胶囊（内容与排版见 [基线 §三](./公共组件与形态基线.md)）；「我的评价」标题（**有数据才渲染**） |
| 8 | 评价列表卡（**基线 §2.1 `CardSection` 壳**，不另起壳；行间分隔线口径见基线 §1.9） | 单张列表卡（`CardSection` 壳，暖奶米半透 `--module-bg`）收纳全部评价行；行间 `1rpx` `--border-color` 分隔线（首末无线） |
| — | 自然文档滚动（`onReachBottom`）+ `uni.showModal` | 触底分页 + 删除二次确认 |

#### 有哪些数据要显示、显示在哪个组件

| # | 数据（字段） | 来源 | 中文含义 | 显示在哪个组件 | 呈现位置 / 形式 |
|---|---|---|---|---|---|
| 1 | `avatar` | `UserInfoVO`（`stores/user`，源自登录 / `GET /auth/profile`） | 头像地址 | 信息卡头像位 | 120rpx 圆形；空 / 失败 → `ImagePlaceholder name="user"`（灰底 `--bg-placeholder`） |
| 2 | `nickname` | 同上 | 昵称 | 信息卡主行 `.strip-nickname` | **直接渲染后端返回值**（后端保证非空）；**端上不兜底、不替换为「游客」** |
| 3 | `bindEmail` | 同上 | 绑定校园邮箱 | 信息卡副行 `.strip-sub`（**认证态**） | 空值回落 `--` |
| 4 | 游客态副行 | **端内静态文案**（非接口数据） | 游客身份状态 | 信息卡副行（**游客态**） | 恒「未完成校园认证」 |
| 5 | `bindEmail` 非空 | 同上 | 认证判据（单点收敛） | 信息卡顶部**条纹着色** `.is-verified` + 「编辑个人信息」胶囊显隐 | 非空 = 已认证 |
| 6 | `records[].id` | `GET /my/reviews`（`PageResult<MyReviewVO>`） | 评价 ID | `ReviewItem` 列表 `key` / 删除目标 | 零可见 UI |
| 7 | `records[].dishName` | 同上（本人视角专属） | 关联菜品名 | `ReviewItem` 菜名行 `.review-dish` | 次级加粗小字，单行省略 |
| 8 | `records[].rating` | 同上 | 评分 | `ReviewItem` 星级行（1~5 实心黄星 + 数值） | 1 位小数 |
| 9 | `records[].content` | 同上 | 评价正文 | `ReviewItem` 正文 | 二级灰，`pre-wrap` |
| 10 | `records[].images` | 同上 | 评价配图（≤3） | `ReviewItem` 配图网格 | 3 等分小方图，点击预览；破图 → 统一占位 `ImagePlaceholder` |
| 11 | `records[].createdAt` | 同上 | 发表时间 | `ReviewItem` meta 行 | `formatDate`（仅 `YYYY-MM-DD` —— 评价条目口径随 `ReviewItem` 全站统一） |
| 12 | （**不出参**） | 同上 | 本人昵称 / 头像 | `ReviewItem` **不渲染**头像与昵称位（本人视角变体，见 [B2](../../func/client/B-UGC表达与治理/B2-我的评价.md)） | 零可见 UI |
| 13 | （**不出参**） | 同上 | 评价者 ID | **不做 `userId` 比对** —— 本人视角恒为本人，三点菜单**恒显**「删除评价」 | 零可见 UI |
| 14 | `records[].dishId` | 同上 | 关联菜品 ID | **零界面消费**（字段保留；详情页无「是否已评价」判定，故不用于过滤请求） | — |
| 15 | `records`（**分页壳唯一字段**） | 分页壳 | 当前页评价行数组 | 列表渲染 + 触底加载更多（时间倒序） | 端上以 `records` 为准；分页壳**不回传 `total`**，结束判据 = 本页条数 < `pageSize` |
| 16 | 空态 / 失败态 | 端上 `isGuest` / `loadFailed` | 空 / 失败 | 空态 `EmptyState`（游客「暂无评价，完成身份认证后可发表评价」+「去认证」/ 认证态「暂无评价，去菜品详情写一条吧」+「去找一道菜」）· `RetryBlock` | 失败 > 在途 > 空；游客**无认证拦截** |

**控件类型**：自然文档滚动（`onReachBottom` 分页）、`ActionSheet` 底部动作菜单、`uni.showModal` 删除二次确认、胶囊行热区（`pressed` = `--bg-soft`，非 scale）
