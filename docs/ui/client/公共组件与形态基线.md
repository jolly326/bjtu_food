## 0 · 设计语言（Q 版动森（圆润厚实 · 轻拟物））

> 适用：**学生端全部页面与组件**。所有 UI 产出严格遵循本节；页面稿只写「本页用法」，不复述本节。

> **双主题（浅色 / 深色）**：本节与各组件规格以**浅色主题**为基准描述；深色为同键换值的第二组色板（**低饱和夜色：深灰蓝底 `#2B3A4A` + 冷调奶白字 + 晚霞橙主色**，🔴 不做纯黑），取值与主题机制见 [设计变量.md](./设计变量.md) §1.2；组件规格**不随主题分叉**（组件不感知主题，只消费语义变量）—— 两套主题共用同一套**形态语言**（圆角 / 描边宽度 / 动效一致），只换色温与明度。

- **关键词**：动森风 / 奶米纸色 / 深棕 / 纯文字入口 / 手绘细描边 / 短横线虚线 / 柔和回弹 / 规整网格画布 / 图片优先 / 全屏沉浸。
- **底色与色彩**：页面奶米纸色 `--bg-page` `#FFFAF3`；主文案深棕 `--text-title` `#44382E`；可读辅助浅棕 `--text-body` `#75665A`；`--color-muted` `#8C7B6B` 仅箭头 / 装饰；主色暖橙 `#FF8A4C` 仅用于非 sheet 品牌 CTA；sheet 内一切可点项统一为**纯文字**（无底色、无边框）。
- **字体**：标题 / 菜名 / 弹层标题用**无衬线圆体**（`--font-sans`）；参数型辅助信息、按钮文案、弹层选项用**无衬线圆体**（`--font-sans`）。字号差距清晰，拒绝信息堆砌。
- 🔴 **字重规则（Q 版动森）**：**所有无衬线圆体标题一律 `--weight-regular`** —— 层级由**字号 + 颜色**承担，**不靠加粗**；唯一例外：无衬线圆体状态标签（如失败态标题）。
- **图片优先**：美食地图以**菜品大图**为绝对主体，磁贴纯图、无文字浮层，回归「看图定夺」的极简本质；弹窗面板为**奶米色面板**（`--overlay-panel-bg` + `--radius-modal` + 顶部细描边）。
- **按钮**：🔴 **Sheet 内一切可点项（反馈选项 / 分页导航 / 纠错入口 / 确认气泡操作）一律为纯文字** —— 无底色、无边框、无胶囊；主操作只靠文字颜色区分（`--text-title` 深棕 vs `--text-body` 浅棕）。
- **光影**：🔴 **全局无阴影** —— 层级只靠底色、描边、圆角与留白区分，不画投影、不用渐变。
- **图标**：统一 **Streamline Plump 黑色轮廓 SVG**（`AppIcon`，`stroke: #000000` + 无填充，不上色）；`heart` 空心（未赞）/ `heart-on` 实心（已赞）；圆润粗胖、不混用图标字体。
- **页面分层**：前景 = 全屏可平移缩放的菜品地图画布 → 底层固定弹窗层（点击磁贴升起半屏 Sheet）。无 TabBar / 无全局顶栏。
- **空态**：🔴 **美食地图不处理空态**（零在售菜品时画布留白，无提示无按钮）；首屏加载 / 加载失败仍走 `PageLoading` / `RetryBlock`。

- **加载 / 失败**：
  - **加载中**：`PageLoading`；`loading` 图标 `56rpx`、`opacity 0.55`、匀速旋转；文案 `--font-h3` / `--weight-regular` / `--text-title`；父容器 `flex: 1` + 居中。
  - **失败块**：`RetryBlock`；与加载中**共用 `StatusBlock` 骨架**（`warning` `56rpx` + 文案 `--font-h3` / `--weight-regular` / `--text-title`），`gap: --spacing-xs` + `padding: --spacing-xl --spacing-lg`。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` = **`#FFFAF3`**（奶米纸色，🔴 全站统一；深色主题取值见 [设计变量.md](./设计变量.md) §1.2）—— **唯一承载处**；页面根 / 组件 **SHALL NOT** 再声明页面底色 |
| 主题（明暗） | **全站双主题**：页面根挂 `data-theme="light"｜"dark"` 切换语义色组；默认浅色、storage 持久化；深色取值与完整机制见 [设计变量.md](./设计变量.md) §1.2 |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；画布页根须再加 `min-height: 0`（否则页根比可视区高出一截） |
| 顶部安全区（**含胶囊**） | 自定义导航栏（`navigationStyle: custom`）下，画布内容起始 = **状态栏高度 + 导航栏高度**：状态栏高（`statusBarHeight`）覆盖刘海 / 挖孔屏；导航栏高由 `uni.getMenuButtonBoundingClientRect()` 与状态栏高算出 —— **保证顶部内容不被右上角胶囊重叠**（实现见 `client/src/utils/safeArea.ts`） |
| 底部安全区 | 画布底部留白须叠加 `env(safe-area-inset-bottom)` |

## 1.2 圆角 / 线宽

- 分档：模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`（卡 / 弹层 / 胶囊三档，见 [设计变量.md](./设计变量.md) §2.1）。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `1rpx`（描边 / 分隔线）；`2rpx` 只留给语义状态线（选中 / 聚焦，配主色）。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-2xs`(4) → `--spacing-2xl`(48)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-subtitle`(26) → `--font-body`(28) → `--font-h3`(32) → `--font-h2`(36) → `--font-title`(40)；**正文级字号下限 `24rpx`，常规辅助文本取 `--font-subtitle`(26rpx)**。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`。

## 1.4 色彩 / 光影

- 色板与取色边界（主色语义分档、文字四档、背景 / 边框 / 语义色 / 对比度口径）见 [设计变量.md](./设计变量.md) §1（**含 §1.2 深色组**）。
- **色值只改 `tokens.ts` 的 `COLOR_MAP`**（分浅色 / 深色两组）；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；🔴 **全局无阴影** —— 弹层 / 面板 / 卡片靠 `1rpx` 细描边与圆角区分。

## 1.5 表面：面板

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块，区块之间**只靠页面留白分组**。
- **弹窗面板只有一套取值**：奶米色面板 = `--overlay-panel-bg` + `--radius-modal`(56rpx) + 顶部 `1rpx` 细描边（规格见 §2.2 `DishSheet`）。
- 页面 / 组件私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 描边一律取已登记形态** —— SHALL NOT 另立新取值。
- 长文本断行唯一写法 = `overflow-wrap: anywhere`。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-placeholder`）；点赞用 `scale(.96)` 按压回弹（唯一 `scale` 例外）。`opacity` 只三档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 ｜ **`.85`** 主色实底 CTA — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 两档：① **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-disabled`；② **非主色可点件** ⇒ `opacity: .5`。Sheet 内文字入口置灰 = 文字取**暖灰棕 `--text-disabled`**（🔴 不用冷灰、不用灰度滤镜），无按压反馈；禁点由组件 `disabled` 守卫承担。 |
| 触达下限 | 可点元素命中区 **≥96rpx（48pt，`--tap-target-size`）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(140) / `--duration-base`(240) / `--duration-slow`(420) + `--ease-out`；**不新增装饰性入场动效**（内容一律立即可见）；`prefers-reduced-motion: reduce` 下过渡取消、旋转环减速。
- 层级：`--z-sheet`(2000)。
- 高度：`--tap-target-size`(96rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；图标资源**一律下载**（Streamline Plump · Flat，CC BY 4.0），几何**不自行绘制**，**只提取图形轮廓**（去彩色填充、统一黑色描边）—— 资源清单与获取流程见 [图标资源.md](./图标资源.md)。规格：`48` 网格、`fill: none` + `stroke: #000000`（宽 2）。图标**只用这一套**，SHALL NOT 混入其它图标库 / 图标字体 / emoji。
- **配色口径**：图标一律**黑色轮廓**（`stroke: #000000` + 无填充），**不做彩色填充 / 上色**。

- **选中态用独立键**：点赞未赞 = `heart`（浅杏主体 + 棕细节），已赞 = `heart-on`（整体深棕 `#8C7B6B`）。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认）/ 筛选触发器 ｜ `32` 伴随标题 ｜ `40` 卡内功能图标 ｜ `48` 卡内图片占位 ｜ `56` 加载态 / 失败态（`StatusBlock` 统一档） ｜ `64` 图片占位默认 ｜ `96` 整块失败态。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键** —— 完整清单（语义 / 键 / Streamline 源文件 / 消费点）见 [图标资源.md](./图标资源.md) §3，**该表为唯一真源**，本节不复列。

> 新增用途须先在[图标资源.md](./图标资源.md) §3 找语义档；确无对应才新增并登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- **图片承载区**（菜品图位）在**加载中 / 失败 / 为空**时，一律**按该区尺寸渲染占位**（`ImagePlaceholder`）—— **不留空白、不用文字失败块**。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

## 2.0 分层与目录（强制）

> 🔴 **只有真正的跨页公共件才进 `components/`**；只有单页使用的组件一律下沉到该页面的 `components/` 下，与页面同包。

| 层 | 目录 | 判定 | 现有成员 |
|---|---|---|---|
| **公共** | `client/src/components/` | ≥2 个页面使用 | `AppIcon` · `ImagePlaceholder` · `RetryBlock` · `PageLoading` · `BaseSheet` |
| **页面私有** | `client/src/pages/map/components/` | 仅美食地图页使用 | `FoodMap` · `DishSheet`（组合器）· `DishInfo` · `FeedbackPanel`（三态） |

- **新增组件的判定顺序**：先问「是否 ≥2 页使用」——否 ⇒ 放进当前页 `components/`；是 ⇒ 进 `components/` 并在 §2.1 登记。

### 2.1.3 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`flex: 1` + 纵向居中；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **实现**：与 `PageLoading` **共用 `StatusBlock` 骨架** —— 两者图标尺寸 / 文案字阶 / 居中位置完全一致。
- **图标**：`warning`，`56rpx`。
- **文案**：`--font-h3` + `--weight-regular` + `--text-title`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 仅忽略点击（🔴 不引入旋转 loading）。
- **不改标题 / 不加按钮**。
- **适用面**：美食地图首屏整页失败态（内容区只渲染 `RetryBlock`，不渲染画布磁贴）。

### 2.1.4 `BaseSheet` —— 底部弹层原语

- **遮罩**：`--overlay-scrim`；点击空白关闭；`mask` 属性可关（`false` 时为透明、不变暗、不加滤镜）。
- **抽屉**：`--overlay-panel-bg` + `border-radius: --radius-modal --radius-modal 0 0` + 顶部 `1rpx --border-color` 细描边（🔴 无阴影）；`padding-bottom: env(safe-area-inset-bottom)`；上滑开合（`--duration-slow`）。
- **顶部压痕**：把手区高度 = 顶部 gap（`--spacing-lg`），压痕在其中**垂直居中** —— 宽 `80rpx`、高 `8rpx`、`--radius-pill`、色 `--border-color`（浅棕）、水平居中；拖动松手用 `--ease-out` 柔和回弹。
- **下拉关闭手势**：手柄区域跟手向下拖（`touchmove` 实时位移）；松手位移 > 120rpx 关闭，未超过回弹到 0；向上拖不展开。
- **本项目用法**：美食地图「菜品弹窗」（`DishSheet`）复用本原语承载详情 + 点赞 + 纠错（详见 §2.2 `DishSheet`）。
- **不引入系统 `ActionSheet`**。

### 2.1.7 `PageLoading` —— 内容区加载块

- **定位**：🔴 **非全屏遮罩** —— 由美食地图画布放进自己的**内容区**，`flex: 1` 占满剩余高度并**竖直居中**（背景透明、不改页面底色）。
- **形态**：与 `RetryBlock` **共用 `StatusBlock` 骨架** —— **居中一枚 `loading` 图标（56rpx、Plump 填充 SVG、`opacity .55`）** + `--spacing-xs` 间距的无衬线圆体文案（`--font-h3` + `--weight-regular` + `--text-title`，默认「加载中」）。
- **旋转**：🔴 **仅图标本体**以 `--duration-spin`(2000ms) 线性匀速旋转；**无外围圆环、无描边、无底色容器**。
- **主题**：🔴 **全局跟随夜间模式**。

### 2.1.8 `DashedRule` —— 短横线虚线分隔

- **用途**：信息页 / 纠错页共用的中线分隔；抽为公共组件，两页虚线口径收敛为单点。
- **形态**：`height: var(--spacing-2xs)`、上下 `margin: var(--spacing-sm)`、短横线虚线（`--sheet-divider`，线 16rpx + 空 16rpx）。
- **使用**：仅 `DishInfo` / `FeedbackPanel`。

## 2.2 新增（本设计引入）

> 逐组件登记规格；**页面稿只写「本页用法」，不复述规格**。

### `FoodMap` —— 美食地图画布（可平移 + 双指缩放 · 规整网格）

- **用途**：美食地图页唯一内容区；承载圆角正方形菜品磁贴的**规整网格平面**，支持单指拖拽平移（带惯性）、双指捏合缩放、**软边界**。
- **几何**：维护一个**内容包围盒**（所有磁贴几何边界）；平移 / 缩放作用于该盒；**软边界** —— 越界后画布仍跟手但位移被**阻尼压缩**（越界越深、跟手比例越低，接近饱和后几乎不动），松手**弹性回位**（过冲缓动），🔴 不硬停、不瞬移回位；缩放**软限位**（贴近上下限时幅度被压缩）。
- **排布**：🔴 **规整网格密铺**：固定行列**行优先**逐行铺满，**行与行不做水平错位**；每次载入菜品**随机映射到已确定的格子**（格子结构不变，只换谁坐哪格）；🔴 **不做簇**（无食堂成簇 / 食堂中心 / 固定锚位 / 权重）；磁贴尺寸统一（240rpx 边长，步长 300rpx）。
- **首屏**：落在**世界几何中心**并收敛到合法边界（不跳、不重置）；重新载入后格子结构不变。
- **磁贴**（画布内联元素，非独立组件）：**圆角正方形** `aspect-ratio: 1` + 圆角 `--radius-card`(44rpx) + `1rpx --border-color` 细描边（🔴 无阴影）；**纯图、无文字浮层**；图直接落在 `<image>` 上（原生 `<image>` 不吃父级 `overflow` 裁切）；加载中 / 失败 / 为空走 `ImagePlaceholder`（§1.9）；点磁贴 ⇒ 唤起 `DishSheet`（位移与时长都在阈值内才算点击），🔴 无长按；按压为**轻微收缩回弹**（`scale(.96)` + `--ease-bounce`）。
- **点击判定**：位移 < 阈值（建议 ≤ 10rpx）且时长 < 阈值 ⇒ 命中卡片点击；否则判为平移 / 缩放，避免误触。
- **动效**：过渡轻柔低速、`--ease-out`；🔴 **尊重 `prefers-reduced-motion: reduce`**（惯性 / 弹性 / 缩放降级为即时）。
- **重新载入**：菜品重新映射到格子 —— 格子结构恒为规整网格，**位置不散乱**。
- **双主题**：浅色 / 深色两套色板同键声明，页面根挂 `data-theme` 生效；两套主题共用同一形态语言（圆角、描边宽度、动效一致）。
- **空态**：🔴 不处理（零在售菜品时画布留白，无提示无按钮）。
- **加载 / 失败**：加载中渲染 `PageLoading`；失败渲染 `RetryBlock`；均占满内容区。
- **使用**：仅[美食地图页](./美食地图.md)。

### `DishSheet` —— 菜品底部弹窗（详情 + 点赞 + 纠错）

- **用途**：点磁贴唤起；承载单品详情、两态点赞与纠错，是美食地图的**唯一信息 / 反馈面**。
- **组合器形态**：`DishSheet` 只做**状态编排**，展示拆给页面私有子组件 —— `DishInfo`（信息区 + 点赞）、`FeedbackPanel`（纠错三态：`pick` → `confirm` → `success`）；业务规则（点赞 / 纠错提交 / 退避 / 本地已反馈软提示）收敛在 `hooks/useDishFeedback.ts`。🔴 **无独立确认弹窗、无成功 toast、无深色遮罩**，全部闭环在 Sheet 内。
- **容器**：复用 `BaseSheet` 原语；半屏 peek（`--radius-modal` 顶圆角 + `--overlay-panel-bg` + 顶部 `1rpx` 细描边 + 顶部**压痕**）；弹起 `--duration-slow` + `--ease-bounce`（底边延伸段吸收过冲）；🔴 **无背景蒙版**（`mask=false`）；大图固定，只有下方滑动区切换。
- **内容（自上而下）**：
  - **大图**：**圆角矩形** —— 四周 gap `--spacing-lg`（顶部由把手区提供），圆角 `--radius-modal`（与弹层顶角同半径 ⇒ 同心圆弧），`1rpx --border-color` 细描边（🔴 无阴影，与弹层一致）；失败走 `ImagePlaceholder`；**信息区文本左缘与图片左缘对齐**（同 `--spacing-lg` inset）；
  - **主信息块**：第 1 行左菜品名（`--font-title` / `--text-title`）、右**点赞组件**（`heart` / `heart-on` 40rpx + 数字 `--font-title`，🔴 **无底色、无边框**），两者 space-between；第 2 行档口名（`--font-body` / `--text-body`，空则不渲染，行高 `--spacing-lg`）；**短横线虚线**（`--sheet-divider`，线 16rpx + 空 16rpx，上下 `--spacing-sm`）；虚线下方左「食堂名 + 可选楼层」，右**纠错入口**（文字 + `chevron` 24rpx 右箭头；🔴 无底色、无边框）；
  - **滑块三段结构**：每个滑块固定为「上方块 / 虚线 / 下方块」，**上方块与下方块等分滑块高度 ⇒ 虚线正好落在滑块中线**；两页滑块高度写死相同 ⇒ 切换时虚线位置完全一致。
  - **纠错页三态**（虚线上下两块高度固定 ⇒ 虚线位置全程不动）：
    - **pick**：虚线上方 3 个选项横排（🔴 **纯文字**，无图标、无底色、无边框）；下方左「‹返回 / 上一页」右「下一页›」（`chevron` 24rpx）。🔴 第一页「返回」= **滑回菜品信息页**（Sheet 保持打开）
    - **confirm**：上方只留选中项（纯文字居中）；下方左「取消」右「确认提交」（纯文字）
    - **success**：上方居中 `check` 32rpx + 「反馈已收到」；下方居中「关闭」⇒ **滑回菜品信息页**（Sheet 保持打开，不清空当前菜品）
  - 三态切换用 `--duration-base` + `--ease-out` **淡入淡出**（`prefers-reduced-motion` 下取消）。
- **交互**：🔴 无长按；点纠错入口 ⇒ 信息块左滑出、纠错块右滑入，点「返回」反向滑回；**大图固定、两页虚线同一垂直位置、弹层高度不变**；点空白关闭；🔴 成功态为**单向收尾**，不提供返回选择页的入口。
- **使用**：仅[美食地图页](./美食地图.md)。

# 三、维护口径

1. **新公共组件**：先进本文件登记规格，再被页面消费。
2. **页面改动**：若某页需偏离本文件口径，**先修订本文件**（或登记该页例外）再动代码。
3. **页面设计稿**不得复述本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
4. **改视觉值只改 token**，不在页面里裸写。
