## 0 · 设计语言（Q 版动森（圆润厚实 · 轻拟物））

> 适用：**学生端全部页面与组件**。所有 UI 产出严格遵循本节；页面稿只写「本页用法」，不复述本节。

> **双主题（浅色 / 深色）**：本节与各组件规格以**浅色主题**为基准描述；深色为同键换值的第二组色板（**低饱和夜色：深灰蓝底 `#2B3A4A` + 冷调奶白字 + 晚霞橙主色**，🔴 不做纯黑），取值与主题机制见 [设计变量.md](./设计变量.md) §1.2；组件规格**不随主题分叉**（组件不感知主题，只消费语义变量）—— 两套主题共用同一套**形态语言**（圆角 / 描边宽度 / 动效一致），只换色温与明度。

- **关键词**：动森风 / 奶米纸色 / 深棕 / 浅杏胶囊 / 手绘细描边 / 短虚线 / 柔和回弹 / 均匀错位方格画布 / 图片优先 / 全屏沉浸。
- **底色与色彩**：页面奶米纸色 `--bg-page` `#FFFAF3`；主文案深棕 `--text-title` `#44382E`；可读辅助浅棕 `--text-body` `#75665A`；`--color-muted` `#8C7B6B` 仅箭头 / 装饰；主色暖橙 `#FF8A4C` 仅用于非 sheet 品牌 CTA；sheet 内按钮统一浅杏胶囊 `--sheet-pill-bg` + 深棕描边 + 深棕文字。
- **字体**：标题 / 菜名 / 弹层标题用**无衬线圆体**（`--font-sans`）；参数型辅助信息、按钮文案、弹层选项用**无衬线圆体**（`--font-sans`）。字号差距清晰，拒绝信息堆砌。
- 🔴 **字重规则（Q 版动森）**：**所有无衬线圆体标题一律 `--weight-regular`** —— 层级由**字号 + 颜色**承担，**不靠加粗**；唯一例外：无衬线圆体状态标签（如失败态标题）。
- **图片优先**：美食地图以**菜品大图**为绝对主体，磁贴纯图、无文字浮层，回归「看图定夺」的极简本质；弹窗面板为**奶米色面板**（`--overlay-panel-bg` + `--radius-modal` + 顶部细描边）。
- **按钮**：统一**胶囊**（`--radius-pill`）；反馈 / 导航 / 确认按钮 = 浅杏底 `--sheet-pill-bg` + `2rpx` 深棕描边 `--sheet-pill-border` + 深棕文字；主操作（确认提交）用加深杏色 `--sheet-pill-bg-strong`；主面板「纠错反馈 ›」是**文字行入口**，不加胶囊。
- **光影**：🔴 **全局无阴影** —— 层级只靠底色（胶囊）、描边、圆角区分，不画投影、不用渐变。
- **图标**：统一 **Streamline Plump 单色棕描边 SVG**（`AppIcon`）；`heart` 未赞为浅棕空心、`heart-fill` 已赞为浅棕填充；圆润粗胖、不混用图标字体、不混用多色图标。
- **页面分层**：前景 = 全屏可平移缩放的菜品地图画布 → 底层固定弹窗层（点击磁贴升起半屏 Sheet）。无 TabBar / 无全局顶栏。
- **空态**：🔴 **美食地图不处理空态**（零在售菜品时画布留白，无提示无按钮）；首屏加载 / 加载失败仍走 `PageLoading` / `RetryBlock`。

- **加载 / 失败**：
  - **加载中**：`PageLoading`；`arrows-clockwise` 图标 `64rpx`、`opacity 0.55`；文案 `--font-h2` / `--weight-regular` / `--text-title`；父容器 `flex: 1` + `align-items: center` + `justify-content: center`（图标与文字同基线）。
  - **失败块**：`RetryBlock`；规格以 [§2.1.3](#213-retryblock--加载失败块) 为准（`warning-circle` `44rpx` + 标题 `--font-body` / `--weight-semibold` / `--text-body`，`gap: --spacing-xs` + `padding: --spacing-xl --spacing-lg`）。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` = **`#FFFAF3`**（奶米纸色，🔴 全站统一；深色主题取值见 [设计变量.md](./设计变量.md) §1.2）—— **唯一承载处**；页面根 / 组件 **SHALL NOT** 再声明页面底色 |
| 主题（明暗） | **全站双主题**：页面根挂 `data-theme="light"｜"dark"` 切换语义色组；默认浅色、storage 持久化；深色取值与完整机制见 [设计变量.md](./设计变量.md) §1.2 |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；画布页根须再加 `min-height: 0`（否则页根比可视区高出一截） |
| 顶部安全区（**含胶囊**） | 自定义导航栏（`navigationStyle: custom`）下，画布内容起始 = **状态栏高度 + 导航栏高度**：状态栏高（`statusBarHeight`）覆盖刘海 / 挖孔屏；导航栏高由 `uni.getMenuButtonBoundingClientRect()` 与状态栏高算出 —— **保证顶部内容不被右上角胶囊重叠**（实现见 `client/src/utils/safeArea.ts`） |
| 底部安全区 | 画布底部留白须叠加 `env(safe-area-inset-bottom)` |

## 1.2 圆角 / 线宽

- 分档：模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`（卡 / 弹层 / 胶囊三档，见 [设计变量.md](./设计变量.md) §2.1）。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `1rpx`（描边 / 分隔线）；`2rpx` 只留给**胶囊描边**（`--sheet-pill-border`，深棕）与语义状态线（选中 / 聚焦，配主色）。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-2xs`(4) → `--spacing-2xl`(48)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-subtitle`(26) → `--font-body`(28) → `--font-h3`(32) → `--font-h2`(36) → `--font-title`(40)；**正文级字号下限 `24rpx`，常规辅助文本取 `--font-subtitle`(26rpx)**。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`。

## 1.4 色彩 / 光影

- 色板与取色边界（主色语义分档、文字四档、背景 / 边框 / 语义色 / 对比度口径）见 [设计变量.md](./设计变量.md) §1（**含 §1.2 深色组**）。
- **色值只改 `tokens.ts` 的 `COLOR_MAP`**（分浅色 / 深色两组）；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；🔴 **全局无阴影** —— 弹层 / 面板靠 `1rpx` 细描边与圆角区分，不画投影、不用渐变。

## 1.5 表面：面板

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块，区块之间**只靠页面留白分组**。
- **弹窗面板只有一套取值**：奶米色面板 = `--overlay-panel-bg` + `--radius-modal`(56rpx) + 顶部 `1rpx` 细描边（规格见 §2.2 `DishSheet`）。
- 页面 / 组件私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 描边一律取已登记形态** —— SHALL NOT 另立新取值。
- 长文本断行唯一写法 = `overflow-wrap: anywhere`。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-placeholder`）；DishSheet 胶囊按钮用 `scale(.96)` 按压回弹（唯一 `scale` 例外）。`opacity` 只三档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 ｜ **`.85`** 主色实底 CTA — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 两档：① **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-disabled`；② **非主色可点件** ⇒ `opacity: .5`。DishSheet 胶囊置灰 = 描边与文字取**暖灰棕 `--text-disabled`**（🔴 不用冷灰、不用灰度滤镜），无按压动画、`@tap` 直接返回；禁点由组件 `disabled` 守卫承担。 |
| 触达下限 | 可点元素命中区 **≥96rpx（48pt，`--tap-target-size`）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(140) / `--duration-base`(240) / `--duration-slow`(420) + `--ease-out`；**不新增装饰性入场动效**（内容一律立即可见）；`prefers-reduced-motion: reduce` 下过渡取消、旋转环减速。
- 层级：`--z-sheet`(2000)。
- 高度：`--tap-target-size`(96rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；图标资源**一律下载**（Streamline Plump · Flat，**单色棕描边 SVG**，CC BY 4.0），几何**不自行绘制** —— 资源清单、单色描边口径与获取路径见 [图标资源.md](./图标资源.md)。规格：`48` 网格（心形 / 加号为紧致 `viewBox`）、`fill: none` + 浅棕 `#8C7B6B` 描边、圆润粗胖。图标**只用这一套**，SHALL NOT 混入其它图标库 / 图标字体 / emoji / 多色图标。
- **单色口径**：功能小图标一律**浅棕描边、无填充**；唯一填充态 = 点赞已赞 `heart-fill`（浅棕填充）。

- **选中态用独立键**：点赞选中 = `heart-fill`（浅棕 `#8C7B6B` 填充），未赞 = `heart`（浅棕 `#8C7B6B` 空心）。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认）/ 筛选触发器 ｜ `32` 伴随标题 ｜ `40` 卡内功能图标 ｜ `44` 失败态 ｜ `48` 卡内图片占位 ｜ `64` 加载态图标 / 占位默认 ｜ `96` 整块失败态。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键** —— 完整清单（语义 / 键 / Streamline 源文件 / 消费点）见 [图标资源.md](./图标资源.md) §3，**该表为唯一真源**，本节不复列。

> 新增用途须先在[图标资源.md](./图标资源.md) §3 找语义档；确无对应才新增并登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image-broken`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- **图片承载区**（菜品图位）在**加载中 / 失败 / 为空**时，一律**按该区尺寸渲染占位**（`ImagePlaceholder`）—— **不留空白、不用文字失败块**。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

### 2.1.3 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`flex: 1` + 纵向居中；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **图标**：`warning-circle`，`44rpx`。
- **文案**：标题 `--font-body` + `--weight-semibold` + `--text-body`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 仅忽略点击（🔴 不引入旋转 loading）。
- **不改标题 / 不加按钮**。
- **适用面**：美食地图首屏整页失败态（内容区只渲染 `RetryBlock`，不渲染画布磁贴）。

### 2.1.4 `BaseSheet` —— 底部弹层原语

- **遮罩**：`--overlay-scrim`；点击空白关闭；`mask` 属性可关（`false` 时为透明、不变暗、不加滤镜）。
- **抽屉**：`--overlay-panel-bg` + `border-radius: --radius-modal --radius-modal 0 0` + 顶部 `1rpx --border-color` 细描边（🔴 无阴影）；`padding-bottom: env(safe-area-inset-bottom)`；上滑开合（`--duration-slow`）。
- **grabber**：约 `96 × 12rpx`（手绘加粗短杠）、`--border-bold`、`--radius-pill`。
- **下拉关闭手势**：手柄区域跟手向下拖（`touchmove` 实时位移）；松手位移 > 120rpx 关闭，未超过回弹到 0；向上拖不展开。
- **本项目用法**：美食地图「菜品弹窗」（`DishSheet`）复用本原语承载详情 + 点赞 + 纠错（详见 §2.2 `DishSheet`）。
- **不引入系统 `ActionSheet`**。

### 2.1.7 `PageLoading` —— 内容区加载块

- **定位**：🔴 **非全屏遮罩** —— 由美食地图画布放进自己的**内容区**，`flex: 1` 占满剩余高度并**竖直居中**（背景透明、不改页面底色）。
- **形态**：**居中一枚 `arrows-clockwise` 图标（64rpx、多色 SVG、`opacity .55`）** + `--spacing-xs` 下距处无衬线圆体文案（`--font-h2` + `--weight-regular`，默认「加载中」）。
- **旋转**：🔴 **仅图标本体**以 `--duration-spin`(2000ms) 线性匀速旋转；**无外围圆环、无描边、无底色容器**。
- **主题**：🔴 **全局跟随夜间模式**。

## 2.2 新增（本设计引入）

> 逐组件登记规格；**页面稿只写「本页用法」，不复述规格**。

### `FoodMap` —— 美食地图画布（可平移 + 双指缩放 · 均匀错位方格）

- **用途**：美食地图页唯一内容区；承载圆角正方形菜品磁贴的**均匀错位方格平面**，支持单指拖拽平移（带惯性）、双指捏合缩放、**软边界**。
- **几何**：维护一个**内容包围盒**（所有磁贴几何边界）；平移 / 缩放作用于该盒；**软边界** —— 越界后画布仍跟手但位移被**阻尼压缩**（越界越深、跟手比例越低，接近饱和后几乎不动），松手**弹性回位**（过冲缓动），🔴 不硬停、不瞬移回位；缩放**软限位**（贴近上下限时幅度被压缩）。
- **排布**：🔴 **均匀错位方格密铺**（非随机散布）：固定网格**行优先**落格、奇偶行**水平错开半格**，结构可预测且行列整齐错开；每次载入菜品**随机映射到已确定的格子**（格子结构不变，只换谁坐哪格）；🔴 **不做簇**（无食堂成簇 / 食堂中心 / 固定锚位 / 权重）；磁贴尺寸统一（240rpx 边长，步长 300rpx）。
- **首屏**：落在**世界几何中心**并收敛到合法边界（不跳、不重置）；重新载入后格子结构不变。
- **磁贴**（画布内联元素，非独立组件）：**圆角正方形** `aspect-ratio: 1` + 圆角 `--radius-card`(44rpx) + `1rpx --border-color` 细描边（🔴 无阴影）；**纯图、无文字浮层**；图直接落在 `<image>` 上（原生 `<image>` 不吃父级 `overflow` 裁切）；加载中 / 失败 / 为空走 `ImagePlaceholder`（§1.9）；点磁贴 ⇒ 唤起 `DishSheet`（位移与时长都在阈值内才算点击），🔴 无长按；按压为**轻微收缩回弹**（`scale(.96)` + `--ease-bounce`）。
- **点击判定**：位移 < 阈值（建议 ≤ 10rpx）且时长 < 阈值 ⇒ 命中卡片点击；否则判为平移 / 缩放，避免误触。
- **动效**：过渡轻柔低速、`--ease-out`；🔴 **尊重 `prefers-reduced-motion: reduce`**（惯性 / 弹性 / 缩放降级为即时）。
- **重新载入**：菜品重新映射到格子 —— 格子结构恒为均匀错位，**位置不散乱**。
- **双主题**：浅色 / 深色两套色板同键声明，页面根挂 `data-theme` 生效；两套主题共用同一形态语言（圆角、描边宽度、动效一致）。
- **空态**：🔴 不处理（零在售菜品时画布留白，无提示无按钮）。
- **加载 / 失败**：加载中渲染 `PageLoading`；失败渲染 `RetryBlock`；均占满内容区。
- **使用**：仅[美食地图页](./美食地图.md)。

### `DishSheet` —— 菜品底部弹窗（详情 + 点赞 + 纠错）

- **用途**：点磁贴唤起；承载单品详情、两态点赞与纠错，是美食地图的**唯一信息 / 反馈面**。
- **组合器形态**：`DishSheet` 本体只做**状态编排**（反馈开合 / 确认 / 成功提示时序），展示与分页拆给页面私有子组件 —— `DishInfo`（信息区 + 点赞）、`FeedbackPanel`（选项分页内部自治，第 1 页「返回」回主信息块）、`ConfirmBubble`（轻确认气泡）、`SheetToast`（成功提示）；业务规则（点赞 / 纠错提交 / 退避 / 本地已反馈软提示）收敛在 `hooks/useDishFeedback.ts`。
- **容器**：复用 `BaseSheet` 原语；半屏 peek（`--radius-modal` 顶圆角 + `--overlay-panel-bg` + 顶部 `1rpx` 细描边，🔴 无阴影）；弹起 `--duration-slow` + `--ease-out`；🔴 **无背景蒙版**（`mask=false`，背景透明）；大图固定，只有下方信息区横向切换。
- **内容（自上而下）**：
  - **大图**：顶部菜品大图（圆角 `--radius-card` + 极细浅棕描边 `1rpx --border-color`），失败走 `ImagePlaceholder`；
  - **主信息块**：第 1 行左菜品名（`--font-title` / `--text-title`）、右点赞（`heart` 40rpx + 数字 `--font-title`，基线对齐）；第 2 行档口名（`--font-body` / `--text-body`，空则不渲染）；短虚线（`--sheet-divider`，8rpx 实线 + 8rpx 间隔）；虚线下方左「食堂名 + 可选楼层」（食堂 `--font-body`、楼层 `--font-subtitle`，楼层空只渲染食堂名），右「纠错反馈 ›」文字入口（`--font-subtitle` / `--text-body`，箭头 `--color-muted`，不加胶囊、不显示 `flag` 图标）；
  - **点赞**：未赞 `heart` 浅棕空心、已赞 `heart-fill` 浅棕填充，均为 40rpx；数字 `--font-title` / `--text-title`；🔴 **无白底胶囊 / 无圆框**，与菜名基线对齐；点即 toggle 并有 Q 弹；
  - **反馈分页**：每页最多 3 个 `SheetPill`（浅杏底 + 2rpx 深棕描边 + 深棕文字，`--radius-pill`）；虚线下方为导航胶囊；第 1 页左侧「返回」、其余页「上一页」，右侧固定「下一页」，末页置灰且无按压/无响应；选项与导航在提交中禁用；
  - **确认气泡**：点反馈胶囊先按压回弹，再淡入「要提交这条反馈吗？」；奶米底 + 细棕描边 + `--radius-modal`，浮于 sheet 上层；遮罩 `--overlay-sheet-scrim`；操作按钮「确认提交」（主操作 = 加深杏色 `--sheet-pill-bg-strong`）「取消」（浅杏底）同为 `SheetPill`；取消淡出并停留当前页，提交失败保留气泡可重试；
  - **成功提示**：确认提交成功后气泡消失，展示「反馈已提交」奶米底细棕描边提示，约 1.2s 淡出，随后自动回到主信息块。
- **交互**：🔴 无长按；只保留按钮操作（点「纠错反馈 ›」进入反馈页、点「返回」「上一页」回主信息块），🔴 无左右横滑手势；大图固定，反馈翻页只切选项行，导航行固定；手柄下拉跟手关闭 / 点空白关闭；提交成功后回到主信息块，弹窗保持打开。
- **使用**：仅[美食地图页](./美食地图.md)。

### `SheetPill` —— 弹层胶囊按钮（反馈选项 / 分页导航 / 确认气泡操作）

- **用途**：美食地图页私有的胶囊按钮；**反馈选项、分页导航、确认气泡操作三处共用同一形态**。
- **形态**：`--sheet-pill-bg` 浅杏底 + `2rpx --sheet-pill-border` 深棕描边 + `--text-title` 文字 + `--radius-pill`；文案 `--font-subtitle`；命中区 ≥ `--tap-target-size`(96rpx)；单行省略。
- **主操作变体**：`accent` ⇒ 底色取加深杏色 `--sheet-pill-bg-strong`（描边 / 文字不变）。
- **按压**：`scale(.96)` 回弹（`--duration-fast` + `--ease-bounce`）；🔴 `prefers-reduced-motion: reduce` 下降级为即时。
- **置灰**：描边与文字取暖灰棕 `--text-disabled`（🔴 不用冷灰、不用灰度滤镜），无按压动画、`@tap` 直接返回；禁点由组件 `disabled` 守卫承担。
- **接口**：props `disabled` / `accent` / `ariaLabel`；对外事件 `press`（🔴 非小程序原生事件名）。
- **使用**：仅[美食地图页](./美食地图.md)。
