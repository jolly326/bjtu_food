## 0 · 设计语言（Q 版动森（圆润厚实 · 轻拟物））

> 适用：**学生端全部页面与组件**。所有 UI 产出严格遵循本节；页面稿只写「本页用法」，不复述本节。

> **双主题（浅色 / 深色）**：本节与各组件规格以**浅色主题**为基准描述；深色为同键换值的第二组色板（**中性灰阶底 + 浅灰字 + 品牌暖橙主色**），取值与主题机制见 [设计变量.md](./设计变量.md) §1.2；组件规格**不随主题分叉**（组件不感知主题，只消费语义变量）。

- **关键词**：极简 / 文艺 / 留白 / 暖调 / 图片优先 / 全屏沉浸。
- **底色与色彩**：页面**暖奶油**（`--bg-page = #FFF7E8`），正文**暖棕**（`--text-title` / `--text-body`）、辅助文字**暖棕**（`--text-tertiary`）；主色暖橙 `#FF8A4C` 🔴 **仅用于「选中态」与「关键 CTA」**，装饰性图标 / 文字 / 卡面元素一律不用主色。
- **字体**：标题 / 菜名 / 弹层标题用**无衬线圆体**（`--font-sans`）；参数型辅助信息、按钮文案、弹层选项用**无衬线圆体**（`--font-sans`）。字号差距清晰，拒绝信息堆砌。
- 🔴 **字重规则（Q 版动森）**：**所有无衬线圆体标题一律 `--weight-regular`** —— 层级由**字号 + 颜色**承担，**不靠加粗**；唯一例外：无衬线圆体状态标签（如失败态标题）。
- **图片优先**：美食地图以**菜品大图**为绝对主体，磁贴纯图、无文字浮层，回归「看图定夺」的极简本质；弹窗面板为**暖白卡片面板**（`--overlay-panel-bg` + `--radius-modal` + `--shadow-modal`）。
- **按钮**：以**线框**为主，**小圆角**（`--radius-btn`，非全圆）；主 CTA **暖橙描边 + 内部深色文字**，其余按钮中性灰描边；不使用实底填充。
- **图标**：统一粗描边性 Phosphor 图标（`AppIcon`），不填充、不混用图标字体。
- **页面分层**：前景 = 全屏可平移缩放的菜品地图画布 → 底层固定弹窗层（点击磁贴升起半屏 Sheet）。无 TabBar / 无全局顶栏。
- **空态**：🔴 **美食地图不处理空态**（零在售菜品时画布留白，无提示无按钮）；首屏加载 / 加载失败仍走 `PageLoading` / `RetryBlock`。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` = **`#FFFFFF`**（纯白，🔴 全站统一；深色主题取值见 [设计变量.md](./设计变量.md) §1.2）—— **唯一承载处**；页面根 / 组件 **SHALL NOT** 再声明页面底色 |
| 主题（明暗） | **全站双主题**：页面根挂 `data-theme="light"｜"dark"` 切换语义色组；默认浅色、storage 持久化；深色取值与完整机制见 [设计变量.md](./设计变量.md) §1.2 |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；画布页根须再加 `min-height: 0`（否则页根比可视区高出一截） |
| 顶部安全区（**含胶囊**） | 自定义导航栏（`navigationStyle: custom`）下，画布内容起始 = **状态栏高度 + 导航栏高度**：状态栏高（`statusBarHeight`）覆盖刘海 / 挖孔屏；导航栏高由 `uni.getMenuButtonBoundingClientRect()` 与状态栏高算出 —— **保证顶部内容不被右上角胶囊重叠**（实现见 `client/src/utils/safeArea.ts`） |
| 底部安全区 | 画布底部留白须叠加 `env(safe-area-inset-bottom)` |

## 1.2 圆角 / 线宽

- 分档：微件 `--radius-xs` → 控件 `--radius-btn` → 模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`；正圆 `--radius-circle`。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `1rpx`（描边 / 分隔线）；`2rpx` 只留给**语义状态线**（选中 / 聚焦，配主色）。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-3xs`(2) → `--spacing-2xl`(48)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-title`(40) → `--font-display`(48) → `--font-hero`(64)；**正文级下限 `--font-subtitle`(24rpx)`。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`。

## 1.4 色彩 / 阴影

- 色板与取色边界（主色语义分档、文字四档、背景 / 边框 / 语义色 / 对比度口径）见 [设计变量.md](./设计变量.md) §1（**含 §1.2 深色组**）。
- **色值只改 `tokens.ts` 的 `COLOR_MAP`**（分浅色 / 深色两组）；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；弹窗面板加 **`--shadow-modal` 低透明柔和浅阴影** —— 🔴 **禁高对比纯黑装饰性阴影**。

## 1.5 表面：面板

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块，区块之间**只靠页面留白分组**。
- **弹窗面板只有一套取值**：暖白卡片面板 = `--overlay-panel-bg` + `--radius-modal`(40rpx) + `--shadow-modal` 柔和浅阴影（规格见 §2.2 `DishSheet`）。
- 页面 / 组件私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 阴影一律取已登记形态** —— SHALL NOT 另立新取值。
- 长文本断行唯一写法 = `overflow-wrap: anywhere`。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-placeholder`）；**SHALL NOT `transform: scale`**。`opacity` 只三档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 ｜ **`.85`** 主色实底 CTA — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 两档：① **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-tertiary`；② **非主色可点件** ⇒ `opacity: .5`。禁点由全局 `.is-disabled { pointer-events: none }` 承担。**`opacity` 全站只表「在途 busy」，不用于禁用** |
| 触达下限 | 可点元素命中区 **≥88rpx（44pt）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(120) / `--duration-base`(200) / `--duration-slow`(360) + `--ease-out`；**不新增装饰性入场动效**（内容一律立即可见）；`prefers-reduced-motion: reduce` 下过渡取消、旋转环减速。
- 层级：`--z-sheet`(2000)。
- 高度：`--tap-target-size`(88rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；图标资源**一律下载**（Phosphor 官方 SVG，**Bold** 字重、选中态另取 **Fill** 字重，MIT 许可），几何**不自行绘制** —— 资源清单与获取路径见 [图标资源.md](./图标资源.md)。规格：`256` 网格、`fill="currentColor"`（填充式，非描边）、圆润厚实。图标**只用这一套**，SHALL NOT 混入其它图标库 / 图标字体 / emoji。
- **选中态用 Fill 字重变体**：点赞选中 = 同一 `heart` 图标换 `heart-fill`（实心）+ 主色。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认）/ 筛选触发器 ｜ `32` 伴随标题 ｜ `40` 卡内线性功能图标 ｜ `44` 失败态 ｜ `48` 卡内图片占位 ｜ `64` 加载态图标 / 占位默认 ｜ `96` 整块失败态。
- `tone`：**预生成色调**（`default` / `primary` / `muted`，见 [图标资源.md](./图标资源.md) §2）—— 微信 `<image>` 支持 SVG **文件**但**不支持运行时换色**，故按色调预生成变体；**深色主题**下三档 tone 取深色色值，变体按主题分组生成。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键** —— 完整清单（语义 / 键 / Phosphor 名 / 消费点）见 [图标资源.md](./图标资源.md) §3，**该表为唯一真源**，本节不复列。

> 新增用途须先在[图标资源.md](./图标资源.md) §3 找语义档；确无对应才新增并登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image-broken`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- **图片承载区**（菜品图位）在**加载中 / 失败 / 为空**时，一律**按该区尺寸渲染占位**（`ImagePlaceholder`）—— **不留空白、不用文字失败块**。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

## 2.0 分层与目录（强制）

> 🔴 **只有真正的跨页公共件才进 `components/base/`**；只有单页使用的组件一律下沉到该页面的 `components/` 下，与页面同包。

| 层 | 目录 | 判定 | 现有成员 |
|---|---|---|---|
| **公共** | `client/src/components/base/` | ≥2 个页面使用 | `AppIcon` · `ImagePlaceholder` · `RetryBlock` · `PageLoading` · `BaseSheet` |
| **页面私有** | `client/src/pages/map/components/` | 仅美食地图页使用 | `DishMap` · `DishTile` · `DishSheet` |

- **页面包名**：`美食地图 → map`（路由 `pages/map/index`）。
- **导入约定**：页面内 `./components/Xxx.vue`；页面私有组件引用公共件一律走别名 `@/components/base/Xxx.vue`（禁止 `../` 跨层相对路径）。
- **新增组件的判定顺序**：先问「是否 ≥2 页使用」——否 ⇒ 放进当前页 `components/`；是 ⇒ 进 `components/base/` 并在 §2.1 登记。

## 2.1 沿用（跨页复用）

| 组件 | 作用 | 规格 |
|---|---|---|
| `RetryBlock` | 加载失败重试（美食地图首屏失败态） | [§2.1.3](#213-retryblock--加载失败块) |
| `PageLoading` | 内容区加载块（图标慢速旋转、主题跟随全局） | [§2.1.7](#217-pageloading--内容区加载块) |
| `BaseSheet` | 底部弹层**原语** —— 承载美食地图「菜品弹窗」（详情 + 点赞 + 纠错） | [§2.1.4](#214-basesheet--底部弹层) |

### 2.1.3 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`flex: 1` + 纵向居中；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **图标**：`warning-circle`，`44rpx`。
- **文案**：标题 `--font-body` + `--weight-semibold` + `--text-body`；副文案 `--font-small` + `--text-tertiary`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 仅忽略点击（🔴 不引入旋转 loading）。
- **不改标题 / 不加按钮**。
- **适用面**：美食地图首屏整页失败态（内容区只渲染 `RetryBlock`，不渲染画布磁贴）。

### 2.1.4 `BaseSheet` —— 底部弹层原语

- **遮罩**：`--overlay-scrim`；点击空白关闭；`mask` 属性可关（`false` 时为透明、不变暗、不加滤镜）。
- **抽屉**：`--overlay-panel-bg` + `border-radius: --radius-modal --radius-modal 0 0` + `--shadow-modal`；`padding-bottom: env(safe-area-inset-bottom)`；上滑开合（`--duration-slow`）。
- **grabber**：约 `96 × 12rpx`（手绘加粗短杠）、`--border-bold`、`--radius-pill`。
- **下拉关闭手势**：位移 > 120rpx 关闭。
- **本项目用法**：美食地图「菜品弹窗」（`DishSheet`）复用本原语承载详情 + 点赞 + 纠错（详见 §2.2 `DishSheet`）。
- **不引入系统 `ActionSheet`**。

### 2.1.7 `PageLoading` —— 内容区加载块

- **定位**：🔴 **非全屏遮罩** —— 由美食地图画布放进自己的**内容区**，`flex: 1` 占满剩余高度并**竖直居中**（背景透明、不改页面底色）。
- **形态**：**居中一枚 `arrows-clockwise` 图标（64rpx + `tone="muted"`、`opacity .55`，🔴 不上主题色）** + `--spacing-xs` 下距处无衬线圆体文案（`--font-h2` + `--weight-regular`，默认「加载中」）。
- **旋转**：🔴 **仅图标本体**以 `--duration-spin`(2000ms) 线性匀速旋转；**无外围圆环、无描边、无底色容器**。
- **主题**：🔴 **全局跟随夜间模式**。

## 2.2 新增（本设计引入）

> 逐组件登记规格；**页面稿只写「本页用法」，不复述规格**。

### `DishMap` —— 美食地图画布（可平移 + 双指缩放）

- **用途**：美食地图页唯一内容区；承载圆角正方形菜品磁贴的**错位方格密铺平面**，支持单指拖拽平移（带惯性）、双指捏合缩放、边界弹性停止。
- **几何**：维护一个**内容包围盒**（所有磁贴几何边界）；平移 / 缩放作用于该盒；边界**弹性停止**（rubber-band，越界不外溢）。
- **首屏**：**居中于世界几何中心**（进入即见地图中心区）。
- **点击判定**：位移 < 阈值（建议 ≤ 10rpx）且时长 < 阈值 ⇒ 命中磁贴点击；否则判为平移 / 缩放，避免误触。
- **动效**：过渡轻柔低速、`--ease-out`；🔴 **尊重 `prefers-reduced-motion: reduce`**（惯性 / 弹性 / 缩放降级为即时）。
- **空态**：🔴 不处理（零在售菜品时画布留白，无提示无按钮）。
- **加载 / 失败**：加载中渲染 `PageLoading`；失败渲染 `RetryBlock`；均占满内容区。
- **使用**：仅[美食地图页](./美食地图.md)。

### `DishTile` —— 圆角正方形菜品磁贴

- **用途**：`DishMap` 内的单元；纯菜品大图。
- **形态**：**圆角正方形** `aspect-ratio: 1` + 圆角 `--radius-card`(32rpx)；**纯图、无文字浮层**；图直接落在 `<image>` 上（原生 `<image>` 不吃父级 `overflow` 裁切）。
- **占位 / 失败**：图位加载中 / 失败 / 为空走 `ImagePlaceholder`（§1.9）。
- **排布**：由 `DishMap` 落在**错位方格**（固定网格 + 奇偶行错位半格；每载入随机分配菜品，无食堂成簇 / 权重）。
- **交互**：点磁贴 ⇒ 唤起 `DishSheet`（`@tap`，位移小于点击阈值时）；🔴 无长按。
- **使用**：仅[美食地图页](./美食地图.md)。

### `DishSheet` —— 菜品底部弹窗（详情 + 点赞 + 纠错）

- **用途**：点 `DishTile` 唤起；承载单品详情、两态点赞与纠错，是美食地图的**唯一信息 / 反馈面**。
- **容器**：复用 `BaseSheet` 原语；半屏 peek（`--radius-modal` 顶圆角 + `--overlay-panel-bg` + `--shadow-modal`）；弹起 `--duration-slow` + `--ease-out`（无过冲）；🔴 **无背景蒙版**（`mask=false`，背景透明）。
- **内容（自上而下）**：
  - **大图**：顶部菜品大图（圆角 `--radius-card` + 极细浅棕描边 `1rpx --border-color`），失败走 `ImagePlaceholder`；

# 三、维护口径

1. **新公共组件**：先进本文件登记规格，再被页面消费。
2. **页面改动**：若某页需偏离本文件口径，**先修订本文件**（或登记该页例外）再动代码。
3. **页面设计稿**不得复述本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
4. **改视觉值只改 token**，不在页面里裸写。

# 四、交付门禁

`npm run verify` 串行执行（契约 / 图标 / UI 裸值 / 文档一致性 / lint / 类型 / 单测 / **小程序构建**），任一失败即阻断。**构建那道不可省** —— 静态检查发现不了 SCSS / 模板编译错误。
