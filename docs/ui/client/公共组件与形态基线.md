# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` = **`#FFFDFE`**（🔴 全站统一）—— **唯一承载处**；页面根 / 组件 **SHALL NOT** 再声明页面底色 |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；**自带滚动容器的页根必须再加 `min-height: 0`**（否则页根比可视区高出一截，页面多出一段可滚区） |
| 主滚动区 | `.scroll-wrap { min-height: 0 }`（缺它会出现「页面 + 滚动区」双层滚动） |
| 滚动区底部留白 | **不全局兜底**：仅自带 TabBar 的页由**页面根**让出菜单栏高度；其余页不得凭空多出死留白 |
| 滚动区底部安全区（**恒需要**） | **任何**滚动承载区底部留白都须叠加 `env(safe-area-inset-bottom)` |
| 顶部安全区 | `max(statusBarHeight, env(safe-area-inset-top))` |
| 宽屏（仅 H5 / 桌面） | `@media (min-width: 768px) { .scroll-wrap { max-width: 720px; margin: 0 auto } }` |

## 1.2 圆角 / 线宽

- 分档：微件 `--radius-xs` → 控件 `--radius-btn` → 模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`；正圆 `--radius-circle`。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `1rpx`（描边 / 分隔线 / 底栏顶边）；`2rpx` 只留给**语义状态线**（选中 / 聚焦，配主色）。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-3xs`(2) → `--spacing-2xl`(64)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-tiny`(20) → `--font-title`(44)；**正文级下限 `24rpx`**。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`（小字会飘在行中间）。

## 1.4 色彩 / 阴影

- 色板与取色边界（主色语义分档、文字四档、背景 / 边框 / 语义色 / 对比度口径）见 [设计变量.md](./设计变量.md) §1。
- **色值只改 `tokens.ts` 的 `COLOR_MAP` / `CSS_VARS`**；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；内容块阴影恒为 `--module-shadow`（极淡暖棕，**禁黑色阴影**）。

## 1.5 表面：模块 / 卡片

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块 `.module-wrap`，区块之间**只靠页面留白分组**。
- **全局唯一实现** = `App.vue` 的 `.module-wrap`：`--module-bg` + `--radius-card` + `--module-shadow` + `padding: --spacing-lg`。
- **表面只有一套**：页面私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 阴影一律由 `.module-wrap` 提供** —— SHALL NOT 在页面私有类里另写，形成第二套表面。
- 模块之间的留白由消费方容器 `flex gap`（`--spacing-lg`）承担（WXSS 不支持 `+` / `~` 兄弟选择器）。
- **长文本断行唯一写法 = `overflow-wrap: anywhere`**（`word-break: break-all` / `break-word` 不作为可选写法）。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-soft` / `--bg-placeholder`；**二者不叠加**）；**SHALL NOT `transform: scale`**。`opacity` 只三档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 ｜ **`.85`** 主色实底 CTA — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …，会跨组件边界冒泡致「点一次跳两次」）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 三档：① **主色实底** ⇒ 底 `--bg-input` + 字 `--text-tertiary`；② **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-tertiary`；③ **非主色可点件** ⇒ `opacity: .5`。禁点由全局 `.is-disabled { pointer-events: none }` 承担。**`opacity` 全站只表「在途 busy」，不用于禁用** |
| 键盘焦点环 | `:focus-visible:not(input):not(textarea)` → `outline: 3rpx solid var(--color-primary)` + `outline-offset: 2rpx` + `border-radius: var(--radius-xs)` |
| 触达下限 | 可点元素命中区 **≥88rpx（44pt）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(120) / `--duration-base`(200) / `--duration-slow`(300) + `--ease-out`；**不新增装饰性入场动效**（内容一律立即可见）；`prefers-reduced-motion: reduce` 下过渡取消、旋转环减速。
- 层级：`--z-page-bg`(−1) / `--z-action-bar`(50) / `--z-tabbar`(100) / `--z-header`(100) / `--z-sheet`(2000) / `--z-actionsheet`(4000)。
- 高度：`--tabbar-height`(100rpx) / `--action-bar-height`(120rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；几何取 **IconPark 线性主题**（48 网格、`stroke-width 2`、圆角端点）。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认） ｜ `32` 伴随标题 ｜ `36` 弹层关闭 ｜ `44` 宫格入口 / 失败态 ｜ `48` TabBar / 空态大图标 ｜ `64` 占位默认 ｜ `96` 整块失败态。
- `color`：**必须事实色**（`COLOR_MAP['xxx']` 或 `#RRGGBB`）—— SVG data-uri 是独立文档，`var()` 与 `currentColor` 都会被回退。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键（完整清单，`-filled` 为选中态变体）**

| 语义 | 键 | 消费点 |
|---|---|---|
| 橱窗 tab | `image` / `image-filled` | [TabBar](#211-tabbar--底部菜单栏) |
| 美食 tab | `dish` / `dish-filled` | TabBar |
| 回味 tab | `book` / `book-filled` | TabBar |
| 图片缺失 / 破图 | `image-broken` | §1.9 `ImagePlaceholder` |
| 加载失败 | `report` | §2.1.3 `RetryBlock` |
| 下拉箭头 | `arrow-down` | §2.2 `CanteenFilter` |
| 未知图标名兜底 | `empty` | `AppIcon` 内部（**唯一非业务键**） |

> 新增用途须**先在表内找语义档**；确无对应才新增并在此登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image-broken`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

## 1.10 列表底部反馈（全局 `.list-foot`）

列表末尾按「触底三态」渲染一行状态文字：**在途**「正在加载更多…」｜ **到底**「没有更多了」｜ **封顶**「已展示前 N 个，切换筛选可查看更多」。

### 2.1.1 `TabBar` —— 底部菜单栏

🔴 **TabBar 固定在底部**，三个 tab 页**恒可见**（本项目无二级页面，故不存在显隐切换逻辑）。

| 项 | 口径 |
|---|---|
| **三项与顺序** | **橱窗** ｜ **美食** ｜ **回味**（显示名；↔ 文档名对照见 [UI 总览](./README.md)） |
| **定位** | `position: fixed; bottom: 0` + `--z-tabbar`(100) |
| **高度** | `calc(--tabbar-height + env(safe-area-inset-bottom))`（`--tabbar-height` = 100rpx） |
| **表面** | **恒透明**（背后即页面底色 `--bg-page`）+ 顶边 `1rpx var(--border-color)` + `--shadow-bar` |
| **每项** | `flex: 1`、纵向居中、`gap: --spacing-xs`；高 = `--tabbar-height` |
| **图标** | `48rpx`（`AppIcon`）；**选中 ⇒ `${键}-filled` 变体 + `--color-primary-bright`**；未选 ⇒ `--text-tertiary` |
| **图标键** | 橱窗 `image` ｜ 美食 `dish` ｜ 回味 `book`（各配 `-filled` 变体） |
| **标签** | `--font-small`(24rpx)；选中 ⇒ `--color-primary-text` + `--weight-semibold`；未选 ⇒ `--text-tertiary` |
| **触摸** | 整项命中 ≥ `--tap-target-size`；按压 `opacity: .6` |
| **徽标** | **无**（无未读、无红点） |
| **内容让位** | 三个 tab 页的主滚动区底部留白 = `--tabbar-height` + `env(safe-area-inset-bottom)`（见 §1.1） |

### 2.1.2 `EmptyState` —— 空态

- **默认形态**：无底色居中列；`gap: --spacing-xs`；`padding: --spacing-xl 0`。
- **文案**：标题 `--font-body` + `--weight-medium` + `--text-secondary`；可选副文案 `--font-aux` + `--text-tertiary`。
- **长度约束**：标题 1 行、副文案 1 行；**允许极简** —— 只留标题、无副文案、无按钮（如「我的食谱」无记录时只有「暂无饮食记录」）。
- **动作按钮（0~2 个）**：方形 `--empty-action-size`(152rpx) 见方 + `--radius-card` + `1rpx var(--border-color)` 描边；图标 `48rpx`（`--text-secondary`）；**文案在按钮下方**（`--font-small` + `--text-secondary`）；按钮间距 `--spacing-md`。
- **与 `RetryBlock` 的分工**：本组件 = **空态**（一切正常但无数据）；`RetryBlock` = **失败态**。渲染优先级 **失败 > 空态 > 列表**。

### 2.1.3 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **图标**：`report`，`44rpx`。
- **文案**：标题 `--font-body` + `--weight-semibold` + `--text-secondary`；副文案 `--font-aux` + `--text-tertiary`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 换 CSS 旋转环 + 忽略点击。
- **不改标题 / 不加按钮** —— 本项目失败态只需"重试"这一个动作。

### 2.1.4 `BaseSheet` —— 底部弹层

- **遮罩**：`--overlay-scrim`；点击关闭。
- **抽屉**：`--overlay-panel-bg` + `border-radius: --radius-modal --radius-modal 0 0` + `--shadow-modal`；`padding-bottom: env(safe-area-inset-bottom)`；上滑开合（`--duration-slow`）。
- **grabber**：`72 × 8rpx`、`--overlay-dark-soft`、`--radius-pill`。
- **下拉关闭手势**：位移 > 120rpx 关闭。
- **本项目的唯一用法**：**纠错选项弹层** —— 单选、5 项、无图标 ⇒ 抽屉内直排**选项行**（每行高 `--tap-target-size`、文案 `--font-body` + `--text-primary`、行间 `1rpx var(--border-color)`、首末行无线），点选即提交并关闭。
- **不引入 `ActionSheet`**（无动作菜单场景）。

## 2.2 新增（本设计引入）

> 逐组件登记规格；**页面稿只写「本页用法」，不复述规格**。

### `PosterSwiper` —— 海报滑动容器

- **结构**：横向一屏一项；每项为圆角 `--radius-card`(40rpx) 的图块。
- **卡宽**：`calc(100vw - 2 × --page-gutter - --poster-peek)`；**比例 3:4**（`aspect-ratio: 3 / 4`）。
- **露边**：右侧露出下一张 `--poster-peek`(48rpx)。
- **手势**：原生滑动、跟手；**可回看前一张**、无循环。
- **占位**：空 / 失败走 `ImagePlaceholder`（`bare`，宿主自带底色）。
- **使用**：仅[档口海报页](./档口海报.md)。

### `DishSwipeCard` —— 推荐扑克卡片

- **结构（自上而下、居中）**：圆形菜品图（直径 `--dish-photo-size` 360rpx）→ 菜名（`--font-h3` + `--weight-semibold`）→ 元信息行（评价分 · 价格 · 位置）→ `WantButton`。
- **表面**：`--radius-card` + `--module-shadow` + `--module-bg`；卡内距 `--spacing-lg`；部件间距 `--spacing-md`。
- **堆叠**：下方卡片向上露出 `--spacing-sm`(16rpx)。
- **划走**：**左右任一方向语义相同**；位移 + 淡出（`--duration-base` + `--ease-out`），随后下一张上浮补位。
- **使用**：仅[推荐菜品页](./推荐菜品.md)。

### `WantButton` —— 「去品尝」

- **形态**：宽度撑满卡内距的主按钮 —— 高 `--tap-target-size`(88rpx)、`--radius-btn`(32rpx)、`--color-primary` 实底 + `--color-on-primary` 文字（`--font-subtitle` + `--weight-medium`）。
- **按压**：`hover-class` ⇒ `opacity: .85`。
- **已品尝态**：转为**不可重复触发** —— 底 `--bg-input` + 字 `--text-tertiary` + 全局 `.is-disabled`（`pointer-events: none`）。
- **使用**：[推荐菜品页](./推荐菜品.md) 卡片内。

### `ReactionPicker` —— 三态评分

- **形态**：三项等距横排（**好吃 / 一般 / 踩**），项间距 `--spacing-md`；每项为**文字胶囊**（`--radius-pill` + `1rpx var(--border-color)` 描边），最小高 `--tap-target-size`。
- **未选中**：字 `--text-secondary`。
- **选中**：底 `--color-primary` + 字 `--color-on-primary`。
- **只读态**（已评分）：选中项保留主色，**其余项不渲染**（评分不可改）。
- **使用**：[我的食谱](./我的食谱.md) 卡片内。

### `MonthTimeline` —— 月份时间线

- **结构**：横向可滑；每项纵向两行 —— 年份（`--font-tiny` + `--text-tertiary`）+ 月份。
- **选中月**：`--font-h2`(40rpx) + `--weight-heavy` + `--text-primary`。
- **未选月**：`--font-subtitle`(32rpx) + `--weight-regular` + `--text-tertiary`。
- **项间距**：`--spacing-lg`(32rpx)。
- **数据**：**仅渲染有记录的月份**（由页面从记录派生）。
- **使用**：我的食谱页顶部。

### `CanteenFilter` —— 食堂筛选

- **形态**：右上角**下拉** —— 用**原生 `picker`**（零自绘）；触发器为「当前食堂名 + `arrow-down` 图标」（图标 `28rpx`、`--text-tertiary`）。
- **默认**：「全部」。
- **切换**：即重筛推荐流，卡片序列重掷。
- **使用**：仅[推荐菜品页](./推荐菜品.md) 右上角。

3. **页面设计稿**不得复述本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
4. **改视觉值只改 token**，不在页面里裸写。

# 四、交付门禁

`npm run verify` 串行执行（契约 / 图标 / UI 裸值 / 文档一致性 / lint / 类型 / 单测 / **小程序构建**），任一失败即阻断。**构建那道不可省** —— 静态检查发现不了 SCSS / 模板编译错误。
