## 0 · 设计语言（Julienne 极简文艺轻拟物）

> 适用：**学生端全部页面与组件**。所有 UI 产出严格遵循本节；页面稿只写「本页用法」，不复述本节。

> **双主题（浅色 / 深色）**：本节与各组件规格以**浅色主题**为基准描述；深色为同键换值的第二组色板（暖黑棕底 + 暖白字，低调饱和度），取值与主题机制见 [设计变量.md](./设计变量.md) §1.2；组件规格**不随主题分叉**（组件不感知主题，只消费语义变量）。

- **关键词**：极简 / 文艺 / 轻拟物 / 留白 / 暖调 / 杂志感 / 纸质卡片隐喻。
- **底色与色彩**：页面**暖白**（`--bg-page`），正文**深炭灰**（`--text-title` / `--text-body`）、辅助文字**浅灰**（`--text-tertiary`）；主色暖橙 `#B4531A` 仅用于高亮（价格、主 CTA 描边、选中 Tab）；卡片表面为**纸片卡面**（`--bg-page` 同色填充 + `1rpx` `--border-color` 细描边 + `--shadow-card-stack` 柔和浅阴影）。🔴 不使用厚重棕色作为正文 / 卡片底色。
- **字体**：标题 / 菜名 / 日期 / 档位词 / **TabBar 标签** / 弹层标题用**衬线**（`--font-serif`）；价格与参数型辅助信息、按钮文案、弹层选项用**无衬线**（`--font-sans`）。字号差距清晰，拒绝信息堆砌。
- 🔴 **字重规则（Julienne）**：**所有衬线标题一律 `--weight-regular`** —— 层级由**字号 + 颜色**承担，**不靠加粗**；唯一例外：无衬线状态标签（如失败态标题）。TabBar 选中项**只换色、不加粗**。
- **纸片卡片（品牌标志）**：**同色卡面**（`--bg-page` 填充，视觉融于页面）+ **细描边**（`1rpx` `--border-color`）+ **大圆角**（`--radius-card` 36rpx）+ **低透明柔和浅阴影**（`--shadow-card-stack`，悬浮轻盈感）；**顶部左右预留信息位**；中部**内容居中**（圆形食物图 + 衬线菜名 + 辅助信息）；底部操作按钮**不贴底**。🔴 卡片内**不带大序号**（Julienne 的序号属于卡片背景层装饰）。
- **按钮**：以**线框**为主，**小圆角**（`--radius-btn`，非全圆）；主 CTA **暖橙描边 + 内部深色文字**，其余按钮中性灰描边；不使用实底填充。
- **图标**：统一细线性 Lucide 图标（`AppIcon`），不填充、不混用图标字体。
- **堆叠与手势**：卡片多层堆叠（下层缩小 + 降透明度 + 向下偏移），**左右横向拖拽翻卡**：跟手平移 + 轻微旋转 / 缩放，松手回弹或滑出；动效轻柔低速，无弹跳 / 闪光。
- **页面分层**：前景可拖拽卡片 → 中层弱化背景装饰（低透明度）→ 底层固定胶囊 TabBar。
- **空态**：卡片栈无数据时**不是另起一个空页面**，而是**同一卡位的一张占位卡片**（同卡面 + 衬线标题 + 浅灰提示）；产生第一条数据时平滑切换回卡片栈，视觉语言不断裂。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` = **`#FFFAF3`**（奶米白，🔴 全站统一；深色主题取值见 [设计变量.md](./设计变量.md) §1.2）—— **唯一承载处**；页面根 / 组件 **SHALL NOT** 再声明页面底色 |
| 主题（明暗） | **全站双主题**：页面根挂 `data-theme="light"｜"dark"` 切换语义色组；默认浅色、storage 持久化；深色取值与完整机制见 [设计变量.md](./设计变量.md) §1.2 |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；**自带滚动容器的页根必须再加 `min-height: 0`**（否则页根比可视区高出一截，页面多出一段可滚区） |
| 主滚动区 | 记忆页滚动区 `.body`：`flex: 1` + `min-height: 0`（缺 `min-height: 0` 会出现「页面 + 滚动区」双层滚动） |
| 底部胶囊让位 | 三个 tab 页统一由页面根（base `TabPage`，见 §2.1.6）让出 `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`（= TabBar 容器内容区高 + 安全区，内容不紧贴胶囊 Tab）；`TabPage` 已内置该 `padding-bottom`，页面内容区（含滚动区）**不得重复让位**；其余页不得凭空多出死留白 |
| 滚动区底部安全区（**恒需要**） | **任何**滚动承载区底部留白都须叠加 `env(safe-area-inset-bottom)` |
| 顶部安全区（**含胶囊**） | 自定义导航栏（`navigationStyle: custom`）下，内容起始 = **状态栏高度 + 导航栏高度**：状态栏高（`statusBarHeight`）覆盖刘海 / 挖孔屏；导航栏高由 `uni.getMenuButtonBoundingClientRect()` 与状态栏高算出（`胶囊高 + 上下间隙 × 2`）—— **保证顶部内容不被右上角胶囊重叠**（实现见 `client/src/utils/safeArea.ts`） |

## 1.2 圆角 / 线宽

- 分档：微件 `--radius-xs` → 控件 `--radius-btn` → 模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`；正圆 `--radius-circle`。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `1rpx`（描边 / 分隔线 / 底栏顶边）；`2rpx` 只留给**语义状态线**（选中 / 聚焦，配主色）。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-3xs`(2) → `--spacing-2xl`(48)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-title`(40) → `--font-display`(48，**页面标题与卡片主标题**同档) → `--font-hero`(64，**页头大标题与卡片装饰大字专用档**)；**正文级下限 `--font-subtitle`(24rpx)`（`--font-tiny`(20) 已退役，最底档即正文下限）**。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`（小字会飘在行中间）。

## 1.4 色彩 / 阴影

- 色板与取色边界（主色语义分档、文字四档、背景 / 边框 / 语义色 / 对比度口径）见 [设计变量.md](./设计变量.md) §1（**含 §1.2 深色组**）。
- **色值只改 `tokens.ts` 的 `COLOR_MAP`**（分浅色 / 深色两组）；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；卡片表面加 **`--shadow-card-stack` 低透明柔和浅阴影**（弥散、悬浮轻盈感；深色下转「压深」低透明语义，见 [设计变量.md](./设计变量.md) §1.2）—— 🔴 **禁高对比纯黑装饰性阴影**。

## 1.5 表面：模块 / 卡片

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块，区块之间**只靠页面留白分组**。
- **卡片表面只有一套取值**：**纸片卡面** = `--bg-page` 填充 + `1rpx` `--border-color` 细描边 + `--radius-card`(36rpx) + **`--shadow-card-stack` 柔和浅阴影**（规格见 §2.2 `PaperCard`；**美味卡片族与记忆卡共用**，两端视觉体系统一）。
- 页面 / 组件私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 阴影一律取该套或已登记的页级专属形态**（海报卡 = `--radius-card-stack` + `--shadow-card-stack`；弹层面板 = `--overlay-panel-bg` + `--radius-modal` + `--shadow-modal`）—— SHALL NOT 另立新取值。
- 模块之间的留白由消费方容器 `flex gap`（`--spacing-lg`）承担（WXSS 不支持 `+` / `~` 兄弟选择器）。
- **长文本断行唯一写法 = `overflow-wrap: anywhere`**（`word-break: break-all` / `break-word` 不作为可选写法）。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-placeholder`）；**SHALL NOT `transform: scale`**。`opacity` 只三档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 ｜ **`.85`** 主色实底 CTA — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …，会跨组件边界冒泡致「点一次跳两次」）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 两档：① **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-tertiary`；② **非主色可点件** ⇒ `opacity: .5`。禁点由全局 `.is-disabled { pointer-events: none }` 承担。**`opacity` 全站只表「在途 busy」，不用于禁用** |
| 触达下限 | 可点元素命中区 **≥88rpx（44pt）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(120) / `--duration-base`(200) / `--duration-slow`(360) + `--ease-out`；**不新增装饰性入场动效**（内容一律立即可见）；`prefers-reduced-motion: reduce` 下过渡取消、旋转环减速。
- **取值来源（SHALL NOT 裸写时长）**：按压 / 选中态过渡取 `--duration-fast`；卡片栈回弹取 `--duration-base`；卡片飞出与入场取 `--duration-slow`。
- 层级：`--z-tabbar`(100) / `--z-sheet`(2000)。
- 高度：`--tabbar-height`(116rpx) / `--tabbar-gap`(20rpx) / `--tap-target-size`(88rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；图标资源**一律下载**（`lucide-static` 官方 SVG，Lucide 线性，ISC 许可），几何**不自行绘制** —— 资源清单与获取路径见 [图标资源.md](./图标资源.md)。规格：24 网格、`stroke-width 2`、圆角端点、`fill: none`。图标**只用这一套**，SHALL NOT 混入其它图标库 / 图标字体 / emoji。
- **选中态不设 `-filled` 变体**：选中 = **同一线性图标换主色**（见 §2.1.1）。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认）/ 筛选触发器 ｜ `32` 伴随标题 ｜ `40` **TabBar** / 卡内线性功能图标 ｜ `44` 失败态 / **流末尾结束态动作图标** ｜ `48` 卡内图片占位 ｜ `64` 空态主图标 / 占位默认 ｜ `96` 整块失败态。
- `tone`：**预生成色调**（`default` / `primary` / `muted`，见 [图标资源.md](./图标资源.md) §2）—— 微信 `<image>` 支持 SVG **文件**但**不支持运行时换色**，故按色调预生成变体；**深色主题**下三档 tone 取深色色值（同见 §2），变体按主题分组生成。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键** —— 完整清单（语义 / 键 / Lucide 名 / 消费点）见 [图标资源.md](./图标资源.md) §3，**该表为唯一真源**，本节不复列。

> 新增用途须先在[图标资源.md](./图标资源.md) §3 找语义档；确无对应才新增并登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image-broken`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- **图片承载区**（海报位 / 菜品卡图位）在**加载中 / 失败 / 为空**时，一律**按该区尺寸渲染占位**（`ImagePlaceholder`）—— **不留空白、不用文字失败块**（页面用法见[风物](./风物.md) §2 · [美味](./美味.md) §4）。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

### 2.1.1 `TabBar` —— 底部胶囊 Tab

🔴 **TabBar 为底置通栏容器内的胶囊**（**非沉底全宽菜单栏**），三个 tab 页**恒可见**（本项目无二级页面，故不存在显隐切换逻辑）。

> 🔴 **本节为 TabBar 的定稿样式**：数值即为实现依据，**改动须先改本节再改代码**（文档先行）。

| 项 | 口径 |
|---|---|
| **三项与顺序** | **风物** ｜ **美味** ｜ **记忆**（显示名；↔ 文档名对照见 [UI 总览](./README.md)） |
| **定位** | **全宽通栏容器**：`position: fixed` + `left/right: 0` + `bottom: 0` + `padding-bottom: env(safe-area-inset-bottom)`（底抵屏幕有效可视区底部，不含系统底部手势横条）；容器内容区高 `--tabbar-height + --tabbar-gap + --spacing-md`(160rpx)，**胶囊在容器内水平 + 垂直居中**；胶囊宽 `calc(100vw - --page-gutter × 2 - --spacing-md)`（= 屏宽 − 88rpx，与[风物页](./风物.md)海报卡同宽）；`--z-tabbar`(100) |
| **胶囊本体** | 高 `--tabbar-height`(116rpx)（`box-sizing: border-box`）+ `--radius-pill`；🔴 外环**仅 `1rpx` `--border-color` 描边**，**无底色 / 无阴影**（与页面底色融合，不成为沉底菜单栏）；**全向**内边距 `--spacing-xs` + 项间 `gap: --spacing-xs` |
| **每项** | **两层结构**：项（`flex: 1` 等分、无描边无底色、横向居中）→ **项内层胶囊**（图标 + 文字，`--radius-pill`）；内层胶囊与外环之间由容器内边距留 `--spacing-xs`(8rpx) |

### 2.1.2 空态 —— Julienne 空态规范

- **原则**：空态是「内容为空」时同一视觉语言的延续，不做夸张插画 / 大色块；大面积留白，细线图标 + **衬线主文案** + 浅灰引导小字 + 暖橙描边主按钮。
- **两种承载**：
  - **美味页无菜品** ⇒ 栈位渲染**空态占位卡**：线性 `dish` 图标（`64rpx`、`muted`、低透明度）→ 衬线标题「暂无菜品推荐」→ 浅灰小字「等待食堂上新美食」（无插画；表面同栈卡，见 §2.2 `DishSwipeCard`）；
  - **记忆页无记录** ⇒ 年月栏下方**垂直居中**：线性 `notebook` 图标（`64rpx`、`muted`、低透明度）→ 衬线标题 + 浅灰描述 + 暖橙描边「去美味页」。
- **与 `RetryBlock` 的分工**：空态 = 一切正常但无数据；`RetryBlock` = 失败态（文本 / 列表型页面）。渲染优先级 **失败 > 空态 > 列表**。

### 2.1.3 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`flex: 1` + 纵向居中（在剩余空间内**垂直居中**）；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **图标**：`report`，`44rpx`。
- **文案**：标题 `--font-body` + `--weight-semibold` + `--text-body`；副文案 `--font-small` + `--text-tertiary`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 仅忽略点击（🔴 不引入旋转 loading —— Julienne 禁循环动画）。
- **不改标题 / 不加按钮** —— 本项目失败态只需"重试"这一个动作。
- **适用面**：**文本 / 列表型**页面的失败态（本项目 = [记忆](./记忆.md)）；**图片承载区**的失败走 §1.9 的占位。

### 2.1.4 `BaseSheet` —— 底部弹层

- **遮罩**：`--overlay-scrim`；点击关闭。
- **抽屉**：`--overlay-panel-bg` + `border-radius: --radius-modal --radius-modal 0 0` + `--shadow-modal`；`padding-bottom: env(safe-area-inset-bottom)`；上滑开合（`--duration-slow`）。
- **grabber**：`72 × 8rpx`、`--border-bold`、`--radius-pill`。
- **下拉关闭手势**：位移 > 120rpx 关闭。
- **本项目的两处用法**（均由 `MemoryActionsSheet` 复用本组件）：
  1. **长按菜单**（记忆卡长按，仅浏览态 A 可唤起）→ 反馈 / 删除记忆 / 取消；「反馈」在**同一 Sheet 内切换**为纠错选项抽屉（单选、无图标 ⇒ 抽屉内直排**选项行**，每行高 `--tap-target-size`、文案 `--font-body` + `--text-title`、行间 `1rpx var(--border-color)`、首末行无线），点选即提交并关闭；

### 2.1.5 `AppHeader` —— 全局页头（品牌 + 明暗切换）

- **定位**：🔴 **与 `TabBar` 同级的基础设施** —— 三个 tab 页**统一挂载**，不是某一页的私有内容。
- **结构**：一行三格 —— **左**：明暗切换（`moon` 浅色态 / `sun` 深色态，`44rpx` 线性图标，`tone="default"`，命中区 ≥ `--tap-target-size`，按压 `opacity: .6`）｜**中**：品牌标题「**知行食记**」（`--font-title`(40rpx) + `--weight-regular` + `--text-title` + 衬线，水平居中；左右**对称内距** `--header-title-inset`(100rpx) 把文字收进「切换钮 ↔ 胶囊」之间的安全区、超长省略 —— 对称内距**不改变居中**）｜**右**：`--tap-target-size` 等宽占位（为微信原生胶囊避让，不改动原生组件）。
- **安全区自持**：外层 `padding-top` = 状态栏高（含刘海避让）；行高 = 导航栏高（与原生胶囊垂直对齐）—— 宿主页 **SHALL NOT** 再自行加顶部内距。
- **留白**：底部 `--spacing-lg`(32rpx)，与下方内容以留白分隔（🔴 不加分割线）。
- **为什么必须在 base**：明暗切换是**全局能力**（作用于三个 tab 页），入口必须三页可达 —— 这是它区别于页面私有组件的唯一理由。
- **使用**：三个 tab 页顶部（[风物](./风物.md) / [美味](./美味.md) / [记忆](./记忆.md)）。

### 2.1.6 `TabPage` —— 三 tab 页统一外壳

- **定位**：三 tab 页（风物 / 美味 / 记忆）**统一挂载**的页面根外壳 —— 与 `AppHeader` / `TabBar` 同级的基础设施，三页复用同一套页面骨架。
- **结构**：页面根 `.page`（`flex` 纵向列、`height: 100vh`、`overflow: hidden`）+ **`AppHeader`**（行 1）+ **`hero` 插槽**（行 2）+ **`.page__main` 内容容器**（`flex: 1` + `min-height: 0`，承载默认插槽，行 3）+ **`TabBar`**（固定，行 4）。
- **`hero` 插槽盒统一高度与上下内距**：三 tab 页的 `hero` 盒（风物问候语 / 美味标题块 / 记忆标题块）统一 `min-height: var(--hero-box-height)`(176rpx) + `box-sizing: border-box` + 上下内距 `--spacing-md`(24rpx) ⇒ **切 tab 时盒高与下方内容区起点完全一致**；盒高取值 = 上下内距 48rpx + 双行标题块内容（标题 76.8 + 标题日期间距 16 + 日期 26.4 ≈ 119rpx）≈ 167rpx 后取整留余量。盒内水平对齐仍各页自理（风物居中 / 美味·记忆左对齐）；**盒内内容垂直居中**（风物问候语 / 美味·记忆标题块在 `--hero-box-height` 内垂直居中），三页标题 / 问候语基线一致；日期行高钉 `1.2`、标题与日期间距取 `--spacing-sm`(16rpx)，二者共同保证盒高确定。
- **两个插槽**：
  - `hero`（行 2，三页同一屏幕位置）：风物 = 问候语；美味 = 页级标题块（标题 + 日期 + 食堂筛选）；记忆 = 页级标题块（标题 + 日期）。
  - 默认插槽（行 3，三页同一屏幕位置）：风物 = 海报区；美味 = Z 轴菜品卡片栈；记忆 = 年月导航 + 日期分组列表。
- **TabBar 让位**：`.page` 内置 `padding-bottom = --tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`；**内容区（含滚动区）不得重复让位**（原记忆页「滚动区单独让位」特例已收敛，见 §1.1）。
- **主题**：根挂 `data-theme`（由 `useTheme` 提供），明暗切换作用于三页。
- **虚拟节点**：开启 `virtualHost`，根 `.page` 直接参与页面 flex 布局。
- **使用**：三个 tab 页根（[风物](./风物.md) / [美味](./美味.md) / [记忆](./记忆.md)）。

### `DishCardStack` —— Z 轴堆叠卡片栈（层线在卡片下部）

- **用途**：美味页卡片栈；一次聚焦一张，划走顶层后下一张**上移放大成为新的顶层**。
- **堆叠模型**：**三张真实卡片** —— 上层完整卡 + 中层 `scale 0.96` 下坠 `32rpx` + 下层 `scale 0.92` 下坠 `64rpx`；🔴 **缩放围绕底边**（`transform-origin: bottom center`）⇒ 底边只下坠不上抬，下坠量即真实露出量；**不透明、无虚化、不画线、不做虚影补位**；槽位 = `cards.slice(0, 3)`。
- **层数**：🔴 **恒定三层** —— 真实卡取队列前 3 张；不足 3 张时用**同卡面虚影层**（`stack__ghost`：同色填充 + 1rpx 描边 + 同圆角、无内容）补齐 ⇒ 划走一张后底部必然补回一层，不会塌成两层；0 张时才进空态 / 结束态。
- **图层**：上层 `z-index` 最高；中 / 下层依次递减、`pointer-events: none`；圆角统一 `--dish-card-radius`(28rpx)。
- **拖拽**：仅顶层响应**水平**拖拽（垂直滑动忽略）；跟手带 `0.9` 阻尼，旋转 `≤ ±3°`；拖拽时按钮禁用；🔴 drag 期间**后方层完全静止**（不跟手、不缩放）——后层 transform 只由档位决定，若跟着 dx 走，松手时 dx 归零会让它「跳回去」而闪一下；划走结束后由 CSS transition 平滑升档。
- **释放**：位移 `< 卡宽 22%` ⇒ 回弹 **`--duration-base`**；`≥ 22%` ⇒ 沿方向飞出 **`--duration-slow`**（`ease-out`），派发 `swipe(id)`；**下一张上移放大成为新的顶层**（卡片 key 复用 ⇒ DOM 节点移动、过渡连续），层线随之少一根。（取值来源见 §1.7）
- **栈槽**：左右 `--page-gutter`(32rpx) **对称**（与风物页海报卡左基准线一致）；上留白 0（卡片顶贴内容区顶部）、下留白 `calc(--spacing-2xl + --spacing-md)`(72rpx) —— 卡高 = 可用区 − 72rpx，纸边下探入页面让位留白
- **加载 / 空态**：顶层渲染骨架卡 / 空态占位卡（卡面同栈卡）；第一条数据上浮淡入。
- **流末尾**：`finished` 时在同一卡位渲染 `end` 插槽内容（`DishFlowEnd`）。
- **事件**：`swipe(id)` ｜ `want(card)`。
- **使用**：仅[美味页](./美味.md)。

### `DishFlowEnd` —— 美味页卡片流末尾结束态（非卡片）

- **用途**：本批卡片全部划完后占据同一卡位（由 `DishCardStack` 的 `end` 插槽承载，位于**卡片区域内、Tab 栏之上的页面居中区**，非悬浮层）；纯展示 + 两个动作事件，流水线（请求 / 批次切换）由页面负责。
- 🔴 **不是卡片**：**不套 `PaperCard`**、无描边 / 卡面圆角 / 吊孔 / 阴影 —— 直接呈现在**页面背景**上，语义是「上层卡片已全部划干净」；留白充足，是温和的结束提示而非错误页。
- **文案层级**：**衬线主标题**「今天的推荐就到这里」（`--font-title`(40rpx) + `--weight-regular` + `--text-title`，居中）→ **浅灰副标题**「明天再来看看，新的美味马上更新」（无衬线 `--font-small` + `--text-tertiary`，与标题间距 `--spacing-lg`，小于主标题、紧凑不拥挤）。
- **结构**：**纵向居中列**（`flex: 1` + 居中）+ 底部**动作区**（两列等宽居中、间距 `calc(--spacing-xl + --spacing-md)`、与副标题间距 `calc(--spacing-2xl + --spacing-lg)`）。
- **动作项（图标框在上、文字在下）**：图标框为**圆角方框** —— 边长 `--flowend-icon-box`(120rpx) + `1rpx` 描边 + `--radius-btn` 小圆角、**无底色 / 无阴影**；框内线性图标 `44rpx` 居中；框下文字 `--font-small` + `--text-title` 居中，与框间距 `--spacing-2xl`；整列可点。**重新浏览**（`refresh-cw` + `tone="default"`，中性灰描边）｜**随机首选**（`sparkles` + `tone="primary"`，**低饱和暖橙点缀**：仅描边与图标色调，文字仍为深棕，**不做高亮主色按钮**）。
- **事件**：`replay` ｜ `surprise`；`busy` 为真时「随机首选」挂 `.is-disabled`（防重复请求）。
- **使用**：仅[美味页](./美味.md) 流末尾。

### `WantButton` —— 去品尝

- **形态**：**固定宽 --want-btn-width(320rpx) × 高 --tap-target-size(88rpx)**，在卡片底部**居中**（margin: 0 auto）；圆角 --want-btn-radius(20rpx) + 描边 --want-btn-border(2rpx) 暖橙 + 暖白底（--bg-page）+ 文案 --want-btn-font(30rpx) --text-title；**无图标**。
- **配色**：暖橙描边（`--color-primary`）+ 暖白填充（`--bg-page`）+ 深色文字（`--text-title`）；**不随按压 / 选中变色**。
- **文案**：随 `tasted` 切换（**去品尝** / **取消品尝**）。
- **在途 / `disabled`**：仅**禁止点击**（全局 `.is-disabled`，`pointer-events: none`），**视觉与默认态完全一致**；`disabled` 供占位卡使用，保证图片未加载时按钮与文案照常可见。
- **按压反馈**：仅 `opacity` 微降至 `.6`，**不改色、不缩放**。
- **使用**：[美味页](./美味.md) 卡片内（主 CTA）。

### `MemoryRecordCard` —— 记忆卡（竖版 · 浏览态 A / 原位评价态 B 两互斥态）

- **尺寸 / 形态**：竖版 480rpx × 540rpx（高 > 宽），圆角 `--radius-card`(36rpx)、`--shadow-card-stack`、`overflow: hidden`（卡片裁切挂角、仅右下角局部露出）；卡内距 48/40/40、卡片表面独立不透明层。
- **浏览态 A（默认）**：**左上菜名**（衬线粗体）｜ **中部圆形菜品图**（280rpx，水平居中、上下留白均等）｜ **底部左 位置·价格** ｜ 右下 **探出式笑脸挂角**：**仅 `face` icon 本体**（无圆环、描边默认 1.75）、放大 ~4×（176rpx）、`rotate(-45°)`、**始终 `muted` 灰（不论是否评价）**；**卡片 `overflow: hidden` 裁切**（偏移 `-56rpx`，脸大半探入右下角可见）；露出部分即命中区（始终一致、不受相邻卡遮挡）；右上角清空。
- **原位评价态 B（Inline 局部模态）**：点笑脸挂角进入；卡片覆盖**与卡片同色的底色面板**（非白底弹窗，容器尺寸 / 圆角不变，不透明覆盖原图文），「为这道菜打分」+ 三档**线性表情**（meh 一般 / smile 不错 / laugh 很棒）；点表情**即时提交**并退出 B、挂角标记已评（暖棕 + 轻微填充）；点空白区**退出 B 不保存**；B 激活时**捕获手势**：禁用本卡长按、横滑动作自动关闭 B 再切卡；B 激活时挂角隐藏。
- **评分映射（仅换皮）**：一般(meh)=1 / 不错(smile)=3 / 很棒(laugh)=5（原「不喜欢(1)」界面改名为「一般」），数值契约见 [`func/client/B2`](../../func/client/B-轻量反馈/B2-评分反馈.md)，🔴 不改档位 / 不改接口；支持再次点挂角**修改**。
- **角标状态**：未评 ⇒ 浅灰（`smile`+muted）；已评 ⇒ 暖棕（`smile`+primary）+ 轻微填充（`rgba(180,83,26,.16)`）。
- **转场**：白底面板淡入 / 淡出 `200ms ease-out`；卡片按压 `scale(.98)` 保持原动效。
- **使用**：仅[记忆](./记忆.md) 日期分组卡片行。

### `MemoryActionsSheet` —— Modal Bottom Sheet + 删除二次确认弹窗

- **长按菜单（仅浏览态 A 可唤起）**：反馈 / 删除记忆 / 取消；半透明 scrim 遮罩（符合 MD 模态）。
- **反馈**：菜单「反馈」→ 同一 Sheet **内容切换**为纠错选项（[`func/client/B3`](../../func/client/B-轻量反馈/B3-菜品纠错.md)）→ 点选即提交（无输入框、无配图）。
- **删除记忆**：菜单「删除记忆」→ 关闭 Sheet、唤起**独立居中二次确认弹窗**（优先级高于 Sheet，阻断底层交互）→ 确认即删；遵循「仅未评分可取消」，后端拒绝 Toast 兜底。
- **关闭**：下滑 / 点 scrim 关闭；「取消」关闭菜单。
- **使用**：仅[记忆](./记忆.md) 长按唤起。

### `useMemoryUI` —— 记忆页全局互斥状态机（模块级单例）

- **两类互斥 UI**：原位评价态 B（`evaluatingId`，全局最多 1 张卡）｜ Modal Bottom Sheet（`sheetOpen` + `sheetMode: menu|issue`）与删除二次确认（`confirmOpen`）。
- **铁则**：① Sheet 与 评价面板 永不同时渲染；② 单卡仅 A 或 B；③ 卡片行横滑自动关闭 B；④ 页面 `onHide` 强制销毁全部状态。
- **实现**：`openEval(id)` 收 Sheet、`openMenu(id)` 收评价态、`openIssue()` 菜单内切换纠错、`requestDelete()` 收 Sheet 起确认、`resetAll()` 清空；由[记忆](./记忆.md) §2 联动。



### `MonthTimeline` —— 年月导航

- **结构**：横向可滑；每项**上下层级** —— **年份小字在上、月份大号衬线在下**（对标 Julienne 年月滚动栏；不再左右横排）；**连续月份轴**：取最早记录月份 → 当前月份（含中间无记录月份）生成一整条连续数组，**空月份保留节点**（仅视觉弱化，不删除），项**宽度随内容自适应（不再固定）**。
- **月份（全部同字号）**：`--font-hero`(64rpx) + **衬线**，所有项一致（与页标题「记忆」同字号）；年份 `--font-small`(22rpx) 在上。
- **选中 / 未选（仅颜色区分）**：选中月 `--text-title`（深色）；未选月 `--text-placeholder` + `opacity: .65`（浅灰弱化）；年份同档（选中 `--text-tertiary`、未选 `--text-placeholder` + `opacity: .65`）。
- **项间距**：`--spacing-lg`(32rpx)；每项**宽度随内容自适应**（中文 2 字月 ≈128rpx、3 字月「十一月 / 十二月」≈192rpx，不再固定）；文字左对齐；左右内距 `--page-gutter`；整项命中 ≥ `--tap-target-size`；屏宽约露 4–5 项、最右项半露（暗示可横滑）。
- **滚动**：外层 `scroll-view` 横向（`scroll-x` + `enhanced` + 隐藏滚动条）；**内容宽 > 屏宽时可滑**（月份较少时自然不滚动）；滑动结束后**选中月自动居中吸附**视口中心。
- **数据**：有记录 ⇒ 连续轴（最早记录月 → 当前月，空月份保留节点）；无记录 ⇒ 近三月兜底（纯装饰，对应 §4 空态）。
- **下方联动**：切到空月份时，下方日期分组**直接不渲染卡片**（空月份只做视觉弱化、不挂载记录）；切选仅切筛选、不重新请求，内容平滑淡入。
- **使用**：记忆页顶部。

### `CanteenFilter` —— 食堂筛选

- **形态**：右上角**下拉** —— 用**原生 `picker`**（零自绘）；触发器为胶囊触发器「当前食堂名（默认「全部」）+ `arrow-down` 图标」—— **轻量化**：`1rpx` `--border-color` 细描边 + `--radius-btn`（小幅度柔和圆角，非全圆）、高 `--tap-target-size`（命中下限不变）；食堂名 `--font-small` + `--text-tertiary`、图标 `28rpx` + `tone="muted"`（低饱和度，不抢视觉重心）。
- **默认**：「全部」。
- **切换**：即重筛推荐流，卡片序列重掷。
- **使用**：仅[美味页](./美味.md) 右上角。

# 三、维护口径

1. **新公共组件**：先进本文件登记规格，再被页面消费。
2. **页面改动**：若某页需偏离本文件口径，**先修订本文件**（或登记该页例外）再动代码。
3. **页面设计稿**不得复述本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
4. **改视觉值只改 token**，不在页面里裸写。
