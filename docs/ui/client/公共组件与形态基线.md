# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` —— **唯一承载处**（小程序最低层，天然在壁纸层之下）。**页面根 / 组件 SHALL NOT 再声明页面底色**。**唯一例外**：`find` 搜索页在其上叠一层**顶部渐变**（`--bg-soft-orange → --bg-page`，仅顶部氛围、**非满屏渐变**） |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；页根声明 `height: 100vh; height: 100dvh`（`min-height` 必须双声明，否则会把页根 `dvh` 顶回 `vh`）。⚠️ **自带滚动容器的页根必须再加 `min-height: 0`** —— 移动端 `100vh`（最大视口）通常大于 `100dvh`（当前视口），全局兜底的 `min-height` 与页根 `height` 并存时 **min 胜出** ⇒ 页根比可视区高出一截 ⇒ **页面本身**多出一段可滚区（内容并未超屏也会滚）。全站 10 个页根一律按此口径：`home` / `profile` / `notifications` / `my-reviews` / `feedback` / `correction` / `auth` / `detail/dish` / `find` / `mine` |
| 主滚动区 | `.scroll-wrap { min-height: 0 }` —— flex 子项默认 `min-height: auto` 不收缩，缺它会出现「页面 + 滚动区」双层滚动 |
| 滚动区底部留白 | **不全局兜底**：仅自带 TabBar 的页（home / mine）由页面自身让出菜单栏；其余页不得凭空多出 TabBar 高度死留白 |
| 固定底栏页 | 滚动区 `padding-bottom: calc(var(--action-bar-height) + env(safe-area-inset-bottom))`，禁内容被遮挡 |
| **主操作位置通则** | **长表单页**（意见反馈 / 菜品纠错 / 写评价等「内容长于一屏」的表单）主操作**固定底部常驻**，不随内容滚动 —— 否则用户必须滚到底才能提交，这是**功能可达性问题**；实现唯一落点 = `styles/_action-bar.scss` 的 `action-bar` mixin（`position: fixed` + `--module-bg-strong` + `--shadow-bar-soft` + safe-area 内距），左右内距与页面 gutter 同轴。**轻量编辑页**（如个人信息编辑：仅头像 / 昵称两处可改）与长表单页**同一条**：主操作固定底部常驻（`AppButton` 通栏），**不设**页头文字按钮。**页头（`AppHeader` / `AppTitleBand`）恒不承载业务操作** —— 微信原生胶囊吃掉右侧 ≈ 204rpx，行内右侧余量不足以在 88rpx 触达下限内并存「右操作 + 绝对居中标题」（二者数学互斥，见 §2.3）。**列表级批量动作**（如系统通知「全部已读」）落**列表上方常驻动作行**：右对齐、在滚动区之外（位置稳定不跳动）。**禁用档统一**：主色实底 = 灰底灰字（`AppButton`），描边 / 文字类 = 中性灰字（`.is-disabled`），二者**都不降透明**（`opacity` 只表在途 busy） |
| 滚动区底部安全区（**恒需要**） | **任何**滚动承载区（`scroll-wrap` / `scroll-view` / 页内滚动容器）底部留白都须叠加 `env(safe-area-inset-bottom)`（Home Indicator 避让）——「无 TabBar 的二级页」也不例外；仅自带 `TabBar` 的页由**页面根**让位（见上条），不由滚动区重复让位 |
| 宽屏（仅 H5 / 桌面） | `@media (min-width: 768px) { .scroll-wrap { max-width: 720px; margin: 0 auto } }` |
| 壁纸 | 全站**页面级一处** `<PageWallpaper fixed />`（`z-index: var(--z-page-bg)` = −1）；壁纸**必须走 `<image>`**（WXSS `background-image: url()` 取不到包内本地路径） |
| 纱（wash） | `--page-wash: rgba(255, 248, 239, 0.7)` —— **α 是唯一旋钮**，铺满整张壁纸、无分段 |

## 1.2 圆角标度（单位统一 rpx；跨端同值口径见 Web 端设计变量 §5，`rpx = 2 × px` @375pt）

| token | 值 | 用途 |
|---|---|---|
| `--radius-none` | `0` | 形状重置 |
| `--radius-xs` | `24rpx` | 微件：焦点环等极小件（12px） |
| `--radius-btn` | `32rpx` | 按钮 / 控件行（16px，控件主档） |
| `--radius-icon` | `32rpx` | 图标底 / 输入项容器 / 头像方图（与 btn 同值、语义不同） |
| `--radius-card` | `40rpx` | **模块表面**（面板主档，20px） |
| `--radius-modal` | `56rpx` | 底部弹层顶部圆角（28px） |
| `--radius-pill` | `999rpx` | 胶囊（搜索框 / chip / 进度条）—— 形状语义，不随档位调整 |
| `--radius-circle` | `50%` | 正圆（头像 / 圆点 / 指示器）—— 形状语义，不随档位调整 |

值域遵循「块越大越圆」：微件 24 → 控件 32 → 卡片 40 → 弹层 56（rpx）；全部落在 4pt 栅格（12 / 16 / 20 / 28 px）。

**圆角只按「物件量级」分档**：**可点**胶囊（chip / 搜索框 / 词条）→ `--radius-pill`；**不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），故不设「不可点标签」专用档。pill 类消费方：搜索历史 / 猜你喜欢词条（find）、**评价星级筛选 chip**（detail/dish）。

**SHALL NOT 裸写圆角值**（全仓 `border-radius: <数字>rpx` 当前 0 处）。

## 1.3 间距标度（4pt 栅格）

`--spacing-3xs` 2 ｜ `--spacing-2xs` 4 ｜ `--spacing-xs` 8 ｜ `--spacing-sm` 16 ｜ `--spacing-md` 24 ｜ `--spacing-lg` 32 ｜ `--spacing-xl` 48 ｜ `--spacing-2xl` 64（单位 rpx）

- `2xs` 为半格，供星标 / 徽标等紧凑布局，避免裸 4rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx` = 16pt，iOS 列表 inset 常规）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 卡片纵向块间距统一 `--spacing-md`（12pt），由公共 `CardSection` 外距承担。

## 1.4 字号 / 字重 / 字距标度

| token | 值 | 档位 |
|---|---|---|
| `--font-tiny` | `20rpx` | 最小辅助 |
| `--font-aux` | `22rpx` | 辅助说明 |
| `--font-small` | `24rpx` | 小字 |
| `--font-body` | `28rpx` | 正文 |
| `--font-caption` | `30rpx` | 说明档 |
| `--font-subtitle` | `32rpx` | 副标题 |
| `--font-h3` | `36rpx` | 三级标题 |
| `--font-h2` | `40rpx` | 二级标题（分区标题） |
| `--font-title` | `44rpx` | 标题档（页面名 / 「返回」） |

**字重**：`regular` 400 ｜ `medium` 500 ｜ `semibold` 600 ｜ `bold` 700 ｜ `heavy` 800
**字距**：`--tracking-h2` −0.02em ｜ `--tracking-h3` −0.01em（仅标题收紧，正文不收紧）
**正文级字号下限 12px（24rpx）。**

**行内基线对齐（同行不同字号文本的通则）**：同一行并排「标题级 + 正文级 + 弱化小字」时（如菜名 + 价格 + 「有问题?」入口），**一律取基线对齐**（`align-items: baseline`）—— 令各文本**首行基线落在同一条水平线上**，底部齐平。
- **SHALL NOT** 用 `align-items: center` 排「同行不同字号文本」：小字那件会被垂直居中在行内，既不在大字行的基线上、上下又各留一段空白，看起来「飘在中间」而不是「和那一行排在一起」。
- **适用范围（不限于某一页）**：菜品详情信息卡名称行与评分行、搜索结果卡评分行、首页菜品卡评分行 —— **一切「同一行内字号不同」的文本组**。
- **配套**：同一行内文本**行高宜一致**（`1.2` 档）；行高差过大时基线仍对齐，但行盒高度不一会让块高看起来仍不匀。
- **代码落点**：`styles/_baseline-row.scss` 的 `baseline-row` mixin（唯一实现，消费方 `@include`；消费方文件需 `<style scoped lang="scss">`）。

## 1.5 色彩

- **色板与取色边界（含主色语义分档、文字四档、背景 / 边框 / 语义色 / 星色与对比度口径）的唯一真源 = [首页菜品浏览.md](./首页菜品浏览.md) §10**（既有裁决，`theme/tokens.ts` 亦以该节为准）。本节**不重复列值**。
- **色值只改 `theme/tokens.ts` 的 `COLOR_MAP` / `CSS_VARS`**（键 = 全局 CSS 变量名）；`theme/generated-colors.css` 由 `App.vue` `@import` 引入，须与 `CSS_VARS` 逐键一致；不接受 `var()` 的原生 API 常量见 §1.16。
- **页面 / 组件 SHALL NOT 裸 hex**（当前全仓自检：0 处违规，命中的均为注释）。
- 星级色为**独立语义色**，**SHALL NOT 随主色换肤**。
- 提示文字 `--text-hint` = `var(--text-tertiary)`（派生引用，非独立色值）。

## 1.7 输入项（下划线语言，全站统一）

- **形态**：`background: transparent` + `border: none` + **仅底部 `1rpx solid var(--border-color)`**。
- **聚焦**：底线转 `--color-primary`（**无闪烁、不加外描边**）。
- **必填标记 `*`**：取 **`--color-error`**（错误色 token，**全站统一**），置于字段标签之后；**SHALL NOT** 用主色橙，也**不得**用输入底线色。
- **行内列表用法**（如个人信息编辑）：底线由**所在行的行分隔线**承担，聚焦改该行 `border-bottom-color`（避免「输入底线 + 行分隔线」双线）。
- **输入框聚焦时 SHALL NOT 呈现主色描边**：`input / textarea` 的 `:focus` 与 `:focus-visible` 统一 `outline: none`，输入态由容器自身样式表达。
- 占位文字色 `--text-placeholder`。
- **校验时机（全站统一）**：**文本类** = 失焦即校验（**不阻断输入**）+ 提交时全量复校；**数值类** = 同文本类；**选择类** = 选中即定、即时反馈。错误文案**紧邻字段下方**（`.field-error`），**不做顶部汇总**；提交失败时**保留已填内容**。
- **键盘避让（必声明，否则视为交付缺口）**：**含输入的页面必须写明键盘避让口径** —— ① **固定底栏页**（如个人信息编辑、意见反馈、邮箱认证）：底栏按钮须在键盘弹起时**不被遮挡**（`scroll-view` 底部留白 = `--action-bar-height` + 键盘高度）；② **弹层表单页**（如写评价弹层、属性选择弹层）：开 `BaseSheet` 的 **`keyboardLift`**，且弹层内输入框一律 `:adjust-position="false"`（防双位移）。

## 1.8 表面：模块 / 卡片

### 1.8.1 模块 `.module-wrap`（**极简无卡片**，页面内容块的默认形态）

- **不用大白卡把一个页面的全部内容框在一起**：每个功能区块各自成一块 `.module-wrap`，区块之间**只靠页面留白分组**。
- **全局唯一实现** = `App.vue` 的 `.module-wrap`：`--module-bg`（暖奶米半透，α 唯一旋钮 0.65；发糊机型用 `--module-bg-strong` 0.75 兜底）+ `--radius-card`(40rpx = 20px) + `--module-shadow`（极淡暖棕）+ `padding: --spacing-lg`。
- **表面只有一套**：页面私有的 `.card` / `.info-card` / `.hero-card` / `.q-card` / `.dish-card` 等类**只承担布局**（`margin` / `overflow` / `flex`）；**底色、圆角、阴影一律由 `.module-wrap` 提供** —— SHALL NOT 在页面私有类里另写 `background` / `border-radius` / `box-shadow` 形成第二套表面（这是「页面风格不统一」的最主要来源）。
- **模块之间的留白由消费方容器的 `flex gap`（`--spacing-lg`）承担** —— 小程序 WXSS **不支持 `+` / `~` 兄弟选择器**（见 [搜索.md](./搜索.md) 样式区登记），故不用相邻兄弟外边距。
- **模块内不设分割线**：模块内部的项目用上下内边距 / `gap` 分组。
- **`padding: 0` 变体（登记例外）**：内容需要通栏贴边时由消费方覆写 —— 首页菜品卡（大图贴上缘）、我的页两块模块（身份卡顶部条纹 / 列表行分隔线通栏）。
- **落地页**：意见反馈页（类型 / 描述 / 截图三块）、搜索页（搜索记录 / 猜你喜欢两块）、搜索结果条目（每条一块）、首页菜品卡、我的页（个人信息 + 快捷功能 / 账号设置两块）。
- **弹窗不在此列**：模态浮层保留卡片形态，底色取 `--overlay-panel-bg`（见 §2.8）。

### 1.8.2 卡片 `CardSection`

- **唯一实现 = 公共 `CardSection`**；`--module-bg`（暖奶米半透）+ `--radius-card`(20rpx) + `--module-shadow`（极淡暖棕）；内距 `--spacing-md`，外距 `--spacing-md --page-gutter`（首个卡片上边距收紧为 `--spacing-md`）；**卡壳自带 `overflow: hidden`** —— 这是**圆角裁切契约**：卡内条纹 / 负 margin 子元素一律由卡壳裁齐，页面不再各自 `:deep` 补裁切。
- **长文本断行唯一写法 = `overflow-wrap: anywhere`**：凡是会折叠的文本槽（`-webkit-line-clamp`）或可能超长的字段（菜名 / 简介 / 四维值 / 拒绝原因）都必须具备断行保护，否则超长无空格串（URL / 长英文）会在折叠处**静默消失且不带省略号**。`word-break: break-all` 与 `break-word` **不作为可选写法**（同语义多写法会漂移）。
- `flush` = 去掉自身外边距（块间距由父级统管）。
- 页面可抬特异度覆盖内距（如前缀页面根改 `--spacing-lg`）；**SHALL NOT 手写卡片三件套另起一套壳**。
- **列表类内容块**（多行成组，行数不可预估）：行高 ≥ `88rpx`、卡内左右内距 `--spacing-md`、**行间 `1rpx solid var(--border-color)`、首末行无线**（行分隔线口径见 §1.9）。消费方：系统通知列表、我的主页评价卡。**SHALL NOT** 为列表内容块另写一套壳。
- **文档类内容块（`.doc.module-wrap`）**：合规文档页（用户协议 / 隐私政策**同款**）把单份静态文本（标题 + 生效日期 + 分节标题 + 正文）**整体收进一块 `.module-wrap`**（连续长文本不拆块）；底色 / 圆角 / 阴影 / 内距由全局类承担，页面只管内部排版。

## 1.9 分隔线

| 场景 | 口径 |
|---|---|
| 列表行分隔（**多行成组**：通知行、评价行等行数不可预估的列表） | `1rpx solid var(--border-color)`；**最上 / 最下无线**（行数多时无线条难辨行边界） |
| 列表项间距（**短列表**：项数固定且 ≤3，如「我的」页其他分组） | **不设分隔线**，改用各行上下内距留白分组 |
| 卡内段间分隔 | `1rpx`（`--border-color`） |
| 输入项底线 | `1rpx`（见 §1.7） |
| chip / 单选项描边 | `2rpx`（**选中语义状态线**，配主色；非「输入底线 / 列表分隔线」语义） |
| 弹层头部 / 固定底栏顶边 | `1rpx`（**结构线**，见 [设计变量.md](./设计变量.md) §2.1 线宽裁决） |
| 虚线框（上传添加格） | `1rpx dashed var(--border-color)` |
| 图片 / 缩略图占位底 | 暖调不透明 `--bg-placeholder`（**不做半透**：占位须是实心块，否则会透出背景显得「空」） |

## 1.10 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-soft` / `--bg-placeholder`；**底色与 `opacity` 二选一，不叠加**）；**SHALL NOT `transform: scale`**、**SHALL NOT 裸色值**。`opacity` **只三档**：**`.6` = 文字 / 图标小件**（顶栏返回、Sheet 关闭、文字链、chip、星标、行内图标钮、TabBar 项）｜**`.7` = 卡片 / 行 / 图片 / 整块**（全局兜底 `.pressed { opacity: 0.7 }`）｜**`.85` = 主色实底 CTA**（`AppButton` / `EmptyState` / `RetryBlock` 双 CTA / 搜索钮 / 表单提交·确认钮）—— **同族元素必须取同值**；**禁用档 `opacity: .5` 不属于按压档位**。`<text>` / `<image>` **不支持** `hover-class` ⇒ 须外层包 `<view hover-class>`（嵌套可点件加 `hover-stop-propagation`） |
| **组件对外事件命名** | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …）—— 原生事件**会跨自定义组件边界冒泡**，与 `emit` 各触发一次 ⇒ **点一次跳两次**（真实事故：首页搜索胶囊曾 `emit('tap')` + 页面 `@tap`，连跳两页搜索页）。统一用**业务语义名**：`enter`（进搜索页）/ `press`（按钮按下）/ `back` / `select` / `close` / `retry` / `pick` / `ready` / `more` / `action`。**门禁 `npm run check:events`**（扫描全组件 `emit` 名与原生名交集，命中即失败） |
| 禁用 | **三档**（`opacity` 全站只表「在途 busy」，不用于禁用）：① **主色实底** ⇒ 底 `--bg-input` + 字 `--text-tertiary`；② **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-tertiary`；③ **非主色可点件**（图片添加格 / 类型卡）⇒ `opacity: .5`。禁点由全局唯一令牌 **`.is-disabled { pointer-events: none }`** 承担（`App.vue`），组件不得再自设降透明 / 降灰度作为禁用视觉 |
| 键盘焦点环 | `:focus-visible:not(input):not(textarea)` → `outline: 3rpx solid var(--color-primary)` + `outline-offset: 2rpx` + `border-radius: var(--radius-xs)`（仅键盘可达时显示） |
| 触达下限 | 可点元素命中区 **≥88rpx（44pt）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.17 列表底部反馈（`.list-foot` 全局文字行）

全局 `.list-foot` / `.list-foot-text`（`App.vue` 唯一实现）承载**列表末尾的一行状态文字**，全站不引入骨架屏。分页滚动列表在列表末尾按「触底三态」渲染：

| 态 | 判据 | 文案 |
|---|---|---|
| 在途（触底加载更多） | `loading && list.length` | 「正在加载更多…」 |
| 到底 | `finished && list.length` | 「没有更多了」（find 结果态用场景化「没有更多结果了」） |
| 封顶（页数上限） | 页数达上限（`pageLimited`） | 「已展示前 N 个结果，切换大类可查看更多」（封顶优先于到底） |

- 首屏在途（列表为空）= `.list-foot`「加载中…」；切视图在途 = 旧列表保留 + 列表末尾 `.list-foot`「正在切换…」；重置式刷新在途且列表非空 = 保留旧列表 + 末尾「加载中…」（不整块清空）。
- 到底 / 在途判据消费分页壳返回的 `finished` 与 `loading`（`usePagedList`）；首页由 store 导出 `homeFinished`。
- 消费方：`home`（HomeContent）、`find`（结果态）、`notifications`、`my-reviews`、`detail/dish`（页面级与评价区在途行）。

# 二、公共组件视觉规格

> 17 个跨页复用组件。**各页设计稿只写「本页用法」**，规格一律以本表为准。

## 2.1 `CardSection` —— 卡片外壳（全站唯一实现）

- **规格**：`--module-bg`（暖奶米半透）+ `--radius-card`(20rpx) + `--module-shadow`（极淡暖棕）；内距 `--spacing-md`；外距 `--spacing-sm --spacing-md`（首卡上边距 `--spacing-md`）。
- **变体**：`flush` ⇒ 外边距归零。
- **消费方**：菜品详情（信息 / 评价两卡）、我的主页（身份卡 + 评价列表卡）。

## 2.2 `SectionTitle` —— 分区标题

- **规格**：无竖线纯文本；flex 行 + `gap: --spacing-xs`；默认 `margin-bottom: --spacing-sm`。
- **标题**：`--font-h2`(40rpx) + `--weight-heavy`(800) + `--text-primary` + `--tracking-h2`；单行省略。
- **计数** `count`（可选）：`--font-h3`(36rpx) + `heavy` + **与标题同色** + 等宽数字；`null` 不渲染（在途 / 失败不显示数字）。
- **`#extra` 具名槽**：右侧附加信息（如「写评价」轻量入口 / find 页「清空」）；消费方均为本组件**直接**使用方，无跨层 slot 塌缩风险。
- **`noMargin`**：去掉标题下外边距（间距交由容器自持）。

## 2.3 `AppHeader` —— 二级页顶栏（带返回）

- **规格**：`position: sticky; top: 0` + `--z-header`；**恒透明**（不含底色 / 蒙版）；底部留白 `--spacing-sm`；顶部安全区 `max(statusBar, env(safe-area-inset-top))`。
- **左「返回」**：**文字**（非图标），`--font-title`(44rpx) + `bold`；命中区撑满导航行高（≥88rpx）；按压 `opacity: .6`。
- **返回行为（组件内建，页面不重复声明）**：`@back` = **有返回栈 → `navigateBack`；无返回栈（分享 / 外部跳转进入）→ `backToHome`**。**带深链参数的页面**（如菜品问题反馈 `dishId`）必须依赖此兜底，否则分享进入时返回键失效。
- **标题**：有返回 ⇒ **绝对居中**（`--font-title` + `bold`）；`showBack=false` ⇒ **居左**（与 `AppTitleBand` 同位）。
- **标题限宽**：`max-width: 56%`，**唯一目的 = 标题自身不进入微信原生胶囊水平范围**（该限宽下 6 字页面名 132px 仍完整，超长单行省略）。**SHALL NOT** 为给「页头操作」腾位而把限宽继续压小（33% 之类会把「个人信息编辑」等页面名截断）；页头**无操作位**，无需为其腾位。
- **无右操作**：本组件**不提供**右操作能力（无 `#action` / 默认插槽，无 `.nav-actions`）—— 页头行内右侧只余胶囊避让区，任何 ≥88rpx（触达下限）的操作都会与绝对居中标题重叠；页面操作落点见 §1.1「主操作位置通则」。
- **与 `AppTitleBand` 的分工**：**两个组件、按需显示、不合并** —— 普通二级页用本组件（`AppHeader`）；**标题需随滚动淡入**的页面（`home` / `find` / `detail/dish`）用 `AppTitleBand`（其自带「返回」）。
- **消费方**（8 处）：`profile` / `privacy/DocPage` / `notifications` / `my-reviews` / `feedback` / `correction`（菜品纠错）/ `auth` / `mine`（`show-back=false`）。

## 2.4 `AppTitleBand` —— 固定标题带（无返回）

- **规格**：`position: fixed; top: 0` + `calc(--z-header + 1)`；**恒透明、不铺任何表面**；`pointer-events: none`（可点件单独抬回）。

## 2.6 `EmptyState` —— 空态

- **文字**：主文案 `--font-body` + `medium` + `--text-secondary`；次文案 `--font-aux` + `--text-tertiary`。

# 三、跨页版面：身份卡（用户信息模块）

「我的」页用户信息模块与「我的主页」用户信息卡是**同一身份版面的两种形态**（前者 = 卡片 A 内第 1 段、整段热区 → 我的主页；后者 = 独立一级卡 + 右侧动作位）。两页**同源同字符串**，各页文档只写自身差异。

**实现**：公共组件 `components/IdentityCard.vue`（§2.17）—— 两页均直接消费，身份版面样式与标记由组件统一持有（两页不各自维护）；排版参数收敛在 `src/styles/_identity-card.scss`。

**内容口径**（两态同结构：头像 / 主行 / 副行 / 右侧）

| 位置 | 认证态（`bindEmail` 非空） | 游客态（未认证） |
|---|---|---|
| 头像 | 头像；空 / 失败 → 统一占位 | 同左（多为静默登录，无头像） |
| 主行 | `nickname`（**后端保证非空**，端上不兜底） | 同左（游客默认「食客 + ID 尾 4 位」由**后端**生成） |
| 副行 | 校园邮箱 `bindEmail`（空值回落 `--`） | 恒「未完成校园认证」 |
| 右侧 | 「我的」页 = `arrow` 图标；「我的主页」=「编辑个人信息」描边胶囊 | **两页均不渲染动作位** |
| 顶部 6rpx 条纹 | `--color-primary-soft` | transparent（**占位保留**，两态等高） |

- **副行语义**：认证态 = 身份**凭据**（证明「我是谁」）；游客态 = 身份**状态**（说明「我缺什么」）。
- 游客态昵称**由后端默认值承载**（新游客号默认「食客 + ID 尾 4 位」）—— 端上 **SHALL NOT** 自行派生，也 **SHALL NOT** 替换为「游客」（后端已保证非空）。
- **编辑入口**：编辑身份信息是**认证态才具备的能力** ⇒ 「编辑个人信息」胶囊**仅认证态渲染**，游客态无任何入口（对应 [个人信息编辑.md](./个人信息编辑.md) 的入口口径为「仅认证态可达」）。
- 认证动作**单一入口** = 「我的」页宫格「身份认证」格；身份卡**不放置**「去认证」入口。

**排版参数**（两页同值）

| 项 | 值 |
|---|---|
| 头像 | 120rpx 圆形（`--radius-circle`） |
| 头像空值 / 失败占位 | 公共 `ImagePlaceholder`（`name="user"`、图标 60rpx、灰底 `--bg-placeholder`，宿主裁圆） |
| 头像 → 文字间距 | `--spacing-md` |
| 主行 | `--font-subtitle` / `--weight-semibold` / `--text-primary`，单行省略 |
| 副行 | `--font-aux` / `--text-tertiary`，单行省略 |
| 主行 ↔ 副行距 | `--spacing-sm` |
| 卡内上下内距 | `--spacing-lg` |
| 顶部条纹 | 高 6rpx，两态恒在（游客态 transparent ⇒ 两态等高），须由卡片圆角裁切 |

# 四、本文件的维护口径

1. **新公共组件**：先进本文件登记规格，再被页面消费。
2. **页面改动**：若某页需要偏离本文件口径，**先修订本文件**（或在本文件登记该页例外）再动代码。
3. **页面设计稿**：不得复述本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.x`。
4. **改视觉值只改 token**：形状 / 间距 / 字号 / 色彩一律改 `theme/tokens.ts` 或 `App.vue` 的 token 块，不在页面里裸写。

# 五、交付门禁（`client` 侧）

`npm run verify` 串行执行八道，任一失败即阻断交付：

| # | 门禁 | 覆盖 |
|---|---|---|
| 1 | `check:contract` | 契约生成产物存在 / re-export 与契约一致 / `RawRow` 未回潮 |
| 2 | `check:icon` | 图标体系一致：单一来源 / 键已登记 / 尺寸档合规 / 颜色实色 |
| 3 | `check:ui` | 裸色值 / 裸尺寸 / `@click` 归零 |
| 4 | `check:doc` | 零旧方案残留 + 文档相对链接可解析 |
| 5 | `lint` | ESLint + oxlint |
| 6 | `type-check` | `vue-tsc` 全量类型检查 |
| 7 | `test` | Vitest 单测全绿 |
| 8 | `build:mp-weixin` | **小程序产物可编译** |

**第 8 道不可省略**：1~7 道均为静态检查，**不产出小程序产物**，故 SCSS 语法损坏（如多余 `}`）、CSS 字面量转义残留、模板编译错误等**只有构建能发现**。样式改动后必须让构建过一遍。
