## 0 · 设计语言（Julienne 极简文艺轻拟物）

> 适用：**学生端全部页面与组件**。所有 UI 产出严格遵循本节；页面稿只写「本页用法」，不复述本节。

- **关键词**：极简 / 文艺 / 轻拟物 / 留白 / 暖调 / 杂志感 / 纸质卡片隐喻。
- **底色与色彩**：页面纯白（`--bg-page`），正文**深炭灰**（`--text-title` / `--text-body`）、辅助文字**浅灰**（`--text-tertiary`）；主色暖橙 `#B4531A` 仅用于高亮（价格、主 CTA 描边、选中 Tab）；卡片为**实色奶白底**（`--bg-card-solid`）。🔴 不使用厚重棕色作为正文 / 卡片底色。
- **字体**：标题 / 菜名用**衬线**（`--font-serif`）；正文、辅助信息、按钮、Tab 用**无衬线**（`--font-sans`）。字号差距清晰，拒绝信息堆砌。
- **食谱卡片（品牌标志）**：**实色奶白纸片**（`--bg-card-solid`）+ **圆角**（`--radius-card-stack` 24rpx）+ 柔和卡栈阴影，**无实体描边**；**顶部左右预留信息位**；中部**内容居中偏上**（圆形食物图 + 衬线菜名 + 辅助信息）；底部操作按钮**贴底**。🔴 卡片内**不带大序号**（Julienne 的序号属于页面底层装饰）。
- **按钮**：以**线框**为主，**小圆角**（`--radius-btn`，非全圆）；主 CTA **暖橙描边 + 内部深色文字**，其余按钮中性灰描边；不使用实底填充。
- **图标**：统一细线性 Lucide 图标（`AppIcon`），不填充、不混用图标字体。
- **堆叠与手势**：卡片多层堆叠（下层缩小 + 降透明度 + 向下偏移），**左右横向拖拽翻卡**：跟手平移 + 轻微旋转 / 缩放，松手回弹或滑出；动效轻柔低速，无弹跳 / 闪光。
- **页面分层**：前景可拖拽卡片 → 中层弱化背景装饰（低透明度）→ 底层固定胶囊 TabBar。
- **空态**：卡片栈无数据时**不是另起一个空页面**，而是**同一卡位的一张占位卡片**（同卡面 + 衬线标题 + 浅灰提示）；产生第一条数据时平滑切换回卡片栈，视觉语言不断裂。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` = **`#FFF9ED`**（奶米色，🔴 全站统一）—— **唯一承载处**；页面根 / 组件 **SHALL NOT** 再声明页面底色 |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；**自带滚动容器的页根必须再加 `min-height: 0`**（否则页根比可视区高出一截，页面多出一段可滚区） |
| 主滚动区 | `.scroll-wrap { min-height: 0 }`（缺它会出现「页面 + 滚动区」双层滚动） |
| 底部胶囊让位 | **不全局兜底**：无滚动区的页（发现 / 美食）由**页面根**让出 `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`（`--spacing-md` 是**呼吸位**，内容不得紧贴胶囊 Tab）；记忆页（含滚动区）由**滚动区底部留白**让出同一高度；其余页不得凭空多出死留白 |
| 滚动区底部安全区（**恒需要**） | **任何**滚动承载区底部留白都须叠加 `env(safe-area-inset-bottom)` |
| 顶部安全区（**含胶囊**） | 自定义导航栏（`navigationStyle: custom`）下，内容起始 = **状态栏高度 + 导航栏高度**：状态栏高（`statusBarHeight`）覆盖刘海 / 挖孔屏；导航栏高由 `uni.getMenuButtonBoundingClientRect()` 与状态栏高算出（`胶囊高 + 上下间隙 × 2`）—— **保证顶部内容不被右上角胶囊重叠**（实现见 `client/src/utils/safeArea.ts`） |
| 宽屏（仅 H5 / 桌面） | `@media (min-width: 768px) { .scroll-wrap { max-width: 720px; margin: 0 auto } }` |

## 1.2 圆角 / 线宽

- 分档：微件 `--radius-xs` → 控件 `--radius-btn` → 模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`；正圆 `--radius-circle`。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `1rpx`（描边 / 分隔线 / 底栏顶边）；`2rpx` 只留给**语义状态线**（选中 / 聚焦，配主色）。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-3xs`(2) → `--spacing-2xl`(48)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`48rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-tiny`(20) → `--font-title`(40) → `--font-display`(48，**页面标题与卡片主标题**同档)；**正文级下限 `24rpx`**。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`（小字会飘在行中间）。

## 1.4 色彩 / 阴影

- 色板与取色边界（主色语义分档、文字四档、背景 / 边框 / 语义色 / 对比度口径）见 [设计变量.md](./设计变量.md) §1。
- **色值只改 `tokens.ts` 的 `COLOR_MAP` / `CSS_VARS`**；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；内容块阴影恒为 `--module-shadow`（极淡暖棕，**禁黑色阴影**）。

## 1.5 表面：模块 / 卡片

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块 `.module-wrap`，区块之间**只靠页面留白分组**。
- **全局唯一实现** = `App.vue` 的 `.module-wrap`：`--bg-card` + `--radius-card` + `--module-shadow` + `padding: --spacing-lg`。
- **表面只有一套**：页面私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 阴影一律由 `.module-wrap` 提供** —— SHALL NOT 在页面私有类里另写，形成第二套表面。
- 模块之间的留白由消费方容器 `flex gap`（`--spacing-lg`）承担（WXSS 不支持 `+` / `~` 兄弟选择器）。
- **长文本断行唯一写法 = `overflow-wrap: anywhere`**（`word-break: break-all` / `break-word` 不作为可选写法）。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-soft` / `--bg-placeholder`；**二者不叠加**）；**SHALL NOT `transform: scale`**。`opacity` 只三档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 ｜ **`.85`** 主色实底 CTA — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …，会跨组件边界冒泡致「点一次跳两次」）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 三档：① **主色实底** ⇒ 底 `--bg-input` + 字 `--text-tertiary`；② **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-tertiary`；③ **非主色可点件** ⇒ `opacity: .5`。禁点由全局 `.is-disabled { pointer-events: none }` 承担。**`opacity` 全站只表「在途 busy」，不用于禁用** |
| 键盘焦点环 | `:focus-visible:not(input):not(textarea)` → `outline: 3rpx solid var(--color-primary)` + `outline-offset: 2rpx` + `border-radius: var(--radius-xs)` |
| 触达下限 | 可点元素命中区 **≥88rpx（44pt）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(120) / `--duration-base`(200) / `--duration-slow`(360) + `--ease-out`；**不新增装饰性入场动效**（内容一律立即可见）；`prefers-reduced-motion: reduce` 下过渡取消、旋转环减速。
- 层级：`--z-tabbar`(100) / `--z-sheet`(2000) / `--z-actionsheet`(4000)。
- 高度：`--tabbar-height`(116rpx) / `--tabbar-gap`(20rpx) / `--tap-target-size`(88rpx) / `--reaction-item-min-width`(120rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；图标资源**一律下载**（`lucide-static` 官方 SVG，Lucide 线性，ISC 许可），几何**不自行绘制** —— 资源清单与获取路径见 [图标资源.md](./图标资源.md)。规格：24 网格、`stroke-width 2`、圆角端点、`fill: none`。图标**只用这一套**，SHALL NOT 混入其它图标库 / 图标字体 / emoji。
- **选中态不设 `-filled` 变体**：选中 = **同一线性图标换主色**（见 §2.1.1）。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认） ｜ `32` 伴随标题 ｜ `36` 弹层关闭 ｜ `44` **TabBar** / 失败态 ｜ `48` 空态大图标 ｜ `64` 占位默认 ｜ `96` 整块失败态。
- `tone`：**预生成色调**（`default` / `primary` / `muted`，见 [图标资源.md](./图标资源.md) §2）—— 微信 `<image>` 支持 SVG **文件**但**不支持运行时换色**，故按色调预生成变体。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键** —— 完整清单（语义 / 键 / Lucide 名 / 消费点）见 [图标资源.md](./图标资源.md) §3，**该表为唯一真源**，本节不复列。

> 新增用途须先在[图标资源.md](./图标资源.md) §3 找语义档；确无对应才新增并登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image-broken`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- **图片承载区**（海报位 / 菜品卡图位）在**加载中 / 失败 / 为空**时，一律**按该区尺寸渲染占位**（`ImagePlaceholder`）—— **不留空白、不用文字失败块**（页面用法见[档口海报](./档口海报.md) §2 · [推荐菜品](./推荐菜品.md) §4）。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

## 1.10 列表底部反馈（全局 `.list-foot`）

列表末尾按「触底三态」渲染一行状态文字：**在途**「正在加载更多…」｜ **到底**「没有更多了」｜ **封顶**「已展示前 N 个，切换筛选可查看更多」。

### 2.1.1 `TabBar` —— 底部胶囊 Tab

🔴 **TabBar 为悬浮胶囊**（**不占满宽、非沉底固定菜单栏**），三个 tab 页**恒可见**（本项目无二级页面，故不存在显隐切换逻辑）。

> 🔴 **本节为 TabBar 的定稿样式**：数值即为实现依据，**改动须先改本节再改代码**（文档先行）。

| 项 | 口径 |
|---|---|
| **三项与顺序** | **发现** ｜ **美食** ｜ **记忆**（显示名；↔ 文档名对照见 [UI 总览](./README.md)） |
| **定位** | 悬浮：`position: fixed` + `left/right: 0` + **左右各留 `--spacing-md`**，**横向撑满**（不贴屏边）；**上下各留 `--spacing-xs`**（不贴内容）；底距 `calc(--tabbar-gap + env(safe-area-inset-bottom))`；`--z-tabbar`(100)；**容器外的空白点击穿透** |
| **胶囊本体** | 高 `--tabbar-height`(116rpx)（`box-sizing: border-box`）+ `--radius-pill`；🔴 外环**仅 `1rpx` `--border-color` 描边**，**无底色 / 无阴影**（悬浮胶囊，与页面底色融合，不成为沉底菜单栏）；**全向**内边距 `--spacing-xs` + 项间 `gap: --spacing-xs` |
| **每项** | **两层结构**：项（`flex: 1` 等分、无描边无底色、横向居中）→ **项内层胶囊**（图标 + 文字，`--radius-pill`）；内层胶囊与外环之间由容器内边距留 `--spacing-xs`(8rpx) |
| **选中态** | 项内层胶囊底 **`--color-primary-soft`**（浅橙填充），填充切换带 `--duration-base` + `--ease-out` 过渡；图标 `tone="primary"`、文字 `--color-primary-text` + `--weight-semibold` |
| **未选中态** | 项内层**无填充**；图标 `tone="default"`、文字 **`--color-brown-deep`**（深棕弱色），无加粗 |
| **实现** | **自绘组件** `client/src/components/base/TabBar.vue`；`pages.json` 置 `tabBar.custom = true` 隐藏原生栏，本组件顶替 |
| **图标** | `44rpx`（`AppIcon`，Lucide 线性），**位于文字左侧**；未选 ⇒ `tone="default"`（**不设 `-filled` 变体**） |
| **图标键** | 发现 `compass` ｜ 美食 `dish` ｜ 记忆 `clock` |
| **标签** | `--font-tiny`(20rpx) + `line-height: 1`；选中 ⇒ `--color-primary-text` + `--weight-semibold`；未选 ⇒ `--color-brown-deep` |
| **尺寸换算**（以 750rpx 屏宽为例，实际随屏宽自适应） | 容器 `702 × 116`（再叠加上下 `8rpx` 内边距）；内胶囊（每项）`≈223 × 100`。内胶囊距容器上/下/左/右边缘、距相邻项**均为 8rpx** |
| **触摸** | 整项命中 ≥ `--tap-target-size`；按压 `opacity: .6` |
| **徽标** | **无**（无未读、无红点） |
| **内容让位** | 无滚动区的页由**页面根**让出 `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`（`--spacing-md` = 与胶囊的**呼吸位**，内容不得紧贴 TabBar）；有滚动区的页由**滚动区底部留白**让出同一高度（见 §1.1） |

### 2.1.2 空态 —— Julienne 空态规范

- **原则**：空态是「内容为空」时同一视觉语言的延续，不做夸张插画 / 大色块；大面积留白，细线图标 + **衬线主文案** + 浅灰引导小字 + 暖橙描边主按钮。
- **两种承载**：
  - **美食页无菜品** ⇒ 栈位渲染**空态占位卡**：衬线标题「暂无菜品推荐」+ 浅灰小字「等待食堂上新美食」（无插画）；
  - **记忆页无记录** ⇒ 年月栏下方**垂直居中**：衬线标题 + 浅灰描述 + 暖橙描边「去美食页」。
- **与 `RetryBlock` 的分工**：空态 = 一切正常但无数据；`RetryBlock` = 失败态（文本 / 列表型页面）。渲染优先级 **失败 > 空态 > 列表**。

### 2.1.3 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`flex: 1` + 纵向居中（在剩余空间内**垂直居中**）；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **图标**：`report`，`44rpx`。
- **文案**：标题 `--font-body` + `--weight-semibold` + `--text-body`；副文案 `--font-small` + `--text-tertiary`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 换 CSS 旋转环 + 忽略点击。
- **不改标题 / 不加按钮** —— 本项目失败态只需"重试"这一个动作。
- **适用面**：**文本 / 列表型**页面的失败态（本项目 = [我的食谱](./我的食谱.md)）；**图片承载区**的失败走 §1.9 的占位。

### 2.1.4 `BaseSheet` —— 底部弹层

- **遮罩**：`--overlay-scrim`；点击关闭。
- **抽屉**：`--overlay-panel-bg` + `border-radius: --radius-modal --radius-modal 0 0` + `--shadow-modal`；`padding-bottom: env(safe-area-inset-bottom)`；上滑开合（`--duration-slow`）。
- **grabber**：`72 × 8rpx`、`--border-bold`、`--radius-pill`。
- **下拉关闭手势**：位移 > 120rpx 关闭。
- **本项目的唯一用法**：**纠错选项弹层** —— 单选、5 项、无图标 ⇒ 抽屉内直排**选项行**（每行高 `--tap-target-size`、文案 `--font-body` + `--text-title`、行间 `1rpx var(--border-color)`、首末行无线），点选即提交并关闭。
- **不引入 `ActionSheet`**（无动作菜单场景）。

## 2.2 新增（本设计引入）

> 逐组件登记规格；**页面稿只写「本页用法」，不复述规格**。

### `PosterSwiper` —— 海报滑动容器

- **结构**：横向一屏一项；每项为**圆角 `--radius-card-stack`(24rpx) + `--shadow-card-stack`** 的图块 —— 圆角 / 阴影与美食页单卡（`DishSwipeCard`）**同源**。
- **卡宽**：`calc(100vw - --page-gutter - --spacing-md - peek)`（`peek = --spacing-2xl`，48rpx）；**区高 = 卡高 3:4**（`calc(卡宽 × 4 / 3)`，宿主不足时收缩）；卡片**贴区域底部**（靠近 TabBar），**卡顶紧接板块标题**；图按 `aspectFill` 填满裁切。
- **高度分配**：页面用 `flex: 1` 的**定位容器**（`.posterArea`，`position: relative`）分配剩余高度；容器内 `swiper` **绝对定位铺满** —— 🔴 原生 `swiper` **不参与 flex 拉伸**（自带默认高度），不得改回在 `swiper` 上直接写 `flex: 1`。
- **左右边距**：**左侧 `--page-gutter`(48rpx)**、**右侧 `--spacing-md`(24rpx)**；🔴 **右侧露出下一张卡边缘**（swiper `next-margin` = 48rpx 换算 px），用 peek 提示「还有更多」。
- **手势**：原生滑动、跟手；**可回看前一张**、无循环。
- **占位**：**为空 / 加载失败**时渲染 **3 张占位卡**（各占一个卡位：`--radius-card` + 底 `--bg-placeholder` + 内嵌 `ImagePlaceholder`），**同样可横向滑动** —— 不留空白。
- **使用**：仅[档口海报页](./档口海报.md)。

### `DishSwipeCard` —— 美食页单卡（栈内）

- **用途**：`DishCardStack` 的栈内单卡；**整卡作为页面主容器**，填充栈槽（左右 `--page-gutter`(48rpx) 对称、上 `--spacing-2xl`(48rpx) / 下 `--spacing-xl`(40rpx)）。
- **结构（自上而下）**：**外层容器**（仅 `1rpx` 描边 + `--radius-card`(36rpx) + `--module-shadow`，内边距 `--spacing-xs`）→ **内层白卡**（`--bg-card` + `--radius-card-stack`(24rpx)）→ **顶部左右信息位**（绝对定位：左群体评级字母 / 右风味评级，见 §2.2 `FlavorRating`）→ **圆形菜品图**（420rpx）→ **衬线菜名** → **辅助信息**（`¥xx · 食堂｜档口`，整行 `--text-tertiary`）→ `WantButton`（贴底）。
- **表面**：外层**只做框**（细浅描边 + 极淡阴影，营造悬浮层）；内层**白卡**承载全部内容；🔴 **顶层不透明、不写 `opacity`**。
- **尺寸**：宽度由栈槽决定（`100% - 2 × --page-gutter`，`box-sizing: border-box`）；图 `--dish-photo-size`(420rpx) **圆形**（`--radius-circle`）；内层卡内距 `calc(var(--spacing-2xl) * 2)`(96rpx) / `--spacing-xl`(40rpx) / `--spacing-md`(24rpx)；内容居中偏上、纵向间距 `--spacing-md`(24rpx)；按钮贴底。
- **顶部信息位**：左右各一，`top: --spacing-lg`(32rpx)、左 / 右 `--spacing-xl`(40rpx)；承载 `FlavorRating`（左评级字母 / 右两行风味评级）。
- **菜品图**：🔴 圆角须**直接落在 `<image>` 上**（原生 `<image>` 不吃父级 `overflow` 裁切）；无图时 `ImagePlaceholder` 铺满圆形图位。
- **按钮**：`WantButton` `make` 变体（细橙描边 + 暖白填充 + 深色文字，**胶囊全圆**、高度 96rpx）；`dragging` 时禁用（防误触）。
- **使用**：仅[推荐菜品页](./推荐菜品.md)。

### `DishCardPlaceholder` —— 美食页栈内骨架卡

- **用途**：卡片栈**加载中**的骨架卡（见[推荐菜品](./推荐菜品.md) §4）。
- **结构**：与 `DishSwipeCard` 同构 —— 同内距（96 / 48 / 24）、同卡面 / 同 420rpx 圆形图位 / 同内容居中 / 同按钮贴底：圆形图位 + 名称 / 信息 / 评价**淡占位块**（`--bg-placeholder` + `--radius-xs`）+ 底部按钮 `disabled` 态。
- **静态**：无旋转 loading、无动画、不可点。
- **使用**：仅[推荐菜品页](./推荐菜品.md) 加载态。

### `DishCardStack` —— Z 轴堆叠卡片栈

- **用途**：美食页卡片栈；一次聚焦一张，抽走顶层露出下一张。
- **图层**：顶层 + 3 层预览；第二层 `scale 0.88` / `opacity 0.45` / 轻微下偏移，更深层继续缩小降透明；下层 `pointer-events: none`。
- **拖拽**：仅顶层响应**水平**拖拽（垂直滑动忽略）；跟手带 `0.9` 阻尼，旋转 `≤ ±3°`；拖拽时按钮禁用；下层同步放大、提亮、向居中靠拢。
- **释放**：位移 `< 卡宽 22%` ⇒ 回弹 **260ms**；`≥ 22%` ⇒ 沿方向飞出 **320ms**（`ease-out`），派发 `swipe(id)`，下一张晋升顶层。
- **栈槽**：左右 `--page-gutter`(48rpx) **对称**；上 `--spacing-2xl`(48rpx) / 下 `--spacing-xl`(40rpx)，卡片占满剩余区域；仅手势翻页（无箭头）。
- **加载 / 空态**：栈位渲染骨架卡 / 空态占位卡（实色卡面）；第一条数据上浮淡入。
- **流末尾**：`finished` 时在同一卡位渲染 `end` 插槽内容（由页面提供「重新浏览 / 随机盲选」空态卡）。
- **事件**：`swipe(id)` ｜ `want(card)`。
- **使用**：仅[推荐菜品页](./推荐菜品.md)。

### `WantButton` —— 去品尝 / 保存 / 提问

- **形态**：宽度撑满卡内距的**胶囊描边式**按钮 —— 高 `calc(--tap-target-size + --spacing-xs)`(96rpx)、圆角 **`--radius-pill`（全圆）**、左右留白 `--spacing-xl`(40rpx)；**仅由「图标 + 文案 + 外围边框」组成**：`1rpx` 描边 + **`make` 底为 `--bg-page`（暖白填充）、其余变体底透明** + `check` 图标 `28rpx`（**在文案左侧**）+ 文案 `--font-subtitle` + `--weight-medium`。
- **三种变体**（由 `variant` 控制，默认 `make`）：
  - **`make`（主 CTA）**：**暖橙描边**（`--color-primary`）+ 内部**深色文字**（`--text-title`）；**不随按压 / 选中变色**；文案随 `tasted` 切换（**去品尝** / **取消品尝**）。
  - **`save`（次要，灰）**：描边/图标/文案恒为 `--border-color` + `--text-tertiary`，文案固定「**保存**」。
  - **`ask`（次要，灰）**：描边/图标/文案恒为 `--border-color` + `--text-tertiary`，文案固定「**提问**」。
- **在途 / `disabled`**：仅**禁止点击**（全局 `.is-disabled`，`pointer-events: none`），**视觉与默认态完全一致**；`disabled` 供占位卡使用，保证图片未加载时按钮与文案照常可见。
- **按压反馈**：仅 `opacity` 微降至 `.6`，**不改色、不缩放**。
- **使用**：[推荐菜品页](./推荐菜品.md) 卡片内（`make` 为主 CTA；`save`/`ask` 仅在页级设计稿中另标才使用）。

### `ReactionPicker` —— 评分控件（三态）

- **形态**：三项等距横排（**喜欢 `smile` / 一般 `meh` / 不喜欢 `frown`**），项间距 `--spacing-md`；每项为**图标 + 文案胶囊**（`--radius-pill` + `1rpx var(--border-color)` 描边），图标 `28rpx`，最小高 `--tap-target-size`。
- **取值**：**喜欢 = 5 ｜ 一般 = 3 ｜ 不喜欢 = 1**；个人档位固定 3 级，不增档位。
- **未选中**：图标 `tone="muted"`、字 `--text-body` / `--text-tertiary`。
- **选中**：描边 `--color-primary`、图标 `tone="primary"`、字 `--text-title` + `--weight-medium`（不实底填充）。
- **只读态**（已评分）：**仅渲染选中项**，收成紧凑胶囊；评分不可改。
- **使用**：[我的食谱](./我的食谱.md) 卡片内。

### `FlavorRating` —— 群体风味评级（卡片左上字母 + 右上风味标签）

- **结构**：**一行两端对齐** —— 左**评级字母**、右**两行文本**；**落位由宿主决定**：推荐卡绝对定位在顶部信息位（`top: --spacing-lg`(32rpx)、左 / 右 `--spacing-2xl`(48rpx)）；记忆卡置于卡内**首行**（圆形菜品图之上，留 `--spacing-xs` 安全间距）。
- **左上字母**：`--font-title`(40rpx) + **衬线** + `--text-tertiary` + `opacity: .45` + `line-height: 1`；字母为 `S` / `A` / `B` / `C` / `D`；**待评时不渲染**（不留占位符）。
- **右上两行**：第一行固定「风味评级」—— `--font-small`(22rpx) + `--text-tertiary` + 字距 `0.08em`；第二行档位词 —— `--font-h3`(32rpx) + `--weight-semibold` + `--text-title` + **衬线**；两行左对齐，行距 `--spacing-3xs`。
- **档位词映射**（**唯一映射处**）：`S` → 臻荐 ｜ `A` → 极荐 ｜ `B` → 推荐 ｜ `C` → 尚可 ｜ `D` → 平实 ｜ 待评 → 待评。🔴 只用中性口碑词，**不出现劝退 / 负面表述**。
- **数据**：`flavorLevel`（`S`/`A`/`B`/`C`/`D`，`null` = 评分条数 < 3 ⇒ 待评）—— 口径见 [`func/client/B2`](../../func/client/B-轻量反馈/B2-评分反馈.md)。
- **纯展示**：无交互、无事件。
- **使用**：[推荐菜品](./推荐菜品.md) 单卡 · [我的食谱](./我的食谱.md) 记忆卡。

### `MonthTimeline` —— 年月导航

- **结构**：横向可滑；单行；中文月份（一月 … 十二月）。
- **选中月**：`2026 十月`（年份 + 月份）—— 月份 `--font-h3`(32rpx) + `--weight-medium` + `--text-title`；年份 `--font-small` + `--text-placeholder` + `--weight-medium`。
- **未选月**：`九月`（仅月份）—— `--font-subtitle`(24rpx) + `--weight-regular` + `--text-placeholder` + `opacity: .65` + 字间距 `0.02em`（更弱化、更柔和）。
- **项间距**：`--spacing-lg`(32rpx)；左右内距 `--page-gutter`。
- **数据**：有记录时仅渲染**有记录的月份**（降序）；无记录时用**近三月兜底**（纯装饰）。
- **使用**：我的食谱页顶部。

### `CanteenFilter` —— 食堂筛选

- **形态**：右上角**下拉** —— 用**原生 `picker`**（零自绘）；触发器为胶囊触发器「当前食堂名（默认「全部」）+ `arrow-down` 图标」（图标 `28rpx`、`tone="default"`，`1rpx` 描边 + `--radius-pill`、高 `--tap-target-size`）。
- **默认**：「全部」。
- **切换**：即重筛推荐流，卡片序列重掷。
- **使用**：仅[推荐菜品页](./推荐菜品.md) 右上角。
