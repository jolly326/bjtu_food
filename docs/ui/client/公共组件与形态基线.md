## 0 · 设计语言（Julienne 极简文艺轻拟物）

> 适用：**学生端全部页面与组件**。所有 UI 产出严格遵循本节；页面稿只写「本页用法」，不复述本节。

> **双主题（浅色 / 深色）**：本节与各组件规格以**浅色主题**为基准描述；深色为同键换值的第二组色板（暖黑棕底 + 暖白字，低调饱和度），取值与主题机制见 [设计变量.md](./设计变量.md) §1.2；组件规格**不随主题分叉**（组件不感知主题，只消费语义变量）。

- **关键词**：极简 / 文艺 / 轻拟物 / 留白 / 暖调 / 杂志感 / 纸质卡片隐喻。
- **底色与色彩**：页面**暖白**（`--bg-page`），正文**深炭灰**（`--text-title` / `--text-body`）、辅助文字**浅灰**（`--text-tertiary`）；主色暖橙 `#B4531A` 仅用于高亮（价格、主 CTA 描边、选中 Tab）；卡片表面为**纸片卡面**（`--bg-page` 同色填充 + `1rpx` `--border-color` 细描边，🔴 无阴影）。🔴 不使用厚重棕色作为正文 / 卡片底色。
- **字体**：标题 / 菜名用**衬线**（`--font-serif`）；正文、辅助信息、按钮、Tab 用**无衬线**（`--font-sans`）。字号差距清晰，拒绝信息堆砌。
- **纸片卡片（品牌标志）**：**同色卡面**（`--bg-page` 填充，视觉融于页面）+ **细描边**（`1rpx` `--border-color`）+ **大圆角**（`--radius-card` 36rpx）+ **低透明柔和浅阴影**（`--shadow-card-stack`，悬浮轻盈感）；**顶部左右预留信息位**；中部**内容居中**（圆形食物图 + 衬线菜名 + 辅助信息）；底部操作按钮**不贴底**。🔴 卡片内**不带大序号**（Julienne 的序号属于卡片背景层装饰）。
- **按钮**：以**线框**为主，**小圆角**（`--radius-btn`，非全圆）；主 CTA **暖橙描边 + 内部深色文字**，其余按钮中性灰描边；不使用实底填充。
- **图标**：统一细线性 Lucide 图标（`AppIcon`），不填充、不混用图标字体。
- **堆叠与手势**：卡片多层堆叠（下层缩小 + 降透明度 + 向下偏移），**左右横向拖拽翻卡**：跟手平移 + 轻微旋转 / 缩放，松手回弹或滑出；动效轻柔低速，无弹跳 / 闪光。
- **页面分层**：前景可拖拽卡片 → 中层弱化背景装饰（低透明度）→ 底层固定胶囊 TabBar。
- **空态**：卡片栈无数据时**不是另起一个空页面**，而是**同一卡位的一张占位卡片**（同卡面 + 衬线标题 + 浅灰提示）；产生第一条数据时平滑切换回卡片栈，视觉语言不断裂。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | `page { background: var(--bg-page) }` = **`#FFFDFE`**（暖白，🔴 全站统一；深色主题取值见 [设计变量.md](./设计变量.md) §1.2）—— **唯一承载处**；页面根 / 组件 **SHALL NOT** 再声明页面底色 |
| 主题（明暗） | **全站双主题**：页面根挂 `data-theme="light"｜"dark"` 切换语义色组；默认浅色、storage 持久化；深色取值与完整机制见 [设计变量.md](./设计变量.md) §1.2 |
| 页面根高度 | `.page { min-height: 100vh; min-height: 100dvh }`；**自带滚动容器的页根必须再加 `min-height: 0`**（否则页根比可视区高出一截，页面多出一段可滚区） |
| 主滚动区 | 记忆页滚动区 `.body`：`flex: 1` + `min-height: 0`（缺 `min-height: 0` 会出现「页面 + 滚动区」双层滚动） |
| 底部胶囊让位 | **不全局兜底**：无滚动区的页（风物 / 美味）由**页面根**让出 `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`（= TabBar 容器内容区高 + 安全区，内容不紧贴胶囊 Tab）；记忆页（含滚动区）由**滚动区底部留白**让出同一高度；其余页不得凭空多出死留白 |
| 滚动区底部安全区（**恒需要**） | **任何**滚动承载区底部留白都须叠加 `env(safe-area-inset-bottom)` |
| 顶部安全区（**含胶囊**） | 自定义导航栏（`navigationStyle: custom`）下，内容起始 = **状态栏高度 + 导航栏高度**：状态栏高（`statusBarHeight`）覆盖刘海 / 挖孔屏；导航栏高由 `uni.getMenuButtonBoundingClientRect()` 与状态栏高算出（`胶囊高 + 上下间隙 × 2`）—— **保证顶部内容不被右上角胶囊重叠**（实现见 `client/src/utils/safeArea.ts`） |

## 1.2 圆角 / 线宽

- 分档：微件 `--radius-xs` → 控件 `--radius-btn` → 模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`；正圆 `--radius-circle`。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `1rpx`（描边 / 分隔线 / 底栏顶边）；`2rpx` 只留给**语义状态线**（选中 / 聚焦，配主色）。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-3xs`(2) → `--spacing-2xl`(48)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-tiny`(20) → `--font-title`(40) → `--font-display`(48，**页面标题与卡片主标题**同档) → `--font-hero`(64，**页头大标题与卡片装饰大字专用档**)；**正文级下限 `24rpx`**。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`（小字会飘在行中间）。

## 1.4 色彩 / 阴影

- 色板与取色边界（主色语义分档、文字四档、背景 / 边框 / 语义色 / 对比度口径）见 [设计变量.md](./设计变量.md) §1（**含 §1.2 深色组**）。
- **色值只改 `tokens.ts` 的 `COLOR_MAP`**（分浅色 / 深色两组）；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；卡片表面加 **`--shadow-card-stack` 低透明柔和浅阴影**（弥散、悬浮轻盈感；深色下转「压深」低透明语义，见 [设计变量.md](./设计变量.md) §1.2）—— 🔴 **禁高对比纯黑装饰性阴影**。

## 1.5 表面：模块 / 卡片

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块，区块之间**只靠页面留白分组**。
- **卡片表面只有一套取值**：**纸片卡面** = `--bg-page` 填充 + `1rpx` `--border-color` 细描边 + `--radius-card`(36rpx) + **`--shadow-card-stack` 柔和浅阴影**（规格见 §2.2 `PaperCard`；**美味卡片族与记忆卡共用**，两端视觉体系统一）。
- 页面 / 组件私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 阴影一律取该套或已登记的页级专属形态**（海报卡 = `--radius-card-stack` + `--shadow-card-stack`；弹层面板 = `--overlay-panel-bg` + `--radius-modal` + `--shadow-modal`）—— SHALL NOT 另立新取值。
- 模块之间的留白由消费方容器 `flex gap`（`--spacing-lg`）承担（WXSS 不支持 `+` / `~` 兄弟选择器）。
- **长文本断行唯一写法 = `overflow-wrap: anywhere`**（`word-break: break-all` / `break-word` 不作为可选写法）。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-placeholder`）；**SHALL NOT `transform: scale`**。`opacity` 只三档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 ｜ **`.85`** 主色实底 CTA — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …，会跨组件边界冒泡致「点一次跳两次」）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 两档：① **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-tertiary`；② **非主色可点件** ⇒ `opacity: .5`。禁点由全局 `.is-disabled { pointer-events: none }` 承担。**`opacity` 全站只表「在途 busy」，不用于禁用** |
| 触达下限 | 可点元素命中区 **≥88rpx（44pt）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(120) / `--duration-base`(200) / `--duration-slow`(360) + `--ease-out`；**不新增装饰性入场动效**（内容一律立即可见）；`prefers-reduced-motion: reduce` 下过渡取消、旋转环减速。
- **取值来源（SHALL NOT 裸写时长）**：按压 / 选中态过渡取 `--duration-fast`；卡片栈回弹取 `--duration-base`；卡片飞出与入场取 `--duration-slow`。
- 层级：`--z-tabbar`(100) / `--z-sheet`(2000)。
- 高度：`--tabbar-height`(116rpx) / `--tabbar-gap`(20rpx) / `--tap-target-size`(88rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；图标资源**一律下载**（`lucide-static` 官方 SVG，Lucide 线性，ISC 许可），几何**不自行绘制** —— 资源清单与获取路径见 [图标资源.md](./图标资源.md)。规格：24 网格、`stroke-width 2`、圆角端点、`fill: none`。图标**只用这一套**，SHALL NOT 混入其它图标库 / 图标字体 / emoji。
- **选中态不设 `-filled` 变体**：选中 = **同一线性图标换主色**（见 §2.1.1）。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认） ｜ `32` 伴随标题 ｜ `36` 弹层关闭 ｜ `40` **TabBar** ｜ `44` 失败态 ｜ `48` 空态大图标 ｜ `64` 占位默认 ｜ `96` 整块失败态。
- `tone`：**预生成色调**（`default` / `primary` / `muted`，见 [图标资源.md](./图标资源.md) §2）—— 微信 `<image>` 支持 SVG **文件**但**不支持运行时换色**，故按色调预生成变体；**深色主题**下三档 tone 取深色色值（同见 §2），变体按主题分组生成。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键** —— 完整清单（语义 / 键 / Lucide 名 / 消费点）见 [图标资源.md](./图标资源.md) §3，**该表为唯一真源**，本节不复列。

> 新增用途须先在[图标资源.md](./图标资源.md) §3 找语义档；确无对应才新增并登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image-broken`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- **图片承载区**（海报位 / 菜品卡图位）在**加载中 / 失败 / 为空**时，一律**按该区尺寸渲染占位**（`ImagePlaceholder`）—— **不留空白、不用文字失败块**（页面用法见[风物](./风物.md) §2 · [美味](./美味.md) §4）。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

### 2.1.1 `TabBar` —— 底部胶囊 Tab

🔴 **TabBar 为底置通栏容器内的胶囊**（**非沉底全宽菜单栏**），三个 tab 页**恒可见**（本项目无二级页面，故不存在显隐切换逻辑）。

> 🔴 **本节为 TabBar 的定稿样式**：数值即为实现依据，**改动须先改本节再改代码**（文档先行）。

| 项 | 口径 |
|---|---|
| **三项与顺序** | **风物** ｜ **美味** ｜ **记忆**（显示名；↔ 文档名对照见 [UI 总览](./README.md)） |
| **定位** | **全宽通栏容器**：`position: fixed` + `left/right: 0` + `bottom: 0` + `padding-bottom: env(safe-area-inset-bottom)`（底抵屏幕有效可视区底部，不含系统底部手势横条）；容器内容区高 `--tabbar-height + --tabbar-gap + --spacing-md`(160rpx)，**胶囊在容器内水平 + 垂直居中**；胶囊宽 `calc(100vw - --page-gutter × 2 - --spacing-md)`（= 屏宽 − 88rpx，与[风物页](./风物.md)海报卡同宽）；`--z-tabbar`(100) |
| **胶囊本体** | 高 `--tabbar-height`(116rpx)（`box-sizing: border-box`）+ `--radius-pill`；🔴 外环**仅 `1rpx` `--border-color` 描边**，**无底色 / 无阴影**（与页面底色融合，不成为沉底菜单栏）；**全向**内边距 `--spacing-xs` + 项间 `gap: --spacing-xs` |
| **每项** | **两层结构**：项（`flex: 1` 等分、无描边无底色、横向居中）→ **项内层胶囊**（图标 + 文字，`--radius-pill`）；内层胶囊与外环之间由容器内边距留 `--spacing-xs`(8rpx) |
| **选中态** | 项内层胶囊底 **`--color-primary-soft`**（浅橙填充），填充切换带 `--duration-base` + `--ease-out` 过渡；图标 `tone="primary"`、文字 `--color-primary-text` + `--weight-semibold` |
| **未选中态** | 项内层**无填充**；图标 `tone="default"`、文字 **`--color-brown-deep`**（深棕弱色），无加粗 |
| **实现** | **自绘组件** `client/src/components/base/TabBar.vue`；`pages.json` 置 `tabBar.custom = true` 隐藏原生栏，本组件顶替 |
| **图标** | `40rpx`（`AppIcon`，Lucide 线性，细线条不变），**位于文字左侧**；未选 ⇒ `tone="default"`（**不设 `-filled` 变体**） |
| **图标键** | 风物 `compass` ｜ 美味 `dish` ｜ 记忆 `clock` |
| **标签** | `--font-body`(26rpx) + `line-height: 1` + **衬线**（Julienne 文艺风；与 40rpx 图标视觉配平）；选中 ⇒ `--color-primary-text` + `--weight-semibold`；未选 ⇒ `--color-brown-deep` |
| **尺寸换算**（以 750rpx 屏宽为例，实际随屏宽自适应） | 容器 `750 × 160`（再叠加 `env(safe-area-inset-bottom)` 内距）；外胶囊 `662 × 116`（**容器内水平居中**，左右各留 44rpx）；内胶囊（每项）`≈210 × 100`。内胶囊距外环上/下/左/右边缘、距相邻项**均为 8rpx**。🔴 海报卡列因右侧 peek 较屏中心偏左 12rpx，故胶囊左缘较海报卡左缘内收 12rpx —— **居中优先**（对齐优先则改回左距 `--page-gutter`） |
| **触摸** | 整项命中 ≥ `--tap-target-size`；按压 `opacity: .6` |
| **徽标** | **无**（无未读、无红点） |
| **内容让位** | 无滚动区的页由**页面根**让出 `--tabbar-height + --tabbar-gap + --spacing-md + env(safe-area-inset-bottom)`（= 容器内容区高 + 安全区，内容不紧贴 TabBar 容器）；有滚动区的页由**滚动区底部留白**让出同一高度（见 §1.1） |

### 2.1.2 空态 —— Julienne 空态规范

- **原则**：空态是「内容为空」时同一视觉语言的延续，不做夸张插画 / 大色块；大面积留白，细线图标 + **衬线主文案** + 浅灰引导小字 + 暖橙描边主按钮。
- **两种承载**：
  - **美味页无菜品** ⇒ 栈位渲染**空态占位卡**：衬线标题「暂无菜品推荐」+ 浅灰小字「等待食堂上新美食」（无插画；表面同栈卡，见 §2.2 `DishSwipeCard`）；
  - **记忆页无记录** ⇒ 年月栏下方**垂直居中**：衬线标题 + 浅灰描述 + 暖橙描边「去美味页」。
- **与 `RetryBlock` 的分工**：空态 = 一切正常但无数据；`RetryBlock` = 失败态（文本 / 列表型页面）。渲染优先级 **失败 > 空态 > 列表**。

### 2.1.3 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`flex: 1` + 纵向居中（在剩余空间内**垂直居中**）；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **图标**：`report`，`44rpx`。
- **文案**：标题 `--font-body` + `--weight-semibold` + `--text-body`；副文案 `--font-small` + `--text-tertiary`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 换 CSS 旋转环 + 忽略点击。
- **不改标题 / 不加按钮** —— 本项目失败态只需"重试"这一个动作。
- **适用面**：**文本 / 列表型**页面的失败态（本项目 = [记忆](./记忆.md)）；**图片承载区**的失败走 §1.9 的占位。

### 2.1.4 `BaseSheet` —— 底部弹层

- **遮罩**：`--overlay-scrim`；点击关闭。
- **抽屉**：`--overlay-panel-bg` + `border-radius: --radius-modal --radius-modal 0 0` + `--shadow-modal`；`padding-bottom: env(safe-area-inset-bottom)`；上滑开合（`--duration-slow`）。
- **grabber**：`72 × 8rpx`、`--border-bold`、`--radius-pill`。
- **下拉关闭手势**：位移 > 120rpx 关闭。
- **本项目的唯一用法**：**纠错选项弹层** —— 单选、5 项、无图标 ⇒ 抽屉内直排**选项行**（每行高 `--tap-target-size`、文案 `--font-body` + `--text-title`、行间 `1rpx var(--border-color)`、首末行无线），点选即提交并关闭。
- **不引入 `ActionSheet`**（无动作菜单场景）。

### `DishCardStack` —— Z 轴堆叠卡片栈（恒定 3 层纸片堆叠）

- **用途**：美味页卡片栈；一次聚焦一张，划走顶层后下一张晋升。
- **堆叠模型**：**恒定 3 层** —— 顶层完整卡（**宽度最大**）+ 后方两层**依次收窄并向上错位**（从顶层卡上方露出层叠纸边）；🔴 **不透明、无边缘虚化**，立体感仅由**宽度差异 + 上移位移 + 卡面柔和浅阴影**承担；**不在每张卡上自带多层纹路**。队列尾部不足 3 张时，空位渲染**纸片虚影**（同卡面轮廓 + 阴影、无内容）补位，页面内永久维持 3 层堆叠视觉。
- **图层**：顶层不透明、最宽；第二 / 三层 `scale 0.96` / `0.92`、向上错位 10 / 20rpx（**不写 `opacity`**）；圆角与顶层统一；下层 `pointer-events: none`。
- **拖拽**：仅顶层响应**水平**拖拽（垂直滑动忽略）；跟手带 `0.9` 阻尼，旋转 `≤ ±3°`；拖拽时按钮禁用；后方两层随进度**放大归位**（scale → 1、上移归零）。
- **释放**：位移 `< 卡宽 22%` ⇒ 回弹 **`--duration-base`**；`≥ 22%` ⇒ 沿方向飞出 **`--duration-slow`**（`ease-out`），派发 `swipe(id)`；**剩余两层向上小幅上移**（卡片 key 复用 ⇒ DOM 节点上移、过渡连续），尾部补入新卡（队列有货）或纸片虚影。（取值来源见 §1.7）
- **栈槽**：左右 `--page-gutter`(32rpx) **对称**；三层堆叠在顶部信息区块与 TabBar 容器之间的剩余空间内**垂直居中**（距上 ≈ 距下，上下留白均衡）；仅手势翻页（无箭头）。
- **加载 / 空态**：顶层渲染骨架卡 / 空态占位卡（卡面同栈卡）；第一条数据上浮淡入。
- **流末尾**：`finished` 时在同一卡位渲染 `end` 插槽内容（`DishFlowEnd`）。
- **事件**：`swipe(id)` ｜ `want(card)`。
- **使用**：仅[美味页](./美味.md)。

### `DishFlowEnd` —— 美味页卡片流末尾结束卡

- **用途**：本批卡片全部划完后占据同一卡位（由 `DishCardStack` 的 `end` 插槽承载，位于**卡片区域内、Tab 栏之上的页面居中区**，非悬浮层）；纯展示 + 两个动作事件，流水线（请求 / 批次切换）由页面负责。
- **文案层级**：**衬线加粗主标题**「今天的推荐就到这里」（`--font-title`(40rpx) + `--weight-semibold` + `--text-title`，居中）→ **浅灰副标题**「明天再来看看，新的美味马上更新」（无衬线 `--font-small` + `--text-tertiary`，小于主标题，间距紧凑不拥挤）。
- **结构**：**纵向居中列**（`flex: 1` + 居中）+ 底部**动作区**（两列等宽居中、间距 `--spacing-xl`、与副标题间距 `--spacing-xl`）；整体**留白充足**（温和的结束提示，非错误页）。
- **动作项（图标框在上、文字在下）**：图标框为**圆角方框** —— 视觉边长 `calc(--tap-target-size - --spacing-md)`(64rpx) + `1rpx` 描边 + `--radius-btn` 小圆角、**白底（透出卡面）、无阴影**；框内线性图标 `28rpx`；框下文字 `--font-subtitle` + `--text-title` 居中；整列可点（命中区含框 + 文字）。**重新浏览**（`refresh-cw` + `tone="default"`，中性灰描边）｜**随机首选**（`star` + `tone="primary"`，**低饱和暖橙点缀**：仅描边与图标色调，文字仍为深棕，**不做高亮主色按钮**）。
- **表面**：与栈卡同卡面 —— 由 `PaperCard` 承载（同色卡面 + 顶部吊孔 + 柔和浅阴影）；内距同栈卡（上 48 / 左右 40 / 下 48）。
- **事件**：`replay` ｜ `surprise`；`busy` 为真时「随机首选」挂 `.is-disabled`（防重复请求）。
- **使用**：仅[美味页](./美味.md) 流末尾。

### `WantButton` —— 去品尝 / 保存 / 提问

- **形态**：宽度撑满卡内距的**胶囊描边式**按钮 —— 高 `calc(--tap-target-size + --spacing-xs)`(96rpx)、圆角 **`--radius-btn`（小幅度柔和圆角，非全圆）**、左右留白 `--spacing-xl`(40rpx)；**仅由「文案 + 外围边框」组成**（无图标）：`1rpx` 描边 + **`make` 底为 `--bg-page`（暖白填充）、其余变体底透明** + 文案 `--font-subtitle` + `--weight-medium`（居中）。
- **三种变体**（由 `variant` 控制，默认 `make`）：
  - **`make`（主 CTA）**：**暖橙描边**（`--color-primary`）+ 内部**深色文字**（`--text-title`）；**不随按压 / 选中变色**；文案随 `tasted` 切换（**去品尝** / **取消品尝**）。
  - **`save`（次要，灰）**：描边 / 文案恒为 `--border-color` + `--text-tertiary`，文案固定「**保存**」。
  - **`ask`（次要，灰）**：描边 / 文案恒为 `--border-color` + `--text-tertiary`，文案固定「**提问**」。
- **在途 / `disabled`**：仅**禁止点击**（全局 `.is-disabled`，`pointer-events: none`），**视觉与默认态完全一致**；`disabled` 供占位卡使用，保证图片未加载时按钮与文案照常可见。
- **按压反馈**：仅 `opacity` 微降至 `.6`，**不改色、不缩放**。
- **使用**：[美味页](./美味.md) 卡片内（`make` 为主 CTA；`save`/`ask` 仅在页级设计稿中另标才使用）。

### `ReactionPicker` —— 评分控件（圆形三态表情，循环切换）

- **形态**：**单个圆形图标按钮**（Julienne 卡片角标形态）—— 命中区 `--tap-target-size`(88rpx)，视觉圆 `calc(--tap-target-size - --spacing-md)`(64rpx) + `1rpx` `--border-color` 圆环；表情图标 `40rpx`（记忆卡三图标中**视觉优先级最高**，气泡 32 / 垃圾桶 28）。
- **三态与循环**：**喜欢 `smile` = 5 ｜ 一般 `meh` = 3 ｜ 不喜欢 `frown` = 1**；个人档位固定 3 级、不增档位。图标显示**当前档位**；未评分 ⇒ `smile` + `tone="default"`（弱化态）；**tap 按 喜欢 → 一般 → 不喜欢 → 喜欢 循环切换**并派发 `pick(下一档)`。
- **选中态**：已评分 ⇒ 圆环描边 `--color-primary` + 图标 `tone="primary"`（不实底填充）。
- **禁用**：`locked`（写入口限频退避中，docs/secur/S-03）⇒ 挂 `.is-disabled` + `opacity: .5`。
- **取值与口径**：三态取值、一次性规则见 [`func/client/B2`](../../func/client/B-轻量反馈/B2-评分反馈.md)；已评分记录的再次提交由后端裁决（失败 Toast 兜底）。
- **使用**：仅[记忆](./记忆.md) 记忆卡右下角。

### `FlavorRating` —— 群体风味评级（卡片左上装饰字母 + 右上风味标签）

- **结构**：**一行两端对齐** —— 左**评级字母**、右**两行文本**；**落位由宿主决定**：美味卡绝对定位在顶部信息带（`top: --spacing-2xl`(48rpx)、左 / 右 `--spacing-xl`(40rpx)，作卡片背景层）。
- **左上字母**：`calc(--font-hero + --font-display + --spacing-md)`(136rpx) + `--weight-bold`；**衬线** + `--text-tertiary` + `opacity: .45` + `line-height: 1`；字母为 `S` / `A` / `B` / `C` / `D`；**大号加粗浅灰水印、作卡片背景层装饰**（对标 Julienne 左上大号淡数字，不遮挡上层内容）；**待评时不渲染**（不留占位符）。
- **右上两行**：第一行固定「风味评级」—— `--font-small`(22rpx) + **衬线** + `--weight-regular` + `--text-tertiary` + 字距 `0.08em`；第二行档位词 —— `--font-title`(40rpx) + `--weight-bold` + `--text-title` + **衬线**（标签小字在上、等级值大字在下）；两行**右对齐**（对标 Julienne 右上 Skill Level），行距 `--spacing-3xs`。
- **档位词映射**（**唯一映射处**）：`S` → 臻荐 ｜ `A` → 极荐 ｜ `B` → 推荐 ｜ `C` → 尚可 ｜ `D` → 平实 ｜ 待评 → 待评。🔴 只用中性口碑词，**不出现劝退 / 负面表述**。
- **数据**：`flavorLevel`（`S`/`A`/`B`/`C`/`D`，`null` = 评分条数 < 3 ⇒ 待评）—— 口径见 [`func/client/B2`](../../func/client/B-轻量反馈/B2-评分反馈.md)。
- **纯展示**：无交互、无事件。
- **使用**：仅[美味](./美味.md) 单卡。

### `MonthTimeline` —— 年月导航

- **结构**：横向可滑；每项**上下层级** —— **年份小字在上、月份大号衬线在下**（对标 Julienne 年月滚动栏；不再左右横排）。
- **选中月**：月份 `--font-title`(40rpx) + **衬线** + `--text-title`；年份 `--font-small` + `--text-tertiary`。
- **未选月**：月份 `--font-subtitle`(24rpx) + **衬线** + `--text-placeholder` + `opacity: .65`；年份 `--font-small` + `--text-placeholder` + `opacity: .65`（浅灰，与当前月形成深浅层级）。
- **项间距**：`--spacing-lg`(32rpx)；左右内距 `--page-gutter`；整项命中 ≥ `--tap-target-size`。
- **数据**：有记录时仅渲染**有记录的月份**（降序）；无记录时用**近三月兜底**（纯装饰）。
- **使用**：记忆页顶部。

### `CanteenFilter` —— 食堂筛选

- **形态**：右上角**下拉** —— 用**原生 `picker`**（零自绘）；触发器为胶囊触发器「当前食堂名（默认「全部」）+ `arrow-down` 图标」—— **轻量化**：`1rpx` `--border-color` 细描边 + `--radius-btn`（小幅度柔和圆角，非全圆）、高 `--tap-target-size`（命中下限不变）；食堂名 `--font-small` + `--text-tertiary`、图标 `28rpx` + `tone="muted"`（低饱和度，不抢视觉重心）。
- **默认**：「全部」。
- **切换**：即重筛推荐流，卡片序列重掷。
- **使用**：仅[美味页](./美味.md) 右上角。

# 三、维护口径

1. **新公共组件**：先进本文件登记规格，再被页面消费。
2. **页面改动**：若某页需偏离本文件口径，**先修订本文件**（或登记该页例外）再动代码。
3. **页面设计稿**不得复述本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
4. **改视觉值只改 token**，不在页面里裸写。
