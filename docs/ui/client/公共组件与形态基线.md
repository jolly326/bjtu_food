## 0 · 设计语言（Q 版动森（圆润厚实 · 轻拟物））

> 适用：**学生端全部页面与组件**。所有 UI 产出严格遵循本节；页面稿只写「本页用法」，不复述本节。

> **单主题（奶米纸色）**：全站仅一套色板（奶米纸底 `#FFF7E8` + 深棕字 + 浅杏胶囊）；🔴 **无昼夜主题切换**，不挂 `data-theme`、不消费深色变量。取值见 [设计变量.md](./设计变量.md) §1。

- **关键词**：动森风 / 奶米纸色 / 深棕 / 软胶囊入口 / 手绘细描边 / 短横线虚线 / 柔和回弹 / 规整图标网格 / 图片优先 / 全屏沉浸。
- **底色与色彩**：页面奶米纸色 `--bg-page` `#FFF7E8`；主文案深棕 `--text-title` `#44382E`；可读辅助浅棕 `--text-body` `#8C7B6B`；页内可点项统一为**浅杏软胶囊**（`--radius-pill` + `--pill-bg` 浅杏底 + `var(--border-width) --border-color` 细描边）。
- **字体**：标题 / 菜名 / 弹层标题用**无衬线圆体**（`--font-sans`）；参数型辅助信息、按钮文案、弹层选项用**无衬线圆体**（`--font-sans`）。字号差距清晰，拒绝信息堆砌。
- 🔴 **字重规则（Q 版动森）**：**所有无衬线圆体标题一律 `--weight-regular`** —— 层级由**字号 + 颜色**承担，**不靠加粗**；唯一例外：无衬线圆体状态标签（如失败态标题）。
- **图片优先**：菜品首页以**菜品图标**为绝对主体（圆角矩形图 + 下方菜名），回归「看图找菜」的极简本质；内联展开卡为**奶白卡面**（`--bg-card` + `--radius-modal` + `var(--border-width) --border-color` 细描边）。
- **按钮**：页内可点项（反馈入口 / 收起 / 空态清空 / 搜索）统一为**浅杏软胶囊按钮**（圆角 `--radius-pill` + `--pill-bg` 浅杏底 + `var(--border-width) --border-color` 细描边；主操作靠 `--text-title` 深棕字强调）；按压 `scale(.96)` 回弹（设计变量 §2.2）。
- **光影**：层级靠底色、描边、圆角与留白区分；卡片 / 弹层可加 `--shadow-soft`（向下）/ `--shadow-up`（向上）极弱弥散阴影，🔴 禁用硬阴影 / 渐变 / 3D 堆叠。
- **图标**：统一 **Streamline Plump Solid 单色棕实心 SVG**（`AppIcon`，`fill: #8C7B6B`，无描边）；圆润粗胖、不混用图标字体。
- **页面分层**：背景纯色 `--bg-page` 底 → 前景 = 3 列菜品图标网格 → 网格内插入内联展开卡 → 底部固定搜索 dock。无 TabBar / 无全局顶栏。
- **空态**：搜索 0 命中时网格区显示「没找到符合的菜，换个说法试试」+「清空搜索」（见 [菜品首页.md](./菜品首页.md) §7）；首屏加载 / 加载失败仍走 `PageLoading` / `RetryBlock`。

- **加载 / 失败**：
  - **加载中**：`PageLoading`；`loading` 图标 `56rpx`、`opacity 0.55`、匀速旋转；文案 `--font-h3` / `--weight-regular` / `--text-title`；父容器 `flex: 1` + 居中。
  - **失败块**：`RetryBlock`；与加载中**共用 `StatusBlock` 骨架**（`warning` `56rpx` + 文案 `--font-h3` / `--weight-regular` / `--text-title`），`gap: --spacing-xs` + `padding: --spacing-xl --spacing-lg`。

# 一、全站形态基线

## 1.1 页面骨架

| 项 | 口径 |
|---|---|
| 页面底色 | 🔴 **唯一承载处 = 页面根视图**（`.home` 自身 `background: var(--bg-page)`）；`page` 选择器的同色声明仅作未挂载兜底；**子组件 SHALL NOT** 再声明页面底色 |
| 主题（明暗） | 🔴 **单主题**：全站仅奶米纸色一套色板，`--bg-page` 恒定；**无昼夜切换**、不挂 `data-theme`、不消费深色变量 |
| 页面根布局 | 单页画布：`.home` 为 `position: fixed; inset: 0` 的纵向 flex（页头 + 内容区 + 悬浮 dock），滚动只发生在内容区的 `scroll-view` 内 |
| 顶部页头（**与胶囊同一行**） | 自定义导航栏（`navigationStyle: custom`）下，`HomeHeader` 的 `padding-top = statusBarHeight`；内容区高 = `(胶囊 top − statusBarHeight) × 2 + 胶囊 height`（即胶囊行高，与胶囊**同顶同底**，不额外加高；取不到胶囊矩形时用 `--header-height` 兜底）；品牌块与右上角胶囊**垂直居中对齐**；网格在页头下方 |
| 底部安全区 | 画布底部留白须叠加 `env(safe-area-inset-bottom)` |
| 底部悬浮 dock | 底部搜索胶囊**脱离布局流**（`position: absolute`，挂在内容区容器上、贴在内容区底缘）：`left/right = --page-gutter`、`bottom = --spacing-sm + env(safe-area-inset-bottom)`、层级 `--z-dock`；滚动内容底部让出 `--dock-reserve` 净空，末行可完整滚到胶囊之上，胶囊不遮挡任何可点区域 |

## 1.2 圆角 / 线宽

- 分档：模块 `--radius-card` → 弹层 `--radius-modal`；**可点**胶囊 `--radius-pill`（卡 / 弹层 / 胶囊三档，见 [设计变量.md](./设计变量.md) §2.1）。
- **不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角），不设「不可点标签」专用档。
- **线宽**：结构线唯一档 `2rpx`（`--border-width`：图片 / 卡片 / 弹层顶边 / 分隔线统一线宽）；🔴 不另设其他线宽档位。
- **SHALL NOT 裸写圆角值**。

## 1.3 间距 / 字号

- 间距 4pt 栅格：`--spacing-2xs`(4) → `--spacing-2xl`(48)，单位 rpx。
- 页面级左右 gutter 统一 `--page-gutter`（`32rpx`）；`--spacing-*` 只表达「元素之间留多少」，二者不可混用。
- 字号梯度：`--font-subtitle`(26) → `--font-body`(28) → `--font-h3`(32) → `--font-h2`(36) → `--font-title`(40)；**正文级字号下限 `24rpx`，常规辅助文本取 `--font-subtitle`(26rpx)**。
- **行内基线对齐**：同一行并排「标题级 + 正文级」文本时**一律取基线对齐**（`align-items: baseline`），**SHALL NOT** 用 `center`。

## 1.4 色彩 / 光影

- 色板与取色边界（文字四档、背景 / 边框 / 对比度口径）见 [设计变量.md](./设计变量.md) §1。
- **色值只改 `tokens.ts` 的 `COLOR_MAP`**（单组色板）；`generated-colors.css` 须与之逐键一致。
- **SHALL NOT 裸 hex**；卡片 / 弹层可加 `--shadow-soft` / `--shadow-up` 极弱弥散阴影，🔴 禁用硬阴影 / 渐变 / 3D 堆叠 —— 层级主要靠 `var(--border-width) --border-color` 细描边与圆角区分。

## 1.5 表面：面板

- **不用大白卡把整页内容框在一起**：每个功能区块各自成一块，区块之间**只靠页面留白分组**。
- **弹窗面板只有一套取值**：奶米色面板 = `--overlay-panel-bg` + `--radius-modal`(56rpx) + 顶部 `var(--border-width)` 细描边（可加 `--shadow-up` 极弱弥散阴影，规格见 §2.2 `DishExpandCard`）。
- 页面 / 组件私有类只承担布局（`margin` / `overflow` / `flex`）；**底色 / 圆角 / 描边一律取已登记形态** —— SHALL NOT 另立新取值。
- 长文本断行唯一写法 = `overflow-wrap: anywhere`。

## 1.6 状态口径

| 状态 | 口径 |
|---|---|
| 按压 | 事件统一 **`@tap`**（禁 `@click`）；反馈 = `hover-class` 的 **`opacity` 微降** 或 **底色档**（`--bg-placeholder`）；`DishTile` 点按用 `scale(.96)` 按压回弹（唯一 `scale` 例外）。`opacity` 只两档：**`.6`** 文字 / 图标小件 ｜ **`.7`** 卡片 / 行 / 图片 / 整块 — **同族元素必须取同值**。`<text>` / `<image>` 不支持 `hover-class` ⇒ 须外层包 `<view hover-class>` |
| 组件对外事件命名 | 组件 `defineEmits` 的事件名**不得与小程序原生事件同名**（`tap` / `touchstart` / `confirm` / `scroll` …）；统一用业务语义名（`enter` / `press` / `back` / `select` / `close` / `retry` / `pick` / `action`） |
| 禁用 | 两档：① **描边 / 文字类** ⇒ 边 `--border-color` + 字 `--text-disabled`；② **可点件** ⇒ `opacity: .5`。文字入口置灰 = 文字取**暖灰棕 `--text-disabled`**（🔴 不用冷灰、不用灰度滤镜），无按压反馈；禁点由组件 `disabled` 守卫承担。 |
| 触达下限 | 可点元素命中区 **≥96rpx（48pt，`--tap-target-size`）**；视觉尺寸可小于命中区，经 `::after` **仅纵向**扩展 |

## 1.7 动效 / 层级 / 关键高度

- 动效：`--duration-fast`(140) / `--duration-base`(240) / `--duration-slow`(420) + `--ease-out` / `--ease-bounce`。
- **只用于状态切换与层级进入**：磁贴按压 `scale(.96)`、展开卡 `scale(.96)` + 淡入、反馈面板淡入 / 上浮、搜索框聚焦描边；🔴 **不做列表逐项入场、不做装饰性循环动画**。
- `prefers-reduced-motion: reduce` 下所有动画 / 过渡压到 0.01ms（`client/src/styles/motion.scss` 统一兜底）。
- 层级：`--z-sheet`(2000) ＞ `--z-dock`(10) ＞ 内容；悬浮 dock 用 `--z-dock`，弹层用 `--z-sheet`。
- 高度：`--tap-target-size`(96rpx) 为命中区下限；可点控件竖直高度 `--control-height`(96rpx)，行内小胶囊 `--control-height-sm`(64rpx)。

## 1.8 图标

- **唯一实现 = 公共 `AppIcon`**；图标资源**一律下载**（Streamline Plump · Solid，CC BY 4.0），几何**不自行绘制**，**不手动提取轮廓** —— Solid 版的 path 本身就是实心底稿，资源清单与获取流程见 [图标资源.md](./图标资源.md)。规格：`48` 网格、`fill: #8C7B6B` + 无描边（🔴 描边版在 40rpx 及以下会把 Plump 的粗线条糊成一团，故不再使用）。图标**只用这一套**，SHALL NOT 混入其它图标库 / 图标字体 / emoji。
- **配色口径**：图标一律**中性棕实心填充**（`fill: #8C7B6B`），单主题下全站同一批文件、同一颜色。

- **无二元选中态图标**：内联展开卡内的反馈入口等可点项用浅杏软胶囊。
- `size`：数字 = **rpx**（也可传带单位字符串）。**档位表（SHALL NOT 自造档位）**：`24` 行内勾选 ｜ `28` 行级前置图标（默认）/ 筛选触发器 ｜ `32` 伴随标题 ｜ `40` 卡内功能图标 ｜ `48` 卡内图片占位 ｜ `56` 加载态 / 失败态（`StatusBlock` 统一档） ｜ `64` 图片占位默认 ｜ `96` 整块失败态。
- **纯展示组件**（不派发事件）；**SHALL NOT** 用 emoji / 文本 / 自绘 SVG 当图标；**零消费的图标键不登记**。

**本设计消费的图标键** —— 完整清单（语义 / 键 / Streamline 源文件 / 消费点）见 [图标资源.md](./图标资源.md) §3，**该表为唯一真源**，本节不复列。

> 新增用途须先在[图标资源.md](./图标资源.md) §3 找语义档；确无对应才新增并登记。**零消费的键不登记**。

## 1.9 图片占位（全站统一）

- **唯一实现**：公共 `ImagePlaceholder` —— 居中图标 + 默认底 `--bg-placeholder`。
- 场景：**图片缺失 / 加载失败 / 破图** → `image`（默认，全站标准）；**宿主自带底色的图片区块** → 同图标 + `bare`（去底色、保留图标）。
- **图片承载区**（菜品图位）在**加载中 / 失败 / 为空**时，一律**按该区尺寸渲染占位**（`ImagePlaceholder`）—— **不留空白、不用文字失败块**。
- **加载顺序**：腾讯云数据万象缩略图 → 原图 → 占位（`useImageSource`）；缩略图按承载区真实像素限宽（`imageMogr2/thumbnail/<w>x/quality/80/format/webp`，磁贴 `400`、展开卡大图 `800`，见 `constants.ts` 的 `IMAGE`），缩略图请求失败自动回落原图，原图再失败才占位。
- `size` 默认 `64rpx`。
- **SHALL NOT** 各页自绘占位、**SHALL NOT** 自定义占位底色（`bare` 除外）。

# 二、本设计的组件清单

## 2.0 分层与目录（强制）

> 🔴 **只有真正的跨页公共件才进 `components/`**；只有单页使用的组件一律下沉到该页面的 `components/` 下，与页面同包。

| 层 | 目录 | 判定 | 现有成员 |
|---|---|---|---|
| **公共** | `client/src/components/` | ≥2 个页面使用 | `AppIcon` · `ImagePlaceholder` · `RetryBlock` · `PageLoading` · `StatusBlock` |
| **页面私有** | `client/src/pages/home/components/` | 仅菜品首页使用 | `HomeHeader`（页头）· `DishGrid` · `DishTile` · `DishExpandCard`（内联展开卡）· `SearchDock`（搜索框）· `FeedbackPanel`（文本反馈） |

- **页面包名**：`菜品首页 → home`（路由 `pages/home/index`）。
- **导入约定**：页面内 `./components/Xxx.vue`；页面私有组件引用公共件一律走别名 `@/components/Xxx.vue`（禁止 `../` 跨层相对路径）。
- **新增组件的判定顺序**：先问「是否 ≥2 页使用」——否 ⇒ 放进当前页 `components/`；是 ⇒ 进 `components/` 并在 §2.1 登记。
- **魔法数字**：尺寸 / 时长 / 阈值 / 存储键一律集中于 `client/src/constants.ts`（`@/constants`）；安全区（状态栏 / 胶囊）在页面内用 `uni.getWindowInfo` + `uni.getMenuButtonBoundingClientRect` 实测。

## 2.1 沿用（跨页复用）

| 组件 | 作用 | 规格 |
|---|---|---|
| `RetryBlock` | 加载失败重试（菜品首页首屏失败态） | [§2.1.1](#211-retryblock--加载失败块) |
| `PageLoading` | 内容区加载块（图标慢速旋转） | [§2.1.2](#212-pageloading--内容区加载块) |
| `AppIcon` | 全部图标 | 见 §1.8 |
| `ImagePlaceholder` | 菜品图占位 | 见 §1.9 |

> 🔴 跨页公共件仅保留 `components/` 内 5 个（`AppIcon` / `ImagePlaceholder` / `RetryBlock` / `PageLoading` / `StatusBlock`）。

### 2.1.1 `RetryBlock` —— 加载失败块

- **形态**：无底色居中列；`flex: 1` + 纵向居中；`gap: --spacing-xs`；`padding: --spacing-xl --spacing-lg`。
- **实现**：与 `PageLoading` **共用 `StatusBlock` 骨架** —— 两者图标尺寸 / 文案字阶 / 居中位置完全一致。
- **图标**：`warning`，`56rpx`。
- **文案**：`--font-h3` + `--weight-regular` + `--text-title`。
- **交互**：整块可点（`opacity: .7`）；**在途** ⇒ 仅忽略点击（🔴 不引入旋转 loading）。
- **不改标题 / 不加按钮**。
- **适用面**：菜品首页首屏整页失败态（内容区只渲染 `RetryBlock`，不渲染图标网格）。

### 2.1.2 `PageLoading` —— 内容区加载块

- **定位**：🔴 **非全屏遮罩** —— 由菜品首页放进自己的**内容区**，`flex: 1` 占满剩余高度并**竖直居中**（背景透明、不改页面底色）。
- **形态**：与 `RetryBlock` **共用 `StatusBlock` 骨架** —— **居中一枚 `loading` 图标（56rpx、Plump 填充 SVG、`opacity .55`）** + `--spacing-xs` 间距的无衬线圆体文案（`--font-h3` + `--weight-regular` + `--text-title`，默认「加载中」）。
- **旋转**：🔴 **仅图标本体**以 `--duration-spin`(2000ms) 线性匀速旋转；**无外围圆环、无描边、无底色容器**。
- **主题**：🔴 单主题（奶米纸色），不消费深色变量。

## 2.2 新增（本设计引入）

> 逐组件登记规格；**页面稿只写「本页用法」，不复述规格**。

### `HomeHeader` —— 页头

- **用途**：菜品首页顶部 brand strip；安全区避让 + 品牌 / 日期，无操作按钮。
- **形态**：`--bg-page` 底、🔴 **无分割线 / 描边**（与网格靠留白分组）；两行文案（wordmark `--font-display` / `--text-title`，subtitle `--font-caption` / `--text-body`）**行高均 1.1**，两行总高落在胶囊行内；subtitle 文案为「M 月 D 日 今天吃什么」（日期与提示语以**空格**分隔）。
- **位置**：与微信右上角胶囊同一水平行 —— `padding-top = statusBarHeight`，内容区高 = 胶囊行高（与胶囊同顶同底，取不到矩形时用 `--header-height` 兜底）；品牌块与胶囊垂直居中对齐；不随网格滚动。
- **使用**：仅菜品首页。

### `DishGrid` —— 菜品图标网格

- **用途**：菜品首页上方主内容区；承载 3 列竖向滚动的菜品图标。
- **排布**：3 列 flex 换行；滚动方向竖直（`scroll-y`），**无左右翻页**；筛选后自动重排填位。
- **内容**：遍历 `DishTile` 渲染；首屏加载渲染 `PageLoading`；失败渲染 `RetryBlock`；搜索 0 命中渲染空状态（见 [菜品首页.md](./菜品首页.md) §7）。
- **使用**：仅菜品首页。

### `DishTile` —— 菜品图标

- **用途**：单个菜品入口；圆角矩形图片 + 下方菜名。
- **形态**：1:1 圆角矩形（`--radius-card` + `var(--border-width) --border-color` 细描边）；图下菜名 `--font-subtitle` / `--text-title`，单行 `ellipsis`；图片按 §1.9 加载顺序取万象缩略图（限宽 `400`），加载 / 失败 / 为空走 `ImagePlaceholder`。
- **交互**：`@tap` 触发 `open`（再点同一磁贴 = 收起），由 `DishGrid` 按 id 展开/收起 `DishExpandCard`；🔴 无长按；按压 `scale(.96)` 回弹（`--ease-bounce`）。
- **使用**：仅菜品首页（被 `DishGrid` 遍历）。

### `DishExpandCard` —— 内联展开卡

- **用途**：点 `DishTile` 后在网格中展开；承载菜品详情、售卖点列表与反馈入口，是菜品首页**唯一信息面**。
- **容器**：🔴 **内联卡**，非弹层、无遮罩；插在被点磁贴所在行的下方，跨 3 列整行；同时只允许一张展开。
- **动画**：`scale(.96)` + 淡入 → 目标尺寸（`--duration-base` + `--ease-out`），🔴 无过冲；切换时旧卡收起、新卡展开。
- **内容（自上而下）**：
  - **大图**：16:9 圆角矩形（`--radius-card` + 细描边），按 §1.9 取万象缩略图（限宽 `800`），失败走 `ImagePlaceholder`；
  - **菜名**（`--font-title` / `--text-title`）+ 右侧「收起」浅杏软胶囊；
  - **指标行**：`N 处售卖` + `¥x 起`（最低价；无价格则不显示）；
  - **描述**（`--font-body` / `--text-body`）；
  - **售卖点列表**：逐项左「食堂 · 楼层 · 档口」/ 右「¥价格」；无档口 / 无楼层显示「暂无」（`--text-disabled`）；`price = null` 显示「价格待定」；
  - **反馈入口**：底部「反馈这道菜」浅杏软胶囊，唤起 `FeedbackPanel`。
- **滚动**：卡片随网格滚动；展开后由 `DishGrid` 用 `scroll-into-view` 带入可视区；长内容由网格滚动承载（卡片内不嵌套滚动）。
- **使用**：仅菜品首页。

### `SearchDock` —— 底部搜索框

- **用途**：菜品首页底部常驻 HUD；输入一句话触发语义匹配。
- **形态**：悬浮胶囊（左右 `--page-gutter`、底部 `--spacing-sm` + `env(safe-area-inset-bottom)`）；`--bg-card` 底 + `--border-color` 细描边 + `--shadow-soft`；圆角 `--radius-pill`；🔴 **聚焦与点按不做变色反馈**（描边恒为 `--border-color`，不转主色）。
- **浮层**：`position: absolute` 挂在内容区容器上（脱离布局流、`--z-dock`），网格从胶囊下方穿过；胶囊只占自身矩形，剩余底部净空由滚动内容的 `--dock-reserve` 让出 —— 任何屏宽下都不遮挡可点区域。
- **控件高度**：输入框与圆形搜索按钮**同高** `--control-height`（`96rpx`），胶囊内距 `--spacing-2xs`，整体饱满、与磁贴体量一致。
- **搜索按钮**：浅杏圆形按钮（`--pill-bg` + `--radius-pill`，边长 = `--control-height`）+ **`search` 放大镜图标 `40rpx`**；搜索中换 `loading` 图标以 `--duration-spin` 匀速旋转并弱化（`opacity .6`）。
- **待机淡出**：无点击 / 输入满 `5s` ⇒ 整条胶囊 `opacity .7`（`--duration-slow` + `--ease-out` 过渡）；任意点击、聚焦、输入、清空或搜索完成立即恢复。
- **交互**：聚焦输入；回车 / 点放大镜 → `POST /dishes/recommend`；有输入时显示「清空」；🔴 暂不做语音 / 主题切换 / 随机。
- **使用**：仅菜品首页。

### `FeedbackPanel` —— 文本反馈

- **用途**：菜品内联展开卡内的反馈入口，提交产品 / 菜品文本反馈。
- **形态**：居中卡片式内联面板（`.fb`，遮罩 `--overlay-scrim` + 面板 `--overlay-panel-bg` / `--radius-modal`）；类型切换（产品 / 菜品）+ 正文多行输入 + 取消 / 提交。
- **提交**：`POST /feedback`；正文过微信 `msgSecCheck`；成功仅给一次 Toast，**无回执、无历史**。
- **交互**：提交失败 / 内容安全未通过 → 提示重试。
- **使用**：仅菜品首页（从 `DishExpandCard` 唤起）。

# 三、维护口径

1. **新公共组件**：先进本文件登记规格，再被页面消费。
2. **页面改动**：若某页需偏离本文件口径，**先修订本文件**（或登记该页例外）再动代码。
3. **页面设计稿**不得复述本文件的组件规格；引用写法 = `见 [公共组件与形态基线.md](./公共组件与形态基线.md) §x`。
4. **改视觉值只改 token**，不在页面里裸写。
