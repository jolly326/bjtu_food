## 1 · 页面结构（自上而下）

🔴 **页面恒为 4 块垂直分区**：**Header（通栏矩形）→ 问候语（通栏矩形块）→ 海报区（横向滑动海报卡）→ TabBar 容器**；区块之间只以留白分隔，**不增加分割线**。

🔴 外层骨架（Header + TabBar 容器 + 页面根 TabBar 让位）由 base `TabPage` 统一提供（见[基线](./公共组件与形态基线.md) §2.1.6）；本页只填 `hero` 插槽（问候语，行 2）与内容插槽（海报区，行 3），二者在三个 tab 页处于同一屏幕位置。

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | **Header（通栏矩形）** | 左：**明暗切换图标按钮**；中：标题「**知行食记**」；右：微信原生右上角胶囊（**不改动**）| 上贴屏幕顶部；高 = `max(statusBarHeight, env(safe-area-inset-top))` + 胶囊带高 + 下间距 `--spacing-sm`(16rpx)；详见下方「Header」 |
| 2 | **问候语（通栏矩形块）** | **只承载问候文本**（独立全屏宽矩形）；随时间四态切换；**对象统一称「小红果」**；**块内水平 + 垂直完全居中**；紧贴 Header 下方 | `--font-title`(40rpx) + `--weight-regular` + `--text-title`(深棕 #44382e) + **衬线**（字号缩小、降低视觉体量）；块上下留白 `--spacing-md`(24rpx)；**盒高压紧一档** `calc(var(--hero-box-height) - var(--spacing-2xl))`(128rpx，单行问候语不与美味 / 记忆双行标题块对齐，见[基线](./公共组件与形态基线.md) §2.1.6） |
| 3 | **海报区** | 次级标题「**今日食单**」（浅棕灰辅助文字、字号下调，二级副标题） + **横向滑动海报卡（slider）**：单卡大圆角、图四周留内边距不贴圆角边缘，右邻卡露出一小段左缘提示可横滑 | 标题 `--font-h3`(32rpx) + `--text-tertiary`(浅棕灰) + 衬线；**与问候语之间留白 `calc(--spacing-2xl × 2)`(96rpx)**；卡宽 = 屏宽 − `2 × --page-gutter` − 24rpx（右侧露下一张卡左缘 24rpx）；圆角 `--radius-card-stack`(32rpx) + `--shadow-card-stack` |
| 4 | **TabBar 容器（通栏矩形块）** | 三项「**风物** ｜ **美味** ｜ **记忆**」；**独立固定容器** | 见 [基线](./公共组件与形态基线.md) §2.1.1 |

### Header（区块 1）

| 项 | 口径 |
|---|---|
| 范围 | 屏幕最顶端，**上贴屏幕顶部**；下边界 = 微信右上角原生胶囊下缘 + 预留间距；**独立完整通栏矩形** |
| 左侧 | **明暗切换图标按钮**：`AppIcon` `44rpx` + `tone="default"`，**图标左缘与页面基准线（`--page-gutter`）对齐**；浅色态显 `moon`、深色态显 `sun`；命中区 ≥ `--tap-target-size`；按压 `opacity: .6` |
| 居中 | 标题「**知行食记**」—— `--font-title`(40rpx) + `--weight-medium` + `--text-title` + 衬线；水平居中 |
| 右侧 | 微信原生右上角胶囊 —— **不改动、不自定义**，本区域仅为其避让 |
| 高度 | `max(statusBarHeight, env(safe-area-inset-top))` + 胶囊带高 + 下间距 `--spacing-sm`(16rpx) |

> 🔴 **明暗切换作用于全站主题** —— tap 即在浅色 / 深色间切换（三个 tab 页与全部组件同批换肤）；**默认浅色**，选择写入 storage 持久化。切换入口暂仅本页 Header。

**问候语四态**

| 时段（本地时间） | 文案 |
|---|---|
| `< 11:00` | 早上好，小红果 |
| `11:00 – 13:00` | 中午好，小红果 |
| `13:00 – 17:00` | 下午好，小红果 |
| `≥ 17:00` | 晚上好，小红果 |

> 「小红果」是**固定的群体称谓** —— **不读取**用户名 / 昵称 / 头像（全匿名）。

🔴 **海报卡内零文本** —— 无标题、无按钮、无蒙层；档口名称 / 所属食堂 / 位置**全部由海报图自身承载**（风味评级只在[美味页](./美味.md)单卡呈现）。

## 2 · 海报横向滑动器（区块 3）

| 项 | 口径 |
|---|---|
| 容器 | 原生 `swiper`（横向、`indicator-dots: false`、`circular: false`）；单卡占满宿主高度（卡顶紧接「今日食单」、卡底靠近 TabBar 容器）|
| 单卡 | **图即卡面**：大圆角 `--radius-card-stack`(32rpx) + 柔和弥散阴影 `--shadow-card-stack` 直接落在图自身上（无外层衬底、无外围矩形环）；四边留白由页面 gutter 与卡间距承担 |
| 卡间与露边 | 卡左缘 `--page-gutter`(32rpx)（与「今日食单」同线）；`next-margin = 左 gutter + 24rpx` ⇒ 右邻卡露出**左缘 24rpx**一小截（暗示可横滑）；卡间呼吸位由下一项左内距承担，**固定间距不变** |
| 滑动 | 横向拖拽分页滑动，依次浏览，可回看上一张；🔴 **无循环、不回跳** |
| 占位 | 图未就绪 / 破图 ⇒ 卡内 `ImagePlaceholder` 灰块（[基线](./公共组件与形态基线.md) §1.9），不额外露灰框 |
| 点击 | **无任何点击行为**（纯展示 + 横滑）|

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page` = 纯白 `#FFFFFF`（见 [设计变量](./设计变量.md) §1.1） |
| Header | 标题 `--font-title` + `--weight-medium` + `--text-title` + 衬线（水平居中）；切换按钮 `AppIcon` `44rpx`（图标左缘 = 页面基准线） |
| 问候语 | `--font-title`(40rpx) · `--weight-regular` · `--text-title` · **衬线**（块内居中，深棕；字号较页头大标题小一档） |
| 次级标题「今日食单」 | `--font-h3`(32rpx) · `--weight-regular` · `--text-tertiary` · 衬线（浅棕灰二级副标题，左对齐） |
| 海报卡 | 圆角 `--radius-card-stack`(32rpx) · 阴影 `--shadow-card-stack`（柔和弥散、低浓度）· **图即卡面**（无外层衬底环）· 图 `aspectFill` 铺满卡盒、圆角落在图上 |
| TabBar 容器 | 见 [基线](./公共组件与形态基线.md) §2.1.1 |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **无任何海报** | 「今日食单」标题下方渲染**统一空态块 `EmptyBlock`**（三页同一实现）：`image` 图标 64rpx + 衬线标题「今日食单暂未更新」+ 浅灰引导「上新的海报会出现在这里」，竖直居中、无动作按钮；**不渲染占位卡** |
| **数据加载失败** | **保留问候语（hero）**，内容区**不渲染「今日食单」与海报滑动器**，改为 **`RetryBlock`（点此重试）**，在 hero 下方区域**竖直居中** —— 与美味 / 记忆三页同构；**不渲染占位卡** |
| **页内恢复入口** | **提供**：失败态整块「加载失败 / 点此重试」可点，重试即重新拉取海报；无下拉刷新 / 无骨架屏 |
| **仅 1 张海报** | 正常展示（单层，不可划） |
| **图比例不符** | 按卡位 `aspectFill` **填满裁切**（卡片不锁比例），四周内边距保留 |
