## 1 · 页面结构（自上而下）

🔴 **页面恒为 4 块垂直分区**：**Header（通栏矩形）→ 问候语（通栏矩形块）→ 海报卡片栈 → TabBar 容器**；区块之间只以留白分隔，**不增加分割线**。

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | **Header（通栏矩形）** | 左：**明暗切换图标按钮**；中：标题「**知行食记**」；右：微信原生右上角胶囊（**不改动**）| 上贴屏幕顶部；高 = `max(statusBarHeight, env(safe-area-inset-top))` + 胶囊带高 + 下间距 `--spacing-sm`(16rpx)；详见下方「Header」 |
| 2 | **问候语（通栏矩形块）** | **只承载问候文本**（独立全屏宽矩形）；随时间四态切换；**对象统一称「小红果」**；**块内水平 + 垂直完全居中**；紧贴 Header 下方 | `--font-hero`(64rpx) + `--weight-regular` + `--text-title`(深棕 #44382e) + **衬线**；块上下留白 `--spacing-md`(24rpx) |
| 3 | **海报区** | 次级标题「**今日食单**」（弱化一档） + **三层 Z 轴海报卡片栈**：顶层完整可划走，中 / 下层下坠半透明作叠层纸边 | 标题 `--font-title`(40rpx) + `--text-secondary`(弱化) + 衬线；**与问候语之间留白 `calc(--spacing-2xl × 2)`(96rpx)**；卡宽 = 屏宽 − `2 × --page-gutter`；圆角 `--radius-card-stack`(28rpx) + `--shadow-card-stack` |
| 4 | **TabBar 容器（通栏矩形块）** | 三项「**风物** ｜ **美味** ｜ **记忆**」；**独立固定容器** | 见 [基线](./公共组件与形态基线.md) §2.1.1 |

### Header（区块 1）

| 项 | 口径 |
|---|---|
| 范围 | 屏幕最顶端，**上贴屏幕顶部**；下边界 = 微信右上角原生胶囊下缘 + 预留间距；**独立完整通栏矩形** |
| 左侧 | **明暗切换图标按钮**：`AppIcon` `44rpx` + `tone="default"`，**图标左缘与页面基准线（`--page-gutter`）对齐**；浅色态显 `moon`、深色态显 `sun`；命中区 ≥ `--tap-target-size`；按压 `opacity: .6` |
| 居中 | 标题「**知行食记**」—— `--font-title`(40rpx) + `--weight-medium` + `--text-title` + 衬线；水平居中 |
| 右侧 | 微信原生右上角胶囊 —— **不改动、不自定义**，本区域仅为其避让 |
| 高度 | `max(statusBarHeight, env(safe-area-inset-top))` + 胶囊带高 + 下间距 `--spacing-sm`(16rpx) |

> 🔴 **明暗切换作用于全站主题** —— tap 即在浅色 / 深色间切换（三个 tab 页与全部组件同批换肤）；**默认浅色**，选择写入 storage 持久化。切换入口暂仅本页 Header。

**问候语四态**

| 时段（本地时间） | 文案 |
|---|---|
| `< 11:00` | 早上好，小红果 |
| `11:00 – 13:00` | 中午好，小红果 |
| `13:00 – 17:00` | 下午好，小红果 |
| `≥ 17:00` | 晚上好，小红果 |

> 「小红果」是**固定的群体称谓** —— **不读取**用户名 / 昵称 / 头像（全匿名）。

🔴 **海报卡内零文本** —— 无标题、无按钮、无蒙层；档口名称 / 所属食堂 / 位置**全部由海报图自身承载**（风味评级只在[美味页](./美味.md)单卡呈现）。

## 2 · 海报卡片栈（区块 3）

| 项 | 口径 |
|---|---|
| 结构 | 同一槽位堆叠**至多 3 张**真实海报：顶层完整不透明、可水平拖拽；中 / 下层依次 `translateY` 下坠 `12rpx × 层深`（中 12 / 下 24）、`opacity: .2`、`pointer-events: none`（纯装饰叠层纸边）|
| 拖拽 | 仅顶层响应**水平**拖拽（垂直滑动忽略），跟手节流 16ms；位移 **≥ 卡宽 22%** ⇒ 沿方向飞出（`--duration-slow`）；**< 22%** ⇒ 回弹（`--duration-base`）|
| 晋升 | 飞出后**下一层上浮接替**顶层（同一 DOM 节点连续过渡）；🔴 **划到末张即停** —— 不循环、不回跳 |
| 卡面 | 圆角 `--radius-card-stack`(28rpx) + `--shadow-card-stack`；卡内**四边内距 `--spacing-lg`(32rpx)** ⇒ 图片在卡内居中、**四周留白不铺满**；图未就绪露 `--bg-placeholder` |
| 卡面装饰 | 底层淡装饰字符「**食**」：衬线 `calc(--font-hero × 3)`(192rpx) + `--text-decor`，左上角出血、`z-index: 0`、`pointer-events: none`；图片 / 占位 `z-index: 1`，**不遮挡** |
| 槽位 | 左右各 `--page-gutter`(32rpx)（卡缘与「今日食单」同线）；底部让出 `--spacing-md`(24rpx) 承接最深层下坠 |
| 点击 | **无任何点击行为**（纯展示 + 划走）|

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page` = 奶米白（见 [设计变量](./设计变量.md) §1.1） |
| Header | 标题 `--font-title` + `--weight-medium` + `--text-title` + 衬线（水平居中）；切换按钮 `AppIcon` `44rpx`（图标左缘 = 页面基准线） |
| 问候语 | `--font-hero`(64rpx) · `--weight-regular` · `--text-title` · **衬线**（块内居中，深棕） |
| 次级标题「今日食单」 | `--font-title`(40rpx) · `--weight-regular` · `--text-secondary` · 衬线（弱化一档，左对齐） |
| 海报卡 | 圆角 `--radius-card-stack`(28rpx) · 阴影 `--shadow-card-stack` · 底 `--bg-placeholder` · 卡内距 `--spacing-lg`(32rpx) · 图 `aspectFill` 填满裁切并留白 |
| 卡面装饰字符 | 「食」· 衬线 · `calc(--font-hero × 3)`(192rpx) · `--text-decor` · `z-index: 0` |
| TabBar 容器 | 见 [基线](./公共组件与形态基线.md) §2.1.1 |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **无任何海报** | 渲染 **3 张占位卡**（按同一卡片栈堆叠，`--bg-placeholder` 底 + 内嵌 `ImagePlaceholder` 图标 **48rpx** 居中），可划走 |
| **数据加载失败** | 同上 —— 渲染 3 张占位卡；**不出现**文字失败块 / 空态文案 |
| **页内恢复入口** | **不提供**（无按钮 / 无下拉刷新 / 无骨架屏）—— 数据需重取时由用户**重进小程序** |
| **仅 1 张海报** | 正常展示（单层，不可划） |
| **图比例不符** | 按卡位 `aspectFill` **填满裁切**（卡片不锁比例），**不做留白** |
