## 1 · 页面结构（自上而下）

🔴 **页面恒为 4 块垂直分区**：**Header（通栏矩形）→ 问候语（通栏矩形块）→ 卡片海报区 → TabBar 容器（通栏矩形块）**；区块之间只以留白分隔，**不增加分割线**。

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | **Header（通栏矩形）** | 左：**明暗切换图标按钮**（浅色 / 深色切换）；中：标题「**知行食记**」；右：微信原生右上角胶囊（三点 + 圆圈，**不改动**）| 上贴屏幕顶部；高 = `max(statusBarHeight, env(safe-area-inset-top))` + 胶囊带高 + 下间距 `--spacing-lg`(32rpx)；详见下方「Header」 |
| 2 | **问候语（通栏矩形块）** | **只承载问候文本**（独立全屏宽矩形）；随时间四态切换；**对象统一称「小红果」**；**块内水平 + 垂直完全居中**（一级信息，**加粗衬线**）；紧贴 Header 下方 | `--font-display`(48rpx) + `--weight-bold` + `--text-title` + 衬线；块上下留白 `--spacing-2xl`(48rpx) |
| 3 | **海报区** | 左上角标题「**今日食单**」；一屏一张、横向滑动，**默认态第 1 张完整露出 + 第 2 张左缘一小截（peek）**；卡片外框宽高统一，**贴区域底部、靠近 TabBar**；**空 / 失败时渲染 3 张占位卡**（同样可横向滑动）| 海报区**顶部内距 `--spacing-2xl`(48rpx)**（与 Header 有效底距对位 ⇒ 问候语与上下两侧标语等距）；标题 `--font-title`(40rpx) + `--weight-bold` + 衬线，距卡顶 `--spacing-lg`(32rpx)（紧凑柔和、不贴死）；卡宽 `calc(100vw - --page-gutter × 2 - --spacing-md)`（= 屏宽 − 88rpx）、**卡高占满海报区剩余高度**；圆角 `--radius-card-stack`(24rpx) + `--shadow-card-stack` |
| 4 | **TabBar 容器（通栏矩形块）** | 三项「**风物** ｜ **美味** ｜ **记忆**」；Tab 在容器内**水平 + 垂直居中**，三项在胶囊内**水平均分**；**独立固定容器，不受上方海报滑动影响** | 容器全宽、底置（底抵屏幕有效可视区底部）；Tab 宽 = 海报卡宽（`calc(100vw - --page-gutter × 2 - --spacing-md)`）、**容器内水平居中**；见 [基线](./公共组件与形态基线.md) §2.1.1 |

### Header（区块 1）

| 项 | 口径 |
|---|---|
| 范围 | 屏幕最顶端，**上贴屏幕顶部**（`top: 0`；自定义导航栏下内容起始即屏顶，状态栏区由本块避让）；下边界 = 微信右上角原生胶囊下缘 + 预留间距；**独立完整通栏矩形**，与下方问候区以留白作视觉分隔 |
| 左侧 | **明暗切换图标按钮**：`AppIcon` `44rpx` + `tone="default"`，**图标左缘与页面基准线（`--page-gutter` 32rpx）对齐**（与海报卡左缘同线）；浅色态显 `moon`、深色态显 `sun`（图标预示点击后的目标模式）；命中区 ≥ `--tap-target-size`；按压 `opacity: .6` |
| 居中 | 标题「**知行食记**」—— `--font-title`(40rpx) + `--weight-medium` + `--text-title` + 衬线；水平居中 |
| 右侧 | 微信原生右上角胶囊（三点 + 圆圈）—— **不改动、不自定义**，本区域仅为其避让 |
| 高度 | `max(statusBarHeight, env(safe-area-inset-top))` + 胶囊带高（胶囊高 + 上下间隙 × 2，与 `uni.getMenuButtonBoundingClientRect()` 对齐）+ 下间距 `--spacing-lg`(32rpx) |

> 🔴 **明暗切换作用于全站主题** —— tap 即在浅色 / 深色间切换（三个 tab 页与全部组件同批换肤）；**默认浅色**，选择写入 storage 持久化；深色色值与主题机制见 [设计变量.md](./设计变量.md) §1.2 · [基线](./公共组件与形态基线.md) §1.1。切换入口暂仅本页 Header。

**问候语四态**

| 时段（本地时间） | 文案 |
|---|---|
| `< 11:00` | 早上好，小红果 |
| `11:00 – 13:00` | 中午好，小红果 |
| `13:00 – 17:00` | 下午好，小红果 |
| `≥ 17:00` | 晚上好，小红果 |

> 「小红果」是**固定的群体称谓** —— **不读取**用户名 / 昵称 / 头像（全匿名）。

🔴 **海报卡内零文本** —— 无标题、无按钮、无蒙层；档口名称 / 所属食堂 / 位置**全部由海报图自身承载**。

> 🔴 海报卡**只承载海报图本身** —— 风味评级属于菜品信息，只在美味卡 / 记忆卡呈现，不在海报卡挂载。

## 2 · 交互

| 项 | 口径 |
|---|---|
| 滑动 | 横向原生滑动（跟手）、**可回看上一张**、无循环 |
| 左右边距 | 左侧 `--page-gutter`(32rpx)；**右侧露出第二张卡左缘 24rpx**（peek，直观暗示可滑动）；卡间呼吸位 32rpx（与页面 gutter 同值） |
| 点击 | **无任何点击行为**（纯展示） |
| 加载中 / 失败 / 为空 | 海报区渲染 **3 张占位卡**（各占一个海报位：`--radius-card-stack` + 底 `--bg-placeholder` + 内嵌 `ImagePlaceholder`（图标 **48rpx**、卡片内垂直居中）），**同样可横向滑动**—— **不留空白、不用文字失败块** |
| 页内恢复入口 | **不提供**（无按钮 / 无下拉刷新 / 无骨架屏）—— 数据需重取时由用户**重进小程序** |
| 明暗切换 | Header 左侧 `sun` / `moon` 按钮，tap 切换**全站**浅色 / 深色主题（默认浅色、storage 持久化；深色色值见 [设计变量](./设计变量.md) §1.2） |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page` = **`#FFFDFE`**（暖白，见 [设计变量](./设计变量.md) §1.1） |
| Header | 标题 `--font-title`(40rpx) · `--weight-medium` · `--text-title` · 衬线（水平居中）；切换按钮 `AppIcon` `44rpx`（**图标左缘 = 页面基准线**，与海报卡左缘对齐）；通栏矩形，与问候区以留白分隔 |
| 问候语 | `--font-display`(48rpx) · `--weight-bold` · `--text-title` · 衬线（**块内水平 + 垂直居中**；加粗，保留深棕色不变） |
| 海报区标题 | 「**今日食单**」—— `--font-title`(40rpx) · `--weight-bold` · `--text-title` · 衬线（**左对齐**，海报区左上角，距卡顶 32rpx） |
| 海报卡 | 圆角 `--radius-card-stack`(24rpx) · 阴影 `--shadow-card-stack` · 底 `--bg-placeholder`（图未就绪时） · **宽高统一、高占满海报区剩余空间**（不锁 3:4） · 图 `aspectFill` 填满裁切 |
| 左右内距 | 左 `--page-gutter`(32rpx) / 卡间 `--page-gutter`(32rpx) / 右 peek `24rpx`（露下一张左缘） |
| TabBar 容器 | 全宽通栏、底置（底抵屏幕有效可视区底部，**独立固定、不随海报滚动**）；三项在胶囊内**水平均分 + 垂直居中**，胶囊在容器内**水平居中**；图标 `40rpx` 线性 + 标签 `--font-body`(26rpx) 衬线；Tab 宽 = 海报卡宽（`calc(100vw - --page-gutter × 2 - --spacing-md)`）；双囊样式见 [基线](./公共组件与形态基线.md) §2.1.1 |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **无任何海报** | 海报区渲染 **3 张占位卡**（同「加载中 / 失败 / 为空」） |
| **数据加载失败** | 海报区渲染 **3 张占位卡**（同「加载中 / 失败 / 为空」）；**不出现**文字失败块 / 空态文案 |
| **仅 1 张海报** | 正常展示（左右等距，无露边设计） |
| **图比例不符** | 按卡位 `aspectFill` **填满裁切**（卡片不锁比例），**不做留白** |
