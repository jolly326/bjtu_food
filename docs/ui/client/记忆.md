🔴 外层骨架（全局 `AppHeader` + 底部 `TabBar` + 页面根 TabBar 让位）由 base `TabPage` 统一提供（见[基线](./公共组件与形态基线.md) §2.1.6）；本页 `hero` 插槽放页级标题块（行 2），内容插槽放年月导航（行 3）+ 日期分组（行 4），二者在三个 tab 页处于同一屏幕位置；TabBar 让位已由 `TabBar` 页面根统一承担，滚动区 / 空态不再单独让位。

**全局日期格式**：对标 Julienne 页面头部 `Wednesday, May 21th` ⇒ **`星期X，X月X日`**（示例：`星期日，10月18日`），星期在前、逗号分隔。

**日期组底层装饰**：每个日期分组背景右下角挂一枚超大淡数字（该组**日部分** `DD`，如 `18`），`--memory-motif-size`(280rpx) + `--text-tertiary` + `opacity .06`；绝对定位、`z-index: 0`、不参与交互，**不遮挡卡片 / 文字 / 图片**；日期标记与卡片行 `z-index: 1`。🔴 不在页面底部挂固定装饰。

## 2 · 交互（业务规则完全沿用 [B4](../../func/client/B-轻量反馈/B4-记忆.md) / [B2](../../func/client/B-轻量反馈/B2-评分反馈.md) / [B3](../../func/client/B-轻量反馈/B3-菜品纠错.md)）

卡片两互斥状态（状态机：`client/src/pages/memory/components/useMemoryUI.ts`）：

- **浏览态 A（默认）**：菜名 / 位置·价格 / 圆形大图 / 右下笑脸角标全部常驻，手势全开。
- **原位评价态 B（Inline 局部模态）**：点笑脸挂角进入；卡片覆盖**与卡片同色的底色面板**（非白底弹窗），居中「为这道菜品打分」+ 三档线性表情（meh 一般 / smile 不错 / laugh 很棒）；点表情**即时提交**并退出 B、挂角标记已评；点空白区**退出 B 不保存**；B 激活时**捕获手势**：禁用本卡长按、横滑动作自动关闭 B 再切卡；其余卡片手势不受影响。

| 项 | 口径 |
|---|---|
| 月份切换 | 点选年月项**仅切筛选、不重新请求**；切换时内容平滑淡入；切到**空月份**时下方日期分组**直接不渲染卡片**（该月仅时间轴节点弱化） |
| 评分（笑脸角标） | 🔴 **仅换皮**：评价面板三档**线性表情** 一般(meh) / 不错(smile) / 很棒(laugh) 映射到后端 **1 / 3 / 5**（原「不喜欢(1)」在界面改名为「一般」），数值契约不变（[B2](../../func/client/B-轻量反馈/B2-评分反馈.md)）；点表情即提交、支持**再次点角标修改**；提交中 / 限频退避挂禁用态 |
| 长按菜单 | 🔴 **仅浏览态 A 可长按**（B 激活时无效）；长按卡片整区 → `Modal Bottom Sheet`（反馈 / 删除记忆 / 取消）+ 半透明 scrim 遮罩 |
| 反馈（纠错） | 长按菜单「反馈」→ 同一 Sheet 内容切换为纠错选项（[B3](../../func/client/B-轻量反馈/B3-菜品纠错.md)） → 点选即提交（无输入框、无配图） |
| 删除（隐藏） | 长按菜单「删除记忆」→ **二次确认弹窗**（独立居中、优先级高于 Sheet）→ 确认即删；遵循「**仅未评分可取消**」，后端拒绝时 Toast 兜底；限频退避挂禁用态 |
| 卡片行 | 横向滑动浏览当日多份餐食；🔴 若某卡处于评价态 B，横滑动作**先关闭 B 再切卡**（全局互斥铁则 3） |
| 加载失败 | `RetryBlock`（整页重试） |

**全局互斥铁则（必实现）**
1. `Bottom Sheet` 与 `原位评价面板` **永不同时渲染**；
2. 单卡同一时刻仅 浏览态 A 或 评价态 B，不叠加；全局**最多 1 张卡**进入 B（开新卡 B 自动关闭旧卡 B）；
3. 横向滑动切换卡片时：若当前卡处于 B，滑动动作**自动关闭 B** 再切卡；
4. 页面返回 / Tab 栏切换（`onHide`）**强制销毁**评价态、关闭所有 Sheet、重置全部卡片状态。

**转场动效**
- 开 / 关原位评价面板：白底面板淡入 / 淡出 `200ms ease-out`；
- 唤起 Bottom Sheet：面板自底部上滑 + 遮罩同步淡入（基线 `BaseSheet` 口径）；下滑 / 点 scrim 关闭；
- 卡片行横滑、卡片按压（`scale(.98)`）保持原 Julienne 动效。

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **加载中** | **骨架屏**：日期标记占位块 + 横向卡片骨架（菜名占位 + 圆形图位 + 操作位占位），🔴 无旋转 loading |
| **无任何记录** | 年月栏（近三月兜底）下方、整体**略偏上**的空态：线性 `notebook` 图标（64rpx、`muted`、低透明度）→ 衬线标题「**暂无美食记忆**」→ 浅灰描述「去美味页标记品尝过的餐食，收藏属于你的校园美食记忆」→ **暖橙描边按钮「去美味页」**（`switchTab` 到美味页）；🔴 不用复杂插画、不用卡片容器 |
| **未评分记录** | 右下笑脸角标为浅灰半透明平脸，点按进入评价面板 |
| **已评记录** | 笑脸角标转为暖棕 + 轻微填充（标记已评），仍可点开面板**修改**评分 |
| **卡片不展示风味评级** | 该信息只在[美味页](./美味.md)单卡呈现 |

## 5 · 禁项

- 禁止厚重按钮、填充色块、多余分割线
- 禁止花哨动效（弹跳、闪光、旋转 loading）
- 卡片表面禁止放置：删除入口、风味评级文字、记录时间、取消按钮、「信息有误」链接、对勾图标

## 6 · 页面动效

- 月份切换：内容淡入
- 卡片行：柔和阻尼横向滑动
- 卡片按压：轻微 `scale(.98)`，缓出动画
