## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让（由 `TabPage` 内 `AppHeader` 承担） | — |
| 2 | **页级标题块（落 `TabPage` 的 `hero` 插槽）** | 左：衬线大标题「记忆」+ **正下方（与标题间距 `--spacing-sm`(16rpx)）**全局日期（垂直排布）；**左右边距与[美味](./美味.md) Topbar 对齐** | 标题 `--font-hero`(64rpx) + `--weight-regular` + 衬线；日期 `--font-small` + `--text-tertiary`；上下 `--spacing-md`(24rpx) / 左右 `--page-gutter`(32rpx)；标题与日期间距 `--spacing-sm`(16rpx)；日期 `line-height: 1.2`；**盒高与三页统一** `--hero-box-height`(176rpx)（见[基线](./公共组件与形态基线.md) §2.1.6） |
| 3 | **年月横向导航（落 `TabPage` 内容插槽）** | 横向可滑；**连续月份轴**（最早记录月 → 当前月，空月份保留节点仅弱化）；每项上下两层：年份小字在上、月份大号衬线在下（**全部月份 `--font-hero`(64rpx) 与页标题同字号**；选中仅加深颜色 `--text-title`，未选浅灰 `opacity .65`）；选中月自动居中 | 见 [基线](./公共组件与形态基线.md) §2.2 `MonthTimeline` |
| 4 | **日期分组容器（落 `TabPage` 内容插槽）** | **倒序日期分组**：`MM.DD` 日期标记 + 当日**横向滚动卡片行** | 日期标记 `--font-display`(48rpx) + `--weight-regular` + `--text-title` + 衬线；标记置于卡片组左上角，下方留 `--spacing-md`；组间距 `--spacing-2xl`(48rpx)；🔴 **无分割线** |
| 5 | 底部 TabBar | 三项（由 `TabPage` 承载） | 见 [基线](./公共组件与形态基线.md) §2.1 |

🔴 外层骨架（全局 `AppHeader` + 底部 `TabBar` + 页面根 TabBar 让位）由 base `TabPage` 统一提供（见[基线](./公共组件与形态基线.md) §2.1.6）；本页 `hero` 插槽放页级标题块（行 2），内容插槽放年月导航（行 3）+ 日期分组（行 4），二者在三个 tab 页处于同一屏幕位置；TabBar 让位已由 `TabBar` 页面根统一承担，滚动区 / 空态不再单独让位。

**全局日期格式**：对标 Julienne 页面头部 `Wednesday, May 21th` ⇒ **`星期X，X月X日`**（示例：`星期日，10月18日`），星期在前、逗号分隔。

**日期组底层装饰**：每个日期分组背景右下角挂一枚超大淡数字（该组**日部分** `DD`，如 `18`），`--memory-motif-size`(280rpx) + `--text-tertiary` + `opacity .06`；绝对定位、`z-index: 0`、不参与交互，**不遮挡卡片 / 文字 / 图片**；日期标记与卡片行 `z-index: 1`。🔴 不在页面底部挂固定装饰。

**日期分组**

| 部位 | 口径 |
|---|---|
| 日期标记 | `MM.DD`（月 / 日均**补前导零**，如 `10.18` / `05.20`）—— `--font-display`(48rpx) + `--weight-regular` + `--text-title` + **衬线**；置于卡片组**左上角**作时间分割标记；下边距 `--spacing-md` |
| 卡片行 | **横向滚动**；单卡 `--record-card-width`(600rpx) × `--record-card-height`(750rpx)（**竖版**，高 > 宽）；行内左右各留 `--page-gutter`（落在滚动**内容层**，滚动容器自身的 padding 不计入可滚宽度）；卡间距 `--spacing-md`，**相邻卡互相露出侧边**暗示可横滑 |
| 分组分隔 | 🔴 **不使用分割线**，只用留白（组间距 `--spacing-2xl`） |

**单卡内容（竖版圆角卡；与[美味](./美味.md)卡片族视觉体系统一）**

```
┌──────────────────────────────┐
│ 鱼香肉丝                      │   ← 左上：衬线粗体菜名（最多 2 行）；右上角整片留空
│ 一楼川菜窗口 · 14元            │   ← 辅助行：紧贴菜名下方、同左对齐
│                              │
│          ○ 圆形大图           │   ← 中部：直径 = 卡内可用宽度 75%
│                              │
│ 反馈                        ☺ │   ← 底部单行两端对齐：左「反馈」文本 / 右三态表情
└──────────────────────────────┘
```

| 部件 | 口径 |
|---|---|
| 卡片形态 | **竖版圆角矩形（高 > 宽）**：`--record-card-width`(600rpx) × `--record-card-height`(750rpx)；圆角 `--radius-card`(36rpx) + `--shadow-card-stack` 柔和低弥散阴影 |
| 卡片表面 | `--bg-page` 填充 + `1rpx` `--border-color` 细描边 + `--radius-card` + `--shadow-card-stack`；卡内距 上 `--spacing-2xl`(48rpx) / 左右 `--spacing-xl`(40rpx) / 下 `--spacing-xl`(40rpx) |
| 菜名 | **左上起点**：衬线 `--font-h3`(32rpx) + `--weight-bold` + `--text-title`（卡内一级标题，最大字号）；最多 2 行 |
| 辅助行（档口 · 价格） | **紧贴菜名正下方、同左对齐、不换行**：`--font-small`(22rpx) + 衬线 + `--text-tertiary`；与菜名间距 `--spacing-2xs`(4rpx)。模板 `档口名 · N元`（「分」→ 元，**整数去掉 `.00`**；无档口时**回退食堂名**） |
| 🔴 右上角 | **清空** —— 不放任何文字 / 图标 |
| 圆形菜品图 | 直径 `--record-photo-size`(390rpx = 卡内可用宽度 520 的 75%)，`border-radius: 50%`；**水平居中**、上下留白均等；`flex: none` **不被挤压**；空 / 失败底 `--bg-placeholder`（浅米） |
| 底部操作行 | **单行、同一基线、两端对齐**：左「反馈」文本 / 右三态表情；与图片间距 `--spacing-lg` |
| 左 · 「反馈」 | 🔴 **纯文本**：衬线 `--font-subtitle`(24rpx) + `--text-tertiary`，无图标 / 无下划线 / 无底色外框；点击态**仅文字加深**（`--text-body`）；命中区 ≥ `--tap-target-size`；点击唤起 `BaseSheet`（[B3](../../func/client/B-轻量反馈/B3-菜品纠错.md)） |
| 右 · 三态表情 | 线性 **40rpx**，**无圆形底 / 无外框 / 无填充**，仅线条颜色区分：未评价 `meh`+muted ｜ 喜欢 `smile`+primary ｜ 一般 `meh`+default ｜ 不喜欢 `frown`+muted |
| 三态循环 | **未评价 → 喜欢 → 一般 → 不喜欢 → 清空（回到未评价）**，每次点击**即时提交**；提交中 / 限频退避挂禁用态 |
| 🔴 卡面不出现 | 删除入口、风味评级、记录时间、「取消」/「信息有误」文字链、对勾 —— 删除走**长按浮层** |

**视觉优先级**：圆形菜品图片 > 菜品名称 > 档口价格辅助文字 > 功能图标。

## 2 · 交互（业务规则完全沿用 [B4](../../func/client/B-轻量反馈/B4-记忆.md) / [B2](../../func/client/B-轻量反馈/B2-评分反馈.md) / [B3](../../func/client/B-轻量反馈/B3-菜品纠错.md)）

| 项 | 口径 |
|---|---|
| 月份切换 | 点选年月项**仅切筛选、不重新请求**；切换时内容平滑淡入；切到**空月份**时下方日期分组**直接不渲染卡片**（该月仅时间轴节点弱化） |
| 评分 | 点右下角表情按三态循环切换并**即时提交**（无二次确认）；🔴 已评分记录的再次提交由**后端裁决**，失败以 Toast 兜底；提交中 / 限频退避挂禁用态 |
| 反馈（纠错） | 点卡片左下角「反馈」**文本** → `BaseSheet` 列选项 → 点选即提交（无输入框、无配图） |
| 删除（隐藏） | 🔴 **卡片表层无删除入口**；**长按卡片整区** → 极简浮层（仅「擦除记忆」文本选项）→ 点选即删；遵循「**仅未评分可取消**」，后端拒绝时 Toast 兜底；限频退避挂禁用态 |
| 卡片行 | 横向滑动浏览当日多份餐食，滚动阻尼柔和 |
| 加载失败 | `RetryBlock`（整页重试） |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页头标题 | `--font-hero`(64rpx) + `--weight-regular` + `--text-title` + **衬线**（与美味页 Topbar 统一） |
| 页头日期 | `--font-small` + `--text-tertiary`（标题正下方）；格式「**星期日，10月18日**」 |
| 年月导航 | 见 [基线](./公共组件与形态基线.md) §2.2 `MonthTimeline`（**连续月份轴**，空月份保留节点；年份 `--font-small` 在上；中文月份衬线在下：**全部 `--font-hero`(64rpx) 同字号，与页标题一致**；选中 `--text-title`、未选 `--text-placeholder` + `opacity .65`（**仅颜色区分**）） |
| 日期组底层装饰 | 每组一枚 `--memory-motif-size`(280rpx) 日数字（`DD`）+ `--text-tertiary` + `opacity .06`；组内右下、`z-index: 0`（内容层 `z-index: 1`） |
| 日期标记 | `MM.DD` —— `--font-display`(48rpx) + `--weight-regular` + `--text-title` + 衬线 |
| 卡片形态 | **竖版** 600rpx × 750rpx；圆角 `--radius-card`(36rpx) |
| 圆形菜品图 | `--record-photo-size`(390rpx) = 卡内可用宽度 75%；`flex: none`；水平居中 |
| 点击反馈 | `scale(.98)`（`--duration-base` `--ease-out`）；🔴 无弹跳 / 闪光 / 旋转 loading |
| 左右内距 | `--page-gutter`(32rpx) |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **加载中** | **骨架屏**：日期标记占位块 + 横向卡片骨架（菜名占位 + 圆形图位 + 操作位占位），🔴 无旋转 loading |
| **无任何记录** | 年月栏（近三月兜底）下方、整体**略偏上**的空态：线性 `notebook` 图标（64rpx、`muted`、低透明度）→ 衬线标题「**暂无美食记忆**」→ 浅灰描述「去美味页标记品尝过的餐食，收藏属于你的校园美食记忆」→ **暖橙描边按钮「去美味页」**（`switchTab` 到美味页）；🔴 不用复杂插画、不用卡片容器 |
| **未评分记录** | 右下表情为 `meh` + `muted`（浅灰平脸），可点循环切换提交 |
| **已评记录** | 表情仅**线条颜色**变化，无外框 / 无底色 |
| **卡片不展示风味评级** | 该信息只在[美味页](./美味.md)单卡呈现 |

## 5 · 禁项

- 禁止厚重按钮、填充色块、多余分割线
- 禁止花哨动效（弹跳、闪光、旋转 loading）
- 卡片表面禁止放置：删除入口、风味评级文字、记录时间、取消按钮、「信息有误」链接、对勾图标

## 6 · 页面动效

- 月份切换：内容淡入
- 卡片行：柔和阻尼横向滑动
- 卡片按压：轻微 `scale(.98)`，缓出动画
