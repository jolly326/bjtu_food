## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | — |
| 2 | **页头** | 左：衬线大标题「记忆」（**加粗**）+ **正下方**小号日期 `2026/10/18`（垂直排布）；**垂直位置与左右边距对齐[美味](./美味.md) Topbar** | 标题 `--font-hero`(64rpx) + `--weight-medium` + 衬线（与美味页标题字重统一）；日期 `--font-small` + `--text-tertiary`（`todayLabelNumeric`，零填充）；上 40rpx / 左右 `--page-gutter`(32rpx) / 下 16rpx |
| 3 | **年月导航** | 横向可滑；每项**上下层级**：年份小字在上、月份大号衬线在下；当前月深色，其余浅灰 | 见 [基线](./公共组件与形态基线.md) §2.2 `MonthTimeline` |
| 4 | **主体** | **倒序日期分组**：`MM.DD` 衬线日期标记 + 该日**横向滚动卡片行** | 日期标记 `--font-display`(48rpx) + `--weight-semibold` + 衬线；组间距 `--spacing-2xl`(48rpx)；🔴 无分割线 |
| 5 | 底部 TabBar | 三项 | 见 [基线](./公共组件与形态基线.md) §2.1 |

- **日期组底层装饰**：**每个日期分组**挂一枚超大淡数字（该组**日部分** `DD`，如 `18`；`--memory-motif-size` 280rpx、`--text-tertiary`、`opacity .06`），绝对定位在**该组背景**右下、`z-index: 0`，**不参与交互、不遮挡卡片 / 文字 / 图片**；日期标记与卡片行 `z-index: 1`。🔴 不再使用页面底部固定装饰。

**日期分组**

| 部位 | 口径 |
|---|---|
| 日期标记 | 如 `10.18` / `05.20`（`MM.DD`，**零填充**）—— `--font-display`(48rpx) + `--weight-semibold` + `--text-title` + **衬线**；置于卡片组**左上方**作时间分割标记；下边距 `--spacing-md` |
| 卡片行 | **横向滚动**；卡宽 `--record-card-width`(600rpx)、卡高 `--record-card-height`(500rpx)（**宽扁比例**）；卡片左侧留 `--page-gutter`；行末留 `--page-gutter` |
| 分组分隔 | 🔴 **不使用分割线**，只用留白（组间距 `--spacing-2xl`） |

**卡片内容（宽扁纸片卡；表面与[美味](./美味.md)卡片族统一）**

| 部件 | 口径 |
|---|---|
| 菜名 | **卡片左上角**：衬线 `--font-h3`(32rpx) + `--weight-semibold` + `--text-title`；最多 2 行；与右上反馈图标同一行 |
| 圆形菜品图 | 直径 `--record-photo-size`(240rpx)、`--radius-circle`；**放大**且**垂直居中偏下**（不贴卡片上部）；底 `--bg-placeholder` |
| 右上 · 反馈图标 | 圆形图标按钮：`message-circle` `28rpx` + `tone="default"`；点击唤起纠错弹窗（[B3](../../func/client/B-轻量反馈/B3-菜品纠错.md)） |
| 左下 · 删除图标 | 圆形图标按钮：`trash-2` `28rpx` + `tone="default"`；点击移除本条记录 |
| 右下 · 评价图标 | 圆形图标按钮：**三态表情循环**（`smile` 喜欢 / `meh` 一般 / `frown` 不喜欢）；显示当前档位，未评分 = `smile` 弱化态；**tap 按 喜欢 → 一般 → 不喜欢 → 喜欢 循环切换**并提交；已评分 = 主色描边 + 主色图标 |
| 🔴 已移除 | **风味评级文字、记录时间、「取消」「信息有误」文字链、对勾标记** —— 卡内只保留**菜名 + 圆形菜品图 + 三个功能图标** |

- **圆形图标按钮（三个功能图标共用）**：命中区 `--tap-target-size`(88rpx)，视觉圆 `calc(--tap-target-size - --spacing-md)`(64rpx) + `1rpx` `--border-color` 圆环；图标 `28rpx`。
- **卡片表面**：与[美味](./美味.md)卡片族统一的**纸片卡面** —— `--bg-page` 填充 + `1rpx` `--border-color` 细描边 + `--radius-card`(36rpx)，🔴 **无阴影**；卡内距 `--spacing-lg`。

## 2 · 交互

| 项 | 口径 |
|---|---|
| 月份切换 | 点选年月导航项即重渲染该月清单（**只切筛选，不重新请求**）；切换时内容平滑淡入 |
| 评分 | 点右下角圆形表情图标：按 **喜欢 → 一般 → 不喜欢 → 喜欢** 循环切换档位并提交（无二次确认）；提交中 / 限频退避时挂禁用态。🔴 改评分遵循 [B2](../../func/client/B-轻量反馈/B2-评分反馈.md) 的**一次性口径** —— 已评分记录的再次提交由后端裁决，失败以 Toast 兜底 |
| 删除 | 点左下角垃圾桶图标移除本条记录（物理删行）；同样遵循 [B4](../../func/client/B-轻量反馈/B4-记忆.md)「仅未评分可取消」口径，后端拒绝时 Toast 兜底；限频退避时挂禁用态 |
| 纠错 | 点右上角反馈图标 → `BaseSheet` 弹层列选项 → **点选即提交**（无文字框、无配图）；提交后无回执 |
| 卡片行 | 横向滑动浏览当日多份餐食，缓动柔和 |
| 加载失败 | `RetryBlock` |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页头标题 | `--font-hero`(64rpx) + `--weight-regular` + `--text-title` + **衬线**（与美味页 Topbar 完全一致） |
| 页头日期 | `--font-small` + `--text-tertiary`（标题正下方） |
| 年月导航 | 见 [基线](./公共组件与形态基线.md) §2.2 `MonthTimeline`（年份 `--font-small` 小字在上；月份大号衬线在下：未选 `--font-subtitle` + `--text-placeholder` + `opacity .65`，当前 `--font-title` + `--text-title`） |
| 页面底层装饰 | `--memory-motif-size`(280rpx) + `--text-tertiary` + `opacity .06`；右下、`z-index: 0` |
| 空态图标 | `book` 64rpx + `tone="muted"` + `opacity .55` |
| 日期标记 | `MM.DD` —— `--font-display`(48rpx) + `--weight-semibold` + `--text-title` + 衬线 |
| 卡片表面 | `--bg-page` + `1rpx var(--border-color)` + `--radius-card`（无阴影，与美味卡片族统一）；卡内距 `--spacing-lg` |
| 圆形图标按钮 | 命中区 `--tap-target-size`(88rpx)；视觉圆 `calc(--tap-target-size - --spacing-md)`(64rpx) + `1rpx` `--border-color`；图标 `28rpx` |
| 左右内距 | `--page-gutter` |
| 动效 | 月份切换内容淡入、卡片行阻尼滑动；🔴 无弹跳 / 闪光 / 旋转 loading |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **加载中** | **骨架屏**：日期标记占位块 + 横向卡片骨架（同新卡结构：菜名占位 + 圆形图位 + 图标占位），🔴 无旋转 loading |
| **无任何记录** | 年月栏（近三月兜底）下方、整体**略偏上**（底部预留卡片空间）的空态：**线性图标 `book`**（64rpx、`tone="muted"`、低透明度）→ 衬线标题「**暂无美食记忆**」→ 浅灰描述「去美味页标记品尝过的餐食，收藏属于你的校园美食记忆」→ **暖橙描边按钮「去美味页」**（`switchTab` 到美味页）；🔴 不用复杂插画、不用卡片容器 |
| **未评分记录** | 右下表情图标可点（循环切换提交） |
| **已评记录** | 表情图标呈**选中态**（主色描边 + 主色图标） |
| **群体评级待评** | 卡片**不再展示风味评级**（该信息只在[美味页](./美味.md)单卡呈现） |
