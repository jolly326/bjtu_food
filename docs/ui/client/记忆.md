**全局日期格式**：对标 Julienne 页面头部 `Wednesday, May 21th` ⇒ **`星期X，X月X日`**（示例：`星期日，10月18日`），星期在前、逗号分隔。

**日期分组**

| 部位 | 口径 |
|---|---|
| 日期标记 | `MM.DD`（月 / 日均**补前导零**，如 `10.18` / `05.20`）—— `--font-display`(48rpx) + `--weight-regular` + `--text-title` + **衬线**；置于卡片组**左上角**作时间分割标记；下边距 `--spacing-md` |

| 分组分隔 | 🔴 **不使用分割线**，只用留白（组间距 `--spacing-2xl`） |

**单卡内容（横版矮胖圆角卡；与[美味](./美味.md)卡片族视觉体系统一；交互两互斥态见 §2）**

┌──────────────────────────────┐
│ 鱼香肉丝（左上，衬线粗体）       │
│                              │

| 部件 | 口径 |
|---|---|
| 卡片形态 | **竖版圆角矩形（高 > 宽）**：`--record-card-width`(480rpx) × `--record-card-height`(540rpx)；圆角 `--radius-card`(32rpx) + `--shadow-card-stack` 柔和低弥散阴影 |
| 卡片表面 | `--bg-card` 填充（`#FAFAFA` 极浅灰白，与纯白页面区分极弱；**无实线描边**） + `--radius-card` + `--shadow-card-stack`；卡内距 上 `--spacing-xl`(40rpx) / 左右 `--page-gutter`(32rpx) / 下 `--spacing-xl`(40rpx)；**`overflow: hidden`** 以裁切探出挂角 |
| 菜名 | **左上起点**：衬线 `--record-name-size`(44rpx) + `--weight-medium` + `--text-title`（卡内一级标题，最大字号）；最多 2 行 |
| 辅助行（位置 · 价格） | **左下角、单行**：`--font-small`(22rpx) + **无衬线** + `--text-tertiary` + 字距 `.02em`（对标参考图弱化辅助行）。模板 `食堂名 · 档口名 · N元`（「分」→ 元，**整数去掉 `.00`**；缺失项自动跳过，分隔符统一 ` · `）；圆图随卡内空间收缩，该行**永不被挤出卡片** |
| 圆形菜品图 | 直径 `--record-photo-size`(280rpx) **固定正方形**（竖直居中于圆图槽、水平居中）；尺寸须保证「菜名折两行 + 位置·价格行」仍放进 540rpx 卡高；空 / 失败底 `--bg-placeholder` |
| 🔴 右上角 | **清空** —— 不放任何文字 / 图标 |
| 🔴 右下角 · 探出式状态角标 | **状态图标**：**已评 = `circle-check`（圆圈对勾）｜ 未评 = `circle-dot`（圆圈点）**；`--record-badge-size`(200rpx)、**正立角度（不旋转）**、**低透明度弱装饰外观**（`muted` 灰 + `opacity .25`）；卡片 `overflow: hidden` 裁切 ⇒ 偏移 `-56rpx`、大部探入右下角可见；`z-index` 高于卡片表面、低于评价面板；**露出部分即命中区**，点按进入「原位评价态 B」 |
| 🔴 卡面不出现 | 删除入口、风味评级、记录时间、常驻评分控件、文本水印、「取消」/「信息有误」文字链 —— 评分走**右下状态角标 / 长按菜单「评价」**，删除走**长按菜单「删除记忆」** |

**视觉优先级**：圆形菜品图片 > 菜品名称 > 位置·价格辅助文字 > 右下状态角标。

**同组卡片景深**：同一日期组内第 2 / 3 张卡逐级 `translateY` 下坠（`--record-stack-step` 一倍 / 两倍）+ `scale .97 / .94`（围绕底边）+ 阴影降档（`--shadow-card-back` / `--shadow-card-back-far`）—— 横向滑动浏览时呈「三层堆叠」层次。

## 2 · 交互（业务规则完全沿用 [B4](../../func/client/B-轻量反馈/B4-记忆.md) / [B2](../../func/client/B-轻量反馈/B2-评分反馈.md) / [B3](../../func/client/B-轻量反馈/B3-菜品纠错.md)）

卡片两互斥状态（状态机：`client/src/pages/memory/components/useMemoryUI.ts`）：

- **浏览态 A（默认）**：菜名 / 位置·价格 / 圆形大图 / 右下状态角标全部常驻，手势全开。
- **原位评价态 B（Inline 局部模态）**：**点右下挂角**或 **长按菜单「评价」**进入（同一 `openEval` 入口）；卡片覆盖**与卡片同色的底色面板**（非白底弹窗，绝对定位覆盖整卡），居中「为这道菜品打分」+ 三档线性表情（meh 一般 / smile 不错 / laugh 很棒）；点表情**即时提交**并退出 B；点空白区**退出 B 不保存**；B 激活时**捕获手势**：禁用本卡长按、横滑动作自动关闭 B 再切卡；其余卡片手势不受影响。

| 项 | 口径 |
|---|---|
| 进入页面 / 切回 tab | 🔴 **每次 `onShow` 重新拉取全量记录**（tab 页不会重新挂载）—— 在美味页新「加入记忆」的菜返回后立即可见 |
| 月份切换 | 点选年月项**仅切筛选、不重新请求**；切换时内容平滑淡入；切到**空月份**时下方日期分组**直接不渲染卡片**（该月仅时间轴节点弱化） |
| 评分（挂角点按 / 长按菜单「评价」） | 🔴 **仅换皮**：评价面板三档**线性表情** 一般(meh) / 不错(smile) / 很棒(laugh) 映射到后端 **1 / 3 / 5**，数值契约不变（[B2](../../func/client/B-轻量反馈/B2-评分反馈.md)）；挂角为**低透明度弱装饰外观、可点进入评价、不标记评价状态**（已评与否只在评价面板内高亮）；点表情即提交、支持**再次点挂角 / 长按修改**；提交中 / 限频退避挂禁用态 |
| 长按菜单 | 🔴 **仅浏览态 A 可长按**（B 激活时无效）；长按卡片整区 → `Modal Bottom Sheet`（反馈 / 评价 / 删除记忆 / 取消）+ 半透明 scrim 遮罩 |
| 评价 | 长按菜单「评价」→ 关闭 Sheet、进入该卡**原位评价态 B**（`openEval`，互斥由 `useMemoryUI` 保证） |
| 反馈（纠错） | 长按菜单「反馈」→ 同一 Sheet 内容切换为纠错选项（[B3](../../func/client/B-轻量反馈/B3-菜品纠错.md)） → 点选即提交（无输入框、无配图） |
| 删除（隐藏） | 长按菜单「删除记忆」→ **二次确认弹窗**（独立居中、优先级高于 Sheet）→ 确认即删；**已评分记录同样可删**（后端重算该菜评价分）；失败时 Toast 兜底；限频退避挂禁用态 |
| 卡片行 | 横向滑动浏览当日多份餐食（同组后卡带 Z 轴景深）；🔴 若某卡处于评价态 B，横滑动作**先关闭 B 再切卡**（全局互斥铁则 3） |
| 加载失败 | **保留 hero（标题 + 日期）**，🔴 **不渲染年月栏 / 日期分组 / 卡片行**，内容区只渲染 `RetryBlock`（点此重试）并在 hero 下方区域**竖直居中** —— 与美味 / 风物三页同构 |

**全局互斥铁则（必实现）**
1. `Bottom Sheet` 与 `原位评价面板` **永不同时渲染**；
2. 单卡同一时刻仅 浏览态 A 或 评价态 B，不叠加；全局**最多 1 张卡**进入 B（开新卡 B 自动关闭旧卡 B）；
3. 横向滑动切换卡片时：若当前卡处于 B，滑动动作**自动关闭 B** 再切卡；
4. 页面返回 / Tab 栏切换（`onHide`）**强制销毁**评价态、关闭所有 Sheet、重置全部卡片状态。

**转场动效**
- 开 / 关原位评价面板：卡片底色面板淡入 / 淡出 `200ms ease-out`；
- 唤起 Bottom Sheet：面板自底部上滑 + 遮罩同步淡入（基线 `BaseSheet` 口径）；下滑 / 点 scrim 关闭；
- 卡片行横滑、卡片按压（`scale(.98)`）保持原 Julienne 动效。

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页头标题 | `--font-hero`(64rpx) + `--weight-regular` + `--text-title` + **衬线**（与美味页 Topbar 统一） |

| 年月导航 | 见 [基线](./公共组件与形态基线.md) §2.2 `MonthTimeline`（**连续月份轴**，空月份保留节点；年份 `--font-small` 在上；中文月份衬线在下：**全部 `--font-hero`(64rpx) 同字号，与页标题一致**；选中 `--text-title`、未选 `--text-placeholder` + `opacity .5`（**仅颜色区分**）） |
| 日期标记 | `MM.DD` —— `--font-display`(48rpx) + `--weight-regular` + `--text-title` + 衬线 |
| 卡片形态 | **竖版** 480rpx × 540rpx（高 > 宽）；圆角 `--radius-card`(32rpx)、`--shadow-card-stack` |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **加载中** | **首屏（尚无任何记录）走整页 `PageLoading`**（44rpx 图标 + 2s 匀速旋转、无外围圆环）；**切回 tab 重拉时保留旧列表**，不闪白、不骨架闪动 |
| **无任何记录** | 年月栏（近三月兜底）下方渲染**统一空态块 `EmptyBlock`**（三页同一实现）：`notebook` 图标（64rpx、`muted`、低透明度）→ 衬线标题「**暂无美食记忆**」→ 浅灰描述「去美味页标记品尝过的餐食，收藏属于你的校园美食记忆」→ 暖橙描边按钮「**去美味页**」（`switchTab` 到美味页）；🔴 不用复杂插画、不套卡片 |
| **未评分记录** | 右下角标为**圆圈点（`circle-dot`）**低透明度弱装饰；点角标或长按菜单「评价」进入评分 |
| **已评记录** | 右下角标为**圆圈对勾（`circle-check`）**低透明度弱装饰；点角标或长按菜单**修改**评分 |
| **卡片不展示风味评级** | 该信息只在[美味页](./美味.md)单卡呈现 |

## 5 · 禁项

- 禁止厚重按钮、填充色块、多余分割线
- 禁止花哨动效（弹跳、闪光、旋转 loading）
- 卡片表面禁止放置：删除入口、风味评级文字、记录时间、取消按钮、「信息有误」链接、对勾图标

## 6 · 页面动效

- 月份切换：内容淡入
- 卡片行：柔和阻尼横向滑动
- 卡片按压：轻微 `scale(.98)`，缓出动画
