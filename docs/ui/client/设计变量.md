# 设计变量（Design Tokens）

> 所属端：**学生端（微信小程序，uni-app）** ｜ 适用：本目录全部页面稿 + `client/src/**`
> **真源声明**：变量**取值**的唯一真源是**代码** ——
> 颜色 = `client/src/theme/tokens.ts`（`COLOR_MAP` 取值）+ `client/src/theme/generated-colors.css`（变量声明与命名，逐键同步）；
> 非颜色（圆角 / 间距 / 字号 / 字重 / 字距 / 时长 / 缓动 / 高度 / 层级 / 结构尺寸）= `client/src/theme/design-tokens.css`。
> 本文档是**对照表 + 命名与使用约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **一律走 CSS 变量**：页面 / 组件样式内只允许 `var(--xxx)`；**SHALL NOT** 裸写色值或尺寸。
2. **三层结构**：Primitive（原值，内联在 `COLOR_MAP` 里，未单独导出，属已知简化）→ **Semantic（语义，主用层）** → Component（本项目不设，组件直接消费 semantic）。
3. **同值不同语义**允许（如 `--text-body` 与 `--text-tertiary` 同值）；**零消费即删**，不留兼容别名。
4. 组件视觉规格真源 = [公共组件与形态基线.md](./公共组件与形态基线.md)。

## 1 · 颜色（暖橙黄主题）

| 组 | 变量 | 用途 |
|---|---|---|
| 主色族 | `--color-primary` / `--color-primary-fill` / `--color-primary-text` / `--color-primary-bright` / `--color-primary-orange` / `--color-primary-yellow` / `--color-orange-deep` / `--color-on-primary` / `--color-primary-soft` | 主色及其分档（填充底 / 文字 / 图形 / 浅底 / 点击态）。**填充档才可承载白字**；图形档 SHALL NOT 作文字或填充底 |
| 强调 | `--color-accent` / `--color-accent-soft` | 重点标识 |
| 功能色 | `--color-error` / `--color-error-soft` / `--color-warning` / `--color-success` / `--color-info` | 语义状态 |
| 价格 | `--color-price` | 价格文字（= 主色文字档，不另立主色） |
| 文字四档 | `--text-title` / `--text-body` / `--text-tertiary` / `--text-placeholder` / `--text-white` | 对比度均已达标；`--text-placeholder` **仅输入占位** |
| 背景 / 边框 | `--bg-page`（**唯一**页面底） / `--module-bg`（内容块唯一底色） / `--bg-card` / `--bg-input` / `--bg-soft`（按压反馈） / `--bg-placeholder`（图片占位底） / `--border-color` | 页面 SHALL NOT 私有底色 |
| 阴影 / 遮罩 | `--module-shadow`（内容块唯一阴影，**禁黑色阴影**） / `--shadow-card` / `--shadow-modal` / `--shadow-bar` / `--shadow-float` / `--overlay-scrim` / `--overlay-panel-bg` | — |

> **三态评分控件不新增语义色** —— 选中态复用 `--color-primary` 实底 + `--color-on-primary` 字（口径见[公共组件与形态基线.md](./公共组件与形态基线.md) §2.2 `ReactionPicker`）。

### 1.1 本设计已定稿的色值

> 本节**只登记已拍板的少数关键色值**；其余取值一律以代码真源为准（见文首「真源声明」）。

| 变量 | 定稿值 | 用途 |
|---|---|---|
| `--bg-page` | **`#FFFDFE`** | 🔴 **全站统一页面底色** —— 三个 tab 页共用同一底色，页面底唯一承载处见[基线](./公共组件与形态基线.md) §1.1 |

> 🔴 **原生平台配置必须字面 hex**：`pages.json` 的 `window` / `tabBar` 配色**不接受 `var()`**（`uni` 原样写入 `app.json`，微信校验要求 hexColor）—— 窗口底 / TabBar 底 = `#FFFDFE`；TabBar 选中 = `#B4531A`、未选中 = `#7F6A55`（取值同本表 §1）。原生配置是平台要求，不构成 CSS 承载处的第二份。

## 2 · 非颜色

### 2.1 圆角（`--radius-*`，rpx）

| 变量 | 值 | 适用 |
|---|---|---|
| `--radius-xs` | `8` | 微件（焦点环等） |
| `--radius-btn` | `32` | 按钮 / 控件行 |
| `--radius-card` | `40` | **模块表面**（面板主档） |
| `--radius-modal` | `48` | 弹层顶部 |
| `--radius-pill` | `999` | **可点**胶囊（形状语义，不随档位调整） |
| `--radius-circle` | `50%` | 正圆（形状语义） |

> 值域遵循「块越大越圆」；**不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角）。**SHALL NOT 裸写圆角**。

### 2.2 间距（`--spacing-*`，4pt 栅格，rpx）

| 档 | `3xs` | `2xs` | `xs` | `sm` | `md` | `lg` | `xl` | `2xl` |
|---|---|---|---|---|---|---|---|---|
| 值 | `2` | `4` | `8` | `16` | `24` | `32` | `48` | `64` |

**页面级 gutter**：`--page-gutter` = `32rpx`（内容到屏幕左右缘的唯一档位）。`--spacing-*` 只表达「元素之间留多少」，二者不可混用。

### 2.3 字号 / 字重 / 字距（rpx）

| 变量 | display | tiny | small | body | subtitle | h3 | h2 | title |
|---|---|---|---|---|---|---|---|---|
| 值 | `56` | `20` | `24` | `28` | `32` | `36` | `40` | `44` |

- **字重**：`regular` 400 ｜ `medium` 500 ｜ `semibold` 600 ｜ `bold` 700 ｜ `heavy` 800
- **正文级字号下限 12px（`24rpx`）**

### 2.4 动效 / 层级 / 高度 / 结构尺寸

| 类别 | 变量 | 值 |
|---|---|---|
| 动效 | `--duration-fast` / `--duration-base` / `--duration-slow` / `--ease-out` | `120` / `200` / `300` ms ｜ `cubic-bezier(0.22, 0.61, 0.36, 1)` |
| 层级 | `--z-tabbar` / `--z-sheet` / `--z-actionsheet` | `100` / `2000` / `4000` |
| 高度 | `--tabbar-height` / `--tabbar-gap` / `--tap-target-size` / `--reaction-item-min-width` | `88rpx` / `24rpx` / `88rpx` / `120rpx` |
| 结构尺寸 | `--poster-peek` / `--dish-photo-size` / `--record-photo-size` / `--record-card-width` / `--empty-action-size` | `48` / `360` / `240` / `420` / `152` rpx |

> 海报 **3:4** 比例不设 token —— 由卡内 `aspect-ratio: 3 / 4` 表达。

## 3 · 红线（改 `client/` 前必查）

1. 页面 / 组件样式 **SHALL NOT** 裸 hex / `rgb()` / `rgba()`（字体栈、`currentColor`、`transparent`、`inherit` 除外）。
2. **SHALL NOT** 裸写圆角、间距、字号、字重、时长、缓动、层级数值 —— 一律走对应 `var(--xxx)`。
3. **SHALL NOT** 裸写 `transform: scale()` 作按压反馈 —— 统一「透明度微降 / 浅底变化」语言。
4. **SHALL NOT** 页面私有底色 —— 一律 `--bg-page`。
5. **改视觉值只改 token**：动 token 即全站生效；新增变量须先入代码真源，再同步本表。
6. 提交前自检（与 [`func/client/README.md`](../../func/client/README.md) 的「UI 实现红线」一致）：grep 裸 scale / 裸 hex / 裸数值 / `@click`。
