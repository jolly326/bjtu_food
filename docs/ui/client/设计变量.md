# 设计变量（Design Tokens）

> 所属端：**学生端（微信小程序，uni-app）** ｜ 适用：本目录全部页面稿 + `client/src/**`
> **真源声明**：变量**取值**的唯一真源是**代码** ——
> 颜色 = `client/src/theme/tokens.ts`（`COLOR_MAP` 取值，单组奶米纸色）+ `client/src/theme/generated-colors.css`（变量声明与命名，逐键同步）；
> 非颜色（圆角 / 间距 / 字号 / 字重 / 字距 / 时长 / 缓动 / 高度 / 层级 / 结构尺寸）= `client/src/theme/design-tokens.css`。
> 本文档是**对照表 + 命名与使用约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **一律走 CSS 变量**：页面 / 组件样式内只允许 `var(--xxx)`；**SHALL NOT** 裸写色值或尺寸。
2. **三层结构**：Primitive（原值，内联在 `COLOR_MAP` 里）→ **Semantic（语义，主用层）** → Component（本项目不设，组件直接消费 semantic）。
3. **同值不同语义**允许（不同语义可共用同一取值）；**零消费即删**，不留兼容别名。唯一例外：`--color-primary` 是**品牌保留 token**（基线 §0 明确保留给非 sheet 品牌 CTA），不按零消费删除。
4. 组件视觉规格真源 = [公共组件与形态基线.md](./公共组件与形态基线.md)。
5. **单主题（奶米纸色）**：语义色只声明一组；页面 / 组件只消费语义键，不挂 `data-theme`、不消费深色变量。

## 1 · 颜色（动森风移动端 · 奶米纸色 + 深棕 + 浅杏）

| 组 | 变量 | 用途 |
|---|---|---|
| 主色族 | `--color-primary` | 暖橙品牌 CTA（品牌保留 token，见 §0.3） |
| 文字层级 | `--text-title` / `--text-body` / `--text-disabled` | 深棕主文案；可读浅棕辅助；`--text-disabled` 置灰（暖灰棕） |
| 背景 / 边框 | `--bg-page`（奶米纸底）/ `--bg-card`（奶白卡面）/ `--bg-placeholder`（图片占位底）/ `--border-color` | 页面 SHALL NOT 私有底色；卡片走奶白 + 细描边 |
| 遮罩 | `--overlay-scrim` / `--overlay-panel-bg` | 弹层遮罩；sheet / 气泡奶米底 |
| Sheet 组件 | `--sheet-divider` | 短横线虚线 |


> **层级表达**：卡片 / 弹层可加 `--shadow-soft`（向下）/ `--shadow-up`（向上）极弱弥散阴影营造轻微悬浮；前后关系主要靠底色（胶囊）、描边、圆角区分。

## 2 · 非颜色

### 2.1 圆角（`--radius-*`，rpx）

| 变量 | 值 | 适用 |
|---|---|---|
| `--radius-card` | `44` | **全站卡片统一大圆角**（磁贴 / 面板） |
| `--radius-modal` | `56` | 弹层顶部 |
| `--radius-pill` | `999` | **可点**胶囊（形状语义，不随档位调整） |
| `--border-width` | `2` | 常规描边线宽（图片 / 卡片 / 弹层顶边统一，图片 border 加粗集中控制） |

> Q 版动森的圆角**整体比常规设计大一档**：块越大越圆，边缘一律圆润厚实。

> 值域遵循「块越大越圆」；**不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角）。**SHALL NOT 裸写圆角**。

### 2.2 间距（`--spacing-*`，4pt 栅格，rpx）

| 档 | `2xs` | `xs` | `sm` | `md` | `lg` | `xl` | `2xl` |
|---|---|---|---|---|---|---|---|
| 值 | `4` | `8` | `16` | `24` | `32` | `40` | `48` |

**页面级 gutter**：`--page-gutter` = `32rpx`（内容到屏幕左右缘的唯一档位，菜品首页共用；左侧基准线以此为齐）。`--spacing-*` 只表达「元素之间留多少」，二者不可混用。

### 2.3 字号 / 字重 / 字体族（rpx）

| 变量 | display | title | h2 | h3 | body | subtitle | caption |
|---|---|---|---|---|---|---|---|
| 值 | `48` | `40` | `36` | `32` | `28` | `26` | `24` |

- **字重（两档）**：`regular` 400 ｜ `semibold` 600 —— 🔴 不设 `bold` / `heavy`（层级靠字号与颜色，不靠加粗）
- **正文级字号下限 12px（`24rpx`）**
- **字体族**：`--font-sans: 'Yuanti SC', 'YouYuan', 'PingFang SC', 'HarmonyOS Sans SC', 'Noto Sans SC', system-ui, sans-serif` —— **优先系统圆体**（Yuanti SC / 幼圆，得手写松弛感），未命中回退苹方（本身圆润）；🔴 小程序**不引入自定义字体文件**（体积与加载成本）。
- 🔴 **真机字体可用性差异（已知限制）**：iOS 命中 `-apple-system` / `PingFang SC`（圆润体观感最佳）；**Android** 命中系统默认 sans，圆润程度由 ROM 决定。若必须跨端一致的圆体，唯一解法是 `wx.loadFontFace` 引入远程圆体字体（需字体文件 + CDN 域名白名单 + 版权合规），届时把 family 名加进本栈首位。

### 2.4 动效 / 层级 / 高度 / 结构尺寸

| 类别 | 变量 | 值 |
|---|---|---|
| 动效 | `--duration-fast` / `--duration-base` / `--duration-slow` / `--duration-spin` | `140` / `240` / `420` / `2000` ms |
| 缓动 | `--ease-out` ｜ **`--ease-bounce`（Q 弹）** | `cubic-bezier(0.22, 0.61, 0.36, 1)` ｜ **`cubic-bezier(0.34, 1.56, 0.64, 1)`** |
| 加载 | `--duration-spin`(2000ms) + 图标 `loading` **56rpx**（`muted`，不上主题色） | 慢速匀速旋转、**无外围圆环**（仅图标本体转）；规格：图标 56 + `--font-h3` 文案 |
| 层级 | `--z-sheet` | `2000`（弹层） |
| 层级 | `--z-dock` | `10`（悬浮 dock：高于内容、低于弹层） |
| 高度 | `--tap-target-size` | `96rpx`（可点元素命中区下限） |
| 高度 | `--control-height` | `96rpx`（主可点控件竖直高度：搜索输入 / 搜索按钮 / 反馈与空态胶囊按钮） |
| 高度 | `--control-height-sm` | `64rpx`（行内小胶囊：展开卡「收起」一类；命中区经 `::after` 纵向补至 `--tap-target-size`） |
| 高度 | `--header-height` | `88rpx`（页头内容区高兜底；实际 = 胶囊行高，见[基线](./公共组件与形态基线.md) §1.1） |
| 高度 | `--dock-reserve` | `156rpx`（= 胶囊外高 `108rpx`〔控件 `96` + 上下内距 `4×2` + 描边 `2×2`〕+ 与底缘间距 `16rpx` + 末行呼吸 `32rpx`）：滚动内容让出的底部悬浮 dock 净空；安全区由消费处叠加 `env(safe-area-inset-bottom)`，单值落盘以免嵌套 `calc` 在端上失效 |

> 🔴 **`--ease-bounce` 是 Q 版动森的核心动效**：弹窗升起、磁贴点按用带过冲的弹性缓动；
> 其余（显隐 / 过渡）走 `--ease-out`。`prefers-reduced-motion: reduce` 下**一律降级为即时**。

## 3 · 红线（改 `client/` 前必查）

1. 页面 / 组件样式 **SHALL NOT** 裸 hex / `rgb()` / `rgba()`（字体栈、`currentColor`、`transparent`、`inherit` 除外）。
2. **SHALL NOT** 裸写圆角、间距、字号、字重、时长、缓动、层级数值 —— 一律走对应 `var(--xxx)`。
3. **SHALL NOT** 裸写 `transform: scale()` 作按压反馈 —— 统一「透明度微降 / 浅底变化」语言；唯一例外是页面可点件（如搜索框）的 `scale(.96)` 按压回弹（见基线 §2.2）。
4. **SHALL NOT** 页面私有底色 —— 一律 `--bg-page`（原生配置除外，见 §1.1）。
5. **改视觉值只改 token**：动 token 即全站生效；新增变量须先入代码真源，再同步本表。
6. 提交前自检（与 [`func/client/README.md`](../../func/client/约定与红线.md) 的「UI 实现红线」一致）：grep 裸 scale / 裸 hex / 裸数值 / `@click`。
