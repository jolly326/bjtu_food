# 设计变量（Design Tokens）

> 所属端：**学生端（微信小程序，uni-app）** ｜ 适用：本目录全部页面稿 + `client/src/**`
> **真源声明**：变量**取值**的唯一真源是**代码** ——
> 颜色 = `client/src/theme/tokens.ts`（`COLOR_MAP` 取值，分浅色 / 深色两组）+ `client/src/theme/generated-colors.css`（变量声明与命名，逐键同步）；
> 非颜色（圆角 / 间距 / 字号 / 字重 / 字距 / 时长 / 缓动 / 高度 / 层级 / 结构尺寸）= `client/src/theme/design-tokens.css`。
> 本文档是**对照表 + 命名与使用约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **一律走 CSS 变量**：页面 / 组件样式内只允许 `var(--xxx)`；**SHALL NOT** 裸写色值或尺寸。
2. **三层结构**：Primitive（原值，内联在 `COLOR_MAP` 里）→ **Semantic（语义，主用层）** → Component（本项目不设，组件直接消费 semantic）。
3. **同值不同语义**允许（不同语义可共用同一取值）；**零消费即删**，不留兼容别名。
4. 组件视觉规格真源 = [公共组件与形态基线.md](./公共组件与形态基线.md)。
5. **双主题**：语义色分浅色 / 深色两组同键声明（深色值见 §1.2）；页面 / 组件只消费语义键，**SHALL NOT** 私写主题分支或深色值。

## 1 · 颜色（暖橙黄主题 / Julienne）

| 组 | 变量 | 用途 |
|---|---|---|
| 主色族 | `--color-primary` / `--color-primary-text` / `--color-brown-deep` / `--color-primary-soft` | 主色及其分档（主色文字 / 未选中项深棕弱色 / 选中项浅橙填充） |
| 文字层级 | `--text-title` / `--text-body` / `--text-tertiary` / `--text-secondary` / `--text-decor` / `--text-placeholder` | 对比度按层级设定（正文深炭灰；`--text-secondary` 弱化辅助行；`--text-decor` 装饰水印；`--text-placeholder` **仅输入占位**） |
| 背景 / 边框 | `--bg-page`（页面底 / 纸片卡面填充） / `--bg-placeholder`（图片占位底） / `--border-color` / `--border-bold` | 页面 SHALL NOT 私有底色 |
| 阴影 / 遮罩 | `--shadow-card-stack`（卡片柔和浅阴影 `0 8rpx 24rpx rgba(0,0,0,.06)`：海报卡 / 美味页纸片卡 / 记忆卡） / `--shadow-modal`（弹层阴影） / `--shadow-inset`（**内阴影**：纸片卡顶部吊孔「打孔下沉」层级） / `--overlay-scrim` / `--overlay-panel-bg` | 🔴 低透明、弥散；**禁高对比纯黑装饰性阴影** |

> **三态评分控件不新增语义色** —— 选中态复用 `--color-primary` 描边 + 主色图标，不新增语义色（口径见[公共组件与形态基线.md](./公共组件与形态基线.md) §2.2 `ReactionPicker`）。

**主题机制**：

| 项 | 口径 |
|---|---|
| 作用域 | 页面根挂 `data-theme="light"｜"dark"`；深色组变量在该作用域下重声明，语义键不变 |
| 默认 | **浅色**（首启无记录时） |
| 持久化 | 切换即写 storage（键 `theme`，值 `light` / `dark`）；App 启动时读取并挂载 |
| 系统跟随 | **不做**（`followSystem`）—— 仅手动切换，首屏底色确定 |
| 原生窗口底 | `pages.json` 窗口 / TabBar 底必须字面 hex（见 §1.1 注），**不随主题切换** —— 冷启动与切换瞬间有短暂暖白底，属已知取舍（见 [`docs/README.md`](../../README.md)） |
| 阴影 | 深色下阴影为「压深」语义（暗底上装饰性暖棕阴影不可见）；禁高对比纯黑装饰性阴影 |
| 图标 | tone 三档深色取值见 [图标资源.md](./图标资源.md) §2，变体按主题分组生成 |

## 2 · 非颜色

### 2.1 圆角（`--radius-*`，rpx）

| 变量 | 值 | 适用 |
|---|---|---|
| `--radius-xs` | `10` | 微件（占位块等） |
| `--radius-btn` | `32` | 按钮 / 控件行 |
| `--radius-card` | `36` | **模块表面**（面板主档） |
| `--radius-card-stack` | `28` | **海报卡圆角**（风物页；与美味卡族同档） |
| `--radius-modal` | `40` | 弹层顶部 |
| `--radius-pill` | `999` | **可点**胶囊（形状语义，不随档位调整） |
| `--radius-circle` | `50%` | 正圆（形状语义） |

> 值域遵循「块越大越圆」；**不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角）。**SHALL NOT 裸写圆角**。

### 2.2 间距（`--spacing-*`，4pt 栅格，rpx）

| 档 | `3xs` | `2xs` | `xs` | `sm` | `md` | `lg` | `xl` | `2xl` |
|---|---|---|---|---|---|---|---|---|
| 值 | `2` | `4` | `8` | `16` | `24` | `32` | `40` | `48` |

**页面级 gutter**：`--page-gutter` = `32rpx`（内容到屏幕左右缘的唯一档位，风物 / 美味 / 记忆共用；各模块左侧基准线均以此为齐）。`--spacing-*` 只表达「元素之间留多少」，二者不可混用。

### 2.3 字号 / 字重 / 字体族（rpx）

| 变量 | hero | display | title | h2 | h3 | body | subtitle | small |
|---|---|---|---|---|---|---|---|---|
| 值 | `64` | `48` | `40` | `36` | `32` | `26` | `24` | `22` |

- **字重**：`regular` 400 ｜ `medium` 500 ｜ `semibold` 600 ｜ `bold` 700 ｜ `heavy` 800
- **正文级字号下限 12px（`24rpx`）**
- **字体族**：`--font-serif: 'Noto Serif SC', 'Source Han Serif SC', serif` —— 标题（菜名）用**衬线**，正文 / 按钮用 `--font-sans`（系统无衬线）；🔴 小程序**不引入自定义字体文件**（体积与加载成本），只用系统衬线族。

### 2.4 动效 / 层级 / 高度 / 结构尺寸

| 类别 | 变量 | 值 |
|---|---|---|
| 动效 | `--duration-fast` / `--duration-base` / `--duration-slow` / `--ease-out` | `120` / `200` / `360` ms ｜ `cubic-bezier(0.22, 0.61, 0.36, 1)` |
| 层级 | `--z-tabbar` / `--z-sheet` | `100` / `2000` |
| 高度 | `--tabbar-height` / `--tabbar-gap` / `--tap-target-size` | `116rpx` / `20rpx` / `88rpx` |
| 结构尺寸 | `--dish-photo-size` / `--record-photo-size` / `--record-card-width` / `--record-card-height` / `--flowend-icon-box` / `--memory-motif-size` / `--month-item-width` / `--header-title-inset` / `--hero-box-height` | `420` / `390` / `600` / `750` / `120` / `280` / `220` / `100` / `176` rpx |
| 美味页卡片族 | `--dish-card-radius` / `--dish-card-pad-y` / `--dish-name-size` / `--dish-decor-letter` / `--want-btn-width` / `--want-btn-border` / `--want-btn-radius` / `--want-btn-font` | `28` / `40` / `56` / `240` / `320` / `2` / `20` / `30` rpx |

> 海报 **3:4** 比例不设 token —— 由卡内 `aspect-ratio: 3 / 4` 表达。

## 3 · 红线（改 `client/` 前必查）

1. 页面 / 组件样式 **SHALL NOT** 裸 hex / `rgb()` / `rgba()`（字体栈、`currentColor`、`transparent`、`inherit` 除外）。
2. **SHALL NOT** 裸写圆角、间距、字号、字重、时长、缓动、层级数值 —— 一律走对应 `var(--xxx)`。
3. **SHALL NOT** 裸写 `transform: scale()` 作按压反馈 —— 统一「透明度微降 / 浅底变化」语言。
4. **SHALL NOT** 页面私有底色 —— 一律 `--bg-page`（原生配置除外，见 §1.1）。
5. **改视觉值只改 token**：动 token 即全站生效；新增变量须先入代码真源，再同步本表。
6. 提交前自检（与 [`func/client/README.md`](../../func/client/README.md) 的「UI 实现红线」一致）：grep 裸 scale / 裸 hex / 裸数值 / `@click`。
