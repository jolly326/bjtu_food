# 设计变量（Design Tokens）

> 所属端：**学生端（微信小程序，uni-app）** ｜ 适用：本目录全部页面稿 + `client/src/**`
> **真源声明**：变量**取值**的唯一真源是**代码** ——
> 颜色 = `client/src/theme/tokens.ts`（`COLOR_MAP` / `CSS_VARS`）→ 产物 `client/src/theme/generated-colors.css`；
> 非颜色（圆角 / 间距 / 字号 / 字重 / 字距 / 时长 / 缓动 / 高度 / 层级 / 结构尺寸）= `client/src/theme/design-tokens.css`。
> 本文档是**对照表 + 命名与使用约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **一律走 CSS 变量**：页面 / 组件样式内只允许 `var(--xxx)`；**SHALL NOT** 裸写色值或尺寸。
2. **三层结构**：Primitive（原值，内联在 `COLOR_MAP` 里，未单独导出，属已知简化）→ **Semantic（语义，主用层）** → Component（本项目不设，组件直接消费 semantic）。
3. **同值不同语义**允许（如 `--text-primary` 与 `--text-title` 同值）；**零消费即删**，不留兼容别名。
4. 组件视觉规格真源 = [公共组件与形态基线.md](./公共组件与形态基线.md)。

## 1 · 颜色（暖橙黄主题）

| 组 | 变量 | 用途 |

| 强调 | `--color-accent` / `--color-accent-soft` | 重点标识 |
| 功能色 | `--color-error` / `--color-error-soft` / `--color-warning` / `--color-success` / `--color-info` | 语义状态 |
| 价格 | `--color-price` | 价格文字（= 主色文字档，不另立主色） |
| 文字四档 | `--text-primary`(=`--text-title`) / `--text-body`(=`--text-secondary`) / `--text-subtitle`(=`--text-tertiary`) / `--text-placeholder` / `--text-white` | 对比度均已达标；`--text-placeholder` **仅输入占位** |

## 2 · 非颜色

### 2.1 圆角（`--radius-*`，rpx）

| 变量 | 值 | 适用 |
|---|---|---|
| `--radius-none` | `0` | 形状重置 |
| `--radius-xs` | `24` | 微件（焦点环等） |
| `--radius-btn` | `32` | 按钮 / 控件行 |
| `--radius-icon` | `32` | 图像 / 图标容器（与 btn 同值、语义不同） |
| `--radius-card` | `40` | **模块表面**（面板主档） |
| `--radius-modal` | `56` | 弹层顶部 |
| `--radius-pill` | `999` | **可点**胶囊（形状语义，不随档位调整） |
| `--radius-circle` | `50%` | 正圆（形状语义） |

> 值域遵循「块越大越圆」；**不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角）。**SHALL NOT 裸写圆角**。

### 2.2 间距（`--spacing-*`，4pt 栅格，rpx）

| 档 | `3xs` | `2xs` | `xs` | `sm` | `md` | `lg` | `xl` | `2xl` |
|---|---|---|---|---|---|---|---|---|
| 值 | `2` | `4` | `8` | `16` | `24` | `32` | `48` | `64` |

**页面级 gutter**：`--page-gutter` = `32rpx`（内容到屏幕左右缘的唯一档位）。`--spacing-*` 只表达「元素之间留多少」，二者不可混用。

### 2.3 字号 / 字重 / 字距（rpx）

| 变量 | tiny | aux | small | body | caption | subtitle | h3 | h2 | title |
|---|---|---|---|---|---|---|---|---|---|
| 值 | `20` | `22` | `24` | `28` | `30` | `32` | `36` | `40` | `44` |

- **字重**：`regular` 400 ｜ `medium` 500 ｜ `semibold` 600 ｜ `bold` 700 ｜ `heavy` 800
- **字距**：`--tracking-h2` −0.02em ｜ `--tracking-h3` −0.01em（仅标题收紧）
- **正文级字号下限 12px（`24rpx`）**

### 2.4 动效 / 层级 / 高度 / 结构尺寸

| 类别 | 变量 | 值 |
|---|---|---|
| 动效 | `--duration-fast` / `--duration-base` / `--duration-slow` / `--ease-out` | `120` / `200` / `300` ms ｜ `cubic-bezier(0.23, 1, 0.32, 1)` |
| 层级 | `--z-page-bg` / `--z-action-bar` / `--z-tabbar` / `--z-header` / `--z-sheet` / `--z-actionsheet` | `-1` / `50` / `100` / `100` / `2000` / `4000` |
| 高度 | `--tabbar-height` / `--action-bar-height` | `100` / `120` rpx |
| 结构尺寸 | `--tap-target-size` / `--strip-height` / `--chip-size` | `88` / `6` / `96` rpx |

> **已无消费方、随代码改造一并移除**：`--search-bar-height`（无搜索）、`--action-bar-height`（无表单页 / 固定操作栏）、`--z-page-bg` 与 `--page-wash`（不引入壁纸层与纱层，见[基线](./公共组件与形态基线.md) §2.3）。

## 3 · 红线（改 `client/` 前必查）

1. 页面 / 组件样式 **SHALL NOT** 裸 hex / `rgb()` / `rgba()`（字体栈、`currentColor`、`transparent`、`inherit` 除外）。
2. **SHALL NOT** 裸写圆角、间距、字号、字重、时长、缓动、层级数值 —— 一律走对应 `var(--xxx)`。
3. **SHALL NOT** 裸写 `transform: scale()` 作按压反馈 —— 统一「透明度微降 / 浅底变化」语言。
4. **SHALL NOT** 页面私有底色 —— 一律 `--bg-page`。
5. **改视觉值只改 token**：动 token 即全站生效；新增变量须先入代码真源，再同步本表。
6. 提交前自检（与 [`func/client/README.md`](../../func/client/README.md) 的「UI 实现红线」一致）：grep 裸 scale / 裸 hex / 裸数值 / `@click`。
