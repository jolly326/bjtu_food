# 设计变量（Design Tokens）

> 所属端：**学生端（微信小程序，uni-app）** ｜ 适用：本目录全部页面稿 + `client/src/**`
> **真源声明**：变量**取值**的唯一真源是**代码** ——
> 颜色 = `client/src/theme/tokens.ts`（`COLOR_MAP` 取值，分浅色 / 深色两组）+ `client/src/theme/generated-colors.css`（变量声明与命名，逐键同步）；
> 非颜色（圆角 / 间距 / 字号 / 字重 / 字距 / 时长 / 缓动 / 高度 / 层级 / 结构尺寸）= `client/src/theme/design-tokens.css`。
> 本文档是**对照表 + 命名与使用约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0 · 使用总则

1. **一律走 CSS 变量**：页面 / 组件样式内只允许 `var(--xxx)`；**SHALL NOT** 裸写色值或尺寸。
2. **三层结构**：Primitive（原值，内联在 `COLOR_MAP` 里）→ **Semantic（语义，主用层）** → Component（本项目不设，组件直接消费 semantic）。
3. **同值不同语义**允许（不同语义可共用同一取值）；**零消费即删**，不留兼容别名。唯一例外：`--color-primary` 是**品牌保留 token**（基线 §0 明确保留给非 sheet 品牌 CTA），不按零消费删除。
4. 组件视觉规格真源 = [公共组件与形态基线.md](./公共组件与形态基线.md)。
5. **双主题**：语义色分浅色 / 深色两组同键声明（深色值见 §1.2）；页面 / 组件只消费语义键，**SHALL NOT** 私写主题分支或深色值。

## 1 · 颜色（动森风移动端 · 奶米纸色 + 深棕 + 浅杏）

| 组 | 变量 | 用途 |
|---|---|---|
| 主色族 | `--color-primary` | 暖橙品牌 CTA（品牌保留 token，见 §0.3） |
| 文字层级 | `--text-title` / `--text-body` / `--color-muted` / `--text-disabled` | 深棕主文案；可读浅棕辅助；`--color-muted` 仅箭头 / 装饰；`--text-disabled` 置灰（暖灰棕） |
| 背景 / 边框 | `--bg-page`（奶米纸底）/ `--bg-card`（奶白卡面）/ `--bg-placeholder`（图片占位底）/ `--border-color` / `--border-bold` | 页面 SHALL NOT 私有底色；卡片走奶白 + 细描边 |
| 遮罩 | `--overlay-scrim` / `--overlay-panel-bg` / `--overlay-sheet-scrim` | 弹层遮罩；sheet / 气泡奶米底；确认气泡用低透明度奶色遮罩 |
| Sheet 组件 | `--sheet-pill-bg` / `--sheet-pill-bg-strong` / `--sheet-pill-border` / `--sheet-divider` | 浅杏胶囊底 / 主操作加深的杏色 / 深棕描边 / 短虚线 |

> **层级表达**：全局**无阴影** —— 只靠底色（胶囊）、描边、圆角区分前后关系。
> **点赞控件**：未赞 `heart` 为浅棕空心，已赞 `heart-on` 为浅棕填充；数字用 `--text-title`，不使用主色橙。

### 1.2 深色模式色板（全站第二主题）

> 深色组与浅色组**完全同键、仅换值**；组件不感知主题（只消费语义变量，SHALL NOT 私写主题分支或深色值）。
> 🔴 **深色系采用低饱和夜色**：深灰蓝底 `#2B3A4A`、冷调奶白字、晚霞橙主色 —— 🔴 **不做纯黑**（夜间是低饱和夜色，不是纯黑房间）；
> 两套主题**共用同一套形态语言**（圆角 / 描边宽度 / 动效一致），只换色温与明度；

**主题机制**：

| 项 | 口径 |
|---|---|
| 作用域 | 页面根挂 `data-theme="light"｜"dark"`；深色组变量在该作用域下重声明，语义键不变 |
| 默认 | **浅色**（首启无记录时） |
| 持久化 | storage 键 `theme`（值 `light` / `dark`）；App 启动时读取并挂载 |
| 系统跟随 | **不做**（`followSystem`）—— 首屏底色确定 |
| 原生窗口底 | `pages.json` 窗口底必须字面 hex（见 §1.1 注），**不随主题切换** —— 冷启动与切换瞬间有短暂暖白底，属已知取舍（见 [`docs/README.md`](../../README.md)） |
| 阴影 | 🔴 **全局无阴影** —— 深浅两版都不设阴影层级；前后关系靠底色 / 描边 / 圆角 |
| 图标 | Streamline Plump（Flat）**仅保留图形黑色轮廓**（`fill: none` + `stroke: #000000`，不上色）；`heart` 空心 / `heart-on` 实心区分两态；学生端只打包实际消费键 |

## 2 · 非颜色

### 2.1 圆角（`--radius-*`，rpx）

| 变量 | 值 | 适用 |
|---|---|---|
| `--radius-card` | `44` | **全站卡片统一大圆角**（磁贴 / 面板） |
| `--radius-modal` | `56` | 弹层顶部 |
| `--radius-pill` | `999` | **可点**胶囊（形状语义，不随档位调整） |

> Q 版动森的圆角**整体比常规设计大一档**：块越大越圆，边缘一律圆润厚实。

> 值域遵循「块越大越圆」；**不可点的静态标签一律是纯文字**（无底色 ⇒ 无圆角）。**SHALL NOT 裸写圆角**。

### 2.2 间距（`--spacing-*`，4pt 栅格，rpx）

| 档 | `2xs` | `xs` | `sm` | `md` | `lg` | `xl` | `2xl` |
|---|---|---|---|---|---|---|---|
| 值 | `4` | `8` | `16` | `24` | `32` | `40` | `48` |

**页面级 gutter**：`--page-gutter` = `32rpx`（内容到屏幕左右缘的唯一档位，美食地图页共用；左侧基准线以此为齐）。`--spacing-*` 只表达「元素之间留多少」，二者不可混用。

### 2.3 字号 / 字重 / 字体族（rpx）

| 变量 | title | h2 | h3 | body | subtitle |
|---|---|---|---|---|---|
| 值 | `40` | `36` | `32` | `28` | `26` |

- **字重（两档）**：`regular` 400 ｜ `semibold` 600 —— 🔴 不设 `bold` / `heavy`（层级靠字号与颜色，不靠加粗）
- **正文级字号下限 12px（`24rpx`）**
- **字体族**：`--font-sans: -apple-system, 'PingFang SC', 'HarmonyOS Sans SC', 'Noto Sans SC', system-ui, sans-serif` —— Q 版动森**全站只用系统无衬线圆体圆体**（标题与正文同源）；🔴 小程序**不引入自定义字体文件**（体积与加载成本）。
- 🔴 **真机字体可用性差异（已知限制）**：iOS 命中 `-apple-system` / `PingFang SC`（圆润体观感最佳）；**Android** 命中系统默认 sans，圆润程度由 ROM 决定。若必须跨端一致的圆体，唯一解法是 `wx.loadFontFace` 引入远程圆体字体（需字体文件 + CDN 域名白名单 + 版权合规），届时把 family 名加进本栈首位。

### 2.4 动效 / 层级 / 高度 / 结构尺寸

| 类别 | 变量 | 值 |
|---|---|---|
| 动效 | `--duration-fast` / `--duration-base` / `--duration-slow` / `--duration-spin` | `140` / `240` / `420` / `2000` ms |
| 缓动 | `--ease-out` ｜ **`--ease-bounce`（Q 弹）** | `cubic-bezier(0.22, 0.61, 0.36, 1)` ｜ **`cubic-bezier(0.34, 1.56, 0.64, 1)`** |
| 加载 | `--duration-spin`(2000ms) + 图标 `loading` **56rpx**（`muted`，不上主题色） | 慢速匀速旋转、**无外围圆环**（仅图标本体转）；规格：图标 56 + `--font-h3` 文案 |
| 层级 | `--z-sheet` | `2000` |
| 高度 | `--tap-target-size` | `96rpx` |

> 🔴 **`--ease-bounce` 是 Q 版动森的核心动效**：弹窗升起、点赞反馈、磁贴点按用带过冲的弹性缓动；
> 其余（显隐 / 过渡）走 `--ease-out`。`prefers-reduced-motion: reduce` 下**一律降级为即时**。

## 3 · 红线（改 `client/` 前必查）

1. 页面 / 组件样式 **SHALL NOT** 裸 hex / `rgb()` / `rgba()`（字体栈、`currentColor`、`transparent`、`inherit` 除外）。
2. **SHALL NOT** 裸写圆角、间距、字号、字重、时长、缓动、层级数值 —— 一律走对应 `var(--xxx)`。
3. **SHALL NOT** 裸写 `transform: scale()` 作按压反馈 —— 统一「透明度微降 / 浅底变化」语言；唯一例外是 DishSheet 胶囊按钮的 `scale(.96)` 按压回弹（见基线 §2.2）。
4. **SHALL NOT** 页面私有底色 —— 一律 `--bg-page`（原生配置除外，见 §1.1）。
5. **改视觉值只改 token**：动 token 即全站生效；新增变量须先入代码真源，再同步本表。
6. 提交前自检（与 [`func/client/README.md`](../../func/client/README.md) 的「UI 实现红线」一致）：grep 裸 scale / 裸 hex / 裸数值 / `@click`。
