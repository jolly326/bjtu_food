# 菜品首页

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔓 匿名（openid 静默识别，接口需携带静默 `student_token`）
> 归属功能：[A1 搜索找菜](../../func/client/A-浏览与发现/A1-搜索找菜.md) · [B1 文本反馈](../../func/client/B-轻量反馈/B1-文本反馈.md)

## 1 · 页面结构

| # | 区块 | 内容 |
|---|---|---|
| 1 | **页头** | 安全区 + 轻量 brand strip：「知行食记」+「M 月 D 日 今天吃什么」；无操作按钮 |
| 2 | **结果区** | **1 列竖向滚动结果卡**；无条件是全量在售，有条件是推荐结果 |
| 3 | **底部 HUD** | 悬浮于内容区底部：上层筛选行（结果数 + 约束 chip + `食堂` / `预算` 入口），下层搜索胶囊（输入框 + 主色放大镜按钮）；加载中 / 加载失败时不显示 |

🔴 无 TabBar、无全局顶栏；仅本页一个轻量页头（品牌 + 日期 + 今天吃什么），无操作按钮；页头与结果区之间不设独立结果条。

> **页头与胶囊同一行**：`padding-top = statusBarHeight`；内容区高 = `(胶囊 top − statusBarHeight) × 2 + 胶囊 height`（与胶囊同顶同底），品牌块与右上角胶囊垂直居中对齐；下方直接是结果区。

## 2 · 结果卡

| 项 | 口径 |
|---|---|
| 身份单位 | `dish_location.id`（菜品 × 位置）：每个在售位置渲染一张卡；图 / 描述 / 价格来自菜品本体 |
| 列数 | **1 列**（固定），竖向滚动；卡片满宽（左右 `--page-gutter`），卡间距 `--spacing-md` |
| 卡片形态 | `--bg-card` 纯白 + `--radius-card` + `var(--border-width) --border-color` 细描边；无阴影、无渐变；`overflow: hidden`，封面满宽贴顶由卡片圆角裁切 |
| 封面 | 16:9（`aspectFill`）；空 / 失败走 `ImagePlaceholder`，限宽 `IMAGE.RESULT_THUMB_WIDTH` |
| 信息区布局 | 16:9 封面之下为**左内容 / 右数据**两栏（右栏宽 `--card-side-width`，`align-items: flex-start`）；两栏间距 `--spacing-md`，只用留白分组、无分割线 |
| 左栏 | ① 菜名 `--font-title` / `--text-title`（单行省略）② `description` `--font-body` / `--text-body`（最多 3 行，空值整行不渲染）③「全文」（描述超长时出现）·「反馈这道菜」两枚**文字链**，命中区经 `::after` 补至 `--tap-target-size` |
| 右栏（右对齐） | ① 售价 `--font-h3` / `--brand`（`price = null` 显示「价格待定」）② 食堂名 `--font-caption` / `--text-title`（单行省略）③ `楼层 · 档口` `--font-caption` / `--text-body`（单行省略，缺失显示「暂无」） |
| 位置信息 | 右栏食堂名与楼层 / 档口只做展示，不承载任何交互 |
| 描述 | 常驻左栏，不做省略号截断；超过 3 行时（由 `RESULT.DESCRIPTION_PREVIEW_CHARS` 字数阈值判定）点「全文」在左栏展开完整描述，右栏不动、不跳位；同时只允许一张展开，切换 / 收起 / 发起搜索 / 清空条件均收起 |
| 反馈入口 | 左栏「反馈这道菜」文字链唤起 `FeedbackPanel`；同一道菜的多张卡共用 `dishId` |
| 图位 | 加载中 / 失败 / 为空走 `ImagePlaceholder`；图源取万象缩略图（`IMAGE.RESULT_THUMB_WIDTH`），失败回落原图，再失败占位 |
| 留白 | 信息区内距 `--spacing-sm`、字段间距 `--spacing-xs`；结果区底部 = `--dock-reserve` + `env(safe-area-inset-bottom)` |

> 750rpx 设计宽下单卡宽约 `686rpx`，左栏约 `430rpx` 可容纳 3 行描述；首屏约 1~2 张，30 张结果约 15 屏滚动。

## 3 · 筛选行（HUD 上层）

| 项 | 口径 |
|---|---|
| 定位 | 悬浮 HUD 的上层，位于搜索胶囊之上；左右 `--page-gutter`；无底色、无描边，只占自身 chip 与文字的矩形 |
| 内容 | 条件态左侧「N 处结果」（N = 结果卡数）；右侧依次 = 已生效约束 chip（最多 2 个）· `食堂` / `预算` 文字入口 · 条件态「清空」 |
| 约束 chip | `--brand` 实底 + `--on-brand` 文字 + `--radius-pill`，带 `×` 取消；再点 chip 等价于取消该约束 |
| 候选值 | 点 `食堂` / `预算` ⇒ 该行 chip 区**就地替换**为候选值（纵向换行，`flex-wrap: wrap`）；同类单选、点已选项即取消，选中后收起候选并重新提交；无横滑、无下拉、无弹层、无「更多」 |
| 触达 | 所有 chip 与文字入口命中区 ≥ `--tap-target-size`，视觉高度 `--control-height-sm`，经 `::after` 纵向补足 |
| 取值数据源 | 食堂 = 当前全量集 `canteenName` 去重（只列有菜的食堂）；预算 = 固定档位 |
| 约束来源 | query 解析 · 筛选行候选值点选；两类统一构造新 query 重新提交 |
| `stale` | 输入框文本 ≠ 已提交 query ⇒ 左侧显示 `--text-disabled` 小字「按回车更新」，结果集保持 |
| 退出 | 清空条件回填全量集；`×` 单独撤销一项约束 |

## 4 · 搜索胶囊（HUD 下层）

| 项 | 口径 |
|---|---|
| 定位 | **悬浮**（`position: absolute`）：左右 `--page-gutter`、底部 `--spacing-sm` + `env(safe-area-inset-bottom)`；层级 `--z-dock`；纯白底 + 细描边 + `--radius-pill` |
| 尺寸 | 输入框与圆形搜索按钮同高 `--control-height`，胶囊内距 `--spacing-2xs` |
| 遮挡 | HUD 只占自身矩形，结果区从其下方穿过且仍可点选；末行由 `--dock-reserve` 保证完全露出 |
| 内容 | 搜索输入框（占位「想吃点什么？一句话告诉我」）+ 圆形放大镜按钮（`--brand` 实底 + 反白 `search` 图标）；有输入时输入框右侧显示「清空」 |
| 交互 | 点击聚焦输入；回车 / 点放大镜触发 `POST /dishes/recommend`；聚焦与点按不做变色反馈 |
| 暂不做 | 语音输入、主题切换、随机按钮 |
| 待机 | 无点击 / 输入满 `5s` ⇒ 搜索胶囊 `opacity .7` 淡出；任意点击、聚焦、输入或清空立即恢复 |
| 键盘 | 输入时上推避让，不遮挡输入框 |

## 5 · 状态

| 场景 | 表现 |
|---|---|
| 首屏加载 | 结果区居中 `PageLoading` |
| 加载失败 | 结果区 `RetryBlock`（点此重试） |
| 搜索中 | 胶囊按钮图标转 `loading` 匀速旋转并弱化（`opacity .6`），结果集保持当前内容 |
| 0 命中 + 有硬约束 | 「`食堂名` 暂时没有符合的菜」+「去掉该条件」+「换个说法」 |
| 0 命中 + 无硬约束 | 「没找到符合的菜，换个说法试试」+「看全部菜品」 |
| 全量为 0 | 「还没有菜品上架」，不提供清空按钮 |
| 搜索失败 | Toast「搜索失败，请稍后再试」，结果集保持当前内容（不渲染成「无结果」），可直接再次触发 |
| 结果待更新 | HUD 筛选行左侧显示浅灰小字「按回车更新」，结果集保持 |
| 图片失败 | 卡面图位 `ImagePlaceholder` |
| 描述为空 | 描述行不渲染，左栏保留菜名与操作链 |

## 6 · 动效

| 场景 | 表现 |
|---|---|
| 结果集替换 | 旧列表淡出 / 新列表淡入，`--duration-base` + `--ease-out` |
| 描述全文展开 / 收起 | 淡入，`--duration-base` + `--ease-out` |
| 候选值展开 / 收起 | 淡入，`--duration-base` + `--ease-out` |
| 按压 | `opacity` 微降，禁 `transform: scale` |
| 胶囊待机 | `--duration-base` + `--ease-out` 淡出到 `.7` |
| 搜索中 | `--duration-spin` 匀速旋转 |
| 反馈面板 | 淡入 + 上浮，`--ease-out` |
| 减弱动效 | `prefers-reduced-motion: reduce` 一律即时 |

## 7 · 视觉规格与基线

### 7.1 本页视觉

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page` 纯白 |
| 页头 | 同页面底、无分割线；wordmark `--font-display` / `--text-title`，subtitle `--font-caption` / `--text-body` |
| 筛选行 | 无底色；文字入口 `--text-body`；选中约束 chip `--brand` 实底 + `--on-brand` 文字；候选值纯文字 chip + 细描边 |
| 结果卡 | `--bg-card` 纯白 + `--radius-card` + 细描边；信息区左内容 / 右数据两栏：菜名 `--text-title`、描述 `--text-body`、售价 `--font-h3` / `--brand`、食堂名 `--text-title`、位置 `--text-body` |
| 搜索胶囊 | 纯白 + 细描边 + `--radius-pill`，搜索按钮 `--brand` 实底 |
| 反馈面板 | 唯一浮层（`--z-sheet`），居中卡片式内联面板，纯白 + 细描边，底色由纯色 `--overlay-scrim` 遮罩衬托 |

### 7.2 视觉基线（本页唯一取值口径）

| 类别 | 键 | 值 |
|---|---|---|
| 颜色 | `--bg-page` / `--bg-card` | `#FFFFFF` / `#FFFFFF` |
| 颜色 | `--border-color` | `#E5E7EB` |
| 颜色 | `--brand` | `#EA580C`（单一主色：搜索按钮 / 选中约束 / 售价 / 主操作） |
| 颜色 | `--on-brand` | `#FFFFFF`（主色实底上的文字与反白图标） |
| 颜色 | `--text-title` / `--text-body` / `--text-disabled` | `#1F2937` / `#6B7280` / `#9CA3AF` |
| 颜色 | `--bg-placeholder` / `--overlay-scrim` | `#F3F4F6` / `#F3F4F6`（图片占位底 / 反馈面板纯色遮罩） |
| 字号 | display / title / h3 / body / subtitle / caption | `48` / `40` / `32` / `28` / `26` / `24`（rpx） |
| 字重 | `--weight-regular` | `400` |
| 字体族 | `--font-sans` | 系统圆体栈（`'Yuanti SC'` / `'YouYuan'` / `'PingFang SC'` / … / `sans-serif`） |
| 间距 | `2xs / xs / sm / md / lg / xl / 2xl` | `4 / 8 / 16 / 24 / 32 / 40 / 48`（rpx）；`--page-gutter` = `32` |
| 形状 | `--radius-card` / `--radius-pill` / `--border-width` | `24` / `999` / `2`（rpx） |
| 动效 | `--duration-fast` / `--duration-base` / `--duration-spin` + `--ease-out` | `140` / `240` / `2000` ms + `cubic-bezier(0.22, 0.61, 0.36, 1)` |
| 高度 | `--control-height` / `--control-height-sm` / `--tap-target-size` / `--header-height` / `--dock-reserve` | `96` / `64` / `96` / `88` / `356`（rpx） |
| 结构尺寸 | `--card-side-width` | `200rpx`（结果卡信息区右栏宽） |
| 层级 | `--z-dock` / `--z-sheet` | `10` / `2000` |

> `--dock-reserve` = HUD 常态高度 `212rpx`（筛选行 `96` + 行间距 `8` + 胶囊外高 `108`）+ 候选值展开余量 `96rpx` + 与底缘间距 `16rpx` + 末行呼吸 `32rpx`。

🔴 **单一色相**：底色、卡面、文字、描边全部中性灰阶，唯一彩色是 `--brand`；无半透明叠加、无渐变、无投影、无第二套近似暖色。图标落盘 SVG 的 `fill` 取 `--text-body` 同值单一中性色，主色实底上的图标经 `AppIcon` 的 `inverse` 反白；`pages.json` 的 `window` 配色为平台要求的唯一字面 hex 例外，取 `#FFFFFF`。

🔴 **红线**：页面 / 组件样式一律走 CSS 变量，禁裸 hex / 裸尺寸数值；事件统一 `@tap` 派发业务语义名，按压只用 `opacity` 微降，禁 `transform: scale`。图标尺寸档位 `24 / 28 / 32 / 40 / 48 / 56 / 64 / 96`（rpx），零消费的图标键不登记。

**图标键（7 枚，零消费即删）**：`check` · `chevron` · `help` · `image` · `loading` · `search` · `warning`。署名 `Icons by Streamline (https://streamlinehq.com), licensed under CC BY 4.0.`

**组件**：页面私有 `HomeHeader` · `DishGrid` · `DishResultCard` · `SearchDock`（含筛选行）· `FeedbackPanel`；公共 `AppIcon` · `ImagePlaceholder` · `PageLoading` · `RetryBlock` · `StatusBlock`。对外事件名 `open` / `collapse` / `feedback` / `remove` / `clear` / `relax` / `search` / `retry` / `update:modelValue`。

## 8 · 不做

- 独立结果条 / 条件回显 / 横向滚动取值行 / 常驻筛选面板 / 下拉筛选器；
- 按菜名聚合多位置、起价与数量摘要、位置折叠、收窄标注、卡内位置明细；
- 独立结果页 / 菜品详情路由页 / TabBar / 排序控件；
- 卡内嵌套滚动、第二个遮罩层；
- 语音输入 / 主题切换 / 随机 / 收藏 / 评分 / 分享 / 社区。

## 9 · 规模闸门

| 触发 | 评估动作 |
|---|---|
| 在售位置 > 60 条 | 分页 / 虚拟列表（`GET /dishes` 全量不分页） |
| 出现分享 / 深链 / 收藏 / 评分 / 长 UGC 需求 | 独立详情页 |
| 食堂数 > 8 且高频按食堂找菜 | 独立「按食堂浏览」视图（本页模型不变） |
