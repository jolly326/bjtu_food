# 菜品首页

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔓 匿名（openid 静默识别，接口需携带静默 `student_token`）
> 归属功能：[A1 搜索找菜](../../func/client/A-浏览与发现/A1-搜索找菜.md) · [B1 文本反馈](../../func/client/B-轻量反馈/B1-文本反馈.md)

## 0 · 设计原则

| 原则 | 口径 |
|---|---|
| **上下文保留** | 反馈在卡片或页头内完成，不使用全屏遮罩打断浏览 |
| **信息层级** | 字号与色阶单调递减：菜名 > 售价 > 位置 > 描述 > 操作 |
| **一菜一卡** | 同一道菜的多个在售位置在同一张卡内并列展示，菜品本体信息只呈现一次 |
| **渐进式披露** | 反馈表单默认隐藏，用户点击「反馈」后在卡片信息区下方展开；长描述按需展开 |
| **卡片即容器** | 与菜品相关的操作（反馈、展开描述）均在卡片边界内完成 |
| **反馈表单一致** | 两类反馈入口与展开状态各自独立，**表单主体（标题 / 关闭 / 输入 / 提交 / 间距 / 文案 / 行为）统一由 `FeedbackForm` 承载**，以 `type` 区分；容器形态按宿主适配 |
| **双主题同源** | 浅色 / 深色共用**同一套语义 token 键**，只换取值：页面根容器挂 `theme-dark` 即整页切深色；切换入口在页头标题右侧，全页只有这一处 |

## 1 · 页面结构

| # | 区块 | 内容 |
|---|---|---|
| 1 | **页头** | 安全区 + 轻量 brand strip：左侧 wordmark「知行食记」+ 紧随其后的日月主题切换图标，右侧「问题反馈」胶囊入口；页头高度与微信胶囊行对齐，右侧为原生胶囊预留空位 |
| 2 | **结果区** | 1 列竖向滚动结果卡；每道菜一张卡，卡面并列其全部在售位置 |
| 3 | **底部搜索** | 单行悬浮搜索胶囊（输入框 + 主色放大镜按钮）；无筛选入口、无结果数；加载中 / 加载失败时不显示 |

🔴 无 TabBar、无全局顶栏；页头与结果区之间不设独立结果条。

> 页头与胶囊同一行：`padding-top = statusBarHeight`；内容区高 = `(胶囊 top − statusBarHeight) × 2 + 胶囊 height`；`padding-right` = 视口宽 − 胶囊 `left` + 呼吸间距（均为运行时测量，单位 px）。品牌块与反馈胶囊垂直居中对齐，且不与原生胶囊重叠。

### 1.1 页头内部布局

页头内容区为一行 flex，两端对齐：

| 区域 | 内容 | 宽度规则 |
|---|---|---|
| 左 · 品牌组 | wordmark「知行食记」+ 主题切换图标（间距 `--spacing-xs`） | 组 `flex: 1`；wordmark `flex: 0 1 auto`，`--font-title` / `--text-title`，单行省略 |
| 右 | 「问题反馈」胶囊入口 | `flex-shrink: 0`，`help` 图标 + 文字，卡面底色细描边 + `--radius-pill`，命中区 `--tap-target-size` |

🔴 页头只承载品牌、主题切换与全局反馈入口，不显示日期、结果数或条件回显。

产品反馈入口由 `ProductFeedbackEntry` 经页头 `#feedback` 插槽提供，点击后在页头下缘展开轻量面板（不关联 `dishId`）。

**主题切换入口（`ThemeToggle`）**：

| 项 | 口径 |
|---|---|
| 位置 | wordmark 右缘、紧贴标题；不进入右侧胶囊区 |
| 尺寸 | 图标边长 = `--font-title`（与标题等大），视觉盒同高，不撑高页头行 |
| 图标 | 示出「点一下切到的模式」：浅色下为 `moon`、深色下为 `sun`；命中区经 `::after` 补到 `--tap-target-size` |
| 交互 | `@tap` 切换；按压 `opacity` 微降；切换写入本地存储，再次进入沿用该选择 |
| 初始值 | 无本地选择时跟随系统主题（`getAppBaseInfo().theme`，取不到按浅色）；状态栏前景 / 背景色随主题取反（平台 API 两个参数均必填） |

## 2 · 结果卡

### 2.1 卡片形态

| 项 | 口径 |
|---|---|
| 身份单位 | `dish.id`：一道菜一张卡，图 / 描述 / 价格来自菜品本体；该菜全部在售位置在卡内并列 |
| 列数 | 1 列竖向滚动；卡片满宽（左右 `--page-gutter`），卡间距 `--spacing-md` |
| 形态 | `--bg-card` 卡面 + `--radius-card` + `var(--border-width) --border-color` 细描边；无阴影、无渐变；`overflow: hidden`，封面满宽贴顶由圆角裁切 |
| 封面 | 16:9（`--cover-aspect-pad` + `aspectFill`）；空 / 失败走 `ImagePlaceholder`，限宽 `IMAGE.RESULT_THUMB_WIDTH` |
| 交互 | 卡面不整卡可点；仅「反馈」「展开 / 收起」两个文字入口可点 |

### 2.2 信息区：单列四段

封面之下为单列四段，段间距 `--spacing-xs`：

| 段 | 内容 | 设计意图 |
|---|---|---|
| 段 1 · 头部 | 左菜名 `--font-title` / `--text-title`（单行省略），右售价 `--font-h3` / `--brand`（`price = null` 显示「价格待定」），baseline 对齐 | 主信息 |
| 段 2 · 位置列表 | 每个在售位置一行：`食堂 楼层 档口` 顺序空格连接，省去中间分隔符；`--font-body` / `--text-title`，单行省略；无位置显示「暂无位置」 | 次要信息 |
| 段 3 · 描述 | 常驻，`--font-subtitle` / `--text-body`，最多 2 行；超过 `RESULT.DESCRIPTION_PREVIEW_CHARS` 时提供「展开 / 收起」；展开只撑高描述区，同时只允许一张展开 | 详情信息 |
| 段 4 · 操作栏 | 左侧「反馈」、右侧「展开 / 收起」，两端对齐同一行；无长描述时右侧留空 | 操作入口 |

> 信息层级靠字号与色阶单调递减：菜名 `--font-title` > 售价 `--font-h3` > 位置 `--font-body` / `--text-title` > 描述 `--font-subtitle` / `--text-body` > 操作 `--font-caption` / `--text-body`。位置比描述大且更深，避免关键售卖信息被压到最弱一级。

> 750rpx 设计宽下单卡宽约 `686rpx`，单列宽约 `654rpx`，可容纳 2 行描述；首屏约 1~2 张。

### 2.3 卡片内反馈

- 段 4「反馈」是文字入口（`--font-caption` / `--text-body`，命中区 `--tap-target-size`）；
- 点击后 `FeedbackForm`（`type = 'dish'`）作为卡片的直接子节点**就地展开**，处于正常文档流：不脱离卡片、不位移、不遮盖兄弟卡片、不使用全屏遮罩；
- 表单关联当前 `dishId`；同一时间全页仅一张卡展开反馈，展开另一张时前一张自动收起。

## 3 · 反馈方案：产品 / 菜品隔离

| 类型 | 入口位置 | 表单形态 | 关联 `dishId` | 宿主 |
|---|---|---|---|---|
| 产品反馈 | 页头右侧「问题反馈」胶囊入口 | 页头下缘水平居中的轻量下拉面板（不遮罩、不影响结果卡滚动） | 否 | `ProductFeedbackEntry` |
| 菜品反馈 | 结果卡段 4 文字入口 | 卡片内就地展开 | 是 | `DishResultCard` |

🔴 两类反馈的入口与展开状态各自独立，不共用遮罩层；**表单本体统一为 `FeedbackForm`**，由宿主直接渲染，不额外套面板容器。

### 3.1 `FeedbackForm` 统一规格

| 项 | 口径 |
|---|---|
| 结构 | 容器即表单本体：标题 / 关闭 / 输入 / 提交为同一层子节点，不设额外包裹层 |
| 外观 | 主体规格两类一致；容器按宿主适配：卡片内 `variant=inline` 只留上分隔线并与信息区左右对齐，不形成第二层卡片；页头下缘 `variant=dropdown` 为 `--bg-card` + 细描边 + `--radius-card` 圆角浮层。均无遮罩 |
| 标题行 | 左标题 `产品反馈` / `对这道菜的反馈`（`--font-body` / `--text-title`），右「关闭」（`--font-caption` / `--text-body`，命中区 `--tap-target-size`） |
| 输入 | 多行文本，`FEEDBACK.MAX_LEN` 限长，高度 `--feedback-input-height`；占位文案按 `type` 区分并主动引导报告问题：产品反馈「发现 bug 或信息有误？说说具体遇到了什么」，菜品反馈「这道菜的图片 / 价格 / 位置有误？说说哪里不对」 |
| 提交 | `--bg-card` 底 + `--brand` 细描边与文字的幽灵按钮，文案「提交 / 提交中」；命中 `429` ⇒ 文案切「N 秒后重试」并禁用，倒计时结束自动恢复；全页唯一实底主色留给搜索按钮 |
| 结果 | 成功 Toast「反馈已收到」并关闭；失败 Toast 服务端 `message`，表单保留已填内容 |
| 动效 | 淡入 + 上浮，`--duration-base` + `--ease-out` |

### 3.2 产品反馈（页头下拉面板）

1. 点击页头右侧「问题反馈」胶囊；
2. `FeedbackForm`（`type = 'product'`）在页头下缘**水平居中**展开：左右各留 `--page-gutter`，宽度跟随内容区，不锚定入口右缘；层级 `--z-header` 高于搜索 HUD；
3. 表单不关联 `dishId`；关闭、提交成功均收起面板。

### 3.3 菜品反馈（卡片内展开）

1. 点击段 4「反馈」；
2. `FeedbackForm`（`type = 'dish'`）在四段信息下方展开，撑高当前卡片，左右留白与信息区对齐；
3. 表单关联当前 `dishId`；关闭、提交成功均收起表单。

## 4 · 筛选

不设筛选入口、筛选面板或下拉筛选器；条件只来自一句话文本。

## 5 · 搜索胶囊（HUD 下层）

| 项 | 口径 |
|---|---|
| 定位 | 悬浮 `position: absolute`：左右 `--page-gutter`、底部 `--spacing-sm` + `env(safe-area-inset-bottom)`；层级 `--z-dock`；`--bg-card` 底 + 细描边 + `--radius-pill` |
| 尺寸 | 输入框与圆形搜索按钮同高 `--control-height`，胶囊内距 `--spacing-2xs` |
| 遮挡 | HUD 只占自身矩形，结果区从其下方穿过且仍可点选；末行由 `--dock-reserve` 保证完全露出 |
| 内容 | 输入框（占位「想吃点什么？」）+ 圆形放大镜按钮（`--brand` 实底 + 反白 `search` 图标）；有输入时右侧显示「清空」，命中区 `--tap-target-size` |
| 键盘 | `cursor-spacing` 上推避让，输入时不遮挡输入框 |
| 交互 | 回车 / 点放大镜触发 `POST /dishes/recommend`；按压仅 `opacity` 微降；命中 `429` ⇒ 搜索按钮禁用并按服务端文案倒计时，期间点击提示剩余秒数，结束自动恢复 |
| 待机 | 无点击 / 输入满 `5s` ⇒ 胶囊 `opacity` 降至 `0.7`；任意点击、聚焦、输入或清空立即恢复 |

> 全页唯一实底主色是搜索按钮；反馈提交等次级操作用描边与文字承接主色，避免卡片内出现抢眼色块。

## 6 · 状态

| 场景 | 表现 |
|---|---|
| 首屏加载 | 结果区居中 `PageLoading` |
| 加载失败 | 结果区 `RetryBlock`（点此重试） |
| 搜索中 | 放大镜图标转 `loading` 匀速旋转并弱化，结果集保持当前内容 |
| 0 命中 | 「没找到，换个说法」+「看全部菜品」 |
| 全量为 0 | 「还没有菜品上架」，不提供清空按钮 |
| 搜索失败 | Toast「搜索失败，请重试」，结果集保持当前内容，可直接再次触发 |
| 图片失败 | 卡面图位 `ImagePlaceholder` |
| 描述为空 | 描述行不渲染 |

## 7 · 动效

| 场景 | 表现 |
|---|---|
| 结果集替换 | 新列表淡入，`--duration-base` + `--ease-out` |
| 描述全文展开 | 淡入，`--duration-base` + `--ease-out` |
| 反馈表单展开 | 淡入 + 上浮，`--duration-base` + `--ease-out` |
| 按压 | `opacity` 微降，禁 `transform: scale` |
| 胶囊待机 | `--duration-base` + `--ease-out` |
| 搜索中 | `--duration-spin` 匀速旋转 |
| 主题切换 | 底色 / 文字色 / 描边随 token 取值过渡，`--duration-base` + `--ease-out`；只过渡颜色，不介入透明度与位移 |
| 减弱动效 | `prefers-reduced-motion: reduce` 一律即时，收敛于 `styles/motion.scss` |

### 8.1 本页视觉

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page` |
| 页头 | 同页面底、无分割线；wordmark `--font-title` / `--text-title`，主题切换图标与 wordmark 等高同色，右侧胶囊入口 `--font-caption` / `--text-title`；无日期 |

### 8.3 深色主题取值（同一套语义键）

深色取值挂 `.theme-dark`（页面根容器），键名与浅色一一对应；灰黑基调取色对齐运营端（近黑页面底 / 抬一档卡面 / 中间灰描边），主色提亮一档以保持近黑底上的辨识度。

| 类别 | 键 | 浅色 | 深色 |
|---|---|---|---|
| 颜色 | `--text-title` | `#1F2937` | `#E8EAED` |
| 颜色 | `--text-body` | `#6B7280` | `#9CA2AC` |
| 颜色 | `--text-disabled` | `#9CA3AF` | `#6F747E` |
| 颜色 | `--bg-page` | `#FFFFFF` | `#17181B` |
| 颜色 | `--bg-card` | `#FFFFFF` | `#202228` |
| 颜色 | `--bg-placeholder` | `#F3F4F6` | `#262930` |
| 颜色 | `--border-color` | `#E5E7EB` | `#3A3E46` |
| 颜色 | `--brand` | `#EA580C` | `#F97316` |
| 图标着色 | `--icon-filter` | `none` | `brightness(0) invert(1) brightness(0.62)` |

> `--icon-filter` 由 `AppIcon` 统一消费：落盘 SVG 为中性灰实心，深色下整体反白并压到与深色正文同档亮度；`inverse`（主色实底上的反白）优先级更高，不受主题影响。

🔴 **单一色相**：底色、卡面、文字、描边全部中性灰阶，唯一彩色是 `--brand`；无半透明叠加、无渐变、无投影。双主题共用同一套语义键，浅色取值挂 `page`、深色取值挂 `.theme-dark`，组件不写主题分支。图标落盘 SVG 的 `fill` 取 `--text-body` 同值单一中性色，主题着色走 `--icon-filter`，主色实底上的图标经 `AppIcon` 的 `inverse` 反白；`pages.json` 的 `window` 配色与状态栏前景 / 背景色（`#000000` / `#ffffff`，🔴 平台只认小写六位 hex）为平台 API 要求的字面 hex 例外。

🔴 **红线**：页面 / 组件样式一律走 CSS 变量，禁裸 hex / 裸尺寸数值；2 行描述截断是登记的行数档位。事件统一 `@tap` 派发业务语义名，按压只用 `opacity` 微降，禁 `transform: scale`。图标尺寸档位 `22 / 24 / 28 / 32 / 36 / 40 / 44 / 48 / 64 / 96`（rpx），零消费的图标键不登记。

**图标键（7 枚，零消费即删）**：`help` · `image` · `loading` · `moon` · `search` · `sun` · `warning`。署名 `Icons by Streamline (https://streamlinehq.com), licensed under CC BY 4.0.`

**组件**：页面私有 `HomeHeader` · `ThemeToggle` · `DishGrid` · `DishResultCard` · `SearchDock` · `FeedbackForm` · `ProductFeedbackEntry`；公共 `AppIcon` · `ImagePlaceholder` · `PageLoading` · `RetryBlock` · `StatusBlock`。对外事件名 `update:open` / `open` / `feedback-open` / `clear` / `search` / `retry` / `close` / `press` / `update:modelValue`。

## 9 · 不做

- 全屏遮罩弹窗反馈；
- 两类反馈共用同一入口、同一展开状态或同一遮罩层；
- 独立结果条 / 条件回显 / 横向滚动取值行 / 常驻筛选面板 / 下拉筛选器、页头日期；
