# 菜品首页

> 所属端：**学生端（微信小程序）** ｜ 鉴权：🔓 匿名（openid 静默识别，接口需携带静默 `student_token`）
> 归属功能：[A1 搜索找菜](../../func/client/A-浏览与发现/A1-搜索找菜.md) · [B1 文本反馈](../../func/client/B-轻量反馈/B1-文本反馈.md)

## 1 · 页面结构

| # | 区块 | 内容 |
|---|---|---|
| 1 | **页头** | 安全区 + 轻量 brand strip：「知行食记」+「M 月 D 日 今天吃什么」；无操作按钮 |
| 2 | **上方视口** | **3 列竖向滚动**菜品图标网格（圆角矩形图 + 下方菜名，仿手机首页 app） |
| 3 | **底部 dock** | 仅**搜索框**，悬浮胶囊 HUD：**脱离页面布局流**、绝对定位于内容区底部之上一层（`--z-dock`），网格从其下方穿过；**加载中 / 加载失败时不显示** |
| 4 | **内联展开卡** | 点图标 ⇒ 在网格中插入跨 3 列详情卡（无遮罩），网格其余部分仍可滚动 / 点选 |

🔴 无 TabBar、无全局顶栏；仅本页一个轻量页头（品牌 + 日期），无操作按钮。

> **页头与胶囊同一行**：`padding-top = statusBarHeight`；内容区高 = `(胶囊 top − statusBarHeight) × 2 + 胶囊 height`（即胶囊行高，与胶囊**同顶同底**，取不到胶囊矩形时用 `--header-height` 兜底），品牌块与右上角胶囊垂直居中对齐；下方才是网格。

## 2 · 图标网格

| 项 | 口径 |
|---|---|
| 列数 | **3 列**（固定） |
| 滚动 | **竖向滚动**（不做左右翻页、不做小圆点） |
| 磁贴形态 | 圆角矩形 **1:1** 图片 + 图下**菜名**（`--font-subtitle`，单行省略） |
| 尺寸 | 统一尺寸，不设 2×1 / 1×2 / 2×2 变体 |
| 图位 | 加载中 / 失败 / 为空走 `ImagePlaceholder`；图源按[基线](./公共组件与形态基线.md) §1.9 取万象缩略图 |
| 排布 | 3 列 flex 换行，筛选后自动重排填位 |
| 留白 | 左右 `--page-gutter`、顶部距页头 `--spacing-lg`；底部 = `--dock-reserve`（`156rpx`，含胶囊外高、与底缘间距与末行呼吸）+ `env(safe-area-inset-bottom)`（让出悬浮胶囊占位，末行可完整滚到胶囊之上）；留白写在滚动内容内层（`scroll-view` 自身不设内边距，否则内容会顶到页头） |

## 3 · 底部 dock（搜索）

| 项 | 口径 |
|---|---|
| 定位 | **悬浮**（`position: absolute`，脱离布局流）：左右 `--page-gutter`、底部 `--spacing-sm` + `env(safe-area-inset-bottom)`；层级 `--z-dock`（浮于网格之上、低于弹层）；`--radius-pill` + `--shadow-soft` → 各屏宽下左右边距与底缘间距恒定 |
| 尺寸 | 输入框与圆形搜索按钮同高 `--control-height`（`96rpx`），胶囊内距 `--spacing-2xs` |
| 遮挡 | 胶囊只占自身矩形（不设整条通栏遮罩），网格从其下方穿过且仍可点选；末行由底部净空保证完全露出 |
| 内容 | **搜索输入框**（占位「想吃点什么？一句话告诉我」）+ **圆形放大镜按钮**（`search` 图标 `40rpx`，浅杏底）；有输入时输入框右侧显示「清空」 |
| 暂不做 | 语音输入、主题切换、随机按钮 |
| 交互 | 点击聚焦输入；回车 / 点放大镜触发 `POST /dishes/recommend`；🔴 聚焦与点按**不做变色反馈**（描边恒为 `--border-color`） |
| 待机 | 无点击 / 输入满 `5s` ⇒ 整条胶囊 `opacity .7` 淡出（`--duration-slow` + `--ease-out`）；任意点击、聚焦、输入或清空立即恢复 |
| 键盘 | 输入时上推避让，不遮挡输入框 |

## 4 · 筛选动效

| 阶段 | 表现 |
|---|---|
| 命中 | 留在网格，由 Grid 自动重排填位 |
| 未命中 | 缩放 + 淡出**退场**（`--duration-base` + `--ease-out`） |
| 清空搜索 | 恢复全量网格 |

## 5 · 内联展开卡

| 部件 | 口径 |
|---|---|
| 展开 | 点磁贴 ⇒ 在该磁贴所在行下方插入**跨 3 列**详情卡（整行），磁贴保留为锚点；同时只允许一张展开 |
| 动画 | 卡片 `scale(.96)` + 淡入 → 目标尺寸（`--duration-base` + `--ease-out`）；🔴 无遮罩、无弹窗 |
| 内容 | 菜品图（16:9）· 菜名 · `description` · **售卖点列表** · 「反馈这道菜」胶囊 · 「收起」 |
| 售卖点 | 每项一行：`食堂 · 楼层 · 档口 · ¥价格`；无档口 / 无楼层显示「暂无」；`price = null` 显示「价格待定」 |
| 切换 | 点另一磁贴 ⇒ 旧卡收起、新卡展开；不关闭页面、不回到顶部；展开后把卡片滚入可视区 |
| 收起 | 卡片内「收起」；再点同一磁贴也收起；发起搜索时自动收起 |
| 滚动 | 卡片随网格滚动，不遮挡搜索 dock；长内容由网格滚动承载（卡片内不嵌套滚动） |

## 6 · 视觉规格

| 项 | 取值 |
|---|---|
| 页面底色 | `--bg-page`（`#FFF7E8`） |
| 页头 | `--bg-page` 底、**无分割线描边**（与网格靠留白分组）；wordmark `--font-display` / subtitle `--font-caption`，两行行高均 1.1；内容区高 = 胶囊行高（与胶囊同顶同底，取不到矩形时 `--header-height` 兜底） |
| 顶部安全区 | 页头顶部 = `statusBarHeight`、页头底 = 胶囊底边（系统信息计算），页头含此安全区，网格在页头下方滚动 |
| 磁贴 | 圆角 `--radius-card`；`--border-width` 细描边；图下菜名 `--text-title` |
| dock | 悬浮层（`--z-dock`）：`--bg-card` 底 + `--border-width` 细描边 + `--shadow-soft`；整条圆角 `--radius-pill`；网格滚动时不与胶囊换位、胶囊不随滚动位移 |
| 展开卡 | `--radius-modal` + `--bg-card` 奶白卡面 + `--shadow-soft`；🔴 无遮罩 |


## 7 · 状态

| 场景 | 表现 |
|---|---|
| 首屏加载 | 网格区居中 `PageLoading` |
| 加载失败 | 网格区 `RetryBlock`（点此重试） |
| 搜索中 | dock 按钮图标转 `loading` 匀速旋转并弱化（`opacity .6`），网格保持当前内容 |
| 0 命中 | 网格区空状态「没找到符合的菜，换个说法试试」+「清空搜索」 |
| 搜索失败 | Toast「搜索失败，请稍后再试」，网格保持当前内容（🔴 不渲染成「无结果」），可直接再次触发 |
| 图片失败 | 磁贴图位 `ImagePlaceholder` |

## 8 · 不做

- 左右翻页 / 页码指示器（网格只竖向滚动）；
- 语音输入 / 随机按钮。
