## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | — |
| 2 | **页头** | 页标题 + 当前日期 | 高 `--tap-target-size`；左右 `--page-gutter` |
| 3 | **月份时间线** | 横向可滑；每项 = 年份 + 月份；**选中月放大** | 项间距 `--spacing-lg`(32rpx) |
| 4 | **主体** | 按日期分组的**卡片行**（横向滚动，右露下一张） | 组间距 `--spacing-xl`(48rpx) |
| 5 | 入口 | 非 tab：经「设置」进入的二级页 | 见 [基线](./公共组件与形态基线.md) §2.1 |

**月份时间线**

| 部位 | 口径 |
|---|---|
| 每项 | 纵向两行：年份（`--font-tiny` 20rpx / `--text-tertiary`）+ 月份 |
| **选中月** | `--font-h2`(40rpx) + `--weight-heavy` + `--text-title` |
| 未选月 | `--font-subtitle`(32rpx) + `--weight-regular` + `--text-tertiary` |
| 数据 | **仅有记录的月份**（降序），由页面从 `GET /my/records` 派生 |
| 跨年 | 年份随月份项直接展示（如 `2026 January` 与 `2025 December` 相邻），**不额外分组** |

**日期分组**

| 部位 | 口径 |
|---|---|
| 日期标题 | 如 `04.30` —— `--font-h3`(36rpx) + `--weight-semibold` + `--text-title`；下边距 `--spacing-sm` |
| 卡片行 | **横向滚动**；卡宽 `--record-card-width`(420rpx)；卡间距 `--spacing-md`(24rpx) |

**卡片内容（纵向，居中）**

| 部件 | 口径 |
|---|---|
| 菜名 | `--font-body`(28rpx) + `--weight-medium`；最多 2 行 |
| 圆形菜品图 | 直径 `--record-photo-size`(240rpx)、`--radius-circle` |
| 评价分 | `--font-small`(24rpx) + `--text-tertiary`；`null` → 「暂无评价」 |
| **评分控件** | 三态 `ReactionPicker`（见 [基线](./公共组件与形态基线.md) §2.2）；**已评分 ⇒ 只读展示** |
| **纠错入口** | 弱化文字链「信息有误」——`--font-small` + `--text-tertiary` |

## 2 · 交互

| 项 | 口径 |
|---|---|
| 月份切换 | 点选时间线项即重渲染该月清单（**只切筛选，不重新请求**） |
| 评分 | 点选三态项**即提交**（无二次确认、不可改） |
| 取消品尝 | **仅未评分**的卡片提供取消入口；已评分卡片不提供 |
| 纠错 | 点「信息有误」→ `BaseSheet` 弹层列选项 → **点选即提交**（无文字框、无配图）；提交后无回执 |
| 加载失败 | `RetryBlock` |

## 3 · 视觉规格

| 项 | 取值 |
|---|---|
| 页头标题 | `--font-title`(44rpx) + `--weight-bold` |
| 页头日期 | `--font-small` + `--text-tertiary` |
| 卡片表面 | `--radius-card` + `--module-shadow` + `--bg-card`；卡内距 `--spacing-md` |
| 左右内距 | `--page-gutter` |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **无任何记录** | 整页 `EmptyState`，**只有一句**：「**暂无饮食记录**」—— **无副文案、无按钮、不长句** |
| **待评记录** | `ReactionPicker` 可点；卡片另可取消 |
| **已评记录** | 评分呈**只读选中态**；纠错入口仍在 |
