## 1 · 页面结构（自上而下）

| # | 区块 | 内容 | 关键尺寸 |
|---|---|---|---|
| 1 | 顶部安全区 | 状态栏避让 | — |
| 2 | **页头** | 左：衬线大标题「记忆」；右：当前日期（浅灰小字） | 标题 `--font-display`(48rpx) 衬线；日期 `--font-small`；左右 `--page-gutter` |
| 3 | **年月导航** | 横向可滑：选中 `2026 十月`（深色、字重柔和），未选 `九月`（更低对比、更细） | 见 [基线](./公共组件与形态基线.md) §2.2 `MonthTimeline` |
| 4 | **主体** | **倒序日期分组**：衬线日期标题 + 该日**横向滚动卡片行** | 组间距 `--spacing-2xl`(48rpx)；🔴 无分割线 |
| 5 | 底部 TabBar | 三项 | 见 [基线](./公共组件与形态基线.md) §2.1 |

- **页面底层装饰**：当前月份超大淡数字（`--memory-motif-size` 280rpx、`--text-tertiary`、`opacity .06`），绝对定位右下、`z-index: 0`，**不遮挡任何内容**；内容层 `z-index: 1`。

**日期分组**

| 部位 | 口径 |
|---|---|
| 日期标题 | 如 `10月17日` —— `--font-title`(40rpx) + `--weight-semibold` + `--text-title` + **衬线**；下边距 `--spacing-md` |
| 卡片行 | **横向滚动**；卡宽 `--record-card-width`(480rpx)；卡片左侧留 `--page-gutter`；行末留 `--page-gutter` |
| 分组分隔 | 🔴 **不使用分割线**，只用留白（组间距 `--spacing-2xl`） |

**卡片内容（纵向，居中）**

| 部件 | 口径 |
|---|---|
| **左上评级字母** | 群体风味评级字母（`S`/`A`/`B`/`C`/`D`），大号淡字；见 [基线](./公共组件与形态基线.md) §2.2 `FlavorRating` |
| **右上风味评级** | 两行：`风味评级` + 档位词（臻荐 / 极荐 / 推荐 / 尚可 / 平实 / 待评）；见 [基线](./公共组件与形态基线.md) §2.2 `FlavorRating` |
| 圆形菜品图 | 直径 `--record-photo-size`(220rpx)、`--radius-circle`；底 `--bg-placeholder` |
| 菜名 | **衬线** `--font-h3`(32rpx) + `--weight-semibold` + `--text-title`；最多 2 行 |
| 辅助小字 | 记录时间 `HH:mm` —— `--font-small`(22rpx) + `--text-tertiary`（🔴 `RecordVO` 无食堂 / 价格字段，暂以时间承载） |
| 已品尝标记 | 右下角细线 `check` 图标 `24rpx` + `tone="primary"` |
| **评分控件** | 三态 `ReactionPicker`（**喜欢 / 一般 / 不喜欢**，见 [基线](./公共组件与形态基线.md) §2.2）；**已评分 ⇒ 只读展示** |
| **纠错入口** | 弱化文字链「信息有误」——`--font-small` + `--text-tertiary` |

- **风味评级落位**：占据卡内**首行**（水平两端对齐），与 220rpx 圆形菜品图之间留 `--spacing-xs`；文字区**不侵入**圆图。

**卡片表面**

- **奶白纸片**（`--bg-card-milky`）+ **大圆角**（`--radius-card-lg`）+ `--module-shadow`，🔴 **无实体描边**；卡内距 `--spacing-md`。

## 2 · 交互

| 项 | 口径 |
|---|---|
| 月份切换 | 点选年月导航项即重渲染该月清单（**只切筛选，不重新请求**）；切换时内容平滑淡入 |
| 评分 | 点选**喜欢 / 一般 / 不喜欢**即提交（无二次确认、不可改） |
| 取消品尝 | **仅未评分**的卡片提供取消入口；已评分卡片不提供 |
| 纠错 | 点「信息有误」→ `BaseSheet` 弹层列选项 → **点选即提交**（无文字框、无配图）；提交后无回执 |
| 卡片行 | 横向滑动浏览当日多份餐食，缓动柔和 |
| 加载失败 | `RetryBlock` |

## 4 · 边界与状态

| 场景 | 表现 |
|---|---|
| **加载中** | **骨架屏**：日期标题占位块 + 横向卡片骨架（圆形图位 + 淡占位线），🔴 无旋转 loading |
| **无任何记录** | 年月栏（近三月兜底）下方、整体**略偏上**（底部预留卡片空间）的空态：**线性图标 `book`**（64rpx、`tone="muted"`、低透明度）→ 衬线标题「**暂无美食记忆**」→ 浅灰描述「去美食页标记品尝过的餐食，收藏属于你的校园美食记忆」→ **暖橙描边按钮「去美食页」**（`switchTab` 到美食页）；🔴 不用复杂插画、不用卡片容器 |
| **未评分记录** | `ReactionPicker` 可点；卡片另可取消；群体风味评级照常展示（与个人是否评分无关） |
| **已评记录** | 评分呈**只读选中态**；纠错入口仍在 |
| **群体评级待评** | 该菜评分条数 < 3 ⇒ 左上**不渲染字母**、右上第二行为「待评」 |
