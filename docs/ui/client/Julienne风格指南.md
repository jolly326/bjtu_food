# Julienne UI 指南 — 学生端风格宪法

> 所属端：学生端（微信小程序，uni-app）
> 定位：**「为什么这样设计」与「什么不能做」的唯一出处**；取值以 [设计变量.md](./设计变量.md) 与 [公共组件与形态基线.md](./公共组件与形态基线.md) 为准，本文件不重复数值表。
> 适用：三 tab 全部页面与组件。**新增 / 改动 UI 前先读本文件，再读对应页面稿。**

---

## 0 · 调研来源（事实基础）

| 项 | 内容 |
|---|---|
| 参考产品 | **Julienne: A Smarter Cookbook**（Afternoon Labs，iOS，2025 年 4 月上架，v1.3.x） |
| 产品主张 | 「Discover the joy of cooking」· 「A smarter cookbook」——把 AI 包装成**更聪明的菜谱书**，而非工具 |
| 调性关键词 | confidence（信心）、inspiration（灵感）、joy（乐趣）——**温和、克制、不炫技** |
| 调研样本 | App Store 官方 9 张界面截图（Cookbook 列表 / Discover 首页 / Shopping List 等）+ 商店描述文案 |
| 品牌隐喻 | 名称来自刀法「切丝」，副标是「书」——**厨具 × 书**，直接决定「纸质手账」的视觉方向 |

**一句话**：把界面当成一本**安静的白纸手账**——纯白纸底、深棕墨色、极弱阴影、大留白，所有装饰都收敛到「恰好够用」。

## 1 · 风格内核（六条不可让渡）

| # | 原则 | 正确做法 | 反面 |
|---|---|---|---|
| 1 | **纸感** | **白底 + 极弱阴影 + 微色阶**（画布纯白、卡面 `#FAFAFA`）分层，**不用实线描边** | 明显奶黄卡面、重投影、玻璃拟态、渐变 |
| 2 | **编辑感** | 衬线大字做标题 + 小号无衬线做元信息（标签 / 时长 / 价格），像刊物标题与说明 | 全站无衬线、靠字重堆层级 |
| 3 | **单一重心** | 一屏只有一个视觉主元素（圆形大图 / 海报卡 / 堆叠卡），其余退到灰 | 多个同级强调、彩色块争抢注意力 |
| 4 | **留白排版** | 用间距与底色差分组，**不画分割线** | 分割线切块、边框套边框 |
| 5 | **克制动效** | 缓动 `--ease-out`、位移 ≤ 24rpx、缩放 ≤ 2%、旋转 ≤ 3° | 弹跳、过冲、循环动画、闪烁 |
| 6 | **低饱和暖调** | 暖橙只在「主 CTA 描边 / 选中态 / 高价值信号」出现 | 高饱和色块、纯黑、彩色渐变 |

## 2 · 色彩（Julienne 实测 → 我们的取值）

### 2.1 Julienne 的实际用色（截图取样，仅供对齐语义）

| 角色 | 观感 | 用法 |
|---|---|---|
| 画布 | **白色 / 近白**（干净克制，不是暖米黄） | 全页底色 |
| 卡面 | 白色或**极浅灰白**（与画布区分极弱） | 卡片、列表行；**无实线描边、极弱阴影**，靠留白与阴影浮起 |
| 墨色 | 近黑深棕 | 标题、菜名 |
| 元信息灰 | 暖灰 | 时长、食材数、副标题 |
| 桃色（soft peach） | 低饱和柔桃 | **小面积填充**：分类徽标、"Pro"标、复选框、Clear chip（文字仍是深棕） |
| 深棕（反白 pill） | 近黑棕 | **选中筛选项**：实底 pill + 白字 |
| 强调橙 | 偏亮的暖橙 | Tab 选中图标与文案、少量主操作 |

### 2.2 我们的落地与比例尺

| 层 | 占比 | 取值 |
|---|---|---|
| **纸** | ~90% | `--bg-page` 纯白 `#FFFFFF` + `--bg-card` 极浅灰白 `#FAFAFA`（卡片）+ `--bg-placeholder` 浅米（图片位） |
| **墨** | ~8% | `--text-title` 深棕、`--text-body` 正文、`--text-tertiary` 浅灰 |
| **印** | ~2% | `--color-primary` 暖橙 —— 只用于**描边 / 图标 / 文字**，不做大面积填充 |

### 2.3 硬规则

- 🔴 **暖橙不做填充大底**（不做橙色按钮底、橙色卡片底）；只能做描边 / 图标 / 文字。
- 🔴 **不使用纯黑**：正文最深到 `--text-title`。
- 🔴 **禁高对比阴影**：唯一卡片阴影是 `--shadow-card-stack`（低透明暖棕、弥散）。
- **弱化 = 换 token 档位，不叠加 `opacity`**；仅禁用态可用 `opacity: .5`。

## 3 · 字体与排版

### 3.1 Julienne 的做法

- **所有标题用衬线**（过渡体 serif，气质接近 Canela / Recoleta 一类），**常规字重**，靠**字号**立威，不靠加粗；
- 关键词用**衬线斜体**强调（如「What are we making for *Dinner*?」）；
- 元信息 / 标签 / 按钮用**无衬线**，小、灰、字距略开；
- 行高宽松，标题多行左对齐，不强行居中。

### 3.2 我们的分工（已按项目编辑口径收敛）

| 用途 | 字族 |
|---|---|
| 页面主标题、菜名、日期标记、档位词、**TabBar 标签**、流末尾标题、空态标题 | **衬线** `--font-serif` |
| 价格 / 食堂·档口等**参数型元信息**、按钮文案、弹层选项、引导小字 | **无衬线** `--font-sans` |

### 3.3 字号梯度（封闭标度，禁止自造）

`--font-hero` 64（页头大标题）→ `--font-display` 48（日期标记 / 问候语）→ `--font-title` 40（板块标题 / 流末尾标题）→ `--font-h2` 36 → `--font-h3` 32（卡片菜名）→ `--font-body` 26（正文 / Tab 标签）→ `--font-subtitle` 24（按钮）→ `--font-small` 22（辅助）。

- 🔴 **字重规则**：**衬线标题默认 `regular`**，**卡片主标题（菜名）可用 `medium`（中等偏粗但不厚重）** —— 层级主要由**字号 + 颜色**承担；🔴 **禁 `bold` / heavy**；`semibold` 只留给无衬线状态标签。
- **行高**：标题 1.2–1.3；正文 1.5–1.6；标签 `line-height: 1`。
- **字距**：小号标签 `0.08em`（「风味评级」类）；其余为 0。
- **层级表达顺序**：**尺寸 → 颜色 → 位置**；字重不作为层级手段。

## 4 · 留白与网格

| 规则 | 口径 |
|---|---|
| 页面左右 | 全站唯一档 `--page-gutter`(32rpx)，所有模块左基准线对齐 |
| 间距节奏 | 只用 `--spacing-*`（2/4/8/16/24/32/40/48…，8 的倍数系） |
| 垂直节奏 | 同级区块间 `--spacing-2xl`(48)；元素间 `--spacing-md/lg`；紧密组内 `--spacing-xs`(8) |
| 呼吸优先 | 拿不准时**加大间距**，而不是加装饰（加线 / 加底 / 加图标） |
| 卡内距 | 大幅海报 48/40/48；记忆卡 48/40/40 |

🔴 **禁止**：为「充实」填内容、为「分隔」画线、为「层次」加底色。

## 5 · 形状 / 描边 / 阴影 / 层次

| 元素 | 口径 |
|---|---|
| 圆角 | `--radius-card`(32) 全部卡片 ｜ `--radius-btn`(32) 按钮 / 图标框 ｜ `--radius-xs`(10) 占位块 ｜ `--radius-pill` 胶囊（TabBar 外环 / 去品尝按钮） ｜ `--radius-circle` 圆形图；🔴 全站节奏统一，**不混用直角 / 小圆角 / 大圆角** |
| 描边 | 🔴 **卡片与面板不画实线描边**（轮廓 = 极浅卡底色 + 极弱阴影）；仅**控件**保留 `1rpx` `--border-color` 极浅描边（筛选触发器 / TabBar 外环 / 弹层按钮），不要 2rpx 以上、不要彩色描边 |
| 阴影 | 仅 `--shadow-card-stack`（卡片，双层极弱）、`--shadow-card-back` / `--shadow-card-back-far`（堆叠后方层）、`--shadow-modal`（弹层）；其余一律不加 |
| 留白 | 卡片内距 ≥ `--spacing-xl`(40rpx) 档、左右 ≥ `--page-gutter`(32rpx)；文字 / 图片 / 按钮**不贴卡缘**，模块之间只用留白分组 |
| 层叠 | 纸片堆叠靠**底边错位 + 轻微收窄 + 阴影**；🔴 不用透明淡化、不用模糊 |
| 图片 | 精选主体用**正圆**（记忆卡大图 / 美味卡圆图）；列表缩略可用圆角方 |

## 6 · 图标（细线语汇）

| 项 | 口径 |
|---|---|
| 来源 | Lucide 官方线性图标（`client/src/assets/icons/`），**单一来源**；禁 emoji / 自绘 / 图标字体 |
| 描边 | **`stroke-width: 1.75`**（hairline，贴近 Julienne 的细线）；圆头端点、无填充变体 |
| 色调 | 三档预生成：`default`（墨）/ `primary`（暖橙，仅高价值信号）/ `muted`（浅灰弱化） |
| 尺寸 | 封闭档位表（见基线 §1.8）；同级图标同尺寸 |
| 形态 | 🔴 **无圆形底、无实底填充、无描边外框**；命中区仍须 ≥ 88rpx |
| 语义 | 一图标一含义；同含义跨页复用同一键 |

**图标键选择遵循「物象而非抽象」**（Julienne 用图像 / 餐具 / 书 / 星芒这类具象物）：

| 位置 | 键 | 语汇 |
|---|---|---|
| 风物 tab | `image` | 海报 = 图像 |
| 美味 tab | `dish`（utensils） | 菜品 = 餐具 |
| 记忆 tab | `notebook` | 记忆 = 手账 |
| 流末尾 · 随机首选 | `sparkles` | 惊喜 / 精选 = 星芒（Julienne 的 AI 语汇） |

## 7 · 组件气质

| 组件 | 该有的样子 | 不该有的样子 |
|---|---|---|
| **TabBar** | 全宽透明容器 + 单外环胶囊 + 选中项浅橙内底，图标与衬线标签视觉配平 | 沉底深色菜单、重阴影、全圆实底 |
| **卡片** | 极浅灰白卡面 `#FAFAFA` + 大圆角 + 双层极弱阴影，**无实线描边** | 明显奶黄卡面、重投影、渐变、多重描边 |
| **按钮** | 描边式、小圆角、文案居中、无图标（主 CTA 细橙描边 + 暖白底） | 实底填充、全圆、双图标 |
| **空态** | 细线图标 + 衬线标题 + 浅灰引导 + 一枚描边按钮；结束态直接落在页面背景（不是卡片） | 插画、彩色块、错误红 |
| **弹层** | 底部 sheet、`--radius-modal`、暖白面板、选项一行一条 | 居中对话框、红色警示 |

## 8 · 动效

| 项 | 口径 |
|---|---|
| 时长 | `--duration-fast`(160) / `--duration-base`(220) / `--duration-slow`(360) |
| 缓动 | `--ease-out`（进入 / 位移）/ `--ease-in-out`（往返）；🔴 不用 spring 过冲 |
| 允许 | 位移、淡入、等宽缩放（≤2%）、旋转（≤3°）、高度过渡 |
| 禁止 | 弹跳、闪烁、循环动画（loading 用骨架块，不用旋转环）、视差 |

## 9 · 与 Julienne 的**有意差异**（须知晓，勿"纠正"）

| 维度 | Julienne 实际做法 | 我们的落地 | 说明 |
|---|---|---|---|
| 标题字重 | 标题中等偏粗但不厚重 | **衬线默认 `regular`，卡片主标题 `medium`** | 禁 `bold` / heavy，靠字号与颜色立层级 |
| 画布色 | 白色 / 近白 | 纯白 `#FFFFFF` | 与截图一致：**不做奶米黄底** |
| 卡面与画布 | 卡片白色或极浅灰白，区分很弱 | 卡面 `#FAFAFA`，**无实线描边** | 层次由极弱阴影 + 留白承担 |
| Tab 容器 | 裸图标 + 小标签，无容器 | 圆角矩形胶囊容器 + 选中浅橙底 | 保留既定容器形态；选中态**只换色不加粗** |
| 筛选选中态 | 深棕实底 pill + 白字 | 细描边 + 暖橙图标（低刺激） | 避免实底色块 |
| hover / 按压 | 无 | 轻微缩放 `scale(.98)` / `opacity .6` | 小程序需要触觉反馈 |

> 若某轮要「回到 Julienne 原版」，改动点是 **token 单值**（画布色、卡面色）与**单组件结构**（TabBar 容器），不涉及业务逻辑。

## 10 · 反例清单（评审红线）

1. 出现**纯黑文字**、**奶米黄底**或**明显暖黄卡片**（Julienne 是白底，不是奶咖风）。
2. 出现**分割线**、**卡片实线描边**或边框套边框（卡里再画卡）。
3. 出现**高饱和色块 / 渐变 / 阴影过重**。
4. **图标带圆形底或实底填充**；图标尺寸超出档位表。
5. 文案层级靠**加粗堆叠**而非尺寸 / 颜色分层。
6. 页面出现**第二个视觉重心**（两个大图 / 两个主 CTA）。
7. 动效**弹跳 / 过冲 / 闪烁**。
8. 自造 token（裸色值 / 裸 rpx 尺寸）—— 门禁 `check:ui` 直接拦。

## 11 · 落地与校验

- **token 唯一真源**：颜色 `theme/tokens.ts` + `generated-colors.css`；非颜色 `design-tokens.css`；对照表见 [设计变量.md](./设计变量.md)。
- **形态唯一真源**：[公共组件与形态基线.md](./公共组件与形态基线.md)（§0 设计语言 / §1 形态基线 / §2 组件规格）。
- **目录规范**：跨页公共件 `client/src/components/base/`；页面私有件 `pages/<scenery|cuisine|memory>/components/`（见基线 §2.0）。
- **图标**：新键落 `client/src/assets/icons/<key>.svg` → 登记 [图标资源.md](./图标资源.md) §3 → `npm run gen:icons`。
- **门禁**：`npm run verify` = `check:ui`（裸值）+ `check:icon`（图标体系）+ `check:event`（事件命名）+ `check:doc`（文档一致 / 断链）+ lint + type-check + 单测 + 构建，全绿才算可交付。
