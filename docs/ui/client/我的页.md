# 我的页 — 页面设计稿（UI 唯一真源）

> 所属端：学生端（微信小程序） ｜ 页面：`pages/mine/index`（主包 · **TabBar 页**） ｜ 代码落点：`pages/mine/index.vue`
> 视觉口径真源：[公共组件与形态基线.md](./公共组件与形态基线.md)（形态 §一 / 组件 §二 / 身份卡 §三）· [设计变量.md](./设计变量.md)（设计变量）
> 「我的」页为**入口聚合页**（非独立功能）——四个入口指向的功能（我的评价 / 系统通知 / 意见反馈 / 个人资料）与「注销账号」各有其功能文档；本稿为该页面的**构成、交互与展示内容的唯一真源**。

- 页面：`pages/mine/index`（**TabBar 主根页**，经 `reLaunch` 切换、无参数，故**恒不显示**返回**（文字）**）。
- 页面构成（自上而下，**两块独立模块 + 版本行 + TabBar**）：固定标题带「我的」→ **模块 A（个人信息 + 快捷功能）** → *（模块留白 `--spacing-lg`）* → **模块 B（账号设置）** → 版本行（在**两块模块外部**下方）→ `TabBar`。
- **分组依据（Apple HIG · 语义分组）**：个人身份信息与个人快捷操作属**同一语义组**（模块 A）；账号协议、隐私政策、账号注销属**独立设置语义组**（模块 B）。两块之间**必须留白分隔**，不合并为一块 —— 避免"我的主页入口"与"危险操作（注销）"同处一块造成的语义混淆与误触。
- 静态短内容页：页根定高 + **常驻 `scroll-view`（`.mine-scroll`）** 承载超高内容（超大字体 / 小屏），TabBar 避让留白由版本行 `padding-bottom` 承担。

### 1. 双模块容器

- **共 2 块 `.module-wrap`**（极简无卡片形态，规格见 [公共组件与形态基线.md](./公共组件与形态基线.md) §1.8.1），两块**共用同一套模块 Token**（`--module-bg` + `--module-shadow` + `--radius-card`）；容器 `.mine-modules` 以 flex column + `gap: --spacing-lg` 承担模块间留白与左右 `--page-gutter`。
- 两块均为 **`padding: 0` 变体**（登记例外）：身份卡顶部 6rpx 条纹需**通栏贴边**，列表行的上下内距由行自身承担。

| 模块 | 收纳内容 | 模块内结构 |
|---|---|---|
| **模块 A** | **个人信息 + 快捷功能** | 用户信息段 → *（`--spacing-lg` 留白，无分割线）* → 功能宫格段（一行 3 格，见 §3） |
| **模块 B** | **账号设置** | 三行列表：用户协议 / 隐私政策 / 注销账号（行间细分隔线，见 §4） |
- **两模块间距**：`--spacing-lg`（**留白分隔**，非分割线 —— 模块本身已是完整边界，再加分隔线会形成双重边界噪声）。
- **模块数量**：本页共 **2 块语义模块**（「个人信息 + 快捷功能」/「账号设置」），圆角与阴影各渲染 2 次。
- 外部形态与模块内两段**均为纯容器合并**：段自身**不带**底色 / 圆角 / 阴影 / 外边距，只保留内距。
- 版本行**不纳入**任何模块，仍位于**模块 B 外部**下方居中。
- **禁止**：不得把账号设置并回模块 A（会丢失语义分组）；不得给模块 A / B 之外的元素再套模块（版本行、标题带均不套）。

### 2. 用户信息模块（**卡片 A 内第 1 段**）

- 形态：**模块 A 内第 1 段**（见上「双模块容器」），顶部 **6rpx 主色软条纹**（`--color-primary-soft`，**仅认证态着色**；游客态 transparent 占位 ⇒ **两态等高**）。两态表面语言一致，差异只由条纹与内容表达。
- 内容与排版参数（头像 / 主行 / 副行 / 右侧）**以 [README §身份卡](./公共组件与形态基线.md#三跨页版面身份卡用户信息模块) 为唯一真源**；本页唯一差异 = 右侧为 `arrow` 图标（「我的主页」为「编辑个人信息」胶囊）。**动作位仅认证态渲染** —— 游客态无任何动作位（整段仍可点 → 「我的主页」，无认证拦截）。
- 交互：**整段热区**（`role="button"`），点击 → **「我的主页」**（`pages/my-reviews/index`——用户信息卡 + 名下评价列表，见 [我的主页.md](./我的主页.md)）；**游客直接进入**（无认证拦截——游客在页内看到游客信息卡与认证引导空态；认证要求仅在**评价写操作**时给出）。按压反馈 = `--bg-soft` 底色（**非** scale）。
- 无障碍：`aria-label="查看我的主页"`。
- 认证动作**单一入口 = 宫格「身份认证」格**（用户信息模块不放「去认证」按钮）。
- **模块底部不设分割线**：身份卡与下方功能宫格靠 `--spacing-lg` 留白分组。

### 3. 功能宫格（**模块 A 内第 2 段**，一行 3 格）

- 形态：**模块 A 内一行三列等宽布局**，**每格无独立外壳**（无底色 / 圆角 / 阴影）；列间距 `--spacing-md`；**每格整格热区**。
- 顺序固定：

| # | 格 | 图标键 | 点击行为 | 附加 |
|---|---|---|---|---|
| 1 | 意见反馈 | `lightbulb` | → `pages/feedback/index` | — |
| 2 | 系统通知 | `bell` | → `pages/notifications/index` | 右上**未读红点** |
| 3 | 身份认证 | `certificate` | 未认证 → 跳转身份认证页 `pages/auth/index`（认证动作单一入口）；已认证 → Toast「已完成身份认证」 | — |

- 格内：96rpx 圆底 chip（`--color-primary-soft`）内嵌主色图标（图标在上）+ 标签在下（`--font-subtitle`、`--weight-semibold`）。**无副标题**（图标 + 标签自明）。
- 角标：**「系统通知」右上未读点**（14rpx、**`--color-primary-amber`**（与系统通知未读竖条同色，见 [系统通知.md](./系统通知.md)）、贴 chip 右上角、**不遮图标主体**，仅未读数 > 0 显示）。**未读态统一用橙，红/橙不混用**（红仅留错误与危险）；**角标唯一语义 = 「有未读 / 待处理」**，「身份认证」格**不设角标** —— 认证完成是状态、非待办，用角标会被误读为待处理，且点击不可消除（认证状态由用户卡副行与条纹着色表达）。
- 按压反馈：`hover-class="pressed"` → `--bg-soft`（**非** scale）。
- 无障碍：每格 `role="button"` + `aria-label`（等于标签文案）；**角标不设 `aria-hidden`** —— 未读点 `aria-label="有未读通知"`（承载信息，非纯装饰）。
- **模块底部**：**不加分隔线** —— 宫格是模块 A 的**最后一块内容**（**两块之间靠留白分隔，不靠线**）。

### 4. 「其他」列表 —— **独立第二块模块（模块 B）**

- 形态：**独立第二块 `.module-wrap`**（暖奶米半透 `--module-bg` + `--radius-card` + `--module-shadow`，与模块 A **完全同款**）；两块之间只靠 **`--spacing-lg`** 页面留白分组（容器 flex gap），**模块内不设分割线**。
- 内部**三行独立列表项**，行间**不设分割线**，靠各行上下内距留白区分。
- 三行**内距一致**（首末行同样留白），模块内无任何分割线。
- 行结构：左侧文字（`--font-body`）+ 右侧 `arrow` 图标（`--text-tertiary`），**整行热区**（`role="button"`，触控目标 ≥ 88rpx）。
- 三行固定：

| 行 | 文字色 | 点击行为 |
|---|---|---|
| 用户协议 | `--text-body` | → `pages/privacy/agreement` |
| 隐私政策 | `--text-body` | → `pages/privacy/index` |
| 注销账号 | **`--color-error`**（危险弱化，非主行动） | **二次确认弹窗**（确认按钮取危险色实值）→ 调注销端点并清本地态 |

- 按压反馈：`--bg-soft`（**非** scale）；无障碍：每行 `role="button"` + `aria-label` 等于文案。

#### 4.1 页内承载物：注销账号（危险弱化行 + 二次确认）


- 行：`.more-row--danger` —— 文字取 `--color-error` + 右箭头 `AppIcon name="arrow"`，**非主行动**。
- 点击 → **二次确认**（`uni.showModal`，确认钮取危险色实值，确认文案「确认注销」），说明后果：昵称头像清空、评价与反馈保留但去身份化、**不可恢复**（重新登录将创建全新账号，旧数据不会回来）。
- 成功后 `useUserStore.forceLogout()` 清本地 token 与用户态，页面回落游客态（旧 token 已被服务端拉黑）。

| 数据 | 来源 | 显示在哪个组件 | 呈现形式 |
|---|---|---|---|
| 弹窗后果说明 | **端内静态文案**（非接口） | `uni.showModal` 正文 | 「注销后账号将匿名化且不可恢复：重新登录将创建全新账号，你的评价与反馈会保留但不关联身份，也不会回到新账号。」 |
| 行文案「注销账号」 | 端内静态文案 | `.more-row--danger` | 错误色文字 + 右箭头 |
| 注销结果 | `DELETE /auth/account` 成功（`data` = null） | 无界面（Toast「账号已注销」） | — |
| 失败提示 | `400` / `401` 响应 `message` | 无界面（Toast 直透，兜底「注销失败，请稍后重试」） | — |

### 5. 版本行

- **两张卡片之外**、独立一行居中纯展示（`aria-hidden` 包裹）：「`知行食记 v{version}`」（`--font-tiny`、`--text-tertiary`）—— 文案、字号、浅灰弱展示样式不变，**不纳入任何卡片容器**。

### 6. 页面展示内容口径（派生值）

| 展示项 | 来源 | 说明 |

### 7. TabBar

- 底部常驻，「我的」高亮（`showTab('profile')`）。TabBar 为**公共组件**（`components/TabBar.vue`，非本页专属），其结构 / 视觉规范见 [公共组件与形态基线.md](./公共组件与形态基线.md) §2.17。

### 8. 动效

- `prefers-reduced-motion: reduce` 下取消 `.grid-cell` / 列表行 / 身份卡的 `background-color` 过渡（按压反馈退化为**直接换色**，不产生动画）；本稿**不新增任何动效**。

### 9. 组件清单（本界面需要哪些组件）

**页面**：`pages/mine/index`（**TabBar 主根页**，经 `reLaunch` 切换、无参数）

> 组件自身规格（尺寸 / 圆角 / 颜色 / 状态 / 交互）以 [公共组件与形态基线.md](./公共组件与形态基线.md) §二 为唯一真源；**本表只写「本页用法」**。

| # | 组件 | 在本页做什么 |
|---|---|---|
| 1 | `AppHeader` | 页头：标题「我的」，`:show-back="false"`（TabBar 主根页恒不显示返回） |
| 2 | 头像渲染范式（基线 §1.15） | 用户卡头像：定尺圆盒 + 原生 `<image>` + `@error` 回退 `ImagePlaceholder name="user"`（由 `IdentityCard` 自持） |
| 3 | `AppIcon` | 宫格图标（`lightbulb` / `bell` / `certificate`）；身份卡内的箭头 / 头像占位由 `IdentityCard` 自持 |
| 4 | `TabBar` | 底部常驻菜单（首页 / 我的，本页高亮 `showTab('profile')`） |
| 5 | 模块容器 `.mine-modules`（页内内联） | flex column + gap 承担两块模块的留白 + 左右 gutter；两块均为 `.module-wrap`（`padding: 0` 变体：条纹 / 分隔线通栏） |
| 6 | `IdentityCard`（公共组件，`mode="entry"`） | 模块 A 内第 1 段：条纹 + 头像 + 主行 / 副行 + 右箭头；整段热区 → 「我的主页」（内容与排版见 [基线 §三](./公共组件与形态基线.md) / §2.17） |
| 7 | 功能宫格 `.grid`（页内内联） | 模块 A 内第 2 段：**一行三列内联宫格**（每格无独立外壳）：意见反馈 / 系统通知 / 身份认证（含角标） |
| 8 | 模块 B =「其他」列表 `.more-group`（页内内联） | **独立第二块模块**（与模块 A 同 Token）：三行：用户协议 / 隐私政策 / 注销账号（危险弱化） |
| 9 | 版本行 `.app-footer`（页内内联） | 「知行食记 v{version}」+ 副文案（`aria-hidden`），**位于两张卡片之外** |
| 10 | `useNotifyStore` | 未读通知数（宫格红点真源；`onShow` **恒刷新** —— 消息中心为登录级能力，游客与认证态同权） |
| — | `uni.showModal` / `uni.navigateTo` / `uni.reLaunch` | 注销二次确认 / 各入口跳转 / TabBar 切页 |

> 本页为**静态短内容页**：页根定高（`height: 100vh / 100dvh`，**`min-height: 0`**）+ **`scroll-view`（`.mine-scroll`）** 承载超高内容（大字体 / 小屏）。
> ⚠️ `min-height: 0` 必需：全局 `.page` 兜底写了 `min-height: 100vh / 100dvh`，而移动端 `100vh`（最大视口）通常**大于** `100dvh`（当前视口）；二者同时存在时 min 胜出 ⇒ 页根高于可视区 ⇒ **内容未超屏也会出现页面级滚动**。
