# 食在交大 · 上线部署路线图（个人开发者版）

> **主体情况**：小程序主体为**个人**（大学生个人开发者）。
> **一句话方案**：**直接买轻量服务器 + 个人 ICP 备案 + 小程序备案，一步到位部署上线**；微信云托管作为"需验证的备选"（个人主体大概率不支持，见 §2）。
>
> 目标读者：零部署经验的小白。本文档与 `docs/DEPLOY_GUIDE.md`（服务器部署操作手册）配套使用：
> - **本文档** = 决策与路线图（个人主体怎么上线、什么时候干什么）
> - **DEPLOY_GUIDE.md** = 服务器部署的详细操作手册
>
> 技术栈：Spring Boot 3.2（Java 21）+ MySQL 8 后端 / uni-app 小程序 / Vue3 Web 管理端。

---

## 0. 个人主体先看：3 个限制 + 1 个强制政策

### 0.1 个人主体小程序的限制（对本项目影响）

| 限制 | 影响 | 本项目是否受影响 |
|---|---|---|
| 不能开通微信支付 | 无法收费/打赏/内购 | ❌ 无支付功能，不影响 |
| 不能获取手机号（`getPhoneNumber`） | 无法一键手机号授权 | ❌ 用邮箱+账号注册，不影响 |
| 可用类目有限 | 不能做电商/金融等企业类目 | ⚠️ 选「生活服务 / 工具」类目即可 |
| 无微信认证（300元/年那步） | 部分高级能力受限 | ⚠️ 对当前功能无影响 |

### 0.2 强制政策（重要）

> ⚠️ **2026 年 6 月 30 日起**，所有小程序（**含个人主体**）必须完成**小程序备案**才能提交审核/上架；存量未备案的将限制功能并逐步下架。
>
> **小程序备案** = 微信公众平台内在线提交，**免费**，与服务器域名的 ICP 备案是两码事，**两个都要办**（见 §1.2）。

### 0.3 个人开发者能走通吗？—— 能

个人可以正常：买服务器 → **个人 ICP 备案**（免费，身份证即可）→ 部署后端 → 小程序 request 域名指向备案域名 → 上线。这条路对个人完全开放，也是本路线图的主线。

## 1. 主路线：直接服务器部署（推荐，无迁移，最省事）

### 1.1 整体流程图

```
第 1 周
 ├─ 买阿里云轻量 2核2G（68元/年，新人价）
 ├─ 买域名 api.你的域名.com（~50元/年，同厂商买，备案快）
 ├─ 提交【个人 ICP 备案】（免费，1~2 周）      ← 服务器域名用
 └─ 完成【小程序备案】（微信平台内，免费）      ← 小程序上线用

第 2~3 周（备案审核期，别闲着）
 ├─ 本机把后端跑起来（开发环境）
 ├─ Web 管理端本地跑（localhost:5173，看数据）
 └─ 准备部署素材（jar 包 / SQL 文件 / 域名解析）

备案通过后
 ├─ 按 DEPLOY_GUIDE.md ①~⑥ 部署：Java21 / MySQL8 / Nginx / HTTPS
 ├─ 微信后台配 request 白名单（api.你的域名.com）
 └─ 小程序上传 → 审核 → 发布 ✅
```

### 1.2 备案双线并行（最耗时，第 1 周就启动）

| 备案 | 在哪办 | 费用 | 周期 | 用途 |
|---|---|---|---|---|
| **个人 ICP 备案**（网站/域名） | 阿里云控制台 → 备案 | 免费 | 1~2 周 | 小程序 request 合法域名必须用已备案域名 |
| **小程序备案** | 微信公众平台 → 备案入口 | 免费 | 几天~2 周 | 2026.6.30 后小程序上架强制 |

> 个人 ICP 备案要点：身份证 + 手机号 + 人脸核验（部分省份）；**域名和服务器要在同一云厂商账号下**（阿里云备案要求名下有一台购买满 3 个月的服务器，可用 68 元/年那台）。
> ⚠️ 微信要求小程序 request 域名**备案主体与小程序主体一致**——个人主体小程序，域名就以**你个人名义**备案。

### 1.3 服务器部署（详细操作看 DEPLOY_GUIDE.md）

按 `docs/DEPLOY_GUIDE.md` 的 ①~⑥ 执行，要点：

- 服务器：**阿里云轻量 2核2G**（68 元/年，200M 峰值带宽 / 40GB ESSD / 不限流量）
- 镜像：Ubuntu 22.04
- 端口：22 / 80 / 443 放行，8080 不对公网
- **2G 内存调优 3 件套**（必做，否则 OOM）：
  1. jar 启动加 `-Xms256m -Xmx512m`
  2. MySQL `my.cnf` 设 `innodb_buffer_pool_size = 128M`
  3. 加 2GB swap

### 1.4 Web 管理端（本地跑，方案 A）

管理员后台不需要公网，本地跑即可，数据连服务器 API：

```ts
// web/src/api/config.ts（改一行）
export const API_BASE_URL = 'https://api.你的域名.com/api'
```
```powershell
cd d:\workspace\code\project\bjtu_food\web
npm install && npm run dev   # 打开 http://localhost:5173，admin/123456 登录
```

> 后端 `CorsConfig.java` 已全局放行跨域，本地 Web 直连线上 API 无问题。
> 图片：后端返回的图片地址用 `APP_PUBLIC_BASE_URL` 拼接，部署时在 `application-prod.yml` 把它配成 `https://api.你的域名.com/api`，否则图片链接是 localhost。

### 1.5 小程序构建

```powershell
cd d:\workspace\code\project\bjtu_food\frontend
$env:VITE_API_BASE_URL="https://api.你的域名.com/api"
npm run build:mp-weixin
```
产物 `frontend/dist/build/mp-weixin/` → 微信开发者工具上传 → 提审 → 发布。

## 2. 备选：微信云托管（需先验证，个人主体大概率不支持）

> 云托管若能用：前 3 个月免费，可"白嫖"抢上线时间，之后仍须迁移服务器（否则按量计费 ~377 元/月，MySQL 是大头）。但对个人主体，**大概率开通不了**，验证方法如下。

### 2.1 验证方法（2 分钟）

1. 打开 [微信云托管控制台](https://cloud.weixin.qq.com)（或微信公众平台 → 云开发/云托管）
2. 用小程序**管理员微信**扫码登录
3. 尝试**创建第一个环境**：
   - ✅ 能创建 → 走原"组合拳"方案（免费 3 个月 + 第 3 个月迁服务器）
   - ❌ 提示主体不支持 → 直接走 §1 主路线，不用纠结

> 官方文档《账号说明》仅写明"未认证的公众号不支持开通云托管"，未明确小程序个人主体；实际开通时以控制台提示为准。**验证成本极低，建议试一次。**

### 2.2 若云托管可用（组合拳备选）

- 后端用 `backend/Dockerfile` 打镜像上传（文档附录 A）
- 环境变量：`SPRING_DATASOURCE_URL`（云托管 MySQL）、`APP_PUBLIC_BASE_URL`（云托管域名）、`SPRING_MAIL_*`
- ⚠️ **图片不能存容器本地**（容器重建会丢），需改上传模块接 COS，或验证云托管持久化挂载
- ⚠️ 免费额度仅首个环境、3 个月；到期自动按量计费，**第 3 个月末必须迁完并关停**

## 3. 全程成本总表

| 路线 | 前期 | 长期 | 备案 |
|---|---|---|---|
| **主路线（推荐）** | 服务器 68 + 域名 50 = **118 元/年** | ~10 元/月 | 个人 ICP + 小程序备案（均免费） |
| 云托管组合拳（备选） | 0~20 元/月（3 个月免费） | 迁服务器后 ~10 元/月 | 免（云托管）但 3 个月后仍要迁 |

> 结论：个人主体下，**主路线（直接服务器）更简单**——少一次迁移，不用赌云托管是否支持。

## 4. 避坑清单

| 坑 | 后果 | 规避 |
|---|---|---|
| 拖到 2026.6.30 后未办小程序备案 | 无法提审/被下架 | 第 1 周就提交小程序备案 |
| 域名备案主体与小程序不一致 | 白名单审核不通过 | 域名用**个人名义**备案 |
| 阿里云备案要求服务器购买满 3 个月 | 备案被驳回 | 用 68 元/年那台（先买再备案） |
| 服务器 2G 内存不调优 | 频繁 OOM 崩溃 | §1.3 调优 3 件套 |
| `APP_PUBLIC_BASE_URL` 忘配 | 图片链接 localhost 打不开 | 部署时必配（见 §1.4） |
| 8080 端口对公网开放 | 被扫描攻击 | 安全组只放 22/80/443 |
| 云托管容器存图片（若走备选） | 重建即丢 | 必须 COS/持久化 |

## 附录 A：backend/Dockerfile（云托管备选用）

```dockerfile
# ===== 构建阶段 =====
FROM maven:3.9-eclipse-temurin-21 AS build
WORKDIR /app
COPY pom.xml .
RUN mvn dependency:go-offline -B || true
COPY src ./src
RUN mvn clean package -DskipTests -B

# ===== 运行阶段 =====
FROM eclipse-temurin:21-jre
WORKDIR /app
COPY --from=build /app/target/bjtu-food-1.0.0.jar app.jar
ENV JAVA_OPTS="-Xms256m -Xmx512m"
EXPOSE 8080
ENTRYPOINT ["sh", "-c", "java $JAVA_OPTS -jar app.jar"]
```
