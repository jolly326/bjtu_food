# B5 · 意见反馈

> 所属端：**学生端（微信小程序）** ｜ 鉴权：**🔑 需登录**（免邮箱认证）
> 归属：**B UGC 表达与治理**
> 返回：[功能总览](../README.md)

## 介绍

学生诉求提交入口：**一张表单、无页签**，反馈类型**单选**（字典驱动，初始 3 条：程序功能Bug / 产品功能建议 / 其他相关问题），字段固定一套 —— 具体描述 + 截图。

| 项 | 口径 |
|---|---|
| 反馈类型 | 单选，选项**实时取自后端字典**（`GET /feedback-options`，仅启用项、按 `id` 升序），端上**零硬编码**、不排序；提交上送 `optionId`，非法 / 缺少 / 已停用 → `400` |
| 具体描述 | 必填；端上 ≤**600 字**（服务端上限 1000），纯空白视为未填 |
| 截图 | 选填，**≤3 张**（端上 / 服务端一致），须先经上传端点转存为 COS 地址 |
| 本地草稿 | 进页自动回填「类型 + 描述文本」（存储键 `feedback_draft`）；**图片不缓存**——草稿里的 COS 地址是临时转存结果，重进小程序可能已失效，缓存它只会让用户提交时报「图片地址不合法」；提交成功后清除草稿 |

入口：

- 「我的」页宫格「意见反馈」。

流程：选类型 → 填描述 → 可选截图（**≤3 张**）→ 提交。提交门禁：类型未选 / 描述为空即置灰（置灰点击 toast 缺失项）；提交中禁用防重复；成功 Toast「已提交，感谢反馈」+ 2 秒自动返回。处理结果经站内通知回执（**提交入口恒需登录 ⇒ 一律投递** —— 静默登录的游客同样收到）。

> **与举报、菜品问题反馈的边界**：举报评价是**独立资源**（`POST /reviews/{id}/report`，见 [B4 举报评价](./B4-举报评价.md)），菜品问题反馈是**独立资源**（`POST /dishes/{id}/correction`，见 [B6 菜品问题反馈](./B6-菜品问题反馈.md)）——**均不在本页范围内**、不共用本端点。

> 接口 / 字段见 [api/feedback.md](../../../api/client/feedback.md)。

## 业务口径

| 项 | 口径 |
|---|---|
| **不收集联系方式** | 不要求邮箱认证、不收集任何联系方式 —— 反馈链路不需要额外身份信息 |
| **归属用户** | 提交**恒需登录**（`user_id` 恒为真实用户）；**静默登录的游客（未邮箱认证）即可提交**，并收回执 |
| **类型锚在字典 ID** | 类型文案真源是 `feedback_option` 字典：改名全站生效、新增类型免发版；被引用的类型**禁止删除**，下线一律停用 |
| **端上字数** | 描述 ≤600 字（服务端上限 1000），校验在端上先做一次 |
| **本地草稿** | 进页回填「类型 + 描述文本」（`feedback_draft`）；**图片不入草稿** —— COS 地址重进可能失效，缓存只会导致提交时报「图片地址不合法」。提交成功后清除，失败时保留便于改后重试 |

> **与举报、菜品问题反馈的边界**：举报见 [api/reviews.md](../../../api/client/reviews.md)，菜品问题反馈见 [api/dishes.md](../../../api/client/dishes.md) —— **均不共用本端点**。

## 数据（读写）

| 表 | 变化 | 中文解释 |
|---|---|---|
| `feedback` | INSERT | 一条意见反馈：类型 = 字典项（`option_id`）、含内容与配图，**无关联对象**；**只存提交事实**，无状态列；列定义见 [schema/feedback.md](../../../schema/feedback.md) |
| `moderation_task` | INSERT（提交**同一事务**预建） | 预建 `pending` 处置任务行（多态键 `type='feedback'`）——「未处置」是显式行；列定义见 [schema/moderation_task.md](../../../schema/moderation_task.md) |
| `notification` | INSERT（管理员**处置时**） | 提交人收处理回执（`reply_title` / `reply_content` 快照，与处置**同一事务**写入，**一律投递**，含静默登录的游客）；列定义见 [schema/notification.md](../../../schema/notification.md) |

> **账号归属迁移**（邮箱认证命中已绑定的其他账号）：本账号提交的**意见反馈与举报**在同一次迁移内**改挂**到目标账号（仅改归属，不改内容，同一事务）—— 事件为 `UserOwnershipMigratedEvent`，发布方为 auth 域，本域自行改本域表。
> **账号注销**：提交记录**保留**（匿名化展示，见 [C4 注销账号](../C-账号与身份/C4-注销账号.md)）；站内通知随注销删除。
