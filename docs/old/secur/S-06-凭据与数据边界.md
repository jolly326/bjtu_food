# S-06 · 凭据与数据边界

> **等级 S（核心防线）** —— **全站唯一可以「一次性拿到全量数据」的路径**：拿到数据库连接串即可直连拖库、改库、删库，与管理端 / 小程序端的任何加固**无关**。故「应用账号仅 DML」是最后一道防线。
> **范围**：数据库可达性与最小权限、口令轮换、私网连接、密钥硬规则。
> **真源**：本文档。JWT 与告警密钥见 [S-01](./S-01-身份与凭证.md)；平台约束与否决记录见 [B-02](./B-02-设计边界与否决记录.md)。

---

## 1 · 🔴 数据库可达性与凭据现状

| 项 | 现状 |
|---|---|
| 数据库形态 | 托管数据库（云厂商），**端口在公网可直接连接** |
| 可达性 | 🔴 端口对公网开放 |
| 凭据 | 🔴 历史口令曾以明文出现在协作记录 / 启动脚本中 —— **须视为已泄露** |
| **应用账号权限** | 🔴 应用当前以**超级账号（root）** 连接：含 `DROP` / `ALTER` / `GRANT` / `CREATE USER` 等高危权限 —— 应用一旦被攻破（如出现注入或 RCE），可直接删库 / 改结构 / 改权限 |

## 2 · 已定口径

| # | 口径 |
|---|---|
| 1 | **应用账号仅 DML** —— 无 `DROP` / `ALTER` / `GRANT` / `CREATE`，DDL 由人工提权执行（库结构变更流程见 [`schema/README.md`](../schema/README.md)），应用账号不得持有 |
| 2 | **口令轮换** —— 曾明文暴露的口令一律作废重设，新值只经环境变量注入 |
| 3 | **优先私网连接** —— 若托管数据库提供私网 / 内网连接能力，改走内网，不再公网直连 |
| 4 | 连接串与凭据**只从环境变量读取**，禁止写入任何文档 / 代码 / commit message / 规则文件 |

**目的**：即使应用被攻破（如出现注入或 RCE），也**打不出删库 / 改结构**这一档破坏。

> 上述第 2、3 项的**执行**（改口令、改权限、切换连接方式）会立即影响运行中的服务与其环境变量文件 —— 属需明确授权的运维动作，见 [`docs/测试/安全待决策项.md`](../测试/安全待决策项.md)。

### 2.1 · 变更后必做

任何库结构 / 权限变更后，同步更新 [`schema/`](../schema/README.md) 使**文档与远程库实况一致**（流程见 [`schema/README.md`](../schema/README.md)）。

## 3 · 密钥硬规则

| 规则 | 说明 |
|---|---|
| **永不入库** | 口令 / secret / 密钥一律走**环境变量**，不写文档、不提交仓库、不进 commit message |
| **示例文件只放占位符** | `.env.example` 不带真值 |
| **双 JWT 密钥独立** | 学生 `JWT_SECRET` ≠ 管理端 `ADMIN_JWT_SECRET`，共用则学生可自签管理端 token |
| **弱密钥启动阻断** | 缺失 / 过短 / 命中开发默认值 ⇒ **启动失败**（fail-fast） |
| **凭据不进日志** | 出网调用日志对 `secret` 等参数脱敏 |

环境变量清单见 [S-01](./S-01-身份与凭证.md) §5。

## 4 · 真实暴露面

因为管理端在本地而后端在公网，**攻击者不需要碰你的前端产物**：

```
攻击者
  → 直接打公网 https://<云托管域名>/api/v1/admin/**
  → 需通过账密登录拿到管理端 JWT
  → 未授权请求被管理端鉴权过滤器拦在鉴权层
```

| 攻击面 | 防护 | 残余风险 |
|---|---|---|
| `/admin/**` | 账密登录 + 双维度限频 + 账号锁定 + 实时告警 | 无 IP 白名单（平台限制，见 [B-02](./B-02-设计边界与否决记录.md)） |
| 学生接口（公开） | 双维度限频 + 归属校验 + 参数校验 + 机审 | 无 IP 白名单 |
| **数据库端口** | 🔴 **直接公网可达** | 见 §1 |

## 5 · 危险访问路径：识别 / 拦截 / 响应

| 路径 | 识别 | 拦截 | 响应 |
|---|---|---|---|
| 数据库账号越权（删库 / 改结构） | — | 应用账号**仅 DML** | — |
| 数据库直连公网拖库 | — | 端口公网可达（现状）；私网连接为已定口径 | 待执行（运维） |
| 凭据明文泄露 | — | 口令轮换 + 环境变量注入 | 待执行（运维） |
| 密钥随产物分发 | — | 前端产物零密钥（见 [A-06](./A-06-端侧约束与反向证据.md)） | — |

## 6 · 与当前代码的差异

> 登记设计已定、代码尚未同步的条目（本篇多为**部署 / 运维口径**，非代码条目）；清零即写「无」。

| # | 差异 | 类型 |
|---|---|---|
| 1 | **数据库口令未轮换**（曾明文暴露的旧口令仍在用） | 运维动作（待授权） |
| 2 | **受限账号已建立（`SELECT` / `INSERT` / `UPDATE` / `DELETE`，无任何 DDL），但线上仍在用 root** | 运维动作：**须先在云托管把连接凭据换为受限账号并发布，确认正常后再撤销 root 连接** —— 顺序颠倒会即刻中断线上 |
| 3 | **未切换私网连接**（当前公网直连） | 部署（待评估平台能力后执行） |
