# A-04 · 信息暴露与注入基线

> **等级 A（纵深缓解）** —— 缺失不直接失守，但它决定攻击者能否**低成本摸清结构**（有哪些表、哪些字段、什么框架版本），从而把爆破 / 注入从盲打变成定向。
> **范围**：异常文案受控、调试面生产关闭、全参数化 SQL、敏感数据不回显。
> **真源**：本文档。参数校验见 [A-01](./A-01-参数与字段校验.md)；时序侧信道见 [B-01](./B-01-口令策略与超期.md)。

---

## 1 · 异常与信息暴露

| 场景 | 口径 |
|---|---|
| 未捕获异常（兜底 500） | 统一文案（如「服务器繁忙，请稍后再试」）；**堆栈只入日志，不回客户端** |
| 反序列化失败 | 不透出 cause |
| **内部非法参数（`IllegalArgumentException` 等）** | 统一返回**受控文案**，原始 `message` 仅入日志 —— 内部枚举值 / 字段名 / 约束信息不得外显（给攻击者的结构探测线索） |
| 业务可读提示 | 只由**受控业务异常**（`BusinessException`）承担，文案为可展示给用户的最终形态 |
| 框架痕迹 | 生产关闭调试页与详细错误信息；不暴露框架版本类响应头 |
| 业务码唯一判据 | 端上只读响应体 `code`，**不解析 `message` 文本** |

## 2 · 调试面生产收敛

| 面 | 生产口径 |
|---|---|
| 接口文档（springdoc） | `api-docs` / `swagger-ui` **关闭**（仅开发环境开启） |
| Actuator | 仅暴露 `health` / `info`，`show-details: never`；**不含** `env` / `beans` / `configprops` / `heapdump` / `threaddump` |

## 3 · 数据与接口基线（反向证据）

| 维度 | 结论 |
|---|---|
| **SQL 注入** | **无** —— 全量 ORM 包装器 + `#{}` 占位；XML 无 `${}`；无 JDBC 字符串拼接 |
| **敏感数据回显** | `openid` / 口令 / token **不出现在任何 VO**；仅以布尔（如「是否已绑定」）暴露 |
| **前端 XSS** | 两端全站模板自动转义，无 `v-html` / `eval` / 危险 `innerHTML`（见 [A-06](./A-06-端侧约束与反向证据.md)） |
| **前端密钥** | 前端产物内**零密钥** |

## 4 · 危险访问路径：识别 / 拦截 / 响应

| 路径 | 识别 | 拦截 | 响应 |
|---|---|---|---|
| 内部信息探测（异常 message / 调试面） | 异常类型 + 生产开关 | 受控文案 / 默认关闭 | 高频探测 ⇒ 告警 |
| SQL 注入 | 参数化查询（结构性消除） | — | — |
| 敏感数据经 VO 外泄 | VO 白名单 | — | — |
