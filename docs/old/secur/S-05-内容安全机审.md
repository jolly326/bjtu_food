# S-05 · 内容安全机审

> **等级 S（核心防线）** —— UGC 违规内容入库是**校园场景合规事故**，且机审是唯一自动处置层；fail-closed 是这条防线的底线。
> **范围**：机审判定口径、文本 / 图片覆盖范围、举报与人工处置闭环。
> **真源**：本文档。上传形态校验见 [A-03](./A-03-上传防护.md)；限频见 [S-04](./S-04-限频与可用性.md)；管理端处置入口见 [`api/web/`](../api/README.md)。

---

## 1 · 判定口径

| 结果 | 处置 |
|---|---|
| `risky`（明确违规） | **拦截 `400`**，不入库 |
| `pass` / `review`（疑似） | **放行入库**（无人工复核队列）—— UGC 治理闭环口径 |
| 上游不可达 / 超时 | **fail-closed：`500` 拒绝入库**（宁可拒收，不放违规内容过关） |
| **生产环境凭据未配置** | **fail-closed：启动失败** |
| **无 openid** | **fail-closed：拒绝入库** |

**生产环境不存在「跳过检测放行」分支。** 非生产环境（dev / test）凭据未配置时跳过检测并放行，仅本地开发生效。

## 2 · 覆盖范围

- **文本**：评价正文、反馈正文、菜品问题反馈说明、用户昵称等一切用户可控文本。
- **图片**：UGC 配图与**头像**走**同一条**安检链路（`POST /upload/cloud-image` → 内容安检 → 转存对象存储），**不存在「头像可绕过」的旁路**。头像上传只接受站内路径或已过检的 COS 地址。
- `field` 型菜品问题反馈的多个提交项**合并为单次送检**（不逐字段外呼）。

上传自身的形态校验（扩展名白名单 / 魔法字节 / 尺寸 / 像素上限 / 文件名）见 [A-03](./A-03-上传防护.md)。

## 3 · 事后手段：举报与人工处置

| 环节 | 口径 |
|---|---|
| 举报限频 | **IP + 账号双维度**（各 2/分 · 10/时，见 [S-04](./S-04-限频与可用性.md) §3） |
| 去重 | 同一 `userId + reviewId` 重复举报 ⇒ `400` |
| 人工处置 | 管理端处置举报时可**联动隐藏评价**；隐藏 / 恢复 / 删除评价有独立管理端入口 |
| 处置留痕 | `hidden_note` / `moderated_by` / `moderated_at`；重新评价覆盖内容时**一并清空** |

> 📌 **游客可读「公开信息」是产品口径**（首页 / 搜索 / 详情免登录），不因防爬而收紧为「必须登录」；抓手放在**速率与枚举异常检测**上（见 [A-02](./A-02-爬取与枚举防护.md)）。是否取消公开读见 [`docs/测试/安全待决策项.md`](../测试/安全待决策项.md)。

## 4 · 已知取舍

| # | 取舍 | 理由 | 重评条件 |
|---|---|---|---|
| 1 | 机审对「疑似（`review`）」一律放行，无人工复核队列 | UGC 治理闭环口径：微信全量检测 + 举报兜底，MVP 内容量小 | 出合规事故或量级增长 |

## 5 · 危险访问路径：识别 / 拦截 / 响应

| 路径 | 识别 | 拦截 | 响应 |
|---|---|---|---|
| 违规内容入库 | `risky` 判定 / 上游可达性 | `400` / `500`（fail-closed） | 告警 + 降级提示 |
| 图片马 / 图像炸弹 / 路径穿越 | 扩展名 + 魔法字节 + 尺寸 + 像素上限 + UUID 名 | `400` 拒绝 | 告警（高频时） |
| 上游审核服务降级被利用 | 出网调用失败捕获 | `500` fail-closed | 告警（提示上游异常） |
| 刷举报挤占审核配额 | 双维度限频 + 同一评价去重 | `429` / `400` | 告警 |
