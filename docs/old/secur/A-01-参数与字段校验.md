# A-01 · 参数与字段校验

> **等级 A（纵深缓解）** —— 缺失不直接失守（归属校验已挡住越权写），但它是「字段注入」试探的第一道回应：攻击者塞入 `userId` / `status` / `isAdmin` 时，服务端必须拒绝而非静默忽略。
> **范围**：DTO 约束、拒绝未声明字段、枚举闭合、分页上限。
> **真源**：本文档。归属校验见 [S-02](./S-02-鉴权与归属校验.md)；限频见 [S-04](./S-04-限频与可用性.md)。

---

## 1 · 校验口径

| 层 | 口径 |
|---|---|
| DTO 约束 | 全部写端点入参 `@Valid` + 长度 / 范围 / 枚举白名单约束（`@Size` / `@Min` / `@Max` / `@Pattern` / `@NotBlank` / `@Positive`） |
| **拒绝未声明字段** | **写端点 DTO 一律拒绝请求体中的未声明字段**（请求体多一个字段 ⇒ `400`）。防「字段注入」试探：攻击者塞入 `userId` / `status` / `isAdmin` 等，试探服务端是否误把 body 当权威值 |
| 类型严格 | 不开启全局「忽略未知字段」的宽松反序列化；读端点（`@RequestParam` / `@ModelAttribute`）不走 JSON 反序列化，天然豁免 |
| 枚举闭合 | 状态类字段只接受白名单取值，**拒绝未声明枚举键**（如纠错类型 `field` / `gone`、处置结论、用户状态、评分 1~5、字典表启用项） |
| 分页参数 | 学生端 `pageSize` 上限 **50**，超限服务端截断（`PageUtil.MAX_PAGE_SIZE`） |
| 数值语义 | 金额一律「分」，评分 `DECIMAL` —— 越界 / 溢出在 DTO 层拦下 |

> 📌 **契约同步**：端上类型由后端 VO 经 SpringDoc 导出（`client/openapi.json` + `api.d.ts`），并在门禁中校验一致性 —— 因此「拒绝未声明字段」不会与端上现实请求冲突。

## 2 · 危险访问路径：识别 / 拦截 / 响应

| 路径 | 识别 | 拦截 | 响应 |
|---|---|---|---|
| **参数篡改 / 字段注入** | DTO 约束 + 拒绝未声明字段 | `400` | 高频异常 ⇒ 告警 |
| 枚举值探测（塞入未声明键） | 枚举白名单闭合 | `400` | — |
| 一次拉全量（超大 `pageSize`） | 服务端截断至 50 | 静默截断 | — |
