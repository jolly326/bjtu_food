# A-06 · 端侧约束与反向证据

> **性质**：**不是防线，是 S/A 级防线的端侧验收基线** —— 本篇登记的约束一旦被端侧破坏（如 token 改存 `localStorage`、H5 放开明文 HTTP），**服务端不变也会削弱对应防线**。故等级取 A：端侧一处回归即真实安全回归。
> **范围**：小程序端与管理端的端侧安全基线（每条标注它守护的是哪条防线）。
> **真源**：本文档。对应的服务端防线见各 S / A 篇。

| 密码体系 | **无账号密码体系** —— 打开即静默登录，无登录页、无口令可泄露 | [S-01](./S-01-身份与凭证.md) §1 | `func/client/README.md` |

## 2 · 管理端基线

| 维度 | 结论 | 守护的防线 |
|---|---|---|
| 前端产物 | **不含任何口令 / 密钥** —— 口令仅在登录表单提交瞬间存在于内存 | [S-01](./S-01-身份与凭证.md) §3 · [S-06](./S-06-凭据与数据边界.md) §3 |
| 凭证存储 | token 存 `sessionStorage`（关标签页即失效），**不用 `localStorage`** | [S-01](./S-01-身份与凭证.md) §3 |
| XSS | 全站 Vue `{{ }}` 自动转义；无 `v-html` / `eval` / 危险 `innerHTML`；**「零 XSS」是 token 存储安全的第一防线** | [S-01](./S-01-身份与凭证.md) §3 |
| 无独立凭证 | 前端**不持有**任何长期凭据；不给入口层注入凭证的机会 | [B-02](./B-02-设计边界与否决记录.md)（反代藏凭证已否决） |
| 路由守卫 | 进入受保护路由前校验登录态（以服务端 `/admin/auth/me` 为准，非仅看本地 token） | [S-02](./S-02-鉴权与归属校验.md) §3 |
| 入口隐显 | `viewer` 不显示写入口、删除仅 `super` 可见 —— **只是体验**，真门控在服务端 | [S-02](./S-02-鉴权与归属校验.md) §2 |
| 破坏性操作 | 删除前二次确认 —— **只是体验**，真护栏是后端写限频 + 引用校验 + 仅 `super` | [A-05](./A-05-告警与破坏性操作防护.md) §2 |
| 限频退避 | 端上按 `code=429` 识别限频、从文案解析 N 做退避倒计时 | [S-04](./S-04-限频与可用性.md) §4 |

## 3 · 已知取舍

| # | 取舍 | 理由 |
|---|---|---|
| 1 | 小程序 token 明文落本地存储（`uni.setStorageSync` 无加密、无 `httpOnly` 等价物） | 微信平台限制；缓解 = 短时效 + **全局吊销**（见 [S-01](./S-01-身份与凭证.md) §4）。未越狱 / 未导出备份的设备上泄露面有限 |
| 2 | UGC 正文草稿明文落本地存储 | 属用户本人设备上的本人草稿；提交成功后即清理 |
