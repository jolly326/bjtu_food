# 设计变量（Design Tokens）

> 所属端：**学生端（微信小程序，uni-app）** ｜ 适用：本目录全部 14 份文档 + `client/src/**`
> **真源声明**：变量**取值**的唯一真源是**代码** —— 颜色 = `client/src/theme/tokens.ts`（`COLOR_MAP` / `CSS_VARS`）
> → 产物 `client/src/theme/generated-colors.css`；非颜色（圆角 / 间距 / 字号 / 字重 / 字距 / 时长 / 缓动 / 高度 / 层级 / 结构尺寸）
> = `client/src/theme/design-tokens.css`（2026-10-01 由 `App.vue` 收口至此后，`App.vue` 仅 `@import`）。
> 本文档是**对照表 + 命名与使用约束**，**不构成第二真源**：改值只改代码，改后同步本表。

## 0. 使用总则

1. **一律走 CSS 变量**：页面 / 组件样式内**只允许** `var(--xxx)`；**SHALL NOT** 裸写色值或尺寸（见 §3 红线）。
2. **三层结构**（本项目现状与目标）：

| 层 | 含义 | 本项目落点 |
|---|---|---|
| Primitive（原值） | 与语义无关的原始值（如 `#B4531A`） | 内联在 `COLOR_MAP` 的值里（**未单独导出 primitive 变量**，属已知简化） |
| **Semantic（语义）** | 按用途命名的变量（`--color-primary-fill`） | **主用层**：页面/组件只消费这一层 |
| Component（组件级） | 组件私有变量（`--card-bg`） | **本项目不设**：组件直接消费 semantic 层（18 个组件规格见基线 §二） |

3. **同值不同语义**允许（如 `--text-primary` 与 `--text-title` 同值 `#2D1F14`）—— 语义键服务于「改一处即全站生效」；
   **零消费即删**（无消费方的 token 直接移除，不留兼容别名）。
4. 组件视觉规格（18 个公共组件）真源 = [公共组件与形态基线.md](./公共组件与形态基线.md) §二；
   色板取色边界真源 = [首页菜品浏览.md](./首页菜品浏览.md) §10。

## 2. 非颜色变量

### 2.1 圆角（`--radius-*`，单位 rpx，`none` / `circle` 为形状修饰）

> **跨端同值口径**：与管理端（Web）以 **px 为基准**统一 —— 同档位 `rpx` = `px × 2`（@375pt，`1rpx = 0.5px`），两端同档同名同值（对照表见 Web 端 [设计变量.md](../web/设计变量.md) §5）。

| 变量 | 值 | 适用对象 |
|---|---|---|
| `--radius-none` | `0` | 无圆角（结构重置） |
| `--radius-xs` | `24rpx` | 微件：焦点环等极小件（12px） |
| `--radius-btn` | `32rpx` | 按钮 / 控件行（16px，控件主档） |
| `--radius-icon` | `32rpx` | **图像 / 图标容器**（与 btn 同值、语义不同；头像 / 缩略图 / 图标钮） |
| `--radius-card` | `40rpx` | **模块表面**（面板主档，20px） |
| `--radius-modal` | `56rpx` | 弹层顶部（28px） |
| `--radius-pill` | `999rpx` | **可点**胶囊：搜索框 / chip / 词条 / 进度条 —— 形状语义，不随档位调整 |
| `--radius-circle` | `50%` | 正圆（头像 / 圆点）—— 形状语义，不随档位调整 |

> 值域遵循「块越大越圆」：微件 24 → 控件 32 → 卡片 40 → 弹层 56（rpx）；全部落在 4pt 栅格（12 / 16 / 20 / 28 px），档位层级 **微件 < 控件 < 面板 < 弹层**。
> **圆角只按「物件量级」分档，不按「是否可点」分档**：端上**不可点的信息标签一律是纯文字（无底色、无圆角）**，故不存在「不可点标签」专用档；**可点**词条 / 胶囊 → `--radius-pill`。
> **线宽**：**结构线唯一档 = `1rpx`**（卡片描边 / 分隔线 / 折口 / 底栏顶边）；`2rpx` 只留给**语义状态线**（选中 / 聚焦，配主色）。
> 圆角标度**不含 12rpx / 16rpx / 20rpx / 28rpx 档** —— 这些值不在标度内，SHALL NOT 消费。

### 2.2 间距（`--spacing-*`，**4pt 基准栅格**，单位 rpx）

| 变量 | `3xs` | `2xs` | `xs` | `sm` | `md` | `lg` | `xl` | `2xl` |
|---|---|---|---|---|---|---|---|---|
| 值 | `2` | `4` | `8` | `16` | `24` | `32` | `48` | `64` |

> `2xs` = 半格，供星标 / 徽标等紧凑布局，避免裸 `4rpx`。

**页面级 gutter**：`--page-gutter` = `32rpx`（16pt，iOS 列表 inset 常规）—— 页面 / 卡片 / 吸顶条等内容到屏幕**左右缘**的边距唯一档位。`--spacing-*` 只表达「元素之间留多少」，二者不可混用。

## 3. 红线（改 `client/` 前必查）

1. 页面 / 组件样式**SHALL NOT** 裸 hex / `rgb()` / `rgba()`（字体栈、`currentColor`、`transparent`、`inherit` 除外）。
2. **SHALL NOT** 裸写圆角、间距、字号、字重、时长、缓动、层级数值 —— 一律走对应 `var(--xxx)`。
3. **SHALL NOT** 裸写 `transform: scale()` 作按压反馈 —— 统一「透明度微降 / 浅底变化 +（图片）轻微缩放」语言。
4. **SHALL NOT** 页面私有底色 —— 一律 `--bg-page` + 壁纸层。
5. 改视觉值**只改 token**：动 token 即全站生效；新增变量须先入代码真源，再同步本表。
6. 提交前自检（与 [docs/func/client/README.md](../../func/client/README.md) 的「UI 实现红线」一致）：grep 裸 scale / 裸 hex / 裸数值 / `@click`。

## 6. 允许裸写的两类（口径依据；清单在 `client/scripts/ui-token-allow.json`）

1. **物理 / 渲染量**：边框宽（`1rpx` / `2rpx` / `3rpx`）、H5 媒体查询与滤镜参数（`px` 值）、**零偏移 `0px`**（如底部操作栏随键盘抬升量的默认值）—— 与设计标度无关；
2. **组件私有尺寸**：图标盒、徽标、输入区高度等源自 `AppIcon :size` prop 或组件自身几何的值 —— **未收敛到标度前按文件逐个登记**（收敛会改变观感，属独立设计决策：需 UI/UX 评审后另行立项，不与 token 规范混做）。
   已登记条目：`RetryBlock` 在途旋转环 `44rpx`；`AppButton` 在途旋转环 `28rpx`（文字左侧小号环，环样式与 0.8s 节奏复用 RetryBlock 的环语言）。
