# 前端开发环境配置指南

## 环境要求

- **Node.js** >= 18（推荐使用 [nvm](https://github.com/nvm-sh/nvm) 管理 Node 版本）
- **npm** >= 8（随 Node.js 一起安装）
- **微信开发者工具**（最新稳定版）

---

## 搭建步骤

### 1. 克隆仓库

```bash
git clone <仓库地址>
cd bjtu_food
```

### 2. 进入前端目录并安装依赖

```bash
cd frontend && npm install
```

### 3. 编译为微信小程序

```bash
npm run dev:mp-weixin
```

编译输出目录：`frontend/dist/dev/mp-weixin`

> 如果只需一次性构建（不监听文件变更），可使用：
>
> ```bash
> npm run build:mp-weixin
> ```
>
> 输出目录相同。

### 4. 在微信开发者工具中预览

1. 打开 **微信开发者工具**
2. 点击 **导入项目**
3. **项目目录** 选择：`bjtu_food/frontend/dist/dev/mp-weixin`
4. **AppID**：填写你的微信小程序 AppID（或使用测试号）
5. 点击 **导入** 即可预览

## 常见问题

### Q: 安装依赖时提示权限错误

在 Windows 上请以管理员身份运行终端；在 macOS/Linux 上避免使用 `sudo`，建议使用 nvm 管理 Node 版本。

### Q: 编译时报错"找不到模块"

尝试删除 `node_modules` 和 `package-lock.json` 后重新安装：

```bash
rm -rf node_modules package-lock.json
npm install
```

### Q: 微信开发者工具中页面空白

- 确认编译命令已成功执行完毕（终端无报错）
- 确认导入的目录是 `dist/dev/mp-weixin` 而非项目根目录
- 尝试在微信开发者工具中点击 **清除缓存** -> **全部清除**

### Q: 如何修改小程序 AppID？

编辑 `frontend/project.config.json` 中的 `appid` 字段，或在微信开发者工具中直接修改。
