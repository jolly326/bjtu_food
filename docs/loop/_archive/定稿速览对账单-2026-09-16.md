## 一、产品定位（5 条原则）

- [ y ] 1. **菜品是唯一核心实体**：食堂/档口只是菜品的属性（随录入 upsert，无独立页）
- [ y ] 2. **菜品无审核**：管理员录入即生效（公开唯一判据 `dish.status='on'`）；机检仅 `risky` 拦截 400
- [ y ] 3. **学生一切诉求 = 反馈**（建议 suggestion / 投稿 add / 纠错 error / 举报 report 四类），管理员在「反馈处理」统一处置；无审核、无人工复核
- [ y ] 4. **评价需邮箱认证**（防刷不防看）；反馈/举报免认证；机检 pass/review 一律放行
- [ y ] 5. **无看板、无操作日志、无收藏、无社区/动态**（全部已下线，恢复须重新拍板）

## 二、数据模型（10 张表，逐字段）
数据模型需要重新设计，比如password现在已经没有了你留着干什么，零消费即删除，然后要符合BCNF原则
### user 用户
- [ ] `username` 学号/游客号（唯一）—— W 登录 R 识别
- [ ] `email` 校园邮箱 —— W 认证 R 展示
- [ ] `password` —— **退役留痕，恒 NULL**（管理端口令制；BCrypt 仅用于验证码哈希）
- [ ] `nickname` 昵称 —— W/R
- [ ] `avatar` 头像 —— W/R
- [ ] `status` active/disabled/deleted —— W 管理员禁用 R 过滤
- [ ] `openid` 微信登录识别（唯一）—— W 登录 R 识别
- [ ] `unionid` —— W 登录补全，**暂无读取**（spec 登记多应用预留）
- [ ] `verified` 认证门槛 0/1 —— W 认证 R 写评价/点赞判定
- [ ] `bind_email` / `verified_at` —— W 认证

### canteen 食堂 / stall 档口（菜品属性字典）
- [ ] `name` · `images` · `location` · `description` —— W 后台字典 R 端上筛选/列表
- [ ] `floor` / `window_no`（档口）—— W 录入 R 展示
- [ ] `latitude` / `longitude` —— W 录入 R 端上距离排序
- [ ] `sort_order` —— W 后台 R 排序

### dish 菜品（核心实体）
- [ ] `stall_id` 归属 —— W 录入 R 归属链
- [ ] `name` · `description` · `images` —— W/R
- [ ] `alias` 搜索别名 —— W 管理员 R 搜索命中
- [ ] `price`（分）—— W/R
- [ ] `original_price` / `promo_price` 折扣 —— W 管理员 R 端上划线价/促销标
- [ ] `tags` —— W 管理员（仅 recommended/signature）R 端上筛选/展示
- [ ] `spice_level` 辣度 —— W 管理员 R 端上辣度筛选
- [ ] `status` on/off —— W 管理员 R **公开唯一判据**
- [ ] `reject_reason` —— **退役留痕，恒 NULL**
- [ ] `created_by` —— **只写不读**（upsert 留痕，无展示）
- [ ] `view_count` / `avg_rating` / `rating_count` —— W 事件异步维护 R 热度/榜单/展示

### review 评价
- [ ] `user_id` + `dish_id`（一人一评，唯一索引）· `rating` · `content` · `images`≤3 —— W 学生 R 公开/本人
- [ ] `is_hidden` —— W 管理员事后处置 R 公开过滤/本人标注

### review_useful 「有用」
- [ ] `user_id` + `review_id` —— W 认证学生 R 计数/标记

### notification 通知
- [ ] `user_id` · `title` · `content` · `related_id` · `is_read` —— W 回执投递 R 我的通知
- [ ] `type` —— **仅 `feedback_handle`**（dish_audit 已退役，历史存量容错）

### user_feedback 反馈（唯一诉求通道）
- [ ] `user_id` · `type`（四类）· `content` · `images`≤3 —— W 学生（免认证）R 管理员处理
- [ ] `sub` 二级分类（仅 suggestion：idea/problem）—— W 学生 R 后台展示
- [ ] `contact` —— **历史列**：前端已不收集，新数据恒 NULL，历史值后台可读
- [ ] `status` pending/handled · `reply` · `reject_reason`（不采纳必填）· `handled_at` —— W 管理员 R 回执/后台
- [ ] `related_type` / `related_id` —— W 举报(review)/纠错(dish) R 直达处置
- [ ] `handler_id` —— **退役不写**（单口令无身份）

### email_verification_code 验证码
- [ ] `email` · `code_hash` · `purpose` · `expires_at` · `used_at` —— W/R 认证流

### view_log 浏览足迹
- [ ] `user_id` · `target_type` · `target_id` · `updated_at` 判重 —— W 浏览 R **浏览量统计与当日去重**（无推荐用途）
